# r802A 逐字全文与判非｜工作记忆多成分模型（Baddeley）｜2026-11-23 实拉

## 独点
1. 工作记忆非统一容量槽：1974 三成分（中央执行/语音回路/视觉空间模板）+2000 情景缓冲器；分离证据=声学/语义/视觉选择性干扰。
2. 中央执行=注意控制/抑制/排序/更新/与 LTM 通信，非存储器；情景缓冲器才是其 storage component，绑定多模态成带时序的 episode。
3. 语音回路两层（数秒 sound storage + articulatory processor 复述）；词长效应/发音抑制/语音相似效应为可测指纹；agent 外推标推断。

## 一手逐字（第二独立域）

- "According to their multicomponent conceptualization, working memory comprises a phonological loop ... and a visuospatial sketchpad ... - "A fourth component, the episodic buffer, was added to the model in 2000; it binds together information about the same stimulus or event from the different subsidiary systems to form an integrated representation that is essential to long-term memory storage."
