# r795F｜MI｜双过程再认：熟悉感是连续强度，记得才是带来源的阈值检索

## 独有点

1. 双通道输出：检索须分别给出连续相似度（familiarity，d′/ROC 曲率）与阈值式细节命中（recollection，含 source_id/span/timestamp/context）；只有单一标量判「不可区分熟悉与记得」。Yonelinas 2010 逐字：familiarity 是 quantitative memory strength、recollection 是 threshold retrieval「recall detailed qualitative information…where or when」。

2. 来源可追溯门槛：命中只有 similarity score 而无来源/时间/上下文时，标签固定为 `familiarity-only`，不得写「已记忆/可追溯」。Eichenbaum 2005 逐字：familiarity「offers no information about the order of events」——顺序与情境只有 recollection 给。

3. 评测双口径：在变化的置信阈值下分别报告 hit vs false alarm，并给出 ROC 截距（recollection）与弯曲度/d′（familiarity）；另设 inclusion / exclusion 两条件（PDP：允许用来源 vs 要求排除仅熟悉项）估两过程贡献 `I=R+F−(R×F)`。只报单一 accuracy 判不合格。

## 判重与判非

- 判重：`familiarity` 本体仅 §r747A「熟悉感错觉」一句（巩固效用评级语境），`recollection`/ROC/PDP 专节 0；与本模块错误记忆、编码特异性分工不复用。豆包自留地 WB 0 落地。
