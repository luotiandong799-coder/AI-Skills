# r796F｜MI｜测试效应：检索不是中性读取，短时重读占优、延迟测试占优

访问日期：2026-11-22；每轮独立实拉禁止复用上轮。

## 一手来源逐字

- https://journals.sagepub.com/doi/10.1111/j.1467-9280.2006.01693.x（Roediger & Karpicke，Psychological Science 17(3)，2006，WebFetch 200 逐字：testing effect 定义/5min 与延迟反转/信心提升但保持更差）

- https://journals.sagepub.com/stoken/rbtfl/dEzGRXuJ8AzLI/full（Rohrer & Pashler，Educational Researcher 39(5)，2010，WebFetch 200 逐字：提取直接强化表征/测试+学习优于等时重读/分散学习/回忆优于再认）

## 独有点

1. 短期/延迟交叉反转必须写出：5 分钟后重复学习优于重复测试，但延迟测试（2 天/1 周）下先前测试保持显著更好，即使重复学习提高了学习者信心（Roediger & Karpicke 2006 逐字）。判据——只写「测试永远优于重读」或只写「多复习几遍」均不合格。

2. 机制锚点：提取会直接强化记忆表征（「retrieve … directly strengthen the memory representation」），recall 式测试收益大于 recognition 式多选题；判据——方案无 retrieval 动作、只有 exposure/重读，判「未命中测试效应」。元认知错觉须写进结论：重读提升 confidence 却不提升延迟保持。

3. 三要素可机检：retrieval（recall 非 recognition）+ spacing（分散而非集中，study time is distributed）+ feedback（增强但非必需）；判据——agent 记忆检索「每次检索都强化特定路径」是人类被试结论的跨领域类比，必须标注推断不得当实证引用。

## 判重与判非

- 判重：`测试效应`/`testing effect`/`retrieval practice` 本体 0 命中（retrieval practice 仅豆包自留地一句），与 §r795F 双过程再认、§巩固效用分工不复用。

- 抓取失败：无 WebFetch 失败。agent 外推已标推断。
