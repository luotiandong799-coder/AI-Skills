# r795B｜DI｜二十七、决策滞后 hysteresis：单阈值必震荡，切换规则要有状态与滞回带

## 独有点

1. 判据：实现必须含锁存状态——ON 条件 `PV≤T_low`、OFF 条件 `PV≥T_high`、带内 `state:=prev`；只有单一比较器 `PV vs T` 即判为必 chattering。CMU 讲义逐字：hysteresis 源于「internal state causes the output response to vary based on the history of the input」，双阈值使「small noise variations around a threshold level will not trigger a change」。

2. 滞回带 `ΔH=T_high−T_low` 必须成对配置且 `T_high>T_low`；`ΔH` 要覆盖信号峰峰值噪声，并与最大允许切换频率联动。混合系统实现须让 flow 集 `μ≤δ` 与 jump 集 `μ≥δ` 重叠；边界无缝拼接时「噪声 ε<δ 不误切换」不成立（arXiv:1910.02026 逐字：hysteresis gap prevents chattering）。

3. 决策记录须写明切换成本与滞回带取值理由；若策略切换、告警升降级、资源扩缩容只有一条阈值，判为「未计入切换成本」。与 §十五「单向/双向门」分工：门定流程与谁拍板，本条定状态机的上下界。

## 判重与判非

- 判重：`hysteresis`/`滞后阈值`/`双阈值` 本体全库 0；与 §八 EVPI、§十五 VoI、单向/双向门分工不复用。豆包自留地 WB 0 落地。

- 抓取失败：无。`2–3×噪声` 一类具体倍数非一手来源给出，未写入。
