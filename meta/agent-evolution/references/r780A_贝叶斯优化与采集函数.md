# r780A 下沉全文｜贝叶斯优化与采集函数（AI / agent-evolution）

> 独立实拉 2026-11-20，≥3 独立域一手交叉。正文下沉，SKILL.md §28 留指针以守 500 行上限。

## 一、BO 与 §27 Hyperband 是两条正交路线：一个用代理模型「选哪个配置」，一个用资源分配「怎么筛配置」
- §27 Hyperband 管的是「固定预算下把训练资源在随机采样的候选间重分配」——候选怎么来是随机的，省的是每个候选的训练成本；本章管的是「每个评估都很贵时，用历史观测建一个概率代理模型，主动决定下一个该评估哪个点」——不靠随机，靠 posterior 给出的均值与不确定性。两者可分阶段叠加（多保真 BO = 代理模型 + 便宜近似评估），但命题不同，不合并。
- 一手定义逐字（arXiv 2507.15138 §1）：「Bayesian Optimization (BO) is a sequential design technique for black-box, expensive-to-evaluate, potentially noisy, and gradientless function optimization」「The BO framework is composed of two parts: a probabilistic surrogate model that estimates the objective function, and an acquisition function that is used for choosing the next evaluation point」。BO 的适用前提是「贵、黑盒、无梯度、带噪」——落在 agent 自改进上就是「每次改版都要真跑一批任务、无法求导、指标有噪声」的场景。
- GP 为什么是默认代理：逐字「Gaussian Processes have been the most popular surrogate model because they are flexible, analytically tractable, and have intrinsic quantification of uncertainty」，且给的是「full posteriors of the objective function that is calibrated given the history of the observation」。后验均值 μ 是「目前认为函数在这里是多少」，后验方差 σ² 是「这个估计有多不确定」——两者一起才构成采集函数的输入。
- 成本边界要实报：arXiv 2004.10599 §2.2 逐字「Exact inference in Gaussian process regression requires inverting the matrix K, typically at each iteration. This is usually done by Cholesky decomposition whose cost scales like O(n³)」，但「in Bayesian optimization the number of observations ... rarely exceeds a few dozens (or perhaps a few hundreds), as an unreasonably large number of observations would defeat the whole purpose of the algorithm」⇒ Declaration「用了 BO」须连观测次数 n 与 GP 求逆成本一起报，n 上千时 BO 的便宜前提已不成立。

## 二、采集函数是「均值 vs 不确定性」的旋钮，不是越激进越好
- 平衡的本质逐字（NUBO arXiv 2305.06709 §2.2）：exploration 是「areas with no or only a few observed data points where the uncertainty of the Gaussian process is high」，exploitation 是「areas where the posterior mean of the Gaussian process is large」，且「This exploration-exploitation trade-off ensures that Bayesian optimisation does not converge to the first (potentially local) maximum it encounters, but efficiently explores the full input space」。⇒ 采集函数的设计目标不是「挑均值最高的配置」，是「不陷进第一个局部最优」。
- 三种经典采集函数及旋钮（arXiv 2507.15138 §2.3 + NUBO §2.2.1 逐字）：
  - **EI**：`α_EI(x)=E[max(f(x)−f(x⁺),0)]`，f(x⁺) 是当前最优；闭式 `(μ_n(x)−y^best)Φ(z)+σ_n(x)φ(z)`，`z=(μ_n(x)−y^best)/σ_n(x)`。EI「selects points with the biggest potential to improve on the current best observation」，无额外旋钮。
  - **PI**：`α_PI(x)=P(f(x)>f(x⁺)+ξ)`，ξ 是 trade-off 项——「biased toward exploitation as ξ tends toward zero and toward exploration for large ξ」。
  - **UCB**：`α_UCB(x)=μ(x)+κσ(x)`（NUBO 写 `μ_n+√β·σ_n`），κ/β 越大越探索——「larger values of κ encouraging more exploration」；β 在自适应版本里是学习率、控制调节速度「Larger values lead to more rapid adaptation but may result in unstable behavior」。
- 为什么这三个流行（arXiv 2004.10599 §2.3 逐字）：「implementation is straightforward, evaluation is inexpensive, and gradients are readily accessible, opening the door for gradient-based optimizers」——可微是关键，才能用 L-BFGS-B/SLSQP 直接最大化采集函数（NUBO §2.2.1）。
- 一个易错点（arXiv 2004.10599 §2.3）：LCB 是把「纯探索、全局降不确定性的 σ(x)」repurpose 成 BO 可用的形式——append μ(x) 并引入权衡 κ；IVR 同理 repurpose 成 `μ(x)−κ·a_IVR(x)`。⇒ 只看公式里的 μ+κσ 就说是「置信上界」会丢掉它来自探索函数这一来源，调 κ 的语义就讲不清。
- 判据：报告「用 BO 调参」必须写 ①代理模型（GP/TPE/其他）②采集函数（EI/PI/UCB/Thompson）③旋钮值（ξ/κ/β）与为何此值 ④当前最优 y^best 的定义；只报「贝叶斯优化」等于没报采集策略。

## 三、单点顺序 vs 并行批/异步：解析采集函数失效，须换 Monte Carlo 近似
- 硬边界逐字（NUBO §2.2.1→§2.2.2）：「the use of analytical acquisition functions is restricted to sequential single-point problems for which every point suggested by Bayesian optimisation is observed via the objective function f(x) immediately before the optimisation loop is repeated」；「For parallel multi-point batches or asynchronous optimisation, the analytical acquisition functions are in general intractable」。
- 解法逐字：从后验直接大量采样、对采集函数取 Monte Carlo 平均，「made viable by the reparameterisation of the acquisition functions and the computation of samples from the posterior distribution via base samples randomly drawn from a standard normal distribution z∼N(0,1)」：`α_EI^MC(X*)=max(ReLU(μ_n(X*)+Lz−y^best))`、`α_UCB^MC(X*)=max(μ_n(X*)+√(βπ/2)|Lz|)`，L 是协方差 Cholesky 下三角；「Due to the randomness in the Monte Carlo samples, these acquisition functions can only be optimised by stochastic optimisers, such as Adam」。
- 异步还有一条逐字：pending points「can be added to the test points but are treated as fixed... they affect the joint multivariate normal distribution but are not considered directly in the optimisation」，且「particularly beneficial for objective functions for which the evaluation time varies」——评估耗时不等时可一边等一边继续选点。
- 落到 agent 自改进：多 agent 并行跑实验 = multi-point batch，不能把单点 EI 的闭式公式直接套；要么用 MC 采集 + 随机优化器，要么显式声明「本批是顺序单点、BH 已锁定」。这条与 §22 并发实验分层互补——那章管「流量/参数不打架」，本章管「同时评估多点时采集函数怎么算」。

## 四、三类扩展各有其存在理由，不是同一招的三个名字
- 逐字（arXiv 2507.15138 §2.3）：「multi-fidelity optimization, the use of inexpensive surrogates of the objective function for an optimization process acceleration; batch optimization, choosing many points of an entire iteration for exploitation of parallel evaluation opportunities; and high-dimensional BO, concentrating on overcoming difficulties of optimizing high-dimensional functions by dimensional reduction or structured kernels」。
- 与既有章节分工：multi-fidelity 与 §27 Hyperband 的「多保真资源分配」相接，但 BO 侧是代理模型选点、HB 侧是 bracket 预算网格；high-dimensional BO 的降维/结构核是 BO 专属，§27 未覆盖；batch 与上面第三节的 MC 采集相接。
- 成本固定项：GP 精确推断 O(n³) 在 n 达数百后成为瓶颈，此时要么限制观测数、要么换可扩展代理（如 TPE/随机森林 surrogate），但换了代理就不再是「GP 后验 + 解析采集函数」那套公式，报告须换说法。
