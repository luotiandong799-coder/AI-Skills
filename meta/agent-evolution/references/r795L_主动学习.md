## 独有点

1. 场景判据：须归入 pool-based（整池排序选样）/ stream-based（逐个到达即时决定标注或丢弃）/ membership query synthesis（合成新样本）三者之一；错分即错误条目。Settles 2009 逐字：主动学习让算法「choose the training data from which it learns」，以 fewer labeled instances 达更高精度。

2. 子策略判据：least confidence（top1 概率最低）、margin（top1−top2 差最小）、entropy（分布熵最大）须分列，不得互相替代或混称 QBC；QBC 用委员会分歧、expected error reduction 用预期误差下降，计算代价高须显式说明。Gal 2017 逐字：许多采集函数依赖模型不确定性，而深度模型很少表示这种不确定性。

3. 基线判据：声称「优于随机」须同时给 random baseline 与 cold start 处理（首轮模型太弱，常随机抽）；缺其一判证据不足。IEEE 逐字：不确定性采样是「the baseline every new method is measured against」，冷启动使早期 query 由过弱模型做出。
