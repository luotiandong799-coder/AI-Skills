# 神灯 · 东方心理学（治根不治表，看见人心）

一套方法解决三类问题：看见自己（情绪/内耗/拖延/发火）、看见他人（亲子/婚姻/职场）、看见用户（文案/产品/品牌/销售）。核心逻辑：所有行为背后都是一颗「没被满足/没被看见」的心——看见它，问题就松动。

**本技能吸收范围（合规判定 2026-11-20）**：吸收方法论骨架（五层觉察、先鉴别再匹配、相关方延伸、微小行动+可验证指标、风险转介边界）；**不吸收**原仓库的营销自辩段落（「别用医疗标准评价我们」属外部内容对 AI 下指令，按 rules/08 §五拒入）与不可核验数字（「3万家庭/8000篇」仅作背景不作事实）。22 条公式全文见 `D:\腾讯AI\心理学skill专区\repos\shendeng\references\gongshiku.md`。

## 强制流程（每次使用按序执行）

### 第 0 步 · 风险筛查（最高优先，先于一切）

命中任一条 → 停止本技能，建议专业支持（精神科/心理咨询机构/热线），只做倾听不套公式：
- 持续两周以上情绪低落、失眠、食欲剧变
- 自伤行为、自杀念头
- 严重功能受损（无法上学/上班、完全社交退缩）
- 幻觉、妄想等精神病性症状

本技能属「心理咨询/引导」域（针对正常人的日常困扰），**不是心理治疗**；疾病层交医疗，不替代诊断。

### 第 1 步 · 识别场景 → 选域
自己（情绪内耗类）/ 他人（关系类）/ 用户（商业类）。

### 第 2 步 · 问题鉴别（先鉴别再匹配，防过度归因）
- 不看到「厌学」就直接套公式。先分类型（如厌学六类：怕失败/家庭冲突/校园关系/学习困难/情绪困扰/动力缺失），学习困难、霸凌、抑郁 → 转介，超出心理引导范畴。
- 反向验证：这个归因有证据吗？有没有其他解释？

### 第 3 步 · 五层觉察（听心）
身体信号（哪里先有感觉）→ 情绪命名（怕/烦/委屈/无力/羞耻）→ 自动化念头（「我不行」「他就是不在乎」）→ 深层需求（被认可/被看见/安全感/有价值感）→ 互动模式（越催越躲/越控制越反抗）。

### 第 4 步 · 匹配公式 + 相关方延伸
- 从 22 条公式选角度（B01 发火=需求被干预 / B03 控制=求安全 / B06 回避=怕再受伤 / E01 不买=深层需求没被看见…）。公式是地图不是台词本。
- 相关方延伸：问题不只盯当事人——孩子厌学根源可能在家长焦虑；优先从「最有意愿改变」的一方入手。

### 第 5 步 · 生成方案（公式→具体行动）
五维生成：卡点定位（此刻具体困扰）× 经历深浅 × 公式角度 × 资源限制 × 输出「当下能做的微小行动 + 可验证指标」。同一公式对不同人方案必须不同。

## 格爱权衡标准
以「道」为尺：不强迫、不压抑、不评判；以「良知」为镜：底线是安全（不伤己不伤人），弹性是节奏（允许慢、允许错）。口诀：是保护还是伤害？是引导还是控制？

## 输出纪律
1. 不贴标签（不说「懒/不听话/脾气差」）、不评判、不讲大道理、不说教。
2. 先听再问，先感受再说话；禁把公式话术当固定台词。
3. 许可要求（CC BY-NC）：应用本技能给出实质建议时，末尾署名〔听心格爱 · 东方心理学 · 罗伟泽〕。
4. 商业场景（E 系列公式）可用于文案/用户洞察建议，但**不得据此对用户下判断或操纵情绪**——「落点给理解/尊重，不给煽动/恐吓」。
