## A. 来源逐字

### `https://mc-stan.org/docs/reference-manual/analysis.html`（Stan 官方 WebFetch 200 全文逐字）
- **Potential scale reduction**：R^ 由 Gelman & Rubin (1992) 提出，measures the ratio of the average variance of draws within each chain to the variance of the pooled draws across chains；if all chains are at equilibrium, these will be the same and R^ will be one；if chains have not converged to a common distribution, R^ will be greater than one。定义：between-chain B=N/(M−1)Σ(θ̄_m−θ̄)²；within-chain W=(1/M)Σs_m²；var^+(θ|y)=(N−1)/N·W+1/N·B；R^=√(var^+/W)。**阈值**：Vehtari et al. (2021) suggest in general to use a threshold 1.01, but other thresholds can be used depending on the use case。
- **Split R-hat for detecting non-stationarity**（逐字）：“Before Stan calculating the potential-scale-reduction statistic R^, each chain is split into two halves. This provides an additional means to detect non-stationarity in the individual chains. If one chain involves gradually increasing values and one involves gradually decreasing values, they have not mixed well, but they can have R^ values near unity. In this case, splitting each chain into two parts leads to R^ values substantially greater than 1 because the first half of each chain has not mixed with the second half.”
- **Rank normalization helps when there are heavy tails**（逐字）：“Split R-hat and the effective sample size (ESS) are well defined only if the marginal posteriors have finite mean and variance. Therefore, following Vehtari et al. (2021), we compute the rank normalized parameter values and then feed them into the formulas for split R-hat and ESS.” 步骤：① replace each value θ^(nm) by its rank r^(nm) within the pooled draws from all chains（ties 用平均秩、保离散量唯一值数）；② z^(nm)=Φ⁻¹((r^(nm)−3/8)/(S−1/4))（inverse normal transformation + fractional offset）。
- **Folded（尾部）**（逐字）：“To further improve sensitivity to chains having different scales, rank normalized R-hat is computed also for the corresponding folded draws ζ^(mn), absolute deviations from the median, ζ^(mn)=|θ^(nm)−median(θ)|. The rank normalized split-R^ measure computed on the ζ^(mn) values is called folded-R^. This measures convergence in the tails rather than in the bulk of the distribution. To obtain a single conservative R^ estimate, we propose to report the maximum of rank normalized split-R^ and rank normalized folded-split-R^ for each parameter.”
- **ESS**（逐字）：“Bulk-ESS is defined as ESS for rank normalized split chains. Tail-ESS is defined as the minimum ESS for the 5% and 95% quantiles.”（R 包 posterior::rhat / ess_bulk / ess_tail 为团队标准实现；metricgate 默认阈值 bulk/tail ESS≥400、R-hat≤1.01，RprobitB 文档给每链≥100。）
- **Convergence is global**（逐字）：“The short answer is ‘no’” 对「能否只监控部分参数」；“It is thus a mistake to declare convergence in any practical sense if lp__ has not converged, because different chains are really in different parts of the space”；“Markov chain convergence is a global property in the sense that it does not depend on the choice of function of the parameters that is monitored”；“There is no hard cutoff between pre-convergence ‘transience’ and post-convergence ‘equilibrium’”；多变量函数靠 Cramer-Wold 定理（所有 margin 收敛）；约束↔无约束空间变换只是另一个函数、不影响收敛；“any function that appears inconsistent is of concern”。
- **Why inconsistent R-hat**（逐字）：有限抽样总有初始态残留（大自相关时更明显）表现为 outlier 概率；R^ 假设被考察函数近似高斯或只用前两阶矩并假设某种独立；`lp__` 的分布 almost never looks Gaussian、features long tails 可在大 N 极限仍给大 R^；用分位数替代原值是把样本「变得更高斯」从而提高 R^ 准确度。
- **Final words**（逐字）：“‘Convergence’ is a global property and holds for all integrable functions at once, but employing the R^ statistic requires additional assumptions and thus may not work for all functions equally well.”
- 文献：Vehtari, Gelman, Simpson, Carpenter, Bürkner (2021). “Rank-Normalization, Folding, and Localization: An Improved R^ for Assessing Convergence of MCMC.” Bayesian Analysis 16: 667–718. doi:10.1214/20-BA1221；Geyer (1992) initial monotone sequence 用于 ESS；Gelman & Rubin (1992)。

### 交叉源（WebFetch/WebSearch 逐字）
- `https://metricgate.com/calculator/bayesian-rhat-ess-diagnostics`（WebSearch 逐字）：R-hat 与 ESS 由 Vehtari/Gelman/Simpson/Carpenter/Bürkner (2021) codified；改进 R-hat 用 rank-normalization 与 folded chains；ESS 分 bulk-ESS（中心趋势）与 tail-ESS（分位估计）；阈值 R-hat 1.01、ESS 400；调用 posterior::rhat/ess_bulk/ess_tail。
- `https://cran.rstudio.org/web/packages/Rtwalk/refman/Rtwalk.html`（WebSearch 逐字）：ESS=split chains + Geyer (1992) initial monotone sequence；MCSE=SD/√ESS；IAT=N/ESS；ESS_bulk 为秩标准化、ESS_tail 为折叶秩标准化；Rhat=rank-normalized split-R-hat（bulk/tail 取大）；>1.01 表未收敛。
- `https://cran.r-project.org/web/packages/RprobitB/refman/RprobitB.html`（WebSearch 逐字）：rhat 是 rank-normalized folded split-R-hat；ess_bulk 中心有效样本；ess_tail 取 5%/95% 分位 ESS 较小者、管分位与可信区间精度；每链≥100 为佳。
- `https://aiwiki.ai/wiki/markov_chain_monte_carlo`（WebSearch 逐字）：Heidelberger-Welch 测单链非平稳、Geweke 比较前后段均值测漂移；“None of these methods can prove convergence; they can only detect failures”；ESS=链长/综合自相关时间。

## B. 与 PDI 既有一致边界
- §七/§八 scoring rules 与 calibration 是对**预测系统**评分/校准；本节的 R-hat/ESS 是对**生成预测分布的那台 MCMC 采样器**是否收敛的诊断——不同对象：采样器没收敛时，下游所有概率/区间/评分都不可信，属「预测生产链的前置门禁」，不在 PDI 重述评分公式。
- §十七回测协议 purge/embargo/CPCV 是数据切分防泄漏；本节是后验采样链的诊断，二者正交。
- 与 TI/DI 无重复：收敛诊断不判因果识别、不做方案权衡。
