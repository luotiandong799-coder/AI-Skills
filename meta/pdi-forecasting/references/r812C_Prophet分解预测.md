# r812C · Prophet 分解预测：把预测拆成趋势+季节+节假日的可解释曲线拟合

> PDI · 2026-11-27 独立实拉，≥2 独立域一手交叉（Taylor & Letham《Forecasting at Scale》论文全文笔记 + Meta 官方 Prophet 文档逐字），3 独点。
> 定位：§r803C ETS 给「指数平滑状态空间 + 自动选模 + 区间」、§r754C 多步策略给 Recursive/Direct 等、§r737C conformal 给覆盖保证；本章管**曲线拟合式的可分解回归预测**——不显式建模时间依赖结构，而是把序列拆成可解释、可由分析师直接调的若干时间函数之和。

## 独点1 模型形态：GAM 式分解，曲线拟合而非显式时间依赖建模
- 《Forecasting at Scale》（Sean J. Taylor & Benjamin Letham，The American Statistician 2018，PeerJ preprint 3190）逐字：用 decomposable time series model（Harvey & Peters 1990），三主成分 trend / seasonality / holidays 加一个 error term：`y(t)=g(t)+s(t)+h(t)+ε_t`，其中 g(t) 趋势（非周期变化）、s(t) 周期变化、h(t) 节假日（可能不规律的日程，跨一天或数天）、ε_t 模型未容纳的特质变化（假设正态分布）。
- 「This specification is similar to a generalized additive model (GAM)」，「We use only time as a regressor but possibly several linear and non-linear functions of time as components」。原文明确「framing the forecasting problem as a curve-fitting exercise, which is inherently different from time series models that explicitly account for the temporal dependence structure in the data」——这是 Prophet 与 ARIMA/ETS 的根本分工，不是同一类模型的参数变体。
- 实用优势（原文逐字）：① 灵活容纳多周期季节、分析师可对趋势作不同假设；② 不像 ARIMA「the measurements do not need to be regularly spaced, and we do not need to interpolate missing values e.g. from removing outliers」；③ 拟合快；④ 参数可解释、可由分析师改以注入假设；⑤ 易扩展新成分（如新发现的季节性）。判据：数据有缺失/不等间隔/异常值剔除后留洞、需要业务人员直接调趋势与节假日时优先；需要显式自相关结构、严格平稳推断时不是它的主场。

## 独点2 三组件机制：分段增长 + changepoint、Fourier 季节、节假日窗口与先验
- **趋势 g(t)**（论文 §3.1 + Meta 文档）：两种形态——饱和（saturating）增长模型用 logistic `C/(1+e^{−k(t−m)})`（C 承载容量、k 增长率、m 偏移），且容量随时间变 C(t)；分段线性（piecewise linear）模型用于无明确上限的指标。changepoints 是增长率允许改变的点，可分析师指定或从候选集自动选择；一个参数控制趋势灵活性（改 rate 的幅度）。原文「The uncertainty in the trend is measured assuming the future will see the same average frequency and magnitude of rate changes that were seen in the history」——趋势不确定性区间假设**未来变点频率/幅度与历史一致**，结构突变期会失效。
- **季节 s(t)**（论文 §3.2 + Meta 官方文档逐字）：用傅里叶级数提供周期性效果的灵活模型，「Seasonalities are estimated using a partial Fourier sum」，「The number of terms in the partial sum (the order) is a parameter that determines how quickly the seasonality can change」。默认值：`yearly` Fourier order=10、`weekly`=3；「Increasing the number of Fourier terms allows the seasonality to fit faster changing cycles, but can also lead to overfitting: N Fourier terms corresponds to 2N variables used for modeling the cycle」。判据：报季节设置写清 order 与各组件，高 order 是过拟合旋钮不是免费提精度。
- **节假日 h(t)**（Meta 官方逐字）：分析师提供 `holiday`/`ds` 两列的过去与未来事件表（未来不重复的节日会建模但不进预测）；`lower_window`/`upper_window` 把节假日效果扩到前后数天（圣诞前夜 `lower_window=-1,upper_window=0`，黑五 `upper_window=1`）；`prior_scale` 可逐节日设，全局 `holidays_prior_scale` 默认 10「provides very little regularization」，观测最少的节日（如超级碗）过拟合时调小该参数平滑。超一个节日同时列两类（playoff 与 superbowl）时效果是叠加的 additive bonus。

## 独点3 Analyst-in-the-loop + 自动评估：人调可解释旋钮，机器大规模筛坏预测
- 论文第 3.5 节「Analyst-in-the-Loop Modeling」：blends statistical and judgemental forecasts——分析师通过少量直观参数（容量 capacity、changepoints、节假日/季节、平滑参数、趋势灵活性与季节强度）注入判断，同时保留必要时退回全自动统计预测的能力。要点：Prophet 的「可调」不是模型精度旋钮，而是**业务假设的注入口**。
- 自动评估（论文 §4）：用 baseline forecasts 与 MAPE（为可解释性）建模准确度；**Simulated Historical Forecasts（SHF）** 在历史多个 cutoff 生成 K 个预测，「simulate the errors we would have made had we used this forecasting method at those points in the past」，简单、可解释、相对无争议。三个诊断：① 某方法误差相对 baseline 大→模型可能误设，调趋势/季节；② 某日期所有方法误差都大→提示异常值，可剔除；③ 某方法 SHF 误差临近某 cutoff 陡增→数据生成过程变了，加 changepoint 或分阶段建模。注意「The more simulated forecasts we make, the more correlated their estimates of error are」——SHF 条数不是独立证据数（与 PDI §r762C CPCV「splits 多不等于独立证据多」同族）。
- 边界与不防：不显式建模时间依赖结构（曲线拟合前提）；季节是固定周期傅里叶近似，多重非整数周期/时变周期需另设 custom seasonality；趋势区间依赖「未来变点统计同历史」假设；缺失/异常鲁棒来自把预测当曲线拟合而非插值，但不等于对结构突变免疫；单变量（仅时间回归量），外生回归量需走 extra regressors 的加/乘组件并声明。
- 判重：`Prophet`/`贝叶斯加性`/`Forecasting at Scale`/`傅里叶季节` 在 pdi-forecasting SKILL.md 与 module-memory PDI 0 专节；co-learn workbuddy/doubao 标题级 0。与 §r803C ETS（状态空间自动选模+区间）/§r754C 多步策略/§r794C conformal（覆盖构造）/§r762C CPCV（回测协议）分工：本章管可分解可解释的曲线拟合预测本体，不复用其评分/覆盖/回测协议。豆包自留地 WB 0 落地。按「增＝加厚现有」0 新建 / 0 合并 / 0 删除。
