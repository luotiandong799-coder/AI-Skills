# r796I｜OI｜汇合同步 barrier：Cyclic 可复用、Latch 一次性，坏一个全坏

访问日期：2026-11-22；每轮独立实拉禁止复用上轮。

## 一手来源逐字

- https://docs.oracle.com/en/java/javase/21/docs/api/java.base/java/util/concurrent/CyclicBarrier.html（Oracle Java SE 21 官方 API，WebFetch 200 逐字：全员 await 放行/可复用/BrokenBarrierException 与 broken 态）

- https://docs.oracle.com/en/java/javase/21/docs/api/java.base/java/util/concurrent/CountDownLatch.html（Oracle Java SE 21 官方 API，WebFetch 200 逐字：one-shot count cannot be reset/await 阻塞至零/countDown 方不必等）

- https://airflow.apache.org/docs/apache-airflow/stable/core-concepts/dags.html（Apache Airflow 官方，WebFetch 200 逐字：all_success 默认/all_done/one_success）

## 独有点

1. 放行条件不可互换：CyclicBarrier ⇔ `getParties()` 个参与方都调 `await()` 才放行且释放后可复用（cyclic）；CountDownLatch ⇔ `getCount()==0` 放行，one-shot「count cannot be reset」，且调用 countDown 的线程不必等归零。判据——需要可复用同步点却用 Latch、或反之，判错配（Oracle Java 21 官方 API 逐字）。

2. 失败传播 all-or-none：任一参与方 interrupt / timeout / barrier action 抛异常 → 其余所有等待方抛 `BrokenBarrierException`，barrier 置 broken 态；超时版额外抛 `TimeoutException`。判据——汇合点未定义 broken 态与超时出口，判「参与方不足可永久挂死」（该风险由 await 语义推出，非独立论文逐字）。

3. DAG join 映射：trigger rule 决定汇合——`all_success`（默认，全上游成功）/ `all_done`（不分成败）/ `one_success`（任一成功即放行）；barrier 语义对应前两者，不对应 `one_success`（Airflow 官方逐字）。判据——把 barrier 直接等同于任意 join 判错；分布式屏障的失败传播外推须标推断（Spark barrier 章节未取到一手）。

## 判重与判非

- 判重：`屏障`/`barrier` 本体命中为 actor mailbox/其他语境，同步屏障专节 0；与 §r795I DAG 调度、§r793A Temporal 确定性分工不复用。豆包自留地 WB 0 落地。
