# wb-experiment-design（对照实验设计）

来源：GitHub `coreyhaines31/marketingskills`·`skills/ab-testing/SKILL.md` 13,346B + `references/sample-size-guide.md` 9,183B（★59k，2026-11-08 一手实拉）。只取统计与流程判据，不取营销话术。

## 一、四个必填输入（缺一个就别开跑）

| 输入 | 含义 | 常见错 |
|---|---|---|
| 基线率 | 当前转化率，**用该指标该页面的**，不用全站均值 | 拿站点平均顶替具体页 |
| MDE | 你真正在乎能测到的最小提升 | 凭"想变好"定，不结合成本与历史 |
| α | 通常 0.05（双侧） | 当成"差异是偶然的概率"（它不是） |
| power | 通常 80% | 不写，跑完才发现不足 |

## 二、样本量与时长

- 均衡分配：`时长(天) = 每变体样本 × 变体数 / (日均可随机化流量 × 曝光比例)`
- 不等分配：**逐臂算，取最长的那条**：`该臂样本 / (日流量 × 曝光 × 该臂分配比例)`
- 重复 pageview 不算新参与者；随机化单位要与算样本时用的单位一致。
- **最短时长**：至少 1 完整周（吃工作日/周末差异）；B2B 走 2 个业务周期；电商要跨过发薪日。
- **最长 4–8 周**：新奇效应会衰减、外部因素会插进来、还占着别的实验的机会。

## 三、多变体要加样本，不是加流量

2 变体 ×1；3 变体 ≈×1.5；4 变体 ≈×2；5+ 先减少变体。多做比较会抬高假阳性，需要 Bonferroni 之类校正。

## 四、五类常见错

1. **欠功效**：样本不够测真实效应 → 务实调 MDE、加流量，或**明确不做**。
2. **过度等**：已经显著还想等满样本 → 既然事先承诺了样本量，就守约跑完，别提前停。
3. **基线用错**：用全站均值代替具体页面/具体指标。
4. **先按全量算、再拆细分**：要做分群分析，就按**最小分群**算样本。
5. **同时测太多**：流量被切碎 → 砍到少数几个优先级最高的并发实验。

## 五、样本要求过高时（七条退路，按顺序想）

抬高 MDE（只测 20%+ 的提升）→ 降到 90% 置信（有风险，须记录）→ 减变体 → 合并相似页面 → **把实验上移到漏斗更早、流量更大的环节** → 改用定性证据决策 → 接受更长周期。

## 六、提前看结果的代价

未到样本量就看数据，会让 α 失效；必须提前看（高风险改动、要早停坏变体）时，用**顺序检验**（Optimizely Stats Accelerator / VWO SmartStats / PostHog 贝叶斯），代价是样本需求略增、分析更复杂。

## 七、决策框架（抄下来填）

```
日均可随机化流量 ___ / 曝光比例 ___ / 臂数 ___ / 各臂分配 ___
基线率 ___ / 我在乎的 MDE ___
每变体样本 ___（查表或计算器）
均衡：天数 = 每臂样本 × 臂数 /（日流量 × 曝光）
不等：天数 = max(各臂样本 /（日流量 × 曝光 × 该臂比例）)
向上取整，再套最短/最长时长规则
天数 >60 → 换设计；>30 → 只给高影响实验；<14 → 可行；<7 → 能跑，但仍建议跑满一周
```

## 八、判据

- **没有 MDE 就没有实验**：说不清"要测多大的变化"，样本量与时长的所有计算都是空的。
- **样本不够时的正确动作是改设计或放弃**，不是"先跑着看"——跑着看得到的是噪声，还会被当成结论。
- 任何一个"显著"结论都要能回答：样本量是多少、跑了多久、中途看过几次。
