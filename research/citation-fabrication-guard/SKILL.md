# research/citation-fabrication-guard

## 为什么会假

- 模型产出的不是检索结果，而是「看起来像参考文献」的字符串分布：期刊名、作者、年份、卷期页码各自都合理，凑在一起并不存在。
- 中文文献比英文更易假：中文期刊题录在训练语料里覆盖稀薄，模型按「像中文期刊的格式」补空。
- 不是模型「不认真」，是这个任务在生成范式下没有真值来源——所以只能靠外部核对，不能靠模型自查。

## 高发四型（核对时按型对号）

1. 真期刊 + 真作者 + **假文章**（最常见，最容易被格式糊弄过去）
2. 真文章 + **错年份/卷期/页码**
3. 预印本（arXiv/SSRN）被说成**已正式发表**
4. **两篇拼接**：A 的作者 + B 的标题 + C 的期刊

## 四核对闸门（每条引用必须全过）

1. **标识可解析**：doi.org / Crossref 能返回该条题录，才算存在；无 DOI 的走期刊官网或知网篇名精确检索。
2. **题录四要素对齐**：标题、作者、期刊/会议、年卷期页，逐项与原文页面比对，不是「大概一致」。
3. **原文可及**：能打开摘要页或原文；只有题录、没有原文 → 标注「仅题录核实」，不得以它支撑具体数据。
4. **语境匹配**：这篇确实支持你要它支撑的那句话——读摘要与结论，不看标题猜。

## 处理规则

- 未过闸门的引用：正文里不许出现；确需提及一律写「未能核实」。
- AI 起草的综述、引言、理论框架里的引用，**先跑闸门，再谈格式**。
- 严禁用「格式正确」代替「存在且相关」；格式越漂亮越要警惕。
- 找不到不是「再搜一次」，是该条作废；换一条真文献，不要换一种说法留假引用。

## 交付格式

一张表：引用原文 → 核实等级（全部核实 / 仅题录 / 未核实）→ 证据链接或检索路径 → 处置（保留 / 替换 / 删除）。

## 工具路径

- 英文：Crossref/DOI 解析、`arxiv.org/abs/<id>` 取 `citation_title` 与摘要（arXiv API 限流时走 abs 页，别反复打 API）
- 中文：知网/万方篇名精确检索、期刊官网当期目录；核对「作者-单位-基金」是否自相矛盾
