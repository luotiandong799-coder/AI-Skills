# Windows 界面自适应重识别（自适应"眼睛"层）

> 本技能是 Windows 操控的**鲁棒性层**：当环境变化导致原定位失效时，按稳定属性重新识别目标。识别手段本身在 `winapp-ui-automation`，输入/视觉在 `computer-use-windows`。

## 一、铁律

**不依赖固定坐标、不依赖固定布局。** 同一控件在不同机器/版本/缩放下坐标不同，只有属性与相对特征是稳定的。

## 二、定位优先级（环境变化时重排）

1. **控件属性**：AutomationId / Name / ControlType（最稳，跨 DPI/主题不变）
2. **文本 / 窗口标题**：用 ClassName/AutomationId 而非可见文本（抗语言切换）
3. **视觉特征**：颜色/形状/比例区域（自绘应用兜底，如微信绿 `#07C160`）
4. **坐标兜底**：仅最后手段，且用窗口 rect 实时计算，不硬编码像素

## 三、环境变化清单与应对

| 变化 | 风险 | 应对 |
|---|---|---|
| **DPI / 缩放** | 像素坐标漂移 | 用 UI 树坐标 / 相对比例，禁硬编码像素 |
| **主题（浅/深）** | 颜色判据失效 | 颜色阈值分浅深两套，或改用非颜色特征 |
| **语言（中/英）** | 文本定位失败 | 用 ClassName/AutomationId/控件结构 |
| **窗口大小/位置** | 绝对坐标错 | 基于窗口 rect 实时计算目标区 |
| **软件版本升级** | 控件树结构变 | 退回视觉/OCR，重新探查树 |
| **动态界面（弹窗/加载）** | 目标暂不存在 | 等待+轮询，确认出现再定位 |

## 四、重识别流程

```
感知当前环境（DPI/主题/语言/窗口状态）
→ 比对"当前状态 → 目标状态"
→ 用最稳属性重定位
→ 校验目标确实是预期的（读回属性/截图）
→ 环境再变则重新走本流程
```
