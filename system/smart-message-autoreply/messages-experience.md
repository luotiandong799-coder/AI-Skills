# 消息回复经验库（由 smart-message-autoreply 技能维护）

> 只存**跨会话可复用**的回复经验：联系人/群聊风格、场景规律、成功与失败策略、人工修改规律、效果与可信度。
> 驱动细节（怎么点、怎么发）在 `win-native-app-automation`；操作方式择优在 `windows-ops-experience`。
> 更新纪律：**实测验证后才写/改**；不靠推测升级；旧经验与近期实际冲突 → 以降权处理（见 SKILL §十五）。
> 目标：**经验越来越精，而不是越来越多。**

## 单条经验结构
`联系人/群聊 → 场景/消息类型 → 最优回复方式(含 why) → 易错点 → 历史失败原因+正确做法 → 可信度(候选/已验证/多次验证/失败/过期) → 验证状态 → 人工修改记录 → 更新时间`
