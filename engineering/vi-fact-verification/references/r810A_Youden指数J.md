# r810A · Youden 指数 J（VI · 2026-11-26 实拉）

## 定义与量纲（逐字）
- Wikipedia 镜像（wikipedia.com/wiki/Hanssen–Kuipers_discriminant，WebSearch 全文逐字；Wikipedia 原页 WebFetch failed，如实登记未冒充一手）："Youden's J statistic ... J=sensitivity+specificity−1=recall1+recall0−1=TPR+TNR−1"；展开式 "J=TP×TN−FP×FN / ((TP+FN)(TN+FP))"；"Its value ranges from -1 through 1 (inclusive), and has a zero value when a diagnostic test gives the same proportion of positive results for groups with and without the disease, i.e the test is useless. A value of 1 indicates that there are no false positives or false negatives"；"The index gives equal weight to false positive and false negative values, so all tests with the same value of the index give the same proportion of total misclassified results"；负值 "just indicates that the positive and negative labels have been switched"。
- ScienceDirect S0167947314000450（WebSearch 摘要+Introduction 全文逐字）："the Youden index (defined as J=maxc{Sensitivity(c)+Specificity(c)−1} Youden, 1950)"；"The optimal cut-off point is determined at where the maximum of Sensitivity(c)+Specificity(c) is achieved"；"It is obvious that markers with the same Youden index can have very different sensitivity and specificity at the optimal cut-off point ... their corresponding sensitivity and specificity differ greatly"。
- ScienceDirect S0167947317300592（WebSearch 摘要+Introduction 全文逐字）："Graphically, the Youden index is the maximum vertical distance between the ROC curve and the diagonal chance line"；"The cutoff point, where the maximum is achieved, provides an optimal threshold for the clinicians to use the diagnostic test for classification if equal weight is placed on sensitivity and specificity"；"Zhou and Qin (2012) ... their modified bootstrap method was comparable to parametric methods when distribution assumption holds unless the Youden index is close to upper boundary (J≥0.90)"。
- PMC6355005（WebFetch 200 全文逐字）："The Youden's index is computed as sensitivity + specificity– 1 and ranges from 0 to 1. Maximising this index (J-point) allows finding an optimal cut-point independently from the outcome prevalence. The 95% confidence interval of the derived optimal cut-point was computed using bootstrap sampling based on 2000 replicates."；另 "the closest top-left point and 2) the Youden's index (J-point)" 两法并列。

## 推断口径（逐字）
- ScienceDirect S0167947314000450："the estimation of the optimal cut-off point associated with Youden index depends on both diseased and healthy samples, henceforth, sensitivity and specificity at the estimated cut-off point are correlated. Therefore, it is desirable to make joint inference on both sensitivity and specificity at the estimated cut-off point"；"marginal/individual confidence intervals" 不够，需 "joint confidence region"。
- Wikipedia 镜像："For a given diagnostic test ... Ĵ=p̂sensitivity−p̂FPR ... Inference for J (with a fixed, pre-specified threshold) therefore reduces directly to inference for the difference of two proportions"；"If the threshold is instead optimized to maximize J, the variance estimate must account for the additional variability of the threshold selection process. In such cases, the Delta method or bootstrapping is required to maintain the nominal coverage probability."
