# wb-xlsx-delivery（Excel 交付硬门）

**一句话**：交出去的表必须"打开就能重算、算出来的数是对的、别人改输入还能跟着变"。以下每条都是这条的失败模式。

## 一、公式必须真算（硬门）

- openpyxl 写公式只写**字符串**，**没有缓存值** ⇒ 任何读缓存值的下游（pandas、`data_only=True`、大多数预览器）看到的都是 `None`。**写完必须重算一次**（LibreOffice 无头重算 / 脚本 `recalc.py`）。
- **`errors_found` 的退出码是 0**：**干净退出不等于干净工作簿**，必须读返回的 JSON `status` 与 `total_errors`。JSON 里出现 `error` 键（而不是 `status`）才表示"根本没算"。
- **绿色 recalc 只证明公式"能算"，不证明"算对"**：off-by-one 区间、引用错行都会安静地产出错误数字。**先写 2–3 条公式核对取值，再铺满整张表**。

## 二、函数兼容白名单

| 类别 | 规则 |
|---|---|
| 优先 | Excel 2007 及更早：`SUMIFS` / `INDEX` / `MATCH` / `IFERROR` / `SUMPRODUCT`，无需前缀 |
| 需前缀 | `_xlfn.TEXTJOIN` / `_xlfn.CONCAT` / `_xlfn.IFS` / `_xlfn.SWITCH` / `_xlfn.MAXIFS` / `_xlfn.MINIFS`——裸写一律 `#NAME?` |
| **禁用** | `XLOOKUP` / `XMATCH` / `SORT` / `FILTER` / `UNIQUE` / `SEQUENCE`：运行时算不了；且溢出数组无 spill 元数据，只有左上角有值，**recalc 仍报 0 错误** ⇒ 用 `INDEX/MATCH` 查，排序/筛选/去重在 Python 里做完再写单元格 |
| 识别 | 算不了的公式被写回时**会变小写**，是 `#NAME?` 旁边的快速指纹 |

## 三、读写陷阱

- **读模型要两遍**：`data_only=True` 给缓存值但公式没了；默认给公式但没值。一遍拿不到两样。
- **`data_only=True` 后再 save 是破坏性的**——公式被永久替换成字面值。
- **刚写过的文件用 `data_only=True` 读全是 `None`**：先 recalc；公式结果为空串 `""` 也读成 `None`。
- **合并单元格只写左上锚点**，其余是只读 `MergedCell`。
- **`.xlsm` 不带 `keep_vba=True` 会丢宏**。
- **带空格的工作表名在跨表引用里必须加引号**：`='Assumptions Inputs'!$B$5`，否则 `#VALUE!`。
- **外部链接会被抹掉**：`='[1]Returns Analysis'!$B$2` 的 `[1]` 指向另一个文件；openpyxl 保存剥掉缓存值，重算时解析失败写 `#NAME?` 并删链接 ⇒ **保存前先把这些单元格的值抄出来**。

## 四、财务模型约定（用户未另行指定时）

- **四色**：蓝 `0,0,255`＝硬编码输入/情景杠杆；黑＝公式；绿 `0,128,0`＝跨表链接；红 `255,0,0`＝跨文件链接；黄底 `255,255,0`＝关键假设/待填格。
- **数字**：货币 `$#,##0` 且单位写进表头（`Revenue ($mm)`）；零显示 `-`；负数括号；百分比 `0.0%` 且**存分数**（存 15 会显示 1500.0%）；倍数 `0.0x`；年份存文本。
- **结构**：每个假设单独一格并被公式引用（`=B5*(1+$B$6)`，**不要** `=B5*1.05`）；**每个预测期公式保持一致**（中途中改一格是最常见的静默错误）；分母加零保护。
- **假设与硬编码数要写在读者看得见的地方**（单元格批注或表尾相邻格），有来源就写来源（文件/页码/链接），来自用户就直说。

## 五、交付前检查

1. recalc 过、`status=success`、`total_errors=0`（不是只看退出码）？
2. 抽样 2–3 条公式手工核对过取值？
3. 有没有用到禁用函数或被写回的 `#NAME?`/小写公式？
4. 公式都是公式、没有 Python 算好后写死的数值？
5. 表名/列名/公式与用户原话逐字一致（"按你的设计算别的"也算失败）？
6. 合并单元格、`.xlsm` 宏、跨表引用加引号都处理了？
7. 表头单位、百分比存分数、零与负数格式对？

## 六、反模式

- 只在 Python 里算好再写数值 ⇒ 输入一变全表错。
- 看到 recalc 退出码 0 就交付。
- 用 `XLOOKUP`/`FILTER` 图省事 ⇒ 交付即坏且报 0 错误。
- 直接 `data_only=True` 打开再保存 ⇒ 公式全丢。
