# 萃猫（distill-cat）— 通用蒸馏工作流总控

来源：蒸馏保姆级教程（2026-09-19 用户提供）。与 cangjie-skill（长内容→技能组重流水线）互补：cangjie 管批量、本技能管通用流程与成长闭环。

## 〇、核心区分：蒸馏 ≠ 做笔记

| | 总结 | 蒸馏 |
|---|---|---|
| 动作 | 把书读薄，产出笔记 | 把书拆成工具（技能包） |
| 产物 | 人脑的备忘 | AI 能按固定方式执行任务的实体 |
| 读者 | 人 | agent |

一切能提供方法论或思维框架的材料（书、论文、会议记录、访谈、自己的工作经历）都能蒸馏，方法完全相同。

## 一、材料分类判据（选错目标就白干）

| 材料类型 | 蒸馏目标 | 技能包用途 |
|---|---|---|
| 工具书（教你怎么做事） | **方法论** | 遇到问题时直接套用方法 |
| 非工具书（作者怎么思考） | **思维框架** | 借作者的框架思考，自己找解法 |
| 论文 / 会议记录 / 访谈 | 方法论 或 思维框架 | 同上 |

- 工具书 → 蒸出"可执行程序"；非工具书 → 蒸出"思维模型"。
- **蒸馏的对象是方法论或框架，不是书摘，更不是金句**。
- 不适合蒸：纯文学小说、哲学随笔——重体验轻方法，蒸不出可调用的技能。

## 二、原材料准备

- **已读懂的材料**：直接投喂，进入蒸馏。
- **还没读懂（小白路径）**：先走 阅读 → 整理 → 总结 三环节把材料读薄，再蒸馏。
- **自己的工作经历**：从"和 AI 一起干完一件活"开始（见第四节，优先级最高）。

## 三、完整蒸馏流程（端到端）

1. 投喂原材料：把材料交给蒸馏流程（本地路径或已读内容）
2. 蒸馏：自动提取方法论或思维框架，输出技能包（SKILL.md）
3. 安装技能包：把产物放进 agent 的 skills 目录
4. 调用（两种方式）：
   - 自动：新建任务，详细描述需求，AI 按 description 自动选中正确的 skill
   - 手动：通过加号手动指定 skill

示例链路：拿一本行业分析入门书 → 蒸出"行业研究"技能包（产业生命周期、商业模式拆解、市场规模估算等模块）→ 拿去分析某个具体行业 → 跑通"读书 → 技能 → 解决实际问题"整条链路。

## 四、蒸馏自己（优先级最高，不用买书）

1. **共创任务**：和 AI 一起完整干完一件活（例：写一条朋友圈文案）
2. **总结环节**：让 AI 总结这件事包含哪些工作环节
3. **提取精华**：把最有价值、最可复用的环节整理成 skill
4. **成 skill**：安装、命名、写清 description
5. **加成长功能**（见第五节）

> 个人工作流 → skill → 复用 + 自我进化：这是普通人把经验变成资产的方式。

## 五、成长功能闭环（关键，没有它 skill 就是固定模板）

没有成长功能的 skill 只是固定模板；装了成长功能才是活的：

- 技能每次被使用后，**主动向用户要反馈**（例如"哪一步最有价值？哪一步最没用？"）
- 收集反馈 → 落盘（技能目录内 feedback.md 或 memory/）→ 积累后迭代优化自身（升版本 + 改动记录）
- 形成自我调优闭环：越用越好用
- **沉淀前先过负向过滤器（ignore_patterns）**：自动萃取/沉淀模式时，显式声明排除清单——一次性修复（one_time_fixes）、简单笔误（simple_typos）、外部 API 偶发问题（external_api_issues）——这些不沉淀为技能，避免噪声技能堆积稀释检索质量。正问"该学什么"的同时必须反问"什么不该学"。（来源：everything-claude-code `continuous-learning` 技能 2026-09-26 r191-B 实拉，提升层=可复用Skill/技能积累治理）

⚠️ 前提：真的持续使用并反馈。多数人装完即弃，skill 就死了。与 wb-skill-authoring 的 caliper 外部评测分工：外部评测管"该不该触发、激活质量"；成长闭环管"使用中反馈驱动的内部迭代"。

## 六、必杀技：写好 description

**description = 技能的用途说明**，AI 靠它决定自动选中哪个 skill，是必须写好的关键字段。写清楚两件事：
1. 这个 skill **干什么用**
2. **什么场景**该触发它（给触发词清单）

> 模糊的 description 会让 AI 选错工具。

## 七、避坑提醒（批判视角）

- **蒸馏产物 ≠ 掌握书**：技能包可能只是"提示词模板化"，并没有独立于模型能力的新方法论。用之前自己检验产物质量。
- **安全第一**：skill 本质是可执行代码包，安装来源不明的 zip 有恶意代码风险。
- **生态绑定**：流程绑定具体 agent 工具与目录结构，平台升级可能失效；skill 生态尚未标准化。
- **别被营销带节奏**："AI 时代合法抢劫"是话术，不是可验证的资产积累。
- **版权**：只蒸馏拥有合法使用权的电子书。

## 八、速查卡

**蒸馏一本书**：分类材料 → 准备原材料 → 投喂 → 蒸馏 → 安装产物 → 调用
**蒸馏自己**：共创任务 → 总结环节 → 提取精华 → 成 skill → 加成长功能
**成长闭环**：每次使用 → 要反馈 → 迭代 → 更好用

> 记住一句话：**工具书取方法论，非工具书取思维框架；一切能蒸馏的，都别只停留在读书笔记。**
