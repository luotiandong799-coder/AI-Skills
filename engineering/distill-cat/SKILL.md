# 萃猫（distill-cat）— 蒸馏总控

合并自 `agent/mao-strategy`（毛选方法论蒸馏）与 `agent/personal-decision-intelligence`（十部经典决策智能），2026-10-09。来源：蒸馏保姆级教程（2026-09-19 用户提供）。

## 〇、蒸馏 ≠ 做笔记

| | 总结 | 蒸馏 |
|---|---|---|
| 动作 | 把书读薄，产出笔记 | 把书拆成工具（技能包/框架） |
| 产物 | 人脑的备忘 | AI 能按固定方式执行任务的实体 |
| 读者 | 人 | agent |

一切能提供方法论或思维框架的材料（书、论文、会议记录、访谈、自己的工作经历、经典著作）都能蒸馏，方法高度相通。

## 一、两大子模式

### 子模式 A · 经典/书籍 → 决策与问题解决框架
**材料**：经典著作（毛选、资治通鉴、孙子兵法、史记、三国志、穷查理宝典、思考快与慢、反脆弱、刻意练习、原则…）。
**两种用法**：
1. **单一经典深蒸馏**（以毛选为例）：把一部经典的方法论编译成可调用工作框架（见 §A-1）。
2. **多经典交叉研判**：十部经典五层框架 + 决策路由（见 §A-2）。

**输出**：事实/假设/核心矛盾/案例/风险/行动/验证/复盘 八段式（§A-2）。

#### §A-1 单一经典深蒸馏（毛选方法论示例）
主流程（决策/动手前必走）：
1. **调查研究（实事求是的前提）**：不做"下车伊始"的论断；典型调查（解剖麻雀）；出处《反对本本主义》《兴国调查》。
2. **矛盾分析（抓主要矛盾）**：枚举矛盾→找主要矛盾（决定性质）→找主要方面；两点论与重点论统一；出处《矛盾论》。
3. **小步验证（实践论）**：假设→试点→反馈→修正→推广；出处《实践论》。
4. **集中资源（各个歼灭）**：主要矛盾方向集中优势，一次解决一个；出处《集中优势兵力》。
5. **回环校准（群众路线）**：方案从一线来、到一线去检验，循环上升。

**框架卡片**
- **A 实事求是**：结论服从事实，而非书本/经验/愿望。每步问"依据是一手事实还是预设？"
- **B 调查研究**：没有调查没有发言权；未调查不决策/不批评/不下结论。
- **C 矛盾分析法**：枚举→排主次→找主要方面→按特殊性选对策→动态复盘。
- **D 实践论小步法**：假设→试点→反馈→修正→推广。把"大赌"拆"小验"。
- **E 集中优势兵力**：资源永远不够，必须集中；同一时段只攻一个主峰。
- **F 持久战/强弱转化**：战略藐视、战术重视；以时间换空间，积小胜为大胜。
- **G 弹钢琴（统筹）**：抓中心也照顾全局，十个指头都动但心中有主旋律。
- **H 群众路线**：从群众中来→形成方案→到群众中去→再集中，循环上升。

**决策自检清单**：做过调查吗？区分主次矛盾了吗？对策针对特殊性还是套老办法？先小范围验证了吗？集中攻坚还是撒胡椒面？强弱/主次会转化吗？一线验证过吗？
**红线**：方法论非口号，每个框架落到具体动作；不神化、不角色扮演作者；原文佐证不替代自己判断。

#### §A-2 多经典交叉研判（十部经典五层框架）
| 层 | 经典 | 解决什么 |
|---|---|---|
| 一·战略判断 | 资治通鉴/孙子兵法/毛选 | 方向、时机、坚持或转向、优势选择 |
| 二·人性与识人 | 史记/三国志 | 人是否可靠、团队组合、关系博弈 |
| 三·认知纠错 | 穷查理宝典/思考快与慢 | 隐藏成本、偏见、概率误判 |
| 四·风险管理 | 反脆弱 | 最坏情况、失败成本、从变化中获益 |
| 五·成长执行 | 刻意练习/原则 | 能力提升系统、个人运行规则与复盘 |

**决策路由**（先选层再调用，默认≤3 层）：

| 问题主类型 | 必调 | 加调 |
|---|---|---|
| 继续/转向 | 资治通鉴 | 竞争对手→孙子 |
| 值不值得投入/怎么打 | 孙子 | 长期影响→资治通鉴 |
| 局面复杂看不清 | 毛选 | 风险高→反脆弱 |
| 看人是否可靠 | 史记 | 组队→三国志 |
| 怕自己想错/隐性代价 | 穷查理宝典 | 情绪带动→思考快与慢 |
| 不确定性大/怕一次输光 | 反脆弱 | 算代价→孙子 |
| 能力提升/成长路径 | 刻意练习 | 固化规则→原则 |
| 老犯同样错/建个人规则 | 原则 | 配套训练→刻意练习 |

**冲突裁决**：现实优先→时间尺度（长期听资治通鉴/原则，当下听孙子/毛选）→可逆性（不可逆加大反脆弱/认知纠错权重）→仍冲突则写"两种结论+各自成立条件"交用户选。
**AI 执行流程**：问题定义→关键变量（毛选主要矛盾/孙子竞争/资治通鉴长期）→人性分析（史记/三国）→认知检查（穷查理/思考快与慢）→风险评估（反脆弱）→行动方案→能力沉淀（刻意练习/原则）。
**八段式输出**：
```
【事实】已确认的客观信息
【假设】未证实但影响判断的前提
【核心矛盾】最关键取舍（毛选主要矛盾视角）
【历史案例】可类比规律（只取规律不套故事）
【关键风险】最坏情形与主要失败模式
【推荐行动】分优先级下一步，含小步试错入口
【验证方法】最低成本验证假设
【复盘节点】何时回看、什么信号调整
```
**输出原则**：不替用户决定；给框架与依据；明示未知；优先现实验证；避免情绪化/宣传腔。

### 子模式 B · 工作/经验/论文/会议 → 技能包 + 成长闭环
**材料分类判据**：工具书（教做事）→方法论；非工具书（作者怎么想）→思维框架；论文/会议/访谈→方法论或框架。
**完整蒸馏流程**：投喂原材料→蒸馏出 SKILL.md→安装到 skills 目录→调用（自动按 description 选中 / 手动指定）。
**蒸馏自己（优先级最高）**：共创任务→总结环节→提取精华→成 skill→加成长功能。
**成长功能闭环**：每次使用后主动向用户要反馈→落盘→积累后迭代自身（升版本+改动记录），越用越好用。沉淀前过负向过滤器（排除一次性修复/简单笔误/外部 API 偶发问题）。
**必杀技·写好 description**：写清"干什么用"+"什么场景触发"（模糊 description 让 AI 选错工具）。
**避坑**：蒸馏产物≠掌握书（可能只是模板化）；安装来源不明 zip 有风险；只蒸馏有合法使用权的电子书；别被"AI 时代合法抢劫"话术带节奏。
**速查卡**：蒸馏一本书=分类→准备→投喂→蒸馏→安装→调用；蒸馏自己=共创→总结→提取→成 skill→加成长；成长闭环=使用→反馈→迭代。

## 二、默认行为（产出即落地）
- 蒸馏产物（技能包/框架）若仓库无同名对象，**默认写入并安装、立即可用**；已存在则提示复用而非重复生成。
- 子模式 A 的经典研判优先走本技能；书/视频/播客/课程要"批量重流水线提取成原子通用技能"→ `cangjie-skill`（RIA-TV++）。
