## 落地 5 独点（每点标注提升层）

### 1. 混合存储架构与索引选型（工具/工作流）
来源：aws-s3vectors / zylosai-hybrid / valkey
- **语义记忆=向量表+ANN 索引：HNSW（高召回高 RAM）vs DiskANN（十亿级低 RAM），PostgreSQL 内经 pgvector/pgvectorscale**；**按团队/任务类型/时间范围逻辑分区提吞吐**。
- **强一致性=一个 agent 写入立即可见（最终一致=协调失败，正是记忆工程要解决的问题）**；**大部分记忆写频繁查低频=驻留成本优化（查询少、存储贵=压缩/分层）**。
- 提升层：工具（存储选型）/ 工作流（分区与一致性设计）。

### 2. 混合检索：语义按 key、情景按 embedding、重排必选（工作流/可复用 Skill）
来源：dev-tamizuddin / agentloop / data-gate
- **语义记忆（偏好/事实）按 key 检索、情景记忆（过去事件）按 embedding 检索**——**混合=精度与召回兼得**；**重排不是可选=向量相似度只给候选，cross-encoder/LLM rerank 判真相关**。
- 提升层：工作流（检索路由）/ 可复用 Skill（混合检索模板）。

### 3. 记忆污染与治理：类型感知隔离+治理层（模型/工具/工作流）
来源：MemGuard / MemArchitect / SSGM
- **MemGuard=写时给每条记忆显式功能角色+检索只取所需类型+类型间维护关系**（异构污染=上下文特定事件过度泛化、功能不兼容记忆误导生成）；**MemArchitect=治理层与模型权重解耦（decay 策略/隐私强制/僵尸记忆=过期事实污染上下文）**；**SSGM=认知策略与记忆基质解耦，经验证/过滤门**。
- 提升层：模型（污染认知）/ 工具（治理层）/ 工作流（写时定型+检索限型）。

### 4. 幻觉变存储问题：写路径即攻面（模型/工具/工作流）
来源：daicelabs / llms3
- **记忆增强 agent 中捏造事实写入存储、下次检索以与真实记录同等置信度返回=模型永远没有第二次怀疑机会**（存储把幻觉的置信度拉平）；**记忆投毒三阶段=注入（外部数据源：PDF/邮件/知识库文章）→持久化（写入长期语义记忆融入行为画像）→执行（数周后按可信历史检索触发泄露）**；**写路径需要校验门（写前验证、来源标注）**。
- 提升层：模型（幻觉机制认知）/ 工具（写路径护栏）/ 工作流（写入校验）。

### 5. 五阶段记忆流水线+框架选型对照（工具/工作流/可复用 Skill）
来源：aliyun-5stage / devtoollab / aiworkflowlab / mem0-icml
- **五阶段=抽取→整合→存储→检索→遗忘（每次 LLM 调用无状态，全流程显式化）**；**框架对照=Mem0 轻量抽取事实入向量库/Letta 显式 memory-block API（MemGPT 血统）/Zep=时态知识图谱（Graphiti 追踪事实随时间变化）**。
- **SimpleMem=分层聚类压缩交互片段+小模型按簇生成摘要+意图质心学习（意图低维空间，任务标签+API 调用启发信号监督）**。
- 提升层：工具（框架选型）/ 工作流（流水线）/ 可复用 Skill（压缩-质心模板）。
