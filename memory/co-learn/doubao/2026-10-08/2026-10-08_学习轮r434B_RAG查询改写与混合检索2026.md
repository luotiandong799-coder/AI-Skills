## 落地 5 独点（每点标注提升层）

### 1. 查询改写技术族与风险表：改写/扩展/分解/step-back 四类（工作流/可复用 Skill）
来源：aipromptprophet-rag-query-rewriting-prompts / manning-chapter9 / npblue-query-expansion / thenerualbase-query-expansion
- **四类技术各有主风险**：query rewriting（把含糊问题改成更清晰的检索语言，适用对话/含糊表达——**风险=语义漂移**）；query expansion（程序化加同义词/变体，适用稀疏索引/词汇失配——**风险=降精度**）；query decomposition（复合问题拆成多个子搜索，适用需要独立证据的多部分问题——**风险=碎片化答案**）；step-back prompting（生成更宽泛的概念问题，适用依赖政策/第一性原则的问题——**风险=检索到太泛材料**）。
- **HyDE**：先让 LLM 生成假设文档再嵌入检索——向量相似度在"假设答案"与真实文档之间，绕过查询-文档表达差异。
- 判据：按问题形态选改写类型，并预判对应风险；HyDE 适合查询太短/表达与语料不匹配。

### 2. 多角度改写（Multi-Query）与子问题分解：多路检索合并提召回（工作流）
来源：csdn-多角度改写 / manning-chapter9 / semeval-1.227 / semeval-1.395
- **多角度改写**：LLM 生成 3-5 个语义相同措辞不同的 query 变体，分别检索，结果合并去重——**一个措辞召回不到，另一个措辞可能成功**，显著提升召回率。
- **会话改写**：改写指令让 LLM 看完整对话历史、解析指代、去口语填充与礼貌语、保留相关实体细节，只返回改写后 query 文本再过检索；**轻量改写模型（Qwen-0.6B）做领域专用改写**（resolve anaphora/恢复隐式实体/强调领域术语），不必上大模型。
- 判据：含糊/多轮对话先做指代消解式改写再检索；召回不足时上多 query 变体。

### 3. 混合检索生产范式：BM25+dense→RRF→cross-encoder→LLM（工作流/工具）
来源：aiworkflowlab-hybrid-search-rag / callsphere-hybrid-search-2026 / lobehub-hybrid-search / arxiv-2609.01617
- **2026 已定型的生产范式**：BM25 稀疏 + dense 向量 → Reciprocal Rank Fusion → cross-encoder 重排 → LLM。
- **RRF**：`score(d)=Σ 1/(k+rank_r(d))`，k 通常 60——**参数轻、一致胜过 learned fusion 方法**；加权 RRF 可用信号权重（向量 0.50/BM25 0.35/KG 0.15）；**k 需按领域调**，防 top-1 文档主导。
- **两通道取 top-50 → 融合去重 ~50 块 → 重排 top-5~10**；ColBERT-V2/SPLADE 为 2026 进阶稀疏向量。
- 判据：混合检索=两路召回+RRF 融合+重排三段式；RRF 是默认融合，加权仅在有明确信号优先级时。

### 4. 重排器定位：不找新文档，只提升已有候选排序；领域微调显著增益（工具/模型）
来源：habr-reranker-历史 / acm-legal-ai-fail / arxiv-2607.11933 / arxiv-2601.15457
- **重排器不召回**：实测 MRR@10 0.597→0.769 但 EvidenceRecall 几乎不变——**reranker 把已找到的正确候选提到 top，不是找新文档**；别用召回率评估重排。
- **领域微调 cross-encoder**（法律 query-语句对）NDCG@20 显著优于 vanilla 预训练重排；**蒸馏 LLM 成高效 cross-encoder**（4-bit 量化）在 RAGAS 指标上 +14% answer relevancy/+16% context precision/+19% answer similarity/+21% answer correctness。
- **延迟成本**：bi-encoder ~15ms/1M docs（独立编码可缩放），cross-encoder 50-150ms/20 docs（联合注意力高质量）——重排只对 top 几十候选做。
- 判据：用 NDCG/MRR 评估重排（不是召回）；领域语料上微调重排器收益显著。

### 5. 检索两层评估：检索层与生成层指标不联动，须分开测量+基线对照（工作流/可复用 Skill）
来源：meilisearch-rag-reranking / microsoft-learn-rerank-context / irjet-component-level-eval
- **检索层指标**：precision@k（top-k 中相关占比）/recall@k（相关文档进 top-k 比例）/MRR（首个相关文档位置）/NDCG@20（位置加权——位置 1 相关比位置 10 贡献大）。
- **生成层指标**：faithfulness/citation accuracy/factual consistency——**两层不联动**：模型可检索对仍答错（忽略检索内容或虚构细节）。
- **基线对照**：先测混合检索无重排的 nDCG/MRR 作基线，再逐重排阶段对比同一指标——评估重排增益必须同口径比。
- 判据：检索质量=检索层+生成层两套指标分开报；任何检索/重排改动先跑基线再对比。
