## 落地 5 独点（每点标注提升层）

### 1. Plan-and-Execute 架构：规划与执行分离+模型分工（工具/工作流/可复用 Skill）
来源：reactiveagents / taskade / dev-ljhao / detached-node / kindatechnical / neelmishra
- **Planner 生成完整多步计划→Executor 顺序执行→Re-planner 在执行偏离时调整尾部**；**规划器用更强模型一次性看到全局（长远程推理），执行器可用更便宜模型逐步骤执行（成本分层）**。
- **ReAct=每步即时思考（易近视、错误传播），P&E=先承诺再行动（复杂多步任务更优）；执行到中途失败=只修订计划尾部（不必整体重写）**。
- 提升层：工具（架构）/ 工作流（先规划后执行）/ 可复用 Skill（P&E 模板）。

### 2. 前瞻反思：执行前批评+自纠证据分级（模型/工作流/可复用 Skill）
来源：arxiv-PreFlect / tencent / openlegion / dev-AREX2 / preprints-survey
- **PreFlect=从历史轨迹蒸馏规划错误模式→执行前批评并精化计划（后验修正→执行前预见；补动态重规划处理执行期意外偏离）**；**Reflexion=失败后生成自然语言诊断存入记忆、下一尝试预置进上下文**；**AREX-2=长程反思=测试时扩展新前沿**。
- **自省自纠证据弱于热情**：intrinsic self-correction 证据不足，**需外部工具 grounding（CRITIC=搜索引擎/解释器）**；Self-Refine 单问题内交替生成与自我批评。
- 提升层：模型（反思机制认知）/ 工作流（先批评后执行）/ 可复用 Skill（反思模板）。

### 3. 失败恢复分层决策表（工作流/可复用 Skill）
来源：zylosai-backtracking / reactiveagents-recovery / xbstack / nerdleveltech
- **transient（网络超时/限流/瞬时不可用）→指数退避重试、不重规划；确定性错误有明确替代（tool not found/文件不存在）→局部替换该步骤；观察矛盾（步骤成功但结果使计划假设失效）→带全上下文重规划；同一步 K 次连续失败→升级人工或带补偿中止；外部环境变化→触发重规划**。
- **重试链路：步骤失败且有重试→带错误消息重试同一步；无重试→buildPatchPrompt 只改写失败与待执行步骤；补丁也失败→标记 failed 继续、由 reflection 决定是否重规划；全部完成但目标未达成→Augment 生成补充步骤**。
- 提升层：工作流（恢复矩阵）/ 可复用 Skill（失败恢复模板）。

### 4. 重规划触发三分类+假设依赖追踪（工具/工作流）
来源：agentixforce / zylosai-goal / ifaamas-scene
- **重规划触发=执行失败/假设失效/预算违规**；**计划基于世界状态假设构建——追踪每步骤依赖的假设，某假设失效时只修订依赖它的后续步骤（定向重规划，不重生成整条轨迹）**。
- **场景图引导主动重规划=执行前比较 RGB-D 场景图与成功示范参考图，相似度低于阈值即诊断差异并生成纠正子计划（预防式而非事后）**；**层级规划=Executor 能力超限升回 Governor 判定（能力不足 vs 授权缺口）再扩权或升级**。
- 提升层：工具（依赖追踪）/ 工作流（预防式重规划）。

### 5. 符号规划与搜索：MCTS 角色分工+失败驱动符号补丁（模型/工具/工作流/可复用 Skill）
来源：SPIRAL / ANNEAL / PIVOT
- **SPIRAL=Planner 提创意下一步+Simulator 预测真实结果 grounding+Critic 提供密集奖励（MCTS 从暴力搜索变引导搜索）**；**PIVOT=PLAN-INSPECT-EVOLVE-VERIFY 四阶段，局部失败归因聚焦需修复的计划部分而非重生成整轨迹**。
- **ANNEAL=失败驱动知识获取 FDKA：定位责任算子→约束 LLM 生成类型化补丁→多维评分+符号护栏+canary 测试后提交（每次接受带完整来源与确定性回滚，不改模型权重=神经符号）**。
- 提升层：模型（搜索范式）/ 工具（护栏）/ 工作流（四阶段）/ 可复用 Skill（角色分工模板）。
