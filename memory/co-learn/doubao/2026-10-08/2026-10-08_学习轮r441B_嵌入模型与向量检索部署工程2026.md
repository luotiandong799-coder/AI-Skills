## 落地 5 独点（每点标注提升层）

### 1. Embedding 选型四步：MTEB 过滤→短名单→自有数据验证→部署（工作流/可复用 Skill）
来源：theneuralbase / ai-tldr / futureagi-glossary / aipromptshub
- **Filter**：从 MTEB 检索任务族挑 3-5 候选（按语言/维度/开闭源过滤）；**Shortlist**：短名单 3-4 个；**Test on your own data**：**自有 eval 不必 fancy——几十条真实领域 query+应召回文档即可排短名单**；**Pick winner for YOUR use case**：100-500 ground-truth query-doc 对算 NDCG@10/MRR/P@K + 延迟吞吐，选任务性能+延迟最优，部署（vLLM/ollama/HF Inference API）。
- **RAG 场景按 MTEB-Retrieval 列排序，不按 MTEB 平均**——两列排名差异真实（OpenAI 3-large 总榜第 8 但 retrieval 58-59 接近榜首）。
- 提升层：工作流（选型流程）/ 可复用 Skill（自建 eval 模板）。

### 2. 领域默认选型表（工具）
来源：futureagi-2026 / datarekha-shootout / ailog
- **English prose RAG**：OpenAI text-embedding-3-large @1024（Matryoshka 维度、$0.13/M tokens 价值默认）。
- **多语言生产**：Cohere Embed v4（100+ 语言、每语言地板最小、**128K 上下文窗口最大 + 原生 binary 量化双形态**：float32 高召回 / 1-bit bitmap 便宜 top-k 预过滤）。
- **代码/代码混合**：Voyage voyage-3-large code variant（标识符+调用图域调优）；**法律/金融**：Voyage domain variants（合同/申报文件微调）。
- 提升层：工具（选型决策）。

### 3. 内存墙与两阶段量化检索（工具/工作流）
来源：datarekha-memory-wall / mixpeek / devrudals
- **10M×1536 HNSW 全内存 ANN 需 ≥100GB RAM**；SQ/BQ（post-filter+re-rank）可压进 16-64GB。
- **两阶段搜索**：Phase1 binary 索引 top-k（k=100，毫秒级 Hamming 距离）；Phase2 只取 top-k 的 float32 精确 cosine 重排。
- **int8 4×小、binary 32×小**；压缩内存检索→top 候选用全精度重排；**oversample 3-4× + rescore 恢复 95-99% recall**、内存账单降一个数量级。
- 提升层：工具（索引配置）/ 工作流（容量设计）。

### 4. TurboQuant / MonaVec：训练无关量化（模型/工具）
来源：aiwiki-qdrant / arxiv-MonaVec
- **TurboQuant**（Qdrant 1.18，2026-05-11，Google Research）：快速 Hadamard 旋转→向量值跨坐标均匀重分布→**无需 per-dataset 调参、跨 embedding 模型通用**；4-bit TurboQuant recall 0.9193（arxiv 数据集）≈标量量化**双倍压缩比**。
- **MonaVec**：RHDH 把任意输入分布条件化到 N(0,1)→预计算 Lloyd-Max 表量化 4-bit（8×压缩）——**无学习 codebook、无数据 pass，训练无关且数据无关**。
- 提升层：模型（量化方法）/ 工具（部署组件）。

### 5. Matryoshka+量化协同渐进压缩（工具/模型）
来源：zylosai / zeroentropy / cosmicmeta
- **MRL 渐进降维**（2560→1280→640→...→40）信息损失低于直接截断；**int8（2KB）/binary（<128B）渐进量化**。
- **2-bit 量化+Matryoshka 适配恢复 95-98% recall**（仅 1-bit 时 85-90% 准确率，适合初筛不适合终排）。
- **Pplx-embed**：INT8 4×、binary 32× 内存降；MRL 保持 1024 维度平衡存储成本。
- 提升层：工具（压缩策略）/ 模型（量化适配）。
