## 落地 5 独点（每点标注提升层）

### 1. 边缘保证 ≠ 分组保证：HG-CRC（可复用 Skill/工具）
来源：arXiv 2607.24562（curl 一手）
- CRC 给的是 marginal 保证，marginal 不蕴含 per-group：满足总体预算的同时可让子群系统性过量暴露于错误；轻微分组构成漂移下标准 CRC 最多在 47% 的 trial 里违反预算。
- HG-CRC=后置校准（只需 held-out 校准集、不重训），在分组层级全部节点同时强制保证：Bonferroni 校正 + leaf-first（优先最具体阈值，finer 未认证或拒答则回退更粗节点）。
- 实测三模型×两基准×八配置：ARC Challenge 上 Qwen3-4B / Llama-3.1-8B 达 0% 违反率且 WGER=0（500 bootstrap 下真值上界约 0.6%，是经验上界非认证）。
- 代价（22–37pp 参与率）与边界（MMLU-Pro 整体弃权 / Llama 残留 WGER=0.014 / Gemma-3-4B 靠弃权优雅退化）；消融：去掉 difficulty level 违反率回落到约 11% ⇒ 层级深度才是清账关键。
- 提升层：可复用 Skill（公平性判据）/ 工具（校准方法）。

### 2. Conformal Cascade：预测集大小当 deferral 信号（工作流/工具）
来源：arXiv 2607.25018（curl 一手）+ pith 评审信
- 痛点：LLM 置信度失校准、阈值要按模型对与域各调一遍、任何取值都给不出形式化精度界。
- 规则：`s_k(x,a)=1−(a 在 N 次采样中出现次数)/N`，每层阈值取校准分数 (1−α) 分位数；预测集坍缩为单一答案则本层受理，否则升级。
- 保证：受理层覆盖真值概率 ≥ `1 − Kα`；selection-preservation 成立时收紧到 `1 − α`；期望成本=α 与校准受理率的闭式函数。
- 实测：18 个多选基准×4 模型族，多数配对严格优于最强 calibration-tuned 启发式级联，推理密集基准收益最大；无需训练只要黑盒 API。
- 两个边界：① 开放式生成需先聚类答案（论文留作未来工作）；② 保证依赖 exchangeability 与"每 query 的 N 次采样独立"——生产 serving 的 shared batching / 固定种子会静默破假设，上线前须实测 `Pr[y_true ∉ C_k | 该层首次受理]`。
- 提升层：工作流（级联路由）/ 工具（校准函数）。

### 3. Conformal Abstention：开放式生成的答/不答（可复用 Skill/工具）
来源：arXiv 2604.27914
- 缺知识时模型倾向生成"像样的幻觉"而非承认不知；重训承认无知会导致过度保守且泛化差（eval 基准稀缺）。
- CA 拒答决策用 prediction confidence 而非 CP 的 non-conformity 分数（后者在开放式生成不可解），对参与率与正确率两侧同时给有限样本保证。
- 用模型内部表示几何度量"知识参与塑造回答的程度"来校准置信度与"无知"对齐；实验条件正确率提升至 75%。
- 提升层：可复用 Skill（拒答判据）/ 工具（几何校准）。

### 4. Gatekeeper：让小模型知道它不知道（工作流/模型层）
来源：arXiv 2502.19335（ar5iv 全文）
- 级联四情形：(b)(c) 只发答得对的 → 联合精度反而等于小模型精度（最低）；(d) 理想情形只发它会答错的，0.2–1× 预算达到该预算下最优联合精度 ⇒ 目标函数应是 deferral performance 而非"少发几个"。
- Gatekeeper 损失：让小模型对正确预测高置信、对错误预测低置信，从源头改善不确定性估计（顺带帮助学任务），含性能/deferral 权衡机制，架构无关，可扩 VLM。
- 相对未调优基线（deferral performance 口径）：CIFAR-100/TinyImagenet 0.72×/2×，ARC-e/ARC-c 7×/10×。
- 分层适用：改不动权重（黑盒）→ CC/HG-CRC/CA；能微调小模型 → Gatekeeper + 后置门。
- 提升层：工作流（路由目标函数）/ 模型（校准训练）。

### 5. 四器具选型表与共同前提（可复用 Skill/工作流）
来源：四篇综合 + pith 评审信
- ① 子群/分层公平或暴露风险 → HG-CRC（group-conditional + leaf-first，22–37pp 参与率代价）；② 省钱多级推理路由且要形式化界 → Conformal Cascade；③ 开放式生成要不要答（防幻觉）→ Conformal Abstention；④ 能改权重、长期降小模型误判率 → Gatekeeper。
- 共同前提：校准集与线上 query 可交换；N 次采样须按 query 独立（共享批处理/固定种子是 CC 最可能的静默失效点）。
- 结构性原则：deferral/弃权本身不产生错误答案，所以各层 conformal 保证才能在 disjoint first-commit 事件上复合——"宁可升级也不要硬答"在数学上是可累加的安全动作。
- 与 r462A 的接口：本面是"判不确定后往哪送"的度量学，那边是"送出去之后谁拥有工作"，两者拼起来才是一条完整降级链路。
- 提升层：可复用 Skill（选型映射）/ 工作流（完整降级链路）。
