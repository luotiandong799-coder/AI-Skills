## 落地 5 独点（每点标注提升层）

### 1. 无源检测三件套：语义熵/SelfCheckGPT/self-consistency（工具/工作流/可复用 Skill）
来源：arxiv-2605.02443 / web3aiblog / ayinedjimi / ai-tldr
- **语义熵=多生成按语义聚类后算熵（高熵=潜在幻觉，优于 token 级不确定性）；SelfCheckGPT=真话多代一致、幻觉代际不一致**。
- **self-consistency=N 次非零温度采样、关键事实分歧=强幻觉信号（生产 5 采样+2/3 一致阈值 ~92% 检测精度、数学 +10-20 分）**。
- 提升层：工具（检测方法）/ 工作流（无源场景）/ 可复用 Skill（三件套对比）。

### 2. NLI 蕴含检测与成本/延迟（工具/工作流/可复用 Skill）
来源：codesota / csharpcorner / aiml-qa / arxiv-2608.21095
- **claim-level 对 source 分类 ENTAILMENT/NEUTRAL/CONTRADICTION；$0.02/1K 检查 ~200ms；RAG 文档场景首选**。
- **分层防御=预防（证据 grounded+严格模板+低温）→检测（self-consistency/NLI/引用验证并行）→纠正；可信 RAG=NLI verifier+poison detector+Trust Index 在检索与信任决策之间**。
- 提升层：工具（NLI）/ 工作流（三层防御）/ 可复用 Skill（RAG 核查模板）。

### 3. 四类幻觉故障模式与对应修复（工作流/可复用 Skill）
来源：futureagi / sourcescore / niteagent / ragaboutit
- **factual=原子分解+外部核查→检索/工具调用上游；grounding=claim 蕴含→严格 prompt+groundedness；citation=来源不存在/不支持→schema 强制引用+registry 检查；reasoning=推理链断裂→逐步打分+低置信链拒答**。
- **强制内联引用+事后校验匹配；归因框架 5 方法平均砍幻觉引用 80%**。
- 提升层：工作流（模式修复）/ 可复用 Skill（故障模式清单）。

### 4. 级联幻觉与记忆中毒防护（工作流/可复用 Skill）
来源：charm / aws-agentsec / arxiv-2604.23366
- **级联幻觉=多步管线错误传播（四类模式+检测中断）；记忆中毒=单个幻觉事实存记忆成为后续 agent 的 ground truth→持续 grounding 检查+置信评分防幻觉入记忆、传播检测→标记/隔离记忆条目**。
- **GSAR=四类 grounded/ungrounded/contradicted/complementary+证据类型权重+不对称矛盾惩罚+三档 proceed/regenerate/replan**。
- 提升层：工作流（agent 安全）/ 可复用 Skill（记忆护栏模板）。

### 5. 生产幻觉测试套件与可信度门（工具/工作流/可复用 Skill）
来源：aiml-qa / technologypulse / arxiv-2604.04269 / arxiv-2606.15782
- **套件分层=reference-based（LLM-judge 校准 human 子集+claim-level 优于整体 verdict）+reference-free（self-consistency/uncertainty）+grounding（NLI）+对抗红队；RAG+严格 grounding+引用验证=幻觉降 60-70%**。
- **verify gate 每个交互单元+校准不确定性下系统弃答；selective gate=强证据接受/部分支持谨慎措辞/弱冲突拒绝或 fallback；低置信输出浮出人工验证（HITL 当特性不当 fallback）**。
- 提升层：工具（套件）/ 工作流（可信度门）/ 可复用 Skill（测试模板）。
