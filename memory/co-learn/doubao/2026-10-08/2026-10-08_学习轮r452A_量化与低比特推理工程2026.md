## 落地 5 独点（每点标注提升层）

### 1. 问题驱动选型四车道（工具/工作流/可复用 Skill）
来源：slavadubrov / datarekha / inferenceengineering
- **权重塞不进 VRAM→W4A16（AWQ/GPTQ+Marlin kernel）；高吞吐 compute-bound→FP8/INT8 W8A8（SmoothQuant 动态激活量化）；长上下文/高并发填满 GPU→KV cache 量化 FP8；重复前缀→prefix caching**。
- **从 BF16 基线在目标 serving 引擎里先量后测；FP8 已成 H100 级新部署默认、AWQ 旧硬件改造、GPTQ 兜底、GGUF 统治边缘**。
- 提升层：工具（量化方法）/ 工作流（问题驱动）/ 可复用 Skill（选型模板）。

### 2. 精度-位宽对照表与推理模型风险（工具/工作流/可复用 Skill）
来源：vrlatech / inferenceengineering / arxiv-2504.04823 / jared-hpc
- **INT8 ~97-98%；AWQ-INT4 ~94-96% 推理编码优于 GPTQ；GPTQ-INT4 ~93-95%；GGUF Q5_K_M ~95-97%**。
- **通用基准 1-3% 降、推理/编码 3-7%（激进组 g=64/32）、数学逻辑链最高 10%=INT4 对 o1 式推理模型有风险；W8A8+动态激活量化+SmoothQuant 仅 1-3%（远低于旧报告 10%+）；无损失可达成=W8A8/W4A16、更低比特引入显著精度风险**。
- 提升层：工具（位宽）/ 工作流（风险判断）/ 可复用 Skill（对照表）。

### 3. PTQ vs QAT vs QAD：训练介入三档（工具/工作流/可复用 Skill）
来源：tensorfoundry / pytorch-qat / nvidia-qad / promptz2h
- **PTQ=分钟-小时无需重训（4bit 以上优秀，下载模型首选）；QAT=前向伪量化+反向全精度梯度（STE 直通估计），低比特质量远好但需训练数据耗时**。
- **QAD=量化感知蒸馏两阶段（PTQ 造 student→冻结 teacher 蒸馏恢复精度，Nemotron NVFP4 22GB 4× 吞吐）**。
- 提升层：工具（训练方法）/ 工作流（介入深度选择）/ 可复用 Skill（三档对比）。

### 4. 校准与敏感性：混合精度与校准集陷阱（工作流/可复用 Skill）
来源：harshith / vlaicu / jared-hpc / prakashkagitha
- **校准集偏域=模型被带偏（Qwen 72B 英文校准→CEval 降 2pp）；首尾层更敏感、中层 INT4 可承受→按层敏感性混合精度（TensorRT/Neural Compressor 自动）**。
- **per-channel vs per-token scale 轴的选择比位宽更重要；RTN 无数据 vs 校准感知（<4bit 必须校准）；校准集=几百-千样本代表数据**。
- 提升层：工作流（校准）/ 可复用 Skill（混合精度模板）。

### 5. 生产判据与四车道默认（工具/工作流/可复用 Skill）
来源：datarekha / slavadubrov / markaicode / nvidia
- **防御默认：FP8/W8A8 用于代码生成/长上下文 QA/数学重 agent（吞吐差 INT4 仅 20-30%、精度保留更好）；AWQ-INT4 用于 chat/摘要/分类/路由=易 token 负载**。
- **GGUF Q4_K_M imatrix 校准~75% 小=边缘/llama.cpp CPU+Metal；INT8 校准（TensorRT）延迟关键 batch=1 最优但需 4-6 小时校准周期 vs FP16 静态无校准近零损失 15-20% 吞吐差；永远在自己 eval 上衡量**。
- 提升层：工具（部署栈）/ 工作流（判据）/ 可复用 Skill（默认清单）。
