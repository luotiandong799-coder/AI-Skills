## 落地 5 独点（每点标注提升层）

### 1. 视觉文档流水线：三阶段架构+OCR 混合+schema 校验循环（模型/工具/工作流/可复用 Skill）
来源：ai-tldr / niteagent / thesimplifiedtech / promptbench
- **视觉 LLM 三阶段**：ViT patch embeddings→cross-modal projector 映射进 LLM token 空间→LLM 解码器联合注意（image tokens+text prompt）。
- **OCR 混合策略**：先 OCR 批量提文本建检索索引→语义问题检索相关页→**页图像+OCR 文本一起喂视觉 LLM**（结构来自图像+文字来自 OCR，比任一单独更好）。
- **schema-bearing prompt**（点名精确字段+格式，附 JSON schema/工具定义让格式非可选）+**校验循环**（parse→validate→失败带错误重试，instructor max_retries 自动捕获失配）。
- 提升层：模型（架构理解）/ 工具（校验）/ 工作流（OCR 混合）/ 可复用 Skill（提取模板）。

### 2. 文档 Agent 工程：归一化+分类先行+有界重试+交叉核对（工具/工作流/可复用 Skill）
来源：aiagents.codeguides / geekchamp
- **输入归一化**：PDF→页图像、HEIC→JPEG、deskew/resize 在模型限制内（build 时验证）。
- **多表单先分类**（invoice vs receipt vs ID）再按类型跑提取 prompt（JSON only 匹配该类型 schema）。
- **校验失败带 validator 错误+同一图像有界重试**；**totals/dates/IDs 可选交叉核对**（calculator/regex）。
- 提升层：工具（归一化/核对）/ 工作流（分类先行）/ 可复用 Skill（文档 Agent 模板）。

### 3. 图像分辨率直接决定 token 数与成本质量（工具/工作流）
来源：stochasticsandbox
- **分辨率→视觉 token 数→成本与质量**（关键实现细节）；高分辨率细节文档与普通插图分开策略。
- 两阶段架构下视觉 token 与文本 token 交错序列。
- 提升层：工具（成本预算）/ 工作流（分辨率选型）。

### 4. 多模态 RAG 基建：CLIP 系统一表征+视频 RAG 共享 schema（模型/工具/可复用 Skill）
来源：nvidia-nvclip / edenai / zilliz / martinuke0 / lobehub-video-rag
- **CLIP 仍是基线最广生态**（ViT-B/32 512 维、ViT-L/14 768 维）；跨模态检索三评估维度=**cross-modal/cross-lingual/needle-in-haystack**。
- **Qwen3-VL-Embedding+配套 Reranker**：统一图文视频表征+支持低比特量化，MMEB-v2 登顶（生产级基建）。
- **视频 RAG 共享 schema**：关键帧+文本块用 CLIP/SigLIP 嵌入，text+time/image+time 同库索引；查询双路检索合并+时间戳引用回答。
- 提升层：模型（嵌入选型）/ 工具（索引 schema）/ 可复用 Skill（多模态 RAG 模板）。

### 5. 视觉 Agent GUI 基准族+action-boundary propagation 失败模式（模型/工具/工作流/可复用 Skill）
来源：arxiv-iosworld / arxiv-autogui / screenspot-v2 / ui-tars / arxiv-visualleakbench / ui-venus-2
- **基准族对照**：iOSWorld 视-only 截图（1536px 最长边上限对齐 API 限制）/ AutoGUI-v2 层级功能区递归解析（region/element 语义+grounding+动态状态预测，2753 任务 6 系统）/ ScreenSpot-v2 屏上元素 grounding（LFM2.5-VL-3B 80.7%）/ UI-TARS VisualWebBench 82.8%（截图推理→鼠标键盘动作）/ UI-Venus-2 验证码八族（滑块/旋转/点选/OCR/视觉推理）/ PSBench Photoshop GUI 操作。
- **action-boundary propagation 失败模式**：**敏感/不安全可见文本从图像复制进下游工具参数**（VisualLeakBench 500 图 5 场景：UI/chat/doc/form/dashboard）——视觉 Agent 特有注入路径，需视觉侧护栏。
- 提升层：模型（基准对照）/ 工具（UI 操作）/ 工作流（视觉护栏）/ 可复用 Skill（GUI 基准选型）。
