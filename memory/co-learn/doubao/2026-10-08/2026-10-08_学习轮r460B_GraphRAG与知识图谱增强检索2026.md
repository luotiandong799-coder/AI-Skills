## 落地 5 独点（每点标注提升层）

### 1. GraphRAG 五阶段流水线与 Leiden 社区检测（工作流/工具/可复用 Skill）
来源：microsoft-graphrag / 腾讯云 / lrec2026 / llmversus / it-blue
- **五阶段=①text unit chunking→②LLM 抽取实体+关系（ontology 约束：同文本范围内抽 (entity1, relation, entity2) 三元组）→③graph construction（跨 chunk 合并成全局图）→④Leiden 社区检测（分层递归聚类直到社区规模阈值，比 Louvain 连通性更好不破碎）→⑤社区层级摘要（leaf→root 自底向上 LLM 写，小社区=具体细节、大社区=宏观主题）**。
- **实体抽取是索引成本大头：500 页语料此单步消耗约 58% 索引 token；节点带 LLM 写的描述+源文档引用；图建成后支持跨文档推理（"语料主要主题是什么"）——chunk 向量 RAG 答不了**。
- 提升层：工作流（建图流水线）/ 工具（Leiden）/ 可复用 Skill（五阶段清单）。

### 2. local vs global 双检索模式（工具/工作流/可复用 Skill）
来源：aiworkflowlab / aipromptshub-tutorial / it-blue / llmversus
- **local search=实体级子图遍历：沿查询相关实体的邻居展开（具体实体问题"X 和 Y 什么关系"）；global search=聚合社区摘要跨全图（语料级问题"主要主题/趋势是什么"）——两种问题类型选对应模式，社区层级提供多粒度导航**。
- **tradeoff=索引成本：建图必须跑 LLM（前置插入检索上下文 vs 模型按需拉取 grounding 两种模式 GraphRAG 都支持）；先想清楚语料是"多文档互连推理"还是"单点事实查询"——后者纯向量更省**。
- 提升层：工具（双模式检索）/ 工作流（问题类型路由）/ 可复用 Skill（local/global 决策表）。

### 3. 向量+图双路混合检索与 RRF 融合（工具/工作流/可复用 Skill）
来源：aws-hybrid / microsoft-horizondb / myengineeringpath / arcadedb / progressive-robot
- **双路并行：向量检索（语义相似起点：答"这是什么意思"）+图遍历（关系链：答"这个和那个怎么关联"）→cross-encoder 重排（纠正"嵌入近但实际不相关"）→Reciprocal Rank Fusion（RRF）合并排序**。
- **图增强多跳企业问答质量提升 20-40% vs 纯向量 RAG（Microsoft GraphRAG 2025-07 发布实证）；图遍历暴露向量检索漏掉的结构重要结果（引用/因果/组织层级/领域边）；向量+图可在同一 Cypher 查询同事务内完成（ArcadeDB）——结果在数据库层直接组合**。
- 提升层：工具（混合检索）/ 工作流（RRF 融合）/ 可复用 Skill（双路合并模板）。

### 4. 实体解析决定图质量：同实体跨 chunk 合并（工作流/工具/可复用 Skill）
来源：dev-nikhil / dev-chaoscypher / aws-hybrid / x-cmd
- **"Acme Corp"/"Acme Corporation"/"the company" 跨 chunk 提及必须解析为单图节点——实体解析质量直接决定图质量；节点是实体、边是关系、边带权重与描述**。
- **图遍历返回"实际证据链"：walk 图找到结构化连接信息+取回证明这些连接的源 passage 合并成单一排序结果——答案不只是相似文本而是 chain of evidence；entities/relationships/claims/provenance 一起进图（geekchamp）**。
- 提升层：工作流（实体解析）/ 工具（证据链检索）/ 可复用 Skill（解析质量检查）。

### 5. 建图成本量级与变体选型（工具/工作流/可复用 Skill）
来源：mintlify-wiki / arxiv-HyGRAG / arxiv-OMD / arxiv-DeepGraphRAG
- **成本量级（GPT-4o）：100 docs/~2000 chunks=15-30min/$1-3；1,000 docs/~20k chunks=2-4h/$10-30；10,000 docs/~200k chunks=20-40h/$100-300——建图前先估成本再决定**。
- **变体选型：HyGRAG（混合图=chunk+entity 双节点层级索引+动态语料更新）；OMD-GraphRAG（ontology 引导抽取+多维聚类+实体级图遍历×社区级语义检索双通道融合，MultiHop-RAG 提 3.43%）；Deep GraphRAG（加权 Louvain 3 级社区层级+自适应集成）——语料动态选 HyGRAG、多跳推理选 OMD、层级语义选 Deep**。
- 提升层：工具（变体库）/ 工作流（成本预算）/ 可复用 Skill（选型矩阵）。
