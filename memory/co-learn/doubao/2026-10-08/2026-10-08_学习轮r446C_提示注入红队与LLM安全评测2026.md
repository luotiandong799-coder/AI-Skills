## 落地 5 独点（每点标注提升层）

### 1. 自动红队方法论（模型/工具/工作流）
来源：GPT-Red / ADVERSA / ARES / arxiv-2512-learning
- **自博弈：攻击模型 vs 防守模型对抗，攻击数据回灌训练防御**（GPT-Red 84% 攻击成功率 vs 人类 13%；攻击直接做对抗训练）；**ADVERSA=多轮护栏退化连续轨迹评分（非单次事件；70B QLoRA 攻击者消除自身拒答）**。
- **ARES=Red LM+自动安全分类器+成功 prompt 回填 in-context 示例（Scoring 策略选例）；learning-based=类别感知攻击生成+层级漏洞检测（lexical/semantic/behavioral 三类检测器）**。
- 提升层：模型（自博弈认知）/ 工具（红队栈）/ 工作流（回灌闭环）。

### 2. 攻击空间分类体系+组合基准（工具/工作流/可复用 Skill）
来源：FAR.AI / HackAgent / arxiv-2606-adversarial
- **FAR.AI 最低标准=67 种静态越狱技术分类体系+组合成超大规模攻击空间+旗舰模型基准（Claude Fable 5/GPT-5.6 Sol/Gemini 3.1 Pro/Grok）**；**HackAgent=开源自适应 agent 红队工具（attacker 模型编排打 target）**；**四家族自动越狱×7826 恶意意图×十类伤害分类的对抗鲁棒性评测**。
- 提升层：工具（攻击空间）/ 工作流（组合评测）/ 可复用 Skill（分类体系模板）。

### 3. 提示注入攻击基准族（模型/工具/工作流）
来源：deepinspect / AgentRedBench / StepJack / Hidden-in-Plain-Text
- **七个活跃基准 ASR 24-84.30%（AgentDojo 629 安全用例/BIPIA/InjecAgent 1054 例/CyberSecEval）**；**AgentRedBench=215 个欠授权场景×24 企业集成×5 攻击类型（无护栏 ASR 32-81%）**。
- **StepJack=多步间接注入使 ASR 最高涨 31.2 点（单步 41.7%→多步 72.9%）**；**Hidden-in-Plain-Text=RAG 社交网络 IPI 基准（HTML/Markdown 消毒+Unicode 归一化+归因门控回答=可部署防御）**。
- 提升层：模型（能力基准认知）/ 工具（基准选型）/ 工作流（防御验证）。

### 4. 注入检测评测+泄漏评分（工具/工作流/可复用 Skill）
来源：arxiv-2604-phrasematch / arxiv-2604-18248 / semanticscholar
- **系统提示泄漏确定性评分：连续 7+ 词短语匹配=0.05 分/条、总分>0 判泄漏——确定性（同输入同输出）/可复现（无主观 judge）/保守（偏好假阴性）/毫秒级**。
- **跨域检测技术：explicit-override 攻击检出 ~92%、data-exfiltration ~99%；基准检测率对比（Liu 64.0%/Garak 55.2%/InjecAgent 85.2%）**。
- 提升层：工具（检测评分）/ 工作流（评测 harness）/ 可复用 Skill（泄漏评分模板）。

### 5. 多轮越狱与自适应攻击：静态防御会被绕过（模型/工具/工作流）
来源：usenix-nasr / monitoringbench / finred
- **自适应攻击（RL 优化）可绕过 RPO/Circuit Breakers（HarmBench 上 100% ASR）；单轮评测看不见多轮升级动力学（severity drift=风险等级随轮次漂移）**。
- **MonitoringBench=阶段化红队管线：攻击分类学保证覆盖防 mode collapse、策略生成与执行分离、事后轨迹精化提升规避**。
- 提升层：模型（防御局限认知）/ 工具（多轮管线）/ 工作流（持续红队）。
