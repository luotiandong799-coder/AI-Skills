## 落地 5 独点（每点标注提升层）

### 1. 声明式签名+编译心智：程序而非提示（工作流/可复用 Skill）
来源：dspy.ai / devto / aiwiki
- **signature=带类型的输入输出声明（替代手写 prompt，可维护可移植）；程序=可组合 Module（classifier/RAG/Agent loop）**。
- **编译=optimizer 自动调参（prompts 和/或 LM weights）最大化指定 metric；DSPy 论文=GPT-3.5 BootstrapFewShot 超标准 few-shot 25%+（复杂推理）、llama2-13b-chat 65%+**。
- 提升层：工作流（声明式）/ 可复用 Skill（签名模板）。

### 2. Optimizer 选型表：按数据量与症状（工具/工作流/可复用 Skill）
来源：dspy-optimizers / dspy-choosing / neuralbase
- **~10 例=BootstrapFewShot；50+=BootstrapFewShotWithRandomSearch；大 trainset 且输入需不同 demo=KNNFewShot；指令不对 demo 对=COPRO/GEPA；两者都弱且有预算=MIPROv2/GEPA；失败模式可命名=SIMBA/InferRules；提示已平顶且模型可调=BootstrapFinetune（软提示权重）**。
- 提升层：工具（optimizer）/ 工作流（选型）/ 可复用 Skill（选型表）。

### 3. MIPROv2 三阶段：Bootstrap→Propose→贝叶斯联合搜索（工具/工作流）
来源：deepwiki / futureagi / hassan11196
- **Bootstrap=跑未编译程序、把 metric 通过轨迹的中间推理捕获为潜在 demo；Propose=GroundedProposer（LM 模块）为每个 predictor 生成候选指令；搜索=贝叶斯/TPE 找（指令, demo）组合在 held-out 上最优**。
- **设计点=联合搜索（指令互补所选示例而非独立）；light 模式 ~120 LM 调用**。
- 提升层：工具（MIPROv2）/ 工作流（三阶段）。

### 4. 编译产物治理：program.json 提交、跨模型重编译、月度重优化（工作流/可复用 Skill）
来源：effloow / pexon / gemilab / antigravity
- **optimizer 结果存 program.json 随代码提交=构建产物；生产不运行时重编译（费 token 不可复现）、入容器镜像/版本化 blob**。
- **提示优化不跨模型迁移（换 provider 重跑）；温度 0 非确定=每例 3-5 样本评分；ReAct 工具上限=prod 4/dev 8；月度重编译（用户措辞漂移、GitHub Actions 自动跑、准确率阈值 ping Slack=写提示变成监控提示）**。
- 提升层：工作流（产物治理）/ 可复用 Skill（月度重优化模板）。

### 5. 自动优化过拟合防护+权重蒸馏（工作流/可复用 Skill）
来源：bestprompt / dropbox / teachaitools
- **metric 陷阱=学结构不学精度（90% val/65% prod：metric 是"与示例相似度"→复制结构）；优化器复制关键词/用户名/原文进提示=加 guardrail 禁止直接包含示例特定内容**。
- **优化器改任务参数（1-5 评分变 1-3）=显式约束任务参数不变；权重蒸馏=编译轨迹蒸馏到 8B 开源模型匹配 70B+ zero-shot（成本-80%）**。
- 提升层：工作流（防过拟合）/ 可复用 Skill（蒸馏管线）。
