## 落地 5 独点（每点标注提升层）

### 1. 可访问性树感知：浏览器 agent 的第一感知通道（工具/工作流/可复用 Skill）
来源：ailearningguides / arxiv-webretriever / novapixel / testdino / top-mcps
- **accessibility tree=浏览器语义结构（role/name/value/state/hierarchy）比截图快且跨站无需每站选择器；Playwright snapshot 转文本=元素名+角色+引用，模型按引用操作而非预测像素坐标**。
- **比视觉类工具更可靠（按钮就是按钮，不随 CSS 样式/屏幕位置/视觉外观变化）；锚定可访问性树=类/XPath 无法比的结构稳定性（ARIA 角色受法规保护、开发者很少破坏）**。
- 提升层：工具（感知通道）/ 工作流（快照优先）/ 可复用 Skill（感知选型模板）。

### 2. 结构化 DOM 出稳定定位器：getByRole 模式（工具/工作流/可复用 Skill）
来源：codersera / scrolltest / arxiv-browser-agents
- **基于可访问性树快照→生成 getByRole('button', {name}) 稳定定位器而非像素匹配（structured DOM in, stable locators out）**。
- **快照模式=默认（20 分钟人工清单→3 分钟自动化）；可访问性快照顺带审计=缺失 alt/标题层级/focus trap（约 axe-core 70% 覆盖率零配置）**。
- 提升层：工具（定位器）/ 工作流（快照默认）/ 可复用 Skill（审计清单）。

### 3. 分层控制：确定性原语+自主 agent 组合（工具/工作流/可复用 Skill）
来源：stagehand / browserbase / firecrawl / brightcoding
- **act/extract/observe=确定可预测的逐步控制（关键路径）；agent=自主多步（复杂流程）；组合=agent 探索+原语跑关键路径**。
- **agent 内部=高层指令拆离散动作→逐动作执行→验证结果→下一步（页慢载也自适应）；maxSteps 限制（默认 20，复杂任务 30-40）或拆小步顺序执行**。
- 提升层：工具（双层 API）/ 工作流（组合模式）/ 可复用 Skill（maxSteps 模板）。

### 4. 重试分级与失败恢复（工作流/可复用 Skill）
来源：kanopy / novita / stagehand-agent
- **分级重试=同一动作短延迟重试（1-3s）→失败则新截图重分析（页可能变了）→再失败换方法（键盘导航代替点击/滚动找隐藏元素/整页刷新）；设置最大重试上限**。
- **可预测失败原因=网络延迟/元素重叠/动态内容晚加载/弹窗意外出现；每任务构建重试逻辑**。
- 提升层：工作流（分级重试）/ 可复用 Skill（重试策略模板）。

### 5. 会话持久与 runbook 固化（工具/工作流/可复用 Skill）
来源：browserless / steel / refrain / skyvern / quox
- **持久会话=cookie/localStorage 跨调用跨运行保留（免每次登录）；Authenticated Profiles=登录保存一次重放；TTL 控制会话寿命；反检测=CAPTCHA 解决/代理轮换/指纹管理（Steel）**。
- **AI 一次生成可复现 runbook→之后确定性重跑（Refrain 首跑 86% 便宜、重跑 100% 便宜）；RPA 维护负担=30-70% 团队精力（修坏 bot）、LLM agent=近零布局维护；页变自愈=站点变时 AI 重新解释页面找替代而非断链**。
- 提升层：工具（会话）/ 工作流（固化流程）/ 可复用 Skill（runbook 模板）。
