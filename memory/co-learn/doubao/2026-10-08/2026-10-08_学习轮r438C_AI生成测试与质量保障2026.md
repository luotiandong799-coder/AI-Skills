## 落地 5 独点（每点标注提升层）

### 1. 对抗双 agent 测试生成：AdverTest 变异引导 + feedback-directed（工具/工作流）
来源：arxiv-2602.08146-advertest / franktip-llmutantkiller / mpapad-tosem
- **双 agent**：Test Generation Agent（造高质量测试套件检测 bug）vs Mutant Generation Agent（生成变异体）——**对抗提升 bug 检测能力**。
- **feedback-directed**：测试不杀死给定变异体→LLM 带场景化反馈（语法错误/依赖违规/执行日志/失败断言）重 prompt 至多 N 次再试（LLMutantKiller 实现）。
- **变异测试整合进单测生成流程**：先造变异体、再生成能杀死它们的测试。
- 提升层：工具（测试生成）/ 工作流（对抗循环）。

### 2. LLM 增强模糊测试：结构化输入生成 + 语义模糊（工具/工作流）
来源：llamafuzz / madfuzz / sefz-2605.13044
- **LLAMAFuzz**=用 LLM 数据转换/格式预训练知识生成结构化数据新有效输入，微调配对变异种子增强。
- **MADFuzz**=用历史触发 bug 的输入骨架让 LLM 补全（Mad Libs 式）+求解器行为反馈（prompt 优化/种子选择）。
- **Sefz=语义模糊**：每条 guardrail 翻译成可达性目标→LLM 变异器生成良性输入→多臂老虎机用目标邻近度做奖励——**自动发现 agent skill 规范违反**（402 个真实 skills 评测）。
- 提升层：工具（模糊测试）/ 工作流（规范验证）。

### 3. LLM 测试生成三 prompt 模式 + 测试集结构（工作流/可复用 Skill）
来源：qaskills-prompting / ai-tldr-evalsuite / evidently-ai / theneuralbase-curated
- **三模式**：Test Case Synthesis（从规格生成）/ Edge Case Discovery（丰富已有测试的边界）/ Code-Based Generation（读源码直接生成）——按框架与粒度选变体。
- **边界注意**：无效格式/边缘日期（闰年等）/空字符串/极短消息/混合语言。
- **测试集结构**：typical 60%（核心任务）/ edge 20%（罕见但合理）/ adversarial 10%（越狱/注入/诱导幻觉）；**15-40 case 典型中间 eval、>100 测的是泛化（不同问题）**。
- 提升层：工作流（测试集设计）/ 可复用 Skill（结构模板）。

### 4. 变异测试基准：安全变异算子 + 有效性度量（工具/可复用 Skill）
来源：secmutbench / mpapad-tosem
- **SecMutBench**=25 个安全特定变异算子覆盖 30 个 CWE 类别（把安全 Python 代码转成真实漏洞变体）——**EffSMS=SMS×Secure-Pass Rate 计测试有效性**。
- **LLM 变异体生成对比评测**：BugFarm / LLMorpheus / 自定义 prompt 在 339 程序 1,869 变异体上对比。
- **传统规则变异 vs LLM 生成变异体**：LLM 出更语义真实的变异、规则算子更可预期。
- 提升层：工具（变异测试）/ 可复用 Skill（安全测试模板）。

### 5. 回归自动化五领域 + TDAD 代码-测试图 + CI 中 LLM-as-judge 门禁（工作流/可复用 Skill）
来源：shiplight-regression / katalon / softwaretestpilot / samuelfaj-tdad / shawnmayzes-cicd-evals
- **五领域**：生成（从 prompt/规格出测试）/ 自愈（selector 变化自动修、不 fail 构建）/ AI 视觉回归（过滤噪声）/ 风险优先化（每 PR 只跑受影响测试）/ 自主分诊（分类失败）。
- **CI 保持确定性主干、AI 叠层**——减维护+提覆盖；**TDAD=代码-测试图+影响分析减 70% 回归**（agent 知道哪些远端测试代表 diff 风险，不跑全部）。
- **LLM-as-judge 门禁**：快便宜模型（Haiku/Gemini Flash）+rubric 打分、低于阈值 fail CI step；**同族 judge 与人类一致性比跨族低 15-25 点**——生成与 judge 用不同模型族。
- 提升层：工作流（CI 策略）/ 可复用 Skill（门禁模式）。
