## 落地 5 独点（每点标注提升层）

### 1. GraphRAG 五阶段索引管线+查询四模式（工作流/可复用 Skill）
来源：microsoft-graphrag / indexing-dataflow / aiworkflowlab / prem / langchain-graphrag
- **text unit 分块→LLM 抽取实体+关系（带描述）→图构建→Leiden 层次社区检测→社区 LLM 摘要**；**"把昂贵推理在索引期花一次，查询期保持便宜"**。
- **查询模式=Local Search（实体邻居扇形展开）/Global Search（社区摘要 map-reduce 处理语料级主题问题）/DRIFT Search（local+社区上下文拓宽）/Basic Search（基线 top-k 向量）**。
- 提升层：工作流（管线）/ 可复用 Skill（四模式路由）。

### 2. 社区检测 Leiden+层次粒度（工具/工作流）
来源：indexing-dataflow / langchain-community / aiworkflowlab-community
- **Leiden=改进 Louvain 的层次社区检测：递归聚类至社区规模阈值；Level 0→特定子主题、Level 1/2→更广主题（多级粒度导航与摘要=语料多分辨率地图）**。
- **社区 level 0 不总是最佳=按问题粒度选层次**；社区摘要=每个社区多级别生成自然语言摘要。
- 提升层：工具（算法）/ 工作流（层次选级）。

### 3. 实体消歧四法+重复实体实测（工具/工作流/可复用 Skill）
来源：neo4j-community / colab-roadmap / prem / aiwithmohit / neo4j-kg-builder
- **embedding 相似度（entity name+描述向量、cosine>0.92 阈值聚类）/LLM-based 判断/rule-based（公司名→ticker 映射）/Neo4j 三种 resolver（同 label 同名合并/spaCy 静态嵌入语义匹配/fuzzy match）**。
- **10K 金融语料实测 34% 实体节点是重复或近重复——不做消歧=图泄漏、边碎片化、检索碎裂、结构优势尽失**。
- 提升层：工具（resolver）/ 工作流（消歧 pass）/ 可复用 Skill（阈值模板）。

### 4. 图构建陷阱四类+对策（工作流/可复用 Skill）
来源：colab-roadmap / bestaiweb / toolsku / ideabosque
- **schema drift（不同 run 发明新关系类型）→strict_mode+固定 allowed_relationships 列表；幻觉边→后过滤只留显式陈述的三元组+更强抽取模型；长文档上下文丢失→逐 chunk 抽取+全局去重**。
- **分块制造指代分裂（代词与先行词分离/引语与说话者分离）→错误被编码成边，先在向量基线修复分块**；增量更新与全量重建冲突→新旧冲突需治理（图随源数据漂移）。
- 提升层：工作流（陷阱对照表）/ 可复用 Skill（strict_mode 模板）。

### 5. 图增强检索模式+图索引工程（工具/工作流/可复用 Skill）
来源：mslearn-horizondb / aws / KET-RAG
- **权威增强=用图结构重排向量结果（高引用/中心连接/结构重要文档排前，即使嵌入相似度中等）**；**混合检索=向量+BM25+图遍历单查询**。
- **候选集 60-100 再重排（更大集合提升召回但增延迟）；DiskANN 百万向量/HNSW 小数据集或快建；GIN 索引频繁过滤属性、复合索引按边属性遍历**；**KET-RAG=先取 10 实体节点、按邻接补关系至 λ/2 token 预算（多粒度索引成本高效）**。
- 提升层：工具（索引）/ 工作流（重排）/ 可复用 Skill（候选集模板）。
