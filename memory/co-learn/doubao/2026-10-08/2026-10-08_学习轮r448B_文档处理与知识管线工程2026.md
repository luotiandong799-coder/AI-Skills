## 落地 5 独点（每点标注提升层）

### 1. 文档处理管线八步（RAG 数据工程）（工作流/可复用 Skill）
来源：databricks / wickedsmartdata / datascale-ai / csdn
- **parse→metadata 提取→去重→过滤→分块→嵌入→索引存储**；**RAG 以文档工程为基础而非终端生成（先文档工程后生成）**；**异构格式解析+结构化清洗+多源稳定摄入+父-子层级多路检索**。
- 提升层：工作流（管线）/ 可复用 Skill（八步模板）。

### 2. 分块方法选型矩阵（五档）（工具/工作流/可复用 Skill）
来源：lobehub / ertas / superml / thedrive
- **fixed-size=同质文本快速原型；recursive char=通用结构化文档（LangChain 默认）；semantic=内容多变主题切换（embedding 分界）；document-structure=技术/法律/学术（每文档类型定制）；agentic/LLM=高价值复杂结构（贵）**。
- **固定长度切开会制造语义嵌合体：chunk 起点在上一节尾、终点在下一节头=embedding 代表两个主题、两个主题的查询都会召回它（精度降）**；分块目的=语义单元聚焦+绕开模型输入上限。
- 提升层：工具（选型）/ 工作流（按文档类型路由）/ 可复用 Skill（分块矩阵）。

### 3. 语义分块+metadata 注入（工具/工作流/可复用 Skill）
来源：xbstack / dataopslabs / unstructured
- **语义切片=按 markdown 标题/段落结束符/句子语义突变点动态切分（每个 chunk=完整语义孤岛）**；**metadata 必须注入：无上下文 chunk（"配置参数为 302"）模型不知道属于哪个项目/谁更新/何时更新**。
- **metadata 作索引字段=向量检索前确定性预过滤（来源/日期/文档类型/访问级别）缩小搜索空间、提升相关性与安全**。
- 提升层：工具（注入）/ 工作流（先结构后切片）/ 可复用 Skill（metadata 模板）。

### 4. 版本化与增量索引（工具/工作流/可复用 Skill）
来源：premai / hrushikedar / ephizen / soapubs / arika
- **变化检测=摄入时 hash 文档内容、再摄入比较 hash；增量重索引=只更新变更文档的 chunk 不重全库；删除处理=源文档删除/权限撤销必须移除对应 chunk**。
- **doc_chunk_registry 表（doc_id/chunk_vector_id/content_hash/version/status active|superseded）=chunks 是派生数据、可随时从文档重建（文档表为唯一 truth）**；**嵌入模型稳定性=换嵌入模型需重嵌全部（生产没人警告的坑）**。
- 提升层：工具（注册表）/ 工作流（增量更新）/ 可复用 Skill（版本化模板）。

### 5. 布局分析 DLA+解析引擎对比+清洗规范（工具/工作流/可复用 Skill）
来源：dataopslabs / novalad / ertas / kanopy / docling
- **DLA=区块分类（表格/图题/节标题/脚注/公式）带边界框：每个下游决策依赖此步精度（先懂文档结构才能智能分块）**；**解析引擎=Docling 表格 97.9%（TableFormer 合并单元格/无边金融表）/LlamaParse 89%/Unstructured 格式最广/Marker 最快但扫描 OCR 降质**。
- **清洗规范=正则过滤乱码/编码修复（NFKC 规范化）/空白统一/领域纠错词典（"Artide"→"Article"）；内容级去重（hash 归一化文本）而非文件名匹配（企业文档 15-30% 重复）**。
- 提升层：工具（引擎选型）/ 工作流（清洗规范）/ 可复用 Skill（DLA 先行模板）。
