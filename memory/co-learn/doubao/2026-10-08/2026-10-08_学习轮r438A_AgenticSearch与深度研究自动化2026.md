## 落地 5 独点（每点标注提升层）

### 1. 深度研究循环：Plan→Search→Analyze→Decide→Repeat/Report + 三子阶段（工作流/可复用 Skill）
来源：max-gherman / fastcrw / agentlist-top / supernodes
- **循环**：Plan（拆子问题）→ Search → Scrape → Analyze → Decide（够了没）→ Repeat 或 Report——**每轮迭代加深理解直到决定信息够**。
- **三子阶段**：iterative retrieval（query 改写/并行搜索/来源质量排序）→ fact verification（多源交叉验证/置信度评分/引用追踪）→ report generation（大纲规划/逐节写作/引用嵌入）。
- **单一检索只是开始**：计划搜索策略→跨多源执行查询→评估发现→识别缺口与矛盾→细化 query→带 provenance 合成 grounded 答案。
- 提升层：工作流（研究循环）/ 可复用 Skill（深度研究模板）。

### 2. 问题分解纪律：3-7 自包含子问题 + 研究框架选择（工作流/可复用 Skill）
来源：aiworkflowlab-python / supernodes / trec-uva-ragtime / lobehub
- **分解成 3-7 个自包含子问题**：每子问题可独立回答无需读其他；**偏好非重叠覆盖而非穷尽覆盖**；**planner 只计划不回答**。
- **query 多样化防回声室**：submodular 优化平衡相关性与多样性（形式化保证）。
- **结构化主题选研究框架**：PESTEL=市场/行业、5W1H=通用、Argument Mapping=争议/辩论——**分解质量决定后续一切**。
- 提升层：工作流（分解方法）/ 可复用 Skill（框架清单）。

### 3. 多源交叉验证 + 置信度分级 + 引用审计器两步（工作流/可复用 Skill）
来源：promptz2h / supernodes / llmversus / xbstack / rework
- **共识分级**：单源事实标"unverified but cited"、2+ 独立来源共识标"verified"。
- **每子问题至少搜 3 个独立来源、全文阅读、每条事实性声明带来源 URL、四档置信度评分后才准入答案**；**两源矛盾=两方都进答案、各带链接，让读者权衡**。
- **引用审计器两步**：①存在性检查（解析所有 markdown 链接/引用号，反向搜索 Semantic Scholar 验证 DOI 真实有效）；②语义对齐检查（声称"据 [1]"的句子与 [1] 摘要语义相似度，严重偏移触发告警/阻断输出）——**硬要求：每个事实声明映射到来源 URL、引文子串必须存在于抓取内容**。
- 提升层：工作流（证据验证）/ 可复用 Skill（审计器清单）。

### 4. Thinker-Actor 递归子 agent 树 + 并行证据获取（工具/工作流）
来源：weisberg-kb / langchain-deepagents / arxiv-2602.22675-smtl
- **递归深度研究**：根 agent 可 spawn 自主子 agent（完整独立实例）调查子分支，子 agent 又可 spawn 孙 agent=**分形调查树**。
- **Deep Agents 模式**：todo list 中间件计划→委派子 agent（隔离上下文）→评估搜索结果→合成带引用报告。
- **Search More, Think Less**：**并行证据获取替换顺序推理**——上下文预算约束下更高效、泛化更好。
- 提升层：工具（子 agent 编排）/ 工作流（并行研究）。

### 5. 深度研究栈选型 + API 三模式 + 两档模型（工具/工作流）
来源：techiehub / firecrawl-deepresearch-apis / aistudio / aiwiki
- **不是单工具是栈**：ChatGPT Deep Research=最长最结构化报告；Perplexity=最快+透明引用；Claude Research=推理合成最强；Gemini=Google Workspace 内最佳；Elicit=学术文献综述（筛 4 万论文提取结构化证据）。
- **API 架构三模式**：①search→extract→synthesize（三显式步骤、每步可控可过滤、最常见）；②并行子 agent 委派；③单 agent 迭代循环。
- **两档模型**：preview=快、可流式回 UI；max=综合最强、适合 cron 后台生成尽调报告（extended test-time compute 迭代推理/搜索/精炼）。
- 提升层：工具（选型）/ 工作流（架构模式）。
