## 落地 5 独点（每点标注提升层）

### 1. MCP 2026-07-28 RC：协议层无状态化（工具/工作流）
来源：mcp-blog-rc / mcp-blog-index
- **MCP 协议层现在 stateless**（6 个 SEP 协同完成）：**之前 client 经负载均衡粘性路由到一个 server 实例、所有实例共享 session store；现在同一 client 可路由到任意 server 实例、无 session store**。
- **远程 MCP server=普通 HTTP 工作负载**——任何已有 API/服务基础设施都能托管；本地 server 也可说 HTTP。
- 判据：**可水平扩展、无粘性会话 = 部署形态从"特殊件"变"普通件"**——选型时按普通 HTTP 服务运维。
- 提升层：工具（MCP 部署认知）/ 工作流（运维模式）。

### 2. MCP 安全实践清单：白名单/不可信输入/审批/令牌绑定（工具/可复用 Skill）
来源：microsoft-learn-mcp（3 篇）/ secappdev-mcp / taf352
- **allowed_tools 工具白名单**；**远程 MCP server 的工具描述/注解/结果=不可信输入（可含间接注入指令）**；高风险操作（写数据/改资源）要求审批，批准前审工具名+参数。
- **令牌永不出现在 query 参数/URI**；RFC8707 audience 绑定、每 server token 绑定、拒绝重放、短时 token+最低 scope。
- **关键资源/敏感操作（删库/批量导出）L3 下二次确认或加强认证**（管理员口令/OTP）——中国 TAF 352 行业标准同源要求。
- 凭证进密钥库（Azure Key Vault 等）不写源码不进版本控制。
- 提升层：工具（MCP 接入）/ 可复用 Skill（MCP 安全清单模板）。

### 3. 工具过滤+语义搜索：动态缩减工具集（工具/工作流）
来源：aws-mcp-strategies
- **动态给 LLM 提供 scoped-down 工具集**——提升选工具准确率+减少上下文窗口占用。
- **tool filtering 三法**：按工具名称（精确匹配/模式）、按工具描述（语义匹配）、按域/类别标签；**semantic search 对"用户意图↔工具描述"匹配特别有效**。
- 判据：**工具一多就先过滤再给**，不把全量工具列表塞进上下文。
- 提升层：工具（工具集治理）/ 工作流。

### 4. A2A v1.0：agent 互操作标准 + 与 MCP 分工（工具/工作流）
来源：a2a-protocol（blog/dev/spec/v1.0/v0.2/v0.3）/ linuxfoundation-press / github-a2a
- **A2A=Google 发起、捐 Linux Foundation、150+ 组织采用**——跨框架/跨厂商 agent 互操作（LangGraph/CrewAI/ADK/Genkit 都能协作）。
- **三机制**：AgentCard 能力发现（声明能力与认证方案）/ 交互模态协商 / 版本协商（多版本共存的语义模型）。
- **多 transport 功能等价性要求**：相同操作集+语义等价结果+一致错误映射（错误码）+等价认证（AgentCard 声明）。
- **与 MCP 分工**：**MCP=暴露可移植工具，A2A=互操作 agent**——两者配套（ADK 等框架内 build with MCP、equip with A2A）。
- 提升层：工具（互操作标准）/ 工作流（跨系统协作）。

### 5. Agent 记忆实现选型：Mem0 vs Letta vs Zep + 提取-检索节点（工具/可复用 Skill）
来源：aitldr-mem0 / aiworkflowlab-mem0-letta-zep / dailyaiworld-mem0 / agdex-memory / aws-s3vectors / mindstudio / devtoollab
- **Mem0=轻量层**：LLM 每轮决定哪些事实值得存（ADD/UPDATE/DELETE/NOOP），**只写蒸馏事实不写原始 transcript**；vector+graph+key-value 混合存储、自适更新（合并不盲目重复）——**最流行开源方案、3 行集成**。
- **Letta=显式 memory-block API（MemGPT 后裔）**；**Zep=时间知识图谱（Graphiti）追踪事实随时间变化**。
- **LangGraph 集成=两个额外节点**：LLM 前 memory retrieval 节点 + LLM 后 update 节点（checkpointing 管 thread 内、mem0 管跨会话）。
- **向量元数据必备**：时间戳/置信度/来源 agent ID/类型分类/过期策略——支持过滤（按 agent ID scope 查询、按过期策略清理）。
- **三 tier**：in-context（现在所见）/ semantic（向量检索事实）/ episodic（关系库结构化交互记录）。
- 提升层：工具（记忆库选型）/ 可复用 Skill（记忆层集成模式）。
