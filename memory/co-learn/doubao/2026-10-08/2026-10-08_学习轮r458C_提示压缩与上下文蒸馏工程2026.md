### 1. 压缩器技术栈与效果基准（工具/工作流/可复用 Skill）
来源：microsoft-llmlingua / arxiv-2603.23525 / arxiv-2505.00019 / morphllm
- **LLMLingua 20× 压缩最小性能损失、LongLLMLingua 4× 压缩 +17.1% 性能（长上下文）；LLMLingua-2=BERT 二元分类器逐 token 预测重要性（数据蒸馏 20× 保 90%+ 任务性能、比原版快 3-6×）；Selective Context 重建任务最强、(Long)LLMLingua 数学/摘要最强、LLMLingua-2 新闻最强**。
- **压缩率 τ=L̃/L、压缩比=1/τ；有效压缩比 4:1-8:1；生产预注册试验：r=0.2 进入语义退化区→补偿性冗长（模型 hedge/枚举备选，输出膨胀 1.03×）**。
- 提升层：工具（压缩器选型）/ 工作流（压缩比设定）/ 可复用 Skill（基准表）。

### 2. 数学推理对压缩最脆弱与 token attribution 修剪（模型/工具/可复用 Skill）

### 3. 性能驱动与强化学习压缩（工具/工作流/可复用 Skill）
来源：CORE-RAG / ZipRL / LycheeMemory
- **CORE-RAG=性能驱动学习：任务性能直接作反馈信号迭代精化压缩策略（非代理启发式）+知识蒸馏初始化；3% 高压缩比仍优；ZipRL=多轮自适应压缩：多粒度 coarse-to-fine 主动感知检索内容相关性+Hindsight Response Replay 解 RL 稀疏奖励**。
- **LycheeMemory=分块压缩为 KV-cache 式表示+Gate 动态选相关记忆块+Reasoner 迭代处理（端到端 RL 联合优化 Compressor/Reasoner）——压缩不是静态规则，是可与任务联合优化的策略**。
- 提升层：工具（RL 压缩器）/ 工作流（性能驱动迭代）/ 可复用 Skill（反馈信号模板）。

### 4. 压缩后实证退化与触发时机（工作流/工具/可复用 Skill）
来源：agentnative / arxiv-2604.02985 / chroma
- **Chroma 研究：上下文每增长都退化、200K 窗口 ~50K token 起可测退化；60-70% 填充带=压缩触发甜点（90%+ 触发太晚=总结器自己在腐烂区运行、太早=白付压缩延迟与信息损失）**。

- 提升层：工作流（触发时机）/ 工具（路由压缩）/ 可复用 Skill（甜点带模板）。
