## 落地 5 独点（每点标注提升层）

### 1. Agent 编码主循环：PLAN-ACT-OBSERVE-REFLECT-DECIDE-VERIFY（工作流/可复用 Skill）
来源：cadence / regolo / sonarsource
- **PLAN**：拆目标为动作序列；**ACT**：选工具（read_file/edit_file/run_shell/run_tests）；**OBSERVE**：原样读工具输出；**REFLECT**：观察与计划匹配吗？变了什么？；**DECIDE**：继续/重规划/升级/停止；**VERIFY**：跑测试+type-check+lint+重读 diff。
- **验证失败→结构化错误反馈回 Execute 阶段（不是重跑 prompt）**；**Closed Loops 需要精确目标+严格上下文边界**（context boundaries），防无限昂贵 Open Loop。
- 提升层：工作流（agent 循环）/ 可复用 Skill（编码 agent 模板）。

### 2. Loop Engineering：从 prompt 工程到控制回路（工具/工作流）
来源：leimingyu / regolo / futureproofing
- **Loop engineering=设计"何时提示 agent、何时停、结果是否可接受"的自治控制系统**——难度从措辞转向"可无人值守运行的可信控制"（比 prompt 工程难）。
- **每阶段 ground truth 明确化**：Build 读计划+现有代码模式；Test 读测试/build 退出码/fixtures；Ship 读 diff+PR checklist——agent 必须证明自己（reusable verification harness）。
- 提升层：工具（控制系统）/ 工作流（验收标准）。

### 3. TDD AI agent 循环（工作流/可复用 Skill）
来源：kilo
- **Red**：agent 写失败测试捕获预期行为；**Green**：写最小实现使测试通过；**Refactor**：清理——**机器速度执行人类纪律**。
- **判据**：生成代码再祈祷它工作（generate-and-hope）不如先写失败测试——TDD AI agent 是最可靠的自主任码形态。
- 提升层：工作流（TDD 循环）/ 可复用 Skill（红绿重构模板）。

### 4. SWE 基准演化与缺陷审计（模型/可复用 Skill）
来源：swebench.com / arxiv 多篇 / openai-signal-noise
- **基准代际**：SWE-bench 2294（12 Python 仓库原始）→ SWE-bench Verified 500 → SWE-bench Pro 1865 多语言 → SWE-bench ProMax 170 七语言重构（issue 描述重写为精确无歧义规格）。
- **缺陷审计**：OpenAI 审计 SWE-bench Pro **~30% 任务 broken**——基准数字必须看审计结论再信。
- **能力缺口**：SWE-EVO 48 任务平均 21 文件+874 测试/实例——GPT-5+OpenHands 仅 21% vs 单文件 65%（长视野多文件是真实缺口）；SWE-Interact 用户驱动多轮（先模糊需求逐步揭示）；BeyondSWE 跨仓库/迁移/全仓生成前沿模型平台。
- 提升层：模型（能力基线认知）/ 可复用 Skill（基准可信度判断）。

### 5. Spec-Driven Development + SCOPE 分级评审（工具/工作流/可复用 Skill）
来源：agentropic / marktechpost / michaelagreiler / dev-tamizuddin
- **SDD**：spec 是 source of truth（非代码非 chat prompt）；写 spec→derive plan→拆原子任务→agent 生成；**需求变化→改 spec 重生成（不手工打补丁）**；"spec is the prompt"；Kiro 三阶段 requirements.md/design.md/tasks.md；**静态 spec 数小时漂移——spec 生命周期是采用前第一个问题**。
- **SCOPE 四级评审**：Initial（团队先评，定监督需求）→ Agent（LLM 自主审）→ Developer（开发者审）→ Team；**AI 评审从 nudge 建议转向 policy-as-code 强制执行门**；验证缺口=agent 生成速度>团队验证能力，diff 底下迭代/中间决策/跨文件副作用不可见。
- 提升层：工具（SDD 平台）/ 工作流（评审分级）/ 可复用 Skill（spec 模板）。
