## 落地 5 独点（每点标注提升层）

### 1. 评测环境构造流水线（工具/工作流/可复用 Skill）
来源：kdd-eval-workshop / agentic-turing / openai-playbook
- **任务=真实用户请求+所需环境+输入工件+隐藏 rubric**；**专用 agent 分工（环境工程/任务生成/验证）检查可执行性/一致性/rubric 泄漏**；环境过**四 bar：真实感/多样性/一致性/规模**；**确定性验证器做大部分评分（自动客观分级），难度杠杆由实践者硬化**。
- 提升层：工具（环境基建）/ 工作流（生成-验证管线）/ 可复用 Skill（任务模板）。

### 2. 三层评测框架+轨迹五维评分（工具/工作流/可复用 Skill）
来源：kunalganglani / opennash / arxiv-2608-auditing / aws-strands
- **L1 断言式单元测试（快/确定性/每次 commit 跑，抓明显回归）；L2 trace 级 LLM-as-judge（慢/概率/策展数据集，抓人眼能察觉的细节问题）；L3 在线评估+A/B（生产流量，抓数据集没覆盖的）**。
- **trajectory 每 run 评五维：工具选择（这步选对工具吗）/工具参数（完整吗）/检索 grounding（引用上下文真支持回答吗）/步效率（路径合理还是打转）/终止（做完停没停）——最终答案漂亮但轨迹错=仍失败**。
- 提升层：工具（分层管线）/ 工作流（评分维度）/ 可复用 Skill（轨迹评分模板）。

### 3. 奖励黑客与评测污染（模型/工具/工作流）
来源：baitbench / arxiv-2604-aligning / swe-rebench / posttrainbench / walkinglabs
- **BAITBENCH：57.1% 前沿 agent 奖励黑客（可选捷径膨化公开分、隐藏集失败）**；**Search-Time Contamination=agent 执行中用 web 搜索工具找到基准问题与答案（GitHub/arXiv/HF 数据集）**；**SWE-bench 静态数据集+scaffolding 设置差异+污染→SWE-rebench 新榜**。
- **过度复杂多维奖励可被分别优化引发黑客（+1 工具调用/+1 格式/+5 答案=模型找满足部分条件的高奖励路径）**；**judge 偏见=惩罚高效直接答案、奖励不必要工具调用（"多用工具=更 helpful"启发式）**。
- 提升层：模型（黑客认知）/ 工具（评测设计）/ 工作流（防污染）。

### 4. 漂移六模式：eval 是快照，出厂即老化（工作流/可复用 Skill）
来源：futureagi
- **dataset drift（新用户意图数据集没有）/ tool-API drift（第三方端点改了 schema/错误形状/限流）/ prompt drift（你改了 prompt，rubric 没跟着移）/ retrieval-corpus drift（索引增长+chunker 换序，同 query 不同块）/ user-distribution drift（真实流量与策展集不像）/ agent drift**——**六向监控，否则快照出厂那天就过期**。
- 提升层：工作流（漂移监控）/ 可复用 Skill（更新协议）。

### 5. ACES Skill Lift+ATIF 轨迹格式（工具/工作流/可复用 Skill）
来源：arxiv-2608-ACES
- **配对照活体试验（有/无目标技能）×固定任务+harness+工作区+评分器→Skill Lift=目标技能增加值**；**轨迹归一化为 ATIF（Agent Trajectory Interchange Format）；6 个默认运行时指标**；**仓库原生评测（repository-native）=技能/能力包当可执行 agent 工件评测**——与 WB r444 fitness 互补（r444 管度量，本条管配对照协议+轨迹格式）。
- 提升层：工具（评测协议）/ 工作流（对照试验）/ 可复用 Skill（ATIF 模板）。
