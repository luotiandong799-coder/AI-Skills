## 落地 5 独点（每点标注提升层）

### 1. 合成数据蒸馏三型+过滤是必选项（工具/工作流/可复用 Skill）
来源：genai4a11 / prem / futureagi / ai-tldr / devweekends
- **hard distillation=学生练教师最终答案（Alpaca 式、简单但丢中间推理）；soft=token 概率分布（更好但需白盒访问）；speculative=生成多样输出+reward model 过滤+只训最好的**。
- **不过滤=10-30% 低质（错误标签/歧义输入/近重复/不匹配任务）；判断比生成容易=同模型能可靠识别自己生成的边界例（judging easier than generating）**。
- 提升层：工具（蒸馏型选）/ 工作流（过滤必选）/ 可复用 Skill（过滤清单）。

### 2. 合成数据去重与多样性工程（工具/工作流/可复用 Skill）
来源：futureagi / prem / shyankdev / arxiv-2606.21631
- **embedding 去重（text-embedding-3-large/multilingual-e5、余弦 0.92 阈值按域调、10K 候选典型拒 15-25%；字符串去重只抓逐字重复、抓不到改写）**。
- **双阶段去重=MinHash LSH 结构近重+SemDeDup 语义冗余聚类（合成样本余弦>0.88 剪）**；**k-center-greedy=嵌入所有例、迭代选距已选集合最远者（5000 多样例>5000 同主题聚类例）**。
- 提升层：工具（去重栈）/ 工作流（双阶段）/ 可复用 Skill（阈值模板）。

### 3. 评测数据污染与对抗污染（工作流/可复用 Skill）
来源：neelmishra / zylos / arxiv-2605.19999 / openai-shared
- **污染=评测例（或近改写）出现在训练语料=记分非能力（GPT-4 报告 1-25% 污染率、QA 基准审计 1-45% 泄漏；10% 污染=5-10 分虚高）**；**对抗污染数据集=unlearnable 但支持推理（污染抗性）**。
- **broken problems=不可解/错误 ground truth/歧义 prompt/缺失文件/不公评分/环境暴露捷径（如隐藏答案文件、仓库历史含 ground-truth patch）——常见到应作标准有效性风险**；**sandbagging=模型策略性低表现（评估协议须防）**。
- 提升层：工作流（污染审计）/ 可复用 Skill（有效性检查清单）。

### 4. 黄金测试集构建与 judge 校准（工具/工作流/可复用 Skill）
来源：masterprompting / latitude / arxiv-2408.08808 / mlflow-rageval
- **黄金集=输入+期望输出+评分法（改 prompt/换模型/改 RAG 后跑 eval 判升降）；分层=release 小黄金集+滚动集跟最近生产变更**。
- **构建顺序=规则检查→人工评审→校准 LLM judge；分域构造=手动策展+半监督聚类+分层抽样（1573 样本 14 类 84% 可分性）**；**RAGEval=completeness_target/hallucination_risk 字段让评分确定性；生成受约束问题=以 keypoint+源段落为上下文、只生成该段落可答的问题（防世界知识泄漏）**。
- 提升层：工具（评分模式）/ 工作流（构建顺序）/ 可复用 Skill（黄金集模板）。

### 5. 指令数据管线与难度分布（工具/工作流/可复用 Skill）
来源：datascale / NebulaExp / InfinityInstruct / Solar / dr-sci / CuratorKIT
- **SFT 核心任务=格式化（概率预测器→规整助手：响应格式/任务域边界/角色语气/安全基线/多轮结构），规模常见数万到百万对**。
- **难度估计器=自一致性发散性（难题多模型分歧大、易题一致）→按难度过滤/平衡分布/重点质检**；**动态难度课程=训练数据随模型能力演进；管线=多源采集→响应式蒸馏→规则+模型过滤→任务正确性验证→难度分级→多样性采样**。
- **CuratorKIT=append-only per-sample provenance 链+拒绝样本保留结构化失败原因（可审计、不静默删除）**。
- 提升层：工具（管线库）/ 工作流（难度平衡）/ 可复用 Skill（provenance 模板）。
