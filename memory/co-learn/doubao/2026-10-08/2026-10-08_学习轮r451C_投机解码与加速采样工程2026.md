## 落地 5 独点（每点标注提升层）

### 1. 投机解码原理：无损的并行验证（数学保证）（工作流/可复用 Skill）
来源：shyankdev / tencentcloud / localaimaster / dev-rosgluk
- **draft 模型提议 K 个候选 token→目标模型单次前向并行验证全序列；接受最长匹配前缀、从首个拒绝处重新采样**。
- **修改拒绝采样=数学无损（输出分布与直接采样目标模型一致）；被接受 token 免费=一次前向验证多个；内存带宽受限=验证 K token 墙钟≈生成 1**。
- 提升层：工作流（原理）/ 可复用 Skill（无损判据）。

### 2. 起草方法家族选型：EAGLE/Medusa/n-gram/MTP（工具/工作流/可复用 Skill）
来源：callsphere / aistackinsights / yobitel / egoistai / coreweave
- **EAGLE-3=直接 token 预测融合多层 hidden states（70-80% 接受率、3.5-5×）；Medusa=K 并行预测头挂目标模型（50-65%、架构简、VRAM 开销小、需 tree verification）**。
- **n-gram/prompt-lookup=零权重零成本（重复文本/摘要/翻译/模板生成场景、部分模型反而更慢）；MTP=训练时内建多 token 预测（DeepSeek-V3 1.8× 开箱 >80% 接受率）**。
- 提升层：工具（方法）/ 工作流（选型）/ 可复用 Skill（家族对比表）。

### 3. 速度公式与适用性判据（何时不划算）（工作流/可复用 Skill）
来源：aistackinsights / dev-rosgluk / tencentcloud / alibabacloud
- **Speedup=(1-α^(γ+1))/((1-α)(1+cγ))（α=接受率、c=draft/目标前向成本比）；接受率 α≥0.6+5 token 2-3× 可行**。
- **不适用=小目标模型<3B、高温>0.7、创意写作/开放生成、高 batch>32 compute-bound；工作负载敏感=chat 2-3×/code 1.5×/随机输出可忽略**。
- 提升层：工作流（判断）/ 可复用 Skill（公式模板）。

### 4. 并行起草与动态投机长度：下一代演进（工具/工作流）
来源：vllm-p-eagle / zylos / sssd / nvidia / neurips-dflash
- **P-EAGLE=可学习 mask token 单次前向生成全部 K draft token（解决 EAGLE 顺序瓶颈）；SSSD=按 batch size 动态选近最优投机长度**。
- **NVIDIA 五准则=GEMM 推入 compute-bound 区不增 KV 压力、attention 主导时 D=128/G-1、对齐 128 tile 边界；DFlash=扩散块起草并行**。
- 提升层：工具（P-EAGLE/SSSD）/ 工作流（长度调优）。

### 5. 部署工程：推理栈支持与紧 GPU 陷阱（工具/工作流/可复用 Skill）
来源：syncsoft / runaihome / vllm-blog / introl
- **vLLM 0.4+ 内置 EAGLE/Medusa/ngram/prompt-lookup（0.4 比 0.3.2 本地延迟降 41%）；SGLang/TensorRT-LLM 2.0-6.5× 低中并发**。
- **并行起草=线性缩放限制 speculator 模型必须极小+K 是敏感调优变量；紧 GPU 上 draft 模型可能更慢（不是更快）；2026 Qwen3.6/Gemma4 内建 MTP drafter 开箱即用**。
- 提升层：工具（推理栈）/ 工作流（部署判断）/ 可复用 Skill（检查清单）。
