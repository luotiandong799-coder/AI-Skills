## 落地 5 独点（每点标注提升层）

### 1. 网关核心能力清单（工具/工作流/可复用 Skill）
来源：litellm / openrouter / llmgateway / docs-litellm
- **统一 OpenAI 兼容 API 覆盖 100-400+ 模型/40-70+ provider**；同模型跨 provider **failover（≤2 次透明重试）**；失败请求不计费。
- **per-project/per-key spend cap+成本追踪**（预算仪表盘）；TPM 配额限流；hooks 认证/日志（可插拔）；选型对照：OpenRouter=托管（BYOK 5% 费/零 markup）/LiteLLM=自托管 MIT/llmgateway=加权打分路由+响应缓存 TTL 10s-1y。
- 提升层：工具（选型）/ 工作流（接入）/ 可复用 Skill（网关配置模板）。

### 2. 密钥池轮换与多密钥（工具/工作流/可复用 Skill）
来源：apipark / neuralbase / openai / beyondscale / maxim
- **多 key 池=限流配额倍增+单 key 打满/泄露其他继续**；**Bifrost 追踪已试 key、全循环后重置池（配额窗口滑过后可复用）**；按应用/按客户发独立 key 隔离重用户。
- **自动轮换 24h 上限限爆炸半径（长活 key 90 天上限）**；环境隔离（staging 低限流+不可访问生产+更快过期）；KMS 加密静态（分环境密钥）；每次调用审计日志（时间戳/调用者/provider/token 数）。
- 提升层：工具（密钥管理）/ 工作流（轮换策略）/ 可复用 Skill（密钥池模板）。

### 3. 限流与配额策略（工具/工作流）
来源：azure-apim / zeroday / calmops / aliyun
- **TPM（token per minute）限流+周期配额（时/日/周/月/年）**；**多维限流表：req/s 5→burst、req/min 30→abuse、req/day 1000→scraping、input tokens/min 50k→context abuse、output tokens/min 30k→output DoW**。
- **单应用不能吃光 TPM 配额堵住其他应用**；按租户隔离限流器+缓存。
- 提升层：工具（限流配置）/ 工作流（配额设计）。

### 4. 三档模型分布 70/20/10+成本量化（模型/工具/工作流/可复用 Skill）
来源：hackernoon / langchain / ourtoken / siddhant
- **标准三档分布：70% 预算档/20% 中档/10% 旗舰（月账单 $100k→$12-15k）**；**LangChain 实测中档路由 64% 成本降无质量变化**；**级联路由省 40-60% 成本<2% 退化（60-70% 任务简单足够低档）**——与 r442C 级联选型互补：本条管成本分布数字与量化。
- 提升层：模型（档位认知）/ 工具（分布配置）/ 工作流（成本治理）/ 可复用 Skill（分布模板）。

### 5. 加权打分路由+floor 后缀（工具/工作流）
来源：nvidia-switchyard / llmgateway / openrouter / ourtoken
- **路由信号=任务类型/难度/上下文长度/预算/错误信号/质量评估；路由须考虑用哪些信号+何时用（信号时序）**。
- **加权打分路由（uptime/吞吐/价格/延迟加权动态选 provider）；`:floor` 后缀或 sort:"price" 一键选最便宜**；阿里智能路由=简单任务轻量模型/复杂任务高阶模型自动匹配。
- 提升层：工具（路由实现）/ 工作流（信号设计）。
