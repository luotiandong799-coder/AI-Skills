## 落地 5 独点（每点标注提升层）

### 1. 双时态记忆引擎：无 LLM 写路径+异步 consolidation+失效不删（模型/工具/工作流）
来源：arxiv-Engram / zylosai-persistent-state
- **fast write path**：关键路径外无 LLM 追加无损 episodes（用户不等记忆写入）；**异步 consolidation** 提取原子 (subject,predicate,object) 事实+双时态知识图谱，无逐事实 LLM 调用解决矛盾。
- **invalidating 而非 deleting**：每事实保留 provenance+supersession chain；**lean retrieved context 优于 full history**（混合读路径）。
- 提升层：模型（双时态建模）/ 工具（写路径架构）/ 工作流（异步合并）。

### 2. 五阶段记忆生命周期+置信度衰减+主动失效（工具/工作流/可复用 Skill）
来源：aliyun-五阶段 / iotdigitaltwinplm
- **五阶段**：抽取（对话→结构化记录）→整合（去重/合并/冲突解决）→存储（每种记忆类型路由到最合适后端）→检索（按需拉取，不每轮拉）→遗忘（主动衰减/归档/裁剪防存储腐烂）。
- **confidence decay**：置信度随龄衰减，检索过滤低于阈值事实；**active contradiction**：新信息矛盾旧事实标 superseded。
- 提升层：工具（生命周期）/ 工作流（遗忘显式化）/ 可复用 Skill（记忆治理模板）。

### 3. 矛盾解决三选一+语义仲裁器（模型/工具/工作流）
来源：zylosai-consolidation / velsof / niteagent / aimarkettrends
- **三选一**：overwrite 静默/双存时间戳按 recency 排序/显式 valid_until 失效（Graphiti）——**option 3 对时间查询最准**。
- **机械时间戳+recency 权重不足**→**arbiter broker（仲裁器）用 LLM 评估冲突条目**做语义合并；**写语义记忆时对同主题做相似性检查**，矛盾标旧 superseded+链接，读时取最新未矛盾条目（"2 月修好的 bug 5 月还在报"=没做写时检查）。
- 提升层：模型（语义评估）/ 工具（写时检查）/ 工作流（读偏好）。

### 4. 记忆类型差异化解冲突+自组织记忆 OS（模型/工作流/可复用 Skill）
来源：arxiv-HiMem / arxiv-EverMemOS
- **HiMem**：客观事件记忆语义稳定无需冲突检测；**知识型记忆（用户偏好/人格特质）语义冲突触发 assimilation/accommodation 操作**（Memory Reconsolidation 记忆再巩固，支持自纠+持续演化）。
- **EverMemOS 三阶段**：Episodic Trace Formation（对话流→MemCells：episodic traces/原子事实/time-bounded foresight）→Semantic Consolidation（MemCells→主题 MemScenes，蒸馏稳定语义+更新用户画像）→Reconstructive Recollection（MemScene 引导 agentic 检索组合响应）。
- 提升层：模型（再巩固）/ 工作流（自组织管线）/ 可复用 Skill（记忆 OS 骨架）。

### 5. 记忆评测基准族+两大失败模式（模型/工具/可复用 Skill）
来源：arxiv-PASB / arxiv-OP-Bench / genies-Memora / arxiv-ATRBench / arxiv-KnowItAct / semanticscholar-PM-Bench / arxiv-MINTEval
- **PASB**：1,600 任务，5 轮 persist+3 轮 neutral query 分两会话（query 无 persist 历史→下游污染必须经持久层）——测**持久谄媚**。
- **OP-Bench**：1,700 实例——**over-personalization 普遍，agent 不必要时也检索并过度关注用户记忆**；**ATRBench**：偏好隐藏 ground truth，8 个 frontier agent 默认低于 oracle ≥62 分——**acquisition（获取偏好）是瓶颈=proactivity gap**；**Know-It-Act**：显式偏好时**检索瓶颈占错误近半**（取不到含目标偏好的片段）。
- **Memora**：周-月跨度对话，三任务 remembering/reasoning/recommending；**PM-Bench**：prospective memory（维持用户意图/执行延迟意图/监测环境变化）；**MINTEval**：多目标干扰（频繁更新+长互连上下文）。
- 提升层：模型（评测认知）/ 工具（基准）/ 可复用 Skill（记忆评测模板）。
