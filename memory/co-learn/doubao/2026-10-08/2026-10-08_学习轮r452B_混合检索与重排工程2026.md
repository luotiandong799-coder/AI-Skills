## 落地 5 独点（每点标注提升层）

### 1. RRF 与 RSF：两种融合策略（工作流/可复用 Skill）
来源：sesamedisk / atlan / ruvector / aioapex / aiworkflowlab
- **RRF=rank-only score-agnostic（Σ1/(k+rank_i)，k=60 默认，忽略原始分数彻底绕开 BM25 无界 vs 余弦 -1~1 归一化问题；无需权重校准，agentic RAG 未知相关性分布时默认）**。
- **RSF=per-list min-max 归一化+加权混合（α 可配，已知相关性平衡时用）**。
- 提升层：工作流（融合）/ 可复用 Skill（融合选型模板）。

### 2. 混合 vs 纯向量：收益与覆盖（工具/工作流/可复用 Skill）
来源：llmversus / dataengineerhub / markaicode / llamaindex
- **混合检索比纯向量多数真实任务高 10-25%；语义+关键词单独各覆盖 ~60% 真实查询、合并 ~95%；混合召回提升 15-40% over 任一单法**。
- **每个检索腿设超时预算（dense 通常更慢）+一腿滞后时 fallback 防空结果**。
- 提升层：工具（双索引）/ 工作流（超时与 fallback）/ 可复用 Skill（覆盖判据）。

### 3. 两级检索架构与重排收益量化（工具/工作流/可复用 Skill）
来源：stackviv / wickedsmart / teachmeidea / neelmishra / arxiv-2604.01733
- **stage1 宽召回（bi-encoder/BM25 top-20-100 廉价）→ stage2 cross-encoder 精排 top-3-10 给 LLM**。
- **收益：MIT 平均 +33% RAG 精度、Databricks +48%、ZeroEntropy NDCG@10 +28% 降幻觉；文本-表格文档 Hybrid+Rerank 较未重排混合 +17.2pp MRR@3/+12.1pp Recall@5；nDCG@10 37.56 vs 27.35**。
- 提升层：工具（两段管线）/ 工作流（架构）/ 可复用 Skill（收益基线）。

### 4. cross-encoder 重排原理与代价（工具/工作流/可复用 Skill）
来源：ai-tldr / cohere / stackviv / bestaiweb
- **cross-encoder=query+单文档一起喂全交叉注意力输出单相关性分（捕获否定/实体/who-did-what-to-whom，向量距离抓不到）；代价=每候选一次前向不能预计算（延迟 5-10× bi-encoder）**。
- **托管 API（Cohere Rerank）低至 $0.002/搜索、三行代码集成；先混合宽召回后重排=最高 ROI RAG 改进**。
- 提升层：工具（reranker）/ 工作流（成本）/ 可复用 Skill（集成模板）。

### 5. 融合权重调优与评估指标分工（工作流/可复用 Skill）
来源：aiworkflowlab / qdrant / sifei / aigentlab / ruvector
- **grid-search dense 权重 0.2-0.8 步 0.1 最大化 nDCG@10（最优罕见 0.5、企业语料多在 0.55-0.65；权重只调训练 split 防泄漏，Sifei α=0.15）**。
- **指标分工：Recall@k 评一段混合检索漏检、nDCG@k/MRR 评二段重排；调优前先验证融合确实优于任一 prefetch（QDrant）**。
- 提升层：工作流（调优）/ 可复用 Skill（指标分工模板）。
