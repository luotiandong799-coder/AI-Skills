## 落地 5 独点（每点标注提升层）

### 1. 框架心理模型：graph vs loop vs chain vs crew 判别线（工作流/可复用 Skill）
来源：ai-tldr-frameworks / mastra / menuagentic / ayautomate
- **Loop**=while 循环单元+增长消息历史+LLM 决定下一步（ReAct/OpenAI Agents SDK；bug 模式=无限循环）。
- **Graph**=node+edge+类型化共享状态对象+显式条件边（LangGraph；bug 模式=状态管理错误）。
- **Crew**=crew 内隐式线程化上下文（状态不透明）。
- **判别线**：需要 cycles（重规划/重试/反思）/多 agent 分支/跨轮持久状态/HITL 审批门/崩溃后持久执行=**用图**；单轮线性不循环不分支=用 chain（LangChain）。
- 提升层：工作流（框架选型）/ 可复用 Skill（心理模型清单）。

### 2. LangGraph interrupts 双机制 + checkpoint 持久化（工具/工作流）
来源：langchain-interrupts / deepwiki-hitel / alicelabs / texasroh
- **静态中断**=compile() 配 interrupt_before/interrupt_after，节点执行前/后暂停；**动态中断**=interrupt() 在节点内任意点调用。
- **interrupt 不是阻塞**：保存全状态到 checkpoint→图退出（yield）→invoke 返回→人工输入到达后带**同 thread_id** 再 invoke→读 checkpoint 从暂停点继续（无需重启工作流）。
- **Command(resume=value)** 送人工决定回暂停的工具/节点。
- **checkpointer 后端**：SqliteSaver=开发推荐、PostgresSaver=生产；**每 thread_id 独立状态历史**——多会话 agent、审计轨迹、失败后中途恢复。
- 提升层：工具（框架 API）/ 工作流（持久化模式）。

### 3. HITL 生产三模式：审批门 / 条件分支 / 状态管理（工作流/可复用 Skill）
来源：niteagent / mintlify / xbstack-hitl / kgptalkie
- **approval gate**：关键决策点暂停求人工批准（不可逆动作前）。
- **conditional branching**：运行时条件决定执行路径。
- **state management**：显式状态跨步传递。
- **中断=图等待不是异常**：调用者收到结构化 payload 要求人工评审，批准/改参后 Command(resume) 恢复；**生产系统全自主是目标、关键决策点必须人工监督**。
- 提升层：工作流（HITL 设计）/ 可复用 Skill。

### 4. ADK agent 原语组合：Loop/Parallel/Sequential + exit_loop/StopWhenDone（工具/工作流）
来源：google-codelabs-adk / lobehub-adk-python / composio-adk
- **LoopAgent+critic+exit_loop 工具**=迭代精炼循环（critic 评审、exit_loop 退出）。
- **ParallelAgent**=fan out 独立任务并发（如选角与票房研究同时跑）；**SequentialAgent**=可预测流水线。
- **StopWhenDone**=读 session.state 的 task_complete 标志，set state 后 escalate=done 退出循环。
- **工作流选择**：可预测流水线用 workflow agents、动态路由用 LLM agents；**小/快模型干常规步骤、最强模型做判断调用**。
- 提升层：工具（ADK 原语）/ 工作流（组合模式）。

### 5. 长期 agent：托管 vs 自托管 + 循环工程三退出条件（工具/工作流）
来源：addyosmani-long-running / buildfastwithai-loop / claude-loops
- **托管**（Agent Platform / Claude Managed Agents）=brain/hands/session 拆分+可观测+身份+审计轨迹开箱；**自托管**（ADK/Claude Agent SDK/Codex SDK）=控制权+能用怪模型。
- **循环工程三退出条件**：成功退出/迭代上限/预算上限——**无人值守循环无预算上限绝不跑**；先手动 loop 跑可信再挂 schedule/event 触发。
- **Claude Code 循环原语**：/schedule、auto mode、dynamic workflows 可组合成长期工作；**路由常规给小快模型、判断调用给最强模型**。
- 提升层：工具（长期运行）/ 工作流（循环工程）。
