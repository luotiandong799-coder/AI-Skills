## 落地 5 独点（每点标注提升层）

### 1. 结构化输出的三机制区分与 constrained decoding 原理（工具/工作流/可复用 Skill）
来源：niteagent-providers / aifrontierpost / stochasticsandbox / devtoollab / claude-structured
- **JSON Mode（只保证语法无 schema 强制）≠ Structured Outputs（constrained decoding 保证匹配 JSON Schema：类型/字段名/required 生成时强制）≠ Function Calling（模型发带结构化参数的 tool call，agent 工作流非数据提取）**。
- **constrained decoding=每步采样 mask 违反 schema 的 token→物理不可能生成无效 JSON（无重试无后处理）；strict:True 编译 schema 为 CFG+mask logits；schema 约束=每对象 additionalProperties:false、全字段 required、nullable 用 type:["string","null"] 联合非省略**。
- 提升层：工具（三机制）/ 工作流（选型）/ 可复用 Skill（strict schema 模板）。

### 2. retry-with-error 循环与阶梯（工具/工作流/可复用 Skill）
来源：techearl / kanopy / niteagent-validation / theneuralbase-retry
- **验证失败→把具体验证错误（非"invalid JSON"）放回 prompt 重试；80-90% schema 违规首轮修复；max_retries=2-3 上限（超 3 token 成本超收益+重复失败=schema 不匹配重试无法修）**。
- **重试阶梯：simple（瞬时：截断/不稳定）→error feedback（80-90%）→stronger model（系统性）→schema 简化；错误反馈必须含失败的精确 schema 约束（模型对 schema 感知反馈显著更优）**。
- 提升层：工具（重试循环）/ 工作流（阶梯决策）/ 可复用 Skill（错误反馈模板）。

### 3. retry-repair 循环与边界验证（工具/工作流/可复用 Skill）
来源：devshakib / bswen / devopsboys / datarekha / richards
- **验证失败不丢整个请求：把模型自己的坏输出+精确验证错误还给它修（修近正确对象比从零生成容易）；限界重试；malformed tool response=在外部数据进入 agent 处用 schema 验证抛 typed error runtime 捕获非 LLM（模型产生 vs tool 返回双向验证）**。
- **free-form JSON=静默破坏源（错类型/缺 required/幻觉工具名）→decode 时严格 schema 强制+enum 处处用（闭合集）+版本化 schemas**。
- 提升层：工具（验证边界）/ 工作流（修复循环）/ 可复用 Skill（边界验证模板）。

### 4. 运行时控制与结构化反射（工具/工作流/可复用 Skill）
来源：ATLAS-RTC / ACL-structured-reflection / structuredllm-REFINESTAT
- **ATLAS-RTC=token 级运行时控制闭环：观察轨迹级信号→预测结构漂移→渐进干预维持输出契约（首次尝试可靠性提升不靠重试；模糊提示下受限解码失败场景）**。
- **结构化反射=把"从错误到修复"变成一等可训练动作：模型基于上一步证据诊断错误+提出可执行后续调用（DAPO+GSPO 目标+工具调用奖励）；REFINESTAT=语义约束（合法分布/良构参数）+诊断感知精化（可靠性检查失败重采样 prior/likelihood）**。
- 提升层：工具（运行时控制）/ 工作流（反射训练）/ 可复用 Skill（契约维护模板）。

### 5. grammar 约束解码工程与动态结构化（工具/工作流/可复用 Skill）
来源：nvidia-grammar / XGrammar-2 / LAVE / GrammarRL
- **NVIDIA：grammargen 从命令文档生成 Lark grammar+llguidance 应用于 llama.cpp→13 模型 pass rate 62.5%→75.2%（小模型最大提升 Qwen3-0.6B）**。
- **XGrammar-2=tag 触发动态结构切换（agent 工作流）+跨 grammar 子结构缓存复用+Earley 自适应 token mask cache；LAVE=lookahead-then-verify 适配 diffusion LLM，卡死上下文用轻量恢复调上下文；GrammarRL=无标签 RL（direct+reverse 双自监督奖励）适配 grammar 约束**。
- 提升层：工具（约束解码）/ 工作流（动态切换）/ 可复用 Skill（grammar 模板）。
