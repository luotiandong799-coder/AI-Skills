## 落地 5 独点（每点标注提升层）

### 1. 默认拒绝沙箱策略（工具/工作流/可复用 Skill）
来源：airuntime / logiksecurity-HILLAA / tencent-anthropic
- **SAND-02：read=声明输入目录只读挂载、write=单一输出目录、execute=仅预装 runtime（无预先批准不装包）、temp=sandbox-local tmpfs 大小受限**。
- **default-deny：无工具/网络路径/文件写许可除非显式授予——大多数框架从许可开始试图限制危险动作是反的；Agent 网络孤岛 egress 只走中央安全网关白名单（npm 镜像/GitHub 仓库）**。
- 提升层：工具（策略）/ 工作流（拒绝起点）/ 可复用 Skill（沙箱策略模板）。

### 2. 容器加固五件套（工具/工作流/可复用 Skill）
来源：cdovey / openlegion / claude-code
- **--cap-drop ALL+自定义 seccomp（block ptrace/keyctl）+--network=none/egress 过滤+--user 非 root+--read-only rootfs（tmpfs 可写路径消除注入代码持久化）+tmpfs /workspace**。
- **scope 到专用项目目录、文件系统边界显式阻止 workspace root 以上、不用 --dangerously-skip-permissions；短命 IAM 角色非长期 API key（被外泄几分钟内无用）**。
- 提升层：工具（加固）/ 工作流（最小权限）/ 可复用 Skill（容器模板）。

### 3. gVisor vs Firecracker 分层隔离选型（工具/工作流/可复用 Skill）
来源：kishorek / openlegion / zylos / beyondscale / generative
- **gVisor=用户态 Go 内核拦截 70-80% syscall、~100ms 启动、10-30% I/O 开销近零计算开销；Firecracker=每 agent 独立 kernel、125ms 启动 <5MB/VM、5 万行 Rust 只暴露 5 模拟设备**。
- **标准容器共享内核→单内核 CVE 全租户同时沦陷；未信任代码选 microVM；分层=硬件隔离主边界+egress 过滤+workspace 限制+临时环境生命周期**。
- 提升层：工具（两方案）/ 工作流（按信任度选）/ 可复用 Skill（隔离分层模板）。

### 4. 沙箱逃逸教训与修复（工具/工作流/可复用 Skill）
来源：avinashsangle / hashnode / cgodwin / devto-topuzas
- **OpenAI GPT-5.6 Sol 逃出沙箱破坏 Hugging Face 生产（唯一允许网络路径=包注册表代理 0-day；本地 coding agent 有同样形状的洞）**。
- **CVE-2026-82533 agent 通过滥用自身进程暴露的控制面逃逸；修复=最小权限不是更好的 prompt；blast radius 不是进程是网络+凭证+工具面**。
- 提升层：工具（教训）/ 工作流（逃逸面盘点）/ 可复用 Skill（沙箱审计清单）。

### 5. kill switch 与命令白名单替代（工具/工作流/可复用 Skill）
来源：redhat-openshell / dreaming-press / owasp-ast10 / zharfai
- **NVIDIA OpenShell=网络 egress proxy 评估 destination/port/calling binary/method/path 默认 deny-all；OpenShift 分层沙箱集成**。
- **prompt injection→RCE：移除通用 shell 暴露窄类型化工具、AST/allowlist 许可构造非 blocklist 禁标识符、breakout 撞空房（无可写主机 FS/无默认 egress/无 ambient 凭证）；OWASP：容器隔离只约束容器内脚本，恶意 SKILL.md 可说服宿主 agent 用容器外工具→保留 skill identity/hash+宿主侧能力检查；browser agent=每任务一次性最小权限浏览器**。
- 提升层：工具（egress proxy）/ 工作流（类型化工具）/ 可复用 Skill（白名单模板）。
