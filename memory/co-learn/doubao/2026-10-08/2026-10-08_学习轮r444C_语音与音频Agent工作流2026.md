## 落地 5 独点（每点标注提升层）

### 1. 延迟预算分解表（工具/工作流/可复用 Skill）
来源：futureagi / smallest / retellai / bitbytes
- **预算= VAD+音频采集 50ms / STT 150ms / LLM TTFT 400ms / TTS 首块 150ms / 网络 50ms ≈800ms**（优化后 P95 600-900ms；生产栈 speak/don't-speak ≈600ms）。
- 流式 STT 首 partial 100-200ms（Deepgram Nova-3/AssemblyAI Universal-1）；TTS TTFA 40-95ms（Cartesia Sonic 3）；LLM TTFT 150-400ms（4o-mini/Haiku）；函数调用 100-500ms。
- 提升层：工具（选型指标）/ 工作流（预算分配）/ 可复用 Skill（预算模板）。

### 2. 流式全链路原则（工作流/可复用 Skill）
来源：orbit / futureagi-optimize / assemblyai
- **每阶段流式端到端=单最高杠杆**：不等完整 transcript 才提示 LLM、不等完整回复才合成音频；feed partial transcripts+句子边界即送 TTS。
- **句子级 chunk 缓冲**（非逐词非全量）；预暖 WebSocket 连接+同区域部署+edge routing 减少网络跳。
- 提升层：工作流（管线设计）/ 可复用 Skill（流式模式）。

### 3. 级联 vs S2S 两架构（模型/工具/工作流）
来源：promptbench / anhtu / assemblyai-s2s / bordane
- **级联 STT-LLM-TTS**：每步有可读文本工件→可日志/审核/过滤/路由=2026 唯一生产就绪选择。
- **端到端 duplex（S2S）**：音频进音频出（OpenAI Realtime/Gemini Live），保留音色/语调/韵律但难调试、无中间文本；统一实时 API 折叠阶段是趋势（cartesia/gemini live 等）。
- 提升层：模型（架构认知）/ 工具（选型）/ 工作流（调试取舍）。

### 4. barge-in 编排+语义轮次检测（工具/工作流/可复用 Skill）
来源：vibeengines / futureagi-bargein / cissychen / dailyai
- **barge-in=用户打断：立即停 TTS+丢弃缓冲+重新倾听**；orchestrator 中央负责取消进行中 LLM 生成、丢弃排队/半生成输出、**只保留真正说出口的上下文**（stateful+racy 三并发）。
- **语义轮次检测**：LiveKit turn-detector（Qwen2.5-0.5B 蒸馏，CPU 低延迟）与 VAD 并行——VAD 管"有没有声/触发 barge-in"，语义模型管"这句话该不该接"；**cancel on contradiction+surface partial state**（"我正在拉取你的账户"）。
- 提升层：工具（turn-detector）/ 工作流（打断编排）/ 可复用 Skill（轮次模板）。

### 5. 语音 RAG 并行化+CLAP 音频嵌入（模型/工具/工作流/可复用 Skill）
来源：futureagi-rag / nvidia / mixpeek / arxiv-2508
- **partial transcript 即启动检索+LLM warm-up 并行**（retrieval_task 协程，await 已启动的检索）；每次检索调用落 trace 与 LLM/TTS span 并列。
- **Whisper→embedding→向量库双步管线**；speaker-turn 分块带元数据 citation（会议 RAG 可引用到说话人轮次）。
- **CLAP=CLIP 的音频对应**：HTSAT 音频编码器+RoBERTa 文本编码器 512 维共享空间，音频侧嵌入基线。
- 提升层：模型（CLAP）/ 工具（并行化）/ 工作流（trace）/ 可复用 Skill（语音 RAG 模板）。
