## 落地 5 独点（每点标注提升层）

### 1. 模型路由与置信度级联：95% 质量保持 + 75-85% 路由成本降（工具/工作流）
来源：iternal-routeLLM / ztabs-confidence-routing / calljmp-llm-cost-optimization
- **路由原则**：按任务所需能力匹配模型成本——分类/抽取/FAQ/格式化→小便宜模型（输出就几 token）；复杂推理/长上下文综合/agentic 循环→frontier。
- **RouteLLM 实证**（UC Berkeley）：**保持 GPT-4 质量 95%，仅 14-26% 查询送贵模型，路由流量成本 -75-85%**。
- **置信度路由**（Pattern A）：小模型先答+自报置信度→**置信度>阈值返回小模型答案，否则升级强模型**；路由前先在便宜模型上验证质量，不无脑切。
- 判据：任务类型分解→按类型定 tier；置信度低于阈值才升级；路由收益需工作负载量支撑（量小不值得养路由层）。

### 2. 路由分类器：1-4B 小模型当 router，把路由决策转成文本分类（工具/可复用 Skill）
来源：jonathanding-routing-classifiers
- **1-4B 参数小模型做路由决策：78.3% 准确率**——极低推理成本（本地部署零边际成本）、语义理解远超 BERT（能理解复杂查询结构）、可本地部署无需额外 API 调用。
- **核心转化**：把"路由决策"转成"文本分类"任务——让 router 输出目标模型档位标签而非开放推理。
- 判据：路由层本身也要成本可控——小模型分类器优于大模型开放判断；先验准确率门槛 ~78% 起步再上生产。

### 3. 压缩技术顺序：Prune→Distill→Quantize（3.68× 压缩实证）（工具/工作流）
来源：synapt-unicomp / distillabs-deployment / arxiv-2605.04062-edgerazor
- **UniComp 统一评估（40 数据集全组合）**：最优顺序=**先剪枝（Prune）→再蒸馏（Distill）→后量化（Quantize）**，**3.68× 压缩同时保持强能力**。
- **量化非线性**：FP16→8-bit 接近免费（大多数任务）；**降到 4-bit 才付出明显准确率成本**——别为省一点内存跳到 4-bit 而白丢质量。
- 结构化混合精度方向：super-group 分配（每 ⌊1/ρ⌉ 个输出通道 1 个 4-bit + 其余 1.58-bit）由参数 ρ 控制 4-bit 权重占比。
- 判据：压缩按 P→KD→Q 顺序做；先 8-bit 试点，质量不达标再评估 4-bit+蒸馏恢复。

### 4. 量化-感知蒸馏 QAD：4-bit 推理恢复配方（工具/可复用 Skill）
来源：arxiv-2608.20953-quantization-aware-healing / nvidia-nemotron-qad / arxiv-2609.26708-on-policy-distillation
- **4-bit 推理脆弱性机理**：量化误差**集中在低熵 token**，沿 chain-of-thought **逐跳传播**放大。
- **QAD 做法**：用 **KL 目标替换 task loss** 做量化感知蒸馏；**恢复中位分数 99.24%**（Nemotron 实证，PTQ 先保守量化→QAD 补损失）；配合针对保留集信号的早停。
- 判据：要 4-bit 部署先配 QAD 恢复流程；量化后用保留集验中位恢复率，<98% 需回退位宽或加强蒸馏。

### 5. LLM FinOps 杠杆排行：输出:输入 4:1 不对称 + 三杠杆 + tier 分布（工具/工作流）
来源：darioiannascoli-output-input-ratio / finout-arbitrage-gap / ecorpit-ai-gateway / varunsingla-tokenomics / doctorofdt-token-economics-pdf
- **输出:输入成本中位 4:1（reasoning 模型 8:1）**→经济激励=压缩冗长输出、只抽结构化数据；多提供商 list price 价差 **>300×**（轻量几美分/M 到 frontier 上百美元/M）→手动追踪最便宜选项不可行，路由/网关工具必要。
- **三大杠杆**：**model routing（路由流量 -75-85%）/ prompt caching（cached input -90%）/ semantic caching（语义命中 30-50%）**——两季度内把全成本 token 单价降 40-70% 不需动模型合同。
- **tier 分布经验**：**70% nano 档（分类+简单工具调用）/ 25% mid 档（结构化推理）/ 5% frontier 档（复杂推理）**；新原语=API-key 治理、代理/可观测性、模型路由。
- 判据：先量输出 token 占比（>30% 先压输出）；再按 70/25/5 分流量；命中率低时查 prompt 结构而非加钱。
