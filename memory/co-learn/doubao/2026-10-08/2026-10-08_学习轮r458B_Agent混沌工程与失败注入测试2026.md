## 落地 5 独点（每点标注提升层）

### 1. AgentChaos：LLM API 共享层程序化故障注入（工具/工作流/可复用 Skill）
来源：arxiv-2608.06790 / csdn-agentchaos / developersdigest
- **所有 agent 系统经同一 HTTP 接口访问 LLM→在该共享层注入 fault 不改源码（crash/omission/value 三类，作用在 content 与 tool call 字段）；运行时拦截修改 LLM API 响应**。
- **验证故障是否触发→过滤未触发任务防低估故障影响；Fault=(p, effect, recovery) 三元组：注入概率/修改后的工具响应/重试能否成功；fault profile Λ(λ) 按级别定义故障集**。
- 提升层：工具（注入框架）/ 工作流（注入-验证流程）/ 可复用 Skill（fault profile 模板）。

### 2. 鲁棒性是系统属性而非模型属性（模型/工作流/可复用 Skill）
来源：floritange / developersdigest / arxiv-2601.06112
- **pass@1 注入下最多降 50pp；鲁棒性排序与 backbone LLM 无关（换 GPT/Claude/DeepSeek/Seed 排序不变）；pipeline agents 最脆弱、iterative/evolutionary agents 最鲁棒**。
- **持续注入抹平架构差距（Δpass 62.39%）——鲁棒性=系统如何处理响应，不是哪个模型生成；选系统架构（迭代/演化式）比换更强模型更能扛故障**。
- 提升层：模型（backbone 无关性认知）/ 工作流（架构选型）/ 可复用 Skill（鲁棒性排序基准）。

### 3. 六类混沌失败模式与注入机制（工具/工作流/可复用 Skill）
来源：mudassirkhan / nefetech / zylos-testing / genai-club
- **六类覆盖：tool timeout（薄包装层定时抛超时异常）、malformed result、model refusal、context overflow、retry storm、schema drift——每类需特定注入机制，验证=产生结构化错误消息而非静默**。
- **chaos middleware：failure_rate 0.10-0.20 注入 timeout/500/malformed_response（staging 环境）；实测 LangChain agent 对抗输入 95% 失败率——不是模型差，是无恢复机制；混沌测的是 harness 不是给模型打分**。
- 提升层：工具（注入中间件）/ 工作流（staging 混沌演练）/ 可复用 Skill（六模式注入模板）。

### 4. LLM circuit breaker：语义退化触发与优雅降级阈值（工具/工作流/可复用 Skill）
来源：zylos-graceful / tamizuddin / cordum
- **LLM 的 circuit 应因语义退化或成本爆炸触发（非仅 5xx/超时）——重复生成 nonsense 即开路防 token 浪费并传播 fallback；Trip to OPEN=连续 5 失败或 60s 窗口错误率>15%；cooldown 60s（LLM API 恢复慢要更长）；HALF-OPEN 探针=轻量低风险请求、绝不重发原失败 prompt**。
- **safety kernel 不可达时 circuit breaker 3 失败 30s open 返回 SafetyUnavailable 而非阻塞；fail-open/fail-closed 二选一策略（closed=指数退避重排队保证不通过未评估任务、open=放行+计数）**。
- 提升层：工具（断路器）/ 工作流（降级策略）/ 可复用 Skill（阈值模板）。

### 5. 记忆投毒与边界故障注入场景（工具/工作流/可复用 Skill）
来源：dzone / amarchaudhari / reintech / flakestorm
- **memory poisoning=检索库注入一个事实错误文档测 RAG faithfulness（系统能识别或标记冲突文档）；工具返回 plausible wrong answers 最毒（测 detect/retry/hallucinate）；检索返回矛盾或空集测"我不知道"vs confabulate；注入延迟至 agent 自身 deadline 测优雅降级 vs 挂起；损坏一步输出看传播多远才被抓住**。
- **Flakestorm 四支柱=环境混沌+行为契约（不变量跨混沌矩阵验证）+回放回归（生产失败会话变确定性测试）+对抗输入（24 类变体，输入与环境双坏）；定义 exit criterion 再注入**。
- 提升层：工具（场景库）/ 工作流（注入场景编排）/ 可复用 Skill（场景模板）。
