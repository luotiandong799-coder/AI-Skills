## 落地 5 独点（每点标注提升层）

### 1. Trace-native CI 闭环：生产失败→回归测试→CI 门（工具/工作流/可复用 Skill）
来源：tracely / confident-ai / braintrust
- **生产 trace 落地即评分**；失败聚类为 named issues（on-call 直接定位）；**坏 run 冻结成测试阻止 PR**。
- **同一 scorer 部署前后跑**（pre-deploy evals+production observability 同系统）；**failing red team trace→regression test+CI/CD gate+production monitor+alert 单工作流**。
- 提升层：工具（平台）/ 工作流（闭环）/ 可复用 Skill（回归门模板）。

### 2. OTel GenAI+eval-as-span-attribute 三层可观测（工具/工作流）
来源：futureagi-otel / zylosai / elastic / aws-agentops
- **三层**：OTel-GenAI（标准 span）+OpenInference+**eval-as-span-attribute**（评分挂 span 而非独立表）；**gen_ai.* 命名空间标准属性**（gen_ai.system/request.model）；**span 级评分**：Faithfulness on response/Tool Correctness on tool call/Plan Quality on trajectory。
- **OTel 2026 从 CNCF 毕业**；auto-instrumentation（OpenAI/Anthropic/LangChain/LlamaIndex 几行接入）；trace 存 Delta 表/CloudWatch 等任意后端。
- 提升层：工具（遥测标准）/ 工作流（span 级评分）。

### 3. 三层评估分层+阈值门+版本化数据集（模型/工具/可复用 Skill）
来源：aws-strands / aws-dataset-management / aws-marketplace
- **三层阈值**：Layer1 Tool Usage >95%（工具选择+参数传递）/Layer2 Reasoning >85%（逻辑决策）/Layer3 Output Quality >90%（有用性+准确率）——**三层全过才部署**。
- **scenarios（inputs/expected outputs/assertions/tool sequences）发布为不可变编号版本**；可变草稿迭代到锁定 checkpoint；**生产失败→永久测试用例，未来每次改动都评估**；**数据集与代码同版本化**（跟踪/评审/链接 agent 版本）；**漂移=任务范围扩展后评测只测子集**（常见错误）。
- 提升层：模型（分层判据）/ 工具（数据集版本化）/ 可复用 Skill（三层门模板）。

### 4. 连续评估 CE 三组合+智能采样+trace 转数据集+replay（工具/工作流）
来源：google-continuous / microsoft-open-trust / aws-agentops-online
- **CE=生产监控+LLM-as-judge 自动化评分+人类反馈三组合**；在线评估可配置采样率（低采样到全流量覆盖）。
- **智能采样**：智能过滤最信号丰富交互（不必每请求评）；**traces to dataset**：生产 trace 转结构化评估数据集补离线覆盖率；**trace replay+可视化逐步回放**理解产出过程。
- 提升层：工具（采样/回放）/ 工作流（CE 管线）。

### 5. SME 校准+内置评估器起步+run/trace/thread 粒度（模型/工具/工作流）
来源：aws-evaluations / mslearn-copilot / langchain-agent-evals
- **内置评估器建立基线→自定义评估器成熟**；**SME 输入校准自定义评分对齐人类期望**（抓自动化评分盲点）。
- **offline evals 对 curated datasets+reference outputs 是回归测试主场**；**评估粒度 run/trace/thread 三选一**；**runevals --output 结果文件跨版本对比**+失败评审四查（响应 vs 期望/期望需更新/需更多训练数据/工具配置）。
- 提升层：模型（SME 校准）/ 工具（评估器/粒度）/ 工作流（失败四查）。
