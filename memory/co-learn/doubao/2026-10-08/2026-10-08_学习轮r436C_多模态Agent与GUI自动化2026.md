## 落地 5 独点（每点标注提升层）

### 1. GUI grounding 两模式：pixel 坐标 vs 语义引用（工具/工作流）
来源：max-gherman-multimodal-agents / yennj12-computer-use / localaimaster-glm45v
- **pixel coordinates**：模型输出原始 (x,y) 引用图像尺寸——直接简单但脆：分辨率变化或 UI 重缩放即失效。
- **semantic references**：模型输出语义描述（"Submit 按钮"/"列表第三项"），**由下游工具用 accessibility tree / DOM 检查 / 视觉元素检测解析成坐标**——稳、可移植。
- **GUI grounding 原语**：截图 + 自然语言指令 → 输出点击坐标；SeeClick 首个开放规模（合成+真实 GUI 数据微调 VLM、坐标当纯文本 token 输出）。
- 判据：跨环境/可变分辨率选语义引用；固定环境可像素坐标；行动输出用结构化 JSON（action/target/value）。

### 2. 多模态架构两模式：native 一体 vs specialist router + 视觉提取后校验（工具/工作流）
来源：niteagent-multimodal-prod / zylos-cross-modal / localaimaster-glm45v
- **native**：单一模型处理多模态——简单、跨模态上下文、简单输入低延迟；但图重负载贵、对每模态控制弱。
- **specialist router**：按模态分派给专家模型再融合——企业大规模异构输入的主流模式。
- **视觉提取后必须结构化校验**：合同/医疗等精度关键场景，**vision 模型初提取 + schema 匹配/交叉核对验证步骤再下游使用**——模型偶尔幻觉表格数字、误读低对比手写（例：GLM-4.5V GUI 输出 JSON action/target/value）。
- 判据：异构输入量大走 router；单模态简单走 native；任何视觉数据进决策前过结构校验。

### 3. 粗到细 GUI 定位：OCR+组件检测→坐标参考→裁剪放大 + VERIFY 循环（工具/可复用 Skill）
来源：arxiv-2608.03270-gui-lens / devpost-screenpilot / techrounder
- **GUI-Lens**：通用 VLM 定位 GUI 目标——**先提取 OCR 文本与检测 UI 组件、把位置当坐标参考呈现给 VLM；VLM 选下一视角区域，裁剪放大看更细细节（主动视觉观察、coarse-to-fine）**——绕过专用 grounding 模型。
- **ScreenPilot 循环**：vision 读屏 → text 规划结构化动作 → OS 级执行 → **每个重大动作后 VERIFY 重截图校验期望状态发生**。
- 成本事实：截图=多模态推理调用，规模化后成本累积快——按需截图非每步必截。
- 判据：定位难先 OCR+组件参考再裁剪；动作后必 VERIFY；截图频率与成本平衡。

### 4. 解耦四模块导航：Planner/Grounder/Reflector/Summarizer（工作流/可复用 Skill）
来源：arxiv-2602.13559-opagent / papernotes-roboagent
- **OpAgent 四模块**：**Planner 生成高层战略思路与指令 → Grounder 把语义指令转成精确可执行动作与坐标 → Reflector 评估状态迁移、监控任务进度 → Summarizer 目标达成后合成最终答案**——循环保证纠错。
- **RoboAgent 能力链**：Exploration Guidance（对象不可见时用常识预测目标方向）/ Object Grounding（开放词汇检测）/ Scene Description / Action Decoding / Experience Summarization（回顾近期动作、分析失败）——**只有 AD 直接产动作，其余四能力都带文本反馈**。
- 判据：导航类任务按"规划/落地/反思/收尾"解耦；非动作能力保留文本反馈形成闭环。

### 5. GUI Agent 评测基准族 2026：鲁棒性/全模态/并行（工作流/可复用 Skill）
来源：arxiv-2605.16402-windeskground / omni-gui / arxiv-2607.22689-paragui / arxiv-2607.11818-mm-toolsandbox / arxiv-2604.27974-finestate
- **WinDeskGround**：参数化生成复杂桌面场景（窗口遮挡/布局密度/语义相似度模拟分布漂移）测 grounding 鲁棒性——静态数据集测不出的真实工作流漂移。
- **OmniGUI**：每步连续交错多模态输入（静态图+同步音频+视频）step-level 评测（708 专家演示/2572 动作步/29 应用）。
- **ParaGUIBench**：多 GUI agent 并行执行与协调（多设备 Docker+共享文件系统+步数缩减比/token 成本效率指标）。
- **MM-ToolSandBox**：视觉 tool-calling 状态ful 环境（500+ 工具/16 域/目标修订/错误纠正/状态突变）；**FineState-Bench**：单步细粒度状态设定+精确目标态验证。
- 判据：评测选基准看"测哪层"——鲁棒性（WinDeskGround）/全模态（OmniGUI）/并行（ParaGUI）/工具调用（MM-ToolSandBox）/状态设定（FineState）。
