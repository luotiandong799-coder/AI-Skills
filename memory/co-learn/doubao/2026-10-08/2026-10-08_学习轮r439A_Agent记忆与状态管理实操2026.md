## 落地 5 独点（每点标注提升层）

### 1. 三温记忆架构 HOT/WARM/COLD + 定量预算（工作流/可复用 Skill）
来源：zylos-consolidation / zylos-token-economics / velsof / gcp-alloydb
- **HOT**=当前会话+即时相关事实（小时-天）；**WARM**=用户偏好/当前项目/近期决策（**2K-8K tokens 预算**，天-周）；**COLD**=历史会话/完成项目/旧决策（无限向量索引，月-年）。
- **三温分层减 60-70% 激活上下文**；WARM 层=Mem0 类库自动提取+冲突消解+多后端。
- **working memory（会话内）vs session memory（外部存储跨轮）区分**：会话内存转瞬即逝、session 存库每轮开头载入。
- 提升层：工作流（温层设计）/ 可复用 Skill（预算模板）。

### 2. 记忆遗忘与衰减纪律：TTL/recency/语义 key 检索（工作流/可复用 Skill）
来源：dev-tamizuddin / zylos-selective / admem
- **永不遗忘是负债**：episodic TTL 30-90 天自动过期；检索 recency weighting 衰减函数缩放分数；**挫折时刻说的偏好不代表长期**。
- **语义记忆不靠相似度检索**：key 查找或关系遍历（"用户偏好 Python"是 KV、"工作在 Acme"是图边）——embedding 相似度查偏好会漏。
- **transition policy**：episodic 毕业 semantic 的时机+合并机制要显式定义（AdMem=每动作后反思"结果符合预期吗/可复用吗"，符合才提取进 procedural）。
- 提升层：工作流（遗忘策略）/ 可复用 Skill（衰减模板）。

### 3. 记忆压缩三法：MemRefine pairwise / SimpleMem 三阶段 / 溢出通知（工具/工作流）
来源：arxiv-memrefine / arxiv-simplemem / mem0-tokencosts
- **MemRefine**=相似度只作候选配对、删/并/保留交给 **LLM judge 基于事实内容**（pairwise refinement，可插在记忆构建与检索之间、不改宿主管道）。
- **SimpleMem 三阶段**=语义结构化压缩（多视图索引单元）→在线语义合成（intra-session 去冗余）→意图感知检索规划（推断意图定检索范围）。
- **token 预算原生强制**：limit+threshold；**溢出 note 必须告诉模型"记忆上下文不完整"**——否则模型对省略的记忆相关问题过度自信。
- 提升层：工具（压缩框架）/ 工作流（预算纪律）。

### 4. 上下文预算当 CPU 预算：退化阈值 + 压法选择 + 原子组边界（工具/工作流）
来源：dev-karthidec / zylos-context-window / microsoft-compaction
- **退化阈值**：60-70% 填满性能可测退化、90% 工具调用质量恶化——**别等满才压**。
- **三压法**：截断最旧（简单但**常丢最关键——原始目标**）/ 拒绝请求（安全但体验差）/ 压缩（去重/摘要/丢低价值/保关键事实=优雅降级，构建贵但 agent 继续跑）。
- **压缩尊重原子组边界**：工具调用+结果消息一起删（Microsoft TruncationCompactionStrategy/MinimumPreserved）——拆散则工具结果悬空不可解释。
- 提升层：工具（压缩策略）/ 工作流（预算治理）。

### 5. 会话状态四策略选型 + 生产持久化（工具/工作流）
来源：openai-agents-python / aws-marketplace / aimadetools / google-codelabs
- **四策略**：result.to_input_list()（应用内存、小对话全手动）/ session（你的存储+SDK、持久可恢复、自定义 store）/ conversation_id（服务端命名会话、跨 worker/服务共享）——**小对话手动、持久会话 session、跨服务 conversation_id**。
- **session-based 模式**：SQLAlchemySession per 会话；**生产用 DatabaseSessionService 防服务器重启丢会话**。
- **session vs memory 分工**：会话=工作台（瞬态详细历史）、记忆=文件柜（跨会话提炼持久知识）。
- 提升层：工具（状态选型）/ 工作流（持久化架构）。
