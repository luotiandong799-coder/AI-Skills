## 落地 5 独点（每点标注提升层）

### 1. 测试时计算的基本定律与两条扩展机制（工具/工作流/可复用 Skill）
来源：mikenguyen / aiwiki / vibeengines / zylos-inference
- **test-time compute 是独立扩展轴：准确率约随 log(算力) 线性（o1 平滑）；固定模型大小下投资推理算力胜过增大模型——当瓶颈=多步推理而非知识检索**。
- **两条机制：对 PRM 搜索（生成多候选、verifier 逐步骤评分选最优）+自适应分布更新（按具体 prompt 更新响应分布）；compute-optimal scaling：easy=一次足够、medium=更多样本甜点、hard=更多；coverage 收益递减需显著更多样本**。
- 提升层：工具（计算轴）/ 工作流（预算分配）/ 可复用 Skill（扩展决策模板）。

### 2. 并行思考优于扩展思考（工具/工作流/可复用 Skill）
来源：arxiv-2506.04210 / theneuralbase
- **"Does Thinking More always Help?"：extended thinking（单链越拉越长）不是有效预算利用；parallel thinking（best-of-n 灵感）=同预算内生成多条独立推理路径+majority vote 选最一致，比 extended thinking 高 20% 准确率**。
- **self-consistency 投票需语义去重非字符串匹配——两个同义正确答法用简单相等会被当成不同票**。
- 提升层：工具（parallel 采样）/ 工作流（投票语义化）/ 可复用 Skill（一致性投票模板）。

### 3. verifier 三选：PRM / 轻量探针 / 粒度调节（工具/工作流/可复用 Skill）
来源：hyperai-Reprobe / arxiv-2606.19354-GRACE / arxiv-2507.15512
- **ReProbe：轻量 verifier 750-810× 少参数 match/exceed 最强 PRM、域外更优——大 PRM 过拟合域内 math**。
- **GRACE：验证粒度随 问题难度×verifier 准确率×预算 相变——预算大/问题难→细粒度占优，低预算/易问题→粗粒度；评测三指标 Maj@k（多数投票）/RM@k（reward 选最好）/Pass@k（任一正确）分用途**。
- 提升层：工具（verifier 选型）/ 工作流（粒度调节）/ 可复用 Skill（验证指标模板）。

### 4. 搜索与回溯：thought-level beam / stochastic backtracking（工具/工作流/可复用 Skill）
来源：arxiv-2608.08020-Gambit / arxiv-2605.25143 / arxiv-2506.22376-OptScale
- **Gambit=thought-level beam search：周期性剪枝劣轨迹+从高质量前缀立即分支（轻量 scorer 探 hidden states），同硬件 +6.7pp**。
- **stochastic backtracking=历史前缀池回访防 premature commitment/diversity collapse（Subpool Selection=随机子池 Top-N 让历史前缀绕过过打分的前沿候选）；OptScale=LM 预测器动态定最小样本数满足性能阈值与置信水平**。
- 提升层：工具（搜索算法）/ 工作流（样本数决策）/ 可复用 Skill（搜索模板）。

### 5. 自适应推理路由与延迟治理（工具/工作流/可复用 Skill）
来源：DART / ODAR / TRIM / infoq-E-GRM / RTR / zylos-adaptive / channel-tel
- **DART=draft-agreement 路由：草稿一致→快路径、不一致→Think 模式+entropy 预测预算，思考 token -32-73%；ODAR 双阈值三路径 c=1/2/6；TRIM=仅路由关键步骤到大模型（PRM 识别易错步，小模型处理常规续写）；E-GRM=奖励模型动态路由 58% 短路径、延迟 -62%、FLOPs -49%、准确率 +3.3pp；RTR=统一路由分配 LM+推理策略防 overthinking/thought pitfalls**。
- **延迟治理：voice 场景 extended thinking 几乎不是默认（4K budget 300ms→4000ms=10×）；streaming thinking indicators+parallel reasoning（ThreadWeaver 并发线程换延迟）**。
- 提升层：工具（路由）/ 工作流（延迟预算）/ 可复用 Skill（自适应推理模板）。
