## 落地 5 独点（每点标注提升层）

### 1. 统一嵌入空间两条路线：单向量融合 vs 晚交互多向量（工具/工作流/可复用 Skill）
来源：bigdataboutique / qubittool / botmonster / martinuke0
- **统一嵌入（Cohere Embed 4/voyage-multimodal-3/Gemini Embedding 2）=文本+图像同向量空间、单索引跨模态查询、单向量存储=简单但粒度粗**；**page-as-image 晚交互（ColPali/ColQwen2）=渲染页直接嵌入、多向量检索=图表密集文档召回最高但每页 100-1000× 向量、需自定义评分**。
- **生产两段式=稠密嵌入（SigLIP）快速召回 + 晚交互模型精排（不只用一种）**；**融合层=文本/图像向量归一化后拼接进同一 768 维空间、单次 ANN 查询返回混合模态**。
- 提升层：工具（两段栈）/ 工作流（先召回后精排）/ 可复用 Skill（融合索引模板）。

### 2. ColPali 晚交互机制：无 OCR 视觉检索（模型/工具/工作流）
来源：vespa / theneuralbase / prakashkagitha / iotdigitaltwinplm / PlanSightRAG
- **ColPali=PaliGemma 3B+ColBERT 风格多向量（图像 patch 换文本 token）+MaxSim 评分**；**整页视觉结构直接嵌入=保留空间对齐与布局、免 OCR/解析管线（视觉优先索引解决几何信息丢失）**。
- **索引=PLAID/HNSW-over-patches 多向量页面嵌入；ViDoRe 评测基准**。
- 提升层：模型（VLM 检索认知）/ 工具（索引栈）/ 工作流（视觉优先文档 QA）。

### 3. 嵌入模型选型五维评测（工具/工作流）
来源：zilliz / chatforest / goo.gle
- **选型维度=跨模态检索（近同干扰下文本匹配正确图）/跨语言（中文查英文文档）/关键信息（4K-32K 长文 needle-in-haystack）/规模/成本**；**Gemini Embedding 2=原生多模态 3072 维单空间（文本/图像/视频/音频/PDF 同空间、100+ 语言、无需转换步骤）**。
- 提升层：工具（选型）/ 工作流（评测维度清单）。

### 4. 统一多模态检索框架+MARVEL 四阶段（模型/工具/工作流）
来源：sjtu / arxiv-2604-MARVEL
- **统一编码器消除模态壁垒+残差融合保单模态一致性并捕捉跨模态交互+缩放训练修正模态学习失衡（均衡三模态样本分布）**；**MARVEL=GPT-4o 视觉 captioning→LLM 查询扩展（检索密集表示）→推理增强密集检索→CoT 重排**。
- 提升层：模型（训练策略认知）/ 工具（流水线）/ 工作流（caption-扩展-重排）。

### 5. 统一嵌入+排序：两阶段训练与 rerank 收益（模型/工具/工作流）
来源：UniNote / UMER / Qwen3-VL / MAGMaR / UME-R1
- **UniNote=两阶段（对比 SFT 建基座嵌入→RL 对齐内容相关性）**；**UMER=对比嵌入+判别排序单 MLLM 联合+互蒸馏（嵌入与排序函数互传偏好）**；**Qwen3-VL-Reranker 8B 全面超基座与基线 reranker（MMEB-v2/JinaVDR/ViDoRe v3）**。
- **MAGMaR=重排使 nDCG@10 从 0.17→0.54（推理式第二段补弱一阶段）**；**UME-R1=自生成推理与摘要比外部强模型更高效（12.3 点 CIRR 下滑警示推理采样有代价）**。
- 提升层：模型（训练范式）/ 工具（reranker 选型）/ 工作流（两段检索）。
