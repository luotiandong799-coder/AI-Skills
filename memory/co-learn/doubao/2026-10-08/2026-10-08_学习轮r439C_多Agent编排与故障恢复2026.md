## 落地 5 独点（每点标注提升层）

### 1. 多 agent 端到端可靠性数学 + 恢复四模式（工具/工作流）
来源：supergood / niteagent / openlegion
- **98% 单 agent 成功率 ×5 顺序 agent ≈ 90% 端到端（无容错时）**——每层失效率相乘，容错不是可选项。
- **恢复四模式**：指数退避+抖动（瞬态失败）/ circuit breaker（停止锤击降级服务）/ dead letter queue（失败任务捕获转人工审查）/ **幂等 agent 动作（安全重试不产生重复副作用）**。
- **inter-agent 协调失败=单 agent 系统不存在的第三层**：dropped hand-offs（发送方 hand_off 成功返回但接收方从未处理）——**发送方写 blackboard 时间戳、supervisor 检测未处理任务**。
- 提升层：工具（恢复机制）/ 工作流（可靠性设计）。

### 2. 编排器恢复管线六动作（工具/工作流）
来源：mech-app / xbstack / zylos-graceful
- **tool timeout→指数退避或 fallback tool；速率限制→入队冷却后重试；部分失败→从最后 checkpoint 续跑不重启；状态冲突→last-write-wins 或 merge；agent 崩溃→重指派 swarm 内另一 agent**。
- **三级超时升级**：2nd 超时 supervisor 减任务范围（全文→只读摘要）或换 fallback 工具；3rd 挂起任务、生成降级报告（"部分步骤超时请检查"）或转人工。
- **deferred retry 调度=自然背压**：失败任务重排程而非同步重试（LLM API 失败时尤其）；Dapr workflows 重启自动检测未完成 workflow 续跑。
- 提升层：工具（恢复管线）/ 工作流（升级策略）。

### 3. A2A 任务生命周期 + 二级认证凭据传递 + 信任状态机（工具/工作流）
来源：a2a-spec / microsoft-a2a / ietf-a2a-trust / cloudsignal
- **A2A 已捐 Linux Foundation（Google 发起）**：跨 LangGraph/CrewAI/ADK/Genkit 互操作、**不暴露内部状态**；capability 发现+模态协商。
- **二级系统认证传递**：TaskStatus.message 用 DataPart 声明所需认证→客户端 out-of-band 取新凭据交还 A2A（AuthenticationInfo 结构）。
- **任务状态机**：waiting_approval→pending→executing→completed/failed；**信任状态机 ACTIVE/DISABLED/DELETED**：disable 先于 delete、DISABLED→DELETED 强制等待期、审计日志保留。
- 提升层：工具（协议细节）/ 工作流（跨 agent 凭据治理）。

### 4. 编排模式选型代价 + 各模式失效模式（工作流/可复用 Skill）
来源：aipromptshub / metacto / zylos-swarm / niteagent / agentic-ai
- **选错模式=多 agent 系统贵 3-5x 的最常见原因**——先选型再动手。
- **supervisor=单点故障+瓶颈**（workers 从 supervisor 视角无状态）；**层级=嵌套 supervisor+隔离上下文窗口**（结果逐级上溯）；**swarm=共享任务板+轮询自选任务**（无中心瓶颈但收敛不可控）；**hub-and-spoke=hub 脆弱（一次坏路由级联）+中心翻译损耗**。
- **治理层把防御从 0.32 提到 0.89**——编排之上的 governance 是失效缓解关键。
- 提升层：工作流（选型）/ 可复用 Skill（失效模式清单）。

### 5. manager-worker 三角色拓扑 + director OrderBatch（工作流/可复用 Skill）
来源：datarekha / swarms-manager-worker / swarms-hierarchical
- **supervisor-worker 三角色**：中心 LLM 持有计划 + 窄域 worker agents + **共享 state 对象穿行其间**——worker 不互聊、全部经 supervisor。
- **director-worker 变体**：中心 director 分析任务→返回**结构化 OrderBatch** 给 specialist workers→可选 judge 对输出迭代反馈。
- **worker 隔离上下文窗口是层级架构关键收益**（Claude Code sub-agents 模式）——结果回传不污染主管上下文。
- 提升层：工作流（拓扑设计）/ 可复用 Skill（实现模板）。
