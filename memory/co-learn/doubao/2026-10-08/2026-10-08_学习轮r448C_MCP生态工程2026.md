### 2. 传输双机制+版本 header 契约（工具/工作流）
来源：mcp-architecture / streamable-http / java-sdk / go-sdk
- **Stdio=本地进程直接通信最优性能无网络开销；Streamable HTTP=POST 客户端到服务器消息+可选 SSE 流式、支持远程部署与标准 HTTP 认证（bearer token/API key/自定义 header、推荐 OAuth 获取 token）**。
- **每个 POST 必须带 MCP-Protocol-Version header 且值必须与 body 的 protocolVersion 一致（服务器拒绝不一致请求）**；多语言 SDK 默认含 Streamable 传输（Java HttpClient/Spring AI 2.0/Go StreamableServerTransport）。
- 提升层：工具（传输选型）/ 工作流（版本契约）。

### 4. MCP 授权工程：OAuth 2.1 动态客户端注册+EMA（工具/工作流/可复用 Skill）
来源：mcp-auth-spec / xbstack / truto / mcp-directory / ema / cloudflare
