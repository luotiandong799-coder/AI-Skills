## 落地 5 独点（每点标注提升层）

### 1. 反馈采集：显式 1-3% + 隐式 97% 双通道（工具/工作流/可复用 Skill）
来源：futureagi / arxiv-2510.27051 / zylos
- **thumbs 等显式反馈只覆盖 1-3% 对话；implicit 信号（retry/regenerate/abandon/copy-paste）覆盖其余 97%——隐式是主力**。
- **生产 agent 同时埋显式（thumbs up/down/rating/comment）+隐式（re-query/session abandonment）双通道，两个 thumbs-down 即可泛化出模式供开发者处理**。
- 提升层：工具（埋点）/ 工作流（双通道采集）/ 可复用 Skill（反馈采集模板）。

### 2. 反馈行 join 纪律：无上下文的反馈行只配 debug（工具/工作流/可复用 Skill）
来源：futureagi / theneuralbase
- **每个反馈事件必须 join trace_id/prompt_version/route/user_cohort/score_source 五字段——无上下文的反馈行只配 debug**。
- **每推理捕获四元组（input prompt+context / model output+confidence / user signal / ground truth when available）→打分管线识别高价值样本→只标高价值不标全部（承担不起标每个输出的成本）**。
- 提升层：工具（追踪字段）/ 工作流（高价值采样）/ 可复用 Skill（四元组 schema）。

### 3. 标注质量门：双标注 + 一致性系数 + 硬门槛 rubric（工具/工作流/可复用 Skill）
来源：futureagi / ajing-mercor / arxiv-2507.01352 / epistemic
- **偏好数据集采样 500-1000 对、每对 2-3 标注者、算 Cohen's kappa/Krippendorff's alpha 过门槛才入集；rubric 用 hurdle criteria 硬门槛防 reward hacking（不过门槛即零分）+grounding criteria 专罚幻觉+Binary Met/Not Met 降标注者分歧**。
- **高冲突项第三人裁决+随机/优质样本/全量三重审计；每个语料批至少两人审计**。
- 提升层：工具（门槛/系数）/ 工作流（审计协议）/ 可复用 Skill（标注 rubric 模板）。

### 4. RLAIF 替代 RLHF 的成本-偏差权衡（工具/工作流/可复用 Skill）
来源：genai4a11 / nvidia / arxiv-2507.01352
- **RLHF 需数千人工偏好标签贵且慢；RLAIF 用强模型评分+解释偏好，Anthropic Constitutional AI 达 RLHF 90-95% 质量、成本零头；代价=AI 反馈继承教师模型偏见**。
- **Human-AI 协同两阶段：严格协议人工核验+人类偏好引导的 LLM judge 规模化（Skywork SynPref 40M 对）**。
- 提升层：工具（RLAIF）/ 工作流（人机协同标注）/ 可复用 Skill（替代方案权衡）。

### 5. 飞轮停滞根因与改进阶梯（工具/工作流/可复用 Skill）
来源：zylos / interpretai / agentloop / nvidia
- **飞轮约第 3 个月停滞：易模式学完、标注质量退化、用户行为变化快于重训周期→用 MAPE 控制环（Monitor-Analyze-Plan-Execute）闭环治理**。
- **改进按最便宜层级爬升：prompt 调整→few-shot→RAG→微调；AgentLoop Trace2Dataset 自动把在线 trace 转 golden/bad-case/post-training 数据集（filtering/dedup/sampling/clustering）**。
- 提升层：工具（Trace2Dataset）/ 工作流（改进阶梯）/ 可复用 Skill（飞轮治理模板）。
