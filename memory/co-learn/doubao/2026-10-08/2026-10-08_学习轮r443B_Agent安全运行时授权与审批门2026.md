## 落地 5 独点（每点标注提升层）

### 1. 授权链作用域衰减+SCO+JIT Scoped Token（工具/工作流/可复用 Skill）
来源：ietf-CAAM / ietf-AAP
- **CAAM**：purpose-bound Session Context Object（SCO）把 agent 权威约束到特定任务；**JIT Scoped Token**；**Scope Attenuation：链中每个后续 token 作用域 MUST≤前驱，禁止委托期间作用域扩张**。
- **AAP broker 部署**：**任何凭证值/临时 token/后端标识不得进入 agent 推理上下文**（agent 只发抽象 grant reference，broker 验证）——防 credential-harvest/exfiltration。
- 提升层：工具（token 链）/ 工作流（委托）/ 可复用 Skill（授权链模板）。

### 2. 双机制网关：Cedar 确定性策略+动态拦截器+信任分（工具/工作流）
来源：aws-agentcore / microsoft-securing-mcp / nvidia-openshell
- **Policy（Cedar 声明式：principal/action/resource+条件）确定性访问控制+Lambda interceptor 动态验证**——双机制互补（确定性+动态）。
- **Agent 加密身份（Ed25519+ML-DSA-65）+0-1000 信任分**（SPIFFE 兼容，违规衰减/合规恢复）+**四层特权环模型**+kill switch 立即终止；**安全策略在系统层应用（agent 无法覆盖），不靠行为提示**。
- 提升层：工具（策略引擎）/ 工作流（信任治理）。

### 3. 审批门三件套：粒度/完整参数/HITL 挂起（工具/工作流/可复用 Skill）
来源：openai-codex / owasp-mcp / dzone / arcade-enterprise
- **沙箱定义技术边界+审批策略决定何时请求（跨沙箱）**；**单次批准 vs 会话级批准**两粒度。
- **显示完整工具调用参数（非摘要名）**；**确认 UI 不能被 LLM 生成回复绕过**；**state-mutating 工具执行挂起直到密码学/会话级批准**；高危操作 out-of-band 流（Slack/email）；**工具定义密码学哈希固定+每次执行前验证**。
- 提升层：工具（HITL 拦截器）/ 工作流（审批粒度）/ 可复用 Skill（审批门模板）。

### 4. 授权拒绝结构化理由+工具级 RBAC+per-client consent（工具/工作流/可复用 Skill）
来源：arcade-enterprise / truefoundry / cyber0946
- **deny-by-default+结构化理由反馈供模型重新规划**（拒绝也可回授，不止错误载荷）；**server 内工具级 RBAC**（客服 agent 可读 CRM 不可删——server 级策略表达不了，每工具带自身授权要求每次调用评估）。
- **MCP 代理 per-client consent**：registry of approved client_ids per user+MCP 自有 consent 页+**redirect_uri 精确字符串匹配**（防 Confused Deputy）。
- 提升层：工具（RBAC 粒度）/ 工作流（拒绝回授）/ 可复用 Skill（consent 模板）。

### 5. 运行时防护件+诚实覆盖率+可重放审计+工作区信任（工具/可复用 Skill）
来源：pypi-agent-runtime-security / pypi-agent-airlock / pypi-mcpkernel / riskatlas
- **防护四件套**：Guard（tool-use 策略）/Scanner（内容注入检测）/AuditLogger（结构化 JSONL 事件）/mcp_guard。
- **覆盖率诚实报告**：Full/Partial/Monitor-only（不宣称覆盖上游范围外）；**确定性信封**（输入输出哈希+Sigstore 签名可重放）+**防篡改 append-only 审计日志**+SIEM 导出。
- **workspace 内 shipped 的 tool/MCP server 配置绝不自动执行**：表面确切命令+来源+显式开发者同意（default reject）+工作区信任决策（AWS CVE-2026-12957 修复）；**子进程环境擦洗**（不继承 AWS_* session tokens/SSH agent sockets）。
- 提升层：工具（防护件）/ 可复用 Skill（审计/信任模板）。
