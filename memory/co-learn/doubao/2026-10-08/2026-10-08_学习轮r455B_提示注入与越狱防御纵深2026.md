## 落地 5 独点（每点标注提升层）

### 1. 七层防御纵深架构（工具/工作流/可复用 Skill）
来源：rapidclaw / balacode / wfnext
- **input handling（分离可信/不可信文本）+output filtering（行动前验证结构）+capability sandboxing（agent 在 jail 跑）+privilege separation（最小权限工具）+canary tokens（外泄绊线）+policy engines（高影响动作前确定性检查）+continuous red teaming**。
- **单分类器不够（每个有假阴性率、攻击演化快于检测更新），分层是必须——分类器只是七层之一不是完整方案**。
- 提升层：工具（七层）/ 工作流（纵深部署）/ 可复用 Skill（防御架构模板）。

### 2. 指令/数据分离具体技法（工具/工作流/可复用 Skill）
来源：matterai / rafaelhart / sdtimes / masterprompting / StruQ
- **不把不可信内容插进 system prompt；XML-escape body 防 </user_input> 终止边界+per-request nonce 后缀（攻击者猜不到）；instruction anchoring 用户消息前放提醒+ABSOLUTE CONSTRAINTS 声明不可被后续指令覆盖**。
- **StruQ=微调模型只跟 prompt 部分指令忽略 data 部分指令（最小效用影响）**。
- 提升层：工具（分隔技法）/ 工作流（结构化消息）/ 可复用 Skill（边界模板）。

### 3. jailbreak 六类分类与逐类防御（工具/工作流/可复用 Skill）
来源：futureagi-jailbreak / techrxiv / arxiv-2501.19180
- **role-play override/encoding bypass/multi-turn drift/indirect injection/system prompt extraction/adversarial suffix 六类；crescendo=五轮良性逐步升级→防御者必须打分全对话非最后一条**。
- **SCoT=要求模型先主动安全推理再拒（非立即阻断）；LLM Salting=旋转内部 refusal direction 使预计算通用越狱 prompt 失效（轻量微调）**。
- 提升层：工具（防御技术）/ 工作流（全对话评分）/ 可复用 Skill（分类→防御映射）。

### 4. RAG 间接注入三道防线（工具/工作流/可复用 Skill）
来源：futureagi-llm-security / arxiv-2606.19660 / kunalganglani / businesstechnavigator
- **检索 chunk 进 prompt 前跑注入分类器；Privilege-Constrained Context Assembly+Output Auditing+Continuous Audit Loop（ASR 71.4%→11.3%）**。
- **RAG Airgap=数据进库前 sanitization 模型（检测被动文本中祈使命令）+context tagging 严格分隔符；attribution-gated prompting 只输出有归因 spans；PoisonedRAG 5 文档 90% ASR 证明输入层防御不足**。
- 提升层：工具（Airgap）/ 工作流（三道防线）/ 可复用 Skill（RAG 安全模板）。

### 5. 输出侧校验与工具调用授权（工具/工作流/可复用 Skill）

- 提升层：工具（输出校验）/ 工作流（授权门）/ 可复用 Skill（高风险动作清单）。
