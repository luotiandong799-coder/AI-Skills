## 落地 5 独点（每点标注提升层）

### 1. 四失败模式与对应检测器（工具/工作流/可复用 Skill）
来源：futureagi-deep-dive / ijarcce / ijisrt
- **四失败模式各自配检测器与修复：Factual（与事实矛盾）→原子分解+外部事实核验→上游补检索/工具调用；Grounding（与提供上下文矛盾）→claim 级 entailment 对检索集→更严 prompt+claim 级 groundedness；Citation（源不存在或不支持）→结构化+可解析性+语义 rubric→schema 强制引用+注册表检查；Reasoning（推理链断裂）→逐步 trace 评分→低置信链拒答+chain rubric**。
- **单一指标必错：不同失败模式要不同检测器——一个分数回答不了"是编的还是没引用对"**。
- 提升层：工具（四检测器）/ 工作流（失败模式路由）/ 可复用 Skill（模式→检测器→修复表）。

### 2. 六种检测方法对比：先便宜后贵（工具/工作流/可复用 Skill）
来源：codesota / futureagi-tools / lyzr / vllm-lettucedetect
- **成本/延迟实测（每 1K 次检查）：NLI entailment 判定 $0.02/~200ms（对每条 claim 分类 ENTAILMENT/NEUTRAL/CONTRADICTION vs 源）最便宜；Retrieval KB 验证 $0.50；RAGAS RAG 评估 $1.20；SelfCheck 一致性采样 $2.50（生成 K 个响应比对）；FActScore 原子事实核验 $3.00**。
- **自一致性=无源可查时用：同 prompt 非零温度采样 3-10 次，关键事实一致→置信升，每次名字/数字/日期不同→强幻觉信号；LettuceDetect v2 做 span 级幻觉检测（覆盖代码/工具输出/文档，非仅文档 grounding）**。
- 提升层：工具（方法库）/ 工作流（成本路由）/ 可复用 Skill（先便宜后贵决策表）。

### 3. Groundedness 指标与生产阈值（工作流/工具/可复用 Skill）
来源：futureagi-understanding / openlayer / qaskills / linhtruong
- **核心指标：faithfulness（中位数+p10）/context relevance/citation accuracy（引用存在且支持声明）/user feedback rate（downvote/regenerate/escalate）/refusal rate（太低=过度自信、太高=过度保守）/tool call validity（agent 专用）**。
- **RAG 不减幻觉只转失败：仍 3-27% 查询错引/忽略相关段落/与上下文矛盾（随任务复杂度）——RAG 把失败从纯编造转为 faithfulness 违规；RAGAS faithfulness 解释带=0.9-1 excellent grounding/0.75-0.9 可生产（偶发漂移监控）/0.5-0.75 grounding 差（prompt 允许自由发挥）/低于 0.5 hallucinatory（模型忽略上下文或检索弱）——按此设生产 groundedness 阈值**。
- 提升层：工作流（指标集）/ 工具（阈值门）/ 可复用 Skill（阈值解释表）。

### 4. 逐 claim 分解验证与细粒度审计（工具/工作流/可复用 Skill）
来源：arxiv-RT4CHART / arxiv-halldetect / csharp-langgraph
- **RT4CHART（retromorphic testing）：把答案分解成独立可验证 claim→对检索上下文做层级 local-to-global 验证→每个 claim 标 entailed/contradicted/baseless 三标签→映射回具体答案 span 并返回上下文侧证据——细粒度审计而非不透明打分；RAGTruth++ 上 answer-level F1 0.424→0.776（+83%）**。
- **HallDetect：分解成原子 claim→对比式编码 entailment 模型（多尺度源块库）验证→不对称聚合分数（单条高置信反驳即 flag 整个响应）——消费级硬件（4-bit 量化）上超生成式/嵌入方法**。
- 提升层：工具（RT4CHART/HallDetect）/ 工作流（claim 分解流程）/ 可复用 Skill（三标签审计模板）。

### 5. 检索弱化降级与三层防御架构（工作流/工具/可复用 Skill）
来源：linhtruong / csharp-langgraph / ijisrt / ragaboutit
- **检索弱化降级：融合+rerank 后若 top[0].score < THRESHOLD 直接返回"信息不足"，不进生成——把低置信检索挡在生成前；双路检索（dense+bm25）→RRF 融合→rerank top5→带引用格式化上下文→prompt 限定"只许用上下文"**。
- **LangGraph 三层防御：Layer1 预防=grounding 检索证据+严格 prompt 模板+低温度限制生成空间；Layer2 检测=自一致性投票（N 次采样比对）+NLI entailment+引文验证（引用的源真含所述事实）并行独立检查；Layer3 纠正=检测失败后重检索/改写/拒答；attribution 五方法（MIT/Stanford 2026-05 预印本）跨金融/法律/生物医学语料把幻觉源引用平均减 80%**。
- 提升层：工作流（降级门）/ 工具（三层防御）/ 可复用 Skill（防御架构模板）。
