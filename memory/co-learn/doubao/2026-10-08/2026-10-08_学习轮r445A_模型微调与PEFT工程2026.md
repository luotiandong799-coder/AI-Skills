## 落地 5 独点（每点标注提升层）

### 1. LoRA 参数甜点（工具/工作流/可复用 Skill）
来源：codersera / aibytes / egoistai / pristren / effloow / cnblogs
- **r=16 甜点**（r=8 内存受限、r=32+ 复杂域迁移）；**lora_alpha=2×r 启发**；**target 全线性层（非仅 attention，2024 后共识）**。
- **lr=2e-4+cosine 调度；bf16 混合精度+gradient checkpointing；dropout 0→0.05 防过拟合；epochs 2-3 不超 5**；场景对照表（通用指令微调 7-14B→r16-32/代码数学→r32-64/70B+ 多任务→r16 控制总参）。
- 提升层：工具（参数配置）/ 工作流（训练流程）/ 可复用 Skill（微调模板）。

### 2. QLoRA 内存账+DoRA（工具/工作流）
来源：codersera / ailearningguides
- **QLoRA=基座 4-bit NF4 量化+fp16 LoRA 之上训练**；**70B 从 ~140GB→~48GB VRAM**（消费级可行）；**质量距全 LoRA 1-2%**=2026 默认。
- **DoRA（Weight-Decomposed LoRA）**：权重分解为幅值+方向，方向用低秩适配——新变体参考。
- 提升层：工具（内存预算）/ 工作流（消费级训练选型）。

### 3. 微调 vs RAG 决策框架（模型/工具/工作流/可复用 Skill）
来源：winder / llmversus / dailyai / futureagi / mudassir / agility
- **知识每周变→RAG（微调把快照冻结进权重=陈旧）；行为类（提示压不住的语气/格式/schema/决策策略）→微调（RAG 只加上下文不加风格）**；**<500ms 延迟硬需求→微调**；**RAG 72-89% vs 微调 91-97% 准确率（依赖检索质量/算力维护）**；**两者组合=生产级客服助手标准**；私有数据合规→自托管微调/自托管向量库。
- 提升层：模型（能力边界认知）/ 工具（选型）/ 工作流（决策）/ 可复用 Skill（决策框架模板）。

### 4. 蒸馏=2026 微调最强用例（模型/工具/工作流/可复用 Skill）
来源：winder / arxiv-2605 / govuk / alibaba / arxiv-2601
- **前沿模型（GPT-5/Claude Sonnet 4.6）生成窄任务高质量输出→微调小开源模型（Llama/Qwen/Mistral），近前沿质量×显著更低成本延迟**。
- **数据质量优先：500-1000 金标指令对>1万条脏数据**；**LSH 近重复去除防数据污染/过拟合**；**MCQ 排除（25% 基线概率会掩盖错误推理链）**；种子集 2,000-5,000 prompt 覆盖域内子任务+多样风格/复杂度/边界 case。
- 提升层：模型（小模型能力）/ 工具（蒸馏流程）/ 工作流（数据准备）/ 可复用 Skill（蒸馏模板）。

### 5. 蒸馏数据管线：联合标注→规则过滤→难度感知选择→多样性采样（工具/工作流）
来源：arxiv-2605-omnithoughtvis / google-cloud / alibaba
- **联合标注（推理难度/答案质量/语义任务标签）→规则过滤→难度感知选择→标签多样性采样**；显式格式约束下蒸馏结构化 CoT 轨迹。
- **指令增广（按语义扩写相似指令）+指令优化（改写措辞更清晰）**；规则法清洗异常数据（少量脏数据即降微调质量）。
- 提升层：工具（数据管线）/ 工作流（蒸馏流程）。
