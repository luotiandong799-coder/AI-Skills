## 落地 5 独点（每点标注提升层）

### 1. prompt 不可变版本与语义化版本（工具/工作流/可复用 Skill）
来源：promptassay / futureagi / masterprompting / omnithium
- **每个改动是不可变工件：版本捕获 text/model/params/change rationale/eval result；历史可 diff/restore/rollback 无需改代码**。
- **MAJOR=输出格式/行为/接口破坏（prose→JSON 现有集成可能破坏）、MINOR=新能力向后兼容（用户可能注意不到但 evals 应确认）、PATCH=typo/无行为措辞；git-native=prompt 作为 .txt/.md/.yaml 进 repo，commit history=版本历史**。
- 提升层：工具（版本化）/ 工作流（评审）/ 可复用 Skill（版本模板）。

### 2. prompt 生命周期三/四阶段与 metadata（工具/工作流/可复用 Skill）
来源：futureagi-lifecycle / aws-wellarchitected / aipromptshub
- **Draft（git+变量 schema 迭代候选）→Gated promotion（eval-on-PR+canary ramp 门控 floor/paired CI/safety flip）→Deprecation（archived+drain window+cache eviction 防 ghost-serving/split-version）**。
- **AWS 四阶段 Draft/Review/Active/Archived 由 approval workflow（CodePipeline/Step Functions）门控非惯例；每 prompt 必需 metadata：purpose/target agent/expected behavior/eval criteria/owner；rollback=一个 config 变更（stored artifact 稳定标识，回归分钟级解决 vs 小时级重构）**。
- 提升层：工具（生命周期）/ 工作流（门控）/ 可复用 Skill（metadata 模板）。

### 3. golden dataset 回归测试（工具/工作流/可复用 Skill）
来源：promptassay-regression / langfuse / latitude / neelmishra
- **golden dataset=精选输入+期望输出+schema+changelog；25-50 例起步→200-500 行扩**。
- **每次变更前跑固定测试集+rubric 评分+套件过才部署；LLM 输出 stochastic 不能 diff 字符串→比较聚合指标+统计显著性（baseline vs candidate 200 例）；捕捉 prompt 编辑与上游模型更新的静默破坏**。
- 提升层：工具（数据集）/ 工作流（回归门）/ 可复用 Skill（golden 模板）。

### 4. eval 门控 CI + canary 自动回滚（工具/工作流/可复用 Skill）
来源：devto-internals / confident-ai / velocity / futureagi-cicd
- **prompt 变更触发 CI eval 跑 golden→报告 gate merge（分数低于阈值 block）；staging label→golden experiment→production label promote**。
- **canary=gateway 路由 1-5% 流量到新 prompt+同 rubric 双群评分，rolling-mean 掉 2-3pp 持续 15-60 分钟触发 auto-rollback；eval blocks the merge 非 morning standup；触发条件=触碰 prompt 文件/tool 定义/retrieval 配置/model 版本**。
- 提升层：工具（CI 门）/ 工作流（灰度）/ 可复用 Skill（流水线模板）。

### 5. "更好的"prompt 会伤害：非单调改进与漂移检测（工具/工作流/可复用 Skill）
来源：arxiv-2601.22025 / futureagi-testing / devto-llmops
- **通用 prompt 改进非单调：加"helpful assistant" wrapper+显式规则→提取准确率 -10% RAG 合规 -13% 指令遵循 +13%；机制=通用规则与任务特定约束冲突（wrapper 本身无效果）；改动必须回归测试非直觉信任**。
- **漂移检测=production 采样 live 流量同 judge 评分 alert drift，失败生产 trace 变 labeled example 进下轮 CI（无 CI+production 两环 prompt 质量不可见直到用户投诉）；A/B 隔离单变量（不同时改推理结构+注入防御+输出格式）**。
- 提升层：工具（漂移）/ 工作流（双环）/ 可复用 Skill（非单调检查）。
