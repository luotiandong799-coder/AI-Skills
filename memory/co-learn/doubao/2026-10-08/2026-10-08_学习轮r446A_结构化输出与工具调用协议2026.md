## 落地 5 独点（每点标注提升层）

### 1. JSON 可靠性四层栈（工具/工作流/可复用 Skill）
来源：thepromptbench / devtoollab / dev-aifrontierpost / techearl / cnblogs
- **四层递增保证：① prompt+parse（最弱）→ ② provider JSON mode（保证可解析不保证形状）→ ③ schema mode/constrained decoding（保证结构精确匹配）→ ④ function calling（结构化参数副作用）**。
- **CD 让解析失败率 8-15%→<0.1%**；四层是**栈不是选项**（schema 设计+provider 强制+CD+验证循环全要）。
- 提升层：工具（选型）/ 工作流（输出管线）/ 可复用 Skill（可靠性模板）。

### 2. Constrained decoding 机制+开源栈（模型/工具/工作流）
来源：zylos / arxiv-2601-XGrammar2 / devtoollab / localaimaster / tensoria
- **CD=采样循环里按 grammar/schema 掩码非法 token（FSM/CFG/PDA），模型物理上产不出非法 token——所有 provider"100% 可靠"声明背后的同一机制**。
- **开源栈：Outlines/XGrammar/llguidance/llama.cpp GBNF**；**XGrammar-2=TagDispatch 动态结构切换+Cross-Grammar Cache 子结构级缓存复用（动态 agentic 负载）；TruncProof=LL(1) 近似最小完成 token 数，token 上限内产出合法 JSON**。
- 提升层：模型（机制认知）/ 工具（本地栈选型）/ 工作流（动态结构切换）。

### 3. provider strict mode 对照+token 开销（工具/可复用 Skill）
来源：precisionaiacademy / aiworkflowlab / cnblogs / google-cloud
- **OpenAI strict:true response_format（supported schema 100% 结构合规）；Anthropic 无 strict 标志但 tool_use+input_schema 同保证（单工具当 response shape）+每请求 313-346 token 工具 system prompt 开销；Gemini response_schema；Bedrock=CD for schema compliance**。
- **复杂 schema 报错修法：缩短属性/enum 名、扁平化嵌套数组、减少带约束属性数（min/max/enum）**。
- 提升层：工具（provider 能力对照）/ 可复用 Skill（strict 模板）。

### 4. Schema 设计规则防漂移（工具/工作流/可复用 Skill）
来源：dev-jeff_pdc / aiwiki / beerandcode / ayinedjimi / aiworkflowlab-nl
- **additionalProperties:false+全部 required（可选性用 union 含 null 表达）；类型显式（nullable=type:["string","null"]）；enum 限值防幻觉；扁平对象优于深嵌套（深嵌套伤准确率+涨 token）；具名参数（city_name 优于 q）；description 写"何时/如何用"（actionable：如"按 email 或 ID 查用户，未找到返 null"而非"管理用户"）**。
- 提升层：工具（schema 规范）/ 工作流（设计纪律）/ 可复用 Skill（schema 模板）。

### 5. 工具错误恢复表+agent loop 预算（工具/工作流/可复用 Skill）
来源：aiagents-codeguides / samuelfaj / dev-aiwave / aiworkflowlab-fc-recovery
- **错误类型分表：invalid_args→修正字段重试（计入签名预算）/ not_found→问用户或换 search 工具（通常不可重试）/ timeout→重试一次或降级（宿主退避软重试）/ rate_limited→等待并尊重 Retry-After/ auth→不空转停跑/ retry_budget_exhausted→停止工具震荡收尾或升级**。
- **恢复率>70%=可靠系统指标（模型在错误注入测试中 80% 二次尝试自修参数错误），恢复率与错误消息质量正相关**；**agent loop 最大迭代预算=max_iterations=生产头号失败模式（无限循环烧 token）的防御**。
- 提升层：工具（错误处理）/ 工作流（预算机制）/ 可复用 Skill（错误分表）。
