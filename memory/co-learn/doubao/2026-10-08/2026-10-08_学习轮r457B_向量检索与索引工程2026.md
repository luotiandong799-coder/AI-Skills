## 落地 5 独点（每点标注提升层）

### 1. ANN 索引三族选型与参数（工具/工作流/可复用 Skill）
来源：chistadata / milvus / nexpro / bigdataboutique / metricgate / aliyun
- **HNSW=图导航 O(log N)、95%+ recall 开箱、2-5× 内存、<10M 活跃写场景；IVF=分区线性代价、适合大 topK(>2000)、构建快但数据变化 recall 漂移（1M 向量 Recall@10 HNSW 0.95 vs IVF-FLAT 0.88）**。
- **PQ=30-50× 压缩 cache 友好但浪费相关子空间容量；OPQ=学习旋转重新分配方差、同压缩 +5-10pp recall；ScaNN=内积搜索最强；ef_search/nprobe 运行时调参**。
- 提升层：工具（索引选型）/ 工作流（参数调优）/ 可复用 Skill（选型决策模板）。

### 2. 量化分层：压缩码近似 + 原始向量精确重排（工具/工作流/可复用 Skill）
来源：system-design / shyankdev / arxiv-2608.12812
- **任何索引选择是 速度/召回/内存 三角上的一点；量化（PQ/SQ/ScaNN）省内存降 recall→典型模式=压缩码近似候选选择+原始向量精确重排**。
- **默认 IVF-PQ 可牺牲 30-70% recall（LanceDB 五数据集低于 0.90 阈值）；strict metadata 过滤与 ANN 结构冲突→pre-filter 先缩小候选再 ANN（后过滤会漏）**。
- 提升层：工具（量化）/ 工作流（分层重排）/ 可复用 Skill（量化-重排模板）。

### 3. 混合检索三阶段：双路召回 + RRF 融合 + 重排（工具/工作流/可复用 Skill）
来源：semeval-caraman / infoq-hybrid / markaicode / lobehub / trec-utokyo / arxiv-2606.28352
- **BM25+向量并行→RRF（Σ1/(k+rank)，k=60/10 无分数标定）→cross-encoder 重排→top-K；RRF 不需要异质检索器间分数标定**。
- **加权线性融合 alpha/CombSUM/CombMNZ/LTR 学习融合；SPLADE=学习稀疏表示自动术语扩展+重要性加权；效果=混合召回 +25-40%（Ollama）、三源融合 w_v=0.50 w_b=0.35、候选 50-100→融合 200→重排 10**。
- 提升层：工具（融合算法）/ 工作流（三阶段）/ 可复用 Skill（混合检索模板）。

### 4. chunk 策略实证与 late-chunking（工具/工作流/可复用 Skill）
来源：yuzec / promtable / ailearningguides
- **512 token Recall@10 83% Precision@3 71% vs 1024=79/64 vs 2048=72/55（512 为推荐起点）；200-500 token 生产甜点、overlap 10-20%、semantic chunking 自然边界、hierarchical 双粒度（句级+段级）**。
- **late-chunking=长上下文 embedder 整文嵌入后切片取 chunk 级向量——chunk"知道"周围文档上下文（适合法律/科学跨块上下文；代价=需长上下文嵌入模型+ingest 更多内存）**。
- 提升层：工具（chunk 策略）/ 工作流（实证调优）/ 可复用 Skill（分块决策模板）。

### 5. embedding 选型与检索质量指标（工具/工作流/可复用 Skill）
来源：web3aiblog / zalt / premai / angelxuanchang
- **MTEB 基准：text-embedding-3-large 通用+指令遵循、Voyage-3 常居榜首+代码金融变体、Cohere embed-v4 多语+query/document 不对称、BGE-M3 开源多语 dense+sparse+multi-vector 一体；两小时基准法=50-100 对 golden 集 Recall@5/@10**。
- **指标：MRR（首个相关文档位次）/NDCG/MAP/Recall@N；Context Precision（低=送噪音给 LLM）与 Context Recall（低=LLM 从不完整上下文答）分开看**。
- 提升层：工具（选型基准）/ 工作流（评估集）/ 可复用 Skill（指标模板）。
