## 落地 5 独点（每点标注提升层）

### 1. 混合检索双路并行 + RRF 融合（工具/工作流）
来源：startmatter / 1337skills / arpanet / web3ai
- **向量检索漏精确匹配**（产品名/错误码/数字"E-4407"/X12 标准）、**BM25 词法漏语义查询**——两路各有盲区。
- **双路并行**（向量+BM25/Postgres full-text/OpenSearch）→**RRF 融合**：reciprocal rank 求和（SIGIR 2009、k=60 标准常数）——**无需两系统分数可比、一行 score-free 公式**。
- **技术语料（产品码/错误码/API 名/法律引用/稀有实体）几乎免费 +10-20%**；pre-fusion re-ranking 在融合前用 reranker 校验每流 top-N（财报机器人删 18% 高分错误片段）。
- 提升层：工具（检索器）/ 工作流（召回设计）。

### 2. chunking=上游决策框定检索天花板（工具/工作流）
来源：ruchitsuthar / superml
- **chunking 是最高杠杆最被忽视的决策**——**上游决定框定下游一切可能检索到的内容**。
- **固定字符切分（1000 字符）破坏三连**：切断句子、分离标题与其引入内容、把单一连贯想法拆两半——naive 分块的典型失败。
- **替代=语义/结构分块**：按语义单元、标题层级、概念边界切（非固定长度）。
- 提升层：工具（分块器）/ 工作流（索引设计）。

### 3. 两阶段检索：bi-encoder 召回 + cross-encoder 重排（工具/工作流）
来源：superml / algorion / futureagi / ailearningguides
- **bi-encoder**：查询与文档分开编码、点积比较——快可搜百万，但查询文档永不碰面、损失信息；**cross-encoder**：联合输入打分、准但贵 10-100 倍——**外科式使用**。
- **两阶段**：retrieve top-50/100（bi-encoder+BM25+RRF）→ **rerank top-5/10（Cohere Rerank 3.5/BGE Reranker v2）**。
- **重排=基础 RAG 单点最高增益**；缓解 lost in the middle 问题。
- 提升层：工具（重排器）/ 工作流（检索管线）。

### 4. RAGAS 四指标分层诊断 + 先分阶段评估（工具/可复用 Skill）
来源：ragas-docs / dev-michael / anna-danilec / ai-tldr / dataaihub
- **四指标**：faithfulness（生成：答案断言被检索上下文支持的占比——**两 LLM pass：拆原子声明→逐条判支持/不支持**）/ answer relevance（生成：答案与问题语义相似）/ context precision（检索：相关 chunk 是否排更高）/ context recall（检索：ground truth 覆盖率）。
- **先分阶段评估**：检索评估隔离搜索失败、生成指标隔离 LLM/prompt 失败——**组合分数隐藏根因**；faithfulness 是关键生成指标（检索完美时幻觉仍可能）。
- RAGAS v0.4 迁移 collections 系统（FactualCorrectness/Faithfulness/ContextRelevance）。
- 提升层：工具（评估框架）/ 可复用 Skill（诊断模板）。

### 5. 查询变换五术 + agentic RAG 检索路由（工具/工作流）
来源：tencent-agentic / azure-agentic / infoq / arxiv-order / arxiv-ltrr
- **五术**：查询扩展（同义词/上下位词/相关实体扩大召回）/ 查询重写（改写为适合向量或关键词检索）/ **HyDE（模型生成假设答案、用其嵌入检索，绕过查询-文档措辞差异）** / 实体消歧 / 查询分解（复合查询拆子查询并行）。
- **agentic RAG**：检索是 agent 按需调用的工具——多步推理、动态查询规划（Azure 查询规划拆子查询并行+语义重排）、跨结构化 SQL 与文档异构源（modality gap）。
- **检索路由**：ORDER（查询路由到预建索引：语义簇学习 chunking+metadata 过滤+重排配置）/ LTRR（检索器路由建模为 learning-to-rank）；RAGRouter-Bench 首个 RAG 路由基准。
- 提升层：工具（查询路由）/ 工作流（检索策略）。
