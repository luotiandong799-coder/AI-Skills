## 落地 5 独点（每点标注提升层）

### 1. RAGAS 四指标与诊断分工（工具/工作流/可复用 Skill）
来源：ragas / csdn / anyscale / arxiv-2601.22025
- **Faithfulness=答案中被上下文 entail 的 claim 占比（直接测幻觉，最关键）；Answer Relevance=LLM 用答案反推问题看与原问题像不像（分低=答案跑偏→查检索上下文偏离意图或 prompt 发散空间）；Context Precision=检索段落中真正相关占比（检索模块打分）；Context Recall=所需信息被检索找到的占比**。
- **Context Recall 无需人工 reference context 标注可估（LLMContextRecall）；参考无关评估**。
- 提升层：工具（RAGAS）/ 工作流（诊断分工）/ 可复用 Skill（指标→问题映射）。

### 2. 检索指标选型：按"首个位置 vs 整列表"分场景（工具/工作流/可复用 Skill）
来源：futureagi / llmdevpro / slavadubrov / exploreagentic / mlflow
- **Precision@k=上下文窗口瓶颈时用（窄域 0.7+/广域 0.5+）；Recall@k=检索器调优主信号（k=20 目标 0.8+）；MRR=首相关位置主导（top-1/top-3 场景）；nDCG@k=分级相关+位置折扣检索金标准；MAP=在意整条排序；hit rate=单事实 QA 粗但直观**。
- **Context Recall/Precision 成 RAG 标准因直接关系 LLM 回答能力**。
- 提升层：工具（指标）/ 工作流（选型）/ 可复用 Skill（指标场景矩阵）。

### 3. Golden set 结构与标注纪律（工具/工作流/可复用 Skill）
来源：ahmetozel / ai-tldr / devto-mryadavgulshan / nitinkc
- **每条含 id/question/reference_answer/relevant_chunk_ids/answer_type/source；标注的是答案来源不是答案本身（labelling answer source not the answer）**。
- **从真实日志挖最近一月实际 query=ground truth 不是想象；必含 hard cases 多跳；基线 50-100 例足够起步**。
- 提升层：工具（schema）/ 工作流（标注纪律）/ 可复用 Skill（golden 模板）。

### 4. 合成 eval set 四门质量门（工具/工作流/可复用 Skill）
来源：futureagi-synthetic / mlflow / tensoria
- **Faithfulness 门=合成答案必须 grounded 在 cited context；Diversity 门=按 topic/length/complexity/intent 覆盖语料；Difficulty 门=易中难按比例；Human spot-check 门=至少审 5-10% 再锁集——过四门才与生产行为相关**。
- **生成用 constrained questions（keypoint+source passage 限制只能从该 passage 回答防外部知识）；eval set 构成=回归用例+15 边界+10 对抗+5 负例（正确答案是拒绝）**。
- 提升层：工具（四门）/ 工作流（eval 构成）/ 可复用 Skill（质量门模板）。

### 5. 单遍 Faithfulness 与多阶段管线取舍（工具/工作流/可复用 Skill）
来源：RAGVUE / deepchecks / nvidia
- **RAGVUE 单遍：一个 LLM call 把答案分解为最小原子 claim 并标 supported/partially/fully hallucinated，验证逻辑编码进单 prompt（省多 LLM 调用）**。
- **Deepchecks 多阶段：SLM 抽事实→检索相关段落→entailment 分类；各指标所需列明确：faithfulness 需 user_input/response/retrieved_contexts，context_entity_recall 需 retrieved_contexts/reference；Grounded in Context 无 reference 也可评 groundedness**。
- 提升层：工具（评测管线）/ 工作流（单遍 vs 多阶段）/ 可复用 Skill（所需列清单）。
