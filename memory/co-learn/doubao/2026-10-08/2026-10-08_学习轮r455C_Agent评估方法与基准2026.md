## 落地 5 独点（每点标注提升层）

### 1. 双层评分：process scoring 与 outcome scoring（工具/工作流/可复用 Skill）
来源：nvidia / anthropic / futureagi
- **step-level process scoring 定位链断点+end-to-end outcome scoring 验证最终环境状态；outcome=环境中最终状态（"已订好机票" transcript ≠ SQL 数据库有 reservation）**。
- **指标层级 benchmark→trial→task→turn→step；accuracy/verbosity/cost 成对报告（success rate with cost）；harness=跑 eval 基础设施 vs scaffold=agent 壳**。
- 提升层：工具（双层评分）/ 工作流（outcome 定义）/ 可复用 Skill（评估层级模板）。

### 2. 工具轨迹五维评估与双轨评测（工具/工作流/可复用 Skill）
来源：microsoft / google-adk / anthropic / arxiv-2606.22737
- **Tool Call Accuracy/Selection/Input Accuracy/Output Utilization/Success 五维；双轨=Tool trajectory 确定性 exact-match+Response quality LLM judge——两个都要（rubric 单独放行读着好但幻觉的答案、trajectory 单独看不出用户是否得到有用回复）**。
- **GroundEval 确定性评分替代 judge（answer correctness+evidence checks+trajectory validity+violation rates）**。
- 提升层：工具（五维）/ 工作流（双轨）/ 可复用 Skill（轨迹评估模板）。

### 3. Scaffold 效应主导：无脚手架全 0-8%（工具/工作流/可复用 Skill）
来源：clawsbench / arxiv-2605.27922
- **ClawsBench：无 skills+meta prompt 全部模型 0-8% TSR，有脚手架 39-63%（+39-63pp 提升远大于模型间 10pp 差异）；top 模型统计不可分**。
- **Harness-Bench=固定外部任务条件变化 harness 配置→scaffold 是评测轴不是规格字段**。
- 提升层：工具（脚手架）/ 工作流（配置对比）/ 可复用 Skill（TSR 基线模板）。

### 4. 轨迹诊断：控制决策分类与失败词汇表（工具/工作流/可复用 Skill）
来源：arxiv-2605.20530 / arxiv-2607.13705 / arxiv-2603.13594
- **AgentAtlas：outcome success 与控制决策质量/轨迹质量分离；六状态控制决策 Act/Ask/Refuse/Stop/Confirm/Recover；轨迹失败词汇表=主错误源+下游影响**。
- **AgentCompass=Benchmark/Harness/Environment 三独立组件+轨迹分析诊断 reward-hacking；企业环境=沙箱 164 表 512 工具 1150 专家任务 8 垂直域**。
- 提升层：工具（诊断词汇表）/ 工作流（三组件）/ 可复用 Skill（失败归因模板）。
