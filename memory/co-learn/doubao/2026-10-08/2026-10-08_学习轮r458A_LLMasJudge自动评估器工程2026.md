## 落地 5 独点（每点标注提升层）

### 1. judge 三大偏差机理与检测协议（工具/工作流/可复用 Skill）
来源：arxiv-2608.18091 / arxiv-2602.02219 / arxiv-2604.22891 / iclr-style-over-substance / csdn-position-drift
- **position bias=呈现属性非内容属性：50% first-slot rates、换序即翻判；rubric-based 评估隐式多选也有位置偏差（LLM 偏好 rubric 列表特定位置的分数选项→balanced permutation 均分缓解）；verbosity bias=长响应无关质量被偏爱（β=0.163）；self-preference/self-enhancement=LLM 系统性偏好自己输出；双向标签偏差=署名双向偏移且方向随维度变（Overall/Novelty/Excitement 升、Feasibility 降）**。
- **检测协议=同样本双评审（AB 再 BA）映射回原始候选：两次同向才算"位置一致"；跟位置走或不稳定都入不稳定集；ICLR：LLM 对判据隐式重权（不声明权重时会忽略某些标准）**。
- 提升层：工具（偏差检测）/ 工作流（评审协议）/ 可复用 Skill（偏差清单模板）。

### 2. judge 可靠性审计与压测（工具/工作流/可复用 Skill）
来源：arxiv-2603.05399-JRH / arxiv-2607.08535 / arxiv-2603.06594 / iovstudio-judge-bench
- **JRH 验证套件=label-flipped 响应测分级准确+格式/改写不变性+verbosity 敏感性+重复采样随机稳定性+序数刻度校准；换 judge 改变测量=评估者性能是一维排序会掩盖 能力/切片/偏差削减/协议设计 四因素**。
- **对抗安全评估中 judge 仅略优于随机硬币（coin-flip 论文）；一致性-偏差悖论=高重测信度可能掩盖严重位置偏差（50% first-slot rates）**。
- 提升层：工具（压测库）/ 工作流（审计流程）/ 可复用 Skill（审计模板）。

### 3. judge 校准与验收门槛（工具/工作流/可复用 Skill）
来源：futureagi-judge-2026 / zylos / galileo / howardism
- **验收协议=100-300 生产轨迹×2-3 人类标注→Cohen's kappa（>0.6 可接受 >0.8 强）→judge-to-human kappa<0.5 则 rubric 重写；exact-match 协议高估机会校正 κ 33-41pp（kappa deflation）需 chance-corrected；rho>0.8 才可用、<0.7 rubric 重设计、OOD 必测（域内 0.8 不保证泛化）**。
- **分层校准=per-class confidence 分层抽样防"聚合准确但单类崩溃"；分布偏斜（judge 只在子类一致）需分层看；每月再校准**。
- 提升层：工具（校准协议）/ 工作流（验收门槛）/ 可复用 Skill（校准模板）。

### 4. committee / 多 agent judge 与程序化 judge 蒸馏（工具/工作流/可复用 Skill）
来源：autorubric / acl-multi-agent-judge / PAJAMA / JudgePanel / auto-arena
- **多 judge 聚合=majority/weighted/unanimous/any 四模式；stakeholder in-group 辩论三阶段=个体评估→组内自由辩论→聚合终判（教师/临床等利益相关方各评各的再收敛）**。
- **PAJAMA=合成程序 judge+联合裁决+低置信度升级 LLM（match 13B LLM judge、零每样本 API 成本、透明可检视可编辑）；JudgePanel=紧凑 judge 多 agent panel 讨论（强评估器 panel 轨迹训练+AdaReward 自适应多奖励 RL）；Auto-Arena=考官出题→双候选多轮对战→委员会定胜负**。
- 提升层：工具（聚合方案）/ 工作流（辩论流程）/ 可复用 Skill（panel 模板）。

### 5. judge 提示工程与动态 rubric（工具/工作流/可复用 Skill）
来源：futureagi-guide / arxiv-2605.30568 / ai-zero-to-hero / arxiv-2603.00077
- **CoT 指令（"先按 rubric 逐步推理再给分"+专用推理字段）降分差 10-25%，推理轨迹成审计线索；显式声明判据权重防隐式重权；rubric 动态生成与精化（按实例自适应）**。
- **上线门槛=与人类标注一致 85%+ 才可用、<80% 调 prompt 或回退规则；评分<0.65 类标记人工复核（按风险容忍定 precision/recall 阈值）**。
- 提升层：工具（judge prompt）/ 工作流（动态 rubric）/ 可复用 Skill（judge 提示模板）。
