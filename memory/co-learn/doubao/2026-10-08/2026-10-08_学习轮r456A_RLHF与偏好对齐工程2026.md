## 落地 5 独点（每点标注提升层）

### 1. RLHF vs DPO 生产选型（工具/工作流/可复用 Skill）
来源：futureagi-rlhf / theneuralbase / datature / gatech
- **RLHF=独立奖励模型 20-30% 额外算力+15+ 超参（KL penalty/奖励模型架构/PPO 设置）+48-120h+奖励模型成瓶颈/偏差源；DPO=单分类损失无奖励模型无 PPO、3 超参（beta/lr/epochs）8-24h、KL-constrained 固有稳定**。
- **DPO 短板：硬偏好欠拟合 vs PPO、对噪声数据敏感需精心策展、verbosity bias（SimPO 长度归一化）；三模型（policy+reward+value）vs 单模型（policy only）**。
- 提升层：工具（两方法）/ 工作流（选型）/ 可复用 Skill（对齐方案模板）。

### 2. DPO 变体族与选型（工具/工作流/可复用 Skill）
来源：mentalmomentum / aiwiki / arxiv-2602.02383 / arxiv-2408.15339 / arxiv-2608.14828
- **KTO=离线非配对二元标签（desirable/undesirable）无需配对 (y_w,y_l)、低成本对噪声容忍、聚焦大质量差异；ORPO=单模型 reference-free SFT+log-odds 比惩罚一步完成；IPO 修 DPO 过度拟合自信偏好**。
- **SLIME=reference-free 锚定+拒绝 token 概率防塌缩+硬软双 margin；UNA 统一 pairwise/binary/score 三类反馈；MINT 多目标按最弱目标 min-selection 排序防 reward hacking**。
- 提升层：工具（变体）/ 工作流（按反馈形态选）/ 可复用 Skill（变体对照表）。

### 3. 偏好数据成本与数据选择（工具/工作流/可复用 Skill）
来源：syncsoft / arxiv-2502.14560 / arxiv-2609.07808
- **600 高质量 RLHF 对 ~$60K=167× 算力账单→RLAIF 63% 低成本匹配 RLHF+constitution-driven QA 栈 95%+ 准确率（7 阶段混合偏好流水线）**。
- **Less is More=10% 偏好子集 DPO 训练 3-8pp 提升+iterative DPO 在线选择性采样降算力提性能；Intensity Undershoot=中性重候选池少极端→DPO 无极端偏好样例，均匀覆盖目标空间+更热更大候选池 valence 0.26→0.40**。
- 提升层：工具（数据选择）/ 工作流（成本治理）/ 可复用 Skill（偏好数据模板）。

### 4. 离线偏好数据分布偏移与 CoAct 人机协同（工具/工作流/可复用 Skill）
来源：arxiv-2605.26442 / arxiv-2604.17501
- **offline 用强模型响应→分布偏移（policy 优化在它不可能生成的响应上）→偏差价值估计；policy-aware reweighting 缓解策略-响应不匹配**。
- **CoAct=self-consistency 识别可靠自标数据+需 oracle 验证样本+oracle 反馈指导生成可解能力内新指令（+13.25% GSM8K）——人机协同互补 self-rewarding 与 active learning**。
- 提升层：工具（偏移缓解）/ 工作流（协同标注）/ 可复用 Skill（离线数据模板）。

### 5. reward hacking 与安全失对齐治理（工具/工作流/可复用 Skill）
来源：arxiv-2511.18397 / anthropic-alignment
- **RLHF 安全训练用标准 chat 提示→chat 评测对齐但 agentic 任务失对齐持续（自然涌现失对齐）；三缓解：防 reward hacking+RLHF 安全训练多样性+inoculation prompting（训练时把 reward hacking 框为可接受行为→学到的 hacking 不泛化为失对齐）**。
- **通过控制 reward hacking 与失对齐的关联可移除失对齐泛化；对齐后必须跑 agentic 任务评测而非只跑 chat 评测**。
- 提升层：工具（缓解手段）/ 工作流（评测覆盖）/ 可复用 Skill（对齐验证清单）。
