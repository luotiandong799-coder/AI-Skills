## 落地 5 独点（每点标注提升层）

### 1. DSPy 程序化提示工程与优化器族（工具/工作流/可复用 Skill）
来源：dspy.ai / aws-prescriptive / aiwiki-dspy / effloow / sungeuns
- **signature+module 声明式定义任务，optimizer 自动搜最优指令+示例+权重（编译器隐喻）；BootstrapFewShot：GPT-3.5 复杂推理超标准 few-shot 25%+、llama2-13b-chat 65%+**。
- **优化器选型=LabeledFewShot（随机 k 示例）/BootstrapFewShot（teacher 生成+按 metric 验证）/BootstrapFewShotWithRandomSearch/KNNFewShot（kNN 选最相关示例）/MIPROv2（贝叶斯优化联合调指令+示例，生产首选）**。
- 提升层：工具（框架）/ 工作流（编译-优化流程）/ 可复用 Skill（优化器选型表）。

### 2. OPRO 与进化式优化器（模型/工具/可复用 Skill）
来源：ai-tldr / 51cto / futureagi-agent / futureagi-glossary
- **OPRO=LLM 当优化器："历史提示词+得分"组 meta-prompt 迭代生成更优提示词——目标函数不可导+搜索空间是自然语言，正好是 LLM 擅长处；ProTeGi=文本梯度：对失败例生成 num_gradients 条批判→每条生成 prompts_per_gradient 个改进变体→beam 搜索（100-500 标注失败 3-6 轮 5-15 点提升、提示词人类可读）**。
- **GEPA=进化+Pareto 选择（保多指标权衡前沿的提示词）；PromptWizard=任务感知反馈驱动自进化（批判-综合、探索-利用平衡、负样本识别增强示例多样性，45 任务领先）**。
- 提升层：模型（LLM 作优化器）/ 工具（进化搜索）/ 可复用 Skill（meta-prompt 模板）。

### 3. 梯度式提示优化（工具/工作流/可复用 Skill）
来源：arxiv-2606.29639-GradPO / korea-promptwizard
- **两阶段=先推理式优化器做大改→GradPO 用 loss/梯度信号识别高影响 prompt span 做局部精修（本地编辑）；token replacement=argmax(-∂L/∂ε_i)——对每个 token 位置用梯度最大方向替换**。
- **TextGrad 系=模型产生文本"梯度"（批判文本）而非数值梯度；梯度式优化适合把离散自然语言提示当可微参数逼近最优**。
- 提升层：工具（梯度优化）/ 工作流（两阶段流水）/ 可复用 Skill（GradPO 流程模板）。

### 4. 生产化：CI 门槛与测试集构建（工作流/工具/可复用 Skill）
来源：futureagi-at-scale / futureagi-methodology / microsoft-learn / n8n
- **冻结评估集三性质=代表性/统计有效（100-500 例）/随生产漂移更新；对抗生成=50 代表例→强模型合成扰动（改写/typo/敌意输入/畸形 JSON）补边界失败模式**。
- **CI gate=PR 重跑 eval 套件+回归合并阈值；MS 门槛=核心质量指标退化≤2% 且至少一指标升、或全部在 1% 内；安全指标 100% 通过（单例失败即阻断部署）；每周或每次部署跑回归；prompt 优化 ship 在 CI 之后**。
- 提升层：工作流（CI gate）/ 工具（回归套件）/ 可复用 Skill（门槛模板）。

### 5. 评估驱动迭代纪律（工作流/可复用 Skill）
来源：bestprompt / theneuralbase / prompteval / latitude / explainx
- **最小提示→5-10 次运行（LLM 随机，1 次≠信号）→按失败模式分类（格式/幻觉/漏约束）→每次只改一个变量→版本化存测试集+评分 rubric；失败溯源=提示问题 vs 模型能力问题（prompt 问题改 prompt，能力问题换模型）**。
- **40 例自动化评估+人工分相关性>0.8 才可信；停止条件=连续两轮改善<5 点→该换结构而非改内容；每周 A/B 回归（现有 prompt vs 改进版全 eval 集）**。
- 提升层：工作流（迭代协议）/ 可复用 Skill（迭代清单）。
