## 落地 5 独点（每点标注提升层）

### 1. Handoff 协议六字段 + mesh 直连（工具/可复用 Skill）
来源：loooop-agent-orchestration / mslearn-handoff
- **Handoff 转移控制，携带**：**target agent（哪个专家）**/**context（累积会话状态或外部存储指针）**/**instructions（目标聚焦什么）**/**metadata（路由原因、优先级、约束）**/**auth（凭证类型 user-delegated 或 service-account）**/**model_hint（可选模型偏好）**。
- **mesh 拓扑**：agent 直连无编排者，按上下文/请求动态转移——适合客服/专家系统动态委派。
- 提升层：工具（协议字段）/ 可复用 Skill（handoff 模板）。

### 2. A2A+MCP 协作栈分工 + 授权链单调收窄（工具/可复用 Skill）
来源：sudoall-a2a-mcp / ietf-zahed / ietf-scrm
- **A2A 标准化 agent↔agent 的发现与任务交换；MCP 标准化 agent↔工具调用——两者组合覆盖完整协作栈**；无共享协议时协调者必须知道每个专家怎么工作/接受什么输入/怎么解析输出。
- **授权链单调收窄**：接收 agent 只被授权到委托者显式许可范围；多跳链每跳验证权限来自原始授权人且**未被扩大**（delegate 不能获得超出 delegator 的权力）；委托链表示紧凑+密码可验证；**delegation receipts=用户私钥作唯一签名权威，移除第三方信任**。
- 提升层：工具（协议栈）/ 可复用 Skill（委托模板）。

### 3. Agent 注册-发现机制（工具/工作流）
来源：ietf-zl / mslearn-a2a-ecosystem / agent-mesh-SPEC / arxiv-SwarmHarness
- **启动时注册能力**（role/skills/context_window）→capability request 按匹配过滤返回目标 agent；**ARS 动态 Agent Database+跨 ARS 同步**。
- **agentCard/v0.3 认证端点+中心发现注册表**（启动注册、运行时查询，消除硬编码端点依赖）；**mDNS/DNS seeds/explicit peer lists 三引导+TTL 广告+gossip 最终一致**（SwarmHarness Kademlia DHT）。
- **匹配算法**：任务描述 tokenize→对注册能力计 keyword+role overlap→top-K。
- 提升层：工具（注册表）/ 工作流（发现链路）。

### 4. 凝聚感知切分 + Fan-Out 合成 + Best-of-N 递归委托（工作流/可复用 Skill）
来源：agentpatterns-multi-agent
- **Cohesion-Aware Task Partitioning**：按依赖凝聚切分再 fan-out——**并行只在跨分区依赖稀疏、上下文转移成本<关键路径节省的计算时才划算**。
- **Fan-Out Synthesis**：spawn N 独立 agent 同题并行→synthesis agent 合并各尝试最强元素；**Recursive Best-of-N**：每递归节点跑 K 并行候选 worker。
- 提升层：工作流（切分判据）/ 可复用 Skill（合成模板）。

### 5. 市场/拍卖分配 + Router 成本特征 + 认知负载均衡（工作流/工具）
来源：omnithium-market / anhtu-6-patterns / aicoo-openclaw-router
- **市场/拍卖**：coordinator 宣布任务→agent 以成本估算/能力分投标→奖给最优标（动态优化资源分配）；**风险=条件变化时反复投标 thrashing**。
- **Router 模式最省**：每请求只一个 agent 处理、只付分类成本——**Router 可用 Haiku 级快模型分类**。
- **认知负载均衡**：按 capability vectors/当前认知负载/context affinity 映射任务（L7 负载均衡器）；**认知碎片化=多 agent 隐藏成本**。
- 提升层：工作流（分配机制）/ 工具（路由层）。
