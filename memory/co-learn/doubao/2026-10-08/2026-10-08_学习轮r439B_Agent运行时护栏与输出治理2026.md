## 落地 5 独点（每点标注提升层）

### 1. guardrail 六层拓扑（工作流/可复用 Skill）
来源：growthengineer / taskade / futureagi / max-gherman
- **六层**：①输入校验（PII/注入/长度上限在模型看到前）②system prompt 约束（显式拒答规则+行为边界）③工具 allow-list（SDK 强制硬名单）④输出校验（Pydantic/Guardrails AI schema 逐响应检查）⑤动作确认钩子（破坏性操作前 HITL 或断言门）⑥成本+迭代上限。
- **结构护栏=模型上下文外运行的确定性代码**（regex 剥离工具响应注入模式跑在 Python 里、不问 LLM）——**模型看到的内容无法影响执行机制**；guardrail 是模型绕不过的运行时检查（非 system prompt 里的建议）。
- 提升层：工作流（护栏设计）/ 可复用 Skill（六层清单）。

### 2. guardrail 推入 AI gateway 层：统一策略+可证明审计（工具/工作流）
来源：getmaxim-impl / dev-tamizuddin-stack
- **应用内护栏→AI gateway 层**：每模型调用跨服务继承同策略/同强制/同审计轨迹——**可证明"此请求因这条策略于此时间被拦"**（跨服务散日志做不到）。
- **roll your own 抽象=一个项目本身**；gateway 输出规则抓幻觉/grounding 缺失；NeMo Guardrails 与自定义 LLM Ops 中间件实时检查 token 流/解析函数调用、违规拦截返回安全默认响应。
- 提升层：工具（gateway 架构）/ 工作流（统一治理）。

### 3. 结构化输出 constrained decoding + schema 语义不足需 domain verifier（工具/工作流）
来源：aws-bedrock / claude-structured / microsoft-foundry / arxiv-2607.18261 / openwop
- **服务端 constrained decoding**（Bedrock 结构化输出/Claude JSON outputs+strict tool use/Triton）——**输出不可能畸形**，零校验数据管道、可靠 agentic 函数调用。
- **但 schema 有效≠语义可靠**：JSON Schema 保证 array+integer，不能保证"过敏冲突被拒/不加洋葱被拆成两个对象/菠萝未默默发明"——**需 domain verifier 再放行，勿让 schema 有效输出直接执行交易**。
- **互操作子集**：递归 $ref 只有 OpenAI/Gemini 支持、Anthropic NO——**偏好扁平结构**；additionalProperties:false 常见。
- 提升层：工具（输出强制）/ 工作流（验证链）。

### 4. 运行时限流四类 guard + 三层配置 + 四档预算数值（工具/工作流）
来源：rapidclaw / misar / truefoundry / dev-mechapp / simpletechguides
- **四类**：token-based（防 context blowup）/ request-based（防重试循环）/ circuit breaker（重复相同调用触发）/ budget caps（美元阈值硬停）。
- **三层配置**：agent/service/infra——任何单点失败不能烧掉预算。
- **数值档**：per-task token 100K-500K（终止+发 checkpoint）/ per-task dollar $0.50-5 interactive、$10-50 batch / per-user daily $1-20（软拦+升级路径）/ per-feature monthly（降级便宜模型）；**读 x-ratelimit-remaining-tokens 响应头提前暂停**。
- 提升层：工具（限流器）/ 工作流（预算档位）。

### 5. fallback chain 降级 + 决策速率限制（工具/工作流）
来源：truefoundry / dev-mechapp / dreaming-press / aitoolsguidebook
- **限流≠硬失败**：声明式 per-route fallback chain（主模型→降级模型→降级输出；token bucket 节流/circuit breaker 打开/供应商故障时给退化结果而非全拒）。
- **决策速率限制**（固定延迟 N ms 或决策 token bucket）**≠ API 调用限流**：agent 每秒多决策、每个决策可触发调用——只限调用率会漏（$50K runaway 教训）。
- **循环硬上限=框架内置**：LangGraph recursion_limit 默认 25、超限 GraphRecursionError——一行把"无限花费"变"抛异常"。
- 提升层：工具（降级链）/ 工作流（限流治理）。
