## 落地 5 独点（每点标注提升层）

### 1. 意图分类三方法误差带与选型（工具/工作流/可复用 Skill）
来源：besthub / devlifted / respan
- **关键词规则 15-40% 误差（意图与词汇固定时可用）；embedding 相似度 8-15%（意图簇清晰时）；LLM 分类 2-5%（处理模糊/复合意图、强模型）**。
- **prompt 结构=intents 枚举+每意图定义+few-shot 示例映射；关键词匹配处理不了上下文（"SQL 注入漏洞"会误路由到 database）**。
- 提升层：工具（三方法）/ 工作流（选型）/ 可复用 Skill（意图 prompt 模板）。

### 2. 三层路由架构 L1 正则/L2 向量/L3 LLM-FC（工具/工作流/可复用 Skill）
来源：juejin / ucalyptus
- **L1 关键词/正则 <1ms 承接 60-80% 请求；L2 向量语义 30-100ms 承接 15-25%；L3 大模型 FC 1-2s 承接 5-15%（一次调用完成意图+槽位+执行）**。
- **两阶段混合=regex 先 <1ms、LLM fallback 仅启发失败；新架构移除小模型层由大模型 FC 接管长尾**。
- 提升层：工具（三层）/ 工作流（分级承接）/ 可复用 Skill（路由分层模板）。

### 3. 置信度门槛与误路由 fallback（工具/工作流/可复用 Skill）
来源：theneuralbase / devlifted / tribunal-kit / aitoolsguidebook
- **低于置信度门槛（0.7）→澄清问题/路由 generalist/升级人工/安全默认路径；fallback 由误路由成本决定；always store and log reasoning+confidence 不只存 intent string**。
- **多域请求路由到 orchestrator；误路由治理=语义分类替代 keyword 命中（"sql" 应到 security 非 database）**。
- 提升层：工具（门槛）/ 工作流（fallback）/ 可复用 Skill（误路由修复模板）。

### 4. 分层工具选择与语义工具路由（工具/工作流/可复用 Skill）
来源：niteagent / zylos / arxiv-2603.20313 / sohu
- **两阶段 AutoTool：Phase1 小模型/embedding 从数百工具选 10-20；Phase2 主 agent 只见相关工具；工具注册时 embed description 进向量索引、每轮 embed 任务 top-K cosine（典型 3-5 而非 50-100 全目录）**。
- **工具注册表带 cost/latency SLO/idempotency 元数据；BM25 匹配名字/字段名、embedding 匹配语义可混合**。
- 提升层：工具（语义检索）/ 工作流（两阶段）/ 可复用 Skill（工具注册 schema）。

### 5. 意图分类评估与漂移监控（工具/工作流/可复用 Skill）
来源：futureagi / arxiv-2506.00210 / gemilab / arxiv-2603.01486
- **existing-intent drift：已知类 precision/recall 周环比 >2 点=输入分布漂移→刷新 few-shot 池重基线；new-intent emergence：OOD 桶周聚类（HDBSCAN）稳定簇超体积阈值两周=新意图候选**。
- **REIC RAG 增强意图分类动态并入知识无需重训；意图分类与路由选择分离（cheap model 分类+自有规则定路由）显著减少误路由**。
- 提升层：工具（漂移监控）/ 工作流（评估管线）/ 可复用 Skill（意图评估模板）。
