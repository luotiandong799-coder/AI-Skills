## 四、提炼核心方法与关键事实

1. **Schema-first**：schema 承载形状、消息承载行为；形状放工具参数/结构化通道，自然语言只写 task+context+behavior。
2. **输出契约三件套**：精确 keys+闭合枚举带 fallback+空输入已定义响应；"场景不是模型错而是模型在错误位置对了"。
3. **加固链分层**：prompt 给 schema（第一层）→ parser 强制（Structured Output Parser 不匹配重试）→ Code 校验（类型/enum/长度/业务规则）→ IF 分流（auto/repair/clarify/human/deny）；解码层约束（原生 structured/format:json/logits）最可靠。
4. **格式防泄漏**：负向指令（"Return ONLY valid JSON, no fences"）+temperature 0-0.2；正导向指令优于负向+XML 格式指示符。
5. **提取全配方**：schema+全量提取+缺省补 null+去重保变体+永不抛错；enum 分类字段；每属性 description；answer/evidence 分离+unsupported_claims+confidence。
6. **Schema 书写纪律**：显式类型（模型默认字符串）、null 永不省略、最小有用结构、additionalProperties:false、描述性 key。
7. **提示生命周期**：deploy 版本化+环境覆盖；运行时从 catalog 注入组件 reference；SKILL.md 固化知识免临时提示；指令与数据分通道（System role 硬编码）。
8. **Few-shot 工程**：3-5 示例封顶、难度递增、格式一致；policy rubric+annotated examples；negative examples 防误分类；示例 XML 结构。
