## 四、提炼核心方法与关键事实

1. **Prompt 三要素**：instructions + inputs + output format；发布前三查 Repeatable/Grounded/Structured。
2. **system prompt 四要素**：Role（含 not 面）/Task scope（forbidden 与 capabilities 同等重要）/Output format/Context；五段模板 Identity/Capabilities/Decision Rules/Behavior/Constraints。
3. **Goldilocks 500-3000 token 核心**：四层结构，太模糊或太详细都不行；稳定指令进 system prompt 释放 user tokens。
4. **工具描述三规则**：动词开头/When-not-to-use 负面例子减半错误率/诚实失败模式带恢复指令——工具描述是 system prompt 隐性部分。
5. **agentic prompt 五组件**：目标+工具集+成功标准+显式决策策略（何时问 vs 何时行动）——改变模型规划预算分配。
6. **Chaining 优于单 mega-prompt**：每步独立 call+schema+错误处理，调试可定位到步。
7. **Claude 5 代瘦身新规则**：80% system prompt 删除无 measurable loss；Progressive Disclosure Level 1 起步按需加复杂度。
8. **Error Recovery**：fallback+置信度分数+替代解释+缺失信息标注。
9. **XML tags 分隔**：<instructions>/<context>/<input> 减少误解；### 分隔符+请求放开头。
10. **JSON contract**：schema 进 prompt+精简带描述+keys 跨版本稳定+模型原生结构化输出最可靠。
11. **Prompt 版本化**：Tables（version/owners/rollout）+回归比较+approvals+失败阈值自动回滚；per-generation 可观测。
12. **trusted/untrusted 双车道**：system 进指令道与 system prompt 同等地位，外部数据进对话道。
