## 独点（10）

1. **任务型对话四层架构**（来源：neuralbase task-oriented dialogue + thoughtworks）——理解（用户说了什么意图）/状态跟踪（现在知道什么、还缺什么）/策略（下一步：要槽/确认/执行）/响应生成；传统规则系统硬编码策略（"缺 party_size 就问"）。判据：**四层各自独立，策略层决定"问/确认/执行"不是模型随意发挥**。提升层：工作流。
2. **槽位填充四任务 + 一次一问**（来源：neuralbase slot filling patterns + maxbot + gcp slot-filling + microsoft）——检测缺失槽/合理顺序提问/校验接收数据/畸形输入优雅恢复；progressive disclosure=一次只问一个问题、不预览未来步骤；节点级 skip-question 可关（始终需确认的槽强制提问）。判据：**收集信息按槽逐步、一次一问、数据校验内置**。提升层：工作流。
3. **槽位-意图矫正**（来源：thoughtworks）——用户槽位与当前识别意图不匹配时，Tracker 按槽位信息矫正意图：大部分槽值属意图 B 则真实意图大概率是 B；设阈值触发矫正（而非无视冲突）。判据：**槽位是意图的证据，冲突时矫正而非无视**。提升层：工作流。
4. **澄清三触发 + 约束响应空间**（来源：how2 + intelligentcx + callsphere + ai-agentsplus）——请求可匹配 2+ 工具/动作、关键参数缺失、置信度低=触发澄清；澄清用带脚手架问题约束响应空间（给 2-3 选项）而非开放式；smart defaults 减少澄清次数。判据：**澄清是设计行为不是兜底，先约束选项再问**。提升层：工作流。
5. **修复重落地（re-grounding）三原则**（来源：dilr + polyai + asoasis）——重述已知+只点名缺失/不确定部分+问更窄问题（不用"抱歉没听清"丢掉全部）；correct a value 只更新该值不重收集；pivot 工作流切换干净；undo 优先（不可撤销动作=确认）。判据：**修复损失最小化：保留已知、只补缺失**。提升层：工作流。
6. **Fallback 分流：分类处理不笼统兜底**（来源：arxiv 2608.30738 + chatbotscape + intelligentcx + rework）——区分 out_of_scope（明确请求但无匹配技能=限制性解释+重定向）vs 欠specified/误转写（=重路由）；re-prompt 限 2 次；两失败后升级人类（不说 bot 失败而说找人帮你）；bucket5 越界流量=处理不修复（scope-aware 回复转人工）。判据：**fallback 先分类再处置，重试有上限、越界转路由**。提升层：工作流。
7. **LLM-native 意图需显式确认门**（来源：neuralbase llm-native intent understanding）——金融等监管域高风险意图强制显式确认（"你请求退款，正确吗？回 YES 继续"）或人工审查，不论系统置信度——不假设 LLM 推理可解释性够当审计轨迹。判据：**高风险意图走显式确认门，信任模型但审计靠交互**。提升层：工作流。
8. **风险分级确认 + 可见动作回执**（来源：ucafs + conversa + polyai）——模糊/不可逆/高影响=确认；低风险=轻量反馈（acknowledgment before action："Got it—I'll update your delivery address to 123 Main Street. Should I apply?"）；visible action receipt=一键/一句取消或修改，不重新输入原命令。判据：**确认强度与风险匹配，动作后可一键回滚**。提升层：工作流。
9. **Scope Validator 三路分流**（来源：neuralbase off-topic redirection）——意图先过 scope validator：in-scope 交主 LLM（system prompt 强制领域边界）/out-of-scope 模板拒绝+记录（数据供扩界决策）/ambiguous（置信<75%）升级人类带上下文。判据：**边界判定前置为独立组件，越界=模板拒绝+留痕，低置信=转人**。提升层：工具。
10. **话题切换暂存/恢复 + 意图复用**（来源：csdn 多轮对话 + asoasis + google dialogflow）——用户频繁切题时识别切换、正确暂存或结束当前任务状态、切回时恢复上下文；confirmation.yes 等通用意图定义一次多页复用避免重复。判据：**切题=状态挂起非丢弃，恢复=回到原上下文**。提升层：工作流。
