## 独点（10）

1. **记忆分层+每层专属存储**（来源：memoryjs + zylos + niteagent）——工作记忆（RAM/Redis，TTL 24h，token 预算，快速优先）/会话记忆（线程级 DB）/情节记忆（时间戳事件日志，时序/向量 DB）/语义记忆（蒸馏事实+偏好，向量 HNSW）/知识图谱（Neo4j/Graphiti）；生产故障点=情节可靠召回 ~50 轮后下降、语义事实陈旧无更新机制、程序记忆硬编码新工具要改代码。判据：**每层记忆配专属存储；各层故障模式不同要单独治理**。提升层：工具。
2. **记忆三型+毕业过渡是硬问题**（来源：arxiv 2603.07670 + mem0 + zenodo）——episodic/semantic/procedural（Voyager 技能库=程序记忆标杆：可运行 JS+自然语言索引+动态组合）；"episodic 何时毕业为 semantic"=过渡策略硬问题；演化=Consolidation（合并抽象）/Updating（改条目）/Forgetting（移除衰减）；检索=精确/语义/混合+Query Construction（从当前上下文构造查询）。判据：**记忆=三型+显式过渡策略+演化三操作+检索四要素**。提升层：工作流。
3. **记忆投毒=跨会话持久威胁**（来源：arxiv 2606.12703 SMSR + securetom + beyondscale MemGhost）——与 prompt injection 不同——注入重置于会话结束，投毒条目持续影响每个后续会话直到显式清除；"Poison Once, Exploit Forever"；MemGhost 单封钓鱼邮件 87.5% 成功率植入企业 agent 持久后门；MSMP（多会话记忆投毒）无正式安全证书防御。判据：**记忆层是持久注入面，防御按持久威胁设计，不止按注入设计**。提升层：工具。
4. **MemMorph：记忆投毒劫持工具选择**（来源：ICML 2026 + codex + llm-hacking）——只写 3 条流畅可信记忆进长期记忆→10 个模型骨干上最高 85.9% 劫持工具选择；不碰工具元数据→标准审计不可见；隶属 OWASP ASI06 Memory & Context Poisoning。判据：**投毒通过"检索后信任的积累经验"生效，审计工具元数据查不出——记忆写入侧要独立防线**。提升层：工具。
5. **A-MemGuard 共识检测+双记忆隔离**（来源：dev.to + arxiv 2604.16548）——投毒记忆单独看貌似合法，但推理与合法记忆冲突——**共识揭示离群**；A-MemGuard 三攻击场景降成功率超 95%（直接注入 100%→2.13%）；双记忆隔离=注入内容与特权记忆物理分离。判据：**检索结果过共识/交叉验证，离群记忆标可疑；不可信内容写入隔离记忆区**。提升层：工具。
6. **遗忘与回滚=安全生命周期必需**（来源：arxiv 2604.16548 + memoria + agent-memory whitepaper）——Forget & Rollback 决定攻击后能否恢复——无快照/版本 diff/取证追溯则只有尽力预防无可靠恢复路径；git-for-memory=快照+回滚命令（确定性、完整）；代理记忆采用"存档不删除"（working→active→archive-candidate→archived，可 grep 索引），确定性衰减用会话文件计数而非浮点分数。判据：**记忆=快照+版本 diff+回滚；衰减确定性可复算，删除前先归档**。提升层：工具。
7. **记忆演化治理：不可变账本+漂移约束**（来源：arxiv 2603.11768 SSGM + agent-memory deck）——Reconciliation（Drift Bounding）=周期性把可变记忆对账到不可变账本（防累计漂移发散）；superseded 标记=事实被推翻是"变更"不是"弃用"；永不衰减事实定期人验（never-decay ≠ never-checked）；矛盾检查=写时扫描、永不挑赢家；provenance=每条事实追溯源会话。判据：**记忆=可变层+不可变账本+周期性对账；写时矛盾检查不裁决；每条带 provenance**。提升层：工作流。
8. **写入门控：复合显著性阈值+归档而非删除**（来源：arxiv 2603.15994 + memoria RFC）——写时门控用复合显著性 S(K)≥τ 进活跃存储（带完整 provenance），<τ 进归档而非删除——保留晋升可能（政策更新后低价值对象可晋升）；预写筛选层=确定性启发式（拒绝空/样板/问候-only 摘要、抑制重复低价值载荷、病理长摘要上限）+skip 原因入遥测。判据：**写入=显著性门控；低价值进归档不进垃圾桶；拒绝原因入日志**。提升层：工作流。
9. **记忆检索=控制决策（多信号+投毒护栏）**（来源：mem0 + agentpatterns + futureagi）——Mem0 单遍分层提取+多信号检索 91.6% 准确、token 降 4x、延迟降 91%（优于全上下文基线 18.7pp）；memory-as-governance=检索层 abstention 控制注入、pre-action gate 在 harness 改文件/重试前查 append-only 事件日志（匹配已记录失败/脆弱目标→结构化警告）；质量指标=记忆陈旧率/写冲突率/溢出率。判据：**检索=多信号+护栏；动作前查失败日志；量化指标管记忆健康**。提升层：工作流。
10. **操作符预算决策：Retain 默认，consolidate 只在正增益**（来源：arxiv 2607.17545 + 2608.22215 + 2606.26806）——预算受限时问"最佳整合操作符是否优于保留原条目"——零增益倾向保留（tie→retention），正增益才选操作符；写快路由+慢整合（fast write routing + slow consolidation）；RAG 赢浅层事实、参数化整合赢目标持久（post-unload 恢复）——按事实类型分。判据：**整合前问增益：零增益保留；浅事实走检索、目标行为走参数化**。提升层：工作流。
