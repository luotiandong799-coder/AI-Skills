## 10 独点（含提升层）
1. **SKILL.md 编写核心纪律**——不要写显然的东西（agent 已会）；gotchas 节=最高信号内容，从 agent 用技能常见失败点积累并随时间更新；frontmatter name（≤64 字符/小写字母数字连字符/禁保留词 anthropic claude）+description（非空/≤1024/禁 XML）；numbered steps 比散文段落可靠；显式 failure modes（"无测试就 flag 而非写一个"）。（提升层：可复用 Skill）
2. **触发式 description 与渐进披露**——description 是模型第一眼看到的：以"何时用"开头非"做什么"；bad="planning, task creation..." vs good="End-to-end customer onboarding workflow for PayFlow...Use when user says..."明确价值主张；会话启动只加载 name/description，任务匹配 description 才加载全内容——省上下文的关键机制。（提升层：可复用 Skill）
3. **SKILL.md=agents 的 package.json**——2025-10 Anthropic 引入→11 OpenAI Codex 采纳→12 开放标准化（Vercel skills.sh）；同目录被 Claude Code/Codex/Cursor/Gemini CLI 等多平台原样消费；标准化深化=versioning/dependency declarations/capability scoping——从"markdown 里的指令"变真 package format。（提升层：可复用 Skill）
4. **skill 依赖与锁定文件**——SKILL.md 可声明对其他技能依赖；gh skill install 自动解析递归安装依赖生成 .skill-lock.json（来源/版本/哈希/签名）；gh skill sync 按 lock 精确恢复；GitHub/skills.sh mutable refs 解析成 full commit SHA；npm ranges/dist-tags 解析成 exact version+tarball+SRI；frozen install 物化 locked source 不重解析。（提升层：工具）
5. **skill 打包治理与质检**——Skilldex 质检表=description words（specificity 阈值）/SKILL.md lines（token 预算约束）/仅允许 scripts/references/assets 子目录/引用资源存在（无 broken relative links）/资源在正确子目录；missing frontmatter=唯一致命条件；provenance=每文件 version 整数+bundle semver+change_summary 必填（描述改了什么非只"改了"）+previous_version 链。（提升层：工具）
6. **skill 评测分层用例与风险分级**——每 eval 建分层用例=routing/deterministic contract/trajectory/final state/semantic quality；P1 business critical=精确率召回≥90%+无超声明余量回归+分歧人工审 / P2 low risk=≥85% advisory；SKILL-TESTER=执行候选技能报复合安全分+三级标签（safe/warning/unsafe）；SKILLGUARDBENCH=技能当多文件包测。（提升层：可复用 Skill）
7. **skill 安全评测基准与 Skill Lift**——腾讯 SkillTrustBench=从主流市场 62,652 skills 提炼 5,520 用例九类安全威胁（技能安全可信度+外部扫描检测效能双重评测）；NVIDIA SkillEvaluator=静态检查+带/不带 skill 的 live runs 测 Skill Lift——平均 Correctness 41/Effectiveness 39 分但每产品 +2~+46 差异（产品域决定 lift）；quality metrics can miss=调错 skill 或调对但跳过/部分跟指令两种失败都流畅。（提升层：可复用 Skill）
8. **skill 供应链信任分级**——SkillSpector provenance 1-5 分=未签名未知发行方→开源可识别无签名→发行方签名无第三方验证→可信发行方签名（NVIDIA/Anthropic/OpenAI/hyperscaler）+公开目录→OpenSSF Model Signing 加密签名可对根证书验证+每日目录同步；marketplace 信任=ratings+security scans+community verification；curated skills 提 agent pass rates 平均 16.2 百分点（SkillsBench 47,150 skills 平均质量 6.2/12——catalog size≠quality）。（提升层：工作流）
9. **skills vs hooks vs 指令文件分工**——Hook=动作必须每次同样发生（lint/拦危险命令/日志）确定性零上下文成本；Skill=agent 决定如何应用或知识性内容按需加载（deploy checklist/style guide/debugging playbook）；AGENTS.md=多 AI IDE 团队单一规范指令文件；Projects/CLAUDE.md=静态参考总是加载；错误=把三者当等价"指令文件"。（提升层：工作流）
10. **skills 组合基元与放行自动化**——compose primitives 别 bundle workflows：一个 skill 一个能力，多个小 skill 运行时组合，一个大 skill 僵硬；subagent 与 skill 同源=frontmatter name/description/tool list 启动加载但 body 不自动调用——显式调用；skill 上线用 evidence bundle+rollout-gate fail-closed 决策库（consume Evidence Bundle+rollout policy 决定 allow/block，GitHub Action 消费）。（提升层：可复用 Skill）
