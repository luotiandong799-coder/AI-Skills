## 10 独点（含提升层）
1. **信任 JSON 的四层栈**——schema design / provider enforcement / constrained decoding / validation loops 全要；"just ask for JSON" 生产 8-15% 解析失败率（尾逗号/缺引号/解释段包 payload）；naive prompt 式已死，JSON Mode 属 legacy。（提升层：工具）
2. **constrained decoding 机制**——schema 编译成 FSM/CFG（GBNF），每解码步 mask 掉会让输出违反 schema 的 token（"hello" 当需 true/false 时采样前被 zero）；strict mode=模型 token 采样被约束；本地模型用 Outlines；AWS Bedrock=编译 grammar 缓存 24h；保证是"每次"不是"通常"。（提升层：工具）
3. **schema 设计五规则**——enum 胜 free-text（无约束则 LLM 生成 high/High/HIGH 变体）；参数必带 description 与示例（否则模型猜语义）；required 字段最小化（可选未知时模型拒绝调用）；字段名清晰（customer_sentiment 胜 sent，模型用字段名引导内容）；工具名 verb-noun（submit_form 胜 process）。（提升层：可复用 Skill）
4. **retry-with-error 循环**——验证失败 append 精确 ValidationError 消息重试（自校正 80-90%，Instructor/openai SDK 自动做）；无错误细节的"再试一次"很少有用；第 3 次仍失败=须改 prompt 或模型；policy violation 该 block 而非 reprompt 到找到宽松答案。（提升层：工作流）
5. **工具输入/输出双向验证**——执行前验证工具输入（edge case/歧义请求下模型生成无效参数）；返回模型前验证工具输出（外部 API 可能返意外格式/错误 payload/结构对语义错）；双向定义 schemas 每调用验证；成功输出也会漂移（上游 API 变更）——输出验证在污染前捕获。（提升层：工具）
6. **工具契约 Hoare 式（ToolGate）**——每工具 form 化为 precondition+postcondition；precondition 门控调用（检查当前状态满足）；postcondition 决定结果能否 commit 更新状态（运行时验证）；符号状态只通过已验证工具执行演化——防无效/幻觉结果污染世界表征。（提升层：工作流）
7. **错误反馈协议**——工具失败返回结构化错误字符串当工具结果（{error:code, message, retry_after_seconds}；Anthropic 加 is_error:true），不 raise 异常不崩循环；模型据此决定修正参数/调 fallback/告诉用户；"把必填参数留在 optional 数组=调用错误最常见单因"。（提升层：工具）
8. **并行工具调用治理**——默认启用（OpenAI 每请求 ≤10 并发）但竞态多；协调困难时 parallel_tool_calls=false 单有序消息收集；每结果标原 call_id；ledger 持久化 call/result 对+瞬时 4xx 幂等指数退避重试；stream 同流内联履行工具输出避免单独后续请求；开放权重模型（Llama 3.3/Qwen 3）并行行为不一致——任务套件上测再假设平价。（提升层：工作流）
9. **schema 版本化与 registry**——schema 当 registry 管理非代码；additive evolution（加可选字段、新版本再删旧、显式迁移持久化记录、拒绝未知版本不猜）；schema_version 字段写进提取模型本身+每 trace 标注（registry 变旧记录不 track 版本=调试惊喜）；50+ schemas 独立模块启动导入（初始化抓版本不匹配）；additionalProperties:false 时必须同步更新 model prompt/grammar/consumer code 三处。（提升层：工作流）
10. **provider 差异与归一化**——Result injection 三形态（Anthropic tool_result content block/OpenAI role:"tool"/Google functionResponse）；LiteLLM 归一化格式=写一次工具循环换 provider；streaming（input_json_delta/tool_calls delta）；Gemini 慢工具（外部 API/RAG）offload 后台任务让模型继续流；compiled grammar/constrained 层三厂稳定 2026-07 起。（提升层：工具）
