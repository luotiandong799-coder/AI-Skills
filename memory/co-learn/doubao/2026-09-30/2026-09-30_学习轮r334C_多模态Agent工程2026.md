## 独点（10）

1. **统一 omni 模型：多模态不跨模型接力**（来源：NVIDIA Nemotron 3 Nano Omni + Qwen3.7-Plus）——单模型原生支持文本/图像/视频/音频——多模型间传递数据耗时+丢上下文；单 30B 混合 MoE 保持效率；Qwen3.7-Plus 视觉语言统一 agent 底座。判据：**多模态先评估单模型原生支持，跨模型接力是最后手段**。提升层：模型。
2. **GUI 感知两模态：结构化树 vs 截图按需**（来源：techrxiv survey + prophetchrome + GLM-4.6V）——结构化（HTML/DOM/A11y tree）表单/数据提取/标准导航在速度/成本/准确度全面胜；截图仅在视觉布局依赖（按钮在价格右边）/canvas/WebGL/图内信息/视觉 QA 必需；双流混合融合=2026 生产标准。判据：**默认结构化感知，截图按视觉依赖场景按需调用**。提升层：工作流。
3. **主动视觉感知：何时与如何调视觉工具**（来源：GUI-Eyes arxiv 2601.09770）——agent 学会战略性决定是否+如何调用视觉工具（裁剪/缩放）；两阶段推理=粗探索→细 grounding；渐进感知策略两级策略协调；空间连续坐标输出精确指认。判据：**视觉工具调用是决策不是默认，粗探索后再细定位**。提升层：工具。
4. **视觉 grounding 模型：语言↔图像元素关联**（来源：Molmo + SeeClick/CogAgent/Ferret-UI）——点指+grounding 让模型指认图像元素；GUI grounding 原语=截图→点击/表单/导航；移动/桌面/网页多形态。判据：**GUI 任务选 grounding 原生模型，不靠 OCR 事后拼**。提升层：模型。
5. **视觉工具参数原生传递：多模态工具闭环**（来源：GLM-4.6V + WebRetriever）——图像/截图/文档/图表直接作工具参数传入，无需先转文本；工具返回的图/截图/图表被模型二次视觉理解纳入推理链；结构化信息不足时调截图分析工具+VLM+具体视觉问题（哪类对应最高柱）+返回滚动位置定位。判据：**多模态工具=图进图出闭环，结构化不足时截图问答补位**。提升层：工具。
6. **感知抽象+外部视觉记忆：图不占对话窗口**（来源：arxiv 2607.08497 + M3-Agent）——入站图像先过感知抽象引擎→结构化语义抽象（描述/属性标签/缩略图）存外部情节视觉记忆；跨模态推理检索相关视觉片段；实时视觉/音频流转实体中心长期记忆+RL 训练控制模型多轮检索。判据：**视觉内容先抽象入外部记忆，对话窗口只留语义摘要**。提升层：工作流。
7. **全模态评测：跨模态事件图合成多跳任务**（来源：OmniGAIA arxiv 2602.22897）——全模态 agent 评测需视频/音频/图像跨模态推理+多轮工具执行；omni-modal event graph 从真实数据合成复杂多跳查询；单模态评测测不出跨模态推理缺口。判据：**多模态 agent 用跨模态多跳评测，单模态分数是假安全感**。提升层：工具。
8. **空间推理动作接口：代码优先于固定动作集**（来源：SpatialClaw）——VLM agent 在持久 kernel 写 Python，组合感知模块/检查中间结果/跨步修正策略；训练免费+11.2 点；固定动作接口限制空间推理表达。判据：**空间/几何任务给 agent 代码接口而非预定义动作**。提升层：工具。
9. **计算机使用 agent 三判官**（来源：google discuss + OpAgent）——数据库状态=绝对真值（成功唯一真相）；Trace Judge=逻辑审计执行日志（抓低效路径/意外撞对）；Video Judge=多模态 UX 检查压缩视频帧序列（高效/安全/无误达目标）；OpAgent 四模块：Planner 高层策略/Grounder 语义→精确动作+协调/Reflector 状态转换+进度/Summarizer 汇总。判据：**GUI agent 验收=数据库真值+trace 审计+视频 UX 三重判官**。提升层：工作流。
10. **视觉技能库：技能工件保留视觉图形**（来源：VISUALSKILL + UI-Venus-2 + Qwen3.7-Plus）——层次多模态技能库（技能工件保留视觉图形提升表现）；闭环感知-推理-动作统一 scaling（环境/任务/反馈联合）；GUI agent 基准（ScreenSpot Pro 79.0/Terminal-Bench 70.3）。判据：**多模态技能工件保留图，不把图降成文字再存**。提升层：可复用 Skill。
