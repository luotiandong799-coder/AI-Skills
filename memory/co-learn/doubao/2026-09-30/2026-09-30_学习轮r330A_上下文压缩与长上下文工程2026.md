## 独点（10）

1. **上下文工程的三分定义**（来源：spheron.network）——上下文工程=决定"什么进上下文窗口、什么顺序、如何缓存与压缩"以最小化 prefill 计算不损质量（优化**成本与延迟**）；提示工程=什么指令与示例产生最好输出（优化**质量**）；RAG=检索哪些外部文档（优化**相关性**）——三者分治，别混为一谈。判据：**优化对象决定用哪一档：成本延迟→上下文工程、质量→提示工程、相关性→RAG**。提升层：工作流。
2. **五桶预算分配模型**（来源：zylos + kaman.ai）——上下文窗口按桶分配：系统指令 10-15%（固定、永不压缩）/ 工具 schema 15-20%（动态剪枝未用工具）/ RAG 检索上下文 30-40%（最可变、用相关性评分压缩）/ 对话历史（会话期增长、结构化紧凑）/ 输出 headroom（预留给模型输出）；每桶在会话开始前分配显式预算 + 预留 5-10% 缓冲。判据：**预算=系统/工具/检索/历史/输出五桶 + 5-10% 缓冲，会话前分配，逐桶监控**。提升层：工作流/工具。
3. **70% 触发阈值与性能拐点**（来源：zylos + agentic skills）——性能在窗口 60-70% 填满时开始**可测退化**、90% 填满时结构化工具调用质量恶化到影响任务；压缩触发阈值 70-80%（80% 触发、90% 警告）——**阈值触发而非周期触发**，先发制人不等撑满。判据：**70% 开始规划、80% 触发压缩、90% 结构化调用已劣化——别等到满才动**。提升层：工作流。
4. **Keep-verbatim 区域**（来源：agentnative.dev）——压缩时**永不概括**的区域：系统提示 + 工具 schema（字节稳定以保前缀缓存命中）、任务陈述与验收标准、最近 5-7 轮原文；只概括中间的历史。判据：**压缩边界=固定区（系统+工具+任务+最近 5-7 轮）原样保留，只压缩中间**。提升层：工作流/工具。
5. **逐字压缩 vs 有损概括**（来源：zylos FlashCompact）——有损概括 70-90% token 缩减但有改写风险（行号、精确错误消息、变量名可被污染）；逐字压缩（保留选定 token 精确副本、丢弃其余）50-70% 缩减且**零幻觉风险**；生产顺序="先逐字后概括"——预防优先，精确保真优先于激进压缩。判据：**精确技术内容先逐字压缩，纯叙述历史再考虑有损概括**。提升层：工具/工作流。
6. **工具结果占位（观测掩码）：最便宜的杠杆**（来源：agentnative.dev）——把过期、可重新获取的工具输出替换成占位（保留一行"调用发生过+返回了什么"）——比压缩更便宜、先做；分三级：先清理旧工具输出 → 再掩码观察 → 最后才压缩。判据：**省 token 顺序=先清可重取工具结果→再掩码→最后压缩**。提升层：工作流。
7. **三厂家紧凑策略对比：选择取决于目标**（来源：zylos 2026-05-05）——Claude Code 精度遗忘=三层级联保留缓存前缀；Codex CLI 交接备忘=全历史替换（简单粗暴）；OpenCode 分级治理=非破坏性先隐藏后概括——2026 共识：**先保缓存前缀，能隐藏就不删，要概括就命名**。判据：**选策略先问：缓存要保住吗？历史要可恢复吗？损失可接受吗？** 提升层：工具。
8. **压缩必须命名它保留什么**（来源：marktechpost）——压缩不是模糊摘要：Deep Agents 压缩后显式加 session intent + next steps 字段、Claude Code 重读最近 5 个文件——**压缩结果要显式声明"目标与下一步"，防止目标漂移**。判据：**压缩产物=摘要+意图+下一步+关键工件指针，缺一目标会漂**。提升层：工作流/可复用 Skill。
9. **记忆检索的预算三参数**（来源：channel.tel + mem0）——记忆注入变预算问题的修法：score threshold（语义相似度 >0.3 才注入，噪声库提高阈值）/ result limit（每请求 5-10 条，>10 条与对话历史竞争注意力）/ 溢出说明（截断时显式告诉模型"上下文不完整"，防过度自信回答）。判据：**记忆注入=阈值+条数上限+截断声明三参数，缺一就超预算或过度自信**。提升层：工具/工作流。
10. **compact vs clear 判据**（来源：coffee.ai + learn.agentpatterns.ai）——同一目标继续→用 /compact（在自然阶段边界：研究→实现之间）；切换到完全无关任务→用 /clear（带旧上下文增加 token 成本并劣化新任务输出）；自动紧凑默认 ~95% 填满触发（太晚）、手动 compact 在劣化前主动触发。判据：**下一步继续同一目标→compact，否则→clear；自动紧凑阈值太高，手动提前**。提升层：工作流。
