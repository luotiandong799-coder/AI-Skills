## 独点（10）

1. **成本不对称驱动预算：cache read 0.1× 是长会话主项**（来源：zylos）——input fresh 1×/output 3-6×/cache write 1.25-2×/cache read 0.1×；长会话 cache read 主导——稳定内容（system/tool defs）保共享前缀进缓存、变动内容靠后。判据：**预算按成本不对称设计：稳定前缀进缓存、输出留足、fresh 输入最小化**。提升层：工作流。
2. **五桶预算模型+pre-flight 检查器**（来源：kaman + zylos）——Cmax=Csys+Cmsg+Ctools+Caux+Creserve；每次 LLM 调用前 pre-flight context checker 评估各桶是否超预算再调用。判据：**每次调用前跑预算检查器，超桶先处理再发请求**。提升层：工具。
3. **生产分配参考：system 10-15%/tools 15-20%/retrieval 30-40%/history 20-30%/buffer 10-15%**（来源：usewire/maxim）——起点非规则；32k 分配表 system+tools 4800/retrieved 8000/history 9600/tool outputs 6400。判据：**预算先按参考分配比建基线，再按实测调**。提升层：工作流。
4. **task budgets：模型可见倒计时的软顶**（来源：claude）——task-budgets beta header 给全 agentic loop（thinking/tool calls/tool results/output）目标 token；模型看运行倒计时自主优先级+优雅收尾；软顶+max_tokens 硬顶组合。判据：**长任务给模型可见 task budget 倒计时，软顶+硬顶双保险**。提升层：工具。
5. **tiered memory：热态 LRU+重要事实 pin**（来源：zylos）——tier1 热态 2000-8000 tokens（agent state/active goal/last N 轮/即时工具结果；LRU 默认+重要事实 pin 不驱逐）；tier2 session 摘要 1000-3000 选择性加载。判据：**记忆分层热态保活+pin 关键事实，冷态摘要外置**。提升层：工作流。
6. **结构化逐出 CWL：类型化 episode+无 LLM 确定性策略**（来源：arxiv 2606.11213）——agent 边工作边注释轨迹为类型化依赖链接 episode；超预算时确定性 LLM-free 策略按优先级逐出（保留用户轮次）；给长水平 agent 近无限工作视界。判据：**上下文逐出走结构化 episode 优先级，别无差别丢最旧**。提升层：工具。
7. **TTFT 随上下文增长：精简直接换响应速度**（来源：agentixforce）——4K 300-500ms/64K 2-4s/128K 8-15s——TTFT 缩放；预算不是纯省钱是延迟优化。判据：**上下文精简的收益算 TTFT，不只算 token 费**。提升层：工作流。
8. **zone 策略地图：system→缓存/历史→压缩/检索→路由**（来源：bestaiweb）——system prompt 固定高重复→prompt caching 90% 节省；对话历史→sliding/summarize/compaction；检索内容→RAG routing 决策（大语料检索、小语料全上下文更便宜）。判据：**每区按内容特征选策略：固定缓存、增长压缩、检索路由**。提升层：工作流。
9. **masking/截断先行：无 LLM 干预先腾空间**（来源：agentnative + louisbouchard）——工具结果清除/masking 常足够（工具输出主导 agent 上下文增长；JetBrains 52% 成本降+2.6% solve-rate 提升无需 LLM 调用）；trivial tier 先无 LLM（observation truncation 切头尾）再花 token 省 token 再 offload。判据：**先做零 LLM 的 masking/截断，不够再压缩外置**。提升层：工具。
10. **编译期打包：必需先入+可选按分贪心+敏感策略**（来源：ctxbudgeter + llm-ctx-mgr）——Resolver 只加载估计能装下的 Reference；必需项先入装不下压缩 hook 或截断；可选按 score_item 贪心打包；PriorityQueue 用户赋权 Critical/High/Medium/Low 满时先丢 Low；敏感内容策略 warn/refuse/redact/allow。判据：**预算按编译算法打包：必需先入、可选贪心、敏感内容设策略**。提升层：工具。
