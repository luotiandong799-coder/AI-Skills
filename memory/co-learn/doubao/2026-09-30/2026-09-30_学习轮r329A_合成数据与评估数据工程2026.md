## 独点（10）

1. **合成数据四模式：persona-prompted / taxonomy-stratified / evolution / 自举**（来源：futureagi definitive-guide + vibeengines system-design + daddaops）——persona 播种=给生成器一个合成用户画像（人口学/意图/熟练度/情绪/方言）产生意图变体；taxonomy-stratified=把任务相关属性（主题/难度/风格/角色/格式/边界）定义为采样空间逐格生成，保证覆盖想要的区域；evolution（deepen/broaden/obscure/adversarial）=制造生产流量不会自然出现的多跳与对抗尾；自举 Self-Instruct=种子 100-500 条→LLM 生成 5-10 条新指令/种子（带显式多样性指令）→生成响应→质量 judge 过滤。判据：**一个模式在另外两个上塌陷——覆盖靠 taxonomy、变体靠 persona、难例靠 evolution，三管齐下**。提升层：工作流。
2. **过滤是承重墙：embedding 去重 + 跨族 judge + mode-collapse 检测 + 5% 人工抽检**（来源：futureagi definitive-guide）——生成之后一道过滤器扛全部承重：embedding 去重、跨模型族 LLM judge、mode-collapse 检测（pairwise cosine distance、熵、HDBSCAN 聚类数）、5% 人工抽检；反模式=同族生成器与 judge（judge 批准生成器的失败模式）、无 mode-collapse 门（坍缩在数据集进生产数月后才可见）。判据：**生成后的过滤决定数据质量，不是生成 prompt**。提升层：工作流。
3. **训练后置评估三指标：统计保真 / TSTR 效用 / 隐私泄露**（来源：futureagi synthetic-data-guide）——统计=分布重叠、边际直方图、列级漂移 vs 参考真实集（KS 检验、Wasserstein、SDV 报告）；效用=train-on-synthetic-test-on-real（TSTR）——小模型只训合成数据、在真实数据上测、量 gap；隐私=membership inference + 最近邻距离确保没有真实记录被记忆。判据：**合成数据验收=统计+效用+隐私三维，缺一不可**。提升层：工作流/工具。
4. **生成温度 0.8-1.0 + 多教师模型防分布坍缩**（来源：ai-tldr + ayinedjimi + vibeengines handbook）——temperature 0 得到近相同输出（词汇多样性=0）；高温 0.8-1.0 增加词汇变体；多教师=一半数据用一模型、另一半用另一模型，防止任何单一模型风格习惯主导数据集（多样来源合成数据可测地减少分布坍缩）；模型坍缩=迭代在自己的输出上训练导致分布尾逐步丢失。判据：**生成用高温、教师不单一、永远锚定真实数据**。提升层：工作流。
5. **k-center-greedy 多样性子集选择**（来源：premai diversity-scoring）——5,000 条多样示例胜过 5,000 条聚在同一主题的示例；k-center-greedy=嵌入所有示例后迭代选"离已选集合最远"的示例，得到最大多样子集；实践=过滤后数据集嵌入→聚类→按 k-center 选取覆盖主题。判据：**多样性用最大距离子集选择，不是随机抽样**。提升层：工具/工作流。
6. **judge 隔离：教师模型与评测 judge 同族=风格对齐而非任务质量**（来源：futureagi how-to-generate）——用 GPT-5 生成微调数据、再用 GPT-5-based judge 评估该微调模型=judge 系统性打高分，因为模型输出进入 GPT-5 风格方言；评测测量的是"与教师风格对齐"而非任务质量；修复=judge 隔离（用不同模型族的 judge）——与 §评测 judge 校准互补，那条管 judge 自身偏差，本条管生成器-评估器同源污染。判据：**生成器与 judge 必须不同族，同族=风格对齐假高分**。提升层：工作流（评估设计）。
7. **模型坍缩防御：70%+ 真实数据锚定 + 双阶段去重 + 0.88 相似度阈值**（来源：shyankdev frontier + aiwiki + heimdall + vibeengines handbook）——至少 70% 高质量去重人类 web 数据锚定熵、防坍缩；双阶段去重=MinHash LSH（结构 n-gram 近重复）+ embedding SemDeDup 聚类（语义冗余），候选相似度 >0.88 剪枝；静默杀手=分布收窄——即使一轮未过滤自生成也会悄悄缩多样（模型过度采样偏好措辞、欠采样罕见 case），所以测多样性不只测准确率。判据：**合成数据必须锚真实数据、双阶段去重、持续测多样性**。提升层：工作流。
8. **标签泄漏与分布校准：聚合分数藏高危簇；幸存集要与生产分布对齐**（来源：futureagi definitive-guide + alldaystech）——常见反模式=标签泄漏（输入编码答案，模型学捷径）、无分布校准（幸存集在生产输入空间的不同区域）、只看聚合分数（78% 总分隐藏高危簇 42%——必须按簇分解报告）；泄漏风险=训练/测试重叠与 benchmark 污染（合成管线倾向复用模式）。判据：**质量门按簇分解报告、显式查泄漏、幸存集校准到生产分布**。提升层：工作流。
9. **Agentic Self-Instruct / error-driven 数据飞轮**（来源：arxiv 2606.25996 Autodata + 2604.21590 AgenticQwen + shyankdev distillation）——autonomous agent 当数据科学家：生成合成数据→用任务特定信号评估→根据结果改进数据生成配方（闭环）；Agentic Self-Instruct=显式优化"能区分弱求解器与强求解器的示例"；双数据飞轮=error-driven 推理飞轮（可验证难例生成）+ agentic 飞轮（线性工作流扩成可执行行为树）；蒸馏规模=种子 500-5,000 条基线→扩到 50,000-200,000 条高多样性训练 prompt。判据：**数据生成闭环=生成→评估→改配方，围绕错误驱动；种子质量定上限**。提升层：工作流/工具。
10. **Evol-Instruct 复杂度进化 + 许可合规管线**（来源：theneuralbase evol-variations + NVIDIA license-compliant）——Evol=对种子指令做约束添加、推理加深、操作链式（"翻译→找习语→建议替代"）制造多难度级，同核心任务多难度=逼出泛化；许可合规=OpenRouter distillable endpoints（license-safe 模型访问）消除蒸馏法律不确定性 + NeMo Data Designer 管线即代码（可复现）+ sampler 列控多样性 + LLM-as-judge 评分后才存训练集；合成≠无合规——来源模型许可决定蒸馏合法性。判据：**难度进化制造泛化；蒸馏数据合法性取决于教师模型许可**。提升层：工作流/工具。
