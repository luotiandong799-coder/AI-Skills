## 独点（10）

1. **Necessity/Sufficiency 测试：步级因果贡献两查**（来源：arxiv 2603.22816 + NLDD + TTS）——necessity=移除步 i 答案变不变（变了=必要）；sufficiency=单独呈现步 i 能否得答案；NLDD 标准化跨模型比较（损坏步测置信度下降）；TTS 量化每步因果贡献区分 true-thinking vs decorative-thinking 步——前沿模型频繁绕过自己推理。判据：**验证推理忠实性先跑步级 necessity/sufficiency 测试**。提升层：工具。
2. **BonaFide 警示：多数 faithfulness 指标近随机**（来源：arxiv 2605.25052）——首个 ground-truth 标签基准（非 plausibility/importance 代理）——8 个主流指标多数接近随机、系统偏差、长 trace 退化；评价指标前先用 ground-truth 基准校准。判据：**选 faithfulness 指标先过 ground-truth 基准，别信代理指标**。提升层：模型。
3. **C²-Faith 两维度：causality+coverage**（来源：acl 2026 gem）——faithfulness 分解为 causality（每步是否逻辑上从前文推出）与 coverage（必要中间推理是否出现）；LLM judge 测 process faithfulness 而非 answer plausibility——用受控比较。判据：**评 CoT 忠实性分 causality/coverage 两轴，别只查 plausibility**。提升层：工具。
4. **NSF-CoT 神经符号验证：SMT+LLM entailment 混合检查器**（来源：cise.ufl）——上下文事实+推理步转逻辑语句、counterfactual attribution 估计步依赖哪些事实、SMT solver+LLM entailment judge 混合验证每步；每步评 groundedness/validity。判据：**高价值步验证用符号+神经混合，别只靠 LLM judge**。提升层：工具。
5. **Faithfulness 度量混淆 incompleteness：分布式计算转线性叙述是压缩损失**（来源：arxiv 2512.23032）——Biasing Features 把"省略提示注入 hint"标为不忠实——混淆 unfaithfulness 与 incompleteness（分布式 transformer 计算转自然语言叙事必经的有损压缩）；多跳任务中很多被标不忠实的 CoT 用其它指标判忠实。判据：**"没提到"不等于"没用它"，评忠实性区分遗漏与伪造**。提升层：模型。
6. **FaithRL 两步奖励：PRM 显式+truncated resampling 隐式**（来源：arxiv 2602.05897 + 2602.03507）——显式步级奖励=PRM 评每步忠实性+缓解 reward hacking 策略；隐式=检测到不忠实 CoT 步从忠实前缀重新生成后续；faithfulness-maximization 目标理论缓解过度自信。判据：**训练要忠实性直接优化步级奖励，别只奖结果正确**。提升层：模型。
7. **生成式 reward 四象限：faithful/correct 分开判**（来源：arxiv 2509.25409）——faithful+correct（支持）/faithful+incorrect（源本身错过时矛盾）/unfaithful+correct（合理总结常识）/unfaithful+incorrect（捏造过度推测）——只 mark incorrect 当真正错误。判据：**评生成质量把忠实与正确分两轴，源错≠模型错**。提升层：模型。
8. **执行 trace 转结构化报告+忠实自然语言解释**（来源：arxiv 2609.06063 + 微软格式）——post-hoc XAI 把长 agent 执行 trace 转结构化报告+忠实解释（grounded in observable behavior）；微软格式：输入/匹配模式/触发证据代码/证据到结论逻辑步（安全发现带行号）——审计员能说"为何错"不只"错了"。判据：**agent 解释输出固定格式 trace：输入/匹配规则/证据/结论链**。提升层：工作流。
9. **决策包（Decision Packets）：密封的命题/参数树/证据快照/选定理由**（来源：ai-agentree + AIACP）——记录完整推理为结构化可审计产物——与执行日志区分（日志记 what happened，决策 trace 记 why：考虑过的选项/查阅证据/权衡参数/选定理由）；AIACP 要求 consequential 决策不可变审计日志（输入/决策/置信度/受影响方/时间戳）+30 天内人类可读解释权。判据：**重要决策给密封决策包：选项/证据/理由/结果追踪**。提升层：工作流。
10. **版本化 agent 定义+统一执行 trace：运行时行为链到具体配置**（来源：kore.ai）——每个 agent 有文档化版本控制定义链运行时行为到配置；事故时定位"哪个版本 agent 做的决策+如何配置"；多 agent 系统全链一步一记录（LLM 调用/工具）。判据：**agent 定义版本化+全链统一 trace，事故可定位到配置版本**。提升层：工具。
