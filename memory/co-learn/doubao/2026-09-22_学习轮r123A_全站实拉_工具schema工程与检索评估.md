## 10 次实拉（逐站留痕）
1. 工具 schema 工程（强）：**description 不是文档，是每次请求都发给模型的 prompt 文本；改写 description 是最高杠杆**；好 description 三件事（命名概念/与相似概念区分/何时用与何时不用）；结构=一句话做什么+何时用（以及何时不用）+返回什么；enum 约束参数减少幻觉；additionalProperties:false+显式 required 消除约 80% 解析错误；schema 质量比模型选择影响更大（10-20% 准确率）；工具名动作化（get_current_weather 优于 weather）
2. RAG 检索评估（中）：检索指标（Recall/MRR/nDCG）与生成指标（Correctness/Faithfulness/Relevance）分测；组件级 Fidelity（top-n 中好文档占比）/NDCG（排序质量）/XDCG（top-k 质量与索引无关）；两阶段混合检索+神经重排大幅优于单阶段
3. Query 变换（强）：**决策表：Rewrite（+1 LLM 调用 1 检索，主提精度，多轮/口语）/Multi-Query（+1 调用 N 检索，主提召回，RRF 融合）/HyDE（+1 调用，伪文档嵌入，主提召回）/Step-back（抽象一层+2 检索）/Decompose（拆多跳+N 检索）/Route（+1 调用路由）**；**HyDE 即使伪文档事实错误也能提供检索信号（结构相似）**
4. 大工具输出（中-强）：三修法=工具边界分页/过滤（concise-vs-detailed+显式 page token）/交回 handle（路径或 ID+小预览，按需 page/grep）/卸载沙箱；memory pointer 法（交互从原始数据转向指针，任意长度无丢失）；静默截断会砍 system prompt
5. 重排三档（强）：**Bi-encoder（首阶段百万级，1 向量/文档）/Cross-encoder（二阶段 top30-100，+5-15 NDCG，50-500ms/100 候选）/ColBERT（中阶段，+3-8 NDCG）**；**cross-encoder 不增加 recall 只重排（Precision@1 是它的指标）——重排≠检索**；候选集 30-100 是边界条件
6. 多智能体通信（中）：直连/黑板（共享状态，多 agent 贡献部分知识/下一步未知/多假设并行）/pub-sub（话题解耦一对多）/队列——与 WB r132 委派判据及 ED 接口契约相邻
7. Trace 审查（中-强）：**失败分类法 9 类（hallucination/incorrect actions/orchestration errors/task instruction non-compliance/execution errors/context handling errors/repetitive behavior/LLM output issues/configuration mismatch），每个失败返回 span 位置+类别+置信度+证据**；三层观测 metrics/traces/logs；agent-strace 的 tool-loop/推理螺旋自动检测（与 WB r132 转圈重叠）
8. 评分质量（中-强）：**同一判定能报出天差地别的一致率，取决于四选择（判断量表/保留案例/弃权与无效输出处理/跨条目跨标准池化）——报告 judge 与人类一致率时必须声明**；RULERS=可执行 rubric+可验证证据+校准量表优于 prompt 措辞（与 D84 相邻）
9. 成本归因（中-强）：**每调用强制打标签（project/team/pipeline step/cost center，gateway 层注入，每请求记账给恰好一个 owner；未打标拒绝或入未归属桶）**；输出比输入贵约 5x，账从累计输入来（每轮重发历史）；**tokens per accepted outcome 指标**；缓存命中率是成本大头
10. 平台探活：n8n Anthropic 节点 prompt caching（opt-in TTL 5min/1h）+n8n Agents 一次定义到处用；Langflow 1.12 OpenTelemetry；Claude Skills API/Files API——平台功能
