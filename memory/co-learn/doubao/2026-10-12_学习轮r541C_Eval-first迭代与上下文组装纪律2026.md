## 落地 6 个真独点（全部带提升层）

1. **Incomplete Executions 机制补充：不开就静默丢 bundle + scenario 级重试粒度** → execute-discipline 3.48.0→**3.49.0**。要点：Break 重试落点是 Incomplete 队列，**关存储=重试无处排队=静默丢 bundle**（"silently drops the bundle"）；**自动重试是 scenario 级非模块级**，模块级需 error handler+router 内部实现；Break retry 参数是开关；成功标记 Resolved 停止、失败留人工 Retry selected。提升层：工作流（错误处理）。
2. **handoff 交接点双端哈希 + diff 定位发散** → execute-discipline 3.49.0（同文件第二条）。要点：Agent A 输出→B 消费前**双端各算一次内容哈希**，一致=无损、不一致=消息丢失/改写；**哈希阶梯定位发散点**（第一条不一致的交接点即发散点）；结构化日志 JSON 而非 printf。提升层：工作流（可观测性）。
3. **静态先动态后 + messages 追加不改 prompt + subagent 替代换模型** → context-compressor 3.644.0→**3.645.0**。要点：稳定内容（system prompt/工具）在前、动态在后，稳定块进前缀缓存；**更新走 messages 追加不编辑已发 prompt**（可审计）；**缓存模型专属，要便宜模型用 subagent 不换主会话模型**（换模型=缓存全失效+行为漂移）。提升层：工作流（上下文工程）/ 工具（缓存治理）。
4. **记忆自动结晶为工作流技能 + 溯源门控只升不降** → context-compressor 3.645.0（同文件第二条）。要点：高频验证记忆**语义聚类自动结晶**为技能（魔搭 182 个实证）；**溯源验证+结构分数门控确保只升不降**（能自动进就能自动拒）；技能画像分离管理+一键分发。提升层：可复用 Skill（记忆→技能自动沉淀）。
5. **Eval-first 六步迭代 + undertrigger 实证 + 重复工作打包信号** → skill-authoring 1.129.0→**1.130.0**。要点：无技能基线→最小草稿→**新实例（Claude B）跑 2-3 prompt**→观察→回编写实例精修→扩大测试集（双实例防自证偏差）；**anthropics/skills 官方明示 Claude 有 undertrigger 倾向——description 要 pushy 防欠触发**；跨用例重复 helper 脚本=技能捆绑脚本信号。提升层：可复用 Skill（编写迭代法）。
6. **SkillTrustBench 模型底座评测 + wxa-skill-eval 配置驱动多模型** → skill-authoring 1.130.0（同文件第二条）。要点：**固定扫描器配置仅替换底层推理模型**（Claude Opus 4.6/GLM-5.1 均衡最佳）——选评测 judge 的控制变量法；wxa-skill-eval 提交前自动跑四维评测、配置驱动混元/DS/Kimi 免注册；云鼎四道防线审查结果消费端可见。提升层：可复用 Skill（评测基建）。
