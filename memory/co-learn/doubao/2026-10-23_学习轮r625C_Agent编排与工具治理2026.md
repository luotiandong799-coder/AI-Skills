## 三、提炼的核心方法与关键事实
1. **治理触发判据**：actions 按 reversibility/impact/verifiability/agent's track record 四因素评估决定何时需 oversight（DXC）。
2. **单 agent 上限 5-7 tools**：超过后窗口被 tool descriptions 填满、推理降质、不可靠——拆多 agent（Alice Labs）。
3. **Policy is code**：自然语言策略编译成 tool boundary 校验；Denial is structural——拒绝由代码执行非模型自觉（Langflow/OpenClaw）。
4. **HITL 四治理控制**：identity/permissions+approval thresholds+output validation（schema+quality gates）+audit trail/explainability；approver 可编辑 AI output 再批（Make）。
5. **安全三优先**：Identity first（谁能对话）→Scope next（能做什么）→Model last（假定模型可被操纵、设计 blast radius 有限）（OpenClaw Cheatsheet）。
6. **凭证物理分离**：credentials 放独立 vault，agent 永不见；agent loop 与 sandbox 分离（Anthropic）。
7. **MCP 注册制**：新 MCP 进 pending+review packet 七要素，review 后 enable；standing token→scoped identity（OpenClaw）。
8. **双门 allowlist**：admin org-wide enable+user 个人授权（Anthropic Claude Cowork）。
9. **Agent lifecycle**：sandboxed testing→permission audits→production 中心目录注册（Vucense）；Agent 定义不可变（damnagent）。
10. **A2A 协议**：跨框架 agent 标准化 discover+communicate（deeplearning.ai/Google）。
