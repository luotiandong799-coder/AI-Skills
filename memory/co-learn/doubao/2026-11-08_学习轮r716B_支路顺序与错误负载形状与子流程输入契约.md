## 二、判重（增量判定，避开 r715 已落基线）

- `wb-execute-discipline` 已含：错误处理两层（node 级 Retry On Fail / workflow 级 Error Trigger）、子工作流即工具、`execution.id` 幂等键陷阱、`retryOf` 只在重试出现 → 这些**判为重复不落**。
- 仍为 0 命中的增量：**支路执行顺序由画布位置决定**（`画布` 命中 16 处均为 UI 跳转/决策面板，无顺序规则）、**错误负载字段随失败位置变化**（`trigger node` 仅 1 处且非此义）、**子流程输入模式三选一**（`输入模式`/`accept all` 0 命中）。
- 与 WorkBuddy r715A（EI 契约三问）不重叠：那组管"每步的 expect/guarantee/maintain"，本组管"图级顺序、错误负载、跨流程输入契约"。

## 三、落地（3 独点 / 1 技能，合并为一节三条）

| 点 | 独有内容 | 提升层 | 落点 |
