## 独点（4 个）
### B1：逻辑间隔压缩 + 文件化规划——压缩选"任务阶段"而非任意时机，规划落三文件（来源：skillsmp #604/#608）
- **strategic-compact（ECC）**：**在逻辑间隔手动压缩上下文**——会话接近上下文限制且某任务阶段结束是自然压缩点（task phase 是自然的 compact 点），而非任意自动压缩；"保留上下文通过任务阶段"是目的。与 wb-context-compressor"按任务状态压"同源的外部正式化，且明确了"手动在阶段边界压"优于"自动任意压"。
- **planning-with-files（davila7/claude-code-templates, 30,896★）**：**Manus 式文件化规划**——复杂任务（>5 tool calls）创建 task_plan.md（计划）/ findings.md（发现）/ progress.md（进度）三文件；文件即状态，agent 重启/切换会话不丢上下文。
- 判据：**压缩时机选"阶段结束"不选"窗口满了"**；规划落盘成三文件让进度可跨会话续（进度/发现/计划分文件，不是一坨笔记）。
- **提升层**：上下文管理 / 工作流。

### B2：为 agent 写作 + 纪律化工作流——写文档给 agent 读、流程固定五步（来源：skillsmp #621/#634）
- **writing-for-agents（mattpocock）**：创建/编辑 skill、AGENTS.md、CLAUDE.md 时用——**文档读者是 agent 不是人**：写可执行指令、明确触发条件、给边界。与 r197"AGENTS.md 二·五先查 GitHub 现成可改"互补——这条管"怎么写给 agent 的文档"。
- **superpowers-workflow（834★）**：强制纪律化工作流 brainstorm → plan → implement（prefer TDD）→ review → finish——**几乎任何非平凡改动都走五步**；与 obra/superpowers 同源，但强调"先脑暴再计划、实现优先 TDD、收尾前 review"。
- 判据：**给 agent 的文档 = 指令不是描述**；非平凡改动固定五步流程，防止跳过 planning/review。
- **提升层**：可复用 Skill。

### B3：39 代理学术研究管线 + 400 技能领域网关——研究级 agent 编排形态（来源：skillsmp #632/#628）
- **academic-research（jeo-skills）**：完整学术管线——4 reference pipelines + 27 modes + **39-agent ensemble**（deep-research 8 modes / academic-paper 11 modes / academic-paper-reviewer 6 modes / academic-pipeline 10-stage orchestrator），全程 human-in-the-loop，路由按请求选 pipeline/mode。
- **bioinformatics（hermes-agent）**：**400+ 基因组学技能网关**——一个技能作为领域网关路由到数百子技能（网关模式：入口技能 + 领域技能矩阵）。
- 判据：**研究级 agent 是"多管线 × 多模式 × 角色集合"的编排，不是单 agent**；领域技能用网关模式组织（一个入口 + 数百子能力）优于平铺。
- **提升层**：Agent 编排。

### B4：技能安全审查高需求（Skill Vetter 273.9K 下载）+ 自改进 agent + 跨协议发现（来源：GitHub 生态搜索）
- **Skill Vetter（agentskillslist #02, 273.9K ClawHub downloads）**：**安全优先的技能审查**——安装任何 skill 前查红旗/权限范围/可疑模式（来自 ClawHub/GitHub/其他源）；273.9K 下载 = 安全审查是技能生态的高频刚需（与 wb-context-compressor"工具面安全"同主题的外部验证）。
- **Self-Improving + Proactive Agent（#03, 209.9K）**：自省 + 自批判 + 自学习 + 自组织记忆——agent 评估自己工作、抓错、永久改进（安静 4 个月仍 209.9K 下载）。
- **agskills.dev / agentskills.codes / agenticskills.io**：Agent Skills Marketplace 生态成型——跨协议发现（pumanitro/global-chat 跨多个 registry 发现 MCP servers + AI agents）、181+ curated（agenticskills）、leaderboard 按 installs+views 排 50 名。
- 判据：**装技能前审查 = 与写技能同等重要**（下载量证明）；自改进 agent 是"评估自己工作→永久改进"的闭环产品化；技能市场已有跨 registry 发现层。
- **提升层**：生态观察 / 安全。
