## 独点（5 个）
### C1：MemOS 四层记忆分层——L1 trajectory / L2 strategy / L3 world model / skills（来源：deepseek-plugin MemTensor）
- 每轮用户消息自动检索对应层；不是一坨记忆。
- 判据：**记忆分层按抽象度**——轨迹（发生了啥）→策略（怎么做）→世界模型（领域事实）→技能（怎么做某类事）。
- **提升层**：上下文/记忆。

### C2：Hindsight per-repo 共享 memory bank（来源：deepseek-plugin hindsight）
- 跨会话按仓库召回知识页；conversations 自动存。
- 判据：**记忆作用域=仓库**——不同项目别串味。
- **提升层**：记忆。

### C3：Ouroboros 规格驱动循环 Interview→Seed→Execute→Evaluate→Evolution（来源：deepseek-plugin ouroboros）
- 先访谈需求→种子方案→执行→评估→进化迭代。
- 判据：**规格驱动不是一次写完 spec**——是循环里持续 evolution。
- **提升层**：工作流。

### C4：skill 三项认证之"可执行性"=沙箱真实演练（来源：虾小宝）
- 不只审代码，把 skill 扔进隔离沙箱真跑一遍，验证 SKILL.md 声明的能力能不能落地。
- 判据：**skill 声明 ≠ skill 能用**——沙箱跑过才算数。
- **提升层**：可复用 Skill/评测。

### C5：技能安全审计三层——模式匹配→去混淆→LLM 意图分析（来源：虾小宝）
- 先正则扫危险模式，再去混淆还原，最后 LLM 读真实意图。
- 判据：**单层审计会被混淆绕过**——三层叠加才拦得住社会工程。
- **提升层**：安全。
