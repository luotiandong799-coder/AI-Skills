## 二、落地点（4 个真独点）

### 1. 自学习按工作量触发（工作流层）
每 session 跨轮累计 model iterations，达 10 才排队一次 review 并清零；前台本轮已改 learned skill 也清零；读/查看技能不触发。判据：学习频率跟工作量挂钩，不跟时间挂钩。

### 2. 审阅者权限边界与准入门槛（可复用 Skill 层）
只能 list/view + save lesson，不能浏览文件/取更多历史/重跑任务；改、写、归档前必须先 view；归档需 `absorbed_into` 或 `reason`；只收"会被再次问到且不改会做错/重做"的可重复程序，一次性细节（某产品/订单/日期/地点）留在会话。

### 3. 托管 revision 的缺省语义（可复用 Skill 层）
发布经校验与扫描产出完整 revision，但**发布不替换当前会话选择**，需显式 attach/refresh 才在下一轮生效；update 的 `name` 是 slug 不是命令名；省略 `name`/`proposal_content` 即保留；`files` 为具名 upsert，省略或 `[]` 保留其余文件；省略可执行位也保留；删文件走 `delete_files`。

### 4. 用运行轨迹给技能改进取证（工具层）
trajectory 是 per-session flight recorder；`/export-trajectory` 输出脱敏 bundle，含 prompt/system prompt/tools、导致答案的 transcript 与工具调用、以及是否超时/中止/被压缩；只接受相对目录（`.openclaw/trajectory-exports/`），绝对路径与 `~` 被拒。
