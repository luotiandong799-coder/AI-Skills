## 四、本轮落地的 6 个真独点

1. **主会话是汇聚点不是聊天记录**：默认 DM 折叠进 `agent:<agentId>:main`（后缀固定，`session.mainKey` 被忽略）；heartbeat 唤醒、子会话结果 announce 回流、群活动上浮 → 提升层：工作流。
2. **新会话创建只投一条有界摘要**：pending creation 合并共享一份有界内存摘要，下一次 turn/heartbeat 才消费；Home/draft/incognito/内部会话/cron 不通知；重置不重复通知；`session.notifyOnCreate:false` 可关 → 提升层：工作流。
3. **隔离与可见两套开关**：`groupScope` 管隔离但主会话自动 watch；`tools.sessions.visibility` + `agentToAgent` 管权限；per-peer DM 路由不限制 session 工具可见性 → 提升层：工具。
4. **修剪是投影不是改写**：原文不重写、投影记在 transcript marker、重启与 idle 卸载后还原；新一轮要同时过 TTL 与占比双门，成功请求刷新 TTL、失败请求不刷新 → 提升层：工具 / 工作流。
5. **服务端清除参数是推导的**：trigger=max(50000, ctx*0.3)、keep=最近 3 次工具调用、clear_at_least=max(12500, ctx*0.05)、`clear_tool_inputs:false`、`exclude_tools` 继承 deny/allow → 提升层：工具。
6. **磁盘预算先归档再删 + 跨会话检索硬数值**：`maxDiskBytes` 默认 10gb，先抽最老未引用历史到已验证压缩归档再删行，live/routed/in-flight 豁免；检索 ≤4,096 UTF-16 单元 / 25 条 / excerpt 300 单元 / 32 KiB，90 秒预算，超时≠无匹配 → 提升层：工作流 / 工具。
