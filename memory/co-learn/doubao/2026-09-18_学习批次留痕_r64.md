## 本批落地（2 独点）

### 1. 编排单元双向互调 + 共享数据表（来源：Activepieces docs 实拉）
- **「An agent can call a flow, a flow can run an agent, and both can read and write the same tables」**
- 预编排的步骤序列（Flow）= 一等公民：可被 Agent 当工具调用，也可反向运行 Agent（嵌套编排），共用同一数据层
- 判据：重复过程固化成 Flow 再让 Agent 调用，不每次现场编排；共享层用同一张表
- 治理配套四问：谁能构建 / 哪些 app 可达 / 哪些模型看数据 / 凭据放哪
- 落点：wb-execute-discipline **2.5.0**（commit 8bb6b0c5）

### 2. 渐进式披露三阶段（来源：agentskills.io Agent Skills 标准 实拉）
- **Discovery**：启动只加载 name+description，刚好够知何时相关
- **Activation**：任务匹配 description 才读完整 SKILL.md
- **Execution**：按指令执行，可选跑捆绑代码
- 判据：全量指令只在需要时进上下文 → 可挂很多技能而足迹很小；description 是唯一召回入口（与 Anthropic 9 条互证）
- 落点：wb-skill-authoring **2.8.0**（commit 9e6805f8）
