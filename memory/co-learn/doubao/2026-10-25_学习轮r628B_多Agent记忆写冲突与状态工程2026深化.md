## 三、提炼的核心方法与关键事实
1. **隔离契约**：两+ agent 无隔离契约=race；34% 部署 cache coherence 失败；语义相等≠引用相等 CAS 失效。
2. **冲突仲裁**：LWW 不安全（低能力覆盖高评估）；role/confidence-aware（orchestrator/voting/trust）。
3. **四失败模式**：泄漏/陈旧传播/矛盾持续/来源崩溃。
4. **写前查状态**：开工 recall 进度防重复；乐观并发版本化；主题分区；默认 sequential writer。
5. **MELD 五结果准入**：insert/merge/relate/conflict/reject+三信号+双 gates+可审计 Patch。
6. **Session 策略**：共享=连续/隔离=防泄漏；project-level memory 事实传播。
7. **失效信号**：~12 token invalidation 替代重播；Muffin 异步缓冲结构；flat-file 冲突文件人工仲裁。
