## 10 次实拉（逐站留痕）
1. Agent 记忆架构（强）：**Mem0=混合四信号检索（semantic+keyword+entity+graph）+多作用域标签（user_id/agent_id/session_id/org_id）+使用率衰减（usage-based decay，非简单 TTL）**；**Letta/MemGPT 三层=core（常驻 RAM：persona+关键事实）/recall（会话历史语义检索）/archival（外部无限存储，如 disk）**，agent 主动管理自身记忆（OS 式）；**语义（facts）vs 情景（events）分离——"what happened" 与 "what's true" 是两类记忆**；冲突检测=新事实与既有图对比、矛盾时更新
2. GraphRAG 选型（强）：**决策=查询复杂度，非架构本身**；单文档/单片段查找→vector（快/便宜/易保鲜）；多跳推理/跨文档关系/全局综合→graph；**<1000 实体用 metadata filter 优于 graph（约 1/10 成本）**；**Type 1 图增强（metadata filter 派生自现有结构化数据，最便宜）→ Type 2（关系抽取）**；**图会陈旧：vector 优雅退化 vs stale graph 静默编码不再成立的关系**；HippoRAG 个人知识图；GraphRAG 本地 1-10s/全局 5-30s 延迟
3. 合成数据生成评测（强）：**五陷阱=①same-family generator+judge（judge 认可生成器的失败模式）②无 mode-collapse gate（塌缩数月后才显现）③label leakage（输入编码答案，模型学捷径）④无分布校准（幸存集在生产输入空间外）⑤只报 aggregate（78% 掩盖高风险簇 42%）**；**2026 工作模式=50-200 真实种子→生成 5-10x→按种子欠表示的轴显式变化→多样性度量（pairwise cosine 对真实参考分布）**；**镜像生产 system prompt（生成时用生产同款指令，漂移削弱评测信号）**；合成+trace 结合最强（launch 前填空白+边界用合成，生产轨迹飞轮晋升 golden）
4. 并行工具调用（强）：**OpenAI strict:true Structured Outputs 与 parallel 互斥（并行时回退非 strict schema——依赖 100% schema 符合要关并行或事后校验；Anthropic/Google 无此限制）**；**Promise.all（fail-fast）用于写操作/全部数据必需；Promise.allSettled（partial success）用于只读/部分数据有用**；**safe_parallel 才并行（cursuri-ai 循环=validate args→authorization→execute parallel if safe_parallel）**；**强行并行三法=单条 user message 独立请求+低温 0.1-0.3+显式 system prompt 指令**；流式并行=每调用 id 一个 accumulator（参数分片交错到达）
5. 层级总结与压缩失败（强）：**时间金字塔=近期全保真、稍早轻度总结、更早深度压缩（granularity 随时间递减，不折叠成一个 blob）——细节在当下、只压缩旧的**；**递归层级总结陷阱=summary of summary 指数级丢信息、每层像 low-pass filter（细节先消失）、递归合并放大幻觉；incremental 比 hierarchical 更不连贯（BooookScore）**；**压缩失败（输出>输入）→三级升级协议（LCM）：escalation 到更激进策略，最后确定性 fallback 强制收敛**；任务选深度=factual QA 用 L1、thematic 可到 L3
6. 语音 agent（中）：500ms 延迟预算（Network 30-50+STT first-partial 100-150+LLM TTFT 200-300+TTS 75-200）；级联（STT→LLM→TTS）vs S2S 单模型（保韵律）；OpenAI full-duplex 移除 turn detector；网易有道 R2T2 Append-only 流式提交（Longest Stable Prefix 确认后不改写）
7. Agentic search/查询分解（中-强）：query planner 分解子查询→**source router（按源类型路由：web/vector/structured db/专用 API）**→evaluator 评估相关性/质量/充分性→循环补 gap；子查询并行+语义重排+合并（Azure）
8. 提示工程 2026（中）：**Chain of Draft=约 5 词推理步骤，7.6% 推理 token 达完整 CoT 同准确率**；动态 few-shot 选择（语义相似度+多样性采样）；合成示例生成（先让模型想象 3 个高质量示例再解决实际请求）
9. LLM judge 偏差（强）：**rubric-based 评分有 position bias（多选项位置偏好）→ balanced permutation（均匀分布各分数位置）聚合既显偏差又提相关性**；**verbosity bias 按模型异质（Llama/Gemini +0.24~0.44 偏好长、Claude Sonnet 4 -0.12 偏好简洁、GPT-4o 中性）——不可假设都偏好长**；**self-preference 能力匹配代理控制后大幅降低（多为评估不确定性非自我识别）**；无参考答案时 judge 过宽（over-credit）
10. 平台/生态探活：Langflow 1.10（Assistant flow building/Memory bases/DB Providers/MCP IDE）；Make（AI module/3000+ apps）；Pipedream（code-first/compute-second）；Activepieces（MIT/280+ MCP）；**技能市场安全模型梯度=Anthropic 官方（人工 verified）/skills.sh（Vercel、npm-style CLI、builder-side 审计）/SkillsMP（~190 万、GitHub 抓取、无审查 inspect-before-install）/腾讯 SkillHub（8 万+/TRACE 评测/三线审核）/虾小宝（3.5 万+ 安全审核）**；智谱 AgentMore；deepseek-plugin.org
