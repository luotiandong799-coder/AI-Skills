## 三、提炼的核心方法与关键事实
1. 编排者职责链：隔离 worker per task + review subagent 收口 + 写盘回执；五纪律兜底。
2. HITL 是治理要求不是 UX：不可撤销动作必审批；interrupt+checkpoint 精确恢复；风险路由。
3. 框架选型：可重放性/决策可见性/维护状态三轴；guardrail=纯函数不是特殊机制。
4. MCP/A2A 分层：MCP inside agents, A2A between agents；AAIF 统一治理；说/传分离（AGMP/AGTP）。
5. 记忆存储三档（Mem0 召回/Letta 状态/Zep 时间）+三态分工（memory base/Message History/Knowledge）+显式记住指令。
6. State 设计：typed 第一天、纯 node、副作用归工具层、durable execution 恢复不重头。
