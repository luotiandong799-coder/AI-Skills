## 10 次实拉（逐站留痕）
1. Query 变换（中-强）：**五策略矩阵=rewriting（清洗对话查询）/expansion（同义词扩充）/multi-query（多视角召回）/decomposition（多跳拆子问）/step-back（抽象化）各自风险**；**LangChain 分解操作约束：每个子问题只关于一个概念/事实/想法——约束是全部工程决策，无约束产出"更聪明的复述"检索同样失败**；单一结构化输出调用同时完成 rewrite+decompose（不加第二次往返）；modality routing（复合查询按模态拆分再 RRF 融合）
2. 多 agent 编排（中-强）：**handoff 两个坑=①过度贪婪（传全 12K 会话对方只需 800 token，每次交接翻倍账单）②丢失意图（A 说"修这个 bug"B 拿到的只是对话）**；**委托循环防护=depth counter 或 no-backsies**；**shared state 争用（多 agent 同时写，看起来像 agent 问题实际是写冲突）**；circuit breaker（fail-fast+半开单测）；**可选 enrichment agent 失败返回 sentinel 让下游处理缺失/必需步骤失败 abort 不产出低质输出/绝不静默丢失败**；**DAG vs 状态机=固定无环依赖→DAG；持久业务生命周期（合法转换/修复可循环）→状态机；生产可组合**；**checkpointed execution（每节点转换自动持久化+interrupt 暂停恢复，人工升级全上下文保留）**
3. 评测/rubric（中-强）：**rubric 结构化 3-7 条标准+每条显式锚点（1 是什么 5 是什么）+要求引用证据+证据缺失 abstain**；**judge 校准=先 30-50 条人工标注测一致率，<80% 不自动化（修 rubric 不是改数据集）**；few-shot verdict balancing（均衡代表各判定类）；self-consistency 检查（同输入跑两次换位）；版本化（commit 格子/golden/judge 配置/结果）
4. 工具调用（中）：parallel 失败=partial failure（5 并行 1 抛错；Promise.all fail-fast vs allSettled；缺 tool_result 400 必须返回占位+error payload）；disable_parallel_tool_use:true 每轮一副作用工具；只读可并行/副作用串行；max-tool-calls guard（10/session）
5. 工作流编排（中-强）：DAG/事件驱动/Actor 三模式；DAG 路由（分支点确定性代码或分类 LLM 决策）；无预编译 DAG（agent=运行时状态机，Prefect 跟随控制流）；orchestrator-worker map-reduce（planner 分解+Send 并行+合成）
6. CoT/自一致（中）：**structured CoT（先识别问什么→列已知→计算→验证）优于 naive "let's think step by step"**；**self-consistency=N 次采样（T=0.7）majority vote，成本×N，只用于高价值答案，先在自己测试集量 majority-vs-single**；**温度分工=0.7-1.0 候选生成/0.0-0.3 验证反思**；Reflexion（HumanEval +24%）
7. Few-shot（中-强）：**四类案例配方=①简单规范案例（锚定格式/长度/语气）②难/复杂案例（脏输入/信息不全）③模糊/边界案例（决策规则）④负例（明确不该做什么）**；**5-8 个精选最优，超过递减**；格式一致性（bullet 全 bullet/table 全 table）；四族选择策略（random/similarity/diversity/complexity 任务类型不同优势不同）
8. RAG 评估（强）：**四指标两对=retrieval（context precision 检索是否相关且排序好/context recall 是否检索全）+generation（faithfulness 声明是否被支持/answer relevance 是否答问题）同一次运行算四个，判断坏答案是检索还是生成问题（修复方向相反）**；faithfulness 两步（分解原子声明→逐条对照支持/不支持→比率）或单次（RAGVUE）；**chunk attribution（模型是否真的用了检索上下文——诊断"检索好但模型没用"）**
9. 上下文压缩（中-强）：**compaction 触发点 60-75% 不等硬墙**；**ACON：压缩指南优化——全上下文成功但压缩失败的轨迹对→LLM 分析失败原因→更新压缩指南**；Focus（主动固化 Knowledge block+剪除原始历史）；compaction 策略（保留用户消息+摘要放分割点）；Headroom（60-95% 压缩+原始按需取回）
