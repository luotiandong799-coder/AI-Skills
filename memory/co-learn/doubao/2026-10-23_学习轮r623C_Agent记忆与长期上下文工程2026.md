## 四、提炼核心方法与关键事实

1. **文件系统记忆与分层**：无隐藏状态（不在盘上不记得）；MEMORY.md 每会话加载保持 short（<200 行只含最高优先级事实）；三实践模式（append-only MEMORY.md/按域 context files/session snapshots）；可靠设置分离（preferences/facts/daily notes/search 分文件）。
2. **Compaction 前记忆转储**：自动 compaction 前 silent agentic turn 写 durable state 到盘（compaction 不能擦关键上下文）；413 恢复链（Context Collapse 轻量→Reactive Compact 重量逐级）；压缩保 decisions/files/risks 三必保。
3. **会话 ID 记忆控制**：复用 ID=检索历史有记忆，留空=无记忆省成本；窗口上限（Maximum conversation history/50-100 起步）；session_id 分组隔离用户/应用；按 name/email 查找历史。
4. **分层记忆架构**：Working（context window 会话内）→Episodic（what happened）→Semantic→Procedural（what to do）；80/20 结构化+向量（精确事实走 JSON/Redis，模糊匹配回退向量）；own the memory（自己控制存储 survive 模型切换）；经验 per-agent（memory.md 在技能目录外，转移技能不转移经验）。
5. **记忆 Consolidation 流水线**：增量扫描会话→consolidate 三型归档；Combine 去重合并按 actor_id+Maintain 合并重叠拆过大；smart memory classification 省 33% LLM call+token-aware；dreaming out-of-band 批处理审 transcripts 提改进。
6. **工作记忆 vs 长期记忆分工**：working 短 KV store recent turns+active task；long-term 向量索引 durable facts/preferences 按需召回与 transient 分开；Context Files 相关会话自动加载+Semantic Search；免整 transcript 注入；按关联强弱分层存储调用。
