## 落地 4 个真独点（全部带提升层）

1. **Gotchas 章节是技能最高信号内容：从常见失败点构建，随时间更新累积** → authoring 1.136.0→**1.137.0**。要点：技能养护主战场=失败点清单；Claude 用技能撞到的坑是最高频不可替代知识；与渐进式披露分工（披露管分层放、本条管层里优先写什么）；反模式：只有怎么做没有别踩什么、Gotchas 不更新不累积、失败点藏折叠线下。提升层：可复用 Skill（技能长期养护/失败知识沉淀）。
2. **压缩后技能重注入有总预算：重注入 invoked skills 按序入窗最老先掉，重要技能靠前保活** → compressor 3.654.0→**3.655.0**。要点：On compaction 重注入已调技能总计预算上限，最老先挤出；技能保活是主动管理（高频靠前/长会话关闲置）；与压缩后规则重声明分工（指令靠重发存活、技能靠重注入预算存活）。提升层：工作流（上下文治理/压缩后恢复）。
3. **错误工作流挂 AI 分析代理 + 错误日志与审计日志分表** → execute 3.58.0→**3.59.0**。要点：Error Trigger 传完整上下文给 LLM 做根因/方案/影响/紧急度分析再格式化告警（告警带分析不带原文）；ErrorLog（workflow/execution ID/error message/failed node 元数据）与 AuditLog（业务事件）分表防噪声稀释；与错误原因逐条可达（WB 已落）互补。提升层：工作流（错误后处理/可观测性）。
4. **flaky 测试治理四招：非确定性输出固定种子/mock 随机/snapshot，环境与数据隔离** → execute 3.59.0。要点：先稳测试再测系统；API rate limits mock 外部调用；环境漂移 Docker/IaC 测试生产对等；测试数据严格隔离防泄进生产（双向）；与代表性失败清单分工（清单管场景选择、本条管执行质量）。提升层：工作流（测试稳定化/CI 纪律）。
