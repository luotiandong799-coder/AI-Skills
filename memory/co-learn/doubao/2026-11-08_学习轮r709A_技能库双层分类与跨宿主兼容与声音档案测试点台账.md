## 四、本轮落地点（4 点，跨 3 技能）

### ① 技能库按「加载面」分两桶：DAILY / LIBRARY，每条 DAILY 必须有仓库证据
- 来源：`affaan-m/ECC`·`.agents/skills/agent-sort/SKILL.md` 5,911B（2026-11-08 一手 contents API 实拉，逐串命中 `Every DAILY decision must cite concrete repo evidence` / `LIBRARY does not mean "delete"` / `Do not duplicate every skill body inside the router`）
- 方法：两桶定义 → 五列证据表（路径/类型/分桶/仓库证据/理由）→ 升 DAILY 三条判据 + 降 LIBRARY 三条判据 → 路由技能只放导航 → 落装后四点复核。
- **提升层：工具 + 工作流**（71 个技能全量常驻，是按 description 在每个会话里为每个 off-stack 技能付费）
- 落点：`engineering/wb-skill-authoring` · KB `## r709A · ①`

### ② 跨宿主投影兼容：结构校验通过 ≠ 在另一个宿主跑得起来
- 来源：`affaan-m/ECC`·`.agents/skills/skill-host-compat/SKILL.md` 3,771B（逐串命中 `Codex leaves those tokens as literal text` / `Codex copy may only use name, description, metadata, license, and allowed-tools` / `Do not treat a passing validate-skills.js run`）
- 方法：宿主变量在别宿主变字面量（静默空结果）→ 投影副本 frontmatter 白名单 → 结构校验只证明文件在，跨树一致性单独跑 → 未实测宿主标 `not-tested`。
- **提升层：工具 + 可复用 Skill**（同一技能多宿主＝同一脚本多套变量语义）
- 落点：同技能 KB `## r709A · ②`

### ③ 声音档案：把「像谁在写」做成可复用结构化产物
- 来源：`affaan-m/ECC`·`.agents/skills/brand-voice/SKILL.md` 3,637B + `article-writing` 2,915B（逐串命中 `5 to 20 representative samples` / `Do not use generic platform exemplars as source material` / `what the author never does` / `Operational reuse`）
- 方法：样本四档优先级（近期原创帖 > 文章/发布说明 > 真发出去的邮件私信 > 站点文案）→ 5–20 份、公开与私下分开 → 九维提取（含「作者从不做什么」）→ 输出短小 `VOICE PROFILE` 块供下游消费 → 八条硬禁 → 不把声纹写进仓库跟踪文件。
- **提升层：工作流 + 模型**（写作品质的稳定化，替代每次重新贴样本猜风格）
- 落点：`writing/wb-doc-writing` · KB `## r709A`；与 §〇 文风锁定的分工写进同节

### ④ 测试点台账：绿 CI 只证明跑过，不证明覆盖到了
- 来源：`affaan-m/ECC`·`.agents/skills/test-collaboration/SKILL.md` 11,111B（逐串命中 `TEST-ORDER-001` / `missing, in progress, unverified, covered, or not applicable` / `"Hard to test" is not a reason` / `Without a TEST-ID or an explicit manual exit, the defect is not fully closed` / `Separate green client and server tests do not prove compatibility`）
- 方法：稳定 ID + 五态；台账只回答「哪条证据证明了它」，成功标准留 Spec 单源；缺陷关闭须 ID 或显式人工出口；跨边界合同用一条 ID 串 contract/consumer/provider/integration 四层；covered 前五查；重扫按事件不按日历。
- **提升层：工作流 + 工具**（把「这次验证过了」升级成「以后还会被挡住」）
- 落点：`engineering/wb-artifact-verification` · KB `## r709A`
