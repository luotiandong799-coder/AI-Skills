# 2026-09-22 学习轮 r123-B（记忆写入工程 + 结构化输出与工具评测 + 重规划与 RAG 输出纪律 · 10 次实拉 · 落地 6 独点）

批前基准：WB r132 + r123-A 批（D96-D100）+ r122 批 D83-D95。B 角度=执行侧可靠性（记忆/结构化输出/重规划/RAG 输出）。

## 10 次实拉（逐站留痕）
1. 记忆写入（强）：**Read 在关键路径，Write 出关键路径**（响应发出后异步写，p50 有界，记忆最终一致）；write-at-end（会话开始加载 LTM+最近 3 episode 摘要进 prompt，会话结束跑摘要写 LTM）；**分级写入：Always write（关键决策/用户偏好/错误与解法/新事实）／Write if significant（新颖信息/对既有理解的修改）／Never write（常规确认/重复步骤/已有信息/填充轮）**
2. 结构化输出失败（强）：**失败五类=截断（max_tokens 太低中 JSON 截断——须当独立错误类处理，别和解析失败混）/refusal（安全拒绝返回 refusal flag，生产管线必须显式检查）/schema 幻觉（凭空加字段/漏必填）/类型强制（"42" 字符串 vs 整数）/语义错误（格式对值错）**；Structured Outputs 保证形状不保证内容（schema-valid but useless）；约束解码是唯一可靠路径
3. 计划验证（强）：**重规划触发条件 9 项（关键前提为假/必需数据不可得/依赖改变/用户目标约束改变/验证器拒绝/工具不可用/剩余预算不足/重复局部修复失败/新高危风险）**；**局部修复 vs 全局重规划**（objective 仍有效+单步失败+有 fallback→局部修复；基本假设错/世界状态大变/级联失败→全量重规划）；**Plan Diff Verification**（重规划后由独立验证器审查新计划：是否解决实际失败、是否保留原目标约束）；计划生成后执行前独立校验器查每步参数完整性
4. Chunking（中）：36 方法/6 域/5 嵌入/1080 配置对照，content-aware 显著优于固定长度；recursive（\n\n→\n→.→space）端到端基准常胜（快/便宜/无额外模型）；semantic 适合非结构化散文但嵌入每句成本高——判不落（recursive 默认是常识级，独点弱）
5. 动态 few-shot（中-强）：**示例选择多样性覆盖边界>数量**（3 个精心选：简单/缺字段/歧义，优于多个相似）；20+ 示例时按输入语义检索 K 个动态注入（静态示例不抗分布漂移）；few-shot 可提升 20-50% vs zero-shot（格式/细微需求）
6. 系统提示结构（中）：四/五层（identity→behavioral→output contract→guardrails）；500 词以上中间三分之一约束最先失效——与 D95 块位置同原理应用于 system prompt 内部，判不落（同源应用）
7. 失败恢复（中）：四级渐进升级 self-correct→fallback→degrade gracefully→escalate；错误分类驱动恢复（transient 重试/LLM 可恢复反馈给模型/需人工暂停）——与 D89 恢复重试语境重叠>60%，判不落
8. RAG 输出纪律（强）：**三条指令承载大部分重量：只从提供上下文回答／每个主张都要引用来源／上下文没有答案就拒绝**（refusal 路径最常被跳过、却拦住最糟失败）；**claim-level 评估优于 answer-level**（answer-level groundedness 是 vibe check；claim 分解+逐 claim 评分+对未用 chunk 做矛盾扫描）；**语言指标（ROUGE/BERTScore）与事实接地会背离**（高分来自参数记忆而非检索上下文）
9. 工具调用评测（强）：**四步合同=call-or-no-call（10-15% no-call 切片测"不该调时别调"）→tool selection（函数名匹配）→argument construction（schema 有效+语义接地）→execution（真实运行）**；**工具数量衰减：5 工具 85-91%、20+ 工具 65-78%、>50 断崖**（支持每请求只注入相关子集）；**参数不匹配占 60-75% 调用失败，比选错工具更常见**；AST 比较防改写函数名糊弄
10. 平台/生态探活：Agent Skills 2025-12 开源标准（SKILL.md+skills-ref 验证库+agentskills.io，微软 48h 集成）；预置文档技能+consolidate-memory+skill-creator——平台生态，判不落
