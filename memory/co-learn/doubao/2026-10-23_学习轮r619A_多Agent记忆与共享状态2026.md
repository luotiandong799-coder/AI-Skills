## 四、提炼核心方法与关键事实

1. **状态三态分离**：per-agent（最小化会话历史）/shared（显式数据结构的工作产物）/global（orchestrator 拥有任务状态）。
2. **累加语义防覆盖**：Blackboard Pattern TeamState+operator.add 自动合并；claims+supersedes 共享文件（写侧单一函数）。
3. **最小充分状态切片+写所有权**：每个 agent 从最便宜层取最小切片、清晰写所有权。
4. **持久化执行形态**：每 turn 快照（ChatSnapshot S3）；checkpoint-resume+idempotency keys 复用子任务（第 9 步失败不重做前 8 步）；delta 增量存储；无 storage 即不跨 run。
5. **记忆生命周期**：Dreaming 定时策展；MemPalace 写一次处处读；Council v2 每 subagent 全新 context；Agensh 去中心 1024 agents。
6. **写入治理**：SVAF gate 写入时过滤；Phase 3 Problem 连接即 7-29% PII 泄漏；判据五条+三域用例。
7. **会话语义**：共享环境+context-isolated session threads；subagent thread 持久；Session=stateful execution+双 durable streams；A2A 协议发现。
8. **编排协议**：冷归档+动态推理；Nexus 只规划不干活；Agent Skills 战略分布；fold subagents into main loop。
