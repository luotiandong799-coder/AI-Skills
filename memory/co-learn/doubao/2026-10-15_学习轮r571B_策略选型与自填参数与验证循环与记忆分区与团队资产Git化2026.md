## 落地（compressor 3.678.0 → 3.679.0，+3 章）

1. **记忆分区与隐私：scope 按用户分区 + 共享禁存个人信息 + session_id 自定义隔离**（来源：Microsoft Foundry《Memory usage》2026-10-11 + Langflow docs《Agent memory》2026-10-04）

   - External memory=结构化数据跨 run 检索；Procedural memory=编码进指令/微调（怎么想不靠检索）
   - **提升层**：可复用 Skill
