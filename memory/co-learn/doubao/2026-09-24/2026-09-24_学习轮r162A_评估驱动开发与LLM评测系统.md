## 二、独点清单 + 判非重复理由（7 点，均≥40% 独有增量）

### 1. 最小评测四件套与六层 Playbook（来源：Precision AI Academy 2026-07-31 + Future AGI 2026-04-12 实拉）
**versioned 输入+scorer+runner+CI 阈值挡 merge——四件齐才能周五改 prompt；六层（dataset/metrics/judge/CI gate/生产观察/闭环），只建三件=dataset+judge+gate**。
- 判非重复：r160A 落测试工程（金字塔/三态门）；本点=**评测基建最小件数**（评测面）。增量≥65%。
- 提升层：工作流（评测基建）。

### 2. 评测就绪清单（来源：LangChain 2026-03-27 实拉）
**任务无歧义+参考解证明可解；正负用例都测；按 agent 类型定制数据集；无生产数据时生成 seed 例子；来源=dogfooding 错误+改编外部基准**。
- 判非重复：r159C 落评测集组成桶；本点=**评测集就绪判据清单**（准备面）。增量≥55%。
- 提升层：工作流（评测集治理）。

### 3. 评测闭环与生命周期定位（来源：Future AGI 2026-03-21 + LangChain 2026-03-10 实拉）
**offline→CI→trace→error feed→optimization 闭环；eval 当静态端点=agent 漂移，当循环=复利；最有用两点=发布前抓回归+发布后抓 drift**。
- 判非重复：r159C 飞轮管数据侧；本点=**评测循环**（评测侧）。重叠<60%，增量≥50%，合并保留增量落地。
- 提升层：工作流（评测运营）。

### 4. RAG 评测指标组与 Faithfulness 分解（来源：Microsoft 2026-06-03 + RAGAS + LangChain 2026-04-08 实拉）
**Groundedness/Relevance/Completeness；Faithfulness=RAGAS 分解原子声明算上下文支持比例（低=幻觉）；answer 可忠实却漏所问（faithful≠relevant）**。
- 判非重复：r160C 落 RAG 生产架构（检索面）；本点=**RAG 评测指标语义**（评测面）。增量≥70%。
- 提升层：工具（指标体系）。

### 5. Agent 轨迹评测三维（来源：Mastra 2026-06-22 + Future AGI 2026-05-14 实拉）
**序列合逻辑/避免不必要动作/中间决策基于可用上下文；安全关键=答案对但读了不该读的数据=合规风险；工具三维=selection/parameter/调用序**。
- 判非重复：r160A 落黄金 trace 重放（测试面）；本点=**轨迹质量维度**（评测面）。增量≥60%。
- 提升层：工作流（轨迹评测）。

### 6. Judge 校准纪律与 Rubric 四性质（来源：Chanl 2026-06-20 + QASkills.sh 2026-06-21 + Mavik 2026-01-27 实拉）
**50 例 judge vs 双人评分算 inter-rater >0.7 才可用；tone 最先分歧；rubric 四性质=分解命名/每级具体定义（'5=答案…'非'5=excellent'）/独立评分/可审计证据**。
- 判非重复：r160A 落 Welch's t-test（统计面）；本点=**judge 校准与 rubric 写作**（方法面）。增量≥65%。
- 提升层：工具（评测方法）。

### 7. 评估驱动提示迭代（来源：arXiv 2601.22025 + GitHub Blog 2026-08-25 + arXiv 2311.11123 实拉）
**通用规则追加不单调改善（强输出契约升严格提取但 RAG 引用合规降 26/30→9/30）；单变量验证（prompt 与模型升级分开测）；prompt 与评估配置像代码一样版本化；不同 API 最优 prompt 不同**。
- 判非重复：全库无提示迭代验证纪律面（r158A 落提示词工程但管结构）。增量≥80%。
- 提升层：工作流（提示迭代）。
