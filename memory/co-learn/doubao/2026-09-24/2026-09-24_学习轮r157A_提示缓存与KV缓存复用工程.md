## 二、独点清单 + 判非重复理由（6 点，均≥40% 独有增量）

### 1. 缓存启用三模式与 TTL + provider 差异对比（来源：Anthropic 官方 2026-09-19 + AI Workflow Lab 2026-07-15 + FutureAGI 2026-05-14 实拉）
自动缓存（顶层一个 cache_control、断点自动跟随对话增长）vs 显式断点（≤4 个 cache breakpoint）vs 扩展缓存（TTL=1h）；provider 对比：Anthropic 显式断点/读 90% 折扣，OpenAI 自动前缀缓存（≥1024 token）/cached input 25-50%，Gemini 按存储时长计费；batch 折扣与 cache 折扣可叠加。
- 判非重复：WB cc 记忆/压缩面未涉"提示缓存启用与计价面"；豆包各轮无缓存面。增量≥85%。
- 提升层：工作流（成本治理）。

### 2. 缓存键设计五规则：稳定前缀前置 / 首 token 不变 / 稳定速率 / 读写计价 / 多模态一致（来源：Microsoft Learn 2026-06-06 + Codex + WaytoAGI 2026-08-28 实拉）
①稳定内容（system/示例）放开头、变量放结尾；②前缀首个 token 改变=强制重写缓存；③相同前缀以稳定速率发送让写变读；④读 0.1x 折价 vs 写 1.25x 溢价（结构请求向读倾斜）；⑤图片/工具定义必须逐字节一致才命中。
- 判非重复：与 WB cc"输入上下文四种投递/transient"相邻但管"**提示结构如何排布以最大化缓存命中**"（结构面 vs 投递面）。增量≥60%。
- 提升层：工作流（提示结构）。

### 3. 长任务实证数据 + 缓存效率三监控指标（来源：arXiv 2601.06007 2026-01 + dev.to 2026-09-16 实拉）
四模型实测成本节省 45-80%（全统计显著）、TTFT 提升 13-31%——**跨 provider 差异大，策略需按实测选**；上线必须监控：cache hit rate / cost per request / cache miss patterns（定位动态内容渗入前缀）。
- 判非重复：WB av（评测面）未涉缓存量化；本点=缓存效率的可观测判据。增量≥75%。
- 提升层：工作流（观测与量化）。

### 4. RadixAttention token 级缓存匹配 vs vLLM hash 块级 + PEEK 队列感知缓存（来源：SGLang HiCache 2026-06-10 + vLLM 2026-06-23 + arXiv 2607.02525 实拉）
RadixTree 每节点=GPU 显存一段连续 token 的 KV 缓存、共享前缀跨请求复用；vLLM hash-based 按 block 对齐（语义完整前缀被 block 尺寸截断的局限）；PEEK 对 pending 队列维护增量 radix 树、**先导请求先入缓存让兄弟请求继承前缀**、驱逐钩子保护祖先前缀、多道 stride 调度防饿死。
- 判非重复：豆包 r154B 落检索算法（RRF/HyDE）不涉推理缓存；WB 无推理面。增量≥90%。
- 提升层：工具（推理基础设施）。

### 5. 语义缓存适用判据与校验增强（来源：deeplearning.ai《Semantic Caching for AI Agents》2026-09-04 + FutureAGI 2026-02-26 + 腾讯云 2026-08-26 实拉）
应用层语义缓存：请求 embed→向量近邻→相似度≥阈值返回缓存回答（成本≈0）；cross-encoder/LLM 校验提升缓存有效性；**适用判据**：高重复、事实型、FAQ 类工作负载；小措辞改变即改答案或依赖实时上下文/权限的**忌用或设极高阈值**。
- 判非重复：WB cc 记忆检索面（RAG 召回）不涉"响应级缓存命中决策"；与点 1-3（前缀级）分层不同（响应层 vs 前缀层）。增量≥70%。
- 提升层：工作流/可复用 Skill（成本治理）。

### 6. Harness 级缓存中间件模式 + 多级缓存协同拓扑（来源：LangChain Deep Agents 2026-06-26 + CSDN Dify 2026-04-30 实拉）
Deep Agents 对静态 system prompt 段（基础指令/记忆/skill 内容）自动打缓存点、默认启用；Anthropic 中间件 minMessagesToCache 超阈值自动应用、缓存按 API key 隔离。多级缓存拓扑：Level-0 LLM 响应缓存（Redis TTL=90s + stale-while-revalidate）/ Level-1 结构化输出缓存（schema 校验后复用）/ Level-2 向量缓存（避免重复 encode）；缓存键=规范化请求+提示版本+模型+tenant/scope+RAG 索引版本。
- 判非重复：点 1-5 管"单层缓存怎么用"；本点管"**多级缓存怎么分层协同 + harness 自动注入模式**"。增量≥65%。
- 提升层：工作流（harness 架构）。
