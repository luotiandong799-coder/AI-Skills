## 二、独点清单 + 判非重复理由（6 点，均≥40% 独有增量）

### 1. 复杂度三级路由 + 工具感知路由（来源：Azure Foundry 2026-09-10 + NVIDIA Switchyard 2026-08-11 + DigitalOcean 2026-06-15 实拉）
低复杂度（事实回忆/问候）→便宜快模型；中复杂度（工具编排）→能生成合法工具调用的中端；高复杂度（研究综合/多步推理/复杂代码）→前沿；**挂工具时路由考虑工具调用能力**；两阶段=SLM 解析意图 + ranking 引擎按实时成本/延迟排序。
- 判非重复：豆包 r157A/B/C、r156 均无模型选型面。增量≥90%。
- 提升层：工作流（路由设计）。

### 2. 级联模式：先便宜后升级、质量阈值门（来源：CometAPI 2026-09-03 + 72tech 2026-08-14 + GingerLabs 2026-06-08 + DistilLabs 2026-06-17 实拉）
级联=先发便宜模型→输出过质量阈值就返回、不过升级强模型（区别于一次性路由）；70% 请求走便宜模型省 41-55%（实测价表）；可选第三 tier 处理 hard 5%；**训练 SLM 知道何时 defer 优于建独立 router（2+2>4）**；代价=升级两次调用加延迟。
- 判非重复：点 1 管"开头选谁"；本点管"**先试后升的决策流与质量门**"。增量≥65%。
- 提升层：工作流（级联设计）。

### 3. 能力向量路由与成本惩罚分发（来源：arXiv HyDRA 2605.17106 + Brick 2606.13241 实拉）
HyDRA：编码器多头 sigmoid 预测 query 的 reasoning/code/debug/tool-use 能力需求→**shortfall matching 选最便宜且能力达标模型**；Brick：六能力维度评分 × 难度估计 + 成本惩罚几何规则，**连续偏好旋钮在质量与省钱间滑动（部署参数非代码）**。
- 判非重复：点 1 管复杂度粗分；本点=**多维能力画像与可调成本偏好**。增量≥70%。
- 提升层：工作流/工具（能力路由）。

### 4. 会话中混合路由：主 agent + sidekick 并行（来源：DEV shaam_ai 2026-09-15 实拉）
hybrid-agent routing=会话中切换而非开头路由一次：**易子任务发给便宜 sidekick 并行、难子任务给前沿主 agent**（Devin Fusion 模式）；易任务不占用前沿上下文与成本。
- 判非重复：与 r155 多 agent 面相邻但当时只落"编排模式概览"；本点=**按难度混合模型的具体分工模式**。增量≥60%。
- 提升层：工作流（混合架构）。

### 5. 跨模型共识评审团：一致=可信、分裂=不可信（来源：arXiv LLM-jury 2607.10139 + Council 2604.02923 + DeepReason 实拉）
LLM-jury：多个独立训练模型各解一次，**一致性是信号——全票=可信答案、分裂=存疑**（无需训练/额外采样）；Council 升级：多数投票把论断二值化丢推理链，**结构化综合保全文、识别分歧原因、评估证据强度**；两层共识幻觉降 90%。
- 判非重复：WB av 落"self-consistency 多路径答案唯一任务"（单模型多采样）；本点=**跨模型共识**（不同模型 = 独立错误源）。增量≥55%。
- 提升层：工作流（验证/共识）。

### 6. 本地 vs 云选型判据（来源：TechTalkClub 2026-04-05 + Microsoft + Xybrid 2026-06-09 + TechEarl 2026-05-18 实拉）
选型六维=延迟（本地毫秒 vs 云 100ms-2s+）/隐私（数据不出设备 vs 外发）/离线/模型能力（SLM 够日常 vs 云强复杂）/成本（零边际 vs 订阅）/电池（本地高 vs 云低）；SLM 1-7B GGUF 量化部署；Ollama 一键本地运行（OpenAI 兼容 API）。
- 判非重复：全库无本地/云部署选型面。增量≥90%。
- 提升层：工作流（部署选型）。
