## 二、独点清单 + 判非重复理由（7 点，均≥40% 独有增量）

### 1. 五个杠杆与全局不变量（来源：Stanford CS224G 2026 实拉）
**Personas/Tools/RAG/Uploads/Prompt 五杠杆全用；全局不变量放 personas 层不每条重复**。
- 判非重复：mts 管输出侧省 token；本点=**输入侧杠杆组合+不变量放置**。增量≥85%。
- 提升层：工作流（上下文设计）。

### 2. U 形上下文布局（来源：AI Workflow Lab 2026-06-26 实拉）
**关键信息按 U 曲线放开头/结尾，中间填静态缓存内容；hybrid→reranker 8-20 chunk→U 形放置**。
- 判非重复：r164A 落重排门（检索质量）；本点=**上下文放置**（lost in the middle 应对）。增量≥75%。
- 提升层：工作流（上下文布局）。

### 3. 隔离模式与子 agent 蒸馏（来源：n8n 2026-07-07 + danilchenko 2026-07-28 实拉）
**巨型窗口拆隔离小窗口只传最终输出；子 agent 干净窗跑聚焦任务返回 1000-2000 token 蒸馏摘要；坏假设不级联**。
- 判非重复：r163B 落多 agent 协议；本点=**隔离/蒸馏纪律（token 侧）**。增量≥70%。
- 提升层：工作流（上下文隔离）。

### 4. 提示缓存三形态与折扣数据（来源：IntuitionLabs 2026-09 + Claude Docs + LangChain 2026-06-26 实拉）
**自动缓存/显式 breakpoint（5min-1h TTL）；Anthropic 90%/OpenAI 50%/Gemini 75%；GPT-5.6 显式缓存 90%+30 分钟；agent 轨迹省 49-80%**。
- 判非重复：cc 落压缩（内容层）；本点=**缓存（成本层）**。增量≥90%。
- 提升层：工具（成本优化）。

### 5. token 预算系统与断路器（来源：Kinda Technical 2026-03-01 + Kunal 2026-07-12 实拉）
**per-user/feature TokenBudgetManager；agent 循环=硬预算+迭代上限+确定性路由+渐进加载+财务断路器**。
- 判非重复：mts 落成本四层（写省）；本点=**执行期预算治理**。增量≥70%。
- 提升层：工作流（预算治理）。

### 6. TALE token 预算感知推理（来源：arXiv 2412.18547 实拉）
**按问题复杂度动态调推理 token；简单查找短答难题给空间；预算写进 prompt；轨迹常过长可压缩**。
- 判非重复：mts 落"简单任务不堆砌思考"原则；本点=**动态预算机制+方法名可查**。增量≥65%，合并保留增量落地。
- 提升层：模型（推理预算）。

### 7. 五策略对照表（来源：NeuralTrust 2026-07-21 实拉）
**sliding 40-70%/摘要 30-60%/RAG 压缩 50-80%/pruning 20-50%/strategic placement 零成本质量增益**。
- 判非重复：cc 落预算管理原则；本点=**策略×量化对照**。增量≥60%，合并保留增量落地。
- 提升层：工具（策略选型）。
