## 二、独点清单 + 判非重复理由（7 点，均≥40% 独有增量）

### 1. A2A 协议核心（来源：a2aprotocol.ai 2026-09-23 + Spec v0.2.0 实拉）
**Agent Card 能力描述符发现（/.well-known/agent-card.json）+ JSON-RPC/HTTP/SSE 三接口+同步/异步/流式+完整任务生命周期；Google 发起 50 伙伴 Linux 基金会**。
- 判非重复：r159B 落 MCP 面；A2A 为独立协议全库无。增量≥90%。
- 提升层：工具（互操作协议）。

### 2. MCP 2026-07-28 大改版增量（来源：MCP Blog 2026-07-28 + AI Buzz 实拉）
**无状态核心（去会话→普通 HTTP 横向扩展）+OAuth 2.1 加固+正式扩展框架（MCP Apps UI+Tasks 长任务）+12 个月弃用窗口+Ratios/Sampling/Logging 弃用**。
- 判非重复：r159B 落早期 MCP 设计；本点=**2026-07-28 后发大改版**，后发版本必覆盖旧信息。增量≥85%。
- 提升层：工具（协议演进）。

### 3. A2A vs MCP 决策点（来源：IEEE 2026-05-20 实拉）
**A2A=agentic 版消息中间件（异步结构化消息），管 agent 协调；MCP 管 agent 调工具；A2A 适合对等体委托/交接/协商责任**。
- 判非重复：r159B 管 MCP 单侧；本点=**双协议分工判据**。增量≥75%。
- 提升层：工具（协议选型）。

### 4. 编排模式与 supervisor 失败共性（来源：QubitTool 2026-05-21 + Velocity 2026-05-22 实拉）
**supervisor（确定性管道）/swarm（动态对话对等交接）/hierarchical（大企业多级树）；supervisor 失败共性=路由逻辑在 prompt、无试过记忆、同任务死循环**。
- 判非重复：r161B 落框架对比；本点=**模式选择判据+失败诊断**。重叠<55%，增量≥60%，合并保留增量落地。
- 提升层：工作流（编排选型与排障）。

### 5. Supervisor 成本分工三角（来源：GitLab ombharatiya 2026-05-14 实拉）
**supervisor=高推理模型分解委派；workers=快低成本模型干活；reviewer=独立 agent 对照原计划验证合并输出**。
- 判非重复：r158B 落路由机制；本点=**三角色成本分工模板**。增量≥65%。
- 提升层：工作流（多 agent 成本结构）。

### 6. 协议治理缺口与补充协议（来源：arXiv 2606.31498 实拉）
**MCP/A2A/ACP 表达不了的治理缺口；ANP=图路由+去中心身份；ERC-8004=链上身份/声誉/验证注册表**。
- 判非重复：全库无协议治理缺口面。增量≥90%。
- 提升层：工具（治理评估）。

### 7. 互操作协议五维分类（来源：arXiv 2606.19135 实拉）
**五维=对端/载荷/交互状态/发现机制/schema 灵活性；A2A 协议普遍混合 payload+会话持久；去中心发现罕见；收敛压力=统一 agent-to-agent 与 agent-to-context**。
- 判非重复：全库无协议分类学面。增量≥90%。
