## 二、独点清单 + 判非重复理由（7 点，均≥40% 独有增量）

### 1. 可靠性三支柱（来源：ai-tldr 2026-06-12 实拉）
**JSON schema + 纯英文 description + loop 错误处理——三处对了，模型就选对函数、给对参数、失败优雅恢复**。
- 判非重复：WB 落重试分类；本点=**可靠性归因框架**。增量≥70%。
- 提升层：工作流（工具调用设计）。

### 2. 错误作数据+单行+带理由重试（来源：chenk.top + developersdigest 实拉）
**不抛异常不展示 stack trace；单行错误喂回；重试带理由块说明改了什么**。
- 判非重复：WB 落重试分类；本点=**错误回喂形态**。增量≥65%，合并保留增量落地。
- 提升层：工作流（错误回喂）。

### 3. 自修复闭环 80%（来源：dev.to aiwave 2026-07-30 实拉）
**验证失败错误作 tool response 喂回，模型第二次自修参数错误 80%**。
- 判非重复：全库无此量化数据。增量≥85%。
- 提升层：工作流（自修复）。

### 4. 确定性幂等键派生（来源：dreaming.press + chiraghasija 2026-07 实拉）
**sha256(run_id+json sort_keys) 调用前派生；网络重试+模型重发都 dedupe；邮件先查 sent API 不只信请求路径**。
- 判非重复：WB 落"写操作幂等配幂等键"原则；本点=**派生算法+邮件 sent-API 反查**。增量≥55%，合并保留增量落地。
- 提升层：工具（幂等）。

### 5. 三类错误分类恢复+封顶（来源：zylos + aicassindra 实拉）
**transient 退避/persistent 升级不烧钱/validation 自修；总尝试+时间+成本封顶；terminal 错误显式标记**。
- 判非重复：WB 落 transport/tool 二分；本点=**三类+封顶+terminal 标记**。增量≥60%，合并保留增量落地。
- 提升层：工作流（恢复策略）。

### 6. verify-before-retry postcondition（来源：arXiv 2608.02645 实拉）
**不确定结果先查 postcondition 是否已满足；已成功不重试，未成功带证据重试；不改 LLM**。
- 判非重复：WB 落"断连后先查是否已生效"；本点=**postcondition 包装器+量化**。增量≥50%，合并保留增量落地。
- 提升层：工具（重试前验证）。

### 7. MCP 命名描述七原则+strict CFG（来源：kansei-link + stochasticsandbox 实拉）
**verb+noun 无缩写/200-400 字含 do not use for X/enum+required 激进/完全限定名；strict=true CFG mask logits 物理禁非法 token；JSON mode≠schema 合规**。
- 判非重复：全库无 MCP 命名/strict CFG 面。增量≥90%。
- 提升层：可复用 Skill（工具定义纪律）。
