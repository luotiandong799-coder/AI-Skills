## 二、独点清单 + 判非重复理由（7 点，均≥40% 独有增量）

### 1. 结构化输出三档（来源：Precision AI Academy 2026-04-16 + AIPromptsHub 2026-06-27 实拉）
**自由文本 JSON=不可预测失败；schema 约束=结构确定性；strict=True=采样器约束 token 流可证明符合；Anthropic 无 strict 用 tool_use input_schema 同保证**。
- 判非重复：r159B 落 MCP 工具面；本点=**provider 结构化输出原生能力档位**（输出面）。增量≥75%。
- 提升层：工具（输出契约）。

### 2. Schema 关键约束与严格模式子集（来源：explainx 2026-06-27 + Jatin Bansal 2026-05-17 实拉）
**required/additionalProperties:false/enum 三约束；严格模式只收 JSON Schema 子集（递归限制）；首请求编译 100-500ms 后缓存**。
- 判非重复：点 1 管档位；本点=**schema 写作细则**。增量≥65%。
- 提升层：工具（schema 工程）。

### 3. 推理模型提示六槽（来源：SurePrompts 2026-07-30 实拉）
**对推理模型"think step by step"/persona 堆叠/few-shot=噪音（模型已在做）；填六槽=goal/constraints/context/audience+shape/reasoning budget/evaluation criteria；忘槽=通用默认太浅**。
- 判非重复：r158A 落普通模型提示工程；本点=**推理模型时代提示**（新范式）。增量≥70%。
- 提升层：工作流（推理模型提示）。

### 4. 温度按任务分档与基线测方（来源：SurePrompts 2026-07-30 + Future AGI 2026-08-10 实拉）
**代码=0-0.3 默认 0；JSON=0-0.2；事实=0.2；聊天=0.7；创作=1.0+；1.5+ 长尾劣化；调参前 10 prompt×20 次测基线方差**。
- 判非重复：全库无温度分档面（cc/mts 管 token 非采样参数）。增量≥85%。
- 提升层：工具（采样参数）。

### 5. Context Engineering 范式（来源：Zylos 2026-06-20 + MasterPrompting 2026-04-15 实拉）
**Prompt 工程=写时静态问措辞；Context 工程=运行时动态问'模型现在需要知道什么'+查询时检索+为生产长会话设计**。
- 判非重复：cc 落预算管理（操作面）；本点=**范式定位与维度对比**（方法论面）。增量≥60%。
- 提升层：工作流（上下文范式）。

### 6. 上下文运行时与记忆注入时机（来源：AI Cost Check 2026-07-26 + OpenAI Cookbook 实拉）
**Claude Code 系统 prompt 减 80%；上下文=可 hack 运行时，生命周期钩子 before_agent_start 做动态注入；记忆注入在 context trimming 后 agent 开始前**。
- 判非重复：cc 落压缩策略；本点=**运行时钩子与注入时机**（执行面）。增量≥65%。
- 提升层：工作流（上下文运行时）。

### 7. Agentic 上下文自主判据（来源：explainx 2026-06-28 实拉）
**自主=可逆动作+源于先前指令+范围限指定文件；停下问=删/覆盖未提及文件+计划不匹配意图+错误改变范围**。
