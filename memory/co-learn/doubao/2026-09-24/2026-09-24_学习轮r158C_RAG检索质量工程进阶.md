## 二、独点清单 + 判非重复理由（5 点，均≥40% 独有增量）

### 1. 查询改写三策略与使用判据（来源：LLM Systems Cookbook 2026-07-13 + Learnixo 2026-05-16 + Qiita 2026-04-15 + SemEval AKCIT 实拉）
HyDE（LLM 生成假想回答再嵌入——与真实答案文档共享词汇）/ Multi-query（3-5 查询变体）/ decomposition（复合问题拆子查询）；使用判据=抽象问题用 HyDE、横断型复合问题用分解；**改写非对所有模型受益**（Qwen 增益、BGE-M3 全降——同改写引入分布偏移）。
- 判非重复：r156-A 落索引层（分层索引/块大小）；本点=**检索前的查询侧处理**（查询面 vs 索引面）。增量≥75%。
- 提升层：工作流（查询工程）。

### 2. 索引期 HyDE 变体：question-question 匹配零延迟（来源：arXiv HyPE 2607.29402 2026-08-25 实拉）
HyPE 把假想内容生成移到索引期：为每块预计算多个假想 prompt、用 prompt 替代块嵌入——检索变 question-question 匹配，**保留 HyDE 对齐收益且无运行时合成延迟**。
- 判非重复：点 1 管运行时改写；本点=**索引期预计算变体**（部署面）。增量≥80%。
- 提升层：工作流（索引设计）。

### 3. Reranker 分数校准纪律（来源：Redis 2026-08-06 + WickedSmart 2026-08-29 + ScoreGate 2606.14269 实拉）
reranker 分数是相对序不是绝对相关——**0.7 跨模型不可比，换 reranker 必须重校准阈值**；领域不匹配时相关/不相关分数几乎相同；实践管线=初始宽召回 top-25 → cross-encoder rerank → final top-4 + score_threshold 0.3；双分数统计融合需按域重导阈值；**强 reranker 在位时仅 query expansion 与 per-source 校准阈值有可靠增益**。
- 判非重复：r156-A 未落 rerank 校准面（ColBERT 判用不上）；本点=**排序后的分数语义与阈值纪律**。增量≥70%。
- 提升层：工作流（排序校准）。

### 4. 引用与实体幻觉检测（来源：CiteCheck 2605.27700 + FACTUM 2601.05866 + EAEV ACL 2026 实拉）
CiteCheck=检索外部真实文献 + 结构化 LLM 验证器比对→Exact/Minor/Major 三标签；FACTUM=四机制分数（contextual alignment/attention sink/parametric force/pathway）——正确引用有更高 parametric force；EAEV=实体级对齐三维度+反事实稳定性；RAGAS faithfulness=断言被源支持比例。
- 判非重复：WB av 落"生成物验证/self-consistency"；本点=**检索落地后的引用真实性验证**（cite 面）。增量≥55%。
- 提升层：工作流（输出验证）。

### 5. 检索质量指标体系（来源：StratRAG 2604.22757 + Azure RAG evaluators 2026-06-03 + arXiv 2504.14891 实拉）
Recall@K / MRR / NDCG@5 三件套（gold 文档命中率/首个命中倒数排名/前 5 折损增益）；**Azure Fidelity 补充面：top-n 检索块对 query 的内容反映程度**（好文档数/已知好文档总数）——测"检索到的好东西占比"而非排名；多跳 QA 另加 efficiency 指标。
- 判非重复：点 3 管分数校准；本点=**检索质量的度量体系**（评测面）。增量≥65%。
- 提升层：工作流（度量）。
