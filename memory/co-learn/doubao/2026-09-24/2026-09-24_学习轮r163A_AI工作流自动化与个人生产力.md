## 二、独点清单 + 判非重复理由（7 点，均≥40% 独有增量）

### 1. AI 自动化候选三特征（来源：Make 2026-05-21 实拉）
**每周跑≥10 次/需人读自由文本输入/输出结构化——三条中两条符合才值得 AI 自动化；不是每个流程都该自动化**。
- 判非重复：全库无自动化价值预筛面。增量≥90%。
- 提升层：工作流（自动化选型）。

### 2. 确定性管道+单 AI 步骤（来源：n8n Solutions 2026-06-05 + Ocade 2026-04-03 实拉）
**工作流=常规节点为主+唯一需判断处放 AI 节点——大多数情况正确答案；单任务 agent=3-5 工具清晰边界**。
- 判非重复：r160B 落通用拓扑模式；本点=**工作流内 AI 最小注入**（自动化面）。增量≥65%。
- 提升层：工作流（工作流设计）。

### 3. 预处理→AI→后校验三明治与显式回退（来源：n8n Playbook 2026-04-02 + AI Workflow Lab 2026-07-04 实拉）
**Set 节点归一化输入+统一 schema → AI 步骤 → JSON schema 校验/guardrails/落库；分类失败默认"需人审"、生成失败回退模板，绝不让失败 AI 步骤静默破坏工作流**。
- 判非重复：r162A 落评测门（前置面）；本点=**工作流内校验与回退结构**（执行面）。增量≥70%。
- 提升层：工作流（可靠性结构）。

### 4. 代理失败四大件与端到端可靠性（来源：Supergood 2026-03-08 + MetaCTO 2026-05-14 实拉）
**98%×5 agent≈90% 端到端（无容错）；四件=退避+jitter/熔断器/dead letter queue 人审/幂等动作；只重试瞬时失败不重试逻辑错误**。
- 判非重复：ed 已落单工具重试纪律（transport/tool 分类+幂等）；本点=**工作流级端到端**（熔断器/DLQ/端到端乘法计算是 ed 无的增量）。重叠<60%，增量≥55%，合并保留增量落地。
- 提升层：工作流（端到端容错）。

### 5. 工作流平台选择矩阵（来源：Zapier 2026-07-29 + ToolChase 2026-09-01 实拉）
**Zapier=安全构建 9000+ 应用；Make=复杂分支+错误处理；n8n=免费自托管无限工作流；Pipedream=开发者 API 集成；按工作方式匹配**。
- 判非重复：全库无平台选型矩阵面。增量≥85%。
- 提升层：工具（平台选型）。

### 6. n8n Agents 一次定义随处用（来源：n8n Community 2026-09-11 实拉）
**agent 定义一次可用四处（直接聊/作节点/连 Slack/跑定时）；区别于工作流内 AI Agent 节点**。
- 判非重复：r161B 落框架选型；本点=**agent 实体可复用范式**（平台面）。增量≥60%。
- 提升层：工具（agent 复用）。

### 7. Claude 定时产品双形态与三触发（来源：HatchWorks 2026-06-02 实拉）
**Cowork Scheduled Tasks=知识工作者定时跑 prompt 带全工具与 Skills；Code Routines=工程向三触发（定时/webhook/GitHub 事件）叠加；把 agent 从召唤物变常驻进程**。
- 判非重复：wb-execute-discipline 已落定时记账判据（排期语义）；本点=**定时 agent 产品形态**（触发面）。重叠<50%，增量≥60%，合并保留增量落地。
- 提升层：工作流（定时 agent 化）。
