## 二、独点清单 + 判非重复理由（7 点，均≥40% 独有增量）

### 1. outcome 先 trajectory 后 + 双 suite（来源：precisionaiacademy + arize 实拉）
**先结果分后步骤分；regression suite 护既有行为 vs capability suite 探新能力分开**。
- 判非重复：WB 落闭合邻域/消融基线；本点=**分层打分+双 suite 分工**。增量≥70%。
- 提升层：工作流（评测编排）。

### 2. judge 校准集 50-200 人标（来源：MLflow 2026-05-21 实拉）
**每次换 judge 模型/rubric 重跑 agreement；否则在 noise 上 gate**。
- 判非重复：全库无校准集规模与节奏。增量≥80%。
- 提升层：工作流（judge 治理）。

### 3. LLM-judge 偏见量化（来源：arXiv 2606.13685/2607.12885/2601.07506 实拉）
**agreement 76%/κ=0.51；语义等价 prompt 翻 25%；11-15 次投票稳；无 ref 过度宽容加 ref 翻 85%；swap ref 被参数知识带偏**。
- 判非重复：全库无此量化数据。增量≥90%。
- 提升层：工作流（judge 可信度边界）。

### 4. eval 两死法（来源：montecarlo 2026-08-25 实拉）
**stale 测试集仍报绿；judge 给自己作业打分内部一致但偏人**。
- 判非重复：全库无此失败模式清单。增量≥85%。
- 提升层：工作流（eval 反模式）。

### 5. 读 transcript 判真错 vs 误杀（来源：Anthropic engineering 2026-01-09 实拉）
**失败时读 transcript 区分 agent 真错 vs grader 误杀合法解；失败必须看起来公平**。
- 判非重复：WB 落双向计分板；本点=**失败归因人工读判**。增量≥70%。
- 提升层：工作流（失败归因）。

### 6. golden set 四要素+bug 加集（来源：businesstechnavigator + Google codelabs 实拉）
**input/context/expected trajectory/expected output 四要素；每个新 bug 变新 case；20-50 起步**。
- 判非重复：WB 落消融基线归任务集；本点=**case 结构+增长机制**。增量≥65%，合并保留增量落地。
- 提升层：可复用 Skill（回归集工程）。

### 7. 可观测信号与五层模型（来源：futureagi + arXiv 2604.26152 实拉）
**trace coverage≥99% 关键路径；span completeness 三字段；五层=校准/probe/CoT monitor/云运维/非侵入 trace；传统日志对幻觉循环无用**。
- 判非重复：全库无可观测信号面。增量≥85%。
- 提升层：工具（生产监控）。
