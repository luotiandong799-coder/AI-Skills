## 二、独点清单 + 判非重复理由（6 点，均≥40% 独有增量）

### 1. MCP 客户端工具管理三纪律：多级细节 / 定义缓存 / list_changed 刷新（来源：MCP 官方 client best practices 2026-07-28 实拉）
工具定义按需提供多级细节（仅名/名+描述/全 schema，由模型自选）；host 侧缓存定义避免重复 tools/list 往返；server 发 list_changed 通知时重索引搜索目录。
- 判非重复：WB cc 工具面安全管"描述注入/同名拦截/最小权限"（安全）；本点管"**客户端工具目录管理的性能与同步协议**"。增量≥70%。
- 提升层：工作流/工具（工具目录管理）。

### 2. 动态工具发现触发阈值与三实现策略（来源：Claude Code MCP 文档 2026-02-15 + AWS 2026 + Spring AI 2026-06-15 实拉）
①**触发阈值**：工具描述占用 >10% 上下文窗口时自动启用按需加载（可调/可禁）；②**过滤面**：名称精确/模式、描述语义、domain/category tag；③**搜索实现三策略**：语义向量 / 关键词 Lucene / 正则名称模式——按场景选。
- 判非重复：豆包 r154 编排面无此点；本系统自身即用 tool_search 按需加载，属"可内化方法确认+参数化"。增量≥60%。
- 提升层：工具/工作流（上下文节省与工具选型）。

### 3. 语义工具发现：向量检索 top-3~5 + token 降 70-90% + 迭代守卫 + RBAC 过滤（来源：arXiv 2603.20313 2026-07-10 + kaman.in 实拉）
工具注册表用 dense embedding 索引，查询时相似度检索只选 3-5 个最相关工具（而非全目录 50-100+）；生产实测工具相关 token 消耗降 70-90%；**迭代守卫**通过驱逐打破工具调用循环（不阻塞）；多租户场景 RBAC-aware 过滤。
- 判非重复：点 2 管"何时启用+过滤面"；本点管"**向量检索机制与循环守卫的实现细节**"。增量≥60%。
- 提升层：工具（动态工具选择引擎）。

### 4. MCP-Zero 主动请求式工具发现：能力缺口触发 + 双级相似度评分（来源：arXiv 2506.01056 2026-06-01 实拉）
反转"运行时注入工具"：**模型检测到能力缺口时主动发结构化能力请求**（"我需要能把 PDF 转 Markdown 的工具"）；框架先按 server 聚合能力描述匹配（server 级），再按 tool 描述语义排序（tool 级），score=(s_server×s_tool)×max(s_server,s_tool)；对原描述与增强摘要双匹配取高分。
- 判非重复：点 3 是"运行时被动检索"；本点管"**模型主动请求的协议形态与双层评分**"。增量≥70%。
- 提升层：工作流（自主工具发现）。

### 5. MCP 原语三权分立：Tools/Resources/Prompts 分属三个控制者（来源：Claude Certified Architect 训练 PDF 2026 + WaytoAGI 实拉）
**Tools=模型控制**（LLM 决定何时调用）/ **Resources=应用控制**（应用决定何时加载数据）/ **Prompts=用户控制**（用户从模板选择）——按"谁该决定何时触发"分配原语，避免把该由应用加载的资源设计成模型可调的工 具、或把用户选择的模板变成模型自动执行。
- 判非重复：WB 各轮未落 MCP 原语职责面；豆包 r154 编排面管 agent 协作不涉原语。增量≥80%。
- 提升层：工作流/可复用 Skill（MCP 服务设计）。

### 6. Skill 平台三线并行安全审核流水线 + 本地静态扫描不出设备（来源：腾讯 SkillHub 2026-09-18 + edgeone skill scanner 2026-09-20 实拉）
平台侧：每个 Skill 上架前过**三线并行审核**（内容合规过滤 / 科恩实验室深度漏洞扫描 / 云鼎 AI 模型安全评估），任一不通即拒；用户侧：edgeone skill scanner 100% 本地静态分析（文件内容与凭据不出设备）扫描后再装。
- 判非重复：WB r156-C 供应链四道闸落"客户端装前审查流程"；本点管"**平台上架治理流水线 + 本地不联网扫描形态**"（治理层 vs 客户端层）。增量≥50%。
- 提升层：工作流（技能供应链治理）。
