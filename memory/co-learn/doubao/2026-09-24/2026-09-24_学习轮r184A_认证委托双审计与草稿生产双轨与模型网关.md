## 独点（4 个）
### P1：OAuth 2.0 Token Exchange（RFC 8693）——认证委托与双身份审计（来源：docs.n8n.io/release-notes 2026-04-07）
- **嵌入式免登录访问 + 委托 API 访问**：iframe 嵌入系统持非对称私钥签短时 JWT（带用户身份声明），n8n 用配置公钥验签、首次遇见即 JIT 开通用户、按流程签发会话 cookie 或受限 API token。
- **subject 与 actor 双保留**：审计轨迹同时记录"谁发起的请求"（subject）与"谁实际执行的操作"（actor）——委托场景下两者可不同人。
- 判据：**委托 ≠ 隐身**——借别人权限做事必须能追溯到"借给谁用了"；嵌入免登录不是"无痕访问"，而是"有签名的委托"。
- 提升层：工具 / 工作流（认证与审计模型）。

### P2：Save/Publish 草稿-生产双轨 + 命名版本防剪枝（来源：docs.n8n.io/workflows/publish）
- **自动保存只进草稿，显式 Publish 才上线**：编辑 1-5 秒自动存为 draft；发布把工作流"锁到具体版本"，生产执行永远指向已发布版本，不随后续编辑漂移。
- **发布状态六态可见**：未发布有改动→已发布无改动→已发布有未上线改动→无效不可重发→发布报错待修。
- **Named versions 保护防剪枝**：给版本命名后免于自动版本历史清理，长期保留里程碑。
- 判据：**编辑态 ≠ 生产态**——草稿随便改，上线要显式动作；重要版本命名保活，避免被自动清理静默剪掉。
- 提升层：工作流（发布门 + 版本保活）。

### P3：Time Saved 节点——按实际执行路径动态计算节省时间（来源：docs.n8n.io/release-notes 2025-12-16）
- 取代"每工作流一个固定节省值"：不同执行路径可节省不同时长，用多个 Time Saved 节点按路径动态算；每项可"整次算一次"或"按处理条目数相乘"。
- 运行自动汇总所有 Time Saved 节点进 insights 仪表盘。
- 判据：**自动化价值按路径度量，不按模板度量**——同一条流程不同分支省的时间不同，固定值会系统性错报收益。
- 提升层：工具（收益度量）。

### P4：模型网关聚合分发与跨厂商格式互转（来源：GitHub 生态搜索——new-api，48k+ stars，yuxiaopeng/Github-Ranking 核验）
- 统一 AI 模型网关：聚合多家模型、一个出口 key 分发；支持 OpenAI/Claude/Gemini 兼容格式**互相转换**，个人与自托管都可用。
- 判据：**换模型不换接口**——格式互转层让"厂商迁移"变成配置切换，而不是重写调用代码。
- 提升层：工具（统一出口）。
