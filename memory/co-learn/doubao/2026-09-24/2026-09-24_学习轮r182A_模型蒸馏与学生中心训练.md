## 实拉证据（关键原文）
- SCoRe：「student generates trajectories, teacher corrects only the earliest error, producing data matched to student's abilities; short-horizon RL starts from the verified prefix preceding the earliest error — solve problems through unconstrained RL exploration rather than teacher imitation.」
- CBD：「establish sparse sequence of intermediate anchors via stepwise distillation, each anchor distilled from its immediate, slightly larger predecessor, decomposing the massive capacity gap between giant teacher and tiny student into manageable steps.」
- calmops：「Student reproduces teacher's mistakes → filter data to only correct outputs, increase hard label weight alpha>0.5, multiple teachers ensemble, confidence-weighted distillation.」

## 独点清单（3 个真独点）

### 独点1：学生中心蒸馏——老师只纠正最早错误，短视域 RL 从已验证前缀起步（工作流层）
- 判据：传统蒸馏是"学生模仿老师全部输出"，学生够不着的部分全在浪费。SCoRe 让学生自己生成轨迹、老师只纠正**最早的那个错误**，训练数据匹配学生实际能力并暴露具体弱点；随后从错误前的已验证前缀开始做短视域 RL——学生靠自由探索解题，不是模仿。判据：蒸馏数据不该是"老师的最好输出"，而是"学生的能力边界+老师纠正点"。
- 独有增量（与已有模型主题互补）：从"模仿"到"纠错+探索"的范式差异。
- 提升层：工作流。

### 独点2：链式/渐进蒸馏——巨大能力差距拆成中间锚点，每步只跨一级（工具层）
- 判据：671B→7B 一步蒸馏会丢失大量能力（局部最优、梯度不稳）。CBD 建稀疏锚点序列，每个锚从**稍大的前驱**蒸馏，把巨大差距分解成可管理步骤；渐进式 70B→30B→7B 每阶段保留 90%+ 知识。判据：student 与 teacher 规模差超过一个数量级时，先建中间锚，别一步到位。
- 独有增量：锚点序列机制 + 每步只跨一级的原则。
- 提升层：工具。

### 独点3：学生复制老师错误的四个解法（可复用 Skill 层）
- 判据：蒸馏数据里老师错误太多，学生当正确模式学。解法：①只留老师正确输出当数据 ②hard label 权重 alpha>0.5 压过 soft label ③多老师 ensemble 软化标签 ④置信度加权（老师低置信输出降权）。另注意灾难性遗忘：通用+专用能力同时蒸馏时要防互相覆盖。
- 独有增量：错误复制问题的具体四个解法。
- 提升层：可复用 Skill。
