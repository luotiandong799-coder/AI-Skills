## 二、独点清单 + 判非重复理由（6 点，均≥40% 独有增量）

### 1. 三层记忆架构与读写时机（来源：DataGate 2026-05-28 + ILMTEC 2026-07-08 + RapidClaw 2026-04-03 实拉）
工作=上下文窗口（每调用都读，风险成本+溢出）/短期=会话内可检索存储（不撑上下文）/长期=跨会话持久（按需检索，风险陈旧+无关召回）；信息按任务需要在三层间移动。
- 判非重复：cc 落记忆提取策略（提取面）；本点=**三层存储结构与各自风险**（架构面）。增量≥70%。
- 提升层：工作流（记忆架构）。

### 2. 记忆写入策略三选（来源：AI/TLDR 2026-06-12 实拉）
eager（每轮写，噪贵）/end-of-session（整会话压缩，漏中途洞察）/triggered（值得记才写，最低噪最难调）；**生产组合=end-of-session 摘要管 episodic + triggered 写 semantic facts**。
- 判非重复：cc 落"会话结束自动提取"单策略；本点=**三策略对比与组合选型**（决策面）。增量≥55%。
- 提升层：工作流（写入决策）。

### 3. 三类记忆存储与 procedural 层（来源：IoT Digital Twin 2026-05-24 + XYZBytes 2026-06-28 + CallSphere 2026-04-23 实拉）
episodic=向量索引交互历史/semantic=结构化事实偏好/**procedural=工具注册表+已验证工具调用链模板——最被低估最有价值，按'怎么做事'检索**；无 reflection pass 的 episodic 塞满低信息噪声。
- 判非重复：全库无三类型记忆分类面。增量≥85%。
- 提升层：工作流（记忆分类）。

### 4. 记忆整合与遗忘四策略（来源：RankSquire 2026-03-12 + Kaya 2026-07-05 实拉）
**consolidation 触发=episodic success 且被后续 3+ 会话成功应用→提升 semantic**；遗忘四策略=TTL/LRU/importance-based pruning（LLM judge 判可忘）/exponential decay；新事实矛盾→旧失效。
- 判非重复：cc 落两级沉淀（日志→长期）；本点=**提升触发条件与遗忘策略**（生命周期面）。增量≥65%。
- 提升层：工作流（记忆维护）。

### 5. 上下文注入布局纪律（来源：Agent Loop 2026-05-30 实拉）
lost-in-the-middle 缓解：**关键上下文放头尾/冗长低优先级放中间/中间激进压缩/总填充限 70% 窗口上限**；典型预算=40K episodic+20K semantic+80K overhead。
- 判非重复：cc 落预算管理（何时规划压）；本点=**注入位置布局**（注入面）。增量≥60%。
- 提升层：工具（注入策略）。

### 6. 记忆循环与注入时机（来源：OpenAI SDK cookbook + Atlan 2026-04-17 实拉）
**循环=inject→reason→distill→consolidate**；注入 hooks 在 context trimming 之后、执行之前；会话末 consolidate 去重、recency wins 解冲突、清空会话记忆。
- 判非重复：cc 落提取→校验两步行；本点=**四步闭环与注入时机**（流程面）。增量≥50%。
- 提升层：工作流（记忆闭环）。
