## 二、独点清单 + 判非重复理由（7 点，均≥40% 独有增量）

### 1. 视觉决策点模式（来源：aiagents.codeguides 2026-07-16 实拉）
**plan in text，只在决策点用视觉；不可逆动作前加第二工具验证；截图断言（error toast visible）**。
- 判非重复：WB 视觉三纪律管提取；本点=**何时用视觉+不可逆验证**。增量≥85%。
- 提升层：工作流（视觉使用时机）。

### 2. 图像提示工程官方规则（来源：Google Cloud 2026-09-18 实拉）
**检测文本单图优于多图；单图放 text 前；多图显式索引 a[1]/a[2]；分辨率×token 权衡**。
- 判非重复：WB"锚定描述"互补；本点=**索引机制+单多图规则**。增量≥65%，合并保留增量落地。
- 提升层：工作流（图像提示）。

### 3. 布局感知 OCR 与语义输出（来源：DEV GLM-OCR 2026-09-14 实拉）
**理解布局（标题/章节/表格/图）→语义格式输出（Markdown/JSON/LaTeX）；reasoning 非纯识字符**。
- 判非重复：全库无布局感知 OCR 面。增量≥90%。
- 提升层：工具（文档理解）。

### 4. 文档管线六段与阅读顺序（来源：Harshith 2026-05-09 + CodeSOTA 2026-05-06 实拉）
**ingestion→preprocessing→OCR→layout→extraction→validation（业务规则+置信阈值）；reading order 保序**。
- 判非重复：全库无文档管线全链面。增量≥90%。
- 提升层：工作流（文档处理管线）。

### 5. 三类文档方案权衡（来源：AI Learning Guides 2026-05-19 实拉）
**A 传统管线（灵活贵）/ B 区域检测+提取（高量便宜）/ C 端到端 VLM（一致格式最便宜灵活低）**。
- 判非重复：点 4 管管线；本点=**方案选型维度**。增量≥70%。
- 提升层：工具（方案选型）。

### 6. 关键帧提取三策略与工具化（来源：CodeSOTA 2026-05-02 + TASKER + VideoThinker 实拉）
**uniform/keyframe/scene 三策略；TASKER 任务相关+场景动态；FrameZoom 区间重采样；场景去重**。
- 判非重复：全库无视频关键帧面。增量≥90%。
- 提升层：工作流（视频理解）。

### 7. 多模态工具编排与证据账本（来源：The Neural Base 2026-04-21 + LedgerMind 实拉）
**每模态独立工具同 state/graph 内编排；工具输出归一化证据账本（source/type/confidence/lifecycle）推理只引活跃条目，grounding 验证实体数值**。
- 判非重复：WB 落断言层哨兵；本点=**模态编排+证据 provenance 结构约束**。增量≥80%。
- 提升层：工作流（多模态编排）。
