## 二、独点清单 + 判非重复理由（6 点，均≥40% 独有增量）

### 1. 数据飞轮六阶段闭环与 eval gate（来源：LLM Stack Book 2026-08-18 + NVIDIA Blueprint 实拉）
闭环自强化循环：vN 服务并记录 → 日志评分（人工/自动代理）→ SFT/RLHF 重训候选 → **候选过 eval gate 才部署 vN+1** → 新模型产更富信号；不是一次性流水线。
- 判非重复：WB av 落评测方法论（怎么跑）；本点=**数据→重训→部署闭环**（数据面）。增量≥70%。
- 提升层：工作流（迭代闭环）。

### 2. 评测数据源分级与 trace-first 转换（来源：AtomsAI 2026-06-10 + Citeables 2026-04-12 + Microsoft 2026-09-01 实拉）
production logs 最佳/support tickets 次佳（预标注边界）/领域专家第三/synthetic 最后且须验证真实表述；**trace-first：抓 trace→挖模式→转数据集→每次变更重评**。
- 判非重复：全库无评测数据来源分级面。增量≥90%。
- 提升层：工作流（数据采集）。

### 3. 数据管道四步与质量优先（来源：TianPan 2026-04-07 + Toolsku 2026-06-23 + AWS Nexthink 实拉）
workload_id 标记 → 去重+class-aware 分层切分 → LLM-as-judge 质量过滤 → 格式化指令对；**精选 5000>噪声 50000**；三种自动标注成本分级；逆向标注（给查询写问题）降负载。
- 判非重复：点 2 管来源；本点=**管道处理步骤**（构建面）。增量≥65%。
- 提升层：工作流（数据构建）。

### 4. 三元反馈体系与反馈版本化（来源：TheNeuralBase 2026-04-22 + arXiv AITL 实拉）
自动高置信信号/每周随机抽查/关键失败升级；**反馈版本化：三月纠正四月发现错→含它的整次重训作废**；AITL 四注解嵌入 live 运营。
- 判非重复：点 3 管管道；本点=**反馈信号分层与纠错追溯**（反馈面）。增量≥60%。
- 提升层：工作流（反馈设计）。

### 5. 合成数据三重质量门（来源：FutureAGI 2026-05-20 实拉）
embedding 去重拒 15-25%（cosine>0.92）→ **跨家族 LLM judge 再拒 40-60%**（不可信/风格坍缩/标签泄漏/平凡可推导）→ 模式坍缩检测（pairwise 距离+unigram/bigram 熵对照真实参考）。
- 判非重复：全库无合成数据质量门面。增量≥85%。
- 提升层：工作流（合成数据治理）。

### 6. 评测集组成桶与 drift/regression 区分（来源：FutureAGI 2026-05-16 + Latitude 2026-07-20 + PromptAssay 2026-08-22 实拉）
评测集四桶（Adversarial/Edge cases/Failure replays/常规，任一归零门失效）；**regression=你改的、diff 内、发布前对比；drift=底下动的、代码外、持续评分 vs 版本基线；三信号=golden set 重跑降/投诉聚类/分布偏移**。
- 判非重复：WB av 落"评测集腐烂"（时间劣化）；本点=**评测集构成与 drift 检测方法**（组成面）。增量≥55%。
- 提升层：工作流（评测集设计/监控）。
