## 二、独点清单 + 判非重复理由（6 点，均≥40% 独有增量）

### 1. 量化选型与 iso-memory 原则（来源：AcinAI 2026-06-27 + TechPulse 2026-04-28 实拉）
Q4_K_M=默认甜点（1/4 尺寸质量近无损）；**iso-memory=同内存下大模型 4-bit 胜小模型 8-bit**；量化阶梯 7B 参考（F16 14GB→Q4_K_M 5GB→Q3 4.1GB）。
- 判非重复：全库无量化选型面（r158B 管模型路由）。增量≥90%。
- 提升层：工作流（本地部署选型）。

### 2. 量化层级详解与 KV cache 量化（来源：ExplainX 2026-06-16 + InsiderLLM 实拉）
**Q=位数/K=K-quant 按组自适应 scale/S/M/L=校准集大小；Dynamic 2.0 GGUF 逐层选型；量化 KV cache 是最被忽略的杠杆**。
- 判非重复：点 1 管选型；本点=**格式语义**（理解面）。增量≥60%。
- 提升层：工具（量化知识）。

### 3. 本地栈三层分层（来源：redlinesoft 2026-08-09 + Vibe Engines 2026-07-20 + AI Mastery 2026-07-03 实拉）
llama.cpp=引擎+GGUF 定义/Ollama=编排层/OpenAI 兼容 API=访问层；**VRAM 容量>算力速度（权重须整体进显存）**。
- 判非重复：全库无本地栈分层面。增量≥85%。
- 提升层：工作流（栈理解）。

### 4. 本地 RAG 全本地栈配方（来源：Markaicode 2026-03-02 + RunAIHome 2026-05-23 + StackNova 2026-04-08 实拉）
**embedding=nomic-embed-text 137M/768 dims（别浪费算力在大 embedding）**；chat=Qwen2.5 7B 平衡/3B 低显存；ChromaDB+Open WebUI/AnythingLLM；硬件后 $0/月。
- 判非重复：r160C 落云端 RAG 架构；本点=**全本地私有配方**（部署面）。增量≥70%。
- 提升层：工作流（私有 RAG 搭建）。

### 5. 本地 vs API 成本模型与决策框架（来源：aistacklabhq 2026-06-16 + SimpleTechGuides 2026-06-17 + Kunal 2026-06-04 实拉）
**本地=资本成本+固定月费；云=纯可变成本；本地只在超用量阈值才赢**；明确胜场景=隐私敏感/离线/短提示延迟/10M+ tokens 天；价格对照（Gemma 12B $0 vs GPT-4o Mini $0.15/1M）。
- 判非重复：全库无本地/云成本决策面。增量≥80%。
- 提升层：工作流（部署决策）。

### 6. SLM 时代与混合部署（来源：Vucense 2026-05-11 + DEV 2026-09-01 + 云栖大会 2026-09-23 实拉）
**2026 重心移到 3B-8B 任务特定 SLM 适配已有硬件；本地翻转三件事=隐私/成本/控制（persona/窗口/停词/拒答）**；混合=本地小模型预处理降 token+云端大模型按需。
- 判非重复：点 5 管成本；本点=**SLM 趋势与混合架构**（趋势面）。增量≥55%。
- 提升层：工作流（架构趋势）。
