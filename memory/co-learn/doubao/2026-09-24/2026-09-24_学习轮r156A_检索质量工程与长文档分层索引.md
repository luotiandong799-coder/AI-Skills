## 二、独点清单 + 判非重复理由（4 点，均≥40% 独有增量）

### 1. 自适应切块：多指标评分 + 尺寸归一化后处理 + 候选池动态选择（来源：arXiv 2603.25333 Adaptive Chunking 2026-03 实拉）
停止追单一"万能切分参数"：①用多指标评分（ICC 内部一致性+BI 平衡+RC 召回+SC 相似性+相邻 chunk 连贯性）而非单维度优化；②**后处理是最高 ROI**——tiny-chunk 合并+oversized 重切，几乎零成本稳定增益；③候选池（page/递归/规则切分）按文档特征动态选。
- 判非重复：豆包 r154B 落 Contextual 检索（chunk 富化"加什么"）；本点管"**切分参数怎么定 + 后处理防碎**"（chunking 决策层）。WB 各轮未落 chunking 决策面。增量≥60%。
- 提升层：工作流（检索质量工程）。

### 2. 晚期交互检索：token 级最大相似度（来源：Future AGI《Evaluating RAG Chunking Strategies in 2026》2026-05-20 实拉）
ColBERT/ColBERTv2 存**每 token 嵌入**而非每 chunk 单池化向量，查询时对所有 token 对取最大相似度评分——保留池化向量抹掉的精确 token 信号；Jina-ColBERT-v2（多语言）/PLAID（压缩索引）解决存储溢价。多语言与代码语料检索的最强档。
- 判非重复：豆包 r154B 落 RRF（结果融合）/HyDE（查询改写）管"检索结果与查询侧"；本点管"**嵌入与匹配机制本身**（token 级 vs 池化）"。增量≥60%。
- 提升层：工作流/工具（检索机制选型）。

### 3. 长文档 QA 分层索引三机制（来源：arXiv 2603.08329 SPD-RAG + AAAI-2026 HTSIR + KohakuRAG 2026-03 实拉）
三种互补组织：①**按文档轴分解**（SPD-RAG：每文档一个专用子代理，coordinator 分发+聚合，token 受限合成层支持递归 map-reduce）；②**两级摘要大纲**（HTSIR：节级高层摘要+段落组中层摘要+原文细粒度，提问跨层并行取）；③**四层树索引+弃权感知投票**（KohakuRAG：文档→章节→段落→句子，集成推理+弃权投票稳定输出）。
- 判非重复：豆包 r154B 落 Agentic 检索循环（查询侧多步）；本点管"**索引侧怎么为长文档建多粒度结构**"。增量≥60%。
- 提升层：工作流（长文档 RAG 架构）。

### 4. 检索元数据异步富化管线（来源：n8n 官方 workflow 8008 2026-02-24 实拉 + RAGFlow Ψ-RAG）
**chunk 入库前异步富化**：定时任务抓新 chunk→LLM 为每 chunk 生成结构化元数据（topics/use_case/risks/audience_level/summary）→写进 vector DB→查询时 Query Builder 把用户问题转成关键词+元数据 filters→过滤+精排。增量更新不阻塞线上检索。
- 判非重复：豆包 r154B Contextual 落"chunk 上下文摘要富化"（语义定位）；本点管"**多维度业务元数据富化+过滤检索**"（检索入口约束）。增量≥40%。
- 提升层：工作流（检索管线增强）。
