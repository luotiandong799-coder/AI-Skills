## 独点清单（3 个真独点）

### 独点1：Golden task 回归集 + 两次稳才发 + 成本可观测四指标（工作流/可复用 Skill 层）
- 原文判据：「Build 20–50 real-scenario regression set, run on every change; same input run 5–10 times for consistency; ship only when stable across two runs」+「Monitor cost per action, cache-hit rate, retry-loop cost, model-call distribution from day one; evaluate models quarterly, not weekly」。
- 独有增量（与已有 wb-skill-authoring「闭合邻域/双向计分板/消融基线」的区别）：那条管**技能该不该被触发**（activation 测量），本条管**改完之后产出稳不稳**——回归集按真实业务场景建（不是合成任务）、跟踪指标除成功率外还要 steps per success 和 cost per success、上线门禁是"两次跑都稳"、成本要从 PoC 第一天就按四指标看而不是规模化后才发现爆炸、模型选型按季度锁死不每周追新。
- 提升层：工作流。

### 独点2：记忆内容治理——claims+evidence / 矛盾检测 / 新鲜度跟踪（模型/工具层）
- 原文判据：OpenClaw v2026.4.7 Memory-Wiki：每条记忆 = claim+来源证据；互相矛盾的记忆自动检测并标红；记忆带 freshness，过期提醒；定期编译成知识摘要。
- 独有增量（与已有 wb-context-compressor「记忆提取四策略/两级沉淀」的区别）：那条管**怎么从会话里提取记忆**（提取侧），本条管**记下来的记忆怎么保持可信**（内容侧）——不能只存结论，必须带证据；两条记忆打架时不能静默二选一；记忆有保鲜期，旧事实要主动标过期。与"压缩后规则重声明"互补：那管压缩后规则活不活，这管记忆内容真不真。
- 提升层：工具（记忆系统）。

### 独点3：Skill 带评分门禁进化 + 任务拆子状态的技能检索（可复用 Skill 层）
- 原文判据：ModelScope Ultron——「分数提升才接受新版本，分数下降回滚上一版」；arXiv 2607.06283——检索技能时先把任务拆成子状态，把技能前置条件与子状态对齐取最高相关作边源，cross-encoder 重排。
- 独有增量（与已有"消融基线归任务集/读到≠激活"的区别）：已有讲评测方法和渐进披露，本条讲**版本门禁**——技能更新不是直接覆盖，要在回归集上跑分，涨才合、跌就回滚；以及**检索精度**——关键词/语义匹配之外，把任务拆成子状态后让技能按"前置条件状态"对齐，比纯 description 匹配准。
- 提升层：可复用 Skill（技能治理与检索）。
