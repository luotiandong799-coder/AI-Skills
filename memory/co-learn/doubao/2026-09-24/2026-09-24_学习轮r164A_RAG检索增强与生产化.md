## 二、独点清单 + 判非重复理由（7 点，均≥40% 独有增量）

### 1. 混合检索三段式标准管线（来源：Markaicode 2026-05-13 + Tensoria 2026-05-15 实拉）
**dense+BM25 并行→RRF 融合（k=60）→cross-encoder 重排 top-20~50→top-5~10；重排=query+文档联合打分显著更准**。
- 判非重复：r158C/r160C 落检索基础与架构；本点=**三段式部件标准与参数**。重叠<50%，增量≥65%，合并保留增量落地。
- 提升层：工作流（检索管线）。

### 2. Pre-fusion 重排作为融合门（来源：Rag About It 2026-05-28 实拉）
**重排不是融合后修正而是融合门：融合前先验证每检索流 top-N 候选与查询的事实对齐；混合检索减 43% 幻觉**。
- 判非重复：点 1 管管线；本点=**重排时机判据**（门 vs 事后）。增量≥70%。
- 提升层：工作流（重排定位）。

### 3. Chunking 策略判据与 2026 基线（来源：DronaHQ 2026-06-23 + Redis 2026-07-11 实拉）
**7 策略按文档类型选；2026 基线=recursive 400-512 tokens 10-20% overlap 先起测量再动；语义 chunking 非普适（FiQA 降 23-27%）**。
- 判非重复：r158C 落检索基础可能含 chunking 概念；本点=**策略选择判据+语义 chunking 反例数据**。增量≥55%，合并保留增量落地。
- 提升层：工作流（索引策略）。

### 4. Late-interaction 检索（来源：Future AGI 2026-05-20 实拉）
**ColBERT 家族每 token embedding+max-sim 打分保精确 token 信号；Jina-ColBERT-v2 多语言/PLAID 压缩索引降存储；多语言+代码冠军**。
- 判非重复：全库无 late-interaction 检索面。增量≥90%。
- 提升层：工具（检索模型选型）。

### 5. 抽取式上下文压缩主导（来源：Rag About It 2026-06-26 实拉）
**RAG 压缩用 extractive 主导（abstractive 蒸馏事实漂移级联进生成）；LLMLingua-2=52% 压缩保 97.8% QA 精度**。
- 判非重复：cc 落通用上下文压缩策略；本点=**RAG 检索上下文压缩专用判据+量化数据**。增量≥60%。
- 提升层：工作流（RAG 压缩）。

### 6. CORE-RAG 性能驱动压缩（来源：OpenReview 2026-05-01 + PaperNotes 实拉）
**1.5B 压缩器 GRPO RL 以任务性能为奖励，压到 3% 长度反 +3.3 EM；压缩=提升任务性能而非找好摘要**。
- 判非重复：点 5 管抽取式；本点=**RL 性能驱动范式**（新方法面）。增量≥85%。
- 提升层：工作流（压缩范式）。

### 7. HyDE+RRF 量化组合与加权融合（来源：Vucense 2026-09-13 + Calmops 2026-06-22 实拉）
**HyDE 提间接问题 recall 20-40%；重排提 precision@1 15-30%；weighted RRF 按查询动态定 alpha；本地零 API 成本**。
- 判非重复：r158C 或含 RRF 概念；本点=**量化增益+加权变体**。增量≥60%。
- 提升层：工作流（检索增益量化）。
