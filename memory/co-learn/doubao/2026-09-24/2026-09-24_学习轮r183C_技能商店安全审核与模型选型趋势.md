## 独点清单（4 个真独点，均带来源）

### 独点1：技能商店的"三线并行安全审核 + TRACE 评测体系"——装技能前先过安全与质量两道门（工作流层）
来源：腾讯云开发者社区《什么是 SkillHub》原文："平台收录 8万+ Skills，通过国内高速镜像实现技能秒速安装，并采用三线并行安全审核机制保障技能安全性…首发 TRACE 评测体系帮助用户识别高质量 Skill"。
- 判据：开放技能生态装 skill 前先看两道信号：① 安全审核（三线并行=代码/行为/来源多线交叉审）；② 质量评测（TRACE 评测体系给技能质量分，帮用户识别"高质量"而非仅"热门"）。与 r183-B 独点1（排行榜=采纳度量）分工：排行榜回答"大家装没装"，TRACE/安全审核回答"能不能装、装哪个好"——两者并列为选型双信号。
- 提升层：工作流。

### 独点2：国内技能生态的"应用商店"模式 + 模型即服务一体化工具链（工具层）
来源：虾小宝（skillhub.wanuai.cn）原文："Skills 就是'App'，装了就能写公众号…虾小宝就是这些 Skills 的'应用商店'，目前收录 35,000+ 个经过安全审核的技能"；ModelScope 首页：ModelScope Library（"offers efficient model inference, fine-tune, and evaluation"）+ ModelHub + Studio（"free and flexible AI application display space"）+ EvalScope（评测）+ Swift（训练推理）+ ModelScope-Agent（Agent 框架）。
- 判据：国内 AI 员工生态正复制手机生态：技能=App、技能市场=应用商店（安全审核后上架）；模型平台则把"推理/微调/评测/Agent 框架/应用展示"做成一体化入口（ModelScope 六件套）。自己选型时：评测框架看 EvalScope、训练看 Swift、Agent 框架看 ModelScope-Agent，同一平台同源可减少集成成本。
- 提升层：工具。

### 独点3：模型发布形态趋势——Flash/Next 轻量推理版成主流 + 端侧小模型与稀疏 MoE 并行（模型层）
来源：Hugging Face trending（3,082,055 模型）+ ModelScope 首页实测：DeepSeek-V4.1-Flash、Qwen3.8-Flash-Next、GLM-5.3-Flash（Flash 系列=推理优化版）；MiniCPM5-2B（2.5B 端侧，128K 上下文）、Xing4.0-29B-A4B（29B 参数仅激活 4B 稀疏 MoE）。
- 判据：选模型先看发布形态——"Flash/Next"轻量推理版（速度/成本优化）与旗舰版并行发布；端侧场景看 2-3B 级小模型（128K 上下文已可用）；MoE 大模型看激活参数量（29B-A4B 实际成本接近 4B 级）。给本地/个人 Agent 选型：优先 Flash 系 + 端侧小模型，而非直接上旗舰。
- 提升层：模型（选型事实）。

### 独点4：一句话招募多 Agent 组队的自然语言协作形态 + Skill 按职业分类组织（工作流层/可复用 Skill 层）
来源：AgentMore 使用指南原文："它不再只是一个'聊天 AI'，而是一个可以长期协作、分工执行、多线程工作的 AI 团队系统。你可以像组建乐团一样，为不同任务配置不同 Agent，让它们同时工作、彼此协同"（一句话招募最多 5 个 Agent）；SkillsMP 原文："Browse 23 occupation groups and 867 detailed occupations to see how people in different fields structure their work"（按 SOC 职业分类组织 3,262,633 个 SKILL.md）。
- 判据：① 多 Agent 协作的消费级入口是"自然语言组队"——用户不说编排模式，只说"我需要一个团队"，产品按任务自动配 Agent（5 个内）；② 可复用 Skill 的组织方式可按"职业/领域"归类（SOC 分类），跨行业找灵感（把别的职业的做法转成自己的 skill）。与已有"多智能体编排模式"分工：那个管 agent 内部怎么协作，本条管用户侧怎么发起（自然语言组队）。
- 提升层：工作流 + 可复用 Skill。
