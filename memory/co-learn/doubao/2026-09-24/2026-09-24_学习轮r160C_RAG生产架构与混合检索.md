## 二、独点清单 + 判非重复理由（6 点，均≥40% 独有增量）

### 1. 混合检索与 RRF 融合（来源：DEV 2026-09-01 + Enison 2026-03-11 + 47Billion 2026-03-03 实拉）
dense 强语义弱专名精确/BM25 相反；**混合并行+RRF(k=60) 融合，多基准提升 15-30%**；'支付失败'vs'交易错误恢复'漏配案例。
- 判非重复：豆包 r158C 落 rerank 分数校准（质量面）；本点=**混合召回机制**（架构面）。增量≥65%。
- 提升层：工作流（检索架构）。

### 2. 多级 RAG 流水线顺序（来源：ShyankDev 2026-07-14 + arXiv 2605.12028 实拉）
**固定顺序：Hybrid → Pre-filtering → Reranking → Contextual Compression → Generation**；三阶段=query rewrite→混合检索→cross-encoder rerank。
- 判非重复：豆包 r158C 落各组件单点（改写/rerank/指标）；本点=**流水线编排顺序**（管线面）。增量≥55%。
- 提升层：工作流（管线设计）。

### 3. 分块策略按内容类型选择（来源：LobeHub paulpas 2026-09-14 + AI Workflow Lab 2026-05-26 实拉）
主题边界文档=语义切分/上下文重要=句子窗口/非结构化日志=递归字符；**固定长度赢均匀记录、语义赢散文、文档感知赢结构化**。
- 判非重复：全库无分块策略选择面（r158C 未涉及）。增量≥85%。
- 提升层：工作流（分块设计）。

### 4. 语义分块细节与 title-chain（来源：AI Wiki 2026-05-01 + arXiv 2608.00824 实拉）
相邻句 cosine 低于阈值切；**256-512 约束（min 100/max 1000）+10-20% overlap**；三阶段=header-split→semantic merge→**title-chain prefixing（用文档自身标题层级零额外 LLM 调用）**。
- 判非重复：点 3 管选型；本点=**语义切分实现细节**（实现面）。增量≥60%。
- 提升层：工作流（分块实现）。

### 5. 索引生命周期五刷新模式（来源：Swfte 2026-05-04 + Red Hat Enterprise 实拉）
Batch nightly/Incremental upsert/CDC streaming/Versioned shadow（零停机）/Manual；**升级 embedding 模型=全体向量语义空间变化→全量 reindex 或双版本并存迁移；改分块策略同理；生产=增量+周全量补漏**。
- 判非重复：全库无索引生命周期面。增量≥90%。
- 提升层：工作流（索引维护）。

### 6. 分层检索架构与热冷存储（来源：CSDN 2026-04-11 + arXiv LiveVectorLake 2026-09-03 实拉）
三层：HNSW+INT8 轻量向量→Cross-Encoder 细粒度 rerank→KG 补全因果校验；**热冷双存储=热 Milvus sub-100ms+冷 Delta Lake 存成本**，ACID 一致。
- 判非重复：点 1 管召回；本点=**分层架构与存储分档**（架构面）。增量≥50%。
- 提升层：工作流（架构设计）。
