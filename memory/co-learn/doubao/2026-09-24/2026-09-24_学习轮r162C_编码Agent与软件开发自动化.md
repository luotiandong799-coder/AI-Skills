## 二、独点清单 + 判非重复理由（7 点，均≥40% 独有增量）

### 1. 编码 agent 采纳三阶段与有用速度（来源：DEV eli 2026-07-26 实拉）
**pilot 2-3 人 2-3 周测基线四指标；测有用速度非原始速度（agent 能快产坏代码）；先定义范围与政策**。
- 判非重复：全库无编码 agent 采纳度量面。增量≥90%。
- 提升层：工作流（采纳度量）。

### 2. 工作流先行与状态机（来源：claudeworkshop 2026-06-23 + Anthropic 2026 实拉）
**先写信任的 agent 循环（request→PR 六步）；状态机=可执行状态；AGENTS.md 解锁 agent 循环收测试/linter 反馈；PLAN.md 提交代码库**。
- 判非重复：r160B 落通用工作流模式；本点=**编码 agent 具名循环**（编码面）。增量≥65%。
- 提升层：工作流（编码编排）。

### 3. Claude Code 三段循环与防金饰化（来源：Kunal 2026-06-05 + Cursor Forum 2026-04-05 实拉）
**gather→action→verify 链式几十动作+中途纠正；先端到端跑通再重构（金饰化丢时间）；单 prompt >200 行质量下降拆小；AI 不记忆跨 prompt 上下文**。
- 判非重复：点 2 管循环设计；本点=**循环执行纪律**（执行面）。增量≥60%。
- 提升层：工作流（编码执行）。

### 4. Cursor+Claude Code 80/20 混合分工与钩子（来源：RockB 2026-04-24 + VoiceOfDev 2026-09-07 实拉）
**Cursor 管 80% 单文件日常，Claude Code 管 20% 复杂自主多文件；Cursor 钩子=beforeShellExecution/afterFileEdit 观察控制扩展循环**。
- 判非重复：r161B 落框架选型；本点=**编码工具具体分工**（工具面）。增量≥70%。
- 提升层：工具（混合工作流）。

### 5. 永不直推 main 护栏（来源：Tembo 2026-04-12 实拉）
**agent 永不直推 main=开 PR 人工评审，非不可协商；坏 commit 成本远高于评审摩擦；隔离执行环境**。
- 判非重复：r162B 点 4 管授权分级；本点=**编码特定护栏**（编码安全面）。增量≥55%。
- 提升层：工作流（编码护栏）。

### 6. AI 代码评审 agent 面（来源：SSOJet 2026-06-22 + Mastra 2026-08-13 实拉）
**读 PR diff 对照周边代码库推理意图发内联评论/摘要/建议（异于静态分析器）；上下文感知=代码库+issue 非仅改行；静态分析门+AI reviewer 配对**。
- 判非重复：全库无 AI 评审自动化面（r160A 管测试）。增量≥80%。
- 提升层：工具（评审自动化）。

### 7. 编码模型专业化分工（来源：RockB 2026-07-14 + Awesome Agents 2026-04-19 实拉）
**单模型统治复杂工作流是错的：Gemini=1M 上下文全局重构/Claude=日常/DeepSeek=成本；Aider architect 双模型管线；SWE-bench Verified 无部分分+2026 停计数+Terminal-Bench 继任**。
- 判非重复：r158B 落路由机制；本点=**编码场景模型分工+基准演化**。增量≥60%。
- 提升层：工作流（模型分工）。
