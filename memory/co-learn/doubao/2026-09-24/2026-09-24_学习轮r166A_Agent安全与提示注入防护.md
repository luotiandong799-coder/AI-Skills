## 二、独点清单 + 判非重复理由（7 点，均≥40% 独有增量）

### 1. 三演员模型与爆炸半径/Safe URL（来源：OpenAI 官方 2026-03-11 实拉）
**用户/工具/内容三演员；目标不是完美识别恶意输入而是限制爆炸半径；Safe URL 会话信息外发第三方时给用户看或拦**。
- 判非重复：WB guardian 三问管执行前验证；本点=**威胁模型+外发通道机制**。增量≥80%。
- 提升层：工作流（威胁建模）。

### 2. ClawGuard 运行时边界强制（来源：arXiv 2604.11790 实拉）
**每个工具调用边界强制用户确认规则集；从用户目标自动推导任务特定访问约束；确定性可审计，不改模型不改基建**。
- 判非重复：WB guardian 是独立小模型审计划；本点=**自动推导约束+边界拦截**。增量≥70%。
- 提升层：工具（运行时防护）。

### 3. DeFuse 触发式注入检测量化（来源：arXiv 2609.22510 实拉）
**trigger-based 注入摄入时检测条件结构；34.3%→3.0%（5% 误报预算）**。
- 判非重复：WB 正则预检管模式匹配；本点=**训练检测器+量化数据**。增量≥75%。
- 提升层：模型（检测）。

### 4. Twin-Agent 双 LLM 隔离（来源：shortspan.ai 2026-07-22 实拉）
**一个探索不可信输入，一个执行特权动作，只传短 hints 过边界；静态测试注入成功率近零**。
- 判非重复：r165-B 子 agent 蒸馏管 token；本点=**安全隔离（dirty/clean 物理分）**。增量≥85%。
- 提升层：工作流（架构隔离）。

### 5. Session-Salted XML 分隔符（来源：aiclaude.codeguides + CodeSecAI 2026-07 实拉）
**检索内容=数据非指令，代码层强制；静态标签 `<context>` 可被伪造，用每会话密码学随机标签**。
- 判非重复：r164A RAG 管检索质量；本点=**注入隔离标签机制**。增量≥80%。
- 提升层：工作流（提示边界）。

### 6. 消毒管线与 exfil 通道切断（来源：Security Cipher 2026-07-14 实拉）
**进模型前消毒（注释/隐藏 CSS/zero-width/NFKC/OCR-only）；禁自动渲染外链图、拒 markdown image、出站白名单、图片代理审查**。
- 判非重复：WB 正则预检管模式；本点=**字符级消毒+外发通道**。增量≥75%。
- 提升层：工具（输入/输出过滤）。

### 7. OWASP ASI Top10 与每动作授权（来源：arnau.au + Microsoft 2026 实拉）
**ASI01-ASI10 独立于 LLM Top10；每动作在每资源上重查授权（不是会话开始一次），不可逆动作 HITL**。
- 判非重复：WB per-tool 最小权限管工具权限；本点=**每动作重查+权威清单**。增量≥65%，合并保留增量落地。
- 提升层：工作流（权限模型）。
