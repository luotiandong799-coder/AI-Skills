## 二、独点清单 + 判非重复理由（7 点，均≥40% 独有增量）

### 1. MRMS 多分辨率记忆底物（来源：arXiv 2607.04617 实拉）
**双轴架构：表示轴（结构化/向量/图）+时间轴（短/中/长）；三表示同步=结构化管资格、向量管召回、图裁决支持/矛盾/取代后再投影上下文**。
- 判非重复：全库无记忆底物架构面（cc 管提取沉淀，不涉及三表示协同）。增量≥90%。
- 提升层：工作流（记忆系统架构）。

### 2. Memora 存/取解耦（来源：Microsoft Research 2026-06-29 实拉）
**内容保持丰富表达，独立轻量结构层管索引检索；consolidate 相关→稳定单元；细粒度按需浮现**。
- 判非重复：全库无"存取解耦"概念。增量≥90%。
- 提升层：工作流（记忆存储设计）。

### 3. 记忆工具选型矩阵（来源：DEV 2026-07-21 实拉）
**Mem0=个人化 / Zep=时间推理 / Letta=自主管理（RAM+archival 类比）/ PLUR=跨工具 engram 格式**。
- 判非重复：全库无工具选型面。增量≥90%。
- 提升层：工具（记忆后端选型）。

### 4. 程序性记忆=指令非数据（来源：Zylos 2026-04-05 实拉）
**"总是用 schema X 校验 JSON"最有用的形态=系统提示指令注入，不是向量检索；载体=prompt+few-shot+微调权重**。
- 判非重复：与 cc 提取面互补（cc 管写入，本点管**程序性记忆的表示形态**）。增量≥85%。
- 提升层：工作流（技能/规则落点）。

### 5. 记忆检索三技术（来源：Kanopy 2026-03-04 实拉）
**recency boosting=相似度×时间指数衰减；矛盾=标 superseded 不删；metadata 过滤=项目/用户/会话标签**。
- 判非重复：cc 落提取/沉淀（写入侧）；本点=**检索侧三技术**。重叠<50%，增量≥65%，合并保留增量落地。
- 提升层：工作流（记忆召回）。

### 6. 个人 AI 记忆闭环与轻方案（来源：AI Memory 2026-05-25 + OpenAI Agents SDK 实拉）
**inject→reason→distill→consolidate 四步循环，冲突 recency wins；SQLite+FTS5 免向量库；按项目打 tag；周导出备份**。
- 判非重复：cc 落两级沉淀（日志→长期）；本点=**个人落地路径+循环形状**。增量≥60%，合并保留增量落地。
- 提升层：工作流（个人记忆系统）。

### 7. 记忆层写语义与信号（来源：Future AGI Glossary 2026-05-21 实拉）
**semantic=选择性写+dedup+TTL，信号=ContextRelevance/Recall/staleness；知识图谱=实体去重 upsert；tool-call cache=会话级 hash-keyed**。
