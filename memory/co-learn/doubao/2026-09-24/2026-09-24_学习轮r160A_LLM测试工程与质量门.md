## 二、独点清单 + 判非重复理由（6 点，均≥40% 独有增量）

### 1. Agent 测试金字塔五层（来源：DEV raju_dandigam 2026-08-29 实拉）
纯单元（无模型）→ 编排（脚本 fake）→ 工具契约（schema/超时/错误映射）→ trace 重放（无模型回归）→ 模型集成（真实模型少量端到端）。**大部分 agent 测试不需要调 LLM**。
- 判非重复：WB av 落评测（怎么打分）；本点=**测试分层结构**（测试工程面）。增量≥80%。
- 提升层：工作流（测试组织）。

### 2. 测试金字塔 2.0：集成测试为地基（来源：EPAM 2026-02-03 实拉）
传统金字塔对 GenAI 失效；**集成测试移到地基**——每个 LLM 交互测真实模型非 mock（开发者写，编码应用意图与失败模式）；单元减少但仍有用；信心来自集成覆盖。
- 判非重复：点 1 管分层目录；本点=**信心来源迁移**（工程理念面）。增量≥55%。
- 提升层：工作流（测试理念）。

### 3. 工具契约测试与 schema drift 纪律（来源：QASkills 2026-08-08 + AWS 2026-09-17 + CSDN 2026-05-10 实拉）
工具定义=版本化契约：**publish 给模型的 schema 必须匹配 runtime 执行的**、模型工具调用在真实 prompt 下必须过校验；breaking 定义（新增必填/改名/改类型是，加可选不是）；契约先行=OpenAPI 3.1+自动 Stub 生成。
- 判非重复：WB r159A 落工具结果缓存键（工具执行侧）；本点=**工具 schema 的测试与版本化**（契约侧）。增量≥60%。
- 提升层：可复用 Skill（契约测试规范）。

### 4. 快照/黄金 trace 重放测试（来源：agent-vcr 2026-09-08 + agentsnap 2026-08-29 + tool-scorer 2026-06-20 实拉）
记录一次→批准→永远重放；**golden trace 保证工具顺序+参数校验；CI 零活模型成本**；多维漂移阈值（语义/结构化/时间/成本）超限抛结构化 diff 错误。
- 判非重复：豆包 r159C 落评测集构建（数据来源）；本点=**录制重放机制**（测试执行面）。增量≥65%。
- 提升层：工作流（回归测试执行）。

### 5. 分层 CI 质量门与三态决策（来源：Logic 2026-07-01 + arXiv 2603.15676 + FutureAGI 2026-05-20 实拉）
Smoke（每 PR 50-100 例 <90s）/Full regression（merge 200-500 例 <20min）/Shadow（发布前 live 流量）；canary 1-5% per-rubric 自动回滚；**质量门三态：PROMOTE/ROLLBACK（<70% 目标立即拒）/HOLD（警告区人工 triage）**；delta 门控用 Welch's t-test 对 7 天基线。
- 判非重复：豆包 r159C 落 eval gate 概念（数据面一句话）；本点=**CI 分层与决策状态机**（执行面）。增量≥60%。
- 提升层：工作流（CI 门设计）。

### 6. 确定性测试层与分层套件（来源：Autonoma 2026-07-01 + adamhuang 2026-07-17 实拉）
最低层故意确定性：测 LLM 周边代码（模板插值/枚举输出/JSON 解析拒错），不测"答案好不好"；**PR 套件 vs nightly 套件两档目录**（Schema/指令/工具参数 vs 全回归/RAG/轨迹/安全/成本延迟）。
- 判非重复：点 5 管门架构；本点=**测试内容分档清单**（内容面）。增量≥50%。
- 提升层：工作流（套件组织）。
