## 二、独点清单 + 判非重复理由（5 点，均≥40% 独有增量）

### 1. 系统提示分层分块结构（来源：Nesyona 2026-06-01 + AIPromptsHub 2026-06-15 + Anthropic system-prompt-writer 2026-03-17 实拉）
四层=Instruction（主指令+变量槽）/Context（事实/人设/已检索块）/Format（输出 schema/节序/长度上限）/Guardrail（禁列表/反编造）；Anthropic 推荐分节+XML/Markdown 划界，混合式=Markdown 头管大节 + XML 标签管节内；可移植七段式=Identity/Mission/Operating rules/Tool policy/Output contract/Examples/Escalation and abstention。
- 判非重复：豆包 r156-B 落"推理与答案分两块可寻址 + 3 区块以上标签划界"（结构化输出面）；本点=**系统提示的完整分层骨架与可移植模板**（组件层 vs 结构层）。增量≥70%。
- 提升层：工作流（提示结构）。

### 2. 指令位置效应与 sandwich 技术（来源：AI Tools Guidebook 2026-05-20 + AI/TLDR 2026-06-13 + Agent Patterns 2026-06-18 实拉）
首因+近因效应：开头与结尾注意力最强、中间最弱（lost-in-the-middle 中间信息准确率降 30%+）；**必须被遵守的规则要出现两次——首尾各一次（sandwich）**；单行简单规则即使放中间也有效、复杂多步指令必须首尾；末尾指令在 KV cache 注意力窗口最活跃。
- 判非重复：WB cc 管"上下文压缩/预算"；本点=**注意力分配的位置工程**（相邻不同面）。增量≥85%。
- 提升层：工作流（提示编排）。

### 3. 工具描述工程：description 是第二 prompt（来源：Together 2026-09-19 + Neural Base 2026-04-22 + AI Workflow Lab 2026-08-07 + Anthropic 实拉）
description 字段不是文档是 prompt 文本——每次请求随模型发送；**重写描述是工具 schema 最高杠杆改动**；写法=一句单职责 + 1-2 个具体何时用 + 说明何时不用/不适用于什么；模型靠描述（非名字）消歧相似工具；enum 替代自由字符串防幻觉值；参数描述含格式/约束/缺值行为；required 显式；把描述写给新同事看（带隐式上下文）。
- 判非重复：WB sa 落"技能描述触发/激活"（Skill 层描述）；本点=**工具（function）层 description 编写规范**（不同对象）。增量≥60%。
- 提升层：可复用 Skill（工具描述规范）。

### 4. few-shot 选择策略与动态检索（来源：Kinda Technical 2026-09-03 + arXiv 2509.13196 + NerdLevelTech 2026-07-26 + Manning 2026-09-17 实拉）
四策略=random（易任务）/similarity-embedding（最有效通用、production 首选）/diversity（输入多样）/difficulty（难度匹配）；**3-5 例最佳准确率-成本比、3 例后平台**；覆盖清单=简单规范例+复杂脏输入例+边界歧义例；**最后例受 recency 影响最大、须精确匹配目标输出**；例序不同可致 30+ 绝对百分点差异；production 用 embedding 相似度动态选例。
- 判非重复：点 2 管指令位置；本点=**示例的选择与排序策略**（样例面 vs 规则面）。增量≥75%。
- 提升层：工作流（示例工程）。

### 5. 约束配替换与越界重定向（来源：TechProFree 2026-07-09 + FreeCodeTutorials 2026-03-28 实拉）
约束块=3-6 条核心行为（编号）+ 边界禁列表（**每条 ban 配 replacement**，不只说"不要 X"）+ 越界时重定向行为（"我只处理 CloudStore 相关问题"）；语气校准=2-3 词+一个 like 比喻优于整段描述；角色具体化（"senior tax attorney with 15 years"优于"helpful assistant"）。
- 判非重复：点 1 管结构骨架；本点=**禁列表的写作纪律（配替换/重定向/可执行性）**。增量≥65%。
- 提升层：工作流（约束编写）。
