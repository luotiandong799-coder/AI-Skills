## 二、独点清单 + 判非重复理由（6 点，均≥40% 独有增量）

### 1. 五可靠 vs 三烧钱模式（来源：Respan 2026-05-22 实拉）
router/parallelizer/evaluator-optimizer/orchestrator-workers/hierarchical handoff 五模式可靠；**无步预算纯 ReAct/全自主/无终止条件三模式烧钱**；"agent 与 workflow 是模型路由自由度光谱非两类"。
- 判非重复：WB ed 落协作纪律（组织面）；本点=**模式可靠性与成本判据**（拓扑面）。增量≥75%。
- 提升层：工作流（模式选择）。

### 2. 工作流模式目录与选择判据（来源：Mastra 2026-07-17 + Gazar 2026-09-23 实拉）
五模式对照表（谁决定路径/最佳场景）：orchestrator-workers=LLM lead 运行时/open-ended；chaining=代码固定/多阶段；parallel=代码全发/独立子任务；routing=分类器/单入口多请求；evaluator-optimizer=代码+模型反馈/明确评估标准；**并行两味=sectioning vs voting**。
- 判非重复：点 1 管可靠/烧钱；本点=**模式目录与适用场景矩阵**（目录面）。增量≥60%。
- 提升层：工作流（模式选择）。

### 3. Orchestrator-worker 解剖（来源：Kaya 2026-05-27 + Blck Alpaca 2026-06-09 + ScaleEngineer 2026-07-13 实拉）
Lead 拆 3-5 并行 worker（隔离 context/structured artifact 返回）；**Synthesis=Lead 唯一作者**；verifier-judge 可选按 rubric 评轨迹；Anthropic 测比单 agent 提升 90.2%。
- 判非重复：豆包 r158B 落模型路由（模型层）；本点=**orchestrator-worker 角色分工细节**（结构面）。增量≥65%。
- 提升层：工作流（多 agent 结构）。

### 4. Supervisor/层级拓扑与子 agent 即工具（来源：Anthropic PDF + DecodeTheFuture 2026-05-09 + Red Hat 2026-07-01 实拉）
中央控制器协调多角色 agent；**subagent 被当作工具——tool-calling 模型决定调哪个 agent 工具**；逐分支 token 预算/取消游走子树/干净审计轨迹。
- 判非重复：点 3 管 orchestrator 平级拆；本点=**层级嵌套拓扑**（拓扑面）。增量≥55%。
- 提升层：工作流（层级架构）。

### 5. 状态机建模五件套（来源：LangChain 2026-07-22 + CallSphere 2026-05-05 + Alice Labs 2026-05-23 实拉）
节点=工作/边=确定或条件/**typed state schema=单一真相源/reducers 合并部分更新/checkpointers 持久化/interrupt 供 HITL**；确定性多 agent 从共享状态定义开始。
- 判非重复：WB r159B 落终态分型（结果状态）；本点=**过程状态建模**（状态面）。增量≥60%。
- 提升层：可复用 Skill（状态机工作流建模）。

### 6. 六大反模式与三防护（来源：AgentPatterns 2026-06-28 + Saram 2026-07-12 + INOVAWAY 2026-03-26 + COMPEL 2026-04-06 实拉）
over-orchestration（单 loop 没试先上多 agent）/God Agent（一 agent 万 token）/reliability paradox（0.95^5=0.77）/handoff 贪婪（12K 全传）；**三防护=turn-count bound/observation-insertion 纪律/tool allow-list**；五 context 失败模式（poisoning/distraction/confusion/clash/rot@100K）。
- 判非重复：全库无工作流反模式目录面。增量≥85%。
- 提升层：工作流（反模式规避）。
