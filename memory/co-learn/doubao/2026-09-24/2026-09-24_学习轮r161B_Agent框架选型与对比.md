## 二、独点清单 + 判非重复理由（6 点，均≥40% 独有增量）

### 1. 三大架构范式与下游后果（来源：RockB 2026-05-08 + MarsDevs 2026-05-10 + FordelStudios 2026-09-02 实拉）
graph-based（确定性状态流）/role-based（角色团队）/conversational（自然语言消息循环）——**架构差异驱动学习曲线/token 成本/可调试性/生产适合度全部下游后果**。
- 判非重复：r160B 落通用模式目录（拓扑面）；本点=**框架范式分类**（实现面）。增量≥70%。
- 提升层：工作流（框架选择）。

### 2. 六框架选型矩阵（来源：Blck Alpaca 2026-08-03 + Nesyona 2026-05-01 + Effloow 2026-04-07 实拉）
LangGraph=生产级有状态/审计强；CrewAI=最快原型（20 行 role crew）；OpenAI SDK=handoff/guardrails/tracing 内置；MAF=.NET/Azure；Claude SDK=subagents/hook；Mastra=TS 栈。
- 判非重复：全库无框架对比矩阵面。增量≥85%。
- 提升层：工作流（选型决策）。

### 3. 成熟路径与工具层框架无关（来源：BigAI 2026-05-22 + ILMTEC 2026-06-26 实拉）
**CrewAI/OpenAI SDK 验原型→LangGraph 上生产；工具保持框架无关让迁移可行**；多数团队分级成熟。
- 判非重复：点 1/2 管选；本点=**迁移路径**（过程面）。增量≥55%。
- 提升层：工作流（架构演进）。

### 4. LangGraph vs OpenAI SDK 重心差异（来源：GingerLabs 2026-08-06 + AgentNative 2026-03-13 + DEV 2026-09-15 实拉）
**可恢复状态机 vs 有界 agent run+应用生命周期；HITL 原生 vs 自建；锁库高 vs 无；hybrid stack=推理框架+durable execution（Temporal）**。
- 判非重复：点 2 管矩阵；本点=**两框架深度对比**（重心面）。增量≥60%。
- 提升层：工作流（架构决策）。

### 5. Pydantic AI 类型边界与自动自纠正（来源：Kanopy 2026-05-07 + Respan 2026-04-29 实拉）
**typed 依赖+result type 运行时校验+无效输出自动带校验错误重试（1-2 次内成功）；依赖注入可 mock+Logfire 追踪**。
- 判非重复：全库无类型安全 agent 定义面（输出校验已有散点，本点为框架原生机制）。增量≥65%。
- 提升层：工具（类型安全开发）。

### 6. 轻量框架定位："谁拥有栈的哪一层"（来源：dreaming.press 2026-06-24 + Web3AI 2026-05-13 实拉）
**Pydantic AI=类型边界；OpenAI SDK=编排原语；Agno=运行时/记忆/控制面（最快）；决策本质=多少栈交给第三方拥有**；全框架 MCP 通用。
- 判非重复：点 5 管 Pydantic AI 单点；本点=**分工定位哲学**（决策面）。增量≥50%。
- 提升层：工作流（选型哲学）。
