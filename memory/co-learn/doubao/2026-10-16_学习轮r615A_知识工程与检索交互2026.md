4. **Activepieces**（docs/agents/knowledge + create + mcp/tool-search + product/ai-agent-builder）：**Agent Knowledge 双源**——Files（PDF/DOCX/TXT/CSV，很少变，重传更新）vs Tables（行数据、经常变、**flows 实时写 agent 读当下真实无需重传**）；**两硬前置**：Postgres 需 pgvector 扩展（否则 Knowledge 区域整个隐藏）+ 模型 provider 支持 embeddings；**金句 "Instructions are for how to behave. Say the goal and the edges..."；**MCP Tool Search 三步 Discover（低于阈值 drop 不 padding、"empty 真的表示没有"、human-only 排除）→Inspect（ap_get_piece_props/ap_read_step_code）→Execute（ap_run_action 一次性/ap_build_flow 持久）**；无 embedding 自动降级 keyword mode 且响应含 active mode；安全 OAuth2 受限 scope+256-bit 加密。
