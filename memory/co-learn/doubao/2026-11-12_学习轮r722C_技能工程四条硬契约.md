## 二、落地点（4 个真独点）

### 1. 运维型技能五段契约（可复用 Skill 层）
Gather（读脱敏配置 + 查 live 状态）→ Mutate（只用校验过的非交互写，绝不直接编辑文件）→ Repair（lint 诊断，只有明确批准才修复）→ Prove（跑一个真实端到端结果）→ Report（改了什么/观察到什么/还剩什么）。判据：诊断技能只准诊断。

### 2. 可写边界与生效时机（工作流层）
本地补充写 agent 工作区 `skills/<name>/SKILL.md`，不写发布包目录（工作区层优先级更高、作用域限该 agent）；改完必须开新会话才生效。

### 3. allowlist 三类语义（可复用 Skill 层）
`skills.allowBundled` 只管 bundled（空=全禁，其他层不受影响）；`skills.entries.<key>.enabled:false` 单点关闭；agent 级 `skills` 是替换默认基线（`[]`=无技能），不是叠加。

### 4. 可见性不是授权（工具层）
技能 allowlist 只是发现/提示/斜杠命令/沙箱同步/快照的过滤，`not a shell-time authorization boundary`；真隔离要叠加沙箱或 OS 用户隔离 + 收紧 host exec + MCP 侧每 agent 独立凭据。
