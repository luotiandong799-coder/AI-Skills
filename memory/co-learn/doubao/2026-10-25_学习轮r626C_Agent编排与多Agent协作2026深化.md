## 三、提炼的核心方法与关键事实
1. **编排者永不自己实现**：triage→plan→delegate→独立评审 gate；Delegation only。
2. **程序即编排**：控制流（Promise.all/while/if）就是编排，无 graph DSL。
3. **ManagedAgent 工具化**：子 agent 包装成 name+description 的工具供 orchestrator 调用。
4. **进程治理**：idle eviction（30 分钟）+bounded live process count（4）+取消终止进程树。
5. **协作载体**：共享 Memory 同步；角色化分工（Manager/Custodian）；简单 agents 代码通信>刚性图。
6. **编排架构三选**：Sequential（输出=输入）/Parallel（fan-out+fan-in）/Hierarchical（子任务不可预知）。
7. **双飞轮进化**：协作底座沉淀执行轨迹/工具日志/成败案例→调优引擎清洗→自动评估→持续进化。
8. **交接载体**：黑板模式（异步共享状态写读）/Workboard 结构化跟踪/bindings 消息路由。
