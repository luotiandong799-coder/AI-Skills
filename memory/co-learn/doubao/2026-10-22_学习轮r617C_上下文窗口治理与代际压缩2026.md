## 四、提炼核心方法与关键事实

1. **Context window 是 RAM 不是 storage**：子任务完成 artifacts evict；持久记忆（偏好/硬约束/学得行为/身份事实/行为模式）外部存储每轮开头 semantic search 固定预算 5-10 检索；"Retention 来自架构不是 token 数"（augmentable）。
2. **上下文四策略**：Write（外化）/Select（精确检索）/Compress（动态压缩）——先外化/检索减量再压缩。
3. **五层压缩流水线**：Budget reduction→Snip→Microcompact→Context collapse→Auto-compact——按压力类型选策略，单一策略无法应对所有压力。
4. **Level-1 先于 Level-2**：先只重写违规节点 payload（保留 turn 边界）再链压缩合并连续节点成 synthetic summary——破坏性排序。
5. **Opaque Compression 边界**：短会话/重取便宜/要最大节省时用；99%+ 比率但不可解释，probe-based eval 才能验证，调试/artifact tracking 禁用。
6. **Tiered Context Strategy**：窗口上限 10-20 turns 起步；膨胀上下文=复利成本（2000-token×1000 对话=$10/day）。
7. **Payload 稳定性三信号**：payload 恒定（~2000 tokens）+早期约束仍被引用（via summary）+token 指标无线性增长——压缩生效判定。
8. **多 agent token 放大**：orchestrator+3 specialist=10-20x 单 agent；四设置控成本（Cap Tokens/最小 Iterations/工具响应小/窗口长度）。
9. **持久化压缩**：compacted context durable（写存储 state，新 run 从摘要起；undo 触及摘要清摘要重压）；native compaction（Anthropic context editing/OpenAI stored responses）历史永不重发、provider 切换不丢会话；客户端截断镜像 compaction marker。
10. **MemAgent/MemGPT**：固定长度可覆写 token memory 替代无限膨胀（8K→3.5M 外推）；两 tier memory+agents 可编辑自己记忆。
11. **记忆-技能统一谱系**：检索/冲突检测/陈旧识别/效用评估四子问题跨域共享；Delta+periodic snapshot 40x 存储缩减；Dify 三层缓存（链路快照/语义指纹/工具结果）。
12. **In-Context RAG 边界**：<100K 文档整集入窗比 vector DB 更准更快（"Context is the new RAG"）；大数据集走检索（retrieval 更便宜可靠）。
13. **治理评测**：payload 稳定性/probe 验证压缩保真/traces→evals 改进 tool selection/RAG 环节单测/SKILL.state O(1) footprint 显式执行状态。
