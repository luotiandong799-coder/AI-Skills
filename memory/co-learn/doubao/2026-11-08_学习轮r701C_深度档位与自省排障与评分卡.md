## 三、三点落地

1. **回答前先给深度档位与 token 估算**（`defaults/wb-max-token-saver` KB + 指针，1.98.0→**1.99.0**）：25/50/75/100% 四档先报估算再回答；输入估算散文"词数×1.3"、代码"字符÷4"；输出按复杂度给区间（3–8×/8–20×/10–25×/15–40×/10–30×）；同会话已选档位静默沿用，一行答案不弹选择。**提升层：可复用 Skill（成本控制）**。
2. **agent 自省式排障四阶段**（`wb-debug-loop` KB + 指针，1.369.0→**1.370.0**）：反复失败先捕获（错误 + 最后成功步 + 最后失败调用 + 重复模式 + 环境假设）→ 对号入座判模式 → 只做最小纠正动作 → 出结构化自省报告；不许盲目重试。**提升层：工作流（排障）**。
3. **证据锚定的 1–5 评分卡**（`wb-agent-evaluation` KB + 指针，1.148.0→**1.149.0**）：先立比较基座；每维 rubric 每级写清"什么证据算这一级"，同一证据对任何对象同分；权重只影响综合强调不参与单维打分；张力两轴分开报告绝不取平均；分数带证据锚。**提升层：可复用 Skill（评估）**。
