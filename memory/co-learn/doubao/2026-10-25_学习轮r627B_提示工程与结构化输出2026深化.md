## 三、提炼的核心方法与关键事实
1. **System Prompt 五组件+缓存布局**：ROLE/CONTEXT/INSTRUCTIONS 按序、stable content first；每句挣位置；Role 写"不是什么"。
2. **结构化输出 Prompt 工程**：约束输出形状（contract spec）；五件组合（instructions+context+example+uncertainty+format control）；不可信输入分隔符。
3. **Schema 三件套**：TS interface 展示法放 system prompt；显式边界指令；validator agent 第二次调用。
4. **Output Contract 设计**：closed value lists+"other"/"unknown" fallback+空输入 literal object；schema 声明式参数。
5. **Prompt 资产组织**：四类归档（task/system/workflow/tool）；prompts as code 版本控制；合并微任务为 sections。
6. **上下文自律防过载**：大文本走 RAG；150k+ 长文档预处理；Provide defaults not menus。
7. **生产五件结构**：Role（双向）/Context/Task/Constraints/Output format。
