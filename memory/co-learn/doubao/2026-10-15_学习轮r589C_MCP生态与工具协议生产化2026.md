## 二、核心方法与关键事实（带来源，已核验）

1. **stateless 迁移**：2026-07-28 移除握手/会话/所有 server-initiated requests；每请求 `_meta` 自足；round-robin 扩展（MCP blog 2026-07）。
2. **安全基线**：tool descriptions=untrusted input；tool poisoning 跨 agent；lifecycle bypass 握手前 tools/list；per-server scoped credentials+窄 OAuth scope（OWASP/IETF/Cloudflare 2026）。
3. **上下文税**：SCOUT hybrid retrieval（BM25+dense+RFF）；Code Mode progressive disclosure 99.9% token 减；offload 进 gateway（arXiv/Cloudflare 2026）。
4. **通道选型**：MCP vs CLI 10-35x token+72% reliability；MCP vs RAG grounding 赢但贵数量级——低量正确性关键用 MCP（devgent/infragistics 2026）。
5. **Tasks**：>10s 工具返回 durable task（taskId/ttlMs/pollIntervalMs）让 planner 不 timeout（SEP-2663）。
6. **编排分层**：MCP=agent 对工具，A2A=agent 对 agent；MCP 需独立 Orchestration Layer 实现价值（alice labs/arXiv 2606.09182）。
