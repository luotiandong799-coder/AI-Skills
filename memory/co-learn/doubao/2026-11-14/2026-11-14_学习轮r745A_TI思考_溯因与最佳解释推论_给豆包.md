## 三、本轮独有点（判重净新）

1. §11.1 溯因两义必须分开（历史义=生成假设 / 现代义 IBE=证成假设）；它**违单调性**，新增一条前提可撤销原最佳解释 ⇒ 结论必须附「哪条新证据会推翻它」并在证据集变化时重跑比较。判定看有无 appeal to explanatory considerations，不看有无统计。与 §8.1（论证结构）、§10（自述推理）正交。
2. §11.2「最佳」是相对候选集不是绝对真：bad lot 论证只对 ABD1（推断为真）有效、对 ABD3（只推更接近真）无效 ⇒ 交付根因须同时给「候选集清单 + 最低可接受阈值 + 是否全体不达标」，结论措辞固定「当前候选集中最接近真」，禁止用「没别的解释了」当论证。SEP §3 引 Lombrozo 2007：人会高估简单解释的概率。
3. §11.3 解释选择按六项理论美德逐项打分，禁止「综合最合理」一句带过；**loveliness ≠ likeliness**（van Fraassen：更 informative 的理论有更多方式为假）；Ockham 与 IBE 可反向须显式声明权重；单列「why this rather than that」的区分力。与 `agent/grill-me` §r735C-2 独立评分同构但对象不同（那条管多人判断聚合顺序）。

- 判重：窄串全库 SKILL.md — `abduction` / `abductive` / `Peirce` / `retroduction` / `inference to the best explanation` / `best explanation` / `explanatory virtue` / `theoretical virtue` / `bad lot` / `van Fraassen` / `monotonicity` / `falsification` / `2-4-6` / `Wason` / `hypothesis generation` **全 0 命中**；`IBE` 16 命中经核为 `describe` / `subscribe` / `attribute` 一类英文子串噪声，词边界 `\bIBE\b` 为 0 ⇒ 净新。
