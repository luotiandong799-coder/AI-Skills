## 二、落地点（4 个真独点）

### 1. description 一行 ≤160 字符（可复用 Skill 层）
原文 `keep it one line and under 160 characters`；它同时出现在 agent 上下文与斜杠命令发现面。判据：description 是索引不是摘要，细节下沉正文/references。

### 2. 两个触发开关方向相反（工具层）
`user-invocable`（是否暴露为斜杠命令）vs `disable-model-invocation: true`（不进系统提示、只能 /skill 手动跑）。判据：一个管人能不能点名，一个管模型能不能自动用；两个都关=死技能。

### 3. `command-dispatch: tool` 绕过模型直连工具（工作流层）
配 `command-tool` + `command-arg-mode: raw` 原样转发参数。判据：确定性命令不必过模型，省 token 且免掉参数被改写。

### 4. `{baseDir}` 替代硬编码路径（工作流层）
技能目录内文件用占位符引用，agent 解析到技能自身目录。判据：技能要能换机器/换工作区/被复制安装，写死 `D:/...` 一搬家就断且断在运行期。
