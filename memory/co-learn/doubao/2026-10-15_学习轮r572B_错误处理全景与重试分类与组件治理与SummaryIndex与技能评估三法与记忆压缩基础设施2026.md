## 落地（execute 3.84.0 → 3.85.0，+3 章）

1. **错误处理全景：Error workflow 独立失败流程 + 提交/回滚两型 + ACID tag + 暂停续跑两模式**（来源：n8n Docs 2026-06-19 + Make 2026-09-08）
   - error workflow=失败时运行的独立流程（Error Trigger 开头，跨多 workflow 复用）
   - Commit=停+保存已处理 / Rollback=停+回滚；回滚只对 ACID tag 事务模块生效
   - Store incomplete executions：开启=暂停移入待处理可续跑 / 关闭=停止+回滚
   - **提升层**：工作流

2. **重试粒度与分类：节点级默认上限 + 从失败步骤重跑 + OOM/超时除外 + AI 三分类 + 死信表**（来源：n8n 2026-07-03 + Pipedream 2026-10-12）
   - 节点级 Retry On Fail（默认上限 5 次/5 秒，超越用 IF+Wait 循环）
   - 重试从失败步骤重跑不从头；OOM/超时不自动重试
   - AI 三分类（transient/permanent/needs_human）+建议退避+死信表（payload+诊断+人工动作）
   - 错误两型（workflow 改配置 vs step 改代码）+错误包装（库错不清抛自定义）
   - **提升层**：工作流 / 工具

3. **组件代码执行治理（allow 开关 + 白名单目录 + 索引路径）+ 输入校验错误包装**（来源：Langflow 2026-08-09 + Pipedream 2026-10-11）
   - LANGFLOW_ALLOW_CUSTOM_COMPONENTS=false 全局阻断任意代码执行；COMPONENTS_PATH 白名单目录+INDEX_PATH 预构建索引
   - 输入校验失败抛包装错误（可读可定位）
   - **提升层**：工具

## 落地（compressor 3.681.0 → 3.682.0，+3 章）

1. **Summary Index 摘要索引 + 多路召回 Rerank + chunk 尺寸经验值**（来源：Dify 1.12.0 blog 2026-02-05 + Dify Docs 2026-05-18 + Dify legacy 2026-04-27）
   - Summary Index：chunk+summary 双向量，命中 summary=整组共享 chunk 一起返回（碎片→全上下文）
   - 多路召回替代 N 选 1：跨关联库检索+合并+Rerank 语义重排
   - chunk 500-1000 token，600+100 重叠最理想；先清洗源文档（页眉页脚/页码/导航）
   - **提升层**：工作流 / 工具

2. **技能评估三法：SkillAxe 自我打磨闭环 / ACES Skill Lift / 强 eval 失败驱动**（来源：微软 SkillAxe 2026-10-13 + arXiv ACES 2608.20614 + Iwo Szapar 2026-09-30）
   - SkillAxe：执行对照→四维诊断→改进简报→重写→再测（SkillsBench 32.5%→41.6%）
   - ACES Skill Lift：带/不带技能配对对比（NVIDIA 实测 300+ 技能平均 41/39 分，跨 harness 不可直接比）
   - 强 eval：failure-derived（真实失败优先）+no-skill 基线+留诊断证据
   - **提升层**：可复用 Skill

3. **记忆压缩基础设施：Headroom 失败学习+跨 agent 共享去重 + Condensate 量化 + Honcho reasoning-first**（来源：CSDN 2026-10-03 + Condensate 2026-10-13 + Honcho 2026-05-26）
   - Headroom=上下文压缩基础设施层（入口先处理）+失败学习（失败会话→改进规则）+跨 agent 共享去重
   - Condensate 量化：83.6% LoCoMo-10 recall @1,647 tokens vs 全转录 20,476 tokens（约 10 倍）
   - Honcho reasoning-first：提取结论不是存 chunk
   - **提升层**：工具 / 可复用 Skill
