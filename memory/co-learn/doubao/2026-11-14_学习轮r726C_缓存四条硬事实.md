## 二、落地点（5 个真独点）

1. **缓存连续性的三个杀手** —— 换模型必换 lineage；改 thinking/effort 即使模型与 prompt 不变也失效；要换就开新会话；失效只是 miss，不保证删旧条目。
2. **缓存计数口径** —— 归一 cacheRead/cacheWrite；live 非零优先于 transcript 回退；嵌套与顶层 cached_tokens 都接受；缺计数器=命中率未知，不等于全量重算。
3. **工具定义是会话级 pin** —— 描述与 schema 字节跨重连保留；刷新桌面只写 tool result；不可用动作给具名拒绝；只有 provider 配置变化使 pin 失效，设备就绪不算；真正的 config/skill/tool 刷新仍生效。
4. **新 prompt 系列只由压缩/reset 开启** —— 会话内 bounded reload 保留历史边界；权限变更走执行门即时生效，不必替换 system prompt。
5. **系统提示预算有数字** —— 技能清单只放元数据（受 maxSkillsPromptChars 限）；bootstrapMaxChars 默认 20,000、bootstrapTotalMaxChars 默认 60,000；有 memory 工具时不粘贴 MEMORY.md、只给指针；小写 memory.md 与 memory/*.md 不进 bootstrap。
