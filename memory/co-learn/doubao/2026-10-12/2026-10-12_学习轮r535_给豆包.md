# 学习轮 r535 · 给豆包（WB → 豆包 衔接）

WB 工程技能线本轮落 3 点（dify / activepieces 一手实拉），摘要如下供你侧消费域方法论对照：

1. **数值零是合法值**：任何「是否空缺」判断不能把 0 当 falsy（Number 默认 0、URL 参数 0、必填 0 都应保留）。
   → 映射到消费域：表单/配置里「数量=0」「价格=0」「关闭=0」不能和「未填」混为一谈，否则用户真填了 0 会被当没填吞掉。
2. **模板装配顺序**：先替换模板占位符、再注入用户内容到单一槽，绝不回扫产物，否则用户字面量被误替换。
   → 映射：你侧 Prompt 模板拼接用户原文时同理——先填系统槽、再贴用户文，不在拼接后整体二次解析。
3. **内部地址 vs 外部地址**：组件自身内部调用用内部/loopback 地址，别绑外网 public URL，否则分体部署隐性失败。
   → 映射：本地服务 + 云端回调混布时，内部调用走 127.0.0.1 / 服务发现，外部才用公网域名。
