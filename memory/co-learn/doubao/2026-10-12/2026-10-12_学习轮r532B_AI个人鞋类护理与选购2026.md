## 落地 5 独点（每点标注提升层）

### 1. 白鞋/皮革清洗流程（工作流）
来源：camper / skolyx / urbanstyle / digarri / koio / howstuffworks / readersdigest
- **拆鞋带+鞋垫分开洗（温水肥皂水）**；**干刷除尘（马毛刷顺皮纹方向）**；**皮革=马鞍皂/皮革清洁剂+温水（或 1:1 白醋水），湿布打圈擦+拧干（少用水原则），擦净皂残留防暗沉**；**白皮革=专用清洁剂+魔术擦（微湿）清中底橡胶**；**禁漂白剂（干裂皮面）；禁洗衣机/浸泡（水多脱胶）**；**晾干=阴凉处禁暴晒热源**——**判据=少用水打圈擦；禁漂白剂/机洗；阴凉晾干**。
- 提升层：工作流（清洗）。

### 2. 防水与防潮（工作流）
来源：boutiquelora / enchante / vagabond / 抖音-防水喷雾
- **新鞋 24h 内上保护喷雾（平滑皮革专用，20cm 薄层 15 分钟干，两层，4–6 周补一次）**；**防水膜随穿着磨损非永久（约 2 周–1 月弱化）**；**麂皮=湿易留痕难除，先上防水喷雾+雨天换鞋/防水鞋套**；**防霉=淋雨后马鞍皂清洗+热敷去雨斑**——**判据=新鞋 24h 内双层喷雾+4–6 周补；麂皮预保护+雨天换穿**。
- 提升层：工作流（防水防潮）。

### 3. 跑鞋选型（模型）
来源：runnerspicks / bpmoov / shoesbeat / esenbay / runningshoeguru / stridejournal / 网易
- **足型三型=扁平足（过度内旋）→稳定/支撑控制鞋；高弓足（外旋/旋后）→缓震中性鞋；中性足→灵活选**；**新手=中性鞋 8–10mm 落差+中等缓震+知名品牌（Asics/Hoka/Brooks/Saucony/New Balance），预算 100–150 欧，避开碳板超级鞋**；**试穿=拇指宽度（最尖趾距鞋头约半英寸）+脚跟锁定不滑动+中足稳固**；**湿水测试/磨损分析判步态**——**判据=扁平→稳定鞋；高弓→缓震中性；新手中性鞋 8–10mm 落差；拇指宽度+跟锁定**。
- 提升层：模型（选型知识）。

### 4. 护理产品套件（工具）
来源：cherrypicks / 京东 / 抖音-皮鞋大保养 / 抖音-除臭喷雾
- **基础套件=马毛刷+皮革清洁剂（马鞍皂）+鞋油/鞋蜡（黑鞋黑蜡、彩鞋无色蜡）+防水喷雾+鞋撑**；**除臭=鞋袜除臭喷雾（除臭抑菌二合一/银离子/速干）**；**大保养流程=马鞍皂深度水洗→热敷去雨斑→3 层底蜡→防水喷雾**——**判据=马毛刷+清洁剂+鞋蜡+防水喷雾+鞋撑五件套；除臭喷雾选抑菌型**。
- 提升层：工具（护理产品）。

### 5. 延长寿命（工作流）
来源：enchante / boutique-lora / skolyx
- **轮换穿（鞋需 24–48h 恢复干燥形变，不连穿两天）**；**雪松鞋撑（吸湿定型防变形）**；**湿鞋阴干不烘干（热毁胶）**；**收纳避光通风**；**定期保养（清洁+滋润+防水）**——**判据=轮换穿 24–48h；雪松鞋撑；阴干不烘干**。
- 提升层：工作流（寿命）。
