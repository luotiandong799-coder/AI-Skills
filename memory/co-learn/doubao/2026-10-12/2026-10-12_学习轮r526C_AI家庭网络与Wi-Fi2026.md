## 落地 5 独点（每点标注提升层）

### 1. Mesh Wi-Fi：死区解法与三频回程（工具）
来源：newsproductupdates / smarthomeautomate / hometosight / comstock / gadgetsfocus / hometechops
- **传统 range extender 短板=分离网络+减带宽**；mesh=多节点统一网络（单一 SSID 无缝漫游）；**30+ 智能设备或多死区→mesh（三频带专用回程=第三个 radio 做 node 间流量，大设备数不掉速）**；**节点放置=主节点与死区中间（约 50% 信号强度处，app 内有信号指示）**；**2500 平方英尺 2-pack、更大/多层 3-pack；Ethernet backhaul=有线回程最大速度**；**2026 现实=Wi-Fi 7 占新 AP 出货约 31% 但客户端适配仅约 25%**——**判据=30+ 设备或死区多→选三频 mesh；节点放主节点与死区中点；能走线就走 Ethernet backhaul**。
- 提升层：工具（Mesh Wi-Fi）。

### 2. 路由器摆放科学：抬高+中央+避开干扰（工作流）
来源：thehomepicker / gadgetsfocus / newsproductupdates
- **实测：路由器放 5 英尺高架子→每房间信号 +10–15%**（WiFi 信号向外向下辐射，**高中央位置>桌角位置**）；**避开厚混凝土墙/微波炉/鱼缸**（干扰源）；**主路由器开放式中央放置**；mesh 节点同理避开干扰物——**判据=先免费优化摆放（抬高 5 英尺/中央/避开微波炉鱼缸）再花钱买 mesh；摆放是 0 成本的第一优化**。
- 提升层：工作流（路由器摆放）。

### 3. 家庭网络分段：Guest + IoT 隔离（工具）
来源：swiftnetscan / tecnoyfoto / vic-gov / reyee / tplink / rottenwifi
- **guest network 三用途=访客隔离+智能设备隔离+儿童设备独立管理**；**VLAN 典型规则="允许 IoT VLAN 访问互联网，禁止 IoT→Trusted 任何连接"**（被攻陷 IoT 设备无网络路径到重要电脑）；**维州政府官方建议=智能设备上 guest Wi-Fi**（智能电视/扫地机器人/语音音箱）；**三网络类型=Primary/Guest/IoT**（guest 支持 user isolation；IoT 设备间隔离需单独配置）——**判据=三网分离=主网+访客+IoT；IoT 默认只许上网不许连内部设备；被攻陷 IoT 隔离在 VLAN 内无法横向移动**。
- 提升层：工具（网络分段）。

### 4. 路由器安全配置清单（可复用 Skill）
来源：asus-parental / xnspy / hiwavemakers / tecnolatino
- **家长控制=上网时段+内容类型+指定设备管理**（华硕 Kids Network 儿童设备集中一网）；**QoS=按设备保留 IP+上下行限速+时间窗**；**新设备接入邮件/推送告警（Netgear/Asus/TP-Link 都有，未知 MAC 一接入即通知）**；**VPN 可绕过 DNS 过滤（已知限制）——需搭配"为什么这样"对话，低龄儿童可路由器级 block VPN 协议**；**固件月更补丁**——**判据=家长控制+QoS 限速+新设备接入告警三件套；VPN 绕过 DNS 过滤是已知限制需对话兜底；固件按月更新**。
- 提升层：可复用 Skill（家庭网络安检）。

### 5. 家庭带宽选型：按并发设备数与场景（工具）
来源：checkfast / internetspeedtest / cablecanyon / usecalcpro / pcmag / htp
- **100 Mbps=典型家庭够 4K+视频通话多设备；重用户/大家庭 300–500；低稳定延迟=游戏/通话关键**；**对照表=1 人 25–100/2–3 人 100–300/4–5 人 300–500**；**3–4 人含 WFH=300 sweet spot+光纤/5G 上载优先；5+ 人或创作者/多摄像头=500–1000 光纤**；**关键数字=并发使用不是总设备数；对称上载=月传 2TB+ 才值得**——**判据=按"并发设备数"选速不是按人；3–4 人 WFH=300 且光纤优先上载；千兆只在增量成本低时值**。
- 提升层：工具（带宽选型）。
