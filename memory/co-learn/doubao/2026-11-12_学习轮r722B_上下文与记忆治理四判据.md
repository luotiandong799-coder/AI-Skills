## 二、落地点（5 个真独点）

### 1. 进展判定先剥非语义字段（工作流层）
比较重复调用时剥 delivery id / timestamp；有 run id 时只在 run 内评估；progress_card 比已保存内容不比 write revision；参数校验失败的调用仍计入失败。

### 2. 三同错误封动作（工作流层）
同 tool + 同 args + 同 error 连续三次即封，给模型一次恢复机会；改参/改错/成功才重置；策略否决不计失败；无自动重试。

### 3. 压缩后单独装再犯护栏（工作流层）
`Post-compaction guard` 在每次 compaction-retry 后武装，窗口内重复相同三元组即中止 run；升级路径先警告（wait 十次）后阻塞，阻塞不取消已执行调用，critical loop 阻塞整批但留一次响应机会。

### 4. 预算分母未知就标未知（工具层）
只用所选模型容量与配置上限，均不可用时显示 `?`/null，不借用通用窗口或其他模型容量；模型变更后显示 "Context window" 直到新 run 提供匹配估计。

### 5. 记忆删除报边界并按血缘删（工具层）
`memory forget` 立即删（`--dry-run` 可预览）；不删原始 transcript、自由编辑与扫描外副本；三类血缘记录分工（chunk provenance / entry origins / curated-write）；无 origin 行无法按血缘删；会话删除保留已删 transcript 归档。
