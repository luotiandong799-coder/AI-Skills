## 二、核心方法与关键事实（带来源，已核验）

1. **结构化输出契约**：constrained decoding+strict mode 消除 parsing bug 类；schema=应用契约，typed frameworks（Pydantic/zod）定义一次到处验证（socialanimal 2026-08）。
2. **Validation Sandwich**：验证失败带 error feedback 重试（非同一 prompt）；max_retries 3 后 reject；一次纠错 90→近 100%（niteagent/openlegion/CSDN 2026）。
3. **评测驱动开发**：golden dataset 每次修订跑 pass rate；Promptfoo CI gate 退出码 100；high-signal 四类用例（khimananda/promptfoo 2026）。
4. **judge 校准**：六 cue 隐藏捷径+CAR；四失败模式；over-correction；pointwise-pairwise 不一致（arxiv 2602.07996/2607.08535/2602.06625）。
5. **自动提示优化**：DSPy 编译器范式 60-80% 省手调；MIPROv2 10-40% lift；GEPA Pareto（dspy.ai 2026）。
6. **模型能力边界**：八硬边界消不掉；校准弃答必须（无 I-don't-know 则必然无限幻觉）；CoT 不可控 0.1-15.4%（arxiv 2609.17686/OpenAI 2026-03）。
7. **提示注入结构化防御**：structural separation 不拼接；per-request nonce 防闭合标签逃逸；三区分离；powerful tools 远离 untrusted context（theneuralbase/rafaelhart/securedai 2026）。
8. **输出护栏三动作**：Sanitize（污染）/Reask（可重生成）/Retry 一次（短暂失败）→fallback；refusal protocol；SDK deny rules 硬拦（openlegion/callsphere 2026）。
