## 三、提炼的核心方法与关键事实
1. **feature loop**：Plan→Implement→Validate 每步 fresh context+独立分支+spec 与代码同 commit（反 vibe coding）。
2. **验证先于自主性**：先写失败测试+验收标准映射测试+agent 不能编辑的 oracle；说不出检查保持短链。
3. **spec 是主要 artifact**：diff 可再生 spec 不可再生；发现 spec 未覆盖→加 spec 不只修代码。
4. **三层架构**：reasoning/action/validation 分离；validation 是确定性真实代码不是模型自评；换模型不用重写。
5. **TTV gap**：看似合理实现不处理边界→总是给可执行验证；不能验证别 ship。
6. **自我审查**：开 PR 前 code review 审自己 patch；ReviewBench 测抓真 bug 非评论频率。
