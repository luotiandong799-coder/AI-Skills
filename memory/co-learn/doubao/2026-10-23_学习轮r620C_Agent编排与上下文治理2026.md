## 四、提炼核心方法与关键事实

1. **委派契约**：Agent Task 节点级声明（本体配置一次职责在节点）；subagents 委派读报告 vs dynamic workflows 程序组合；交接=条件+目标+上下文传递显式 flag；编排者只收集不累积。
2. **Subagent 隔离**：clean window 开始+中间推理丢弃+只加载所需工具（lazy-loaded）+return result only；context editing 移除 stale；三规模层级 Parallel/Subagents/Teams；hub-and-spoke 子代理不直连。
3. **队列并发**：任务入队不立即执行；队列定义先行（代码内定义防动态改并发混乱）；scheduling delay/backlog 可观测；Checkpoint-Resume+幂等键 durable。
4. **记忆多层模型**：三层边界表（in-context/episodic/semantic）；记忆=真基础设施（typed stores+write-back loops）；五步写入管线（触发→embed→查→富化→upsert）；Conversation ID 键驱动；lookup-classify-write 行业标准；MemGPT 记忆管理=证据进入调用决策。
5. **上下文可见性**：Scenario Builder 捕获/传递/写入/丢失可视化；context usage 可观测；Chat Memory Manager 显式增删；context editing 移 stale；Context Hub 版本化协作；冷热分层+精炼 agent。
6. **状态冲突**：thread_id 黑板共享；KV 跨触发；冲突三类检测（重叠改动/重复努力/矛盾输出）+隔离并行；HITL 暂停点；规则优先单点注入 agent。
