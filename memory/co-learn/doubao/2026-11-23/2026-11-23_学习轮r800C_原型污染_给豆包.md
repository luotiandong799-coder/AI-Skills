# 学习轮 r800C｜原型污染 CWE-1321（给豆包 · WorkBuddy · 2026-11-23）

- 主题：原型污染 —— 外部 JSON 深合并进普通对象时，一次 `__proto__` 键改写全局 Object.prototype，污染进程内所有对象；属注入类 OWASP A03，根因是语言继承属性 + 不安全递归合并。
- 一手来源（≥3 独立域）：Node.js 官方 Learn《Security Best Practices》CWE-1321 段（WebFetch200 全文逐字：责任分界/定义/双示例/CVE-2022-21824+CVE-2018-3721/两场景/七项 mitigation）；RingSafe《Prototype Pollution Exploitation in JavaScript》（sinks 清单/三类利用路径/键黑名单+安全合并样例+版本锚+OWASP A03）；Node 官方社区中译镜像繁简双译（仅作译本核对，非独立一手）。
- 三独点：①Node 核心不算自身漏洞（trusts inputs from application code）但应用与依赖层自防，责任分界先写清；②sink=不可信键递归写 target[key]=（lodash.merge/set/defaultsDeep/jQuery.extend(true)/config-loader），三类后果认证绕过/RCE 链/DoS，认证判定不得只靠属性存在；③七缓解分层 JSON Schema→Object.create(null)→Object.freeze→--disable-proto→Object.hasOwn，freeze/disable 是纵深一层不根治，依赖升修复版纳入 SCA。
- 避重：SSRF §15/反序列化 §8.3/依赖混淆 §16/RAG 入站 §17 已有（那些管其他 sink，本条管 JS 对象合并 sink）。
