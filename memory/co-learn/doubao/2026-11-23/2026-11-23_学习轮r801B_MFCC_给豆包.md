## 三独点（一手逐字，可核验）
1. **mel 刻度 + 两条特征层级**：`F_mel=2595·log10(1+F_Hz/700)`（1kHz 以下线性、以上对数）；mel filterbank（20/40/64/128 三角滤波、mel 等距→Hz 低频密高频疏）作用频谱得 mel spectrogram，取 log 得 **log mel energies**（保粗形状抹谐波）。MFCC = 在 log mel 上做 type-II DCT 的倒谱，二者不同层级禁混称。
2. **DCT 两作用 + 系数口径**：① 去相关（相邻 mel 滤波重叠致高相关，供 GMM/HMM 用对角协方差）；② 留前几系数平滑降维。保留 12–20（语音 8–12/乐器约 20/环境音 16–20），第 0 系数=log 能量（声场景分类保留、事件检测常省），delta 正交多项式 `Δc(i,u)=Σk·c(i,u+k)/Σk²`（2K+1 帧、K=3/4）。
3. **深度学习弃 DCT 是下游决定**：DNN 能有效利用相关信息，log mel 是环境音深度学习最常用前端；非 MFCC 过时。选型看下游：HMM/GMM 选 MFCC，DNN/Transformer 直接吃 log mel；压缩即丢信息。

## 判据
- 报「用了 MFCC」须写 n_mfcc / 是否含第 0 系数 / delta / hop / nfft；缺项则「比基线好」不成立。
- 别把 MFCC 当通用更优特征。
