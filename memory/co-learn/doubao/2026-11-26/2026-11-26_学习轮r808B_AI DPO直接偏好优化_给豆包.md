- 主题：把 RLHF 的「奖励模型 + 强化学习」重参数化为对偏好对的一个分类损失；梯度里的排序误差权重是和「等权提升 chosen」的分界线。

## 方法论三独点
1. **隐式奖励重参数化**：RLHF 目标 `max E[r] − β D_KL[πθ‖πref]`（π_ref=π_SFT，β 控偏离、保多样性防 mode-collapse）；DPO 损失 `L=−E log σ(β log πθ(y_w|x)/π_ref(y_w|x) − β log πθ(y_l|x)/π_ref(y_l|x))`，隐式奖励 `r̂=β log(πθ/π_ref)`，Bradley-Terry + logsigmoid 使偏好学习变成二分类，无需显式 reward model / 价值网络 / RL 采样步。与 PPO（clip 软信赖域、on-policy）、SAC（熵进目标、off-policy）是三个不同旋钮，禁互换措辞。
2. **梯度权重是机制核心**：`∇L=−βE[σ(r̂(y_l)−r̂(y_w))·(∇logπ(y_w)−∇logπ(y_l))]`，原文把 σ(...) 标注「higher weight when reward estimate is wrong」；按隐式奖励把 rejected 排得越高权重越大；原论文明言去掉该系数的朴素版「can cause the language model to degenerate」（Appendix Table 3）。所以「chosen 做 SFT + rejected 当负样本」的等权做法不是 DPO。
3. **工程口径与边界**：两阶段（π_ref 采成对 completions → 人工标注成 D；固定 π_ref/β 优化 πθ）；无 π_SFT 时以 chosen 的最大似然初始化参考缓分布漂移。TRL 默认 loss_type=sigmoid，β=0.1、典型 0.1–0.5，β→0 即忽略参考；数据三列 prompt/chosen/rejected，model 与 ref_model 同架构；验收看 rewards/accuracies 与 rewards/margins，不是只看 loss。hinge/ipo/cDPO/robust 的 β 语义各异禁混报。边界：原论文 OOD 泛化、reward over-optimization、>6B 规模自陈开放；arXiv:2605.20834 证条件等价——RLHF 最优策略必须偏好人类偏好回答，否则 DPO 只优化相对优势，可「loss 下降却更偏好 rejected」。
