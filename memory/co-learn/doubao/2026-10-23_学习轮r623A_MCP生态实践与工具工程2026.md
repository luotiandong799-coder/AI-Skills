## 四、提炼核心方法与关键事实

1. **MCP 工具设计三原则**：按意图分组不镜像 API（更少、描述良好的工具优于 exhaustive API mirrors）；描述精确化（输入+动作+输出，动词开头）；少而够用（每 server 耗 context token 劣化 tool selection；首批五 server 覆盖多数工作流）；remote server 最大化触达。
2. **MCP server 生产护栏**：参数即用户输入（JSON Schema 验证+参数化查询，MCP spec 不代做）；服务端验证+fail closed（Zod/AJV，入参出参都验证）；两阶段输入验证（pattern+semantic）+per-tool rate limit；工具级最小权限（token 绑工具+高险工具独立账号）。
3. **工具形态三选一**：Native node（确定性步骤）/Agent tool（单动作）/MCP server（跨端消费）——按确定性/决策权/暴露面选，单 workflow 可组合。
4. **工具暴露边界治理**：scope to the job（按角色裁剪工具集）；子集发布（MCP Toolboxes 不暴露整个栈）；白名单（available workflows）；flow→tool 粒度（一个 flow 一个工具）。
5. **认证与凭据工程实践**：per-user auth（external_user_id 独立可撤销）；managed auth 免建授权流；环境变量注入（配置层零凭据）；范围 headers（一次请求限定项目/环境/用户/应用）；自动认证分发（新 project 新 key）。
6. **MCP 2026 规范演进与平台双向模式**：双向平台（消费+暴露）；flow→tool 一键暴露（Share→MCP Server）；stateless core 跑普通 HTTP+MCP Apps+Tasks extension；A2A 合并（MCP 接工具、A2A 接 agent）。
