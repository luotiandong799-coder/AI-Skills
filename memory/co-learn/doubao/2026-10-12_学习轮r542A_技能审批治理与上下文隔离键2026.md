## 落地 6 个真独点（全部带提升层）

1. **Skill Workshop：技能创作过审批队列，代理不直接写 SKILL.md** → skill-authoring 1.130.0→**1.131.0**。要点：review queue 提议 + **人工批准后才激活**；治理四件套 **audit trails/security scanning/hash binding/rollback**。提升层：工作流（技能库治理）。
2. **description 双向剪裁 + 1024 字符硬规格** → skill-authoring 1.131.0。要点：**false positives 与 false negatives 同时剪**（skill-creator 官方用样本 prompts 分析）；**max 1024 字符、无 XML 标签**；触发测试用例跑"该触发/不该触发"两侧。提升层：可复用 Skill（触发质量）。
3. **session key 是上下文隔离键：用会话 ID 不用静态值，配窗口限制** → context-compressor 3.645.0→**3.646.0**。要点：静态 key=所有用户共享历史互看上下文；天然会话 ID 当 key；持久化不等于无界（窗口独立配）。提升层：工作流（上下文隔离）。
4. **记忆后端选型分层：原型窗口、生产可查询持久化，别一上来就永久存储** → compressor 3.646.0。要点：Window Buffer（无持久）vs Postgres/Redis/Mongo（可查询）；**最常见错误是直接上永久存储**；选型问"要不要查旧历史"。提升层：工作流（记忆选型）。
5. **本地廉价模型定期压缩对话记忆：防 token bloat** → compressor 3.646.0。要点：Ollama 零成本压缩器按交互计数触发（实测可防 15x token 放大）；**压缩保留 OPEN_LOOPS 进行中状态**。提升层：工作流（记忆运维）。
6. **orchestrator 只路由不干活 + 子 agent 工具面收敛 3-5 个** → execute-discipline 3.49.0→**3.50.0**。要点：编排者只 classify+hand off+collect，不 retrieve/update/API；**每个子 agent 只见 3-5 个相关工具**；记忆按角色给。提升层：工作流（多 Agent 编排）。
