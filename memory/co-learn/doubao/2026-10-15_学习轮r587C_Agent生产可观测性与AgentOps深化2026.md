## 二、核心方法与关键事实（带来源）

- **OTel GenAI SemConv 稳定（1.29+）**：gen_ai.system/model/input_tokens/output_tokens/prompt hashes/tool call metadata 标准化；vendor-neutral 跨 OpenAI/Anthropic/自托管；AgentCore Evaluations 用 OTel 属性子集分类 spans 提评测数据；跨栈关联=LLM token 异常与 Pod OOM 同 trace；Traccia=OTel 原生治理平台
- **GenAI 遥测隐私三层**：①默认关 OTEL_INSTRUMENTATION_GENAI_CAPTURE_MESSAGE_CONTENT ②Collector redaction processor allowlist（blocked_values/blocked_key_patterns）③transform processor（OTTL）兜底；应用级脱敏最优先、网关脱敏、Collector 最后（数据已离开进程）；typed placeholders（[EMAIL]/[NAME]）保可调试；tiered retention
- **采样**：trace-level 而非 span 级（独立采样→碎片化 traces）；Rate=min(1.0, Budget/TPS)；正常 1-5%、异常/静默失败/循环>5 次强制 100%；Honeycomb=GenAI 不采样（对话缺 turn 即失值，completeness>volume，filter 滤噪替代）
- **生产 agent 五失败模式**：tool call cascade（意外 schema→补偿调用→连环失败；修=工具层熔断器=同一相关工具连续两次失败短路）/infinite retry loops/hallucination cascade（多 agent 交接复合成真实动作）/silent quality drift（input drift+retrieval drift）/confident fabrication（编造没做的工具调用结果）；hallucination loop（同推理修同错）；检测=telemetry-only（语义嵌入 step output+token 级不确定性+action metadata，微秒/步，健康运行训练）——每步第二 LLM 判断比 agent 贵
- **在线评估**：eval set 从发布日老化（六 drift modes）；trace-eval bridge=新失败模式回灌离线集；三种生产 evals=Automated scorecards/Scenario regression/Drift detection→闭环+采样 5-10%；online evals 异步后台（同步 judge 毁响应时间）；thumbs 反馈校准 judge 最便宜；traces become test cases、evals run ahead of deploys；三级 CI/CD=Level 1 unit（10-30s 卡 PR）/Level 2 golden（merge 卡部署）
- **记忆与状态**：三层=short-term（context window 最受限）/episodic/semantic；token budget 模型；性能 60-70% 填充降级；coding agent 读五文件烧 81% context 在工具结果；checkpointing=版本化快照恢复（防 crash-and-restart）；生产 checkpointer 需分布式持久性；prompt 当数据库=失败起点——durable state/retries/approvals 移出窗口；MCP Resources=持久状态接口、Roots=跨会话工作目录
- **Prompt Registry**：prompt=可部署产物（命名+版本受控）；版本不可变+commit hash 寻址；alias 运行时拉取免重部署；语义版本+评测结果链接（版本身份由性能定义）；环境晋升+一键回滚；canary/gray；git-native=prompts 入仓库（commit=版本历史）；工具=PromptLayer（registry-first）/LangSmith Prompt Hub/MLflow/阿里 MSE AI Registry
- **成本治理四层**：Prevention（smart routing）/Control（progressive budgets 先警告再降级）/Visibility（per-harness/per-model）/Safeguards（thrashing detection/scheduled-task limits/terminal approvals）；预算网关层强制（post-hoc 太晚）；每请求打 tag（team/feature/user/environment）；semantic cache 30-50%；cost per outcome 上升=管道退化信号；token budget caps block runaway loops；硬停 sloppy=分阶段降级
- **平台生态**：Langfuse（MIT 自托管）/LangSmith（托管+Polly AI）/AgentOps（auto-instrumentation+per-agent token cost）/Datadog（APM 同看）；OpenLIT（OTel harness 工程 Apache-2.0）/Helios（tracing+cost+security 单栈）/Orchid（零插桩 record-and-replay 本地回放）/Token Telemetry（MIT coding agents）/Helicone（YC W23 一行代码）/Arize Phoenix/Comet Opik/OpenObserve（LLM+infra 统一）；阿里 AgentLoop（零侵入 OTel 兼容）；智谱 AgentMore（构建/编排/知识/调优/批量评测/部署一站式）；FlagOS Skills 1.0 技能库；腾讯 WorkBuddy 企业版可观测平台（流量/成本/性能/质量四维+轨迹详情定位）
