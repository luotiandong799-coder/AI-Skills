## 三、提炼的核心方法与关键事实
1. **Contextual Retrieval**：LLM 生成 50-100 token chunk 位置上下文 prepend，embedding+BM25 用 combined text；失败率 -49%/-67%。
2. **RAG 决策阈值**：<20 万 token 直接 Prompt+缓存；几百页以上 RAG 仍更便宜更快；检索封装为模型可调工具。
3. **Agentic 检索编排**：router 最简；retrieve→judge→rewrite→retry loop；swarm 并行 backup；HyDE。
4. **Query 工程**：口语改写 3 个检索友好 query；按类型路由；复合拆子查询+上下文扩展。
5. **Rerank 流水线**：retrieve-50-rerank-to-5（丢弃优于塞满）；RRF fusion+metadata filter 先于重排；metadata boost。
6. **分块量化**：512 tokens+25% overlap；Recall@5≥0.90；先修 chunking 再上 reranker=最大单项增益。
7. **两级 chunking**：标题层级+语义边界；600+100 或 500-1200+10-15%。
