## 四、本轮落地点（3 点）

### ① 建图三级取证 + 边级置信三标（提升层：工具 + 工作流）
- Pass 1 Tree-sitter 纯本地抽结构（代码不进 LLM 语义抽取，纯代码语料跳过 Pass 3）→ Pass 2 本地转写并用 top god nodes 做领域偏置 → Pass 3 才用 LLM 子代理抽文档/论文/图片的 nodes/edges。
- 边必须带 `EXTRACTED`（源码可见，恒 1.0）/ `INFERRED`（离散档 0.95/0.85/0.75/0.65/0.55）/ `AMBIGUOUS`（进报告待人工复核）。
- 同一关系的多次发现只留最高置信那份，其余进 `also_seen`（去重不删证据）。
- 内容 SHA256 指纹做增量，不用时间戳；Leiden 按边密度聚类，结构即相似度，不另建向量库。
- 落点：`research/ki-knowledge-graph/SKILL.md`（无 version 字段，正文即全文，直接追加一节，5,496B → 7,800B）。

### ② 评审席位的独立性是流程属性（提升层：模型 + 工作流）
- 五席各自定稿后才允许交叉引用；同模型家族必须披露相关误差，跨模型只是"换底物"不是"多一个独立评审"；校准用带裁决结论的论文集（3 篇方向性 / 5–20 篇完整，每篇 5 次重复）产 FNR/FPR/balanced accuracy，未达标一律标 `NOT_CALIBRATED`；无法核验的新鲜度写 unverified，不许把重复称独立。
- 落点：`engineering/wb-agent-evaluation` KB，1.154.0 → **1.155.0**。

### ③ 对照实验设计：MDE 先行（提升层：工作流 + 可复用 Skill）
- 四个必填输入（基线率/MDE/α/power）；时长公式（均衡与不等分配逐臂取最长）；最短 1 完整周（B2B 两个业务周期、电商跨发薪日）、最长 4–8 周；多变体乘数 1 / 1.5 / 2；五类常见错；样本过高时七条退路；提前看结果必须用顺序检验；>60 天就换设计。
- 落点：**新建** `research/wb-experiment-design/SKILL.md` 1.0.0。
