## 二、核心方法与关键事实（带来源）

- **OWASP LLM01 纵深防御 2026**：五层=输入验证/硬化 system prompt/最小权限/输出验证/人工审批（ai-agent.camp）；四层 defense stack 含 guard model（Llama Guard 3/Bedrock Guardrails/Azure Content Safety 输入输出双路，小模型分类器）；LLM01 同时覆盖直接+间接注入；间接注入=攻击者向网页/文档/邮件植入指令等 agent 读取（tutorials.technology 直接=用户供文/间接=第三方供文）
- **间接注入实证**：ClawGuard=工具调用边界强制 user-confirmed rule set；SkillInject DSR 25.00→77.38%（DeepSeek-V3.2）/65.48→94.05%（GPT-5.4）/100%（Claude-Sonnet-4.6）；MCP 三层=manifest 签名（RSA 防篡改）+LLM-on-LLM 语义审查+轻量启发式 guardrail；ACL：τ_d=0.72 语义意图分类器（3B 蒸馏、8,400 benign+3,200 adversarial 微调）隔离人类复核；PoisonedRAG=百万级知识库五条恶意文本 90% 成功率；Redis context poisoning（RAG 投毒/MCP 工具描述投毒）；memwall 扫记忆 standing orders/exfil vectors/PII
- **Dual-LLM**：privileged 持工具权限+quarantined 读不可信内容，只交换不透明引用/结构化摘要（mudassirkhan 2026-05、agentpatternscatalog）；DualView=人看正常文件数据/agent 只看符号化处理后的不可信内容（Stored IPI 跨任务跨存储休眠攻击）；Asimov=确定性 denylist（Gate 1）+无状态 context-free LLM judge（Gate 2）四层优先级
- **Typoglycemia/零宽**：首尾相同+中间乱序（sorted 校验/每词一个编辑容错）；ZWSP U+200B/ZWNJ U+200C/ZWJ U+200D 插入关键词破 pattern 保模型理解；BiDi RLO U+202E；Unicode Tags 变体对工具描述/技能文件/MCP 元数据注入（CSA）；Reverse CAPTCHA 评测框架（零宽二进制+Unicode Tags 两编码、四提示级别、工具开关）；agent-hardening 技能=运行时扫描输入/输出/技能/记忆（注入/Unicode 走私/隐藏指令/凭证暴露/供应链投毒）+模糊不区分大小写匹配
- **HITL 审批门**：needsApproval:true 一等公民（Vercel AI SDK 7 GA 2026-06-25）；审批=interrupt-and-resume checkpoint（LangGraph interrupt()+Command(resume=value) 同 thread_id）；**wrap 副作用工具本身不包周围任务**（gate 在支付 API/SMTP send 前不在推理循环末）；ApprovalRequest 带 reasoning；三级 autonomous/notify/approve；不可逆操作置信阈值 0.85；persist pending+timeout+invalidate changed calls+test replay；审批是 pause 不是 failure；blocking(in-the-loop) vs post-processing(draft review)（damiangalarza 2026-05）
- **跨会话记忆投毒（OWASP ASI06）**：实测攻击成功率 80-99%；SMSR=写时 HMAC-SHA256 provenance（0% 未签名注入成功率）+查询时随机化记忆消融多数投票；TMA-NM=laundering 下 content/lineage 防御不可靠、写时 origin binding 必要、Sybil 抗性 corroboration-gated elevation（IFC）；Trojan Hippo=限 80 字符 15-30% ASR、provable IFC policy 0% ASR 但阻塞合法 send_email（utility≈0）；codex disable_on_external_context=true 跳过含 MCP 工具返回/web 搜索结果线程的记忆注入=切断外部内容持久化通道；写默认不可信、信任决定在读取时（标记 provenance user-issued/tool-output/environment-observed+毕业策略）；strip user memories out of system prompt（Anthropic Claude 修复）；misattribution gap=投毒看起来像模型失败；跨作用域提升泄漏→scope isolation
- **输出侧检测**：系统提示泄漏两路=直接（精确/近似复现+词替换）+间接（换措辞/改句式/加微妙上下文）；tool results 也扫注入（网页/邮件/票据埋指令）；PII/凭证输出脱敏成标签 [CREDIT_CARD_VISA]/[AWS_ACCESS_KEY]；记录 PII 违规不阻断=观察非强制；agentic 管线 PII 经工具调用参数先于输出层执行默认无审计轨迹→参数边界拦截；快→慢排序（regex/canary/allow-deny→ML→LLM judge 控延迟）；Sentinel-LLM V2 注入被阻断时输出 IP 检测自动更敏感（跨层硬化）
- **MCP 治理**：Bifrost 不可变审计（虚拟 key/用户身份 OIDC/工具名参数/结果/时间戳，SOC2/GDPR/HIPAA/ISO27001）；Microsoft Agent Governance Toolkit=四层特权环+kill switches+append-only hash-chained audit logs+replay debugging；mcp-guardian=regex triage→schema analysis→LLM semantic verdict 三层+mTLS+真实 token 成本；mcp-tollbooth=tamper-evident audit trail 跨边界；MyApi=AES-256-GCM at rest+scoped tokens 哈希存储+调用审计归因
- **供应链投毒**：ToxicSkills=3,984 技能 1,467 恶意 payload/36% 缺陷率/76 确认恶意；ClawHavoc=ClawHub 1,184 技能被毒化；Zenity=skills.sh typosquatting（Paperclip/Browser Use 仿冒）1.7M 下载；LiteLLM CVE-2026-33634 CVSS 9.4（毒化 CI/CD scanner 窃 PyPI 发布凭证，3.4M 日下载）；三隐藏模式=staged fetch（安装时干净首调用拉外部恶意代码击败安装前审查）+split-file placement（分散两个良性位置）+delayed activation；vet-before-install=先只读运行（public 地址/read-scoped key）行为异常不给提款权；Claude Code ANTHROPIC_BASE_URL CVE-2026-21852（恶意仓库配置覆盖路由重定向凭证）
