## 二、落地点（5 个真独点）

### 1. 重试单位是单请求（工作流层）
`Retry per HTTP request, not per multi-step flow`；只重试当前步以保序；避免产生重复副作用的操作；默认 3 次/10% 抖动/400ms 起/30s 帽。

### 2. 重试给 fallback 让路（工作流层）
有 replay-safe fallback 时，用掉一半 bounded run timeout 即停止接纳重试；in-flight 请求保留自身 timeout，剩余 fallback 时间不保证。

### 3. 标识符整值保留（工具层）
`identifierPolicy: "strict"` 默认；降级摘要可省略装不下的 ID；纠正反馈只报完整值并说明省略数量，绝不把截断值当精确值。

### 4. 字节守卫与 token 双尺度（工具层）
`maxActiveTranscriptBytes` 达阈值在 run 前触发语义压缩；失败则用有界视图（整 turn 省略、保留 tool 配对与 system+当前请求、不改写存档、失败不算成功）；hydration cap = 8×token 预算（1KiB–64MiB），quarter-cap 步进。

### 5. 恢复重过权限（工作流层）
ack 前落库、collect 合并与 consumed 同事务、优雅关闭写 resume marker、重启按每个发送者当前权限准入、崩溃残留惰性不自动重发。
