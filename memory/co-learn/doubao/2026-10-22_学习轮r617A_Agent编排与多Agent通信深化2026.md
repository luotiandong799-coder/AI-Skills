## 四、提炼核心方法与关键事实

1. **MCP 与 A2A 两层分工**：MCP 连外部数据/工具（A2C），A2A 让 agents 相互发现协作（agent-to-agent）；标准化 payload 结构（sender/context_ref/payload+schema_uri）替代把变量注入 prompt 模板；同一 minimum context shape/return schema/failure shape 让多模式共存不 collapse。
2. **同步 vs 异步二选**：同步=快速查询/简单委派；异步=复杂分析/长运行（taskId 轮询）；handoff 是单通道也是信息丢失最大处。
3. **编排逻辑代码化（dynamic workflows）**：Claude 写 JS orchestration script 传 Workflow tool 后台执行——确定性部分（顺序/过滤/验证/合并）下沉为代码，只留智能决策给 agent；Skill 编排三阶段（Task-driven Retrieval→DAG Orchestration→Multi-skill Execution）。
4. **Subagents vs Agent Teams**：teams=subagents+shared task list+peer-to-peer messaging+lifecycle management；纯并行独立用 subagents；Make One-level nesting（子不能再嵌套）。
5. **层级通信原语**：delegate_to_sub_agent/report_to_parent/list_sub_agents/update_sub_agent；委派记录为 inter-agent message 全审计；能力查询先于委派（AgentCapabilities：tools/specializations/maxConcurrency/costPerToken/responseTime）。
6. **轻量 coordinator+按需技能 specialists**：AWS Kiro 协调者零技能只做路由，specialists 各 ~15K tokens 技能。
7. **共享状态协议**：Git 化共享记忆（commit-tracked+pull/push）+ownership protocol（owner 字段）+TTL reservation；Shared Memory 双职责（会话上下文+任务进度）；集中式存储跨 agent（PostgreSQL/triggerAndWait）。
8. **子 Agent 会话级状态**：own durable session、响应流回父级 tool card；sleep/wake 保持全部状态；消息送达三硬化（mid-turn 不丢/崩溃不截断/kill 重答）。
9. **委派兜底**：父指令加"只返回 findings 不回复用户"reinforcement；confidence-based routing 低置信转人工；自纠正 review 环+circuit breaker（reject 上限 force-approve）；质量门挂 hooks 不挂提示词。
10. **五编排通信模式**：Sequential/Broadcast-Subscribe/Fan-out-Fan-in/Handoffs/Blackboard——按任务依赖形状选。
