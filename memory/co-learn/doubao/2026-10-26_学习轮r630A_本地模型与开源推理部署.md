## 三、提炼的核心方法与关键事实
1. **引擎选型决策树**：Ollama=本地最易/vLLM=GPU 生产最快/llama.cpp=纯 CPU 最优/LM Studio=GUI；别把 Ollama 当高吞吐服务器。
2. **OpenAI 兼容万能接口**：改一个 Base URL 切换本地/云端；Claude Code 三环境变量接本地。
3. **量化决策树**：CPU→GGUF Q4_K_M 默认（25% fp16 内存）；reasoning→FP8；multi-LoRA→GPTQ；GPU chat→AWQ。
4. **吞吐参数**：Ollama NUM_PARALLEL=4+MAX_LOADED_MODELS=2；vLLM batched-tokens 8192+seqs 256+显存 0.9；多卡 tensor-parallel 4。
5. **air-gapped 隐私**：install.sh --local 离线完整栈；Llama 容器无 call home；MLX drop-in；sensitivity 分流。
6. **成本与验证**：规模省钱、监控 p95、7B 起步、微调 50 条真消息再切。
7. **实测**：llama.cpp CPU 快 3-8x；Q4_K_M 25% 内存；MLX 122B ~65 tok/s。
