## 落地 4 个真独点（全部带提升层）

1. **技能开发走评估驱动五步：先量缺口，再写最小指令；Agent 起草、人删减纠偏** → authoring "1.137.0"→**"1.138.0"**。要点：gap-first 五步（无 skill 跑任务记缺口→三场景评测→基线→最小指令→迭代）；指令是补缺口最小集合，每段要能指回某缺口/评测失败；与 Agent 多轮评测分工（那条管评测设计、本条管开发顺序）；Agent 起草人定稿。提升层：可复用 Skill。
2. **技能安装与版本治理：来源验证/版本钉死/安装前审查/审计日志；行为退化不抛异常须谱系追踪** → authoring 1.138.0。要点：安装前治理九项清单；Markdown-only 技能也要审注入/过宽指令/隐藏策略冲突/工具权限；技能行为退化不抛异常，需版本+谱系追踪；与技能安全审查分工（那条管内容注入、本条管供应链治理）。提升层：可复用 Skill。
3. **上下文多分辨率驻留：full→compressed→structured→pointer 四级降级链，压力下保持不变量** → compressor 3.656.0→**3.657.0**。要点：四级驻留（逐字→压缩→类型字段→句柄）；约束不低于 structured、证据指针必须可解析；与预算管理分工（预算管何时压、本条管压的梯度）。提升层：工具。
4. **上下文管理归编排层不归模型；按需加载走轻量标识符** → compressor 3.657.0。要点：LLM 看不见上下文限制，让它管记忆加延迟+失败模式，编排层每次调用前定上下文；JIT 加载（保持 file paths/stored queries/links 指针，用到才载）；与预算管理分工。提升层：工作流。
