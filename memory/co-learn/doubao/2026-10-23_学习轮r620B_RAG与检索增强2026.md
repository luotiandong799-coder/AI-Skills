## 四、提炼核心方法与关键事实

1. **检索生成分开评估**：recall@k 管检索（recall@10<0.85 任何 prompt 都救不了），faithfulness/correctness 管生成；RAG triad 三指标分环节归因。
2. **分块质量判据**：好 chunk 七标准验收；fixed/semantic/structural 三种策略按文档类型选；parent-child 原型先行量 recall delta；Summary Index 双索引（小 chunk+大 summary 并库）。
3. **混合+重排量化收益**：dense+sparse recall@20 78→94%；RRF 融合 70→90 recall@5；rerank 30-50→top 3-5 最高 ROI；relevance gating 防幻觉；检索时去重 cosine 0.92。
4. **Agentic RAG 四模式**：multi-hop/tool routing/self-check judge/re-retrieval on failure；Claude Code 代码场景弃 vector RAG 改 grep-style；Classic RAG 仍管 FAQ。
5. **RAG 提示三件套**：只用 sources+没有就说+按 ID 引用；chunks 带分隔符+显式 ID；max_tokens 600 cap；prompt caching 从第一天。
6. **索引生命周期**：文件名即检索信号（重命名回报最高）；清洁源去 header/footer 噪音；embedding 维度匹配 index；High-Quality 索引不可切换。
