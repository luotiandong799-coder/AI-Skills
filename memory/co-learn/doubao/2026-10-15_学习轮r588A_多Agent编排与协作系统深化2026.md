## 二、核心方法与关键事实（带来源，已核验）

1. **拓扑选型矩阵**：Supervisor token 线性+一条 trace tree+context OOM 失败；Swarm 广播二次方+handoff 图+无限 loop；Hierarchical 每层显式图可审计；单 supervisor ≤8-10 worker（腾讯云实测）；LangGraph 配显式 state graph、AutoGen 配会话消息（aipromptshub 2026-06/paiteq 2026-05）。
2. **Handoffs vs tools**：specialist 要直接答用户用 handoff（切 active instructions），只做 subtask 用 agents-as-tools；guardrails 作用域=Input 只护链首/Output 只护终局（openai.github.io 2026-10）。
3. **三层 token 预算**：per-call（SDK）/per-task（orchestrator 含全部 subagent）/per-tenant daily（网关）；log agent/task/tenant ID；超限人工队列不静默重试；delegation-leak=预算按 aggregate session 算（adamarant 2026-05/codex 2026-07）。
4. **MAST 14 失败模式**：inter-agent miscoordination/runaway loops/unchecked outputs；consensus loops=无终止条件交接循环；politeness spiraling 15x；5-agent 10-50x token（botonomy 2026-07/aitoolsvaults 2026-05）。
5. **协议分层**：MCP 管工具、A2A 管 agent 间、AGTP 传输层治理（header 优先/scope 子集/跨 AGMP 会话）（a2a-protocol.org/IETF 2026-03）。
6. **thoughtfulness**：模型能否考虑他人心智模型决定多 agent 成败；先单 agent 失败再加协调；每 agent 必有预算否则是 bug；Dynamic Workflows=编排脚本化；Managed Agents=脑手分离（anthropic.com 2026-08）。
7. **动态组建团队**：主 agent 按难度决定启用子 agent+动态规模+per-agent 模型/工具/预算+任务结束释放（爱分析 2026-08）。
8. **先 pattern 后框架+关键指标测团队**：deeplearning.ai 方法论；五技术=角色分工/共识机制/任务合并/跟踪模式/资源控制（learn.deeplearning.ai 2026-10/jimmysong.io 2026-08）。
