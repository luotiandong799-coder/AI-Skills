## 二、落地点（5 个真独点）

### 1. 不可信内容 agent 默认禁四工具（工具层）
`deny these by default`：`gateway` / `cron` / `sessions_spawn` / `sessions_send`。判据：读外部内容的 agent 不该同时握有改配置、造定时任务、派生与跨会话发送的权；禁的是能力，不是内容。

### 2. deny 只匹配命令 ID（工具层）
`matches exact node command names only, not shell text inside a command payload`。判据：deny 是入口开关，不是内容过滤。

### 3. 审批只认"恰好一个具体本地文件"（可复用 Skill 层）
`cannot identify exactly one direct local file ... denied rather than promising full semantic coverage`；批准后复用 `systemRunPlan`，改 command/cwd/session 会被拒。判据：审批审计的是"这一个文件+这段上下文"，命令要先收敛到可指认的脚本。

### 4. 写状态走原子替换，读方不冻结（工作流层）
`atomic sibling-temp + rename`；普通读拿到的是句柄当时的字节。判据：要"完整旧或完整新"，责任在写方；路径侧拒绝 `..`、绝对路径、链接逃逸。

### 5. 三次同错即停 + 去抖判进展（工作流层）
三次连续同 (tool, args, error) → 拦该动作并给一次恢复机会；进度比较剥掉 debug 计时 / hit score / 消息 id / 时间戳 / 卡片写版本；`post-compaction guard` 在压缩后再现同一三元组即中止。判据：第三次不是再试，是换路子；不去抖则"换个 id 的同一次调用"会被当新进展。
