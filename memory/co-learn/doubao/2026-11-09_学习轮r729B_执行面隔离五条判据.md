## 四、本轮落地的 6 个真独点

1. **三层控制各管一事**：sandbox=在哪跑 / tool policy=哪些工具可调 / elevated=exec 专用逃生门（绕不过 creator role 的 required；沙箱关闭时 elevated 无意义）→ 提升层：工具。
2. **deny 永远赢、allow 非空即白名单**；tool policy 只按名字过滤、不查 exec 副作用——禁 write/edit ≠ shell 只读 → 提升层：工作流。
3. **目录枚举专用通道**：`ls` 不授予 shell、返回完整 JSON 引号名 + `after` 游标、按 tool-result 预算分页、绝不返回半截文件名；后端无 readDirectory 则 `ls` 隐藏且不回退读宿主 → 提升层：工具。
4. **bind 双重路径校验**：规范化源路径 + 最深已存在祖先解析后二次校验，symlink 父逃逸不可绕过，不存在叶子也校验；默认无 mode 即 rw；`scope: "shared"` 忽略 per-agent binds；挂 docker.sock = 交宿主控制权；workspaceAccess 与 bind 独立 → 提升层：工具 / 工作流。
5. **沙箱内外清单**：沙箱内 exec/ls/read/write/edit/apply_patch/process + 可选浏览器；宿主上 = Gateway 进程本身与 elevated 工具；`non-main` 只沙箱非主会话 → 提升层：工作流。
6. **生效值自证**：`sandbox explain` 打四样（mode/scope/workspaceAccess、是否真被沙箱、allow/deny 来自哪层、elevated 门与修复键路径）；`agents/tool-policy` 审计含规则标签/配置键/受影响工具名 → 提升层：工具。
