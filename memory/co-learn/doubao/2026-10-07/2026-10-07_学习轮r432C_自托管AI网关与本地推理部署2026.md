## 落地 5 独点（每点标注提升层）

### 1. 推理引擎四选型：Ollama / vLLM / llama.cpp / LM Studio（工具/工作流）
来源：stackpractices-local-llm-deployment / promptquorum-qwen-local-deployment
- **按场景选引擎**：**快速本地实验=Ollama**（自动多 GPU 拆分，适合个人服务器与 <20 并发）；**生产高吞吐=vLLM**（tensor parallelism+continuous batching，并发负载 2-4× 更高效，适合 100+ req/h）；**纯 CPU 或 CPU/GPU 混合=llama.cpp**；**桌面 GUI=LM Studio**。
- **VRAM 需求速查**：7-8B Q4=6-8GB；14B=10-12GB；23B Q4≈14GB；70B 需多卡/量化。
- 判据：个人/小团队选 Ollama，对外服务选 vLLM，无 GPU 选 llama.cpp——别一个引擎打天下。

### 2. 自托管盈亏平衡：吞吐足够时比 API 便宜 5-10×（工具/工作流）
来源：phosailabs-self-host-ai-stack / devto-devrudals-self-hosted-llm-gateway / devto-lingdas1-running-llms-locally
- **自托管翻转成本结构=固定算力 vs 计量消耗**：GPU VM 按时计费不随 token 量涨；**吞吐足够时自托管比 API 便宜 5-10×**（饱和单 H100 vLLM 跑 Llama-3.3-70B FP8 的 GPU 租金 $0.17-0.81/百万输出 token，低于托管 API 且 12-60× 低于 GPT 类）。
- **个人档硬件**：二手 RTX 3090 24GB（$700-900）+32GB RAM ≈ $1,200 一次性，可全质量跑 Qwen-2.5-32B/DeepSeek-R1-14B/任意 7-14B，对比 $200/月云 API。
- 判据：算盈亏平衡=月 token 量 × 单价 vs 固定硬件/租金；个人高频自用直接算整机成本。

### 3. 量化四档速查：FP16 / Q8_0 / Q4_K_M / AWQ（工具/模型）
来源：shengyayun-vllm-ollama-deployment / stackpractices-local-llm-deployment
- **量化=质量与显存/速度的杠杆**：**FP16**（~14GB，基准质量）；**Q8_0**（~9GB，质量损失可忽略，+10% 速度）；**Q4_K_M**（~4.9GB，+30% 速度）；**AWQ**（4 位激活，~5.2GB，+35% 速度）。
- 判据：先按显存定能跑多大模型，再选最接近原质量且放得下的量化档；Q8 几乎无损优先。

### 4. LiteLLM 网关：OpenAI 兼容端点 + 负载均衡 + 成本上限（工具/可复用 Skill）
来源：litellm-ai-gateway / everylocalai-litellm-ollama-gateway
- **LiteLLM=开源 AI 网关/LLM 代理**：**一套 OpenAI 兼容端点背后负载均衡、追踪成本、设速率限制、路由到该处理的模型**；**自托管分钟级、无需信用卡**；实测量=某些高级 AI 任务（如编码）成本降 56%。
- **LiteLLM+Ollama 组合**：6 组件、约 20 分钟搭建、约 $800 硬件 + $0/月 vs 云；单机跑多模型统一入口。
- 判据：多模型/多后端统一入口用网关；本地推理 + 网关=个人版多模型路由。

### 5. 本地部署决策模型：vLLM 多卡 / Ollama 多 GPU 自动拆分 / 盈亏判断（工作流/工具）
来源：promptquorum-qwen-local-deployment / cloudhostreview-ollama-vllm-localai / vercel-self-host-openai-api
- **Ollama 支持多 GPU 推理（自动拆分）；vLLM 用 tensor parallelism 在多卡上摊大模型**。
- **月租档位参考（2026-05）**：RTX 4090 24GB VPS=承诺 $180-280/月、按需 $0.30-0.50/h，8B FP16 或 13B INT4 舒适；RTX 3090 24GB 更便宜档；**工作站 16GB+ GPU=免费自用**，CPU-only 只适合 7B 且太慢不生产。
- 判据：先量化需求（并发/延迟/质量），再选引擎+量化+硬件档；个人工作站起步、云 GPU 扩容。
