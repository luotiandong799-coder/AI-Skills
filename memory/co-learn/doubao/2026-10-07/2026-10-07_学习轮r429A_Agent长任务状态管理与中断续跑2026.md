## 落地 5 独点（每点标注提升层）

### 1. Agent 是持久身份，不是常驻进程（工具/工作流）
来源：cloudflare-long-running-agents
- **Agents are durable identities, not always-on processes**：状态、SQL 数据、调度、fiber 检查点在休眠/重启后仍存活；**内存变量/定时器/打开的 fetch/局部闭包在驱逐后不存活**。
- 判据：设计长任务 agent 时，凡需跨重启存活的必须落到持久层（SQL/检查点/调度），不许藏在进程内存里。

### 2. 持久执行（Durable Execution）= 检查点 + 精确续跑（工具/工作流）
来源：zylos-durable-execution-runtimes / microsoft-durable-task-for-ai-agents / zylos-session-continuity
- **核心主张**：持久化已完成执行边界，崩溃后恢复时**不重复工具调用、外部变更、人工审批或外发消息**——Temporal/Restate/Inngest/Hatchet/DBOS/Cloudflare Workflows/Azure Durable Task 直接暴露这些原语。
- **Azure Durable Task**：运行时自动检查点 agent 工作流每个状态迁移（LLM 响应/工具调用结果/控制流决策）到持久存储；失败后从最后检查点恢复而非从头重启——**已完成的 LLM 调用不重复，省 token 省墙钟时间**；内建带退避的重试策略处理 LLM API 瞬时失败。
- **LangGraph checkpointer**：每个节点执行写检查点到配置存储（SqliteSaver=单进程开发/PostgresSaver=多进程生产，支持多 worker 捡同一任务）——重启后从最后检查点重放、跳过已完成步骤。
- 判据：长任务默认 durable execution 运行时；"不重复已完成副作用"是恢复正确性的底线。

### 3. keepAlive vs runFiber：心跳保活 ≠ 可恢复（工具/工作流）
来源：cloudflare-durable-execution-api / cloudflare-long-running-agents
- **keepAlive() 防驱逐但不管恢复**：即使有心跳（代码更新/告警超时/资源限制），进行中的工作照样丢——**心跳是保活不是持久化**。
- **runFiber() 内部调 keepAlive 且把工作持久化到 SQLite 可恢复**：按需选择——分钟级活跃工作用 keepAlive，需要恢复能力时用 runFiber。
- 判据：把"防驱逐"与"可恢复"当两个能力分开评估；保活 ≠ 恢复，只有落盘才可恢复。

### 4. 追加式事件日志是长任务 agent 的底线（工作流/可复用 Skill）
来源：addyosmani-long-running-agents / moai.team / agentpatternscatalog-agent-resumption
- **append-only event log 让 agent 可恢复、可调试、可审计**：原文——"如果你不能从持久存储重建 agent 过去 24 小时的行为，那你有的只是一个碰巧调用 LLM 的长跑 shell 脚本，不是一个长跑 agent"。
- **把压缩与上下文重置当一等公民**：Anthropic 明确 summarization-as-compaction 对超长任务不够，必须真正清上下文（context reset）。
- **Agent Resumption 模式**：每步的 plan、tool result、中间状态都检查点到持久存储，按 run/thread 键控——部署热修复/容器重启后从精确断点续跑，不丢不重。
- 判据：凡自称"长任务 agent"的，先问"24 小时行为能否从持久存储重建"；事件日志 append-only 不可变。

### 5. thread_id 持久游标 + 超步检查点（工具/工作流）
来源：langchain-runtime-deep-agents
- **LangChain 生产 deep agents**：agent 跑在**托管任务队列+自动检查点**上——任何 run 可从精确中断点重试/重放/续跑。
- **每个超步（super-step）写检查点到持久层（默认 PostgreSQL），用 thread_id 作持久游标**；worker 崩溃后新 worker 从 thread_id 位置继续。
- 判据：长任务执行以 thread_id 为锚定位"跑到哪了"，恢复/重放/审计都以它为键。
