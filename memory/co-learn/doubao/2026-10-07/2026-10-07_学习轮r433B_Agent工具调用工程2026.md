## 落地 5 独点（每点标注提升层）

### 1. 工具 schema 设计：显式输入/输出 schema + 窄工具（工具/可复用 Skill）
来源：loooop-tool-use-patterns-v17 / zylos-tool-augmented-llm-agents / openlegion-agent-tool-use
- **声明显式 input/output schema（Zod/JSON Schema）**：减少参数强制转换、简化校验、让 UI/agent harness 可渲染表单并在执行前校验。
- **窄工具优于宽工具**：把 `query_database` 与 `update_database` 拆开=降低歧义+缩小每个工具 schema 的表面积；**描述必须带示例、边界与返回值语义**（"returns null when…"）。
- 判据：每个工具=窄职责+显式双 schema+描述带示例与边界；能用两个窄工具就不写一个宽工具。

### 2. 并行 vs 串行调用判据与冲突消解（工作流/工具）
来源：ai-tldr-tool-calling-best-practices / loooop-tool-use-patterns-v31 / aigentlab-parallel-tool-use
- **并行**：输出相互独立、I/O-bound（数据库/API）、顺序无关；**串行**：A 的输出是 B 的输入、调用修改共享状态、需要确定性顺序。
- **并行结果冲突须预定义消解策略**：两个价格源不一致时先定规则（谁优先/取平均/上报）再让模型综合——**冲突消解写在调用前，不是事后临场**。
- **依赖无关的工具用 asyncio.gather/Promise.all 并发执行削延迟**。
- 判据：先判依赖（独立→并行；有依赖/改共享状态→串行）；并行集合先写冲突消解规则。

### 3. tool_choice 四值与确定性动作（模型/工具）
来源：futureagi-function-calling-2026 / aigentlab-parallel-tool-use
- **tool_choice 四值**：`auto`（模型决定）/`required`（强制至少调一个）/`none`（禁止调用）/`specific tool`（锁定某工具）——**force a deterministic action 用 required/specific**。
- **并行工具调用=一个响应里多个 tool request**（独立动作、削延迟）；**tool result=函数输出回灌新 turn**（多轮 agent 循环）。
- 判据：流程关键步用 required/具体工具锁死，别全交给 auto；模型不可信时收窄 tool_choice。

### 4. 工具调用评估：metric 集 + step-level traces（工作流/可复用 Skill）
来源：machinelearningmastery-tool-calling-roadmap / futureagi-function-calling-2026 / aiworkflowlab-function-calling
- **工具特定评估五指标**：**正确工具选择率 / 首次参数有效率 / 错误传播进最终输出率 / 恢复质量 / 效率（是否有不必要调用/token 浪费）**——不只看"任务完成没"，完成但工具选错/反复纠错也算缺陷。
- **function-call eval=实际 vs 期望的工具名与参数打分**（跨模型快照回归）；**tool selection 数据集=100-500 例带正确工具标注，准确率按工具类别/输入歧义度/可选参数分桶**。
- **无 step-level traces 无法做这些评估**：日志记录每次调用=参数/结果/后续推理步。
- 判据：工具调用质量=五指标+按桶分析；先有调用级 trace 再谈评估。

### 5. Harness 工程与可复用工具原语（工具/可复用 Skill）
来源：arxiv-harness-engineering-reusable-tool-primitives
- **harness 工程=agent-native 可复用工具原语**：工具输出质量四问=语义对齐（输出是否匹配用户所求）/参数一致（解析参数是否符合意图与 schema 约束）/执行有效性（无运行时错误、返回符合输出 schema）/约束满足（任务级/领域级约束）。
- **可复用原语=把高频工具调用序列固化为带 schema 的原语**（如"检索→重排→引用"），agent 像用工具一样用原语——减少逐次编排的失败面。
- 判据：评估工具输出用四问框架；重复出现 3+ 次的调用序列固化为原语。
