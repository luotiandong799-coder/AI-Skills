## 落地 5 独点（每点标注提升层）

### 1. 多模态 Agent 架构两模式 + 专用视觉子代理（工具/工作流）
来源：niteagent-multimodal-production / mindstudio-add-vision / nvidia-nemotron-omni
- **两模式架构**：**Monolithic**（单一多模态模型处理所有模态——跨模态上下文最简、简单输入延迟最低，图像密集工作负载贵、每模态控制弱）；**Specialist Router**（路由把各模态分派给专用模型再融合结果——企业生产主流模式）。
- **专用视觉子代理模式（省 VRAM）**：不要加载一个巨大全模态模型做一切——**用小而专的视觉模型（如 MiniCPM-V）处理截图/图像/PDF，把输出以纯文本传给主编排器**；自动化保持完整、VRAM 可控。
- 方向对照：NVIDIA Nemotron 3 Nano Omni=把视觉/音频/语言合一减少模型间传数据丢失时间（另一极，面向边缘/低资源）。
- 判据：先问"模态负载与资源预算"——图像密集用专用子代理，低资源边缘用 Omni 型合一；企业多路输入用 Specialist Router。

### 2. 视觉-规划-行动三段管线 + Set-of-Mark 精确接地（工具/可复用 Skill）
来源：agents-lib-ui-tars / luowle-multimodal-agents / dev-agdex-gui-agents
- **UI-TARS 三段管线**：**Vision Encoder（读屏）→ Planning Engine（决定下一步）→ Action Executor（执行）**。
- **Set-of-Mark（SoM）接地**：前端脚本把**编号标记（Marks）叠加到网页截图所有交互元素**（按钮/链接/输入框）——模型**不需要猜坐标，只需输出"点 15 号"→ 100% 精确视觉接地**。
- **GUI agent 接地两方式**：a11y 节点（无障碍树）vs 纯视觉像素→坐标——**a11y 节点被遮挡/自定义控件时回退纯视觉接地**（OSWorld 2.0 级 benchmark 的判据）。
- 判据：视觉 agent 给交互元素编号再让模型按号行动，杜绝坐标猜测；a11y 可用优先、被遮挡回退像素接地。

### 3. VLM 四段管线 + 截图预处理与按场景选输入（模型/工具/工作流）
来源：linhtruong-vlm-pipeline / bestin-it-vlm-playwright / aiagents-multimodal-browser / swarms-vision-agent
- **现代 VLM 四段管线**：**Vision Encoder（ViT-L/SigLIP/InternViT，patch→embeddings）→ Connector（MLP/Q-Former/Cross-Attn/Resampler，对齐到 LLM 空间）→ LLM Decoder（Llama/Qwen/Mistral/Gemma）**。
- **截图预处理**：缩放图像到 VLM 友好宽度——**token 别浪费在超大分辨率**；本地 VLM 走 OpenAI 兼容 /v1/chat/completions 接口。
- **输入类型按场景选**：**全页/视口截图→决定下一步点击/检测错误/验证 UI 状态；裁剪 UI 区域→专注 OCR 读标签（免全页噪音）；扫描 PDF/照片→字段提取/表单分类；图表/图示→总结趋势读标注**。
- **视觉任务指令要具体**：差="Look at this image"；好="识别图中所有车辆，按类型（轿车/卡车/摩托）计数并描述颜色与位置"。
- 判据：先缩放再喂模型；任务指令写明"识别什么+怎么输出"；按任务类型选输入形态（全页/裁剪/文档/图表）。

### 4. 面向图像的长文档理解=agentic 工具调用（模型/工具）
来源：arxiv-InSight-doc / arxiv-Q-Guide / arxiv-VISOR / arxiv-Orion
- **InSight-doc=retriever-free agentic 长文档理解**：不用页级检索，**用图像裁剪/缩放工具增强 CoT 推理（"thinking with images"范式）**。
- **Q-Guide=证据获取 agent**：读问题→判断还缺什么证据→**调用定向工具**（需要文字就读文字/需要细节就放大/需要位置就接地区域）——DocVQA2026 65% vs 直接提示 4%、Manga109 同类优势。
- **VISOR=agentic 视觉 RAG**：迭代搜索+超视距推理，GRPO 强化学习+状态掩码+信用分配（动态上下文重建）。
- **Orion=统一视觉 agent**：编排 OCR/检测/分割/关键点定位/扩散/几何分析等**专用视觉工具执行多步视觉工作流**（从被动理解到工具增强执行）。
- 判据：长/密图像文档别整页塞，让 agent 按需裁剪/缩放/聚焦；文档理解把"读文字/看细节/定位区域"建模成可调用工具。

### 5. 视觉幻觉缓解三层法（模型/工作流）
来源：openreview-EVisRAG / CVPR-Envision-ACR / arxiv-MCite-RL / openreview-robust-vision-rag / MXRAG
- **证据引导推理（EVisRAG）**：**逐图观察→逐图记录证据→聚合证据推理**——多图证据不整合是 VRAG 幻觉主因；MXRAG=跨模态可解释 RAG（+21.4% EM、-38.6% 相对幻觉率、token 级可追溯）。
- **对比解码（无训练）**：**VCD=原图+加噪图对比模型输出；RITUAL=喂随机旋转/裁剪副本与原图对比**——解码期直接抑制幻觉（CVPR2026 Envision-Attend-Respond）。
- **引用增强多模态 RAG（MCite-RL）**：citation-enhanced agentic RL——IoU 平均 **+26.16%** vs 普通 RAG 基线。
- **检索投毒防御（Robust Vision RAG）**：**semantic coherence 反馈机制**削弱被投毒检索的语义破坏（prompt/检索视觉证据/生成输出三方语义对齐校验）。
- 判据：多图任务强制逐图证据记录再聚合；无训练场景用对比解码；生产视觉 RAG 叠引用验证+语义一致性校验（防检索投毒）。
