## 四、提炼核心方法与关键事实

1. **错误分类决定重试边界**：可重试=瞬态（408/409/425/429/500/502/503/504/超时/连接/限流）；不可重试=永久（400/401/403/404/422/语法/结构性错误）。结构性错误重试五次=推迟五次失败+污染日志（alltomate："retries buy time for the outside system to recover. They don't fix anything on your end"）。
2. **timeout 先查基础设施再重跑**：`Task request timed out` 可能 runner 未注册/broker 断连（XBSTACK）。
3. **五错误处理指令矩阵**（Make）：Skip/Retry/Resume/Commit/Rollback 各管一类失败语义；批处理用 Resume 不用 Break（首 bundle 错整批停是常见坑）；错误指令不占 credits。
4. **Durable execution**：稳定 execution id+每有副作用步骤 checkpoint（run log 15s 快照覆盖写）+resume 非特殊路径（每步问输出在 log 吗）+崩溃最多损失一步+Pending Writes 并行部分成功保留只重跑失败节点+只重试易失败步骤。
5. **DLQ+replay**：死信先存库（stringify JSON 保精确状态）再通知；DLQ 三要素（完整上下文+错误历史+stack/结构化告警/Replay 单条不重跑整批）；FOR UPDATE SKIP LOCKED 防抢行；incomplete execution 状态机（30 天自动删/仅 active 时重试/并行≤3）。
6. **幂等三件套+作用域**：确定性 key 从业务数据派生+唯一约束 ON CONFLICT DO NOTHING+provider 幂等键；attempt scope（每次重试新键）vs global scope（全局唯一）；失败清键成功留键；TTL 窗口。
7. **后台护栏五件套**：202+id+轮询/Idempotency-Key/per-tenant 并发上限(429)/zombie reaper 兜底(SCHEDULED>5min/RUNNING>30min 强 fail)/超时=p99×1.5；流式 worker 必须 try/except+错误事件转发（否则前端无限等待）；队列状态机排障（delayed=退避重试中/failed=需查/usersInteraction 不重试）。
8. **Claude Code hooks 错误语义**：退出码 0/2/其他三分法；PreToolUse deny+updatedInput；Stop decision approve/block+reason；PermissionDenied retry:true；hooks 60s 超时+不能热加载。
9. **Agent 失败五分类**（error-recovery skill）：Transient/Context Gap/Complexity/Boundary/Fatal 各配策略；agent-introspection 四阶段（capture→classify→contained recovery→report）；先缩小范围跑一个判别性检查再重试。
10. **后台任务平台横向**：平台 cron 不重试 vs 队列/任务平台重试；QStash DLQ 7 天；Trigger.dev CRIU checkpoint；TTL 防卡队列。
