## 二、核心方法与关键事实（带来源）

- **deeplearning.ai Evaluating AI Agents**：code-based/LLM-as-a-Judge/human annotations 三选；对 agent 的 skills 与 router 决策分别设评；从收集的 traces 造测试示例+准备详细 LLM-as-judge 提示词；convergence score=评估 agent 能否在高效步数内响应；Agentic AI=component-level evaluations（对 workflow 各组件分别评估）
- **LLM-as-judge 五大偏差量化**：style bias 主导（0.76-0.92 远超 position ≤0.04）但研究最少；position flip rate 0.17-0.50（换槽位翻转，注意力不对称，代码评测换序偏移 10+ 点）；verbosity 更长答案虚高 ~15%（truncation controls 证明 judge 质量敏感 0.92-1.00 非简单长度偏置）；self-preference 同族高 10-25%；assertiveness=人类与 LLM 同向偏好自信但错误（平均 human+LLM 不消偏）；缓解=双顺序跑/anti-length 指令/不同模型族/中立 prompt/rubric 分离；pointwise O(N) vs pairwise O(N²)+强 position bias
- **评测数据完整性**：contamination 是最大威胁（GPT-4 报告 1-25%；10% 污染→记忆项虚高 5-10%）；continuation testing（Carlini）+log-prob/perplexity 检测；私有 post-cutoff 数据集；golden dataset=版本化不可变修订+provenance（区分分数变化来自模型/prompt/judge/测试集）；Zylos 三类谎言=label leakage（mock 收到期望输出直接重发射=100% 假满分）/tautological tests/非 gating metrics；LLMEval-Fair 私有题库抗污染
- **评测框架**：DeepEval（pytest 集成 eval=测试函数、60+ 指标、Apache-2.0）；Ragas（RAG 指标标准：faithfulness/answer relevancy/context precision）；Promptfoo（prompt 回归测试、YAML/CLI/CI、red teaming）；menuagentic=四框架四种 correctness 单位先决定测什么再选
- **Anthropic**：三 grader=code-based（验证结果强/行为脆）/model-based（LLM-as-judge+rubric 处理细微维度）/human（不可扩展但必要）；**Describe the goal, not the steps**（rubric 指定具体命令不可用时静默失败、检查没跑——定义"什么算证明"，grader 有 writer 全套工具自己找）；harness 预验证=被测模型先探测沙箱（静态分析+实际逃逸尝试）再跑成百上千次
- **LangSmith/Langfuse**：数据飞轮=production traces→datasets→evals；Trajectories=可读会话视图+online evaluators+annotation queues；Tuned Evaluators（Perceived Error）=LangChain-managed judge 评每条 trace；Langfuse observation-level evals=单次 LLM 调用/检索/工具执行级评分（vs 整条 trace）更快更精确；alerts 阈值+managed catalog（Ragas 合作）
- **GitHub 生态**：AgentBench（THUDM 八环境 harness、Docker runner、数百美元/数小时）；ReviewBench（1 亿+真实 PR 语言/规模/尺寸分布、多源 golden set+一致 rubric+高级工程师验证）；GitHub Copilot harness 评测（harness 塑造智能应用方式、20+ 模型、token 效率）；AgentCompass=Benchmark/Harness/Environment 三组件解耦+轨迹分析诊断 reward-hacking；HF agent-eval=bare/clone/skill access 三档；Claw-Eval=安全非仅成功；Toolathlon（ICLR 2026：32 软件/604 工具/108 任务）；2H-2026=reliability 成主指标（N-run consistency/policy adherence/cost-adjusted accuracy）+framework-attributed scores 强制
- **LMArena 误区**：Leaderboard Illusion（选择性披露=私有变体选最优分，Meta 27 个；数据不对称 Google 19.2%/OpenAI 20.4% vs 83 开源模型 29.7%；ArenaHard 112% 增益→过拟合 arena）；style control 移 Elo 10-30 点→style-controlled leaderboard；sample bias=投票人群≠用户群；最佳实践=Arena+MMLU+SWE-Bench+GAIA 组合，专业榜比综合榜可靠
- **WaytoAGI 评测**：2026 五硬指标=任务完成率/幻觉率（未知工具幻觉/影子调用/参数幻觉三类）/工具调用准确率/错误恢复率/成本延迟；离线=Golden Tasks 卡 CI、线上=分层采样+轻量裁判模型；诱饵目录/影子陷阱/过度承诺对抗；四步法=定义成功标准与一票否决→正常/边界/异常/对抗测试→观察工具轨迹/状态变化/真实副作用→按路由/RAG/工具/状态/提示词归因修复；六维分列=argument extraction/result utilization/error recovery/plan coherence/task completion（聚合隐藏退化）；N-run 一致性（跑三次首过后续全错）
