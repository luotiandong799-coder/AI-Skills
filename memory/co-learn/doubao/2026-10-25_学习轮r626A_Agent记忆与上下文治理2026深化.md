## 三、提炼的核心方法与关键事实
1. **记忆注入三形态**：auto-injection（memory:notes block 渲染进 system prompt）/检索式（RAG）/声明式（用户显式点名）。
2. **会话边界写读**：会话结束自动提取存储、下个会话开始前自动召回。
3. **记忆去重与冲突仲裁**：相似度阈值判相似→提升置信度；语义相反→更新覆盖。
4. **Facts vs Retrieval 分工**："现在知道什么"用事实库、"之前说过什么"用检索（元数据过滤：task ID/step type/tool name/approval state）。
5. **survivable Tasks**：自动压缩下显式 Task APIs 持久化 current work/decisions/handoffs。
6. **压缩窗口策略**：保留最新 5 user turn+移除已完成 reasoning/tool 输出+不删 event log。
7. **null-deletion 投影**：transient reasoning→persistent structured state，只留未来所需。
8. **记忆物化**：Markdown 文件+SQLite 索引，回答给路径不给全文；CLAUDE.md 22000 vs 1900 tokens（11 倍差）。
9. **三层记忆**：long-term（可复用）/history（完整消息）/state（会话内可恢复）。
10. **技能生成触发四判据**：工具≥5 次/错误恢复/用户修正/非直观流程。
