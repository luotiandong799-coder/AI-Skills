## 四、提炼核心方法与关键事实

1. **工具面契约**：Function Calling vs ReAct 双机制选型；工具描述纪律（输入+输出+适用场景，禁模糊词）；prompt 点名工具+触发条件；单层工具面（禁止 agent 套 agent）。
2. **错误分类治理**：技术错误系统重试 vs 逻辑错误回馈 LLM 改方案；错误即工具响应（Continue/ Never Error）；sub-workflow 错误隔离；降级链=复杂→简单窄 scope→人工；分诊式重试（per-incident 预算）。
3. **工作流即工具**：scenario 作工具三要素（on demand+输入输出契约+头尾模块）；MCP 暴露工作流供外部 agent 调用；组件即工具；active+on demand 自动触发。
4. **自动化形态**：Markdown 意图驱动工作流+强护栏；规则过滤有边界（模式外输入交 agent）；LLM 节点单一职责；六模式目录（autonomous/chaining/routing/parallelization/orchestrator-worker/evaluator-optimizer）。
5. **HITL 工程**：waitpoint 挂起零算力+精确恢复点；工具级 needsApproval 审批门；全量审计日志（compliance 查每个 tool call）；manual review stages。
6. **可观测韧性**：每步日志/错误/耗时；执行打标可搜索元数据；chat agent 机器睡眠模型（消息唤醒/冻结/状态幸存）；快照再水合（丢容器不丢 run）。
