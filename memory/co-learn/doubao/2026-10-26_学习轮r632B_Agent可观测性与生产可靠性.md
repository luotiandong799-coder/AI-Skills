## 三、提炼的核心方法与关键事实
1. OTel GenAI 标准属性统一命名+Collector 采样脱敏；TTFT 指标。
2. 生产首配告警：error/P95/TTFT/cost/cached ratio；成本最被忽视；遥测异步不阻塞。
3. Golden trace 回归：30-80 真实 trace 重放；测执行路径不只输出；场景模拟不重放旧稿。
4. 契约测试+模型 pin：工具参数 schema 版本化+mock 重放；pin 精确 ID 读回断言。
5. metric 级阈值+分品类跟踪+采样评测+分歧监控。
6. trace_id 贯穿+日志自动拾取+脱敏先行。
