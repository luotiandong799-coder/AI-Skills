## 五、本轮落地点（4 点）

### ① LLM 编码行为四律（提升层：工作流 + 可复用 Skill）
- 先想后写（假设显式、多解并列、不清楚就停）；简单优先（不为单次使用造抽象，200→50 就重写）；外科手术式改动（不顺手改邻近代码、不重构没坏的、死代码只报不删、**每行改动可追溯回请求**）；目标驱动（任务翻译成可验证目标，每步带 verify）。
- 落点：`engineering/wb-execute-discipline` KB，3.310.0 → **3.311.0**。

### ② 三级门 + token 硬约束 + material 清点（提升层：工具 + 工作流）
- Floor 不可豁免 / Reflex 可书面豁免 / Finish 不阻断；颜色字体必须走 `:root` token；禁 `transition: all` 与尺寸动画、`overflow-x: clip`、`minmax(0,1fr)`、focus-visible、reduced-motion 回退；**绝不编造指标/证言/logo 墙**；单屏约 80 词、hero 三件在 1280×800 不滚动可见；动笔前 real/pictures/absent 三栏清点；交付前跑 sloplint。
- 落点：`media/wb-visual-gen` KB，1.9.0 → **1.10.0**。

### ③ 并行 pane 五模式（提升层：工作流）
- 研究+实现双轨（结论回灌而非并行决策）；多文件特性；测试 watcher + 修复者（失败信息压成摘要再传）；跨 harness 按能力分工；三视角并行评审。硬纪律：只并行互不依赖、边界清晰、合并前复审、冲突用 worktree 隔离、pane ≤5–6。
- 落点：`engineering/wb-subagent-delegation` KB，1.68.0 → **1.69.0**。

### ④ 横纵分析法（提升层：模型 + 可复用 Skill）
- 三路并行取证；一手优先并识别"多家转载＝循环印证假象"；事实发生时间/页面发布时间/更新时间三者分记；单一来源/有分歧/暂缺三种标注；纵向五要件（起源/诞生/演进/决策逻辑/阶段划分）；横向按竞品 0 / 1–2 / 3+ 三场景；交汇五问（历史塑造位置、竞品时间线差异、优势与劣势的历史根源、未来三剧本）。
- 落点：**新建** `research/wb-hv-research/SKILL.md` 1.0.0。
