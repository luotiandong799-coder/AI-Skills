### 独点判据原文（逐条，不缩水）

- **r710C-1**：STRIDE / MITRE ATLAS / OWASP LLM Top10 是**同一评估的三个缩放层级**不是竞品，按序跑（广角威胁类型→technique ID+案例+防御手册→组件映射）；映射须**双向**（risk→component 圈范围、component→risk 查新组件继承什么风险）；加固预算按**组件共现频次**（LLM 推理端点命中 7/10 最该全面硬化、向量库 3/10 按信任边界处理）；检索层是信任边界非可信内部组件
- **r710C-2**：AI-native 威胁模型须补 **inference flow 第四维**（经典 STRIDE/PASTA/Trike 只画 data flow，假设决策在设计期由开发者做；AI 在运行时由模型做决策）+ worksheet 三行专属（model provenance / context-window trust boundary / tool-call authorization）；不可信输入边界要枚举到 chat 之外（检索文档/工具输出/记忆库）；**unexpected but technically permitted** 调用当检测信号而非授权 pass，连同触发 prompt 留日志；HITL 有效性按 Bannerman Authority/Time/Understanding 三要素验
- **r710C-3**：模型权重是**不可信供应链工件**：PyTorch 默认 pickle 反序列化即执行任意代码、load-time backdoor 早于首次推理；Sonatype 找出 Hugging Face `picklescan` 四个 bypass ⇒「扫描通过≠安全」，须补 load-time policy（weight hash 匹配签名 + 发布者白名单）与威胁模型中「加载这个模型会发生什么」独立条目；权重按 package-lock/容器 base image 同级管 provenance
