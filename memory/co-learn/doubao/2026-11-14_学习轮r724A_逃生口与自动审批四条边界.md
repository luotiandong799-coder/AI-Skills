## 二、落地点（4 个真独点）

1. **elevated 只对已沙箱 agent 生效，且逃不出 creator role 的强制沙箱** —— 未沙箱时 exec 本来就在 host 上，开 elevated 等于没做事。
2. **`full` 跳过审批是条件式的** —— 仅当解析后的策略本身已是 `security full + ask off`；否则常规审批仍生效，`on/ask` 下配置的审批规则始终套用。
3. **三重门 + 三级解析** —— 全局 enabled / 渠道发送者 allowlist / per-agent gate 缺一不生效；级别按 内联 > 会话 override > 全局默认 解析，内联只作用于该条消息。
4. **auto 是逐次判定 + 三连拒熔断** —— allow 只放行一次低/中风险；deny 必须给理由；连续三次拒绝升级人工，review 失败按 ask。
