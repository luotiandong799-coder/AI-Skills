## 落地 5 个真独点（全部带提升层）

1. **共享记忆只读化 + 多租户命名空间：防记忆注入的结构性手段** → context-compressor 3.646.0→**3.647.0**。要点：共享状态（组织策略/合规规则）设**只读记忆**防 prompt injection via shared memory；多租户用 **assistant_id 命名空间**；记忆结构文档化进 system prompt；不是所有 trace 都成记忆。提升层：安全（记忆注入防御）/ 工作流。
2. **MCP server 生产清单：命名/副作用标注/schema 校验/可观测性一票制** → compressor 3.647.0。要点：action-oriented 服务前缀（github_create_issue）+ 单责；写操作描述显式标副作用；typed JSON Schema + **handler 边界 Zod 校验**；长任务返回 **job ID** 状态资源化；版本化只 **additive schema 变更**；**CI 跑 MCP Inspector 冒烟测试** + 每工具 rate limit/timeout；窄用例起步。提升层：工具（MCP 工程）。
3. **错误分类→处置四标准** → execute-discipline 3.50.0→**3.51.0**。要点：瞬时错误 backoff+quarantine；数据校验错误 skip+reason code；**鉴权错误立即告警并暂停排程**；**rate limit 减速不重试**（重试放大突发是常见放大错误）。提升层：工作流（错误处置）。
4. **记录先于处置（logging before directives）+ Rollback handler** → execute 3.51.0。要点：任何 error handler 前先加模块捕获错误细节；处置指令五选一（Break/Ignore/Resume/Commit/Rollback）按可恢复性×关键性选。提升层：工作流。
5. **生产部署的 URL 是资产：避免不必要 redeploy** → execute 3.51.0。要点：redeploy 生成新 webhook URL，生产避免不必要 redeploy；端点 URL 是接口契约，不能静默换。提升层：工作流（部署运维）。
