## 落地 5 独点（每点标注提升层）

### 1. 2026 开源 AI 编码代理三新秀（工具/可复用 Skill）
来源：ai-tldr-releases / csdn-github-weekly38 / devto-10-open-source-agents
- **OpenCode 越 146k stars**：开源终端 AI 编码 agent——terminal-first、provider-agnostic、**完全开源基础设施可作 Claude Code 的换用**（要全开源 infra 就选它，不用被锁）。
- **ECC（everything-claude-code，affaan-m）**：AI 编码代理的 **harness 性能优化与工程系统**——Trending 第 38 周第三；harness 层（非模型层）优化成为独立工程品类。
- **阿里 Open Code Review（alibaba/open-code-review，Go）**：混合架构 AI 代码审查 CLI——2026-09 第 38 周 Trending 榜首；**AI 代码审查 CLI 化**（review 进命令行工作流，不依赖 IDE 或网页）。
- 判据：要自托管全栈编码 agent 看 OpenCode；harness 性能问题看 ECC 类工程；代码审查自动化优先 CLI 化方案（可进 CI/脚本）。

### 2. Agent Harness 生态目录与跨 surface 连续性（工具/工作流）
来源：harnesses.sh / betterclaw-frameworks / atlan-harness / rework-frameworks
- **harnesses.sh 75 harnesses profiled·9-axis capability schema**：9 轴能力模式对比 75 个 harness（最后验证 2026-07-08）——**选 harness 看能力轴评分不是看 star 数**；OpenClaw 382k stars MIT 自托管个人助手（"龙虾方式"数月爆涨）。
- **Kilo CLI（25,785 stars，基于 MIT OpenCode）**：终端 agent 三特征——**500+ 模型零加价 BYOK 定价**、MCP marketplace、**跨 surface 连续性**（任务可在 Slack/VS Code/JetBrains/cloud/terminal 间迁移不中断）。
- **CrewAI 1.15（2026-09，59K+ stars）**：role-based 编排，IBM/PepsiCo/DocuSign 使用（自称 65% Fortune 500）；AutoGen/AG2 61,042 stars 为清单最高但已 maintenance mode（迁移路线 r399B 已落）。
- 判据：选 harness=9 轴能力对照（模型/工具/记忆/权限/UI 等）+跨 surface 连续性；BYOK 零加价防锁定；star 最高不等于在维护（AutoGen 反例）。

### 3. Agent 基建新类别：网站转 CLI/agentic 浏览器/协作空间/身份网关（工具/工作流）
来源：yuxiaopeng-github-ranking-ai / trackawesomelist-awesome-agents
- **OpenCLI（jackwener，29,765 stars）**：**把任何网站变成 CLI**，复用你已登录的浏览器给 AI agent 用——网站没有 API 也能以 CLI 形式给 agent 调用（登录态复用是关键）。
- **BrowserOS（13,757 stars）**：开源 agentic 浏览器——ChatGPT Atlas / Perplexity Comet / Dia 的开源替代。
- **sim（simstudioai，29,765 stars）**：构建/部署/监控 AI agents 的协作工作空间——10 万+ builder 使用。
- **casdoor（14,488 stars，Go）**：**Agent-first IAM**——LLM MCP & agent gateway+auth server，支持 OpenClaw/MCP/OAuth/OIDC/SAML/CAS/LDAP/SCIM/WebAuthn/TOTP/MFA/Face ID——agent 时代的身份与网关（不是传统 IAM 改名）。
- 判据：网站无 API 时用 OpenCLI 转 CLI 复用登录态；agentic 浏览器类选开源替代；agent 规模化的身份层选 Agent-first IAM（网关+认证一体）。

### 4. 开源生态健康三维评估：星数不可靠（可复用 Skill/模型）
来源：arxiv-2607.02453 / atlan-harness
- **arXiv 纵向研究**：15 个主流开源 agent 框架仓库 2022 末-2026 初，用 **808,042 stars / 73,997 PRs / 86,241 commits / 987,330 用户画像**评估生态健康（awareness/adoption/retention 三维）。
- **第一发现：headline popularity unreliable**——**星数反映炒作周期**不是真实采用；PR 数/提交活跃/用户留存才是生态健康信号。
- **8/10 公司称数据限制是规模化 agentic AI 的首要路障（McKinsey）**——数据就绪度是 agent 落地的真实瓶颈，不是模型能力。
- 判据：评估开源项目别只看 star（炒作周期）；查 adoption（PR/commit 活跃度）+retention（用户留存）；agent 项目落地先盘数据就绪度。

### 5. Awesome 清单新信号：安全/本地/自进化/零门槛生成（工具/可复用 Skill）
来源：trackawesomelist-awesome-agents / awesome-ai-agents-korchasa / gitgem-ai-agents / awesome-ai-agents-2026
- **DarkMoon（⭐913）**：开源自托管自主渗透测试平台（MCP host）——编排 80+ 进攻性安全工具经 Claude/本地模型+本地 Privacy Gateway（安全测试本地化闭环）。
- **Atomic Agent（⭐2.5k）**：本地优先 CLI/TUI 编码助手——llama.cpp fork 全本地运行、**无账号无 API key、56 内置工具**（浏览器/终端等）。
- **Evolver**：GEP 驱动的 AI agent **自进化引擎**——通过 Genes（基因）与 Capsules（胶囊）实现**可审计可复用**的进化（不是黑盒自进化）——EvoMap 网络核心。
- **codex-slides（nexu-io）**：Codex 内开源 AI 幻灯片工作室——image-native decks、每页完整视觉画布、**10+ 高质量页约 4-5 分钟（并行渲染）、零 API keys、整链可见**（research→outline→style→render→edit→present→export PDF/PPTX）。
- 判据：安全测试本地化看 MCP host+Privacy Gateway 形态；本地隐私场景看无 API key 全本地 agent；自进化要可审计（基因/胶囊显式结构）不要黑盒；生成类工具零 API keys+整链可见=可信。
