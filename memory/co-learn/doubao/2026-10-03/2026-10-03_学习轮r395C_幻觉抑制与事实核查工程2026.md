## 落地 5 独点（每点标注提升层）

### 1. 幻觉抑制四阶段量化组合 + 严格引文契约（工作流）
来源：myengineeringpath / futureagi / sourcescore / niteagent / basicsof
- **四阶段降幅与成本量化**：RAG grounding 40-60% 降（50-200ms 检索成本）→ prompt constraints 10-20%（0ms）→ self-consistency 15-25%（2-5x 推理成本）→ NLI verification 20-30%（50-150ms 分类器）——按任务选组合，RAG 是单点最高杠杆；领域查询 RAG 减事实错误 50-70%。
- **严格引文契约（citation contract）**：每个事实声明必须引用检索段落 ID，**无段落支持必须弃答（abstain）**——在解码时抓主导捏造失败模式而非评审时；retrieve-and-hope 不够，需 ①严格 system prompt 禁无根答案 ②生成后引文检查拒绝无来源响应；inline citations 格式 `[^N]` 匹配上下文块，引文必须可对照验证。
- **闭卷→分级检索**（domain-grounded tiered retrieval）：像人类应试——先凭记忆答，绝对确定才输出；不确定走分级检索验证，不盲搜全网（贵且慢）。

### 2. 置信度门控弃答 + 行为校准 + 评分让错答比弃答贵（工作流/工具）
来源：zylos-calibration / fp8 / arXiv 2512.19920 / zep / freecodecamp
- **置信度门控弃答（confidence-gating）**：测模型不确定性→与阈值 τ 比较→超 τ 扣留或标记响应——**abstention 从失败模式变成正面能力**（共识转向）；测置信度四法=token log-probabilities / self-consistency sampling / semantic entropy / P(True) self-check。
- **行为校准**：可信模型应按用户指定风险阈值 t 动态调整拒答——**置信度 p≥t 才输出实质答案，否则输出拒答 token（"I don't know"/<IDK>）**；校准弃答层用少量覆盖率换大幅错误率下降。
- **评分设计**：把"I don't know"设为可接受、被指导的结果；**评估设计成"错答代价 > 弃答代价"**——模型学到的策略才会倾向弃答而非猜。

### 3. Informed Abstention 三缺口框架（可复用 Skill）
来源：arXiv 2606.02965（Designing for Doubt）
- **弃答是正面能力，但要有信息支撑**：Informed Abstention 是 precondition-aware、functional、traceable——触发于三缺口：① **specification gap**（所需输入缺失）② **verification gap**（世界状态无法确认）③ **authority gap**（无显式授权）。
- **路由到具体恢复动作而非终止**：暂停后不是结束，而是走向可执行的下一步（要输入/查状态/请求授权）。
- **生成结构化记录**：每次弃答留审计记录（什么缺口/为什么/恢复动作），使暂停**可审计、可改进**——弃答质量本身可评测可迭代。
- 反模式：无信息弃答（瞎拒）；弃答即终止不留恢复路径；弃答不可追踪。

### 4. CoVe 四阶段验证循环 + agent 每步验证门（工作流）
来源：devgent / zep / dev.to mech_app_ai（Chain-of-Self-Questioning）
- **Chain-of-Verification 四阶段**：① 起草首答 ② 按声明规划验证问题 ③ **不看草稿**独立回答验证问题 ④ 仅基于验证结果产出最终答案——分离草稿与验证优于一次抛光答案。
- **agent 映射**：验证门跑在**每一步**而非只在结尾（zep：run verification gates at each step, not just at the end）；Chain-of-Self-Questioning=承诺答案前先自问"我有答对所需信息吗"，自评不过则弃答——把答/拒决策变成可观测可调的控制面。
- 成本认知：CoVe/self-consistency 都花额外 token 换更少错误声明，无需外部知识库。

### 5. 归因幻觉 + CiteGuard-RAG 验证中心 + CiteCheck 三标签（工具）
来源：arXiv 2605.12882（CiteVQA）/ arXiv 2609.15830+智源（CiteGuard-RAG）/ arXiv 2605.27700（CiteCheck）
- **归因幻觉（Attribution Hallucination）**：模型答对率高但空间归因准确率（SAA）低——能提取信息答对，却无法把信息精确链接到文档内具体空间来源（GPT-5.4 答分 87.1 但 SAA 仅 59.0）；**引文有效性必须单独测，不能只看答案分**。
- **CiteGuard-RAG 验证中心**：运行时验证决定候选答案**接受/拒绝/再生成**；受控评估 99.1% 检索准确率/98.3% grounded-answer accuracy/98.3% 引文有效性；**消融=移除验证模块后答案依据准确率急剧下降（即使检索不变）**——验证模块不是可选项。
- **CiteCheck 混合检测**：验证引文①是否对应真实学术作品②元数据是否忠实——检索候选出版物+结构化 LLM verifier 比较+映射 **Exact/Minor/Major 三标签**；Retromorphic Testing（RT4CHART）=反向测试（从答案推检索需求）测幻觉检测，RAGTruth++ 答案级 F1 0.424→0.776。
