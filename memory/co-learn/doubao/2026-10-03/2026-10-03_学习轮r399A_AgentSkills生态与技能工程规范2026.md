## 落地 5 独点（每点标注提升层）

### 1. Anthropic SKILL.md 官方硬约束（可复用 Skill）
来源：anthropic-best-practices / anthropic-overview / anthropic-complete-guide / anthropic-help-custom-skills / claude-managed-skills
- **Skill bundle 结构**：目录顶层必须含 SKILL.md（YAML frontmatter 的 name+description 是唯二必填）+ 支持脚本/资源——SKILL.md 本身即核心。
- **name 硬约束**：≤64 字符；仅小写字母/数字/连字符；**禁 XML 标签；禁保留词 "anthropic"/"claude"**。**description 硬约束**：非空、≤1024 字符、禁 XML 标签、写"做什么+何时用"。
- **命名精确性**：文件名必须精确 `SKILL.md`（大小写敏感，SKILL.MD/skill.md 都不认）；技能文件夹 **kebab-case 无空格**（notion-project-setup ✅ / Notion Project Setup ❌）。
- **安装形态**：目录可 zip 上传到 workspace 或逐文件传，创建返回 `skill_*` ID 供附加到 agent；Anthropic 预制技能每个 workspace 自带无需安装。
- 判据：写技能先过命名与字段硬约束（name/description/kebab-case/SKILL.md 精确大小写）——这是被官方索引与安装器识别的前提。

### 2. 技能编写质量标准：recurring 工作流 + 输出可复现 + Quality Checks/Anti-Patterns（可复用 Skill）
来源：pm-claude-skills-standard / claude-blog-skills / skillsmp-marketplace
- **五条可勾选标准**：①解决 **recurring 专业工作流**（非一次性任务）②**问缺失输入而不是编造**③输出格式具体到"两次运行像同一个产物"④含 **Quality Checks 和 Anti-Patterns**——这是让技能可信的东西，不只是 prompt ⑤**无 setup 读文件即用**（不装依赖不配环境）。
- **文件是通用原语**：技能用文件表达=Git 版本化/Google Drive 存储/团队分享——skill 创作不限于工程师，普通用户也能写。
- **装前必读**：任何市场技能装前读 SKILL.md 和引用的脚本/权限——市场索引不等于认证，像对待开源代码一样对待社区技能。
- 判据：自写技能按五条勾选自查（尤其 Quality Checks+Anti-Patterns 必含）；装第三方技能前先读全文与脚本。

### 3. skills CLI 技能管理命令集 + 来源元数据溯源（工具）
来源：skillsmp-meta-find-skills / vscode-skills-sh / agskills-infsh-cli / skillmp-search-skill
- **命令集**：`npx skills find [query]`（交互或关键词搜索）/ `npx skills add <package>`（从 GitHub 或其他源安装，可 `--skill <slug>` 精确装单个）/ `npx skills check`（查更新）/ `npx skills update`（更新）——技能管理统一 CLI，像包管理器管 npm 包。
- **安装流程**：`npx --yes @agentskill.sh/cli install <slug>` → 验证安装位置 `.claude/skills/` → **补 source 元数据**（source-type: agentskills-io + source-origin: <slug>）——每个技能保留来源溯源，审计可查。
- **防静默覆盖**：`install.sh X --yes`——无 `--yes` 时非交互模式对已装技能直接拒绝（防止静默覆盖）；交互模式才阻塞等待 stdin。
- **编辑器集成**：Skills.sh 是 VS Code/Open VSX 扩展（Cursor/Windsurf/VSCodium 都能装），编辑器面板管理技能。
- 判据：技能增删改查走统一 CLI+来源元数据；批量安装带 --yes 前确认防覆盖。

### 4. 技能市场安全与信任机制：索引不认证 vs 三线审核 + TRACE 评测 + SkillPay 认证（工作流）
来源：skillsmp-marketplace / tencent-cloud-skillhub / cnr-skillpay / skillhub-wanuai
- **两类信任模型**：SkillsMP/ClawHub 类=**索引公开 GitHub 仓库但不认证不安装**（索引≠认证，社区技能按开源代码对待）；腾讯 SkillHub/虾小宝类=**平台审核后收录**（腾讯三线并行安全审核机制、虾小宝 35,000+ 安全审核技能）——选市场先确认它属于哪类。
- **TRACE 评测体系**（SkillHub 首发）：帮助用户识别高质量 Skill 的评测机制——质量参差是国内市场核心痛点，评测体系是差异化武器。
- **SkillPay 支付体系**（2026-07-16 上线）：技能分发+Agent 调用+技能支付同链路打通；平台负责**来源认证、内容完整性校验、可信调用入口**，微信支付做底层——付费技能的商业化支撑链路。
- 判据：装技能先查市场信任模型（索引型自己审，审核型信平台但也要读）；付费技能看认证链（来源认证+完整性校验）。

### 5. 国内技能市场生态格局：本土化镜像/算力模式/零 Token 安装/企业多源（工作流）
来源：tencent-skillhub / tmtpost-skill-stores / ai-indeed-skill-markets / skillhub-wanuai / allclaw-tencent-skillhub
- **腾讯 SkillHub**（2026-03-11 上线）：OpenClaw/ClawHub 官方生态的**本土化高速镜像**——解决海外下载卡顿/全英文界面/质量参差三痛点；聚合 13,000+（后期 8 万+）技能，国内镜像秒速安装；支持 WorkBuddy/QClaw/ima 等多款腾讯产品；大厂用 Skill 商店引流、算力是收入（调用消耗云算力）。
- **阿里虾小宝**（xiaxiaobao.cn）：JVS Claw Agent 助手内置技能市场，35,000+ 审核技能，一键同步到工具；**市场免费、调用耗算力**——算力是阿里云业务收入。
- **智谱 AgentMore Skills 广场**：整合官方严选+Skill Hub+开源社区三模块，**一键零 Token 安装**（零 Token=不耗积分直接装）。
- **字节双线**：火山 Find Skill 面向企业客户、整合 ClawHub/GitHub 多源；扣子（Coze）搭载自有 Skill。
- 判据：个人用户装技能按平台选（SkillHub 镜像秒装/虾小宝审核全/AgentMore 零 Token）；企业级（Find Skill）不投入；理解"免费市场+算力收费"模式后选平台。
