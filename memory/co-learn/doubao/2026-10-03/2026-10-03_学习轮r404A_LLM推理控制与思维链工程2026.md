## 落地 5 独点（每点标注提升层）

### 1. 推理预算控制三术：Budget Forcing / Separate Budgeting / 控制 token（工具/模型）
来源：zylos-budget-forcing-s1 / arxiv-2505.05315-elastic-reasoning / arxiv-2508.17196-budgetthinker / intuitionlabs-reasoning-tokens / gemilab-thinking-budget
- **Budget Forcing（解码阶段干预）**：模型思考超预算→**强制注入 `</think>` 结束符截断**；未达预算且该继续→**追加 "Wait" 续思 token 强制扩展**；s1-32B 仅 1000 条 s1K 微调+预算强制即超 o1-preview 竞赛数学 **27%**。
- **Separate Budgeting（显式分相）**：总预算 c=t+s 分开管——**思考相 t 与解相 s**；思考相耗尽注入 `</think>` 强制转解相——比 S1 各预算档更优。
- **BudgetThinker 控制 token**：解码时插入 8 个控制 token 表示剩余预算分数（7/8..1/8）——模型感知剩余预算自我调整推理投入。
- **budget_tokens 语义**：**预算是 target 不是 ceiling**——实际用量随任务变化；Anthropic 硬下限 1024 token（低于被拒）。
- **thinking 独立计费档**：Gemini 2.5 thinking tokens $3.50/1M（普通输入 $1.25、超 200K $2.50）、输出 $10/1M——**思考 token 比输入贵 2.8 倍，比预算更贵的是无限思考**。
- 判据：给推理模型设预算=target 非硬帽；复杂任务显式分思考相/解相；监控 thinking token 独立成本项。

### 2. 过度思考量化与最优思考长度（模型/工作流）
来源：arxiv-2604.10739-overthinking / papernotes-multi-agent / danilchenko-efficient-reasoning
- **边际回报随预算增加显著递减**；**过度思考=延长推理导致放弃先前正确答案**（不是无害冗余，是主动变错）。
- **最优思考长度随问题难度变化——统一计算分配次优**；成本感知评估框架=中等预算停止可大幅降计算保精度。
- **test-time compute 最值得用于难/中任务**：简单任务仅 +2.2pp——**系统应自适应难度路由**（简单→便宜路径，失败回退贵路径）。
- **SelfBudgeter**：推理模型自估最小 token 预算（无用户约束时）+按预算生成——缓解过度思考、减用户等待。
- 判据：给推理模型配预算=target 非硬帽；简单查询直答不触发长篇思考；监控"放弃先前正确答案"的过度思考信号。

### 3. 并行思考与多 Agent 推理计算权衡（模型/可复用 Skill）
来源：arxiv-2604.01302-parallel-thinking / arxiv-2608.24658-parason / heavyskill-github / arxiv-2605.01566-multi-agent-reasoning / papernotes-multi-agent
- **并行思考框架**：推理预算分布到独立线程，每线程多轮自验证+自精炼——**单条生成短（绕二次注意瓶颈），总 token 超训练时一个数量级**；顺序推理极端延迟→多分支并发替代逐 token 解码（Parason）。
- **HeavySkill=Parallel Reasoning（K 条独立轨迹并发）+ Sequential Deliberation（批判性综合成最终答案）**：**heavy thinking 一致优于 Best-of-N 多数投票**；强 LLM 通过 deliberation 逼近 Pass@N。
- **Debate 收益主要来自并行 agent 而非更多轮次**——过多轮次增加上下文成本并放大错误；**Self-refinement 表现差：重复自我修改≠更强推理**（无外部反馈时）。
- 判据：要并行就并行独立轨迹（K 路并发），不要靠更多轮次串行堆；合成时用批判性综合优于多数投票；无外部反馈的自我精炼别当推理增强。

### 4. Self-Consistency 实操：答案规范化 + 多数投票（工作流/可复用 Skill）
来源：36kr-self-consistency / wanshuiyin-reasoning-tutorial / papernotes-multi-agent
- **Self-Consistency Sampling（Wang 2022）**：temperature>0 采样 N 条 CoT→**提取每条最终答案并规范化**（去单位/简化分数/统一格式）→**多数投票**选最多答案；GSM8K **+17.9%**。
- **核心直觉=正确答案是"吸引子"**：复杂推理有多条有效路径，多条路径收敛于同一答案=高置信。
- **反模式**：不做答案规范化直接投票；假设更高 temperature 更好（实际多方法在 0.5-0.7 最佳区间）。
- **小模型极端扩展打不过大模型**——算力堆在能力基线上有上限，别用小模型无限采样冒充大模型。
- 判据：多采样投票前必须规范化答案（单位/分数/格式）；采样温度用中低档非越高越好；预算路由先按难度分档。

### 5. 效率提示与架构级省法（工具/工作流）
来源：danilchenko-efficient-reasoning / redis-token-budget / papernotes-adaptive-thinking / huawei-reasoning-cost
- **效率提示三术**：**Chain of Draft=每推理步 ≤5 词**（测出多少推理是 filler）；**Sketch-of-Thought 降 token 84%**（认知启发速记）；**更短推理链比长链准确率高 34.5%**；预算感知提示（提示含合理 token 预算）减半成本几乎无精度损失——**预算数值选择起关键作用**。
- **Sonata 自适应思考**：轻量 adapter 在 **prefilling 阶段从 last-layer hidden state 单次前传预测 self-consistency**——把"采样才能得到的难度信号"变"单次前传信号"，思考开始前就分配预算。
- **架构级省法（prompt 级 alone 会失效）**：**极度激进 Prompt 缓存**（5000+ token 系统提示只传变化部分，KV 复用率 80%+）；动态采样+自适应输出长度；**能力降档**（Luna/Terra 更多 test-time compute 下 98% 精度 1/18 成本）。
- 判据：推理型任务先问"多少思考是 filler"（CoD 测量）；预算提示数值要实验选定；架构层（缓存/路由/降档）与提示层一起省，不是二选一。
