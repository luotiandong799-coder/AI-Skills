## 落地 7 独点（每点标注提升层）

### 1. 路由四模式阶梯：从静态规则起步，复杂路由很少回本（工作流）
来源：dev-nathanbrooks-model-routing-guide / sfailabs-router-economics / gingerlabs-llm-semantic-routing / truefoundry-intelligent-routing
- **四模式复杂度阶梯**：静态规则（输入长度/user tier/query type/API endpoint——多数系统的最优起点）→ 启发式复杂度 → LLM-judge 动态 → 级联（cheap first + gate + escalate）。**从 pattern 1 开始，复杂度很少回本**。
- **典型静态规则**：短查询→便宜模型；长查询→强模型；免费用户→便宜模型、付费用户→贵模型；代码生成请求→代码调优模型、其余→通用模型。
- **路由是"用小决策替换硬编码模型"**：多数 SDK 默认把所有请求发给硬编码的一个模型——超支的根因就是没把硬编码换成"分类任务→选档位→必要时升级"。
- 判据：先问"这条路径是否需要动态决策"——不需要就用静态规则，别为简单负载上重型 router。

### 2. 级联路由的数学：break-even 命中率极低，但"理论节省≠现实节省"（工具）
来源：prakashkagitha-llm-stack-caching-routing / futureagi-evaluating-routing-policies / agentnative-cascade-pattern / gingerlabs-cascade-vs-single
- **break-even 命中率公式**：p*_s = c_s / c_l（便宜层单次成本 ÷ 贵层单次成本）——顺序级联中被升级查询浪费的只是便宜层那一次调用，所以 break-even 极低（示例 0.001/0.015 ≈ **6.7%**）。
- **理论 vs 现实节省差距大**：广告"60% 流量走便宜层、便宜层 1/5 token 价 → 省 48%"；现实要扣除重试、级联升级、shadow traffic、缓存未命中——**50% 广告命中率的 cheap-first 级联现实只省 30-35%**。
- **级联三层组件**（FrugalGPT）：prompt adaptation（短提示降 token）/ LLM approximation（缓存复用相似查询）/ LLM cascade（能力递增链）——FrugalGPT 报告最高 98% 成本降低且匹配或超 GPT-4 精度。
- **升级阈值从价格阶梯算，不从直觉**：$1.20/M-output 到 $25/M-output 是 ~20 倍步长——一次升级只有在预期质量提升值 20 倍 token 差价时才该发生。
- **成本台账记反事实**：每条路由决策记 cost_actual / cost_if_frontier / tier / escalation_reason——"我们以为路由省钱"和"路由真省钱"的差距只有反事实日志能变成测量。
- 判据：节省数字必须含重试/升级/缓存未命中后的事实核算；理论节省只是上限。

### 3. 路由折叠：预算越大越默认选最贵模型，小模型被系统性弃用（模型）
来源：arxiv-2602.03478-routing-collapse / arxiv-2605.07395-unsolvability-ceiling / arxiv-2606.29424-entrorouter
- **routing collapse 定义**：用户成本预算增加时，router 系统性默认选最强最贵模型，即使便宜模型已足够——**小模型利用不足，浪费算力与钱，违背路由初衷**。
- **根因是 objective-decision mismatch**：许多 router 的优化目标与决策方式不匹配；小预测误差即可翻转相对排序、触发次优选择。EquiRouter 直接学习模型排序，恢复小模型角色（RouterBench 上在 GPT-4 级性能处再省 ~17% 成本）。
- **两个 collapse 变体**：① 预算越大越选贵（over-reliance on frontier）；② Trust Region Collapse——多轮路由 RL 中强模型使用概率被推到零、"永远拒绝升级"的退化局部最优。
- **人工合成评测陷阱**：shuffled labels / random Gaussian features 都能复现 collapse——**纯标签边缘分布就能触发**，与特征质量无关；评估 router 须防评测产物（eval artifact）误导。
- 判据：router 上线后监控各档位利用率分布——若预算档位升高时便宜档位占用率不升反降，就是 collapse 信号。

### 4. Handoff tax：中途换模型的移交税，升级常比"冷启动"更贵（工作流）
来源：arxiv-2608.24358-handoff-tax / codexkb-handoff-tax-escalation / arxiv-2607.00053-swe-router / agentnative-structured-handoff
- **handoff tax 实证**（58,000 agent runs / 2M LLM 调用 / 500 SWE-bench Verified）：把非本模型的轨迹交给新模型续跑存在持续罚金——**naïve 升级几乎从来不是正确策略**。
- **方向不对称**：减少 LC（弱）模型轨迹信息→提升升级质量；移除 HC（强）模型轨迹→降低降级质量——**升级与降级要继承的轨迹信息量相反**。
- **SWE-Router 发现**：升级时 m2 应从任务重启（conditioning m2 在 m1 推理上会 bias m2 到 m1 的错误里）；弱模型 K 个回合成本先付、计入任何升级 run 的总成本。
- **结构化 handoff 而非 raw transcript**：任务陈述 + 便宜层尝试 + 客观失败证据（失败测试/schema 错误/工具拒绝）——封顶升级 token 成本，给前沿模型一个"评审任务"（比冷重启便宜可靠）。
- 判据：升级前先问"续跑非本地轨迹的税 vs 从任务重启的成本"哪个低——轨迹继承量与方向必须按升降级分别调。

### 5. 缓存感知路由：prompt 缓存是路由策略的一部分，不是事后账单（工具）
来源：maxtokens-cache-aware-routing / swfte-semantic-cache-aware-routing / digitalocean-prompt-caching-hit-rate / saram-caching-architecture
- **路由决策要算剩余视野总期望成本**：缓存写/读、未缓存输入、输出 token、预期重试、以及"早前缓存条目在 router 返回时还活着吗"的概率——**每个模型单独的缓存状态**。
- **prompt 缓存价格结构**（Anthropic）：cache write 1.25× 基础输入价（5 分钟 TTL）或 2×（1 小时 TTL）；cache read 0.10×（-90% 折扣）。Sonnet 4.6 $3/M 输入时写 5 分钟缓存条目 $3.75/M、读 $0.30/M。
- **缓存三层的命中率与节省**：prompt/prefix 缓存（精确 token 前缀，provider 侧，命中省 90% 输入 token，优化后 60-87% 命中）/ semantic 缓存（向量相似度，自建，命中 100% 省——LLM 不调用，生产 20-45%）/ KV-cache 优化（吞吐与延迟）。
- **路由时机判断**：上下文长且反复复用→一次路由（同模型续用积累缓存命中）；上下文短、反正冷→每步路由（切换自由）。session pinning 只在"切换便宜过缓存预热成本"时才断。
- 判据：路由策略的输入必须含缓存读写价与命中概率——"缓存是路由策略的一部分，不是 billing detail 事后发现"。

### 6. Conformal routing：分布无关的安全保证（模型）
来源：conformal-llm-routing-distribution-free / arxiv-2607.25018-conformal-cascade / openreview-routenlp / paperz-conformal-arbitrage
- **conformal gate 流程**：logistic 回归 gate（文本 embedding 特征）预测每查询安全 → Clopper-Pearson conformal calibration 选路由阈值 → **保证路由查询中违反率 < α（容忍度）的概率 ≥ 1-δ（置信度）**——分布无关、有限样本保证。
- **Conformal Cascade（CC）**：以 conformal prediction set 大小作 deferral 规则——校准集坍缩到单一答案时接受、否则 defer 下一档；per-tier union bound 给出接受层答案覆盖正确答的概率 ≥ 1-Kα。
- **RouteNLP 实操**：每任务每档 500 calibration 样本估算不确定性阈值；token 级不确定性 u = 1/L Σ(1-p(y_i|y_<i,x))；不足则级联到 k+1 档。
- **Conformal Arbitrage**：主模型 + 保守 Guardian（另一模型或人类专家）之间用 conformal risk control 校准阈值——长期不良事件频率（事实错误/安全违规）不超过用户指定配额，有限样本分布无关。
- 判据：高利害场景的"该信任哪档输出"要有数学保证——conformal 是给出违反率上限的校准方法，不是 vibe 也不是 leaderboard 分。

### 7. 会话感知路由：切换次数本身是成本，长视野 agent 要 pin 模型（工作流）
来源：vllm-session-aware-agentic-routing / channel-multi-model-agent-routing / nvidia-switchyard-escalation-router / mtrouter-multi-turn-routing
- **SAAR（Session-Aware Agentic Routing）实证**（21,600 确定性 turns）：router 持有会话记忆 + 工具循环硬锁 + 不可移植 provider 状态锁 + 安全重置边界 + prefix-cache-aware 切换定价 + 可重放 trace——**模型切换降 79.29%、消除 3,836 次不安全切换、估算物理模型成本降 78.71%**。
- **MTRouter**（历史-模型联合 embedding）：多轮路由比反应式单轮 router 做更少不必要切换（ScienceWorld 上 -58.7% 成本且超过 GPT-5、切换更少）——**"每轮独立选模型"是错的，会话内连续性是质量与成本资产**。
- **三模型架构**：一个 agent 至少用三个模型——plan 用强、route 用便宜、summarize 用便宜；监督者可用三者中最便宜的。
- **Escalation router 的 LLM judge 逐轮监督**：会话从低成本模型开始，LLM judge 逐轮监控进展（重复错误/循环/漂移）检测持续困难才升级——把 LLM 分类器路由从静态扩展为自适应。
- 判据：切换有税（见独点 4）——router 决策单位是"会话"不是"单轮"；工具循环、provider 状态、缓存命中都应在会话维度上受管。
