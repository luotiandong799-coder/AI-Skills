## 落地 5 独点（每点标注提升层）

### 1. Few-shot 用量与失效条件（模型）
来源：promptmake / promptai360 / technologypulse
- **JSON 遵循 70%→94%（3 例）**；3-4 例甜点，更多有害。
- **失效=简单任务/示例互相冲突**。
- 提升层：模型（提示参数化）。

### 2. CoT 与推理模型分工（模型）
来源：futureagi / aibuilderclub
- **非推理模型显式 CoT 提准确率**；推理模型加可见指令反而 hurt。
- **按任务选**；先 eval 验证再提交。
- 提升层：模型（推理策略选型）。

### 3. Lost-in-middle 实证与对策（工作流）
来源：ai-tldr / github-context-degradation / machinelearningmastery
- **U 型曲线，中间 recall 低 10-40%**；4K/10 块即触发。
- **rerank 放首尾/分阶段/chunk 1024 最优**。
- 提升层：工作流（长上下文编排）。

### 4. MCP 2026-07-28 无状态化大改（工具）
来源：aws-mcp-stateless / mcp-roadmap / render
- **核心改 stateless/initialize 握手移除**；remote=HTTP workload。
- **OAuth 2.1+PKCE 强制**；临时 bearer 只够原型。
- 提升层：工具（协议演进）。

### 5. MCP 工具设计规范与反模式（可复用 Skill）
来源：gingerlabs / ayinedjimi / loooop
- **单一职责/动作命名/描述标注副作用/typed schema**。
- **反模式=execute_anything/秘密入参/>30s 无异步**；响应全视为不可信。
- 提升层：可复用 Skill（工具开发规范）。
