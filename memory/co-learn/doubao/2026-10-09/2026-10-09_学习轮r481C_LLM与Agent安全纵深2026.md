## 落地 5 独点（每点标注提升层）

### 1. RAG 数据管道五防御（工具/工作流）
来源：securedai / protecto / wfnext
- **文档级 ACL+变更追踪+provenance+入库扫描+知识库当生产代码**。
- **投毒在到达检索层前处理**；数据源锁得像生产库。
- 提升层：工具/工作流（RAG 安全）。

### 2. 直接 vs 间接注入分工与全内容分类器（工具）
来源：arnav / owasp-cheatsheet / futureagi / aithinkerlab
- **direct=指令层级/系统加固；indirect=provenance/allowlist/调用前确认**。
- **inline classifier 覆盖全部外部内容**；pattern filter 不可靠。
- 提升层：工具（检测层）。

### 3. Ambient authority 移除清单（工作流）
来源：richards / agentpatterns / aiagents
- **八条硬化：不传环境变量/不挂 home/不暴露 socket/不复用凭证/不共享 cookie/不授权全部 MCP/禁默认网络出口/模型不选任意命令**。
- **工具定义=授权边界**；intent-shaped 胜 platform-shaped。
- 提升层：工作流（环境硬化）。

### 4. 多 agent 沙箱三规则（工作流）
来源：trezalabs / microsoft-securing-mcp / agentconn
- **独立凭证不继承/委托显式 scoped/sub-agent 结果视为不可信先验证**。
- **四层特权环+kill switch+hash-chained 审计**。
- 提升层：工作流（沙箱纪律）。

### 5. 审计日志悖论与异常监控（可复用 Skill）
来源：microsoft-owasp-mapping / owasp-threats / dev-owasp-recording
- **log_all_calls=True 默认=全参原文含 PII 入日志——日志本身是泄露面**。
- **ASI01-ASI10/Least-Agency/三列控制**；四模式异常监控。
- 提升层：可复用 Skill（安全框架）。
