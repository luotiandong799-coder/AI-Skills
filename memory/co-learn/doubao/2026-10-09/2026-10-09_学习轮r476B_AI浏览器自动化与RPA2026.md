## 落地 5 独点（每点标注提升层）

### 1. 自愈选择器与定位器韧性（工具）
来源：playwright / qaskills / startdebugging / arxiv-locator
- **getByRole/getByLabel 优先于 testId 再 CSS，无 exact:true**；十层定位器优先级。
- **Playwright 1.59 自愈=normalize()/pickLocator()/ariaSnapshot()**；LLM 读 ARIA 快照重识别+fallback 链。
- 提升层：工具（选择器）。

### 2. DOM 语义地图（可复用 Skill）
来源：brocogni
- **网页编译成结构化语义图（预计算选择器+置信度+fallback 链）而非倒原始 HTML**。
- **LLM 得到理解而非数据**——降噪声/脆弱/token 浪费。
- 提升层：可复用 Skill（agent 页面交互）。

### 3. 反检测指纹与反 bot 向量（工作流）
来源：kanopy / sendwin / ztabs / mobileproxy
- **指纹=WebGL/canvas/字体/navigator/鼠标轨迹/动作时序**；vanilla Playwright 默认挂；**JA3 hash+HTTP/2 settings**。
- **真 Chrome 带 display 非 headless+住宅代理+人类行为模式**（直线/均匀间隔=机器人信号）。
- 提升层：工作流（反检测）。

### 4. 挑战处理与 API 优先（工作流）
来源：codeables / capsolver / zharf
- **挑战检测器=内容/URL/DOM 签名，路由分流（bail 或人在环）**；CAPTCHA 服务=灰色地带。
- **API 优先=稳定文档化事务可验证/幂等**；浏览器自动化加渲染/会话/反 bot/ToS 风险。
- 提升层：工作流（合规自动化）。

### 5. Computer Use 工具面与 Tool Search（工具）
来源：dailyaiworld / edenai / anhtu
- **2026-08 GA 四件套=Computer Use/Browser Use/Tool Search/Managed Agents**；**Tool Search 上下文 72K→8.7K（-85%）**。
- **三大提供商=Claude/Gemini 3.5 Flash/OpenAI CUA**；先建安全脚手架（审计/kill-switch/人在环）。
- 提升层：工具（computer use）。
