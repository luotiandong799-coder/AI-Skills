## 落地 5 独点（每点标注提升层）

### 1. chunking 实证判据（工作流）
来源：rajatgautam / exploreagentic / superml / stochasticsandbox
- **512 tokens recursive/sentence 是生产默认，overlap 无可测增益（2026 研究）**；**表格 chunking 前抽出带表头行**（否则值丢失列含义）；**late chunking=先嵌整文档再切 token 序列**（保留上下文，Jina arXiv 2409.04701）。
- **生产 RAG 四失败点=naive chunking/检索 miss/排序失败/幻觉过 vibe check**。
- 提升层：工作流（分块选型）。

### 2. 混合检索+RRF+reranker 实证（工具）
来源：infoq / theneuralbase / aiworkflowlab / markaicode
- **hybrid=dense+BM25 并行，RRF 融合免分数归一化**（公式=1/(rank+1) 求和）；**k=60 常规；cross-encoder 在 top 20 上 +12.1 Recall@5 / +17.2 MRR@3**。
- **生产管道=Ingest 双索引（BM25+dense）→ 双通道 top-50 → RRF → cross-encoder top 50→10 → LLM+引用元数据**；**精确词/产品代码/错误码场景纯向量失效**。
- 提升层：工具（检索管道模板）。

### 3. RAGAS 四指标与阈值（工作流）
来源：callsphere / qaskills / devopsboys / inductivee / aiworkflowlab-vi
- **四指标=Faithfulness（回答只含检索上下文信息，抓幻觉）/Answer Relevancy/Context Precision（相关 chunk 排顶部）/Context Recall（上下文覆盖答案）**。
- **faithfulness 生产阈值 ≥0.85**（低于=≥15% 无来源信息不可接受）；**接入 CI 在 held-out QA 集跑**。
- 提升层：工作流（评估标准）。

### 4. RAG 评估集规模与策略（可复用 Skill）
来源：ianas / qaskills / ragas-docs
- **30-50 问=最小可行 / 100-200 问=生产理想 / 200+=仅多领域分开覆盖**；**50 条好问题 > 500 条生成问题**。
- **reference-free 指标评生产流量（无 ground truth）vs reference-based 开发期更强信号**；四指标承载几乎全部诊断权重。
- 提升层：可复用 Skill（评估集设计）。

### 5. RAG 四存在理由决策判据（工作流）
来源：ailearningguides / kunalganglani / younggao
- **freshness=百万 token 窗口不是数据库（小时级更新只能查询时检索）；scale=千万文档装不进任何窗口；cost=检索 2000 tokens 几乎免费 vs 发送 200 万 tokens 真实花钱且效果相当或更好；attribution=返回来源可引用/审计**。
- **naive RAG 已死（$0.001/query 原型），生产 RAG 是分层系统**——决策判据：何时用 RAG vs 长上下文 vs 微调。
- 提升层：工作流（架构选型）。
