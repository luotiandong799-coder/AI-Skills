## 落地 5 独点（每点标注提升层）

### 1. named passes 与双模型 draft-edit（工作流）
来源：aipromptshub / smartremotegigs / thedataquarry / findaiverse
- **named passes 单遍一目标**（tighten→cut 20%→flag vague，一次一要求否则 mushy compromise）；**draft 完整生成后再编辑**（实时 scrub 打断生成流）。
- **drafting 与 editing 用不同模型**（主 LLM 生成、轻量 LLM scrub 零边际成本）；**fresh session 每节一个**（brainstorm 与写作分开）。
- 提升层：工作流（编辑纪律）。

### 2. AI 文风量化指标与 CV-5 编辑门（可复用 Skill）
来源：humantext / metaflow / aivanguard-tcea / dredyson
- **perplexity=文本太可预测**（AI 说 "It is important to note that..." 人说 "Remember..."）；**burstiness=句长节奏（3 词到 30 词）**。
- **CV-5 编辑门=Cadence（句长标准差 ≥6.0 over 400 词）/ Volume punctuation（em-dash ≤ words/400）/ Five tell patterns（regex 扫描模板开头/hype 动词/形式化过渡）**；AI 列表等长等结构，人类列表不均。
- 提升层：可复用 Skill（文风质检规范）。

### 3. 内容质量记分卡与四信号（可复用 Skill）
来源：semihuman / winmassiveimpact / aivanguard-content
- **六维记分卡=Accuracy/Voice/Specificity/Relevance/Flow/Factual grounding**；权重表=Specific Examples 25%/Credibility 20%/Parentheticals 12%/Objections 10%/Imperfections 8%。
- **四信号=unique data+specific numbers+named entities+contrarian perspective——全过排名与人写持平，缺任一比历史基线低 41%**；Google 检测的不是"AI 写的"而是"是否添加了网上不存在的信息"。
- 提升层：可复用 Skill（质量记分卡）。

### 4. 结构化输出三阶段验证（工具）
来源：kanopy / precisionai / aiwisdom / zalt
- **syntax（合法 JSON）→schema（Pydantic/Zod 字段类型）→semantic（值合理：价格 -$500 合法 JSON 符合 schema 但业务规则错）**。
- **native structured output 优先**（response_format: json_schema/tool-use/JSON mode，失败率 <1%）+**validate-and-repair 兜底**（验证错误回传模型 maxRetries: 2）；Pydantic @field_validator 业务规则校验。
- 提升层：工具（输出验证管线）。

### 5. guardrails 附加控制（工具）
来源：actionai / vucense / dev-guardrails
- **refusal enforcement=模型该拒未拒/中途屈服 jailbreak 要 block；length/format 校验；confidence scoring 附置信度**。
- **guardrails 减风险不保部署安全**（schema 校验 + PII 脱敏 + toxicity 过滤）。
- 提升层：工具（护栏清单）。
