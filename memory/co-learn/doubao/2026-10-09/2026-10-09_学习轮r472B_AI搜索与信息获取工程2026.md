## 落地 5 独点（每点标注提升层）

### 1. agentic search 五步循环与六模式（工作流）
来源：csdn-mistral / usewire / arxiv-eigentsearch
- **Mistral 五步循环=search→open→navigate→read→grep**（模型每步决定下一步，非被动接受结果；FinanceBench 准确率翻三倍）。
- **usewire 六模式=read-before-answer gate（强制先读后答，12k 案例 +14.9-19.9 accuracy 点）/分解多跳/先路由后检索/路由与推理模型分离/验证循环/step budget 封顶**。
- 提升层：工作流（检索循环）。

### 2. 证据验证纪律（工作流）
来源：supernodes / linkup / aofirs
- **拆子问题→≥3 独立来源→全文读→每条声明带来源 URL→四档置信度评分才进答案**；**两源冲突=两侧都进答案带链接**。
- **diversity check=存留证据不同根域名 <4 触发改写再检索**；来源评估七问（Expertise/Evidence/Currency/Methodology/Originality/Commercial interest/Provenance）。
- 提升层：工作流（证据纪律）。

### 3. 查询改写实证与漂移抑制（工作流）
来源：arxiv-reformulation / alphaxiv / csdn-search-r1
- **改写非普适**（nDCG@10 增益按领域/范式高度可变）；**ReformIR=ranker feedback 在线抑制漂移**（更多改写=更严重退化）。
- **Search-R1=强化学习训练检索策略本身超越 RAG**（arXiv 2503.09516）；ThinkQE=corpus-interaction 迭代细化。
- 提升层：工作流（改写选型）。

### 4. 重检索闭环参数（工具）
来源：arxiv-rvr / futureagi / ragaboutit
- **RVR=Retrieve→Verify→Retrieve**（verifier 挑高质量子集，后续 query 用已验证文档增强找未覆盖答案，off-the-shelf 也有效）。
- **re-retrieval on failure=改写 query 围绕未支持声明再检索，2-3 次封顶超限拒绝**；**self-correction 循环=置信度 <85% 触发修正（改写/调 k/换方法），最大 3 次尝试**。
- 提升层：工具（闭环参数）。

### 5. 研究管道五阶段模板（可复用 Skill）
来源：dailyaiworld / codeables / anshadameenza
- **五阶段=拆研究问题为多 query 覆盖不同来源类别→执行收集候选 URL→并行提取（限速）→按相关性过滤+去重近似源→合成带内联引用结构化答案**。
- **别把原始问题直接扔给搜索引擎**（那是研究简报不是 query）；**行为=计划/执行/验证循环而非聊天**。
- 提升层：可复用 Skill（研究管道模板）。
