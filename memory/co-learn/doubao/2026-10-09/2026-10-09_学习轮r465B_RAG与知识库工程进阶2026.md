## 落地 5 独点（每点标注提升层）

### 1. 混合检索：dense+sparse+RRF（可复用 Skill/工作流）
来源：younggao / 1337skills / aipromptshub / dezakia
- **为什么要混合**：纯向量丢精确匹配——**查 'CVE-2025-47177' 或 '发票 #INV-20260512' 纯 dense 效果差（嵌入空间保不住罕见 token 身份）；BM25 单独又丢语义**。
- **实操**：dense（语义相似）+ sparse（BM25 精确词）双路检索，用 **Reciprocal Rank Fusion（RRF）融合**——按排名而非分数合并（两系统分数无需可比），文档在向量里排 #1、BM25 排 #3 综合高于两路都排 #2。
- 提升层：工作流（检索管道）/ 可复用 Skill（融合算法）。

### 2. Reranker 两阶段=最高影响力升级（工具/工作流）
来源：local-ai-hub / ailearningguides-mini / google-codelabs
- **相似≠相关**：向量检索只找"像的块"，不保证"切题"——reranker 把第一段 top 20-50 拿出来，**cross-encoder 逐对（query, chunk）打分真实相关性**，重排后只送 top 5-10 给 LLM。
- **定位**：基础 RAG 管道上加**单个最高影响力**的组件（第一段保证召回，第二段保证精度）；顺带解决 "lost in the middle"（长上下文中间内容被忽略）。
- 提升层：工具（reranker）/ 工作流（两段检索）。

### 3. RAG 评估框架：四指标+检索指标（可复用 Skill）
来源：eduresearch-ragas / mlflow / openlayer / microsoft / exploreagentic
- **RAGAS 四指标（reference-light，LLM 可估）**：**Context Precision**=检索出的块多少真相关（低=检索器在拉噪音，LLM 易锚定跑题段落）；**Context Recall**=回答所需信息有没有被检索到（精度高但召回低=答不全）；**Faithfulness/Groundedness**=答案是否被上下文支撑（直接测幻觉，答案主张中被上下文蕴涵的比例）；**Answer Relevance**=答案是否对题。
- **检索侧指标**：Recall@k（检索调参主信号）/ MRR（首条相关排位，第一条主导生成质量时用）/ nDCG（分级相关性+位置加权）/ Hit rate（单事实 QA 够用）。
- 提升层：可复用 Skill（评估矩阵）。

### 4. 查询转换四技（工具/工作流）
来源：kunal-playbook / bitdribble / mlmentorship / aithinkerlab / gohector
- **四技**：①Query rewriting=LLM 把模糊/对话式问题改写成可独立检索的查询（"那个年度的呢？"→完整查询，含指代消解）②Multi-query=生成 N 个变体分别检索取并集③Decomposition=复合问题拆子问题逐个检索④**HyDE（Hypothetical Document Embeddings）=LLM 先生成假设答案，嵌入假设答案去检索**——反直觉但有效：**答案形状比问题形状在嵌入空间更接近真实答案**（多文档 RAG 尤其重要）。
- **成本权衡**：每查询多 LLM 调用+延迟——**保留给 genuinely messy 的查询分布**（模糊/多部分/口语化），简单查询直接检索。
- 提升层：工具（HyDE）/ 工作流（查询转换决策）。

### 5. 分块策略与向量库选型（可复用 Skill/工具）
来源：google-codelabs / rapidclaw / ailearningguides-prod
- **分块四法**：Character（字符固定切）/ Recursive（标点/段落递进切）/ Token（token 数切）都影响检索质量；**Semantic 语义分块**=按嵌入相似度分组，主题连贯性跌破阈值处切（LangChain 有实现）——同类文本优先语义边界。
- **向量库权衡表**：Qdrant=自托管高性能+强过滤（运维负担）；Pinecone=全托管省心（规模成本+厂商锁定）；Weaviate=混合检索原生（体量重）；Milvus=十亿级 GPU 索引（集群复杂）；**pgvector=已在跑 Postgres 就用它（>10M 条才落后专用库）**；OpenSearch/ES=已跑它要统一 BM25+向量时。
- 提升层：可复用 Skill（选型表）/ 工具（分块实现）。
