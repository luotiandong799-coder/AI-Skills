## 落地 5 独点（每点标注提升层）

### 1. 视频 prompt 六要素模板+70/30 权重法则（可复用 Skill）
来源：novakit / skrrol / seeddance / hailuoai
- **六要素**：Subject（谁/什么在画面）→ Action（动作，动词比静图更重要）→ Camera move（static/dolly in/pan left/crane up/handheld）→ Environment（地点/光照）→ Style（cinematic/documentary/animated）→ Constraints（什么保持固定/什么不能出现）。
- **原理**：图 prompt 描述冻结瞬间，**视频 prompt 描述冻结瞬间+接下来发生什么**。
- **70/30 法则**：70% prompt 权重给 subject+core action（锚定"什么"），30% 给 camera path+environment（描述"怎么"）——防止模型只追镜头丢主体。
- 提升层：可复用 Skill（视频 prompt 模板）。

### 2. 相机运动术语与 prompt 顺序（可复用 Skill）
来源：sureprompts / imagera / lzyprompt / creatide / aivideobootcamp
- **术语表**：Pan=固定点水平转/Tilt=固定点垂直转/Dolly in-out=物理靠近-远离/Truck=横向穿越空间/Pedestal=垂直升降/Orbit=环绕/**static locked-off=完全不动**；**named movement+方向+节奏**（"slow dolly in"/"handheld tracking shot following the runner"）比"cinematic movement"可靠得多；**想无运动直接写 static camera** 防模型漂移。
- **token 权重顺序**（模型前部 token 权重更高）：Subject → Action → Camera movement → Lens/framing → Style/lighting——越重要的越靠前。
- 提升层：可复用 Skill（相机指令集）。

### 3. 时序一致性显式指令（可复用 Skill）
来源：promptailearning
- **temporal consistency**=光照不漂移/主体外观不变/相机不突然切镜；靠**显式指令**强制：`maintain consistent lighting throughout` + `no scene cuts` + `subject appearance remains identical across all frames`。
- 判据：一致性不是模型默认能力——VBench 2026 数据 motion smoothness 97%+ 但 **temporal consistency 仅 26-30%**（当前最大短板），必须写进 prompt 而不是指望模型。
- 提升层：可复用 Skill（一致性指令集）。

### 4. 角色一致性工作流（工作流）
来源：aivideobootcamp / novakit-multimodal
- **identity-locked**：先生成 character reference sheet（主体 4-6 个角度，如 Nano Banana Pro）→ 每镜用对应角度图作 **start-frame reference** → 驱动每镜（Kling 3.0 角色一致性领先/Seedance 2.0 写实领先）。
- **跨项目纪律**：所有镜保持 reference set 不变；**seed control**——同 seed+同 prompt≈相同输出，做同场景变体用。
- 提升层：工作流（角色一致性管线）。

### 5. 多镜协调整合+工具矩阵（工作流/工具）
来源：domer / nisai / aitoolbox / cvpr
- **六步流程**：①fast models 先验证最难镜（主体稳不稳/运动合理不）→ ②问题在 reference/prompt 阶段修（别烧 premium compute）→ ③最高保真模型每镜出 **2-3 variations** 给剪辑选项 → ④跨场景 reference set 不变 → ⑤post 统一调色 → ⑥场景完成 checklist：角色匹配 anchor set（脸/衣/比例）/光照来源与方向一致/环境细节跨镜重复/相机地理符合 shot map/风格匹配 production style/**按序列审不按单镜审**。
- **工具矩阵**：Kling=真实人体运动物理精度最高/Luma=最快高保真/HeyGen=口型同步+175 语言翻译 0.02s/Hailuo=面部微表情领先/Pika=风格化+快速迭代（10s 上限）/Veo=4K+可扩展场景/Sora=长叙事；组合=hero shot 用 Sora/Kling+有真实素材用 Runway Aleph（更便宜可控）+文字字幕用 Veo 或后期加。
- 提升层：工作流（多镜管线）/ 工具（选型矩阵）。
