## 落地 5 独点（每点标注提升层）

### 1. LLM 数据分析四类失败（可复用 Skill）
来源：arxiv-data-in-the-wild / aipromptshub / bswen
- **aggregated/disaggregated 双计数**：male+female+total 的 total 不滤就重算错；**Transformation Error 23.2%**（datetime day-first 解析错等整理失败）。
- **plausible-but-wrong aggregations**：对已平均列再平均/fan-out join 双计数/滤波器悄悄改分母——结果合理正是危险处；invented numbers（问不在数据集里的统计）。
- **pattern matching 而非计算**：数据像零售销售就生成"感觉对"的统计，不管实际数字。
- 提升层：可复用 Skill（失败分类清单）。

### 2. 统计陷阱与显著性幻觉（可复用 Skill）
来源：hub-cissychen / lianxh / oxford / pnas
- **Simpson's paradox（分组后趋势反转）/幸存者偏差/type/NULL 静默错（NULL 当 0 拖低均值）/p 值造假（agent 自动跑几十个切片挑"显著"的讲故事）**。
- **Prompt-Hacking 实证**：94.4% 零假设可制造虚假显著性；98.1% 真实效应可隐藏；68.3% 已显著效应可逆转（Type S error）；**即使标准流程+较强模型错误结论仍约 31%，小模型近 50%**；改变量名可让预测误差变化高达 82%。
- 提升层：可复用 Skill（统计红线清单）。

### 3. 验证纪律：ground truth + agreement（可复用 Skill）
来源：treese / iclr / bswen
- **LLM 输出不经验证不可信**——必须对照 ground truth/人标签；**raw confidence 不可用**（系统性过度自信），用自洽性 agreement 作 triage 不当概率。
- PII 在调外部 API 前检测/脱敏；eval 需 error bars——单次分数不稳（模型/agent/judge 本质随机）。
- 提升层：可复用 Skill（验证管线）。

### 4. NLQ 工具与 query-creator 模式（工具）
来源：pypi-askpandas / vslzai / geekchamp / langflow / dotprotools
- **query-creator 模式=LLM 生成中间 Python/SQL 代码再执行而非直接答**——可审计可复现，是"可信"的来源。
- 工具矩阵：PandasAI（CSV/SQL/DataFrame 英文查询+出图）；askpandas（**本地 Ollama 免费无 key**）；Colab Gemini Data Science Agent（免费浏览器内）；Julius AI（全循环解释结果）；Langflow conversational CSV（非技术用户）。
- 提升层：工具（选型矩阵）。

### 5. 个人周报流水线模板（工作流）
来源：claudelab / excellogics / vibecoding
- **模板=取数（CSV/Google Sheets）→pandas 聚合→Matplotlib 出 PNG→LLM 分析环比写点评→Markdown 报告+Slack 通知→定时跑**。
- Excel 侧：Power Query 清洗+**Reporting Month 参数化**（改范围不动查询）+Power Automate 刷新调度；调度选型=GitHub Actions（连代码库）→GCS Scheduler→VPS cron（简单周期）→Prefect/Airflow（多步依赖，复杂度递增）。
- 提升层：工作流（可复用模板）。
