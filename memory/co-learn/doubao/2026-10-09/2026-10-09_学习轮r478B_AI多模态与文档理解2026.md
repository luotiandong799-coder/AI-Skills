## 落地 5 独点（每点标注提升层）

### 1. VLM 取代 OCR 管线（工具）
来源：niteagent / noqta / ai-tldr
- **Vision LLM 单次调用取代 Tesseract+layout+NRE**；pipeline=normalize→VLM→schema 验证→路由。
- **PDF 分矢量/扫描两类；200-300 DPI；表格提示 Markdown 输出再解析**。
- 提升层：工具（文档提取）。

### 2. 分类引导与 schema 驱动提取（可复用 Skill）
来源：arxiv-vie / niteagent / mixpeek
- **类型分类与抽取解耦+ICL 动态 prompt 注入任务知识**（零样本跨版式）。
- **Pydantic schema 带校验约束远好于自由式提取**；误分类=下游级联错误。
- 提升层：可复用 Skill（提取设计）。

### 3. 混合管线：OCR+LLM vs 纯 VLM（工具）
来源：ai-engine / llmversus / cohere-parse5
- **传统 OCR 走 80-90% 便宜流量+VLM 边界 case/手写/交叉验证**（4x 低成本+100% 准确）。
- **Parse 5=2.3B VLM→规范 Markdown+bbox 坐标；NuExtract 3=4B 金发区**。
- 提升层：工具（混合管线）。

### 4. 粗到细视觉处理与置信度路由（工作流）
来源：papernotes / iterationlayer / anhtu
- **VRFM 框有效区域→裁背景→紧凑 VLM 精识别**（干净小块提效）。
- **per-field 置信度→超阈值自动/低于阈值人工复核**；bbox=引用锚定。
- 提升层：工作流（路由与复核）。

### 5. 文档处理五阶段与证据链（工作流）
来源：xbstack / aws / webotit / codeables
- **ingestion→OCR→structuration→decision（LLM+rules）→citations 五阶段**。
- **页码指纹+角色过滤+证据高亮坐标人工复核**；元数据打标再分块。
- 提升层：工作流（证据链）。
