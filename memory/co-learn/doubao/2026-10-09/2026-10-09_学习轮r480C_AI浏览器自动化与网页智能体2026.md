## 落地 5 独点（每点标注提升层）

### 1. Playwright MCP 浏览器自动化（工具）
来源：playwright-dev / microsoft-learn / csdn
- **MCP 服务器通过无障碍快照驱动，无需视觉模型**。
- **客户端无关+remote MCP 托管云浏览器**（无需装二进制）。
- 提升层：工具（自动化通道）。

### 2. 无障碍树感知三档（可复用 Skill）
来源：ailearningguides / openlegion / jeromeetienne / w3c
- **DOM（token 爆炸）→a11y 树（去噪可靠）→截图+坐标（最贵）**。
- **browser_snapshot 转文本**；纯视觉信息需混合截图。
- 提升层：可复用 Skill（页面感知）。

### 3. Agent-ready 网站与 sitemap 增强（模型/工作流）
来源：arxiv-agent-ready / aclanthology-sitemap
- **executability=理解后可靠动作的程度**；可读性/可操作性/决策可靠性。
- **sitemap 增强显著提升成功率**（强于 ReAct 基线）。
- 提升层：模型/工作流（站点可代理性）。

### 4. CAPTCHA 分层处理与合规边界（工作流）
来源：openlegion / browserless / geekflare / zharf
- **三层=环境指纹代理→执行层自动解→人机 handoff（2FA/QR）**。
- **合规=验证码信号即停止按站点流程**；不绕过访问控制。
- 提升层：工作流（验证码处置）。

### 5. 浏览器自动化可靠性工程（工作流）
来源：novapixel / browserless / voidmob
- **生产走 ISP/住宅代理**；显式关闭 contexts 防资源泄漏。
- **空数据校验 challenge 签名**；随机点击=坏模式。
- 提升层：工作流（可靠性）。
