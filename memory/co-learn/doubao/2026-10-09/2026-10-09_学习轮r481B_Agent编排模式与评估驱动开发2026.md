## 落地 5 独点（每点标注提升层）

### 1. 编排三模式与选型决策表（工作流）
来源：stochasticsandbox / aiforanything / aws-step-functions
- **单循环/多 agent 委托/supervisor**；决策表按子任务数/上下文/专业化/实时性选。
- **Step Functions 把编排移出 agent 层**（确定性路由可独立测试）。
- 提升层：工作流（编排选型）。

### 2. LangChain 动态 subagent 三模式（可复用 Skill）
来源：langchain-dynamic-subagents / arxiv-swarmresearch
- **classify-and-act/fanout-synthesize/adversarial verification** 按问题形状选。
- **orchestrator 不写 subagent prompt**；能力边界分清。
- 提升层：可复用 Skill（模式库）。

### 3. 系统级评测指标栈（模型/工具）
来源：futureagi / logic
- **模型基准不预测应用回归**；系统级 correctness/relevance/faithfulness。
- **agent 级 task adherence/tool-call accuracy/trajectory**；RAG 级三类。
- 提升层：模型/工具（指标选型）。

### 4. 评估驱动迭代与回归管线（工作流）
来源：techearl / promptassay / arxiv-generic
- **golden dataset+评分混合+CI fail**；阈值 0.7 默认/0.85 客户面向。
- **通用 prompt 改进会伤特定用例**，必须评估驱动迭代。
- 提升层：工作流（迭代纪律）。
