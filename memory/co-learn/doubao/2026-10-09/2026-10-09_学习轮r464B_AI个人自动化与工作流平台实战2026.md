## 落地 5 独点（每点标注提升层）

### 1. 自动化平台选型判据（工具/可复用 Skill）
来源：csdn-n8n-dify / dev-hirak8 / aiclases
- **三平台各管一段**：n8n=通用自动化和系统集成核心，AI 是其中一个强大组件——**需要把多个 SaaS 连起来、数据在系统间流转时选它**；Dify=AI 应用开发核心，自动化是辅助——**要搭以 AI 对话为核心的应用（客服机器人/RAG 知识库）时选它**；Make/Zapier=无代码快速场景（如发票提取走 Make+Claude Vision）。
- **自动化水平阶梯**：可复用 prompt → 无代码工具（Zapier/Make/n8n）→ AI agent——按任务复杂度选级，不一步上 agent。
- 提升层：工具（选型）/ 可复用 Skill（决策表）。

### 2. n8n AI Agent 分层架构与四模式（工具/工作流）
来源：strapi / n8n.it / aiworkflowlab / triumphoid / mintlify
- **分层节点架构**（LangChain.js）：根节点 AI Agent（定义主逻辑，自 1.19 版原生）+ 子节点（模型/记忆/工具/输出 parser）——**可视化画布里组装 agent，可版本化/可调试/可部署**，同任何 workflow。
- **四模式**：①Chained requests=顺序 AI 模型调用+中间处理，**降 API 成本 30-50%** ②RAG pipeline=向量库+嵌入检索上下文 ③Hybrid rule engine+LLM fallback=规则优先、LLM 兜底（不是每个决策都值得 LLM 上）④Manager agent with sub-agent tools=经理 agent 评估输入分派给专用子 agent（各配角色/记忆/模型）。
- **两条实现路径决策**：内置 AI 节点（快、低代码）vs Code 节点裸 Python/LangChain（灵活、可控）——模板教程都推路径 1，复杂定制才走路径 2。
- 提升层：工具（节点架构）/ 工作流（模式选型）。

### 3. 生产级多 agent：上下文作用域+按任务选模型（工作流）
来源：n8n-blog-production-ai / n8n-lead-qualification
- **scope context per agent**：**别把完整对话历史给每个 agent**——账单专家只要账单相关片段，不是前面 15 条技术排查消息；用 workflow 逻辑抽取只传相关上下文。
- **按任务选模型**：不是每个 agent 都要最强（最贵）模型——分类/路由/简单任务用轻模型，复杂推理留给旗舰模型（与模型路由互补，这里是平台内落地）。
- 提升层：工作流（上下文裁剪+模型分级）。

### 4. 个人自动化场景库（可复用 Skill/工作流）
来源：n8n-personal-data / aitooldiscovery / forbiddenai / aiempowered / n8nlab / dev-hirak8
- **邮件 triage（最值）**：新邮件→AI 分类（紧急/普通/垃圾）→路由标签/文件夹→紧急件草拟回复——每天省 30-90 分钟收件箱时间。
- **个人多 agent 助手**（Telegram+GPT-4o）：工作追踪 agent（开始/结束命令算工时写 Google Sheets）+ 任务管理 agent（待办增删改查实时同步）+ 财务 agent（多币种收支/日报/交易历史）+ 邮件分析 agent（Gmail 摘要）——一个入口多 agent 分职。
- **其他模板**：发票提取（Make+Vision：邮箱收发票→提厂商/金额/日期）、内容转载（博客→Twitter/LinkedIn/newsletter 摘录+排程）、网页爬取、带记忆聊天机器人、文档分析、社交内容 agent。
- 提升层：可复用 Skill（场景库）/ 工作流（模板复用）。

### 5. 构建纪律与记忆隔离（可复用 Skill）
来源：n8ntemplatestore / aitoolsdaily / n8n-it
- **先最小再叠加**：先接单个 Agent 节点无工具确认模型响应正常→一次只加一个工具（每个工具=HTTP Request 节点，URL/方法/输出 schema 精确）→工具描述=像向没见过的人解释→**逐个隔离测试再接进 agent**。
- **一对一任务不需要记忆**：每封邮件独立，不加 memory；真要加（如跨邮件线程上下文）用 **session key（如 thread ID）** 防对话串扰——记忆每轮都进上下文，**直接线性涨成本**。
- 提升层：可复用 Skill（构建纪律）/ 工作流（记忆开关决策）。
