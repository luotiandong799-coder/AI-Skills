## 落地 5 独点（每点标注提升层）

### 1. 图像提示词七槽结构（可复用 Skill）
来源：egoistai / agentbrisk / sureprompts / neuraplus
- **七槽=[Subject]+[Environment]+[Style/Medium]+[Lighting]+[Camera/Composition]+[Mood]+[Quality Modifiers]**；六槽填满就停词。
- **每个 token 必须挣得位置**——style cargo culting（抄来的 "Trending on ArtStation" 已大多失效、"Unreal Engine 5" 很少按预期改变输出）；一次只改一个元素。
- 提升层：可复用 Skill（提示词规范）。

### 2. 模型特定提示词语法（工具）
来源：bestaiweb
- **SD3.5 正向 prompt 前置**（早 token 权重更大）；**加重 (term:1.3) 用得克制**（MMDiT 双 CLIP+T5 对权重不如 SD1.5 敏感）；减弱 [term]；negative prompt 按模型写。
- 语法不通用，按模型选。
- 提升层：工具（选型语法）。

### 3. seed 锁定与版本化一致性（工作流）
来源：aiquickpicks / moruk
- **seed 锁定=面部几何/产品比例/地平线保持**；逐参数变化（chaos +0.05/stylize -0.x）探索受控变体。
- **版本化命名=project_subject_style_v03_seed1234**；保存 prompt+negative+model version+seed；style reference 锚定品牌风格向量。
- 提升层：工作流（一致性纪律）。

### 4. 图像质检指标矩阵（可复用 Skill）
来源：colossis / sozee / communeify / papernotes
- **FID=批量健康（<10）→CLIP Score（>0.85）=文本对齐→LPIPS（<0.1）=感知相似→PickScore=per-image triage（比 CLIP 更贴合人类排名，逐图 pass/fail）**。
- 无参考=NIQE/BRISQUE+VLM judge（ArtifactLens）；Q-Judger 结构化 JSON 四档 0/1/2/N/A 可追溯；**CREval 三指标 IF/VC/VQ=改到位/没改坏/画质好分开核验防总分糊一起**。
- 提升层：可复用 Skill（质检规范）。

### 5. inpaint/outpaint 编辑工作流（工作流）
来源：versely / knowledgelabs / nexvy / flux-art
- **inpainting=mask+text 只重生成区域内**；**outpainting=边界外扩展（竖转横/加 headroom 放文字/改比例一次出多版）**；**feather mask 边缘防接缝**。
- 坏手修复=刷区域+"natural relaxed left hand…same lighting and skin tone"；selective inpainting 配 subject-segmentation skip 保护区域外；character swap=LoRA 换人保背景/姿态+增强阶段修细节。
- 提升层：工作流（编辑模板）。
