## 落地 5 独点（每点标注提升层）

### 1. LLM-as-Judge 四偏置与二进制打分（工具）
来源：mlait / ai-tldr / evidently / mastra / microsoft
- **position（随机化顺序+平均）/verbosity（直接打分非选最佳）/self-preference（异族模型）/sycophancy 四偏置**占信任失败大头。
- **二进制打分优于 1-5**（Microsoft 六脆弱性：scale ambiguity/prompt sensitivity/context sensitivity/calibration drift/aggregation opacity/reference-free）。
- 提升层：工具（评分设计）。

### 2. Judge 校准纪律（可复用 Skill）
来源：futureagi / digitalocean / arxiv-sos
- **无人类校准的 judge 分数不相关任何可测物**；rubric 写可测要求非"总体质量"；单 rubric 多用途=drift。
- **judge prompt 五要素=准则/校准示例/随机化/schema/自一致性**；SOS-Bench=风格压倒实质（judge 隐式偏置）。
- 提升层：可复用 Skill（judge 设计）。

### 3. Golden Set 纪律（工作流）
来源：metacto / langchain / matterai
- **代表性=分布镜像生产流量（只能用 tracing 采样）**；100-300 例够抓回归；**git 版本化**。
- **seed=50 条生产 trace 人工标 pass/fail 启动首个 eval 套件并校准 judge**。
- 提升层：工作流（评估集构建）。

### 4. 回归测试统计学与 LLM 测试金字塔（工作流）
来源：futureagi / wickedsmartdata / testquality
- **frozen golden set+Welch's t-test 对 7 天滚动基线逐例 delta**；统计假设检验非简单阈值。
- **金字塔=unit→regression eval→integration→red-team**；RAG 三连防幻觉。
- 提升层：工作流（回归纪律）。

### 5. Agent 三 grader 与 eval 契约（可复用 Skill）
来源：anthropic / vectorinstitute / agentropic / mastra
- **code-based（机器可验证抓错数字）+model-based（n=3 多数决评推理）+human（抽样校准）三 grader**。
- **eval=golden dataset+scoring method+pass-rate threshold 三件套**（验收标准变 eval cases）；工具调用三指标=selection/parameter/sequence accuracy。
- 提升层：可复用 Skill（agent 评估契约）。
