## 落地 5 独点（每点标注提升层）

### 1. Agent 可观测性工具选型矩阵（工具）
来源：handpickedai / langfuse / langchain
- **Langfuse=开源 MIT 自托管框架无关**（LLM+非 LLM 全记/session 追踪/agent 图）；**LangSmith=闭源 SaaS**（annotation queues/LLM-judge 自动评分/SmithDB 亚秒查询）。
- **选型=部署方式+什么在坏**（LangChain 生态深→LangSmith；评估瓶颈→Braintrust）。
- 提升层：工具（选型）。

### 2. OTel 基座与 traces/metrics 分工（工作流）
来源：futureagi / infoq / microsoft
- **"traces are for debugging, metrics are for alerting"**——granular session 上下文只放 traces/结构化日志。
- **异步批量导出器（span 内存队列周期 flush）**；嵌套子 span 保留委托链；瀑布图+根因聚类。
- 提升层：工作流（观测基建）。

### 3. 确定性重放与 counterfactual replay（可复用 Skill）
来源：burr / microsoft / arxiv-agentstepper
- **生产失败完整上下文→隔离环境确定性重放→step-through+二分**（比"复现+加日志"可靠）。
- **counterfactual replay=任意步 fork、只改一输入、只重放下游、diff 轨迹**——未改分支 hash 全同且零 token（可信任 diff vs 噪声）。
- 提升层：可复用 Skill（调试方法）。

### 4. 工具可靠性四查与多 Agent 交互图（工作流）
来源：dev.to-santu / machinelearningmastery / arize / arxiv-agentsight
- **工具四查=API 响应质量/超时/重试/畸形输出**（agent 对噪声输出极敏感）。
- **多 Agent tracing=交互图+路径图找委托断裂/瓶颈**；AgentSight eBPF 零插桩（TLS 意图+内核效应因果关联，<3% 开销）。
- 提升层：工作流（可靠性分析）。

### 5. Trajectory 会话视角与失败回链（工具）
来源：langsmith-trajectories / zylos / langfuse
- **Trajectory=跨主/子 agent 聚合 human/AI/tool 消息按首次出现顺序**，可打分+路由 annotation queues。
- **失败回链=judge 标记时回链到当时确切 prompt/检索块/工具输出**；traces 重放新模型=受控实验。
- 提升层：工具（会话调试）。
