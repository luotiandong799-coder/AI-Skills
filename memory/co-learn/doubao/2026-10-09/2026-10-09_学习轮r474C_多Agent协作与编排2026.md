## 落地 5 独点（每点标注提升层）

### 1. 编排模式实证数字与单 orchestrator 共识（工作流）
来源：niteagent / syncsoft / flowhunt
- **Bounded Collaboration=窄域可靠 100% vs 1.7%**；AORCHESTRA 并行 +16.28%。
- **2026 共识=单 orchestrator 持有全部上下文+临时隔离子代理+只回压缩摘要**（Anthropic/Cognition/OpenAI/MS/LangChain 全收敛）；Supervisor 失败模式=控制器瓶颈（~15x token）。
- 提升层：工作流（模式选择）。

### 2. Fan-Out/Fan-In 与 Blackboard 模式（工作流）
来源：molayo / paiteq / zylos
- **Fan-Out/Fan-In=dispatcher 并行分发独立子任务→聚合**（探索性并行/研究最佳）。
- **Blackboard=共享结构化工作区按能力捡活**（爬虫/分布式代码分析/弹性负载）；Swarm=无中央协调+终止规则。
- 提升层：工作流（并行模式）。

### 3. Agent 通信协议分层与 AACP 压缩（工具）
来源：iotdigitaltwinplm / ijsrst / arxiv-acp / ietf-aacp
- **协议分层=MCP（工具层）/A2A（跨组织握手）/LangGraph（状态编排）/ACP（发现+协商+执行）**。
- **AACP=自然语言协调指令→确定性类型化 packet（管道分隔）**，可验证/可审计/可重放。
- 提升层：工具（协议选型）。

### 4. 框架选型与混合路径（工具）
来源：dev.to-saaro / ayinedjimi
- **LangGraph=复杂合规最大状态控制；CrewAI=快速原型；AutoGen=会话+人交互**。
- **混合=原型 CrewAI、生产 LangGraph**；铁律=2-3 agent 起步+清晰边界+错误处理计划。
- 提升层：工具（框架选型）。

### 5. 多 agent 可观测性：trace ID 与重放（可复用 Skill）
来源：langfuse / futureagi / mlflow / makerstack
- **跨服务传播 trace ID（OTel 上下文传播→同一 trace）；从 seed 派生确定性 trace ID**；span 级 rubric 评估。
- **确定性重放+成本治理+消息总线可见性**（APM 做不到）；Galileo 运行时护栏、PandaProbe 漂移监控（$29/mo）。
- 提升层：可复用 Skill（观测纪律）。
