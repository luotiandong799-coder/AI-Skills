## 落地 5 独点（每点标注提升层）

### 1. 语音 Agent 级联架构与延迟预算（可复用 Skill）
来源：nvidia / ijarcce / arxiv-realtime / assemblyai / agentbrisk
- **STT→LLM→TTS 级联**，每组件独立；**总延迟<600ms 才自然**（1s 阈值是分界）。
- 流式三件：streaming ASR 句末出终稿→LLM 流式→TTS 收首批 token 即合成（78ms 首音频/端到端 0.79s）；**sentence buffer=流式 LLM 与 TTS 的临界桥**——检测句末标点（.?!）yield 完整句子给 TTS（TTFB 219-236ms；RTF 0.05-0.10=比实时快 10-20×）。
- **全双工 voice model 移走 turn detector**（GPT-Live）——边听边说，无需单独检测器。
- 提升层：可复用 Skill（延迟架构）。

### 2. TTS 选型矩阵（工具）
来源：bitbytes / futureagi / reviewnexa / aikonjured
- **速度档**：Cartesia Sonic 3=40-95ms TTFA（最快）；ElevenLabs Flash v2.5=75ms 流式（克隆质量最佳）；Turbo v2.5=250-400ms。
- **模型族分工**：Flash 低延迟→交互/agent；multilingual v2/v3 高质量→内容/旁白/播客（29-70+ 语言）。
- **监听测试方法论**：同一 5 样本（calm narration/energetic 等）跨平台盲听+客观指标双打分；本地 Coqui 2s vs 云 200ms——实时场景不选本地。
- 提升层：工具（选型矩阵）。

### 3. 语音克隆伦理合规三规则（工作流）
来源：aicourser / 00011000 / aifloxium
- **EU AI Act=合成媒体须显式同意标签；California SB-1047=商用克隆须同意；FTC 已执法 deepfake 欺诈**。
- 实操三规则：**仅明确书面同意才克隆 + 商用披露 AI 语音 + 不克隆公众人物**。
- 伦理框架参照 Resemble：consent verification+voice biometrics 认证+生成内容 watermarking；平台（ElevenLabs/Fish Audio）可封违规号。
- 提升层：工作流（合规门槛）。

### 4. ASR 转写精度工程（可复用 Skill）
来源：quillhub / loronote / assemblyai / noisereducerai / speechtext
- **音频质量是单一最大精度因子**（静音房 95-98% vs 噪声暴跌）；**先降噪再转写**（noisereduce 取前 1s 作噪声样本）。
- **多声道 vs diarization 是不同问题**：每说话人独立声道→multichannel 转写防串扰错归属；单轨混合→才用 diarization。
- 麦克风：lavalier>directional>omni；录音电平峰值 **-12 到 -6 dBFS**（低于 -20 弱噪、0 削波不可恢复）；**音乐比噪声更糟**（模型会尝试转录歌词）；约 10dB 信噪比阈值。
- 提升层：可复用 Skill（采集+预处理规范）。

### 5. 转写后处理与词汇表（工作流）
来源：vatis / transcribethis / quillhub
- **术语反复误转→加入可复用词汇表 + search-replace 双动作**（模型不认识该词，只改本次文件不够）。
- 校对按句义（重听短段）不按孤立音素；选对语言/方言变体（US/British 不是一种声学模式）。
- 提升层：工作流（后处理管线）。
