## 落地 5 独点（每点标注提升层）

### 1. 感知方式选型：accessibility tree 优先（可复用 Skill）
来源：ailearningguides / webfuse / jonjones / playwright
- **accessibility tree=浏览器语义结构**（role/name/value/state），经 CDP Accessibility 域或 Playwright accessibility snapshot 暴露——**同于视障用户所见，跨站无需 per-site selector，比截图感知快/省/稳**。
- Playwright MCP=结构化 snapshots 喂 LLM，**无需视觉模型**；截图+VLM 作 fallback（browser-use DOM 蒸馏：元素 index 定位 action 精度>95%）。
- 判据：能用 a11y tree 就别截图——截图慢、贵、有 DOM drift。
- 提升层：可复用 Skill（感知选型）。

### 2. observe-act-verify 操作循环（工作流）
来源：microsoft-playwright-workspaces / agent-browser / novita
- **官方模式=Create→Navigate→Observe→Act→Verify——不让 agent 跑长序列不查页面状态**；每步核对页面状态再继续。
- CLI 形态：snapshot 返回稳定元素 ref（@e1）→ fill/click/select → wait networkidle；**wait 原语显式用**（load/networkidle）而不是猜。
- 提升层：工作流（浏览器操作编排）。

### 3. DOM 失败六模式与恢复（可复用 Skill）
来源：surfs / theneuralbase / menuagentic / dailyaiworld
- **六种失败**：stale element（DOM 重渲染使旧 handle 失效）/occluded target/unexpected modal/navigation divergence/partial form failure/anti-bot challenge。
- **stale 恢复=从当前 snapshot 用指纹相似度重取元素，语义重解析优先于 handle 复用**；捕获具体异常（ElementNotFound/TimeoutError）而非 bare Exception——bare 会吞掉认证失败/网络崩溃；**retry 前先 screenshot() 记录页面实际内容**，把盲重试变有信息重试；vision 路径=失败后 re-screenshot+re-identify 再动作。
- 提升层：可复用 Skill（恢复回路）。

### 4. 选择器策略与 self-healing（可复用 Skill）
来源：atalupadhyay / qaskills-healer / surfs
- **优先级**：稳定属性 data-testid/id/name → text 内容 fallback（//button[text()='Submit']）→ CSS path with tolerance。
- **healer**：期望元素 vs accessibility tree 实际内容对比+role-based locator 修复脆 selector（#checkout-btn-2024 → getByRole('button', name: 'Checkout')）。
- **DOM drift 注意**：模型推理用的截图 400ms 旧——点击落空/点错，动作前重取。
- 提升层：可复用 Skill（定位规范）。

### 5. MCP 浏览器决策框架（工具）
来源：bswen / qaskills / skillmd
- **用 MCP 当**：需要登录态/OAuth consent/paywall 或厂商门户挡 headless/多步认证工作流/需复用 Chrome 扩展。
- **跳过 MCP 当**：简单 API 调用够用/只抓公开页/token 效率敏感长流程/无认证边界。
- Profile 三模式：persistent（刻意连续）→ isolated（干净测试/CI）→ extension（复用扩展）。
- 提升层：工具（选型矩阵）。
