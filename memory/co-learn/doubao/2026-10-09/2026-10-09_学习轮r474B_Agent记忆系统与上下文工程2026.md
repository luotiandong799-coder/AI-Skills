## 落地 5 独点（每点标注提升层）

### 1. 记忆三层架构与三存储组合（工作流）
来源：devtoollab / selina / programming-helper
- **三 tier=in-context/semantic/episodic**；Letta 三层=Core（每轮事实）+Recall（历史可搜索）+Archival（向量长期）。
- **生产级三存储=Redis（episodes）+向量库（事实）+知识图谱（关系推理）**；agent 自己决定层间换页。
- 提升层：工作流（记忆架构）。

### 2. 结构化记忆反模式：schema 优先于向量（工具）
来源：velsof / dev.to-tamizuddin
- **结构化内容（偏好/账户状态/last-known-good/当前目标/步骤）用 schema 存**——向量库存结构化记忆是反模式（检索不可精确）。
- **已知字段→精确存储（KV/schema），未知语义→向量**；agent memory 是数据工程不是提示工程。
- 提升层：工具（存储选型）。

### 3. 记忆写入评估路径二选一（工作流）
来源：AWS 博客 / OpenClaw Dreaming
- **路径一=写入时 LLM 评估**；**路径二=后台确定性加权公式打分**（Dreaming=不为每次写入付 LLM 成本，低于阈值留短期、高于晋升长期）。
- 高频写入/低延迟场景选路径二省 LLM 成本。
- 提升层：工作流（记忆写入策略）。

### 4. mem0/Letta/Zep 记忆框架选型（工具）
来源：aiworkflowlab / atlan / cognee
- **Mem0=轻量提取事实进向量库（65,589★）；Letta=显式 memory-block API；Zep=时序知识图谱（Graphiti）追踪事实变化**。
- **单用户跨会话→三选一轻量；多 agent 共享知识→Cognee 图谱**；记忆层三能力=持久化+跨会话连续+跨 agent 可移植。
- 提升层：工具（框架选型）。

### 5. prompt caching 2026 布局纪律（可复用 Skill）
来源：tokenoptimize / agentpatterns / datadog / openai
- **Anthropic 读 0.1x/写 1.25-2.0x、2026 自动缓存+显式断点（≤4 块：tools→system→messages）；OpenAI 自动缓存≥1024 token、30 分钟窗口 90% 折扣**。
- **布局=稳定置顶易变置底**；cachePoint 放最后一块不变内容上；单个 cache-busting 变更毁全部后续节省；用 TokenUsage 校验断点。
- 提升层：可复用 Skill（缓存布局纪律）。
