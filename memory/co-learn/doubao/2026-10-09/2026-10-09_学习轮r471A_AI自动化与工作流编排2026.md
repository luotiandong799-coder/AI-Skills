## 落地 5 独点（每点标注提升层）

### 1. HITL 三模式与审批分档（工作流）
来源：anhtu / aigentlab / openlegion / myengineeringpath
- **In-the-loop（每步审批，agent 暂停，不可逆高风险）/ On-the-loop（实时监控介入，可回滚快速流）/ Out-of-the-loop（事后审计，可逆高量低风险）**。
- **Tier 2 异步队列审批**（agent 排队继续干活，人异步批/拒——draft PR/日历邀请/知识库更新）；**pre-execution approval gate**=interrupt 编码在工作流结构里 agent 无法绕过。
- 提升层：工作流（审批选型）。

### 2. 生产级组合 pattern（工作流）
来源：n8n-agentic-design-patterns / n8n-production-playbook / openai-agents-js
- **客服工作流=知识库检索+schema 输出验证+低置信度升级人工+主 provider 不可用切 fallback 模型**——多 pattern 组合提可靠性不牺牲自动化。
- **agent-as-tool 层级多 agent**（orchestrator 有多个 tools，其中一个是子 agent）。
- 提升层：工作流（组合架构）。

### 3. Assume Failure 与 circuit breaker（工具）
来源：metacto / digenio / dev-fault-tolerant
- **Assume Failure 五条**=每操作超时限制/每个外部调用重试/AI 输出验证/工作流状态可恢复/每个失败路径显式处理。
- **circuit breaker 状态机**=失败超阈值 open（停发）→cooldown 后单探针→成功 close；挂几分钟到几小时的依赖持续重试=浪费资源拖延管线。
- 提升层：工具（可靠性组件）。

### 4. smart retry with provider switching（工具）
来源：mindstudio / valuestreamai / zalt
- **Try primary→if error→Try secondary→if error→Try fallback→log failure**（失败 N 次切提供商，先抽象模型层）；**指数退避=base 1-2s、2x per attempt、jitter 0-base_delay**（防同步重试风暴）。
- **无 retry/timeout budget=30s 硬超时无重试=任何慢响应杀任务**。
- 提升层：工具（重试链）。

### 5. 可观测四件套与重试模板化（可复用 Skill）
来源：zalt / suhasbhairav / dev-reliable-pipelines
- **可观测四件套=structured logs/latency percentiles/token counts/output-class distribution**（无观测=调试盲）。
- **显式 retry/fallback 指令进 CLAUDE.md/Cursor rules 模板**=分离决策逻辑与执行+bounded retries with backoff+安全 fallback 保数据完整性——标准化成模板=可重复/可审计/可测试。
- 提升层：可复用 Skill（模板纪律）。
