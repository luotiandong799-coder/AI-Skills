## 落地 5 独点（每点标注提升层）

### 1. CoT 与自一致性栈（可复用 Skill）
来源：ailearnings / aipromptshub / futureagi / acl
- **CoT=先中间步骤再结论**；自一致性=温度>0 采样 N 次取多数（最可靠不微调策略）。
- **选择规则=零样本→few-shot→CoT→自一致**；self-refine/self-verify 复核。
- 提升层：可复用 Skill（提示策略）。

### 2. 结构化输出四档保证（工具）
来源：promptbench / precisionai / kalvium
- **四档=prompt parse→JSON mode→grammar 约束→function calling**（保证递增）。
- **strict mode 100% 结构合规但 <0.3% 违规 +80-150ms**；静默 schema drift 最难。
- 提升层：工具（输出约束）。

### 3. Guardrails 五层与运行时拦截（工作流）
来源：zalt / freecodecamp / openlayer
- **五强制点=输入过滤/输出 schema/PII/权限/动作门控**（缺一=事故）。
- **实时拦截 groundedness<85%→整条拦截**（enforcement 非 log-later）；失败=回退/路由/人工。
- 提升层：工作流（运行时护栏）。

### 4. LLM-as-judge 生产化与六模式（工具）
来源：zylos / futureagi
- **>50% 生产 agent 团队运行时依赖 judge LLM**（质量门/幻觉防御/工具验证）。
- **六模式各有延迟/成本预算**；inline evaluator 接线回退/路由/人工。
- 提升层：工具（judge 部署）。

### 5. 幻觉类型与 groundedness 验证（工作流）
来源：dev-guardrails / web3aiblog / openlayer
- **四类=有害内容/幻觉 groundedness/结构 schema/提示泄露**。
- **两用途=泄露补漏+幻觉遏制**；detection vs enforcement 之别。
- 提升层：工作流（幻觉防御）。
