## 落地 5 独点（每点标注提升层）

### 1. Batch API 异步折扣（工具）
来源：respan / aiapiplaybook / cloudchipr / aws
- **OpenAI/Anthropic Batch=24h 内异步，输入输出约 50% 折扣**；Bedrock=JSONL 经 S3 异步。
- **夜间 evals/批量分类/embedding 回填/批量内容生成全走 batch**——同步跑批量=付零售价。
- 提升层：工具（账单杠杆）。

### 2. 缓存自动化 2026（工具）
来源：tokenoptimize / programstrategyhq / pristren
- **Anthropic 自动缓存多轮（单 cache_control 管 breakpoints）+显式断点**；GPT-5.5/5.4 90% 折扣对齐。
- **缓存读 0.1x（90% 折扣）；写贵 25%→breakeven 判断**；2026 最高 ROI 单一优化。
- 提升层：工具（缓存杠杆）。

### 3. 语义缓存与 KV 感知路由（工作流）
来源：redis / lecompute / arxiv-control-plane
- **语义缓存（向量命中既往答案）砍成本最高 73%**。
- **KV 感知路由=查哪个节点已有前缀 KV→直达，预填充短路 TTFT 骤降**；控制平面=全局 KV 索引+P/D 编排。
- 提升层：工作流（推理路由）。

### 4. 量化梯级与 CoT 蒸馏（工具）

- **梯级=FP16（基线）→FP8（H100+）→INT8（decode 绑定）→FP4（激进必 eval）**；KV cache FP8 内存减半。
- **CoT 蒸馏=学生学中间推理步骤**（KL 不够，ℒ=(1-λ)ℒCE+λℒCoT）。
- 提升层：工具（部署优化）。
