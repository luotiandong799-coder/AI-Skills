## 落地 5 独点（每点标注提升层）

### 1. 2026 工作流平台横向对比（工具/可复用 Skill）
来源：rockb-langflow-vs / n8n-report / 1337skills-visual / geekyexpert / bit-flows
- **四平台定位**：**n8n=业务流程自动化**（公平码许可证，自托管免费无限用；通用节点+AI 节点）；**Dify=LLM 应用生产平台**（MIT，Agent/Chatflow/Workflow/知识库/API 全家桶）；**Langflow=LangChain/RAG 管道**（Apache 2.0，RAG 管道控制最强：chunking/embedding/reranking）；**Activepieces=MIT 全免费无限制自托管**（数据主权）。
- **n8n 2026 新增**：内置 AI Agent builder（画布上直接设计带记忆/工具/护栏的 agent）、**HITL 门控工具**（agent 执行高影响工具前必须人工批准）、执行历史+Insights 仪表盘；2026 评分表参考：CrewAI 65/Dify 59/Gemini EAP 80/Gumloop 71（codability）。
- 提升层：工具（选型表）。

### 2. 多 agent 编排四模式+选型（可复用 Skill）
来源：aipromptshub / decodethefuture / aiworkflowlab / exploreagentic
- **四模式**：**supervisor**（单控制器路由任务给专业 worker）/ **swarm**（agent 平级互相交接）/ **hierarchical**（supervisor 嵌套 supervisor，大团队）/ **network**（全去中心，共享内存/消息总线通信）。
- **选型判据**：**orchestrator-worker 占约 70% 生产部署**（协调开销低，并行专业 worker）；选错模式是"多 agent 系统比该花的贵 3-5 倍"最常见原因。
- **关键设计规则**：**恰好一个 agent 被指定为 orchestrator**——两个 agent 都以为自己在协调=重复工作+矛盾指令+竞态；worker 之间不直接对话，协调走中心。
- 提升层：可复用 Skill（模式选型）。

### 3. 生产级 agent 护栏量化（工作流）
来源：dzone / resiliotech / jztan
- **循环护栏**：**max iterations 5-10 步封顶**（别让 agent 无限跑）；**token 预算**——单任务超成本阈值（如 $0.50）即杀；**HITL**——置信度跌或同一工具调用重复 3 次→升级人工。
- **重试必须分层且受限**：模型推理重试/工具调用重试/整体编排重试三层独立重试成本爆炸——**把可重试与不可重试失败分开**（瞬时错误可重试，4xx 是 bug 不重试）。
- 提升层：工作流（护栏配置）。

### 4. 重试与断路器纪律（可复用 Skill）
来源：bestaiweb / valuestreamai / bitontree
- **typed retry 契约**：哪些异常算瞬时=**typed 匹配非字符串匹配**；每次调用重试上限（非无限）；退避曲线=指数+抖动（100ms 起、封顶）；幂等——重试必须同结果；circuit breaker 三态=Closed/Open/Half-Open 带明确触发阈值。
- **错误分层**：500/502/503/504→指数退避+换 provider；网络超时→立即重试一次再退避；模型不可用→断路器+切 fallback 模型；4xx=fail fast 零重试。
- 提升层：可复用 Skill（重试契约模板）。

### 5. 错误处理五模式+ExEx 可解释异常（工作流/可复用 Skill）
来源：jztan / actionai / zylos
- **五模式递进**（各挡前一个挡不住的失败）：**circuit breakers** 检测质量失败（非仅 HTTP 错误）→ **validation gates** 坏动作执行前拦截 → **idempotent sagas** 部分失败干净回滚 → **budget guardrails** 循环跑偏时限制爆炸半径 → **human escalation** agent 该停止决策开始问人。
- **ExEx（Explainable Exceptions）**：低置信度输出**不丢弃**，打包模型推理+输入数据+置信度分数+建议替代方案送人工审查；**审查决定记作 ground truth**，模型随时间学习。
- 提升层：工作流（异常升级）/ 可复用 Skill（ExEx 模式）。
