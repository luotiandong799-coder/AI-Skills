## 落地 5 独点（每点标注提升层）

### 1. 章节滚动起草与上下文锚定（工作流）
来源：fieldguidetoai / datafield / cissychen
- **每章写时加载四件上下文**：master document context（全书定位+风格）+Chapter 1 作 voice reference+前章 summary+本章 outline——章节间一致性由此保持。
- **单 prompt ≤~1500 词/一章**；每节 prompt 含完整 outline+引言+已写节；前章结尾作锚点防重复与漂移；写完即读与前面比对，问题当场修（拼装后难修）。
- 提升层：工作流（长文起草）。

### 2. 长文四阶段结构与 coherence check（工作流）
来源：dynamicduniya / copywriter.pocketguide / ai-agent.camp
- **四阶段=thesis→outline→chapter drafts→continuity**，每阶段防下一阶段特定失败；长文是结构问题不是长度问题。
- **每 3-4 节一次 coherence check**：「read back…narrative build logically? tone consistent? contradictions/repetitions?」；初稿后 integration passes=交叉引用检查/主题贯穿核验/声音一致性审计/术语一致性。
- 提升层：工作流（结构+审计）。

### 3. CogWriter 认知写作规划-生成-评审框架（可复用 Skill）
来源：arxiv-cogwriter
- **规划 agent 分层规划分解任务→多个生成 agent 并行执行→持续监控评审机制对照约束评估输出并触发修订**（对齐认知写作理论 planning/translating/reviewing/monitoring）。
- **实测**：Qwen-2.5-14B 做骨干时 LongGenBench 复杂指令完成度超 GPT-4o 22%，可靠生成 >10000 词——小模型+框架>大模型裸写。
- 提升层：可复用 Skill（长文生成框架）。

### 4. 成本分层生成栈（工具）
来源：llmversus
- **三层模型分工**：outline 用强模型（Sonnet 4）一次调用/章节草稿用弱快模型（Haiku 4 或 Gemini Flash）并行生成+cached system prompt/终稿 polish 用强模型查 flow 与引用。
- **成本**：$0.15-0.45/5000 词（开 prompt caching）；弱模型并行便宜快，强模型只用在开头与收尾。
- 提升层：工具（成本工程）。

### 5. Voice+Evidence+Constraints 三件套与事实核查（工作流）
来源：whizi / sitebard / techandproductivity / buildaiq
- **写作前必给三件套**：Voice（语气样本+禁语清单）/Evidence（真实笔记与事实）/Constraints（长度/读者/要避免的 claim）；生成两版+critique pass+手改。
- **事实核查**：让模型 flag every claim（标注统计/日期/断言）→人工对原始源验证；分离 reviewer 确认引用/数据源；**编辑查 AI 三默认=hedging（含糊）/abstraction（抽象）/repetition（重复）**；五遍校读 sweeps=typos→grammar→表达一致性→可读性→结构诚实。
- 提升层：工作流（质量+核查）。
