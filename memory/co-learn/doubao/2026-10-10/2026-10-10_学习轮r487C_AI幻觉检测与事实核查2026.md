## 落地 5 独点（每点标注提升层）

### 1. 幻觉检测四桶分类与知识检索验证模式（可复用 Skill）
来源：ijarcce / web3aiblog
- **32+ 缓解方法四桶=engineering/RAG/self-refinement/decoding**：RAG 好但受检索质量拖累；self-refinement 不需外部数据但烧 token。
- **知识检索验证**：模型断言→查询外部知识库对比（Wikidata 通用事实/CrossRef 学术/PubMed 医学/法院 API 法律/内部政策库）。
- 提升层：可复用 Skill（检测分类）。

### 2. Self-Consistency 采样与 NLI 检测参数（工具）
来源：technologypulse / codesota
- **Self-Consistency=同 query 生成 3-7 样本非零温度，高一致=高置信、显著分歧=潜在幻觉**。
- **NLI 检测**：输出每个 claim 对源分类 ENTAILMENT/NEUTRAL/CONTRADICTION；$0.02/1K 检查、~200ms 延迟。
- 提升层：工具（检测技术）。

### 3. 生产幻觉指标集与 RAG 三层 guardrail（可复用 Skill）
来源：futureagi / markaicode / myengineeringpath
- **指标集**：faithfulness（中位数+p10）/context relevance/citation accuracy（源存在且支持）/用户反馈率/拒绝率（太低=过度自信，太高=过度限制）。
- **三层 guardrail**：validate retrieval quality→score answer faithfulness→route low-confidence 到 fallback；Groundedness 目标 >0.9（NLI 测）；SelfCheckGPT=reference-free 跨样本一致性。
- 提升层：可复用 Skill（生产指标）。

### 4. 个人事实核查五技术工作流（工作流）
来源：honelabs / zeroday / productive / aiviewer
- **五技术=source-forcing（强制给源）/claim decomposition/对抗性重提示/引用检查/junior test（找不懂的人审，不懂才会问）**。
- **claim 提取 prompt**：「把文本里每个事实 claim 编号列出，含统计/日期/名字/引用语录」→逐条查→找不到源=未验证。
- **四结果状态**=Confirmed/Partly confirmed/Contradicted/Unresolved；**四处置**=holds（保留+记源）/holds with caveat（加年份/收窄范围）/doesn't hold（按源修正）/not found（删或标）。
- 提升层：工作流（个人核查）。

### 5. 幻觉检测工具格局与 doublecheck skill 三层（工具）
来源：braintrust / futureagi / lobehub
- **工具格局**：Braintrust=LLM-as-judge+在线评分+回归 diff+CI 质量门；Galileo Luna-2=微调评估器 sub-200ms 内联拦截；Arize Phoenix=OSS 自托管；DeepEval=pytest 风格。
- **doublecheck skill 三层**=提取可验证 claim→web search 找支持/反驳源→对抗性审查标幻觉模式；Active 持久模式=响应内联验证摘要+自动分类规则；One-shot 按需跑。
- 提升层：工具（检测选型）。
