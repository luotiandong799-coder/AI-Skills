## 落地 5 独点（每点标注提升层）

### 1. 审批门设计：不可逆阈值与置信度门控（工作流）
来源：anhtu / openlegion / yureki / veto
- **不可逆动作需置信度≥0.85 才自动跑，低于转人审**；可逆动作阈值≥0.70；生产约 30 天后用 **ECE（期望校准误差）** 重校准阈值（agent 自称 0.8 置信度是否真的 80% 正确）——**自报置信度不可靠，必须校准**。
- **审批队列三层分级**：Red=不可逆阻塞等批（删数据/付款/发邮件）；Yellow=可逆但贵或吵（装依赖/迁移 dev DB/开 PR）→**自动批但汇入每日 digest**；Green=低风险可逆直接跑——**不打断**，按日批处理。
- 升级链：主审人不应答→升下级，直到最终超时；低风险可逆动作超时自动批但打 flag。
- 提升层：工作流（介入点设计）。

### 2. 运行预算四上限（硬停止条件）（工具）
来源：gdunhao / agentmelt / systemdesigner
- **max steps**（推理-动作迭代上限，多数任务 15-25 步）、**max tokens**（每 run token 预算防成本爆炸）、**max wall-clock**（超时终止）、**max tool calls per tool**（防反复调用同一失败工具）。
- **硬停止条件是安全网**：人审失效时（agent 能无限循环或无限花钱），预算让失控 agent **自停**而不是把小 bug 滚成大账单。
- 上限触发时优雅降级：返回部分结果或升级给人；执行循环显式命名状态迁移与终态（success/waiting/failure/abandonment 可区分）。
- 提升层：工具（自主性边界）。

### 3. 沙箱边界与审批配合（环境层先遏制）（工具）
来源：openai-codex-safely / anthropic-contain-claude / anthropic-alignment-security
- **沙箱定义技术执行边界**（可写位置/能否访问网络/哪些路径受保护）；**审批策略决定何时必须请求**（跨越沙箱边界时）——两者互补；用户可单次批准，或**会话内批准该类操作**。
- **Anthropic 遏制原则=先环境层设计遏制，再模型层引导行为**：egress 事件（员工钓鱼/第三方 allowlist 泄露）都是数据从**许可路径**流出，模型层抓不到异常（没有异常可抓），**确定性边界才拦得住**。
- 安全评测默认跑在无互联网硬化沙箱，唯一外连=模型自身 API，**API key 放环境外**、每次评测开始前验证配置。
- 提升层：工具（沙箱与审批架构）。

### 4. HITL 四组件与检查点恢复（工作流）
来源：anhtu / openai-agents-js / aaif / xbstack / omnithium
- **四组件**：①interrupt（动作前暂停、不丢上下文）②notification（按类型/风险路由给对的人）③context-rich review UI（意图+精确工具调用+参数）④resume（从检查点恢复，含嵌套 agent 工具执行）。
- **中断可跨长时间不占服务器**：state 序列化（toString/JSON stringify）重启后继续；MRTR（多轮往返）=服务器回"I need input"+不透明 continuation（HMAC 签名保护），人回答后**任意健康副本**可续跑——非阻塞。
- 审批动作三态：approve=读 checkpoint 状态穿过中断进下一节点；reject=清当前步、状态置 rejected 路由回**重新规划节点**换替代方案；edit=操作者直接改参数（收件人/邮件正文）。
- 提升层：工作流（中断-恢复协议）。

### 5. auto-review 与断路器降级（可复用 Skill）
来源：openai-codex-auto-review / tencent-agent-governance / mohammadshaker / dev
- **auto-review=独立 agent 替代沙箱边界人审**：Codex 内部实测比手动审批**少停约 200x**，仍拦住多数人想停的动作——**长自主任务无同步人审的可行通道**。
- **断路器模式**：连续 2 次 LLM 调用失败（网络/超时/格式异常）自动打开→**5 分钟降解模式**（不发新 LLM 调用）→半开允许一次测试调用→成功关闭/失败重启 5 分钟。
- 输出 guardrails 检查离开的东西（schema 有效/on-policy/无泄密）再达用户或下游；审批面板显示 Intent（agent 以为在做什么）+Action（精确工具调用与参数）。
- 提升层：可复用 Skill（自主循环治理套件）。
