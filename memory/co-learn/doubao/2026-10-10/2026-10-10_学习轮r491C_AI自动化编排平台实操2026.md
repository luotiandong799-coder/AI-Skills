## 落地 5 独点（每点标注提升层）

### 1. AI Agent 节点纪律与工具错误提示（工具）
来源：aiagentskit / n8n-official / n8n-community
- **AI Agent 节点（n8n 1.19.0 起）=模型+工具列表+循环直至完成**，区别于单次 LLM 节点；**Max Iterations=10 是防无限推理环的即时安全栏**。
- **工具错误三通道边界**：节点级重试（最大尝试+等待、内置退避处理瞬断）→循环 IF 节点做高级重试策略；**On Error Continue 只管 Agent 自身逻辑、不管连接工具内部崩溃**；Error Workflow 只在整体执行失败触发——工具返回错误码时靠 system 指令「**不要停止，分析错误并向用户解释技术问题**」。
- 提升层：工具（Agent 节点配置）。

### 2. 确定性步骤与 AI 步骤混合与失败默认值（工作流）
来源：n8n-production-ai-playbook
- **先确定性步骤后 AI 步骤**：能用规则完成的（解析/路由/清洗）不用模型；**AI 失败必须设合理默认值**——分类失败默认「needs human review」、生成失败回退模板；**绝不让失败 AI 步骤静默破坏后续工作流**。
- **每个 AI 步骤前加输入护栏、后加输出护栏**（成本极低）：护栏前拦垃圾输入、后验 AI 输出是否符合形状再放行。
- 提升层：工作流（生产 AI 步骤）。

### 3. Dify 编排节点模式与知识检索参数（工作流）
来源：dify-quick-start / deepwiki / dify-hosting / aitoolsatlas
- **标准编排链**：User Input→Parameter Extractor（识别目标平台）→IF/ELSE（验证提取结果）→List Operator（按类型分离文件）→Doc Extractor（抽文档文本）→LLM（整合参考材料）→Answer——每步一个职责。
- **知识检索节点参数权衡**：Rerank/TopK/Score Threshold 在精度-延迟-成本间调；**多知识库互补可加、内容重叠要避免**（造成重复结果）；LLM 节点用**结构化输出（JSON schema）**当下游要程序化解析响应时。
- 提升层：工作流（Dify 编排）。

### 4. 调试三层与限流治理（工具）
来源：n8n-debug / n8nlab / n8n-triage
- **每次执行全节点记录输入/输出数据**——AI Agent 行为调试从「看日志」变「看每节点数据流」，三层调试（Prompt 层/推理层/工具层）直接映射到画布节点。
- **限流治理**：循环/Item Lists 喂下游 API 同时多发会破速率上限（15 任务同时 POST Todoist 实测违规）——**插入 Wait 节点（1 秒）节流**；失败执行分类重试=AI 诊断+遥测+每事件重试计数（上限 3）→transient 且有预算才指数退避后调 API 重试，否则升级人工。
- 提升层：工具（调试与节流）。

### 5. 平台选型矩阵与自托管判据（可复用 Skill）
来源：activepieces / stepper / apimarket / brightseotools
- **三平台定位**：Activepieces=开源 MIT、自托管无执行限制、641+ 集成+MCP、Plus $25/月无限任务（Zapier 替代首选）；Pipedream=可视化+Node.js/Python/Go/Bash 代码步骤混编、2,400+ 应用、**GitHub 同步把工作流纳入版本控制**（开发者友好）；Make=真画布（分支/错误处理器/并行路径/迭代器聚合器更可读，曲线陡）。
- **选型判据**：高量自动化→自托管 n8n/Activepieces（云免费层会快速触限）；隐私/零锁定→Activepieces MIT；AI-first→AI 助手草拟流程（Agent 自己选工具+对涉钱/客户/生产步骤设审批闸门）；要版本控制→Pipedream GitHub 同步。
- 提升层：可复用 Skill（平台选型）。
