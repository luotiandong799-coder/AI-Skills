## 落地 5 独点（每点标注提升层）

### 1. 视觉 agent 两种架构模式（工作流）
来源：niteagent / mindstudio / marsys / bestin-it
- **Unified Multi-Modal Pipeline**：所有输入路由单多模态模型（GPT-5.4/Gemini 2.5 原生 text+image+audio 一通）——2026 最常见架构。
- **vision-as-dedicated-sub-agent（低 VRAM）**：小专用视觉模型（MiniCPM-V）处理截图/图像/PDF，输出纯文本交给主编排者——**不整包加载一个什么都干的巨大多模态模型**；工具返回多模态内容用 ToolResponse 对象（结构化、可解析）。
- **四阶段截图分析管道**：Playwright 无头 Chromium 截 PNG→预处理 resize 到 VLM 友好宽度（省 token）→本地 VLM 收图+问题（OpenAI 兼容端点）→后处理提答案。
- 提升层：工作流（视觉架构选型）。

### 2. 工具编排式视觉推理：Orion 与 ChartAgent（工作流）
来源：arxiv-2511.14210 / arxiv-2512.14040 / redeepseek
- **VLM 描述式输出不够**：Orion 编排专用 CV 工具套件（精确目标检测/关键点定位/全景分割/OCR/几何分析）执行多步视觉工作流——视觉推理=工具编排而非单模型生成。
- **ChartAgent=TIR 工具集成推理**：图表分析分解为可观察、可回放步骤+十余个模块化工具（key 检测/实例分割/OCR）动态编排；中间输出标准化为 **Evidence Package（证据包）**——结论可溯源可复现（黑箱悖论：关键数字缺失时性能暴跌）。
- **agentic extraction 趋势**：单模型调用→agent 规划读取序列（放大顶栏转录、放大数据格转录、交叉核对）——OmniParser/Computer Use 即此模式。
- 提升层：工作流（视觉工具编排）。

### 3. 文档理解管道替代 OCR 管线（工作流）
来源：mlhive / mixpeek / arxiv-2603.00122 / semanticscholar / nvidia-nemotron-parse
- **NuExtract-3（4B 甜点）**：高保真图转 Markdown（视觉表格/列表/复杂头→结构正确的 Markdown）+ **零样本 JSON schema 提取**（给图+schema 即填）+劣化文档处理。
- **两遍表格提取**：第一遍检测表区域提取为 HTML（保留 rowspan/colspan，比 Markdown 保结构）→第二遍验证 HTML 表结构（列数一致/无孤儿单元格），失败换 prompt 或模型重提。
- **图像分类器门（NovaLAD）**：每张图先过 ViT 分类器判有无价值，无关图存 skipped_images 不进 Vision LLM——省 token 省延迟；文档 agent 配方=视觉提取 prompt 只输出匹配 schema 的 JSON+validators+retries+system-of-record 工具（明确权限边界）——**视觉单独不够**。
- 提升层：工作流（文档视觉管道）。

### 4. 视觉输入预处理与 token 治理（工具）
来源：ai-tldr-ocr / niteagent / arxiv-2602.24134 / arxiv-2608.03270
- **DPI 选档**：印刷文档 150-300 DPI；手写/小字 300-400——太低字符糊、太高浪费 token+延迟；PDF 用 PyMuPDF 每页渲染 200 DPI。
- **AgenticOCR（query-driven 按需提取）**：静态全文本 OCR→先"思考式看图"分析布局→只识别感兴趣区域→**按需解压视觉 token**——检索粒度与页面级切块解耦。
- **GUI-Lens coarse-to-fine 裁剪**：对连续聚焦视图逐级放大直到目标确定；proposed crops/clicks 全程对照指令检查；最终局部坐标映射回原屏坐标——GUI 接地最高提升 24.9pp。
- 提升层：工具（视觉 token 预算与接地）。

### 5. 多模态 agent 评测与视觉验证（可复用 Skill）
来源：microsoft-asgardbench / arxiv-2602.10814 / arxiv-2603.26648 / codeguides / arxiv-2603.16289
- **评测发现**：部分模型文本+详细反馈可达图像基线水平，但最强视觉模型（Kimi-K2.5/GPT-4o）图像性能显著更高——**视觉接地提供纠错之外的信息**；GUI 静态感知强模型=GPT-5 90.5%（字段读取 98.4%），开源 Qwen3-VL-32B 77.5% 超 UI-TARS-1.5-7B。
- **验证器可替换**：Vision2Web 双 GUI verifier 骨干（GLM-4.6V vs GPT-5-Mini）功能分绝对差仅 0.31——**功能评测与验证器解耦**，换验证器不换评测。
- **多模态浏览检索（VisBrowse-Bench）**：任务设计为多模态融合必需（搜索中要图像理解）——agent 工具集=文本搜索/图搜/反向图搜/图像裁剪/网页浏览，鼓励主动收集+推理视觉内容。
- 提升层：可复用 Skill（多模态评测与验证器选型）。
