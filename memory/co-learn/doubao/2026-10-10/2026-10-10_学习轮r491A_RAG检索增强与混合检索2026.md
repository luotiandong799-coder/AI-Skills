## 落地 5 独点（每点标注提升层）

### 1. 混合检索三段式与 RRF 融合常数（工具）
来源：arpanet / markaicode / dev / ragaboutit
- **三段式=BM25 词法路 + 稠密向量路 → RRF 融合 → cross-encoder 重排**；BM25 管精确词/产品码/缩写，稠密管语义改写；双路合盖 **95% 相关块 vs 向量单独 70%**。
- **RRF（Reciprocal Rank Fusion）=无分数融合**，一行公式+常数 k=60（Cormack et al. SIGIR 2009），避开两路分数不可比问题；SPLADE v3 稀疏编码器可替 BM25 作稀疏腿——企业数据集上幻觉降幅 31%→43%。
- 提升层：工具（检索组件）。

### 2. 分块参数甜点与语义/结构感知分块（工具）
来源：promtable / startmatter / web3aiblog / aiexpert
- **200-500 token/块是 2026 生产甜点**：小于 300 失上下文，大于则稀释 embedding 信号；**相邻块 10-20% overlap 保边界连续**。
- **chunk size 是最高杠杆旋钮**；语义分块（主题转变处切）几乎总优于定长切分；**结构感知分块**（Markdown 标题/HTML 节/PDF 章）尊重文档天然边界；小块=高精度（检索块可直接喂生成器）、RAGSmith 精度-召回权衡。
- 提升层：工具（分块参数）。

### 3. 宽召回窄进重排序与阈值治理（工作流）
来源：rocco / microsoft / aliyun / arxiv-financial
- **先宽后窄**：首轮召回 top 20-30 → cross-encoder reranker（Cohere Rerank/本地 bge-reranker）逐对打分 → 只留 top 5——**reranker 是最大单点改进（约 +15% 质量）且省 30-40% LLM token**。
- **相似度阈值无通用最优**：太高丢相关块、太低进噪声，须在调试控制台迭代调；金融 RAG 自适应截断两法=累计概率阈值（保留至累计归一化分达 55%）/分数悬崖检测。
- 提升层：工作流（检索-生成衔接）。

### 4. 查询变换与上下文工程（工作流）
来源：gc-codelabs / younggao / ailearningguides / google
- **查询变换三技**：HyDE（假想文档嵌入，先让 LLM 写假答案再嵌入检索）/ Step-back Prompting（先问大问题再落细节）/ query rewriting+expansion——处理口语化/指代不清查询。
- **GraphRAG**：实体丰富语料（组织架构/产品关系）用知识图谱补向量检索，多跳问题精度显著提升；结构化引用要求（structured prompting with citation requirements）+高利害输出做 faithfulness 忠实性验证。
- 提升层：工作流（查询侧）。

### 5. RAG 评测三指标与诊断框架（可复用 Skill）
来源：premai / nips-ragchecker
- **检索侧三指标**：Context Precision（检索块中真相关占比——低=LLM 收噪声）/ Context Recall（检索集是否含答对所需全部信息——低=在残缺上下文上作答）/ MRR（首个相关文档排多高——评 reranker 质量）。
- **RAGCHECKER 细粒度诊断**：检索模块与生成模块分测（meta 评测证实其与人工判断相关性显著优于其他指标）；RAG 是模块化系统，评测必须分模块归因——检索差与生成差不能混为一谈。
- 提升层：可复用 Skill（评测口径）。
