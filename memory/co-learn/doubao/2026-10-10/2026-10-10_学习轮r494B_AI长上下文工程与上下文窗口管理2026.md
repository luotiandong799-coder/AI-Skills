## 落地 5 独点（每点标注提升层）

### 1. Context rot 与 U 形注意力失效（工作流）
来源：flowverify / zeroentropy / thepromptbench / arxiv-2606.29718
- **Context rot=输入上下文增长时 LLM 输出质量可测量退化，与窗口是否接近容量无关**——18 模型研究覆盖所有前沿模型；工程修法=**系统化上下文策展，不是更大的窗口**。
- **U 形注意力**：self-attention 对长上下文不均匀——中间窗口 token 注意力低于首尾几千 token；上下文越长 U 越深（lost-in-the-middle 文献名）；位置编码在短于使用的长度训练加剧。
- **premature termination（早停）**：长上下文下模型提前放弃或给不确定错误——控制 query 难度后仍与上下文长度正相关；名义窗口≠有效利用窗口。
- 提升层：工作流（上下文质量认知）。

### 2. 失效模式三分类（工作流）
来源：arxiv-2601.02023 / twnside / cosmo-edge / theneuralbase
- **Distributional Collapse（分布坍缩）**：无法综合分散在多处的证据（分散事实比单点事实更难）；**Safety Tax（安全税）**：反幻觉提示（"别编造"）过强麻痹了检索与推理——Don't Make It Up 提示形状影响检索；**Drift（漂移）**：长处理中从核心 query 逐渐偏离（分析 5000 条工单中途偏到情绪分析）。
- **NIAH 是标准基准但有限**：单点事实+无关干扰的检索测不出多跳/分散综合；扩展认知负荷下部分模型出现性能悬崖——发布前用实际长度+实际模型测实际任务。
- 提升层：工作流（失效模式诊断）。

### 3. 三层 tier 与层级上下文架构（工作流）
来源：swarmsignal / zylos / agentloop / agentic-ai
- **层级上下文架构**：Tier1=system prompt+当前任务+活动约束（**永不压缩、始终在场**）；Tier2=近期工具输出与对话轮次（滑窗管理）；Tier3=摘要历史与参考信息（按需检索）——镜像人类工作记忆。
- **会话记忆预算 1000-3000 token**：压缩摘要+关键决策+约束清单；会话恢复或压缩事件后注入；对话历史修剪三策略递增激进=滑窗（保留最近 N 轮，简单可预测丢早期）→关键信息摘要→分层淘汰。
- 提升层：工作流（三层架构模板）。

### 4. 结构化驱逐 CWL 与可寻址压缩 ARC（工具）
来源：arxiv-2606.11213 / arxiv-2607.25066 / arxiv-2609.00749
- **CWL（Context Window Lifecycle）**：轨迹按 typed、带依赖链的 episode 标注（工作过程中边跑边标）；token 超预算时**确定性、LLM-free 策略按优先级驱逐**——有效无限工作水平且驱逐可预测。
- **ARC（Addressable Recall Compaction）**：工具观察存 append-only、ID 可寻址日志；压缩时旧观察换紧凑**引用（citation）**——agent 按 ID 取回内容，不重跑工具、不依赖相似性检索。
- **ContextPipe 数据库式组装**：五阶段 Plan→Bind→Optimize→Execute→Feedback+结构化数据源目录+确定性 cache-aware optimizer+EXPLAIN ANALYZE trace——上下文可审计（像 SQL 查询计划一样能解释为什么放了这些内容）。
- 提升层：工具（确定性上下文治理）。

### 5. 上下文循环回收与放置策略（可复用 Skill）
来源：arxiv-2606.26105 / theneuralbase / aldeiadaponte / cnblogs / anthropic-managed-agents
- **窗口=可回收执行工作区**：固定预算资源、每轮显式装载-使用-释放（OS 工作集类比）；五层记忆层级=LoRA 零 token 领域专家层→磁盘存储（近无限）→确定性主动检索在每次推理前组装相关知识。
- **放置策略**：关键信息放**首 10%+尾 5%**；文档喂 LLM 前用 **BM25+embedding 双路排序**（不只 embedding 相似度）；>20K token 文档用 **query-focused summarization 而非切块**；context distillation=100 页文档只抽相关部分（Vectara 实测 54%→89%）；重复查询吃 context caching；压缩保留架构决策/未解 bug/关键实现细节，丢弃已替代探索轮/已解决报错/无影响中间推理。
- 提升层：可复用 Skill（上下文装配与回收）。
