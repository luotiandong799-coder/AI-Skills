## 落地 5 独点（每点标注提升层）

### 1. Plan-first 四阶段工作流与计划先行（工作流）
来源：zencoder / dev-ai-coding-mastery / victorsaisse / puglieseweb
- **四阶段**：Explore（让 AI 摸代码库、找相关模式/库/配置，浮现认证等约束）→Plan（计划逐条确认）→Implement→Verify（端到端验证）——可重复流程把探索与实现分开、沿途验证。
- **plan before execute 是 10x 杠杆**：让 AI 先解释方法再写码，成功率数量级提升；**改/加导出函数/类/组件=接口变更，先与用户确认再写码**（接口是代码库接缝，需要品味）；需求的 AI 反问式细化（AI 主动追问填细节生成完整需求文档）再逐条过。
- 提升层：工作流（编码流程骨架）。

### 2. 测试先行 AI 工作流与 TDD 三阶段 prompt 形状（工作流）
来源：reinventing / sureprompts-tdd / dev-5-tricks / ailearningguides
- **Test-first**：让 AI 先为计划功能写全测试→人工审阅补边界（加漏掉的 edge case、收紧断言）→再让 AI 实现到测试通过→跑套件把失败喂回调试——测试当 AI 的「刹车系统」（AI 擅长给量化目标迭代收敛）。
- **TDD 三阶段各需不同 prompt 形状**：Red=命名行为、拒绝实现；Green=**bound diff、标记测试文件不可改**；Refactor=命名质量目标、拒绝 scope creep；**最坏失败=agent 改测试让测试过**——Green prompt 显式禁止+读 diff 验证；高 stakes 代码（auth/钱/PII）强制 TDD。
- 提升层：工作流（测试驱动 AI）。

### 3. 小步原子提交与 diff 预算（工作流）
来源：baeseokjae-12-patterns / rkyash / sureprompts / whizi
- **一次会话=单函数/单 bug/单特性**（直接缩小 AI 错误爆炸半径）；**强制小原子提交**：接口一个 commit、实现一个、测试一个——AI 破坏时 git bisect 与 revert 成本最低；不要让 AI 一次改 15 个文件。
- **显式停止信号**：测试通过/文件数/diff 大小预算（agent 会一直「改进」到改了半个仓库——不给停止信号就这样）；**diff 大到读不完=拒收+收紧范围**；每个改动文件必须在 scope，范围外改动要书面理由。
- 提升层：工作流（变更粒度治理）。

### 4. AI 代码评审 lens 与机械门禁（工具）
来源：augmentcode / aisrc / geekchamp / dev-anthropic-guardrails / anthropic-scaling
- **review prompt 给 lens 不给「看看代码」**：聚焦 security/performance/error handling/API compatibility，输出 severity+file:line+问题+怎么修。
- **机械门禁优先**：高 AI 采纳团队 PR 评审中位时间涨 5 倍、每 PR 事故翻三倍、telemetry 显示评审人在 skim——**人工评审超过 400 行失效**；修法=编译器/类型门、diff-scoped SAST、依赖存在性检查、变异测试套件、merge 后 canary 持续跑。
- **独立实例分层评审**：一个 Claude 实例评逻辑/维护性/团队标准，另一遍专评安全（注入/认证绕过/数据泄漏）；/security-review 命令审计 GitHub Actions 工作流（对照 CLAUDE.md 策略）。
- 提升层：工具（评审自动化）。

### 5. 重构纪律与安全重构（工作流）
来源：cadence / aitoolsguidebook / tencent / claude-datadog
- **重构 prompt 四要素**：①命名变更单元 ②声明保持的不变量 ③bound scope（防「while I'm here…」顺手改漂移）④先出计划/diff 再提交。
- **纪律**：纯文本先写 3 行 before/after+必须仍过的测试；**每次文件编辑后强制跑测试**；审架构意图不审语法；小重构日并胜过大爆炸 PR；**架构级重构 2026 仍不可靠**——AI 可提架构、你决定，再逐块 plan-then-execute 应用；Claude Code Plan Mode（Shift+Tab 两下）先出计划再动手。
- 提升层：工作流（重构安全）。
