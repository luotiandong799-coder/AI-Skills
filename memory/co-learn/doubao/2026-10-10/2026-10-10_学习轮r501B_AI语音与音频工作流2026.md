## 落地 5 独点（每点标注提升层）

### 1. 级联管线 STT+LLM+TTS（可复用 Skill）
来源：checkthat / dev-jays / futureagi
- **cascaded pipeline 三段式**：STT 音频→文本→LLM 生成→TTS 音频回；**每阶段产出可检查文本工件**——"text tokens 是确定性中间层"，出问题可定位到阶段；优化流式可达 600-900ms 端到端。
- **延迟基准**：Cartesia Sonic Turbo 40ms 首音频（voice agent <400ms 回合延迟的结构选择）；全双工音频原生 SLM 是另一路线（音频直达、省 STT/TTS 但难检查）——级联=可检查可控制，全双工=快。
- 提升层：可复用 Skill（音频 agent 架构）。

### 2. 语音克隆与 TTS 选型矩阵（工具）
来源：futureagi / modelcitizen / pexo / worldmetrics / research
- **零样本克隆**=6-10 秒参考音频即可（XTTS-v2 17 语言/F5-TTS 扩散式/Orpheus 情感表达/Fish Audio S1 10 秒 48+ 情感标签）；ElevenLabs v3=质量+克隆保真 32+ 语言；**ElevenFlash 快但牺牲表达**——按延迟/质量/情感需求分层选。
- **一致性工作流**：ElevenLabs 神经克隆复用训练好的音色画像跨脚本保持角色一致；Murf 用角色预设保持短片段叙述一致——**重复性角色资产用"训练-复用"，散片段用"预设"**。
- 提升层：工具（选型）。

### 3. 播客五段管线与转录编辑（工作流）
来源：apatero / aiworkflows / ohsoneedy / theplanettools / myweirdprompts
- **五段管线=research→scripting→TTS→production→distribution**——当黑盒整体处理效果差；**脚本质量是唯一最重要因素**：显式 prompt 要求打断/犹豫/分歧/自然口语模式；多音色开源=Kokoro/Coqui XTTS v2；逐行分配音色让 Studio 自动 threading。
- **转录编辑**（Descript 类）=编辑转录文本即编辑音频（剪/重排/修 filler/归一化/降噪/混音）；音频组装=统一 44.1kHz mono 16-bit PCM + EBU R128 -16 LUFS 响度归一 + -1.5dB true peak。
- 提升层：工作流（播客制作）。

### 4. ASR 质量与 LLM 后处理（工作流）
来源：sipsip / promptz2h / assemblyai / arxiv-french
- **准确率天花板**：干净内容 AI≈人类；困难音频（噪声/口音/高技术）人类领先 **8-15 个百分点**——难音频仍要人。
- **LLM 后处理提可读性/准确 5-15%**（补标点/同音词/术语/去冗余），域专属内容最有效——自定义词表（keyterms）修"陌生领域词"；**格式化准确度跟着识别准确度走**（听错的词没法标对），错误聚集三处=噪声/重叠说话/陌生词表（词表可自查修）。
- **多通迭代**=Speaker Recognition ↔ Word Recognition 交替（Qwen3-Next-80B 临床转写验证显著提升说话人归属）。
- 提升层：工作流（转录后处理）。

### 5. 高级说话人分离与音频组装（可复用 Skill）
来源：msitarzewski / aclanthology-sommelier / lobehub-audio-transcribe
- **多模型融合**=pyannote 说话人段 + VAD 过滤的 Whisper 输出对齐（比单一 diarization 模型准）；**跨录音说话人身份**=embedding 持久化识别跨会话回访者；**重叠语音检测**=标记并隔离（此处转录质量退化，下游消费者必须知道）。
- **语言切换检测**+hotword biasing（中文预设可热词偏置）；音频组装统一格式+响度归一（见独点 3 参数）。
- 提升层：可复用 Skill（说话人分离）。
