## 落地 5 独点（每点标注提升层）

### 1. 推理提示技术方法与收益权衡（模型）
来源：aipromptshub / thematrix / exemplar / infoq / ai-cc
- **技术阶梯**：CoT（展示推理过程）→ self-consistency（非零温度多次采样+多数投票——**正确推理路径趋向收敛、错误路径发散**）→ ToT（生成 3-5 条路径→评估 pros/cons/可行性（1-10 分）→展开 top 2 各 2-3 子分支→弱分支剪枝——用于解路径不显然的问题）。
- **self-consistency 成本曲线**：成本 N 倍但**准确率收益对数增长**——5 样本捕获大部分收益，再往上烧钱；留给高价值答案（关键计算/一次性分析），不做高频请求；**先在自己测试集上量"多数投票 vs 单次调用"的准确率差再决定**。
- role-based prompting（设专家角色）改善语气与深度，但**别把框架术语当魔法——改变的是怎么 framing，不是模型能力**。
- 提升层：模型（推理方法选型）。

### 2. 提示自动优化：prompt 当程序参数编译（工具）
来源：dspy / futureagi / arxiv-2608.02919 / aws / effloow
- **DSPy 核心思想**：prompt 不是手写字符串，是**程序参数**，用 optimizer 编译最大化可测指标——不用预知某模型吃哪种 prompt 技巧，optimizer 去找。
- **2026 四个关键 optimizer**：BootstrapFewShot（从数据 bootstrap 示范）/MIPROv2（联合优化指令+few-shot，贝叶斯优化找最优组合）/COPRO（指令级）/GEPA（维持 prompt 种群→trainset 跑→读 per-predictor feedback→reflection_lm 提编辑→**Pareto 前沿返回最佳**——有强 reflection LM+feedback 形 metric 时 prompt-only 优化最优）。
- **优化后的小模型程序可匹配手调大模型**——省成本；BetterTogether=prompt 优化+权重优化（微调）序列组合（prompt→weight→prompt）；换模型时手调 prompt 会碎，DSPy 重新编译即可。
- 提升层：工具（自动优化框架）。

### 3. pin 完整调用信封与语义版本化（工具）
来源：lobehub / loooop / ailearningguides / futureagi
- **"v3 prompt"只有 pin 完整调用信封才有意义**=Model ID（精确带日期）/temperature/top_p/top_k/max tokens/stop sequences/系统用户消息角色与顺序/结构化输出 schema（**content-addressed hash**）/工具注册（名+schema）/推理 effort——**任何一个变更都是新版本**。
- **语义版本化**：major=破坏性/minor=增补/patch=微调；changelog 写行为意图；**canary+回滚**：新 prompt 滚小流量→监控 accuracy/format/error-rate→promote 或 rollback；运行时 feature flag 支持 per-环境。
- 版本化策略（整数/语义/日期）选一个一致应用；回滚纪律=坏了能精确回到上一个已知好版本。
- 提升层：工具（版本治理）。

### 4. prompt 度量与门禁（工作流）
来源：dataaihub / futureagi / truefoundry
- **candidate 跑数据集评分**：平均分/最差样本/失败聚类——从轶事到评估器。
- **每个 prompt 改动用 eval 门禁**：小措辞改动过明显 case 却破边界 case；分环境 diff/回滚/pin。
- **五步流水线**：跑 golden set（准确率+格式合规）→找失败聚类→修订→版本注册（**永不硬编码**）→CI 每次 prompt 变更跑 eval 集、回归阻止提升→生产记录 prompt 版本/输入/输出/验证结果，采样 1-5% 人审，验证失败尖峰告警。
- 提升层：工作流（变更门禁）。

### 5. split prompt design from enforcement + 规划原语（工作流）
来源：truefoundry / getmaxim / promptot
- **guardrail 属于网关不属于 prompt**：prompt 里写限制可被模型忽略——安全/合规校验放网关层强制（与已落工具面安全互补：那条管工具调用，本条管 prompt 内容边界）。
- **复杂任务 prompt 内规划原语**：先要短计划再执行/每步 checkpoint 输出/**低置信步骤定义回溯策略**；structured prompt architecture=prompt 当模块化版本化资产而非散落硬编码指令（集中管理/模块化设计/错误率降约 60% 量级，管理 50 个 prompt 年省约 $400k——量级参考非断言）。
- 提升层：工作流（架构与边界）。
