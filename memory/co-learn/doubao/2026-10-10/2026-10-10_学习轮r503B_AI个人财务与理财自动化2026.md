## 落地 5 独点（每点标注提升层）

### 1. 记账工具与 AI 的分工边界（可复用 Skill）
来源：happycapy / fintechnosphere / softpicker
- **记账应用管"管道"、AI 管"分析与教练"**：银行同步/分类/重复账单检测是 LLM 做不可靠的活（应用干）；AI 擅长=写清晰分类规则/月末支出转大白话总结/个性化债务偿还计划/账单谈判脚本/周报——**"AI 是坐在数据之上的分析师与教练，不是替代应用的管道"**。
- **能用 CSV 就不用实时银行连接**：上传 6 个月银行流水让 AI 做支出分析、找趋势、建预算拆分，效果接近 Copilot Money 而无连接风险。
- 提升层：可复用 Skill（分工架构）。

### 2. 接入安全基线：只读 + 人工审批（可复用 Skill）
来源：agent-finder / uniclaw / valapoint
- **接入财务前四件事**：每个关联账户先开 2FA；**只用只读权限**，任何写动作（转账/支付）须人工审批；**永不在第三方表单填完整银行凭据**（走应用安全 API 连接）；连接后审查初始分类，花 20 分钟纠错（业务误标个人/收入误标转账）——每次纠正都在训练模型。
- **数据主权变体**：AI agent 只扫邮件提取账单/收据/订阅通知→写入你自己控制的 CSV/表格→数据留在本机文件，不用给银行密码。
- 提升层：可复用 Skill（安全基线）。

### 3. 多因子异常检测（工作流）
来源：xbstack / valapoint / overchat
- **不只盯交易大小**：多因子模型=深夜交易/全新支付国家/**当日该类累计支出超历史均值 3 个标准差**——任一命中即 `is_anomaly=true` 触发用户确认，防卡盗刷。
- **订阅检测**：追踪 recurring charges，续订/涨价前提醒；银行流水分析=分类收入/支出/转账/重复订阅，浮出消费模式与现金流异常并 flag 可疑活动。
- 提升层：工作流（异常检测）。

### 4. 分类训练闭环（可复用 Skill）
来源：agent-finder / valapoint / softpicker
- **闭环三步**：AI 猜初始分类→人纠错（误分类是训练样本）→按近 3 个月实际支出设各分类预算上限；接近上限时 flag 并给调整建议。
- **两阶段管线**：解析原始交易字符串→归一化商户名→LLM/ML 分类器打标（Plaid UXC v2 两阶段比早期方法子分类准确率 +23%）；**分类规则写成可复用规则集**（YNAB 类应用把规则持久化）。
- 提升层：可复用 Skill（分类系统）。

### 5. 税优化全年运行（工作流）
来源：agent-finder / pickaxe / softpicker
- **报税不 4 月冲刺**：每笔交易实时分类为个人/可抵扣/业务（自雇/副业者免 April scramble 找收据；准确率 85-90%）；**year-round 跟踪**成本基/识别税损收割机会/生成整理好的报税记录。
- **场景建模**：Roth 转换优化/社保领取策略/税务预测与规划（专业顾问工具类）；通用助手=上传流水 CSV 让 Code Interpreter 算税场景、解释复杂概念。
- 提升层：工作流（税务自动化）。
