## 落地 5 独点（每点标注提升层）

### 1. 确定性引擎 + AI 原语混合架构（可复用 Skill）
来源：techiehub / aicostcheck / arxiv-building-browser-agents / toutiao
- **最强生产模式是混合**：纯 AI 端到端太慢太贵、纯确定性太脆——**AI 原语叠在确定性引擎（Playwright）上**：确定性跑可预测步骤，LLM 推理只在页面不可预测处介入；**DOM 驱动为主路径、视觉为回退**；关键动作留人工检查点。
- **Web Agent 与 Coding Agent+视觉模型组合读网页操作**（不用截图点坐标的通用方案），速度更快成本更低；一句指令可拆多个分身在不同网站并行执行。
- 提升层：可复用 Skill（混合执行架构）。

### 2. 观测表示按模型能力选型（模型/工作流）
来源：arxiv-read-more-think-more
- **观测表示选择依赖模型能力与 thinking token 预算**：紧凑观测（accessibility tree）适合低能力模型；详细观测（HTML）适合高能力模型；**增加 thinking tokens 进一步放大 HTML 收益**。
- **误差分析**：高能力模型利用 HTML 布局信息做更好 action grounding；低能力模型被额外噪声干扰——**选观测表示先看模型档位**，不是一律压缩。
- 提升层：模型（选型）/ 工作流（观测设计）。

### 3. 双通道 SoM grounding + 浏览器运行时契约（可复用 Skill）
来源：taivu-web-browser-agent / dev-browser-use / aicostcheck
- **双通道 Set-of-Mark**：注入 JS 同时**渲染编号红色标签作视觉叠加**（VLM 在截屏中看）+**设置 data-agent-id DOM 属性**（Playwright 程序化定位）——消除"VLM 说点标签 5 但 DOM 定位不到"的 grounding 歧义。
- **运行时必须暴露**：截图/DOM 快照/accessibility tree/网络日志/控制台日志/文件下载处理/cookie 会话库/重放视频或 trace——**模型不应只依赖截图**：DOM 与 accessibility 更便宜更稳更可审计。
- 提升层：可复用 Skill（grounding 协议）。

### 4. 网页 agent 上下文与 token 治理（工作流）
来源：arxiv-building-browser-agents / arxiv-read-more-think-more
- **MCP 类实现保留全部对话历史含每步页面快照→token 随动作线性增长**（accessibility tree 快照 10K token/步）——浏览器 agent 必须**压缩快照/管理状态、丢弃掩盖目标的噪声**，否则长任务必然爆窗。
- **观测降维经验**：DOM tree distillation（100k+ 星 browser-use 做法）=把完整 DOM 蒸馏成精简可交互元素清单再喂模型，显著降 token 并保持 grounding。
- 提升层：工作流（上下文预算）。

### 5. 生产六失败模式 + 人工兜底（可复用 Skill）
来源：futureagi / anhtu / aiwiki / arxiv-webvoyager / browseract / clawhub
- **WebArena/Mind2Web 分数不迁移到生产**：快照基准=冻结 DOM 的 happy-path 完成率——测不出 DOM 移动/模态打断/会话新鲜/端点变化/限流/验证码；**WebVoyager 跑真实网站**（500 任务 15 站，GPT-4V judge 对比最终截图），自己跑一遍会暴露验证码/地理限制/限流。
- **兜底链**：登录/验证码页面**暂停等人工处理，从停下的地方继续而非失败**；CAPTCHA 求解服务（2Captcha/CapSolver）作后备层；**复用真实浏览器**（日常 Chrome 指纹+会话 cookie）使 agent 与用户无差别，规避 Cloudflare；防检测=指纹/代理/随机间隔/人类仿真 timing/navigator masking，分层组合。
- 提升层：可复用 Skill（生产健壮性）。
