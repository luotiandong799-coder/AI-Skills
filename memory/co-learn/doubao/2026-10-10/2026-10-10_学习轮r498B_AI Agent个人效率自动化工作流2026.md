## 落地 5 独点（每点标注提升层）

### 1. 个人效率自动化四件套模式（工作流）
来源：blink / moderncreator / devmanushraky / spicyautocorrect / ai-agent-camp
- **邮件四桶分拣**：每封未读邮件归四桶——URGENT（当天回，一句话摘要）/ ACTION（需我决策或行动）/ FYI（仅信息）/ ARCHIVE（newsletter/回执/通知）；**只显示 URGENT+ACTION 加摘要，其余归档**——40 封变 5-8 封。
- **会议后流水线**：记笔记→总结决策与行动项→起草跟进邮件→建任务清单（含负责人+截止）——2-3 周打磨成半自动 routine。
- **LifeOS 四 pod**（Today/Money/Admin/Social）各接数据源（Gmail/Calendar/银行 API）——早 7 点前 dashboard 已知保险到期、已起草邮件回复，人批准或跳过。
- 判据：**"足够的本地权限 + 足够的审批门——不 embarrass in public"**；先手动跑通再固化。
- 提升层：工作流（个人自动化模式）。

### 2. 审批在后果边界，绑定 sealed payload（工作流）
来源：accessallgpt / aiflowreview / toutiao-郑森文 / theneuralbase
- **approval at consequence boundary**：审批点按**行动后果**定，不按工具类型定——同工具不同后果不同门槛。
- **approval 绑定一个精确 sealed tool payload**：canonical hash+reviewer 身份+policy 版本+过期时间+**单用途幂等键**——防重放/防陈旧/防未授权；maker-checker 分离+更强认证。
- **授权分级**：低风险任务级授权；支付/发布/删除等高风险二次确认；操作可见可追溯、可暂停/接管/撤回；个人信息最小必要；授权与执行全流程留痕。
- 提升层：工作流（审批实施细节）。

### 3. interrupt 是控制流信号，不是阻塞调用（工具）
来源：sitepoint / dreaming-press / anhtu
- **LangGraph interrupt()**=control-flow signal 不是 blocking function call——配 checkpointer 持久状态；resume 用 Command(resume=value) 同 thread_id 从**同一状态**继续；OpenAI Agents SDK 用 needs_approval 标志。
- **审批门=中断-恢复检查点**：工具调用执行前拦截→surface 给人类（proposal+reasoning+confidence，不只是二元决定）→批准/拒绝/编辑后同状态恢复。
- 用 interrupt+durable execution 等审批，**不烧资源轮询**；防 alert fatigue 与 automation bias——HITL 先坏在人的那一侧。
- 提升层：工具（HITL 实施）。

### 4. agentic 调度防重入：Skip/Queue/Replace + miss thresholds（工作流）
来源：zylos / aiagentskit / dualite
- **上一轮还在跑时**：Skip（跳过本次——简单但可能错过关键 run）/ Queue（排队——安全但任务持续超时队列无限增长）/ Replace（取消旧开新——监控类只要最新结果）。
- **第四策略=miss thresholds**：每任务可配错过阈值，连续错过 N 次触发处理——兼顾 Skip 的简单与不丢关键 run。
- 个人 cron 自动化必须显式选重入策略，否则重入叠加状态（发两遍邮件/重复扣费类副作用翻倍）。
- 提升层：工作流（调度防重入）。

### 5. 个人自动化工程反模式与可靠架构蓝本（可复用 Skill）
来源：aliyun / shivam / sapirex / wickedsmartdata / taskade / arxiv-polaris
- **三件套防反模式**：run_state.json 断点续跑（崩溃可恢复）/ dedupe_index.json 幂等键去重 / **handoff.md 结构化传参——禁止子任务靠聊天上下文传信息**（个人长自动化必踩）。
- **可靠 agent 蓝本**：显式状态机+窄角色+独立验证+受控权限+持久执行记录+测试过的恢复路径——**"更长 prompt 修不了控制问题，换架构别换模型"**；可靠 agent 把开放推理变成有界工作流，围绕模型搭的系统才是持久优势。
- **stateful orchestration + safety supervisor**：编排层评估工具输出有效性/限流/异常处理/歧义路由人工——在运行时把失败圈在传播到下游之前。
- 提升层：可复用 Skill（个人自动化工程规范）。
