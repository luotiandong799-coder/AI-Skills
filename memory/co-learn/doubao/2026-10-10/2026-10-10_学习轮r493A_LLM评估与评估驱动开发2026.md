## 落地 5 独点（每点标注提升层）

### 1. Golden set 四桶结构与真实失败优先（工作流）
来源：futureagi-golden-set-design / dev-golden-sets / confident-ai / techearl
- **CI 级 golden set 四桶**：主要用例按流量比例（常见 60%）+对抗覆盖（jailbreak 语料/注入变体/15%）+领域专家手写边界（合规域/歧义/稀有类/15%）+生产失败回放（Error Feed 簇与历史事故/10%）——每桶独立版本化。
- **真实失败优先**：不写合成当真有——每个修掉的生产 bug 变成 golden set 一行（awkward 真例=空消息/阿拉伯语消息/只有标点的消息最抓回归）；50 个真实用例胜过 500 个合成例；golden set 小到每次变更都能跑（5 个起）。
- 提升层：工作流（评估资产构建）。

### 2. LLM-as-judge 五命名偏置与测量（可复用 Skill）
来源：futureagi-judge-bias / hub-cissychen / ai-tldr / aiworkflowlab
- **五命名偏置**：①position（成对比较 A/B 顺序改变赢家——GPT-4 为 judge 位置交换一致性仅 ~65%）②verbosity（更长答案赢更多，~15% 通胀）③self-preference/family（judge 偏爱自家模型家族输出，GPT-4 评 GPT-4 vs Claude 偏 GPT-4）④format（prose/列表/表格形状影响分）⑤calibration drift（judge 模型换了、rubric 没换，信号语义就变了）。
- **对应测量**：position→swap-and-aggregate 双序聚合（两序一致才记胜，分歧记平；校准集必做、生产按成本选择）；verbosity→rubric 显式「两者都对时偏好简洁」+词数比>1.5x 后验打折；family→避免同家族互评；format→rubric 显式格式中性+校准集跨格式采样；drift→**钉 judge 版本**+定期对人工校准（Spearman ρ≥0.7，如 1,500 例×3 judge 夜间跑约 $25）。
- 提升层：可复用 Skill（judge 偏置清单）。

### 3. Pointwise vs pairwise 选型与 CoT/rubric 技术（工作流）
来源：arxiv-autorubric / dev-choosing-judge / arxiv-position-bias
- **选型**：主观质量（helpfulness 等）用 **pairwise**——相对比较比绝对打分更易与人对齐；客观准则（事实/格式/安全）用 **pointwise** 单输出打分。
- **提准技术**：CoT 评审 +2-5% 准确率（+30% token）；rubric prompting 适合结构化任务（+20% token）；Position Swap 消位置偏置（同 token 两遍）；**rubric 给逐行分档评分表（line-by-line score rubrics）+参考答案**——pointwise 用 1-5 分档时 rubric 逐行定义分档边界。
- 提升层：工作流（judge 提示技术）。

### 4. 回归门禁三层（工作流）
来源：futureagi-eval-confidence / rits-it / metacto / dailyaiworld
- **三层结构**：①CI regression——每个 PR 跑 golden 集、几十秒/case，拦坏变更进 merge；②Deploy gate——每次候选部署跑全量 golden 集、对比 last-known-good 快照，**>N% 先前通过用例现失败即自动拦部署**；③离线 benchmark——每周/模型换/检索器变时跑 held-out 集 headline 指标。
- **基线比较优于绝对阈值**：候选显著差于生产基线才 fail，不钉死一个绝对分（0.8 是刻在春天里的假精确）；evals 语义评测可识别高达 85% 的问题。
- 提升层：工作流（CI/CD 评估门禁）。

### 5. 生产闭环与基线清单（工作流）
来源：dailyaiworld / divinci / futureagi
- **trace-to-dataset 循环**：生产 evals 是持续闭环不是一次性离线——**只精选困难低分/异常片段入集，不导全量 firehose**；生产失败分类回放回 golden set。
- **基线 manifest**：精确模型权重+prompt 模板+检索索引+judge 版本钉死——否则分数移动分不清「模型变了还是尺子变了」；候选模型对最近 14 天生产 trace 回放，切片分数偏离离线分数超阈值即拦发布（catch golden set 尚未覆盖的漂移）。
- 提升层：工作流（生产评估闭环）。
