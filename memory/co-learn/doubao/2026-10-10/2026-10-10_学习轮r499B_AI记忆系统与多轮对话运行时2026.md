## 落地 5 独点（每点标注提升层）

### 1. 记忆写入时机：递归整合，不是每轮都写（工作流）
来源：aclanthology-recmem / aliyun / arxiv-2601.06037-telemem / besthub
- **RecMem**：原子交互单元先写 subconscious store（轻量结构化+向量化，原始历史可直接嵌入检索）；**LLM 级整合只在"复发"时触发**（同主题/同人/同工具反复出现才整合）——不是所有交互都值得 LLM 整合。
- **五阶段流水线**=抽取→整合→存储→检索→遗忘；TeleMem 结构化写入=批量/检索/聚类/整合——提存储效率、降 token、加速记忆操作；每次 LLM 调用都是无状态的——记忆系统补的正是这个洞。
- 提升层：工作流（写入时机）。

### 2. 冲突解决四策略与生产组合方案（工作流）
来源：zylos-consolidation / tencent / arxiv-2607.16211-mosaic
- **新记忆与旧记忆矛盾时四策略**：recency wins（真正变化的事实）/ confidence wins（源可信度+佐证次数）/ merge（双保留带时间戳+变更摘要）/ human escalation（高利害冲突标记人工）。
- **生产组合方案**：轻量冲突→时序优先自动消解；重大事实冲突→标记冲突+条件触发；严重冲突→向用户交互确认；无法判定→共存标注，召回时提示模型存在矛盾信息。
- **MOSAIC 在保存时主动冲突检测**：新信息与记忆图交叉引用，冲突触发警告并可经更新/删除消解。
- 提升层：工作流（冲突处理）。

### 3. 遗忘与保鲜：TTL 分级 + 重要性向量 + 召回强化（工作流）
来源：agentloop-memory-decay / arxiv-2604.20943-scm / arxiv-2609.32049-engramrag / lobehub-mymemory
- **不是所有记忆都活到永远**：TTL+相关性衰减模型按类型分级（turn 级摘要 24-48h / session 摘要更长 / 长期事实保留策略各异）。
- **SCM**：概念标四维重要性向量+工作记忆严格限量+离线 sleep cycle（NREM 强化重要关联 / REM 生成新连接 / 主动遗忘模块剪枝低价值记忆）；interference-based forgetting=新记忆干扰旧记忆。
- **召回强化**：检索到 dormant 记忆会提升其分数（ACT-R 式强化）使其自然回活跃层——**像回忆强化记忆，无需特殊逻辑**；usage-weighted 拓扑=用得多的小记忆路径权重高。
- 提升层：工作流（遗忘与保鲜）。

### 4. 复合检索评分与记忆-RAG（可复用 Skill）
来源：aiagentskit / agentloop / selfclaw-engram / streamzero
- **单靠语义相似度会污染上下文**——复合评分=时间衰减+主观重要性+语义余弦组合，消除上下文污染。
- **memory-as-RAG**=长期记忆当检索源（与知识库检索并列，agent 直接检索自己的历史）；**compiled dossier 优先于逐查询向量搜索**（查询时用编译好的结构化档案优于每次向量检索——连贯性与延迟双赢）。
- **分层记忆各层不同后端**（vector/relational/key-value——把一切塞单一向量库是常见错误）；episodic 保 30-90 天（合规需要）。
- 提升层：可复用 Skill（检索与架构）。
