## 落地 5 独点（每点标注提升层）

### 1. 负面提示纪律：正提示不写否定（可复用 Skill）
来源：aitoolsguidebook / ai-wiki / ai-tldr / bestprompt
- **把 "no glasses, no hat, not smiling" 写进正提示是 CLIP 类模型最常见的自伤 bug**：分词器把 glasses/hat/smiling 保留为相关 token，否定被稀释——越写越出现。
- **负面放专用通道**：SD 有负面提示字段（对扩散步骤精确数学影响）；Midjourney 用 `--no`（更像通用引导而非精确排除）；**对审美连贯有优先级的模型（MJ），负面指令可能被训练偏好覆盖**。
- 提升层：可复用 Skill（图像提示纪律）。

### 2. seed 锁定 + 单变量原则（工作流）
来源：bestprompt / aiinfluencer / aiagentskit / scaler / tinytiny
- **seed 锁定保基础构图**：小迭代改 prompt 不换视觉前提（大改 prompt 即使 seed 固定也换图）。
- **一致性四控**：seed 锁 + 相同风格描述词 + 参考图 + 角色圣经；**黄金法则=一次只改一个变量**：新姿势/新服装/新灯光不同时堆叠，堆叠就漂移；outfit 测试=同 seed 只换服装字段，脸和姿势保持几乎一致。
- 提升层：工作流（迭代控制）。

### 3. 角色圣经 + 参考权重（可复用 Skill）
来源：promptmake / aitoolsguidebook / scaler
- **写任何参考 URL 前先写 Character Bible**：8-12 个精确 token 逐字粘进每个 prompt；**顺序关键=身份 token 放最前权重最高**。
- **漂移时提高参考权重**：Midjourney `--ow` 100→400-600；SD IP-Adapter 提到 0.8-1.0；ChatGPT/Nano Banana 重贴规范图+明确说 "same person, same face"；想主动换风格才降权重。
- 提升层：可复用 Skill（角色一致性）。

### 4. ControlNet 结构控制 + 角色 LoRA（工具）
来源：iimagined / zro2one / learning-aiecos / floniks
- **分工=骨架/构图交给 ControlNet，身份交给 LoRA**：姿势用 OpenPose、场景布局用 Depth、精确轮廓用 Canny；**control 模型必须匹配 base model（SD1.5/SDXL/SD3.5/FLUX 不可互换）**。
- **保存姿态骨架库**跑批生成一致照片集；参考图+seed 锁+规范提示=生产级一致性管线。
- 提升层：工具（ControlNet 选型）。

### 5. 放大与后期两阶段管线（工作流）
来源：novakit / gdefoto / toolworthy / myimageupscaler / floniks / toutiao
- **AI 放大=补细节**（传统插值糊，AI 学高低分辨率对幻觉细节），**但会在 logo/印刷文字/精细纹理上编造假细节→全尺寸检查，能重拍永远胜过放大**。
- **批处理两阶段**：先批量抠图隔离主体（rembg/BiRefNet）→只把需要处理的进 Photoshop；边缘 100-200% 缩放检查导出；透明输出用 PNG；新一代模型 4K 直出（Nano Banana 2.1 蒙版编辑/一键替换背景）。
- 提升层：工作流（后期管线）。
