## 落地 5 独点（每点标注提升层）

### 1. self-correction 可靠边界：内在不可靠，外部接地才有效（工作流）
来源：zylos / arxiv-2603.05863 / csdn / griddynamics
- **2024-2025 研究一致结论**：prompting LLM「check your work」无外部接地时，**在推理任务上反而降级**；自纠只在外部反馈接地时可靠=单元测试结果/检索验证/工具输出对比。
- **验证分层**（CSDN 实战）：能程序判定的先用 ast/json.loads/真实测试用例，**静态层通过才上 LLM 语义审查**（"结构合法但内容是否真正满足任务"）——LLM judge 只在最后层。
- ReflexiCoder=RL 把「生成→bug/优化感知反思→自纠」轨迹内化进权重，推理时完全自主——**2026 趋势：模型层内化自纠，而非运行时 prompt 依赖**。
- 提升层：工作流（自纠可靠性认知）。

### 2. Actor-Critic 双循环（可复用 Skill）
来源：csdn / griddynamics / callsphere / taskade / regolo
- **Reflection 模式**=generate→critique→refine 闭环；critic 可用**不同模型/不同温度/更怀疑的 system prompt** 审计 actor 输出，对照**确定性约束**（schema 校验/compliance 规则/事实接地）——批判与生成分离是核心。
- 2026 变体=**多个专长 critic**（Skeptic/Logician/Creative，各不同 prompt persona）多维批判；Thinker-Worker-Verifier=规划 agent 分解、执行 agent 产出、评估 agent 把关形成结构化迭代环；Critic 也可**调工具验证**自己的怀疑（Tool-Augmented Self-Correction：critique 点名疑似错误→查工具→结果进修订稿→迭代到工具无新问题或预算耗尽）。
- 提升层：可复用 Skill（Actor-Critic 模式）。

### 3. 自纠预算阶梯与收益曲线（工作流）
来源：zylos / yennj / ai-tldr
- **自纠预算阶梯**：Attempt1=标准 prompt 生成；Attempt2=定向批评（"前次响应缺 X，请补"）；Attempt3=换更强模型/换生成策略；Escalate=标记人审——按任务关键度与延迟约束选；每轮记录 critique+最终结果成日志。
- **Self-Refine 收益曲线**：前几轮抓明显缺陷收益最大，后续收益几何衰减趋于平台——**知道何时停止迭代比迭代本身值钱**（多轮空转烧 token 无产出增量）。
- 提升层：工作流（迭代停止判据）。

### 4. Long-horizon 四属性与状态中心架构（工作流）
来源：ubc / arxiv-2607.11388 / arxiv-2608.05013 / alphaxiv / espressio
- **长程四属性**：state 跨决策因果相关/中间错误改变后续可行路径/权衡局部反馈与全局约束/中断后须从外部工件重建（**不能从聊天记忆猜**）——难度不是"步骤多"，是依赖/恢复/问责。
- **StructAgent**：统一 state 保持紧凑可验证任务进度+**verifier-backed 状态迁移**规约进度=显式进度 checkpoint/证据驱动完成/定向失败恢复/工具支持执行——所有进度更新接地于验证。
- 任务分解：OneDayAgent=分解成有序子任务列表（subgoal/层次结构）；MiRA=基于里程碑的稠密奖励 RL 训练（Gemini 在 WebArena-Lite 约 +10% 绝对成功率）；Plan-Execute-Verify=逐 phase 执行，phase 完成对照计划验收标准验证再写记忆推进，失败从最后成功 checkpoint 恢复而非重启。
- 提升层：工作流（长任务架构）。

### 5. Replanning 纪律与自适应编排（工具）
来源：ranjankumar / ii / dev-acai
- **已完成任务永不重写**，只有 pending 任务可重写——崩溃/重规划后仍从最后完成的任务恢复（**保留 checkpoint 属性**）。
- **replan 硬上限=3 轮**：否则 findings 触发 replan 无限循环（重规划出的新发现又触发下一次重规划）。
- **Zenith 自适应编排**：milestone 封顶需两层都过；**重复模式提炼成可复用 skill**（后续会话不用重学）；编排者在每个边界决定 continue/replan/add worker/add tester/synthesize skill/reset strategy/move next milestone/stop——harness 强制执行协议，orchestrator 决定形态。
- 提升层：工具（编排协议）。
