## 二、独点清单 + 判非重复理由（4 点，均≥40% 独有增量）

### 1. 记忆摄取打分门控 + NO_INGEST 显式拒绝（来源：LangFlow docs 2026-09-23 实拉）
摄取到长期记忆前先打分：**正面两类**（持久偏好/进行中项目里程碑）值得存；**负面三类**（事务性技术噪声、对话填充、已有事实的陈旧重述）零值；总分 0 → 显式返回 `NO_INGEST` 拒绝入库。
- 判非重复：ctx §记忆提取四策略（语义/摘要/偏好/情节 + 提取→校验）管"按类型提取+校验值得存吗"，**本点给出可执行打分名单（正 2 负 3）与显式 NO_INGEST 拒绝协议**，且把"陈旧重述"单列为零值类（防重复入库）——增量≥40%。
- 提升层：工作流（记忆摄取门控规格）。

### 2. 远端 MCP 的多用户隔离透传：external-user-id（来源：Pipedream 2026-09-23 实拉）
一个远端 MCP endpoint 服务多用户，用 `x-pd-external-user-id` 头透传用户身份，auth 由平台托管，agent 直接 callTool。
- 判非重复：ctx §工具面安全（per-tool 最小权限/同名拦截）管"工具权限面"，**本点管"远端 MCP 出口的多用户身份透传与 auth 托管"**——同一 endpoint 按用户隔离上下文与权限，个人自建 agent 接 2700+ API 免管 auth。增量≥40%。
- 提升层：工具（远端 MCP 接入形态）。

### 3. Skill 编排的字段映射是关键步（来源：腾讯云《用 AI Skills 搭可复现最佳实践》2026-08-19 实拉）
Skill 工作流 7 步里 3/4/5（编排触发条件、字段映射、导出）最关键，其中**字段映射（明确每个 Skill 的输入/输出字段怎么接）单独点名最易错**。
- 判非重复：harness §插件三件套（parameters schema + output.schema）管"插件自身声明结构"，**本点管"两个 Skill/步骤之间的输入输出字段对接是编排最易错环节、要显式做映射步"**——声明与对接是两个面。增量≥40%。
- 提升层：工作流 / 可复用 Skill（多 Skill 集成）。

### 4. Agent 成本熔断 + 一键回滚链（来源：数数科技《大模型 Agent 平台落地》2026-07-30 实拉）
任务级/用户级 **Token 上限 + 自动熔断**（防计费失控）；预设**人工介入触发器 + 一键回滚**（模型准确率低于阈值或严重幻觉时，退回规则引擎或人工）。
- 判非重复：§成本可观测性管"三通道分开看"（观测面），**本点管"预算硬上限+自动熔断"（拦截面）**；§质检-回退管"步骤间结果太少重试"，**本点管"整系统回滚到无模型的规则/人工链"**（降级面）。增量≥40%。
- 提升层：工作流（成本熔断与降级回滚）。
