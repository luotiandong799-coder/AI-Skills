## 二、独点清单 + 判非重复理由（4 点，均≥40% 独有增量）

### 1. 技能可见面排除：disable-model-invocation——从 system prompt 移除、保留 /skill 手动通道（来源：docs.openclaw.ai creating-skills 2026-09-21 实拉）
低频或手动触发的技能可用 `disable-model-invocation` 保持不进 agent 的 system prompt（省上下文、避免抢占注意力），仍可通过 /skill 显式运行。
- 判非重复：r152-A 落 available_skills 预算（列表占上下文 2%、34-36 截断）管"总量预算"；本点管"**单技能主动从可见面排除**、保留显式手动通道"——排除机制。增量≥50%。
- 提升层：上下文管理 / 工具（技能装载策略）。

### 2. 命令直通：command-dispatch tool——slash 命令绕过模型直达工具（来源：docs.openclaw.ai creating-skills 2026-09-21 实拉）
高频、确定性命令可设 `command-dispatch: tool` + `command-tool`，斜杠命令直接路由到工具执行、不经模型——零模型推理成本、输出确定。与 AgentMore"零 Token 安装/调用"同思路（技能封装后调用不耗额外 token）。
- 判非重复：WB r151-C schema 格式化响应管"输出机器可校验"；本点管"**确定性命令连模型都不过**"——路由面。增量≥50%。
- 提升层：工具 / 工作流（命令路由治理）。

### 3. 装技能前查平台评测/信任信号：TRACE 评测体系 + L4/L5 分级（来源：腾讯 SkillHub techpedia 2026-06-10 + dsh.so 2026-09-22 实拉）
SkillHub 首发 TRACE 评测体系帮识别高质量 Skill；dsh.so 对 DSH 插件做 install-tested (L4) / run-tested (L5) 自动化信任分级——**装任何第三方技能/插件前，先查平台质量与信任分级信号**，不只信描述。
- 判非重复：WB r151-C 插件安装 10 项安全评测清单管"自己动手查的清单"；本点管"**利用外部注册表的自动化评测/信任分级信号**做装前筛选"——外部信号面。增量≥40%。
- 提升层：可复用 Skill（技能供应链治理）。

### 4. 平台自动升版机制：社区 Skill 新版本自动检测更新（来源：腾讯云智能体开发平台 docs 2026-07-14 实拉）
"来自 SkillHub 社区的 Skills，平台会自动检测是否有新版本，若有则自动更新至 Skills 广场，无需用户手动操作"——**技能源仓库出新版时平台自动检测并更新本地副本**，与用户 09-23 拍板的 WB→豆包同步机制同构（WB 权威源自动覆盖镜像）。
- 判非重复：WB r151-B 显式同步协议管"手动 commit/push/fast-forward pull"；本点管"**平台侧自动检测新版本并自动更新**"——自动化面，且与本机同步脚本互为印证。增量≥50%。
- 提升层：工作流（技能分发与更新）。
