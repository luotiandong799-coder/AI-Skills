## 二、独点清单 + 判非重复理由（4 点，均≥40% 独有增量）

### 1. 动作敏感记忆五要素（来源：OpenClaw docs 2026-09-23 实拉）
记忆不是记"事实"，是记"什么条件下该改变行为"。五要素：**改变什么未来行为 / 何时或何条件生效 / 何时过期或什么解锁动作 / 该避免什么动作 / 来源或所有者是谁（影响信任与权限）**。
- 判非重复：ctx §记忆提取四策略管"提取什么+校验"，r151-B 打分门控管"要不要存"；**本点管"存下来的内容必须回答'它改变什么行为、何时过期、谁有权'"**——内容规格面，三者互补。增量≥40%。
- 提升层：工作流（记忆内容规格）。

### 2. 子代理 prompt 完整自足：只有 prompt+CLAUDE.md，不许占位符（来源：GitHub Consortium CAPABILITY.md 2026-04-26 实拉）
子代理隔离 = 只有其 prompt + CLAUDE.md，**无对话历史、无父技能、无累积上下文**；因此 prompt 里每个值都必须给全，"Never pass placeholder values like [PATH_TO_FILE]"。
- 判非重复：r151-A 独立评审管"评审者不带实现上下文"（信息隔离面）；**本点管"隔离的后果：prompt 必须完整自足、禁止占位符"**（完整性纪律面）——隔离决定了 prompt 写法。增量≥40%。
- 提升层：可复用 Skill / 工作流（子代理任务书写法）。

### 3. 子代理输出原样透传：父默认会转述，需要原文要显式指令（来源：growthengineer.ai 2026-05-04 实拉）
父代理收到子代理工具结果会像处理其他工具结果一样压缩/转述；**要原文直达到用户，主 prompt 必须显式加"pass them through unchanged"**。
- 判非重复：§同一份结果两个消费方管"模型版短/程序版全"（产物双视图）；**本点管"子代理产出要交付用户时，父的转述默认有损，需显式原样透传指令"**——交付面。增量≥40%。
- 提升层：工作流（多级输出交付）。

### 4. 插件安装 10 项安全评测清单（来源：DeepSeek Harness 官方评测指南 2026-08-14 实拉）
装任何插件前过 10 项：**钉版本/commit → 一次性主机与仓库 → 合成密钥与数据 → 最小模式起步 → 默认拒绝出网 → 逐源审代码 → 变更需外部审批 → 捕获并检查轨迹 → 固定任务集对比模式 → 保留回滚路径并删预览数据**。
- 判非重复：ctx §per-tool 最小权限管"工具权限面"、§第三方技能选型三判据管"装前筛质量"；**本点管"装插件的完整安全评测协议（10 项可勾选清单）"**——协议面，含"默认拒绝出网/合成密钥/外部审批变更/回滚路径"等执行细节。增量≥40%。
- 提升层：工具 / 工作流（插件安全评测）。
