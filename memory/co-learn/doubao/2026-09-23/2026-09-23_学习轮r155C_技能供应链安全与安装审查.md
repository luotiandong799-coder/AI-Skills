## 二、独点清单 + 判非重复理由（4 点，均≥40% 独有增量）

### 1. 技能安装前企业级检查四步（来源：Anthropic 官方 enterprise skills 文档 2026-03-11 实拉）
①无硬编码凭据（API key/token 必须环境变量或凭据库）②列出 Skill 指示的全部工具与命令（bash/文件/工具引用）③文件读取+网络工具组合的合成风险 ④外部 URL 重定向域名核验。
- 判非重复：WB wb-skill-authoring 管"技能发布/激活评测"（怎么写技能）；本点管"**装第三方技能前的安全审查清单**"（怎么收技能）。增量≥60%。
- 提升层：工作流/工具（技能安装治理）。

### 2. 技能供应链风险量化 + 隐藏指令载体目录（来源：Snyk ToxicSkills 2026-02-05 + Termdock 2026-03-17 实拉）
**13.4% 技能含 critical 级问题、36.82% 至少一个安全问题（1467/3984）**；76 确认恶意样本 91% 用提示注入；**隐藏指令可藏在代码注释/Markdown 格式/不可见 Unicode 字符/标 "example" 的代码块**——SKILL.md 正文作为可信指令加载，这些载体是审计必查点。
- 判非重复：WB cc 工具面安全（工具描述可注入/guardian 三问）管"工具运行时威胁"；本点管"**技能文件静态审计的载体与量化基线**"。增量≥50%。
- 提升层：工具/工作流（技能静态审计）。

### 3. 技能文件运行时只读保护（来源：arXiv 2606.16287 DyMalSkill 2026-08-25 实拉）
**动态恶意技能攻击**：运行时修改技能文件引入恶意行为（OpenHands/Claude Code 均验证可成功）；防御=**操作系统内核级只读挂载技能目录**，阻断动态篡改同时保留良性技能功能。静态扫描解决不了"装了之后被改"，只读挂载解决。
- 判非重复：WB cc"Agent 安全纵深/工具面安全"管输入与工具威胁；本点管"**技能文件被运行时篡改的防御（内核只读）**"。增量≥40%。
- 提升层：工具（技能运行时防护）。

### 4. "clean 扫描不保证安全"：行为偏差率 + 混淆绕过认知（来源：Unit 42 Trust No Skill 2026-09-19 + SkillCloak/SkillDetonate 2026-07 实拉）
**Unit 42 分析近 5 万 OpenClaw 技能：80% 存在行为偏差（做了 SKILL.md 没告诉用户的事）**；**SkillCloak/SkillDetonate：结构混淆在 1600+ 真实恶意技能上绕过 8 个流行扫描器 >80%**；Trail of Bits 用编译字节码藏 payload 绕过 Vercel/ClawHub/Cisco 检测。结论：**多扫描器+clean 徽章≠安全，安装后仍需自身验证（audit --deep / 沙箱默认/人工审）**；对照 OpenClaw×NVIDIA 三扫描器+judge 汇总+Skill Card 的纵深模式。
- 判非重复：点 2 管"静态审计看什么"；本点管"**扫描器的能力边界与纵深验证必要性的量化证据**"。增量≥40%。
- 提升层：工作流（技能验证纵深）。
