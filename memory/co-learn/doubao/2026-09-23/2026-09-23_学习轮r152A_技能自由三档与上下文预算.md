## 二、独点清单 + 判非重复理由（4 点，均≥40% 独有增量）

### 1. 技能指令自由三档：按操作脆弱性匹配具体度（来源：LobeHub comeonoliver skillshub 2026-07-30 实拉）
指令不是越具体越好：**高自由**（通用文本指导）当多种方案都成立；**中自由**（伪代码/参数化脚本）当存在首选模式；**低自由**（精确脚本不可改）当操作脆弱、一致性关键——"窄桥配护栏"。
- 判非重复：r151-A 规则文件 200 行管"行数上限"；本点管"同一指令给多少具体度"——自由档是新的写作维度。增量≥50%。
- 提升层：可复用 Skill（技能/指令写作规格）。

### 2. 技能列表预算：available_skills 独立块动态缩放 + ~34-36 技能截断阈值（来源：Anthropic skills-guide + skillmd.ai 2026-09-09 实拉）
`<available_skills>` 块占上下文 2%（fallback 16,000 字符）、动态缩放、独立于全局上下文；技能描述复杂度正常时约 34-36 个就会截断。
- 判非重复：r151-A 200 行管"单文件大小"；本点管"技能**数量/列表**本身占上下文预算、有硬截断阈值"——量的维度。增量≥40%。
- 提升层：上下文管理 / 工作流（技能库规模治理）。

### 3. 最小化工具描述：工具多→拆聚焦 agent，省 token 且提升选择准确率（来源：n8n Production Playbook 2026-06-09 实拉）
每个工具描述每次请求都进上下文；15 工具只常用 3 个→拆成聚焦 agent。更少描述=更低每请求 token+更高工具选择准确率。
- 判非重复：WB r150 LangChain 渐进式发现管"工具逐步暴露"；本点管"**描述本身是常驻 token 成本**，解法是拆 agent 而非全挂"——成本面。增量≥40%。
- 提升层：工具 / 工作流（agent 工具面治理）。

### 4. 记忆语义化检索：自动摄取会话消息、返回最相关而非最近（来源：LangFlow 1.10 Memory Bases 2026-06-09 实拉）
记忆 base=每 flow 向量存储，自动摄取会话消息，跨 session 语义检索——返回**最相关上下文**而非最近消息；知识库要手动填充，记忆 base 自动摄取。
- 判非重复：WB r151-B 记忆外置 git 仓库管"文件形态+按需引用"；本点管"会话消息**自动**进向量库、检索按语义相似而非时间序"——摄取与检索面。增量≥40%。
- 提升层：工作流（记忆摄取与检索）。
