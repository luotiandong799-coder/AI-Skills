## 二、独点清单 + 判非重复理由（4 点，均≥40% 独有增量）

### 1. 失败路径记忆：长期记忆必须记录"失败的尝试及其原因"，不只存成功结论（来源：Anthropic long-running Claude + PromptRefinery Error Pattern Memory 2026 实拉）
progress file 四要素：状态/已完成/失败尝试与原因/已知局限——**没有失败记录，后续 session 会重复同样的失败**；配套 Error Pattern Memory 提示模板：记录尝试→为何失败→什么替代更好→相似任务回引。
- 判非重复：WB cc"记忆提取四策略"管**怎么提取**（语义/摘要/偏好/情节策略）；本点管**记忆内容必须含负样本（失败路径）**。增量≥60%。
- 提升层：工作流（记忆内容建模）。

### 2. 记忆类型学渐进叠加：semantic → episodic → procedural 三层按序加（来源：deeplearning.ai Long-Term Agentic Memory With LangGraph 2026 实拉）
三层分工：semantic=事实/偏好/演化的 system prompt；episodic=过去交互样例；procedural=流程与程序知识。**渐进加层而非一次全上**，每层有独立检索与注入方式。
- 判非重复：WB cc 管存储分层（日记→档案）与保鲜；本点管**记忆类型学三分+渐进叠加顺序**。增量≥50%。
- 提升层：工作流（记忆类型设计）。

### 3. 上下文健康检查与拆对话重开：定期让模型自述目标，答错即重开（来源：WaytoAGI/w3cschool 上下文管理 2026 实拉）
**每隔几轮问"用 3 句话总结当前目标和关键决定"**——答对=上下文完好，答错=上下文已碎应果断重开；复杂任务拆多个对话+每个新任务重贴背景卡，换桌重开效率高出 3 倍以上。
- 判非重复：WB cc 预算管理管"token 何时压"；本点管"**对话何时该重开**（健康检查动作+量化收益）"。增量≥40%。
- 提升层：工作流（对话级上下文治理）。

### 4. skills-lock.json 技能版本锁定清单：集中钉死每个技能的来源与路径（来源：Full Stack Skills skills-lock.json 2026 实拉）
锁文件 `skills:{name:{source, sourceType:github, skillPath:xxx/SKILL.md}}`——**一个清单集中管理全部技能来源，可复现安装**，杜绝"同名技能不同来源"漂移。
- 判非重复：wb-skill-authoring caliper 管**单技能评测复现**（git 源钉 commit）；本点管**技能集合的锁文件集中管理**（多技能来源一次性钉死）。增量≥40%。
- 提升层：工具（技能安装治理）。
