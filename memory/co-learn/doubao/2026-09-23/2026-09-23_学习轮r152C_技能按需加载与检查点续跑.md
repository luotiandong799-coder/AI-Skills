## 二、独点清单 + 判非重复理由（4 点，均≥40% 独有增量）

### 1. 技能上下文双面预算：启动只预载元数据、正文/脚本按需加载零常驻 + 正文截断 1%（来源：Anthropic best-practices 2026-03-12 + inside-claude-code 2026-06-10 + yourdocs 2026-09-21 实拉）
启动时只有全部技能的 name+description 预载；正文、脚本、参考文件按需加载——"A Skill can include dozens of reference files, but Claude loads just that one file… The rest remain on the filesystem consuming zero tokens"；脚本执行时代码不进上下文。另：技能正文的截断预算是约 1% 上下文窗口（元数据块是 2%，两者分开计）。
- 判非重复：r152-A 落 available_skills 元数据块预算（2%/34-36 截断）；本点补**正文侧**：按需加载零常驻机制 + 正文 1% 截断预算——预算分元数据/正文两槽。增量≥50%。
- 提升层：上下文管理（技能装载策略）。

### 2. 技能上下文审计：定期跑"找浪费上下文的技能"命令（来源：Anthropic skill-doctor，implicator.ai 2026-09-07 实拉）
Anthropic 2026-09-04 发布 CLI 审计命令，找出"配置过长/浪费上下文"的技能——**技能面不是只增不删，定期审计哪些技能在烧上下文**。
- 判非重复：r151-A 规则文件 200 行上限管"写作时的行数约束"；本点管"**运行期定期审计、删浪费者**"——治理动作。增量≥50%。
- 提升层：可复用 Skill（技能库治理流程）。

### 3. 检查点续跑：暂停→审批→从断点恢复，已完成步骤不重跑（来源：LangFlow HITL 2026-09-07 + Activepieces changelog 2026-09-03 实拉）
HITL 暂停流程时建 checkpoint，人审批后从 checkpoint 用所选分支恢复，"previously completed steps are not executed again"；Activepieces 同机制"Runs resume from their last checkpoint, never from the start"。多步流程中人工介入不推倒重来。
- 判非重复：WB r151-C 负载超时管"按负载类型定超时"；ED 执行态/交付态管"两态分开记"；本点管"**重跑粒度**——从断点续跑而非整流程重跑"——执行成本面。增量≥50%。
- 提升层：工作流（长流程断点续跑）。

### 4. 代码库记忆外置为查询图：本地确定性 AST 解析、每条 edge 有解释、无需向量库（来源：Graphify/codebase-memory-mcp，GitHub Trending 2026-09-20 实拉）
把代码库（含 docs/SQL schema/config/PDF）转成可查询知识图；本地确定性 AST 解析、每条关系有解释、无向量库；codebase-memory-mcp 直接砍掉"重读 repo 烧掉的 token"。
- 判非重复：WB r151-B 记忆外置 git 仓库管"记忆文件按需投影引用"；本点管"**代码库特定形态**：确定性 AST 图（无向量库、edge 可解释）替代反复全文重读"——代码库记忆专用方案。增量≥50%。
- 提升层：工具 / 工作流（代码库理解与记忆）。
