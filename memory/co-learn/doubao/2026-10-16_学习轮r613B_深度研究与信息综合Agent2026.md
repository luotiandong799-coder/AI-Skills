## 二、提炼核心方法与关键事实（可内化，均带来源）

- 并行化收益量化（Anthropic）：token 用量=80% 性能方差因子；3-5 子代理+3+ 工具并行省 90% 时间；升模型 > 加倍 token 预算；模型不对称配置（frontier orchestrator + cheap subs）。
- 引用证据治理五件套：citation lineage 假独立识别；Tier 权重 1.0/0.85/0.65/0.40；确定性五匹配验证；置信上限硬规则（≥0.7 需 2+ 独立源、单源 cap 0.6）；Phase Gate Protocol 文件门。
- Synthesis≠Summary 九项强制交付；三账本（Task Ledger/Verification Log/Decision Log）；Not Found 显式化不编数字。
- Knowledge vs Instructions 分界；不全贴 prompt 双原因（大小/新鲜度）；空结果=真没有不当填充；Max steps 防卡死。
- 工具输出治理：Code 节点裁剪 envelope、prompt variable 而非 Context、LLM 节点必须 User message、Aggregator source 选"产 bundle 模块"、去重 Filter、429 指数退避。
- Skill 供应链安全：26.1% 漏洞率、脚本捆绑 2.12×、导入前审 SKILL.md 与脚本；URL 幻觉交付前必验；沙箱最小权限/联网显式开。
- 深研入门口：拒绝协议（vague in = vague out）、隐含偏置重述、中立原则+negative findings、饱和点+硬停。
