## 四、提炼核心方法与关键事实

1. **注入防御输入侧分层**：四件套过滤（签名 regex/语义相似度/长度限制防 many-shot/独立分类器）；规则+ML 双层（正则拦已知+BERT 拦语义+24h 再训练）；负约束 Constraint String 精简；硬分隔符+三明治重申；无层互信（regex flag+fence 剥闭合+scrubber 杀外泄）。
2. **动作层确定性护栏**：权限分离（LLM 输出永不直接触发特权动作）；确定性工具边界（ClawGuard/cc_hook 按工具名拦截 skill 指令一切动作）；沙箱边界（ro 只读+无网络默认+deny 验证）；审批 fail-closed（超时即拒+永续授权是系统性风险）。
3. **技能供应链安全**：Agent Skills 行行皆指令→平凡注入；"检测数据中的指令"对 skills 失效；'Don't ask again' 授权延续到近似有害动作；只信已验证来源；MCP 五检查；protocol pivoting 跨 agent 跳转。
4. **概率 vs 确定性双层护栏**：过滤器概率性会被绕过（期望失败）；行为控制（allowlists/scoped credentials/spend caps/approval gates）确定性兜底；动作层≠文本层（输出无害也有副作用）；运行时八类护栏=执法非评估。
5. **安全审计与监控**：审计四要素（tool calls+凭据生命周期+策略变更+防篡改+SIEM+加密签名）；逃逸监控（escape classifier 动作前阻断+沙箱红队测试）；越权信号（超范围访问即报警）；系统级威胁（资源耗尽+cache-bypass 检测 nonce 注入）。
6. **凭据与访问边界**：token 永不进上下文（注入无物可偷）；per-project MCP+网关收敛（SSO/策略/审计一处+一键撤销）；凭据生命周期审计；传输侧风险（ClawBleed：连接参数不经 URL）。
