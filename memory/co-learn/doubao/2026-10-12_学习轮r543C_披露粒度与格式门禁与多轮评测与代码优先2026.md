## 落地 6 个真独点（全部带提升层）

1. **渐进式披露 Progressive Disclosure：只有名称+描述常驻，细节按需加载** → authoring 1.132.0→**1.133.0**。要点：细节指令下沉按需加载；Anthropic 实证系统 prompt 削减 80% 无评测损失；工具定义延迟化。与 References load when needed 互补（那条管文件级，本条管元数据级）。提升层：可复用 Skill（上下文工程/技能设计）。
2. **编译器式格式符合度评分：发布质量门不看人气看规范** → authoring 1.133.0。要点：Skilldex compiler-style line-level 反馈 grounded in 规范；skillset 共享资产（vocabulary/templates/persona）保同组输出互洽。提升层：可复用 Skill（发布质量门/技能分组）。
3. **Agent 多轮评测：评中间状态与工具使用，不只最终输出** → authoring 1.133.0。要点：多轮性让评测难；覆盖中间状态与工具调用序列；过程正确性与结果正确性分测。提升层：可复用 Skill（评测方法/Agent 系统）。
4. **最小充分上下文 + context rot：窗口再大，准确率也随内容堆积下降** → compressor 3.650.0→**3.651.0**。要点：context rot 与窗口大小无关；目标=高信号 token 的最小充分集；prompt 高度按失败模式迭代。提升层：工作流（上下文管理）。
5. **Agent 决策过程可见可审：透明面板 + run 感知改进循环** → execute 3.54.0→**3.55.0**。要点：nothing runs behind the scenes（Reasoning Panel 实时看怎么想/调哪些工具/为何走此路）；Maia run 感知改进（review run+tools used→what to improve→apply）。提升层：工作流（可观测/迭代治理）。
6. **代码优先 agent：写代码执行而非 JSON 工具调用** → execute 3.55.0。要点：CodeAgent 一次生成多工具+循环+中间变量；同准确率少 30% 步数（HF+DeepMind）；导入白名单逐个授权禁 os/subprocess。提升层：工作流（Agent 编排/执行安全）。
