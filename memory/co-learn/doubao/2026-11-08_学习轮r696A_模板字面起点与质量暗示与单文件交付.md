## 三、三点落地

1. **改现成产物先读模板**（ui-visual-qa）：先 Read 全模板 → 当字面起点（"Build on it, don't rebuild it"）→ FIXED 段一字节不动（页头/侧栏/品牌字体配色/控件）→ 只换 VARIABLE 段；五类偷懒禁令（从零重写/自创配色/换系统字体或深色主题/改侧栏/只当灵感）。**提升层：工作流**。
2. **质量暗示**（visual-gen）：prompt 里对"工艺水位"反复申明 2–3 次 + 验收段给可检查水位词（平衡/色彩和谐/层级/性能/可复现）；只写参数不写水位＝出均值货；用户要快版/草稿时不上。**提升层：模型（提示工程）**。
3. **交付形态单文件化**（execute-discipline KB）：多文件工程 bundle 成自包含单 HTML 再交付（交付目录＝把部署成本转给用户）；但简单单文件产物禁止上重栈；可视产物测试可后置，但交付前必须确认文件真能打开。**提升层：工作流（交付纪律）**。
