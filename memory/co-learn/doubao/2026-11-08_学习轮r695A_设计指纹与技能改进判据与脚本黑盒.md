## 三、三点（各附提升层）

1. **AI 生成设计的指纹清单与两遍法**（ui-visual-qa）
   - 五组痕迹：奶油底 `#F4F1EA` + 高对比衬线 + 陶土色 `#D97757`；近黑底 + 荧光绿/朱红；报纸式（发丝线/零圆角/密栏）；SaaS 卡片套件（同圆角、同 `rgba(0,0,0,.1)` 阴影、渐变装饰）；模板装饰条款（全大写 eyebrow、中点元信息、带空格 em dash、假黑 `#0B0B0B`、等宽小标签、链接尾巴 `→`）。判据：这些是"默认"不是"错"，brief 没指定却用了就是缺陷，brief 明确指定则照做。两遍法：先出 token 计划（4–6 hex + 字体角色 + 布局线框 + 三原则）→ 对着 brief 复核"这套放到任何同类页面是否也成立"→ 才写码。大胆只花一处；质量地板（响应式/键盘焦点/reduced-motion/对比度）不宣传也要有；改完截图自评。附 CSS 特异度互抵与"文案即设计"（CTA 说清结果、动作全流程同名、错误不道歉）。**提升层：工作流 + 可复用 Skill**。
2. **技能改进的两个可测判据**（sa）
   - ① 读 transcript 而非只看产物：三个用例都自己写同一个 helper（`create_docx.py`/`build_chart.py`）→ 该把它写进 `scripts/` 让技能直接调用。② 描述触发率要单独测：正负各 8–10 条，**负例必须是近邻易混**（共享关键词但该由别的工具干），明显无关的负例什么也测不出；查询要像真人输入；每条跑 3 次取稳定触发率；60/40 训练/留出、**按留出集选**防过拟合，最多 5 轮。③ 全大写 ALWAYS/NEVER 是过拟合黄旗 → 改成讲清"为什么"。④ token/耗时只随完成通知来一次，当场落盘。**提升层：可复用 Skill + 工作流**。
3. **捆绑脚本按黑盒调用**（cc）
   - 先 `--help` 再直接调用，**跑不通才读源码**——大脚本会永久占用上下文并挤掉推理内容；反模式是"为了保险通读两千行"或"自己重写一份等价脚本"。判据：`--help` 成本一屏 vs 读源码成本是常驻预算。**提升层：工具 + 工作流**。
