## 三、提炼的核心方法与关键事实
1. **MCP 走 Gateway**：裸连=侧门（无法枚举 agent 工具面）；工具四分级 low/medium/high/critical 高风险默认审批。
2. **agent 当用户管**：RBAC/SSO/SCIM 同策略；autonomy 与工具影响成反比；不可逆动作强制 HITL。
3. **权限模式权衡**：sandbox 安全高维护/bypass 无保护/manual 居中（93% 接受率）；containment=监督能做什么。
4. **密钥不落盘**：Vault 一次性 TTL+Envoy 实时注入。
5. **社区 skill 四查**：inspect source/权限/活跃/只装懂的；26.1% 市场带漏洞；安装激活=operator-level authority。
6. **spawned agent 隔离**：sub-workflow 独立凭据；service identity 最窄角色；运行/编辑权分离；认证配置化。
7. **治理四支柱**：lifecycle/risk/security/observability；inputs/outputs/decisions 追踪；版本化审计。
8. **信任边界显式编码**：白名单外直接拒绝；isSourceAdminTrusted 才给 MCP；Auth Proxy（secrets 永不进运行时）。
