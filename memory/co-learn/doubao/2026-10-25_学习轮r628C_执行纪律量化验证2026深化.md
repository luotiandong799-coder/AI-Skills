## 三、提炼的核心方法与关键事实
1. **样本量非谈判**：10k+/variant 或 power analysis 100-500；eval harness 门禁+guardrail metrics 赢者也不许破。
2. **primary+guardrails**：primary 管保留，guardrail 管暴露。
3. **回归分层**：capability vs regression 双套件；versioned test fixtures（生产失败变永久 case）；分级容差（1-2% vs 零容忍）。
4. **统计判定**：A/B 50x→p-value/CI；delta≥0 或 Welch t-test；per-segment diff。
5. **结构回归**：执行 DAG sub-5ms 确定性 Exit 0/1；五规则评分器；轨迹评分。
6. **成本效率**：cost_per_success=cost/成功率；mean tool calls；P95；趋势优先。
7. **优化闭环**：regression suite gates every change；复现+回归双验证；组件级评估。
