## 三、三点落地

1. **数字必须标证据基座**（`defaults/wb-max-token-saver` KB + 指针，1.97.0→**1.98.0**）：measured/inferred/provider_reported/benchmark_counterfactual/observed/verified/unpriced 七档各答不同问题；数值旁写基座、聚合不许换基座、缺 usage 不许用估计顶替；文件大小≠计费 token；未知价格输出 0 必须同时标 unpriced；估计不许从"每天"升级成"每月"；省 token 结论要"原始配对 + 质量复核"双证。**提升层：可复用 Skill（成本度量）**。
2. **验过即停 + 外科补丁**（`wb-execute-discipline` KB + 指针，3.301.0→**3.302.0**）：验收任务先定最小充分证明集、先聚焦后宽门、复用需"仍新鲜且仓库状态匹配"、状态只报四态；验证请求没写"修"就不许改产品代码；过验收后不许加抛光/清理/无关测试；修复只改拥有该行为的最窄一层，保留无关行为，只加任务相关回归证明；修好即停。**提升层：工作流（执行范围控制）**。
3. **读证据的三条边界**（`wb-artifact-verification` KB + 指针，2.447.0→**2.448.0**）：空结果=当前无信号而非零；不许从聚合或单条极值推因果，要用有界窗口 + 闭环过滤 + 对照组；每条结论带记录 id 与精确时间窗；默认只读元数据、不拉 payload；核验期只读，不许启停实验。**提升层：工作流（证据复核）**。
