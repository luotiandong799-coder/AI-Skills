## 三、提炼的核心方法与关键事实
1. **三规则**：先单 agent（协调只在 demonstrably fails 时加）；Pattern > framework；每 agent 必须有预算（turns/tokens/tools/wall-clock）。
2. **模式权衡**：Pipeline 易调试但错误累积；Supervisor/Worker 灵活但路由可能错；Swarm 并行须硬性轮数上限；Blackboard 共享空间。
3. **handoff 契约**：well-formed handoff summary（type/reason/urgency）；80% 上下文 handoff 变 stale→委派 fresh context+磁盘持久化；@tool 返回 Handoff 动态路由。
4. **按角色分模型**：只对强推理角色用高端模型（成本降 40%）；supervisor 生成 JSON 任务队列+执行 agent 干确定性活；Opus 高层+Sonnet 执行。
5. **嵌套与隔离**：agent-as-tool（Dify 嵌套/n8n AI Agent Tool/Make Sub-Agents）；子工作流参数接口通信+上下文隔离；首尾相连否则线性。
6. **框架坐标**：LangGraph 生产耐用 34.5M 月下载/CrewAI 56.9k/OpenAI SDK 最轻量/80% 时间在数据工程非框架。
7. **终止条件**：TextMentionTermination("APPROVED")+max_turns；AG2 adapter consulting 自动关闭/discussion round-robin。
