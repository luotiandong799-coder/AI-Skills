## 二、核心方法与关键事实（带来源）

- **CRAB（arXiv 2604.28138）**：语义感知 checkpoint/restore 运行时——eBPF inspector 分类每轮 OS 可见效果决定 checkpoint 粒度；coordinator 对齐 turn 边界且与 LLM 等待时间重叠 C/R；host-scoped engine 调度跨沙箱 checkpoint 流量
- **DeltaBox（arXiv 2605.22781）**：毫秒级沙箱 C/R——DeltaFS 冻结 writable layer 插入新层（更新变 copy-on-write、回滚=层切换）；DeltaCR 从冻结模板进程 fork（CRIU dump 兜底）；checkpoint ≈10.83ms 隐藏于推理下、rollback ≈1.86ms；SWE-bench/RL micro-benchmarks
- **checkpoint 四物分层（elsai/Belgavi）**：checkpoint=step boundary 处的 durable copy（messages+structured working state+下一步+产出代码元数据）与 session（对话消息）/orchestrator position/HITL interrupt 分开存；四层 checkpoint schema（状态层用 protobuf/flatbuffers 强 schema 二进制，JSON 字段重命名/加 optional 演进灾难）；三内存层=session/file-based/event-sourced（understandingdata）；idempotent resume/write ordering/forking
- **LangGraph Delta Channels（2026-05）**：deepagents v0.6 默认——不存每 checkpoint 全量快照只存 diff（message histories 和 files delta-based）；缓解长运行 agent 写 checkpointer 的数据库瓶颈；checkpointer（thread-scoped 短期：对话连续性/HITL/time travel/容错）vs store（cross-thread 长期：用户偏好/事实/共享知识）双持久化；time travel 修复=replays 不再复用 stale RESUME、subgraph 恢复 parent 历史 checkpoint；生产 HITL 需 durable checkpointer（SQLite/Postgres/DynamoDB）非 InMemorySaver
- **Claude Code sessions（2026-10 多语言）**：resume 三选项=Resume from summary（/compact 立即跑，后续请求带摘要而非全历史）/Resume full as-is（全量加载每请求成本随会话大小增长）/Don't ask me again；resume by ID 常见原因=跟进已完成任务（免重读文件）+从 limit 恢复；fork=以对话副本开始（默认 subagent 从零）；PR URL 粘贴到 /resume 找回创建它的会话；会话间消息（macOS/Linux 会话互传发现/决定免重述）；background sessions 出现在 /resume 可 pin
- **handoff skill（dennisrongo/claude-skills）**：四要素模板（从对话里拉每个决策的 why 不只 what）+日期 slug 文件名+.claude/handoffs/+memory pointer 写 auto-memory 并在 MEMORY.md 索引
- **Time-travel 调试**：OrcaReplay=每步不可变 Merkle-hashed 事件+replay/fork/compare；外部 API 响应缓存保确定性重放；lazy context reconstruction；<50ms/tool call 开销、~200MB/h 存储；Burr counterfactual replay=fork 任一步只改一个输入只重放下游 diff 两轨迹——未改分支每个 output hash 一致且 0 token=可信 diff；db.why() 因果血缘（工具响应 schema 变→agent 静默回退弱路径）；rewind/Agent VCR（回退/状态编辑/恢复，中间失败不改从头跑省 100%）
- **Durable execution**：三原语=deterministic control flow+managed side-effect abstraction+event-sourced state persistence；durable 引擎 persist 每步输入+结果到 append-only journal，崩溃重放已完成步返回缓存结果、从第一个未完成步恢复、副作用永不重复；checkpointing≠durable execution（快照 vs 事件日志）；51CTO=控制流表达为可重放状态机/DAG，节点输入/结果/推进位置在语义安全点持久化，只从最近已提交 checkpoint 恢复，未提交尾段可重算但重复执行必须同业务结果；Temporal=全部状态从不可变事件日志重建非内存态+activity-level 各自 retry；Microsoft Agent Framework=step 后自动 checkpoint+executors 跨机器分布+Durable Task Scheduler；Microsoft Foundry crash recovery=exit_for_recovery 留 response in progress 供再调用、crash recovery 重进同 attempt state 不消耗 retry budget
- **Mem0**：token-efficient 算法=单趟 ADD-only 提取——事实提取一次存为新记忆、永不被提取管线覆盖或删除（错误纠正走显式删除非隐式覆盖）；检索=语义相似+关键词+实体匹配三路；记忆存模型外、每轮只检索相关、跨重启与换模型存活；DeepSeek harness 两工具 search_memory/add_memory 跨运行持久
- **Zep graphiti**：时序感知知识图谱记忆；LoCoMo 1540 问 94.7% vs mem0；relational+vector；memnode=可检查召回+来源溯源+scoped tokens+共享租户
