## 三、三点（各附提升层）

1. **先写视觉哲学再动画布**（visual-gen）：两段式——先出 `.md` 视觉哲学（流派名 1–2 词 + 4–6 段，五维各一次：空间与形 / 色与材质 / 尺度与节奏 / 构图与平衡 / 视觉层级），再表达为 `.png`/`.pdf`；成品 **90% 视觉 + 10% 文字**；用户原意当**隐性线索**埋进形色，懂的人直觉到、不懂的人看到完整作品（反模式：把主题画成标签/图解）；哲学要给方向但别细到每元素摆位。**提升层：工作流**。
2. **精修只收敛不加件 + 边界硬约束**（visual-gen）：第二遍唯一动作是"让已有东西更紧"，判据问句"能不能让已经在那里的更像作品"；想加滤镜/换字体/画新形状就停——那是逃避"构图不够紧"；**任何元素不得出血、不得互相压盖、必须留呼吸位**，重叠=没做完不是风格。**提升层：工作流（视觉验收）**。
3. **主题套件四步 + 三件套**（ui-visual-qa）：主题 = 色板（hex）+ 字体配对 + 可说清的视觉身份；流程 = 给全量样张 → 问选哪套 → **等显式确认** → 再全量套用；无合适主题则按同结构自造，**仍先展示复审再套**；一致性优先于单页好看，"这页单独调一下"是破窗。**提升层：可复用 Skill**。
