## 四、本轮落地点（3 点，跨 3 技能）

### ① 目标环境验收与本地检查分开记：四态枚举 + 环境版本 + 下一许可步骤
- 来源：`affaan-m/ECC`·`.agents/skills/verification-loop/SKILL.md` 3,480B，逐串命中 `Passing local checks, review, merge, or release does not establish target acceptance` / `Report VERIFIED or FAILED for an executed target check` / `next permitted check or precise access dependency`
- 方法：六段本地核验（build/type/lint/test/security/diff）→ 目标验收单独一槽，四态 `VERIFIED` / `FAILED` / `NOT PERFORMED` / `NOT APPLICABLE`，各带环境与版本、证据、下一步许可动作；合并·评审·发布均不构成验收；纯本地任务显式标 not applicable。
- **提升层：工作流 + 工具**（交付结论从「我本地跑过了」升级为「哪台机器上看到什么、下一步谁验」）
- 落点：`engineering/wb-artifact-verification` · KB `## r709B`

### ② 演示文稿两条硬门：一屏一页零滚动 + 密度上限；风格用三份单页预览让用户"看"而不是填问卷
- 来源：`affaan-m/ECC`·`.agents/skills/frontend-slides/SKILL.md` 6,559B（另引同仓 `STYLE_PRESETS.md`），逐串命中 `every slide must fit inside one viewport with no internal scrolling` / `never solve overflow by shrinking text below readable sizes` / `Content Density Limits` / `Generate 3 single-slide preview files`
- 方法：每页必须一屏放下、页内零滚动，装不下拆页不许缩字号；密度上限表（标题 1+1 / 正文 4–6 条或 2 段 / 卡片 ≤6 / 代码 ≤8–10 行 / 引用 1+出处 / 图 1）；字号间距用 `clamp()` 随视口；五档尺寸验收；风格发现走三份单页预览（≤100 行、能看出排版配色动效），禁止抽象风格问卷。
- **提升层：工作流 + 可复用 Skill**（演示类交付从此有可判定的完成条件，不再靠"看起来还行"）
- 落点：`media/wb-visual-gen` · KB `## r709B`

### ③ 本地规则只写增量：不得豁免项目级、无缺失不建副本、不按目录配额建空文件
- 来源：`affaan-m/ECC`·`.agents/skills/module-governance/SKILL.md` 6,643B，逐串命中 `Local rules cannot waive project-wide constraints` / `Do not create empty files to meet a two-file quota` / `Directory names alone do not establish a bounded context` / `Resolve relative links from each referencing document's directory`
- 方法：项目级持全局约束，本地只加"额外的"（职责/状态归属/接口指针/验证入口）；项目级已覆盖则链接不建副本；缺失文件是复核提示不是建文件命令；边界不由目录名证明；相对链接按每个引用文档自己的目录解析；链接检查通过不等于实现完成，同名文件仍可能是错 owner。
- **提升层：工作流 + 可复用 Skill**（规则层不再靠"每目录补两份文档"膨胀，减少重复与漂移）
- 落点：`meta/knowledge-governance` · KB `## r709B`
