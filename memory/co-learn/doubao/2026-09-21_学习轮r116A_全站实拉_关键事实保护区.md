## 独点：2 条
**D18：关键事实保护区（trauma memory）——压缩/重写前维护一份"永不压缩的关键事实清单"**（来源：ReCompress《Query-Aware Rewriting and Tiered Memory for Efficient LLM Context Compression》2026 实拉）
- 机制：保护区上限 ~50 tokens，从用户目标初始化，随新关键事实出现更新；**strictly append-only、永不经压缩**；事实含命名实体、桥梁关系、数字约束、用户声明的目标；**任何组件动作前先查保护区，checkpoint builder 被指示绝不压缩保护区里的任何事实**。
- 判据：**压缩前先维护"保护名单"**——哪些事实是本次任务的地基（目标/数字约束/关键关系），列入保护区后任何压缩/重写不得碰；压缩质量门除了"摘要好不好"，还要查"保护名单里的每一条还在不在"。
- 与 ctx §压缩质量门/记忆自维护分工：那条管"压缩结果好不好"，本条管"压缩前先声明哪些不能压"。
- 提升层：工作流/可复用 Skill。

**D19：检索重排链（reranker chain）——neural reranker（校准截断）+ MMR 去冗余 + UDF 业务信号**（来源：Vectara《Tune retrieval for agents》2026-09-04 实拉）
- 机制：单个重排器很少够用；最强配置是一条链——①神经重排器做相关性主力（带校准截断值）②MMR 去冗余（agent 不该看到同一段的五个转述）③可选 UDF 加业务信号（时效/热度/自定义维度）。
- 判据：**重排不是一步，是三步**——相关（重排器）→ 去重（MMR）→ 业务加权（UDF）；只做相关性重排的检索会把"五条同义结果"喂给 agent。
- 与 D14 分工：D14 管"排序标准用决策效用"，本条管"重排后的三段流水线（相关/去冗余/业务信号）"。
- 提升层：工作流/可复用 Skill。
