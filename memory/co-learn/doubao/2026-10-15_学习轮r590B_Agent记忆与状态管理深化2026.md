## 一、10 站实拉证据（general_search 文本通道，每站带来源）

### 站1 Agent 记忆架构（swarmsignal 2026-04 / arXiv 2603.07670 / aiorbitx 2026-08 / mastra 2026-06 / moeidsaleem 2026-07）
- 四层：Working（active context window）/Episodic（timestamped log 按 similarity/recency 检索）/Semantic（vector index 知识块）/Procedural（技能复用）
- MemGPT：Main context（RAM）/Recall storage（disk 搜索数据库）/Archival storage（cold vector-indexed）；agent 经 memory management 调用移数据
- Working 主动管理=清 stale tool results+running summary/running notes file+压缩旧会话；"默认在上下文的要问该不该在"
- 生产路径=先 working 优化+RAG→episodic 个性化→procedural；retrieval quality over capacity

### 站2 上下文注入（atlan 2026-09 / lobehub context-window / agentloop 2026-05 / arXiv 2606.11213 / mindstudio 2026-05 / openlegion 2026-07）
- Token budget=前置；static/dynamic 分离保 prompt caching（cache read=输入价零头）；governance+observability 决定第 10 周可靠性
- 三区预算+三健康态（ok<60%/compact 60-80%/exhausted>80%）+80% 压缩规则+压缩前协议
- 四条原则=Budget first/Retrieve don't store/Summarise at boundaries/Write with intent
- CWL=typed dependency-linked episodes+deterministic LLM-free eviction；注入优先级=core→task→knowledge→memory

### 站3 记忆写入蒸馏（arXiv 2508.03341 / 2609.27334 / 2605.20616 / 2608.12990 / danorlando 2026-05 / clawpedia 2026-08 / zylos 2026-04）

### 站4 记忆召回与遗忘（arXiv 2605.08538 / 2606.12945 / sandgarden 2026-09 / mem0 2026-09 / humux 2026-05）

- Mem0 decay=recent 1.5×/idle 0.3×；stale 从不 zeroed；recency-only 对相关查询错；选择性保留
