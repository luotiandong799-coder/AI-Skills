## 四、本轮落地点（3 点，跨 3 技能）

### ① 新建 `writing/wb-outreach`：一对一对外沟通（冷邮件 / 自荐 / 内推 / 跟进）
- 来源：`affaan-m/ECC`·`.agents/skills/investor-outreach/SKILL.md` 2,644B，逐串命中 `Personalize every outbound message` / `Keep the ask low-friction` / `Use proof instead of adjectives` / `Never send copy that could go to any investor` / `day 4 or 5` / `day 10 to 12` / `under 100 words`
- 方法：五核心规则（每封个性化 / 单一低摩擦请求 / 证据替形容词 / 短 / 不编 CTA）；五段结构（具体主题行 → 为什么是这个人 → 身份+可核对证据 → 一个动作一个时间窗 → 落款可信锚点）；个性化四源（对方公开产出 / 共同联系人 / JD 痛点匹配 / 公开选择）；跟进止损 day0 → day4-5（带新信息）→ day10-12 干净收尾，之后不再追；引荐请求附 ≤100 词可原文转发 blurb；缺个性化就标"未完成"，不伪装成品。
- **提升层：可复用 Skill + 工作流**（此前库内没有任何"一对一沟通写作"位置，用户 2027 秋招的冷邮件/内推/跟进从此有可执行模板与判据）
- 落点：`writing/wb-outreach/SKILL.md`（新建，正文内联，无 KB）

### ② 决策级分析报告骨架：先立定位简报，再只回答三个问题
- 来源：`affaan-m/ECC`·`.agents/skills/competitive-report-structure/SKILL.md` 8,409B，逐串命中 `who do we compete with, how do we compete, and where is our defensible white-space` / `Do not add a blended total column` / `Leading with methodology`
- 方法：定位简报四件（战略张力 / 精力配比 / 差异点一句 / 目标象限）→ 三问结构 → 摘要决策先行、方法学入附录 → 矩阵维度分开报、禁混合总分列 → 深潜 3–5 家"选来教学不选来排名" → 结尾给逼决策触发问题。
- **提升层：工作流 + 可复用 Skill**（把"竞品对比写成文献综述"改成"读完能拍板"）
- 落点：`writing/wb-doc-writing` · KB `## r709C`

### ③ 跨产物一致性：先有单一事实源，再写第二份材料
- 来源：`affaan-m/ECC`·`investor-materials/SKILL.md` 2,724B + `market-research/SKILL.md` 2,227B，逐串命中 `All investor materials must agree with each other` / `If conflicting numbers appear, stop and resolve them before drafting` / `Include contrarian evidence and downside cases` / `Separate fact, inference, and recommendation clearly`
- 方法：先盘点规范事实（数字/角色/时间线/金额/里程碑）→ 冲突停下来解决再动笔 → 每数回源、假设显式 → 四条红线（不可核验声明 / 无假设模糊市场规模 / 头衔不一 / 加不平）→ 研究型材料加"反方证据 + 陈旧数据标注 + 事实·推断·建议三分"。
- **提升层：工作流 + 工具**（多份材料并行时的真实风险是版本漂移，不是文笔）
- 落点：`engineering/wb-artifact-verification` · KB `## r709C`
