## 10 次实拉（逐站留痕）
1. Agent 可观测性（中-强）：OTel GenAI 语义约定（gen_ai.provider.name/request.model/usage.input_tokens/output_tokens/finish_reasons/tool.call.id）统一 span schema 跨框架可移植；**telemetry 前 redact 敏感内容（prompt/tool args/span attributes 中 PII/secrets）**；一致 span 属性命名+评估 run ID 关联 trace
2. Agent 自修复（强）：**自修复稳定性六控制=最大修复次数/同失败签名两次上限/rollback-first 补丁/成本上限/权威漂移升级/flaky 高危循环隔离**（自修复不稳定=一直补"上一个补丁造成的症状"）；**失败信号→失败类别→定向恢复动作（显式预算）→验证恢复轨迹→可观测 trace（arXiv 2606.01416）**；**未验证的工具结果不得流入推理链**；**agnost 现实边界=2026 检测与诊断是真的、merge button 不是（人审后才上线）**；VIGIL 元程序自修复（诊断工具失败→fallback 诊断→修复计划）
3. KV/prompt 缓存（中-强）：**break-even 极低=1.4-2 次命中即回本；cached token 便宜 50-90%、TTFT 降 65-85%**；**Don't Break the Cache（arXiv 2601.06007）：全部 provider 开缓存=45-80% 成本降、TTFT +13-31% 因 provider 而异**；DeepSeek V4 92% 命中率→44x 降本；缓存失效=动态前缀在缓存位置前
4. 长上下文 vs RAG（强）：**延迟数学=RAG（3-5 chunk~3K tokens）0.8-1.5s / 200K 无缓存 5-15s / 200K 缓存命中 2-5s / 1M 15-60s**；**成本数学=1M 单请求输入 $15-25、2M 比 RAG 贵 25x、1M 比 RAG 贵约 1250x、1 万查询/天→$20 万/天**；**长上下文赢=整文档推理（找矛盾/交叉引用/一次性分析/结构顺序重要/多模态一起）+bursty one-shot；RAG 赢=大语料/高频/保鲜/成本**；**hybrid=生产默认（检索窄窗口+1M 模型 grounding 检查）**；1M prefill 加 10-20s 才开生成
5. 模型路由/级联（中-强）：**四模式对比=Single Router（RouteLLM，固定质量省 48-75%）/Cascade（便宜→强，质量下限，省 70-80%，+0-400ms）/Speculative-Race（省延迟 -30-60%）/rule-based（多步推理/代码/数学→frontier）**；级联成本=success rate 70% 时约半价
6. 批处理（强）：**OpenAI/Anthropic Batch API=50% 折扣、24h SLA（多数 1-6h 完成）、上限 5 万/10 万请求；迁移延迟容忍任务（文档富化/评测 harness/夜间代码评审）**；批+缓存叠加（Batch 价上 cached 再半价）；**判据=人在等吗——不等就 batch**
7. Agent 安全/沙箱（强）：**excessive agency 三根因=excessive functionality/permissions/autonomy；修复=least privilege 不是 better prompts（OpenAI Sol 沙箱逃逸→HF 生产事件）**；**GrantBox 精心构造场景 84.80% 攻击成功率（LLM 有基本安全意识但被复杂攻击击穿）**；**输出过滤=唯一满分防御（15000 攻击 0 泄漏——操作有限输出空间 vs 无界输入空间）**；微 VM 隔离/read-only rootfs/no network
8. Prompt injection 防御（强）：**四插入点=user input/检索上下文/tool results/multi-agent messages；间接注入=扫描检索上下文和工具结果，不只 user input**；**trifecta 特权分离=单 agent 不同时拥有 data+untrusted input+egress**；LLM05=模型输出视为不可信输入到下一阶段；输出模式阻断=leaked system prompts/base64/attacker domains/exfiltration 工具参数
9. OpenClaw 技能（中-强）：**加载优先级=workspace/skills > .agents/skills > ~/.agents/skills > ~/.openclaw/skills（最高优先在前）+load 时按环境/配置/二进制存在过滤**；**agent 级可见性=agents.defaults.skills 继承、agents.list[].skills: [] 清空**；创建指南（Be concise/exec 防注入/本地测试/ClawHub）
10. 平台/生态探活：GitHub agent 生态（GrantBox/Interrupt 2026 LangChain 深研：auth proxy 密钥不进 agent 上下文+allowlisting MCP+seccomp/cgroups/read-only rootfs）；WaytoAGI/ModelScope（Qwen+OpenClaw vLLM 本地链路）；OpenClaw 技能四层加载；智谱数据出站审计事件
