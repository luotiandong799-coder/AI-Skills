## 三、提炼的核心方法与关键事实
1. **评估体系骨架**：golden dataset 100-500+worst-decile；offline=ground truth、online=benchmark 双跑。
2. **judge 工程**：五要素（criterion/calibrated examples/randomization/schema/self-consistency）；季度 Cohen's Kappa 校准；1 judge+1 deterministic 配对。
3. **质量门**：PR 触发 eval gate 与 main 基线比较；2-of-3 阈值+ties fail closed；模型升级 relocate evaluator 不淘汰。
4. **轨迹级评估**：完整轨迹 log（plans/tool calls/reasoning/side effects）；Trajectory Efficiency/Tool Call Accuracy/failure mode 分布。
5. **工具调用三 track**：AST/executable/irrelevance-detection；场景清单（ambiguous/revoked/stale/injection/duplicates/retries/rollback）；六指标全过才 pass。
6. **评估闭环**：confirmed failures 回灌 golden dataset；annotate traces→结构化数据集；单次运行全链路追踪。
7. **部署阈值按错误成本**：routine ≥95%/重要 ≥90%/<2% tool failures/零未授权动作。
