## 独点：输出不止文本——Generative UI 三形态选型 + 工具/状态渲染

**来源**：DeepLearning.AI《Build Interactive Agents with Generative UI》课程大纲（learn.deeplearning.ai，2026-09-18 实拉）+ CopilotKit docs（docs.copilotkit.ai 状态渲染/工具调用渲染，2026-09-16 更新）

**内容**：
1. **Generative UI Spectrum 三分类**：
   - **Controlled**：开发者完全控制 UI，agent 只提供数据
   - **Declarative**：agent 声明要什么组件/卡片/表单，开发者注册组件渲染器
   - **Open-Ended**：agent 自由生成布局
   - 判据：按可控性需求选——品牌一致性→Controlled；按需生成→Declarative；完全自由→Open-Ended
2. **Tool Call Rendering（工具调用渲染）**：不把工具返回的原始 JSON 甩给用户，注册组件画成品牌化卡片（参数+实时状态+最终结果）。判据：工具结果进 UI 前先问「这坨 JSON 用户怎么读」
3. **State Rendering（状态渲染）**：agent 每推进节点/发状态更新，前端实时渲染——进度条（Researching 2/5 complete）、进行中草稿、反映 agent 状态的 dashboard。判据：过程状态做成可实时渲染的结构化更新，不攒到最后一次性给结论
