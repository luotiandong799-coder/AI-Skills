## 四、提炼核心方法与关键事实

1. **eval-driven development**：先建 eval 定义能力再实现；定义 eval tasks=压力测试需求具体性。
2. **evaluate snapshots not conversations**：构造测试状态+追加 user message；打分含最终状态与末次工具调用参数。
3. **Judge 协议**：3-judge consensus≈97% F1；短 judge prompt（rubric 内联+正反例+裁决先行）；kappa 对齐人工；六平台指标每项过才通过；pointwise/pairwise/listwise。
4. **失败资产化**：failure map/eval misalignment（生产失败即 test case）；Eval Suite 四类（golden/boundary/regression/adversarial）；30 天买方测试；readiness scoring 四域；pass^k。
5. **观察层与断言**：observability≠evaluation；"done"是文本不是证据（断言独立 artifact）；no-op 路径；LLM observability 四元组；trajectory vs outcome。
6. **Skill 实证**：with/without 配对；Skill Lift；SWE-Skills-Bench 反例（39/49 零提升+451% token）；degradation tests 找悬崖；context strategies 同 test set 隔离。
7. **评估闭环**：Evaluator-optimizer；85%/3.5 告警阈值；runs 可复现；harbor 固定任务集+experiments+online evals；CI GitHub Action。
8. **Quality gates**：数值阈值控制部署阶段转换；无门禁=评估只是报告。
