## 三、三点落地

1. **技能要声明 operating modes**（skill-authoring KB，1.295.0→1.296.0）：guidance（只答被问的那块，不跑全流程、不建目录、不写产物）/ full（显式要求才跑全阶段并落文件）；"Loading it does not authorize the complete audit workflow or file creation"；模式不明先问一句；**先定模式再定交付清单**。**提升层：可复用 Skill**。
2. **覆盖率台账 + 二终态**（artifact-verification KB，2.442.0→2.443.0）：单元 = surface × boundary × attack class，侦察前建计划、每次返回更新、父级独占写权；prior run 四类状态逐条改判（源码变了必须重建单元、不得进排除名单）；scoped/quick 自报部分覆盖；**只许两个终态**（产物齐 + 校验器全过，或 incomplete + 具体原因），禁中途停。**提升层：工作流**。
3. **结论分级四档锚点**（doc-writing KB，1.17.0→1.18.0）：critical/high/medium/low/informational 各对应一种打穿程度；强弱判别问句"完全击穿了显式控制，还是只削弱了它"；**等级不得超过已证明的影响**；未验证不给等级。**提升层：工作流（评审与报告）**。
