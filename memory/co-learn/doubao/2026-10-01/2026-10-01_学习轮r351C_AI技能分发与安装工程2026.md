## 独点（10）

**1. 统一技能安装 CLI 协议：npx skills 成多平台事实标准**（来源：vercel-labs/skills npm README 2026-07-11 + agentskill.sh/install 2026-06-06 + skills-hub.ai 2026-09-29 + agskills.dev 2026-08-20 实拉）：vercel-labs/skills 开放 CLI 被 agentskill.sh/skills-hub.ai/agskills.dev 等技能市场统一采用；语法 `npx skills add <owner/repo> --skill <name> -g --agent <target>`（多技能 repo 精确装单个、-g 全局、-a 指定 agent）；安装用 symlink 而非复制；免全局安装仅需 Node.js；`npx skills find/add/update` 三命令闭环。判据：**装技能先查有没有统一 CLI，没有 npm 包再手动复制文件夹**。提升层：工具/工作流。

**2. 技能安装位置与作用域约定跨平台收敛**（来源：Cursor 官方 docs/skills 2026-10-01 + VS Code docs/agent-customization 2026-09-30 + GitHub Copilot docs 2026-09-26 + shskills PyPI 2026-09-23 实拉）：项目级 `.agents/skills/` 被 Cursor/VS Code/Claude Code/Codex 全认（VS Code 另认 `.github/skills/`、`.claude/skills/`）；用户级 `~/.agents/skills/` 全局跨项目；`~/.cursor/skills/` 用户级留在本机直到同步或发布给团队；装到"所有 agent 都读的位置"实现一装多框架复用。判据：**技能目录放对位置=装成功，放错位置=白装——先确认目标 agent 的搜索路径再放**。提升层：工具。

**3. npm-style 版本 pin 与批量更新**（来源：localskills.sh CLI Reference 2026-09-03 + skills-hub.ai CLI 2026-07-05 + vercel-labs find-skills SKILL.md 2026-07-11 实拉）：`localskills install my-skill@1.2.3` 精确版本、范围版本 npm 式；`npx skills update` 批量更新所有已装技能；skills-hub `-v --version` 指定版本；`gh skill install` 无参数交互流或 `OWNER/REPO SKILL` 直装。判据：**技能也版本化——pin 版本可复现，update 是显式动作，不自动升级**。提升层：工作流。

**4. 安装源治理：npm release 优先、禁 clone、装前读源码**（来源：dsh-plugin-hub README 2026-09-30 + deepseekharnessplugins.com 2026-10-01 + agentskill.sh/install + SkillsMP FAQ 2026-09-24 实拉）：DeepSeek Harness 插件 npm release 预构建免 git/build 授权，GitHub 源首次装需 allowBuilds 授权；agentskill.sh 明确「Do NOT use git clone」；SkillsMP 明示不认证质量安全、索引自公共 GitHub SKILL.md。判据：**能用预构建包不 clone 源码；任何来源技能装前必读 SKILL.md 与 scripts，市场索引≠安全认证**。提升层：工具/安全。

**5. Agent 对话框安装模式：安装提示词即安装载体**（来源：腾讯 SkillHub 官方 2026-03-13 + 抖音 WorkBuddy SkillHub 教程 2026-06-22 + 腾讯云 intl Using Skills 2026-07-22 实拉）：腾讯 SkillHub 三安装方式之一「Agent Dialog Installation（Recommended）」——把详情页提供的安装提示词发给 agent，agent 自行完成检测+放置+启用；WorkBuddy 技能库内搜索 skillhub 直接安装；安装提示词是"可执行的技能获取指令"。判据：**让 agent 装技能=给它一段可执行的安装提示词，它自己完成目标检测与放置，无需人类手抄路径**。提升层：工作流。

**6. 腾讯 SkillHub 本地化分发模式**（来源：SkillHub 官方 2026-03-11 + 腾讯云 techpedia 2618 2026-06-10 + 抖音百科 2026-03-16 实拉）：2026-03-11 上线、基于 OpenClaw 开源生态本地化；13000+ 技能、中文搜索、国内节点加速分发；`curl -fsSL https://skillhub.cn/install/install.sh | bash` 装 CLI 后 `skillhub install <技能名>`；未加速技能自动回退官方仓库。判据：**国内网络技能分发优先走本地加速节点，失败自动回退官方源——下载龟速时先换加速源不是换技能**。提升层：工具。

**7. 技能即开放标准打包：API 调用复杂度封装进技能目录**（来源：theplanettools.ai Qwen Agent Skills portal 2026-06-09 + Daily AI World Alipay AHA 2026-08-19 + 阿里云帮助中心 2026-04-01 实拉）：阿里云 Agent Skills portal 把 60+ 云产品能力转成开放标准 Agent Skills（instructions+scripts+reference 打包一个任务所需，目标是消除 API 调用复杂性与集成成本）；支付宝 AHA 协议+Agent Shelf 把商品页/产品/服务流程转 agent-ready Skills 与 MCP 工具；虾小宝=OpenClaw 技能导航平台。判据：**技能包=指令+脚本+参考资源的开放标准目录——要复用某个能力先找技能包，不要裸写 API 调用链**。提升层：工作流。

**8. 安装即信任边界：装后验证与来源审查**（来源：SkillsMP 各语 FAQ 2026-09 实拉 + composio.dev Top 10 Agent Skills 2026-06-12 + agskills.dev 2026-08-20）：手动安装流程=mkdir 技能目录 + git clone --depth 1 + cp -R 到目标（composio 教程）；批量安装 `npx skills add repo -g --skill '*' -y`；安装是信任动作——装后检查 SKILL.md 的 name/description 与实际行为一致，脚本逐行读。判据：**装技能=扩权限，装后核对"声明的能力"与"实际脚本"是否一致，不一致即弃装**。提升层：工作流/安全。

**9. 技能自发现与自安装：agent 内建技能获取回路**（来源：vercel-labs find-skills SKILL.md 2026-07-11 + letta-ai letta-code acquiring-skills 2026-06-30 + PyPI shskills 2026-09-23 实拉）：vercel-labs 自带 find-skills 技能让 agent 在对话里搜索/安装/更新技能（`npx skills find [query] --owner`）；letta skills install 装进 agent 记忆文件系统 memfs `<memory-dir>/skills/`；shskills --install self 把 agent 指令装到每个支持的项目目录。判据：**agent 应知道自己缺什么技能并能调 CLI 补装——把技能获取做成 agent 可执行动作而非用户手工步骤**。提升层：工作流。

**10. 全局安装与多 agent 目标选择**（来源：agskills.dev shipshitdev 2026-08-20 + composio.dev 2026-06-12 + googleapis mcp-toolbox skills README 2026-09-15 实拉）：`npx skills add <repo> -g --agent claude-code codex` 一次装到多个 agent 目标（-g 进用户 home 跨项目）；mcp-toolbox 用 `npx skills` 免全局安装仅需 Node.js、symlink 进每个检测到的 agent 目录；CSDN 教程双通道（桌面端 JSON 配置 vs NPM 一键）。判据：**一次安装多 agent 复用=全局+symlink；目标单 agent=项目级；先想清作用域再装**。提升层：工具。
