## 独点（10）

1. **RAG 四核心指标正交分工：faithfulness（答案声明可被上下文推导）与 answer relevance（答案回应提问）正交——忠实但跑题/切题但编造都可通过单指标；context precision（相关块排序靠前）与 context recall（检索覆盖 ground truth）分测检索**（来源：respan + confident-ai + arXiv 2601.22025）——四指标正交。判据：**四个都跑，单指标不能代表 RAG 质量**。提升层：工具。
2. **golden set 必须标注应检索文档而非只有答案：查询+期望答案+期望检索文档三元组，才能分开测 retriever recall 与 answer quality**（来源：theneuralbase）——文档标注。判据：**只有答案的 golden set 无法归因检索失败**。提升层：工作流。
3. **synthetic 测试集四质量门：faithfulness gate（答案必须 grounded）+diversity gate（按主题/长度/复杂度/意图覆盖语料）+difficulty gate（易中难按比例）+human spot-check（人工抽检 5-10%）**（来源：futureagi）——四质量门。判据：**四门全过才锁集，否则与生产行为不相关**。提升层：工作流。
4. **synthetic 生成反跑 RAG：知识库→LLM 提取关键事实→生成真实用户查询；生成后 30-50% 用真实查询替换**（来源：evidentlyai + webscraft）——反跑生成。判据：**纯合成集偏中心分布，真实查询补边缘**。提升层：工作流。
5. **judge 四偏差定量：positional（首选项 15-30% 偏移）/verbosity（长答案约 15% 膨胀）/self-preference（同族 3-10%）/sycophancy（附和题干前提）；缓解=换序+长度归一 rubric+跨族 judge+前提中立 prompt**（来源：aiworkflowlab + qaskills + adaline）——四偏差。判据：**四条缓解有研究背书：人工抽查校准/参考引导评分/meta-judge 单模型/不同供应商 judge**。提升层：模型。
6. **RAG judge 复合问题：只评最终答案会混淆 query understanding/retrieval/generation 三环节；fluency 与 faithfulness 正交，judge 常把流畅当忠实**（来源：respan）——复合问题。判据：**逐环节打分，不让一个 judge 包办全链**。提升层：工作流。
7. **faithfulness 可被模糊答案游戏：hedged/无断言答案 0 声明→得分 1.0；必须配对 completeness/coverage 指标**（来源：ai-tldr）——游戏化。判据：**单跑 faithfulness 有病理边 case**。提升层：工具。
8. **属性度量海市蜃楼：在 off-query distractor 池（无关主题检索块）上相似度度量 AUC 接近 1.000，换同查询 hard negatives（主题密集但无答案）崩溃到随机；评估集必须含 hard negatives**（来源：arXiv 2608.23252）——难负例。判据：**用难负例评估，不用易负例自欺**。提升层：工作流。
9. **NAG Acc 噪声注入鲁棒性：向检索集注入受控比例无关文档测生成器鲁棒性——20 百分 噪声注入平均降准确率 35 百分，可设容忍阈值**（来源：ragaboutit）——噪声注入。判据：**好系统应优雅降级忽略噪声**。提升层：工具。
10. **时间漂移盲区：语料过期（Q2 报告 vs Q3 可用）产生忠实但过时答案，无标准 RAG 指标检查 temporal validity；置信度无覆盖率=自信答案只用了部分上下文**（来源：layerlens）——时间漂移。判据：**补时间有效性检查与覆盖率检查，标准四指标不够**。提升层：工具。
