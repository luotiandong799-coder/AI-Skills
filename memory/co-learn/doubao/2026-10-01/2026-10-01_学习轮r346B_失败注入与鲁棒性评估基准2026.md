## 独点（10）

1. **ToolMaze 2×2 扰动分类：显式/隐式 × 瞬时/永久——显式（报错/超时/异常可见）vs 隐式（结果错误但格式正常，如负价格/缓存错误页）；瞬时（重试可解）vs 永久（需换路或放弃）；DAG 拓扑复杂度分离系统化重规划与盲目试错；隐式语义失败下降最陡，Perturbation Recovery Rate 掉约 37%，复杂拓扑困住 agent 进徒劳试错**（来源：arXiv 2606.05806 ToolMaze）——扰动分类。判据：**注入设计先按 2×2 分类；隐式语义失败是鲁棒性最弱象限；用拓扑复杂度区分重规划与试错**。提升层：工作流。
2. **AgentChaos：HTTP 层程序化故障注入（不侵入源码）——crash/omission/value 三类故障作用于 content 与 tool call 字段；65 故障配置下 pass@1 掉最多 50pp；鲁棒性排名跨模型一致=系统实现问题而非模型能力；验证每个故障确实触发以过滤未触发任务**（来源：arXiv 2608.06790 + developersdigest）——注入框架。判据：**鲁棒性排序看系统不看模型；在 LLM API 共享 HTTP 层注入；验证触发过滤**。提升层：工具。
3. **错误三分分类：Transient（重试+指数退避+抖动）/ Permanent（同结果必复现→fallback 简化方法/缓存/默认/人工）/ Critical（预算超支/破坏性副作用/安全违规→保存状态+告警+紧急停）——重试有害的类别绝不重试**（来源：taskade + myengineeringpath）——错误分类。判据：**先分类再行动；Permanent 重试 0 收益，Critical 重试危险**。提升层：工作流。
4. **鲁棒性四指标组：Recovery Rate（含至少一次瞬态失败后仍达成用户目标）/Error Identification Accuracy（推理正确命名错误类型）/Unrecoverable Failure Rate（死循环/崩溃/乱输出）/Perturbation Recovery Rate——洁净数据 pass@1 是危险乐观估计；分层测试集按工具×错误码建桶**（来源：AAAI 鲁棒性指标 + futureagi + arXiv 2606.05806）——鲁棒性指标。判据：**报告鲁棒性用四指标组而非单一成功率；按工具×错误码分层建测试桶**。提升层：工具。
5. **隐式（静默）失败是主要盲区：缓存错误页/负价格以预期格式到达被当作事实消费；Outcome Monitors 检测 outcome contract 违规，保留结果并发出非绑定 receipt（点名违规属性+公开恢复工具）；约束在"恢复可及性"而非诊断——剥离工具列表整体失效**（来源：arXiv 2608.19303 + agentpatterns）——静默失败。判据：**静默失败需契约监控+恢复可及性提示；诊断≠恢复，恢复工具映射必须显式**。提升层：模型。
6. **Bench2Robust：把无故障基准转成受控随机环境，情节显式要求 retry/switch/abstain 三策略；Bayesian Tool Memory（结构化运行期恢复上下文）+RL 互补恢复行为，结合达 40.8-45.5% 注入下提升同时保持无故障性能**（来源：arXiv 2608.11977）——恢复策略。判据：**恢复策略=retry/switch/abstain 三选一；显式注入 solvability 场景**。提升层：模型。
7. **MAS-FIRE：15 故障型（intra-agent 认知错误+inter-agent 协调失败），三种非侵入注入机制（prompt 修改/响应重写/消息路由操纵）；容错行为四层（机制/规则/提示/规划）；区分局部识别率 Lf 与端到端成功率 Sf——识别到故障但缺恢复策略=低 Lf**（来源：arXiv 2602.19843）——多 agent 注入。判据：**多 agent 评测同时看 Lf（识别）与 Sf（恢复后全局成功）**。提升层：工具。
8. **自愈编排 vs retry-only vs 全重规划：匹配恢复预算扫描下自愈每档最优（单次恢复预算 94.0% vs 85.3%/88.2%）；验证器引导的自愈把静默失败压到 0.0%（非验证基线返回"错误但貌似合理"输出）；失败类×信号×恢复动作×升级条件四列表格化**（来源：arXiv 2606.01416 + codex）——自愈编排。判据：**恢复预算固定时自愈最优；验证器是静默失败的天敌；四列表格管失败类**。提升层：工作流。
9. **ReflexGrad 进度门控双进程路由：快速进程（TextGrad 风格每 3 步局部梯度精修）+慢速进程（Reflexion 风格连续低分触发因果重规划），零样本同情节切换；Qwen3-8B ALFWorld 成功率大幅提升；冷却期让计划呼吸**（来源：arXiv 2511.14584 + papernotes）——双进程恢复。判据：**默认战术精修、进度停滞才战略诊断；加冷却期**。提升层：模型。
10. **ReliabilityBench 与 RL 测试循环：1,280 生产相似情节；四发现=复杂推理架构可能不如简单架构/重试逻辑关键/rate limiting 是最伤故障型/洁净 pass@1 危险乐观；六步循环=OTel 插桩→span 评分→CI 门禁→模拟→线上采样→失败上优化 prompt**（来源：arXiv 2601.06112 + futureagi）——可靠性循环。判据：**故障注入是生产可靠性唯一真来源；六步循环把测试做成 CI 门禁**。提升层：工作流。
