## 独点（10）

1. **LLM 网关实时评分路由：最近 5 分钟指标四因子加权 不用轮询 按 prompt 复杂度用户层级任务类型路由 简单问候小模型 专业问题强模型加专门 system prompt**（来源：LLM Gateway + Noqta）——网关路由。判据：**路由决策基于实时健康与任务复杂度，而非轮询**。提升层：工具。
2. **路由与故障转移分离：静态回退是基础 成本加权质量感知路由主动迁移流量 故障转移生产前 staging 模拟中断测试 验证切换透明 fallback 收到完整请求上下文**（来源：Context Studios + OpenRouter）——路由治理。判据：**failover 必须实测：staging 模拟供应商中断，验证完整请求上下文到达 fallback**。提升层：工作流。
3. **语义缓存工程：embedding 加 ANN 相似检索跨措辞命中 实践命中率 40 起 最优离线策略 NP-hard 用多项式启发式 在线策略结合 recency frequency locality 多轮语义缓存融合对话上下文 校准双层距离规则区分 hit novel out-of-domain**（来源：valuestreamai + arXiv 2603.03301 + ACM Higress）——语义缓存。判据：**语义缓存按含义匹配非文本匹配，多轮需会话分区防串上下文**。提升层：工具。
4. **语义缓存安全边界：相似度阈值权衡 precision 与 recall PII 动态数据个性化响应不缓存 多轮无显式会话分区安全低 失效需 reindex 或按向量 ID soft-delete 最佳用例开放式 helpdesk 静态 FAQ 而非固定工具调用**（来源：dev.to 语义缓存何时错 + 架构属性对比）——缓存安全。判据：**可缓存判定四问：含 PII 吗 动态吗 个性化吗 会串会话吗 任一答是不缓存**。提升层：工作流。
5. **虚拟键治理实体：per-key 消费上限限流模型白名单路由规则到达 provider 前强制 虚拟键解耦访问与 provider 凭证 属性化使用 吊销不需轮换 provider 键 每键限可达范围 每 team project customer 独立策略**（来源：Maxim + TrueFoundry）——虚拟键。判据：**无控制平面等于共享键无归属无审计等于影子 AI 虚拟键是治理主实体**。提升层：工具。
6. **prompt caching 计费经济学：cache write 1.25x 到 2x 基础输入率 cache read 0.10x 90 折扣 显式与隐式 cache 大重复上下文负载选有有效 prompt caching 的 provider 比选更低基础单价更重要 GPT-5.6 显式缓存精确控制缓存段 30 分钟**（来源：DigitalOcean + 阿里云 + GMI + AWS）——缓存计费。判据：**重复上下文负载先比缓存价格再比基础单价 write 贵 read 便宜故系统提示放缓存前缀**。提升层：工具。
7. **KV cache 复用实现：prefix caching 最长公共前缀 hash 匹配 vLLM 或 radix tree SGLang 前缀命中只算后缀 二次复杂度变线性 HotPrefix 热度感知调度两阶段过滤减 GPU host 传输 KV 复用 per-call 成本随 N 降到 Cload 下限**（来源：arXiv 2601.19910 + HotPrefix + arXiv 2606.13361）——KV 工程。判据：**缓存命中率是最重要 serving 指标之一 前缀一致是命中前提 稳定 system prompt 放最前**。提升层：工具。
8. **重试熔断背压分工：只重试服务端失败 5xx timeout 连接失败 不重试 4xx 内容过滤 熔断器前置 retry 5 连续失败 open 60 秒直接 fallback half-open 单探针 错误率超阈值停路由 fallback 必须在熔断器后面防 429 叠加 pod 级背压 529 Retry-After 不排队**（来源：LLM Gateway + llmapi + aiworkflowlab + leetmotion）——弹性模式。判据：**重试管瞬时 熔断管持续 背压管实例满 fallback 在 breaker 后面**。提升层：工作流。
9. **级联推理与 router 分工：cascade 先小模型 judger 评输出质量 阈值决定升级 约 80 查询小模型可处理 router 按 prompt 分类提前选模型等于猜测 cascade 按实际输出决定等于可靠 自评信心低于阈值升级 近零训练成本 vs classifier 需构造偏好数据**（来源：arXiv 2603.04445 + CASCADIA + 72tech）——级联路由。判据：**cascade 按输出质量升级而非按输入猜测 三档结构 50 45 5 覆盖 90 用例**。提升层：模型。
10. **多租户四点边界强制：检索按租户过滤索引 缓存按租户键 凭证按租户铸造 审计按租户分区 租户上下文在认证时附着并流经每个策略工具检索审计点 控制平面与无状态网关 pod 分离 网络隔离私有子网无公共入口**（来源：dev.to Azure 网关 + DeepInspect + TrueFoundry + 三层架构）——多租户隔离。判据：**租户边界在数据面四触点落地，不只认证层**。提升层：工作流。
