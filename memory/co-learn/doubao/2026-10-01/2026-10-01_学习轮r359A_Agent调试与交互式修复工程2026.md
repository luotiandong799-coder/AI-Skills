## 独点（10）

**1. Agent 化调试器（调试器暴露为 MCP 工具，agent 自主驱动断点/单步/变量检查/表达式求值）**（来源：JetBrains CLion 2026-07-31 + Spark/Visual Studio 2026-09-09 + LobeHub claude-mcp-debugger 2026-08-31 实拉）：IDE 通过集成 MCP server 把调试器暴露给外部 AI agent——agent 自己启动/停止调试会话、管理断点、单步执行、检查线程和变量、求值表达式；自然语言描述问题→agent 收集运行时证据→定位栈帧解释不了的问题；把编译器错误/警告共享给 agent 自动修构建诊断；Test Explorer 里跑单测、抓 flaky 失败并在调试器下调查；多语言支持（Python/Node/Java/browser JS，适配器首次用自动下载）。判据：**调试器暴露为 MCP 工具（断点/单步/变量/表达式），agent 自主驱动运行时证据收集，不靠人逐步代跑**。提升层：工具/工作流。

**2. Rewind/时间旅行回退（自动检查点+滚回对话与沿途文件改动；fork+replay 在同时间线验证补丁）**（来源：Anthropic Claude Code 2026-09-27 + agentoptics.dev Rewind 2026-04-15 实拉）："don't have to fix forward"——/rewind 把对话（含沿途文件改动）滚回更早点；checkpoint 自动无需设置（Esc 两次打开回退菜单）；agentoptics Rewind=Chrome DevTools for AI agents——record/inspect/fork/replay/diff/evaluate 同一时间线；rewind fix=AI 诊断失败+建议修复+可选 fork+replay 打补丁——一条命令从坏了到证明修好。判据：**回退=自动检查点+滚回对话与文件改动；fork+replay 在同一时间线上验证补丁（broken→proven 一步到位）**。提升层：工具/工作流。

**3. Replay 运行时上下文（失败瞬间全量 DOM/变量/网络状态可查询，免复现）**（来源：Replay 2026-06-02 + Replay Web Debug Bench 2026-04-07 实拉）：栈帧解释不了的 bug（竞态/水合不匹配/十次一挂的测试）——Replay 给 agent 运行时上下文：从失败时刻起的每个 DOM 状态/变量值/网络请求，可查询无需复现 bug；replay MCP+Claude Code/Codex 十分钟接好；Web Debug Bench=自动生成 agent 未见过的 web app 与问题（不同栈/类别），难度随 agent 能力提升自适应——多出的上下文让 agent 理解 bug 能力强很多。判据：**失败瞬间全量运行时状态可查询（DOM/变量/网络），免复现；调试基准自动生成+难度自适应**。提升层：工具/工作流。

**4. 事件日志化执行（每次执行=可倒带/fork/中间点重执行的追加日志；状态层+决策层双层快照）**（来源：Zylos 2026-06-20 + Antigravity 2026-05-07 实拉）：步 12 的坏 API 响应静默损坏工作记忆→步 47 才显形、证据已丢——agentic replay 把每次执行当事件日志可倒带/fork/任意中间点重执行（源自 event sourcing）；双层=State Layer（某时刻内部状态快照——记忆/上下文窗口/工具连接状态，可重放事件日志前向验证）+Decision Layer（模型决策的推理上下文——完整 prompt/工具 schema/温度 seed/生成文本/理想 logprobs——模型是黑盒就成对保存输入输出）。判据：**调试=事件日志化（倒带/fork/中间点重执行）；状态层快照前向验证、决策层成对保存输入输出**。提升层：工具/工作流/可复用 Skill。

**5. Trace-first 调试环（先 trace 后追责；每 incident 留永久工件防同回归二次上线）**（来源：DEV trace-first 2026-09-21 + CallSphere 2026-05-05 + wearecleon 2026-06-01 实拉）：agent run 退出码 0 但 diff 删了 400 行——trace first, blame later；闭环=Locate（按用户/会话 ID/时间戳找产生坏输出的精确 run）→Reproduce（拉 trace 输入本地重放同模型+工具、确定性确认或刻画方差）→修复→每个 incident 留永久工件（dataset row）——同一回归不能二次上线；没 trace 的 agent=靠迷信调试（tracing gap 先补再谈别的）。判据：**调试环=先定位 trace→重放复现→修复→留永久数据集工件；无 trace=迷信调试**。提升层：工作流/可复用 Skill。

**6. 最小复现自发散点（定位发散步+重建前步上下文；错误传播视图标继承失败态的父 span）**（来源：OpenLegion 2026-07-01 + addyosmani agent-skills 2026-09-15 + FutureAGI 2026-05-14 实拉）：trace replay=重放失败生产 run 的确切输入（同 system prompt/同对话历史/同工具结果）而非手动重建场景；定位发散点（20 步中步 14）后从步 14 开始、用步 13 重建上下文做最小复现——不跑全 20 步；错误传播视图=工具 span 失败常不在工具 span 显示、而在顶层 agent span 出现错答案——点击失败 span 标记每个继承失败态的父 span 和成功兄弟 span；复现纪律=失败可靠发生→不能复现则收更多上下文/最小环境→真不可复现记录条件+监控。判据：**最小复现从发散点+重建前步上下文开始；错误传播视图标继承失败态的父 span**。提升层：工作流/可复用 Skill。

**7. 确定性鸿沟（温度 0 ≠ 可复现：GPU/MoE 非确定性→重放性观测；静默错误仅对比期望输出可测）**（来源：Microsoft sean-weldon 2026-07-02 + Zylos 2026-04-30 实拉）：生产 agent 非确定性失败挑战传统调试——温度 0 与同 prompt 同配置仍不可复现（GPU 非确定性、batch invariance、MoE 架构使 hosted API 无法逐位确定）→replayability-based observability；静默错误（任务完成/结果合理/无错误信号但输出错——系统性误分类/未标缺失记录/自信引用不存在来源）trace 无异常（全 span 成功、延迟 token 正常）——仅能靠对比期望输出检测。判据：**温度0≠可复现（GPU/MoE 非确定）→重放性观测；静默错误仅对比期望输出可测**。提升层：模型/工作流。

**8. Trace ID 贯穿（错误信息带 Trace ID→一条命令捞完整会话；生产 trace 转 dataset+eval 防复发）**（来源：腾讯云 2026-05-21 + Codeables 2026-04-12 实拉）：错误信息含 Trace ID（Error: LLM response parsing failed Trace ID: 3a7f9b2c）→grep "trace_id: 3a7f9b2c" agent.log 或 jq select——一条命令捞出完整执行记录；生产失败无法 dev 复现→捕获完整生产 trace（非仅日志）+精确重放时间线→转成 dataset 和 evals（LangSmith 端到端 observe/reproduce/evaluate/fix）——不修一次了事，把失败行为提取进数据集防再次上线。判据：**Trace ID 贯穿错误信息，一条命令捞全程；生产 trace 转 dataset+eval 防复发**。提升层：工具/工作流。

**9. Reviewer/Fixer 角色不对称（审查者只读、修复者有写：捕获→复现→隔离→最小修复→验证）**（来源：OCDevel 2026-06-21 + BestAIWeb 2026-05-21 实拉）：reviewer 是冷批判（只读无 Edit）、fixer 是调试子代理（Read/Edit/Bash/Grep/Glob）——任务=捕获错误与栈、复现、隔离、最小修复、验证；指令=修根本问题不修症状；reproducible multi-file 跨组件 bug→Debug Mode（agent grep 代码库+运行时日志埋点+端到端验证修复；Cursor Composer 2.5 在 SWE-Bench Multilingual 79.8%）。判据：**审查者只读/修复者有写，修复=捕获→复现→隔离→最小修→验证（修根因非症状）**。提升层：工作流/可复用 Skill。

**10. VCR/ghost replay（任意步时间旅行+状态快照+编辑恢复+成功回放省成本；fork-改-级联重执行验证假修复）**（来源：Geek Salad 2026-05-10 + ProductCool Retrace 2026-07-02 + sapirex 2026-08-19 实拉）：Agent VCR=时间旅行任意执行步+全状态快照+编辑并从特定帧恢复（纯本地无 API key）；session forking 平行实验；ghost replay 保存成功 run 即时回放降成本；Retrace=选 trace 中任意 span 改输入（prompt/工具参数）fork→级联从 fork 步重执行保全文上下文——测试假修复无需从头跑；prove-the-fix=fork+改+验证；LangGraph get_state_history=每 checkpoint 唯一 checkpoint_id/state dict/配置/parent 引用——完整可见 agent 记忆演进。判据：**VCR=任意步时间旅行+状态快照+编辑恢复+成功回放省成本；fork-改-级联重执行验证假修复**。提升层：工具/工作流。
