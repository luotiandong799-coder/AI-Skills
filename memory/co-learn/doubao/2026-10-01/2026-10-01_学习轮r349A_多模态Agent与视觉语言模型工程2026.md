## 独点（10）

1. **桌面 GUI 代理视觉管线：1920 乘 1080 截图加坐标归一化到内部 1000 乘 1000 网格加预测坐标投影回物理像素 4K 原图直接喂模型 token 膨胀延迟恶化**（来源：dev.to agdex）——坐标网格。判据：**归一化网格推理、投影回物理像素执行，不在原始分辨率上推理**。提升层：工作流。
2. **VLM 统一多模态取代碎片栈：30B-A3B 单模型统一视觉音频文本推理 Nemotron 3 Nano Omni 避免多模型间传数据丢上下文 或 Gemma 3 编排加专用视觉推理模型分工**（来源：nvidia blog + nvidia gtc26）——统一与分工。判据：**要么单模型统一、要么明确编排者加视觉推理者分工，不做无编排的碎片栈**。提升层：模型。
3. **视觉 token 压缩：语义显著性预算或训练无关剪枝 576 到 32 token 保持性能 或未变化帧自适应剪枝 Adaptive EVS 压缩 88 到 95 百分 FLOPs 保 95 百分加精度**（来源：arXiv 2603.14892 + LoWi + nvidia VSS）——视觉 token 预算。判据：**视觉 token 是 VLM 最大成本项，先压它再谈上下文**。提升层：工具。
4. **多模态幻觉 token 级检测：Attention Dispersion Score 幻觉 token 注意力弥散 vs 真实对象紧凑 加 Cross-modal Grounding Consistency 细粒度检测优于全局分数**（来源：arXiv 2604.04863）——token 级接地。判据：**用 token 级注意力度量定位幻觉，不用全局分数**。提升层：工具。
5. **视觉谄媚 69.6 百分：VLM 三因素诊断 潜在异常检测 加 视觉必要性 KL 加 竞争分数 盲图噪声图冲突图反事实干预分离幻觉来源**（来源：arXiv 2603.18373）——视觉谄媚。判据：**盲图噪声图冲突图反事实干预分离幻觉来源**。提升层：工作流。
6. **视觉 RAG 分块：VLM 生成表格与图摘要进索引 多模态摄取 加 200 到 400 DPI 栅格化页面索引 加 三级标题结构保持语境位置**（来源：arXiv 2607.24799 + 2608.26091 + 2506.16035）——多模态索引。判据：**图与表先转文本摘要或栅格化再进检索，纯 OCR 丢结构**。提升层：工具。
7. **视觉 token 查询路由：Query Complexity Router 按难度选检索与推理路径 加 Perception-Reasoning 解耦 轻量 VLM 转视觉线索为文本 LLM 只做推理**（来源：arXiv 2603.05551）——感知推理解耦。判据：**视觉翻译与逻辑推理分模型，小 VLM 翻译大 LLM 推理**。提升层：工作流。
8. **多模态 embedding 统一空间：文本图像视频文档映射单空间 Gemini Embedding 2 或 Qwen3-VL-Embedding 或 WeMM 融合嵌入多输入一向量**（来源：blog.google + alibaba + arXiv 2608.24053）——统一嵌入。判据：**检索跨模态先选原生多模态 embedding，不用文本 embedding 硬编码图**。提升层：工具。
9. **GUI agent 安全双通道分类：视觉点击目标加推理文本各自对照知识库 任一通道风险即阻断 互补失效模式 视觉查目标不匹配 文本查危险意图**（来源：arXiv 2603.14707）——双通道守卫。判据：**守卫在感知回路外独立跑，不只信 agent 自己的判断**。提升层：工作流。
10. **多模态 agent 评测状态验证：ClawMark 1537 确定性 Python checker 查执行后服务状态 无 LLM 判定 加 AgentVista 最优仅 27.3 百分 长程多模态工具用还远未解决**（来源：arXiv 2604.23781 + 2602.23166）——状态验证评测。判据：**用执行后状态确定性验证，不用 LLM 打分；长程任务别高估 SOTA**。提升层：工作流。
