## 独点（10）

**1. 运行时 guardrail 与离线评测分工；六种不可协商 guardrail**（来源：FutureAGI《AI Compliance Guardrails for Enterprise LLMs: 2026 Playbook》2026-05-14 + FutureAGI glossary《What Is an AI Guardrail?》2026-05-23 实拉）：guardrails=包在每个 LLM 调用外的输入/输出过滤器，**区别于离线评估**；pre-guardrails 在模型看到输入前查 prompt injection/PII/jailbreak 模式，post-guardrails 在用户看到输出前查 toxicity/泄露 PII/离题/幻觉事实；每个策略检查毫秒级决定 allow/block/rewrite/escalate 四动作。六种不可协商：PII redaction、prompt-injection blocking、toxicity、hallucination check、off-policy refusal、decision-trace logging。判据：**评估管"模型行不行"，guardrail 管"每次调用放不放行"——两个层都要建，只评测不上护栏是上线事故**。提升层：工作流。

**2. 三层控制映射 OWASP/NIST：Input 与 Processing 分层**（来源：dexity《Responsible AI in Production 2026》2026-08-17 实拉）：Input 层=注入检测+PII redaction+allowlisted RAG 来源+请求限流，映射 OWASP prompt injection(#1)/sensitive info disclosure(#2)+NIST Manage；Processing 层=最小权限 IAM+工具审批工作流+有界 token/计算预算+system-prompt 隔离，映射 OWASP excessive agency/unbounded consumption/system-prompt leakage+NIST Govern/Manage。判据：**每个安全控制必须能指到具体威胁编号**——说不清防哪个威胁的控制大概率是摆设。提升层：工作流。

**3. 防篡改审计链工程：receipt 签名链 + IETF AIVS 归档 + action lineage**（来源：Asqav《Regulatory and Standards Alignment》2026-09-30 + IETF draft-stone-aivs-00 2026-03-25 + DeepInspect《AI Agent Security: From Identity to Action Lineage》2026-08-20 实拉）：每个审计收据服务端 ML-DSA-65 (FIPS 204) 签名、密钥在 agent 环境外，per-agent previousReceiptHash 链让删除/重排可检测；IETF AIVS=gzip tar 自验证归档（SHA-256 hash 链审计日志+Ed25519 签名+机器可读 manifest+嵌入式验证脚本仅需 Python 标准库）；action lineage 重建完整遍历：user 授权→goal→prompt→分类→策略→结果→下一步。判据：**审计链的签名与链式哈希必须放在 agent 环境之外生成/持有**——agent 自己签自己的账等于没签。提升层：工具/可复用 Skill。

**4. 审计日志合规量化：SOC2 CC7.2 单条事件纪律 + EU AI Act 时间线**（来源：OpenLegion《AI Agent Audit Log》2026-06-01 + EU AI Act Service Desk Article 26/Article 12/Article 16 2026-09 实拉 + Alice Labs《Enterprise AI Security in 2026》2026-05-23）：SOC2 CC7.2=每个工具调用必须单独日志条目（agent_id/时间戳/工具名/完整参数/结果），聚合指标（过去一小时 100 次）不满足；保留≥1 年（Type II 审计期 6-12 个月）；trace ID+parent step reference+action type+inputs/outputs+timestamp 因果链支撑调查。EU AI Act：高风险 AI 义务 2026-08 生效、罚款最高 €30M 或 6% 全球年营业额；Art26 部署者保留自动生成日志≥6 个月；Art12 防篡改日志 2026-08-02 强制执行；provider 注册 EU 数据库+文档留 10 年；Prohibition 9 于 2026-12 生效。判据：**日志够不够审计，问一句"能不能定位到某一次具体工具调用"**——能才算事件级，不能说"大概一小时一百次"。提升层：工具/工作流。

**5. DLP 2026 四大新泄漏向量与七执行动作**（来源：AI Buzz《AI Data Loss Prevention for ChatGPT & Copilots》2026-09-14 + Nightfall《Best AI Agent Security & MCP Security Platforms for DLP in 2026》2026-07-02 + Strac《DLP Features 2026》2026-09-02 实拉）：四大向量=MCP 连接/多模态 AI 输入/AI 会议 copilot/浏览器扩展生态，legacy DLP 全检测不到；现代 AI DLP 在交互点检查 PII/PHI/PCI/secrets/IP；端到端数据血统跟踪（数据从源头到 AI 工具目的地单架构）；enforcement 七动作=Block/coach/redact/delete/revoke/quarantine/encrypt；inline blocking 而非 alert-only。判据：**DLP 检查点放在"数据进入模型上下文之前"的交互点，不是事后扫日志**。提升层：工具。

**6. PII 掩码三分法与检测四层**（来源：MetaCTO《PII Redaction in LLM Pipelines》2026-06-17 + TrueFoundry《PII Redaction 网关 vs 应用层》2026-07-04 实拉）：掩码三策略按用途选——Mask（[REDACTED] 占位符）用于单向往日志/向量嵌入/遥测/训练数据；Pseudonymize（稳定不可逆合成值 Person_a3f2）用于模型需跨轮跟踪 referent 但永不见真值；Reversible tokenize（不透明 token+vault 映射出口恢复）用于用户需要看原值而模型与下游不需要。检测四层按延迟选：Regex+验证（结构化 PII 亚毫秒）/Shannon 熵滑窗（无固定模式 secrets/tokens 1-2ms）/NER transformer（名称组织地址数十 ms）/外部 PII API（复杂域文档 100-200ms）。判据：**先定数据流向再选掩码策略——会回流到用户的用 tokenize，只进日志的用 Mask，要跨轮指代的用 Pseudonymize**。提升层：工具。

**7. 跨轮 PII 保护：CAMP 追溯伪匿名化 + SurrogateShield 类型一致替身**（来源：arXiv 2604.16521《CAMP》2026-09-16 + arXiv 2606.29567《SurrogateShield》2026-08-26 实拉）：CAMP=CPE 分数超阈值→对全对话历史追溯伪匿名化，真实 PII 换一致合成替身后再转发外部模型，去掩码层在响应返回用户前恢复，外部模型全程只见合成身份；SurrogateShield=客户端代理在传输前把 PII 换成类型一致替身并在响应恢复，三阶段级联检测 PatternScan/EntityTrace/ContextGuard 覆盖 22 类 PII，真实 PII 不跨网络。原则=不发送 LLM 工作不需要的敏感数据。判据：**跨轮场景只掩单轮会漏——历史上下文里上一轮的真值仍会泄露，必须追溯整条历史一致替换**。提升层：工作流/工具。

**8. sandbox 三资源边界 + 凭证隔离 + 非特权沙箱**（来源：Architect View Master《Sandboxed Agents》2026-05-06 + NVIDIA OpenShell DEV 2026-09-30 + arXiv 2605.26298《Sandlock》2026 + Awesome Agents《Best Agent Sandbox Tools 2026》2026-04-19 实拉）：沙箱边界三资源=文件系统/网络/CPU 内存；凭证隔离=agent 永不见真实 API 键/token，凭证在沙箱外持有仅按需注入；Sandlock=非特权 Linux 进程沙箱（静态输入无关策略编译进内核强制规则+窄 supervisor 管运行时决策，无 root/cgroups/images/namespaces，TOCTOU-safe execve 检查）；gVisor 用户态内核全拦截但 10-30% I/O 开销，Membrane=Docker+eBPF sidecar+DNS 白名单（按 hostname 非 IP）；2026 已确认三起沙箱逃逸（含 OpenAI agent 破坏 containment 黑外部目标）；1/8 AI 安全事件涉 agentic 系统（HiddenLayer 2026）。判据：**三资源边界缺一个，沙箱就只是个目录**；凭证隔离与沙箱是两件事，只隔离执行不隔离凭证等于白搭。提升层：工具。

**9. AST10 记忆防护五条 + 技能写记忆先隔离验证 + 短时作用域委派身份**（来源：OWASP Agentic Skills Top 10 白皮书 V1 2026-03-01 + Modulos《OWASP Top 10 for Agentic Applications 2026》2026-07-30 + wowhow.hashnode.dev 2026-05-02 实拉）：AST10（ASI01-ASI10，2025-12-09 发布 2026 版）是 Agentic Skills 层十大风险；记忆防护五条=加密+内容验证（新记忆写前扫恶意/敏感内容）+分段（用户会话/主题隔离）+访问与保留最小化（仅可信来源可写、按任务限访问）+血统与异常标记（记录记忆来源、标记异常更新）；关键：技能写的 MEMORY.md/SOUL.md/向量存储更新必须先隔离验证再提交——签名干净、声誉好的技能装完后仍可能投毒记忆；身份工件（SOUL.md/MEMORY.md）限制读写+签名版本控制；ASI07 供应链=委派时派生唯一短时作用域身份（token 仅限子任务动作+TTL≤预期完成时间）；ASI10 rogue agents=per-agent telemetry 对比行为基线+异常告警+kill switch+隔离编排防冒充审批；三 artifact 需映射（LLM Top10/Agentic Top10/粒度威胁分类），每项预防/检测/监控三列控制。判据：**记忆写入必须过"隔离验证再提交"关卡——不信签名、不信来源信誉，只信写前扫描**。提升层：可复用 Skill。

**10. 观测侧敏感数据最小化：typed placeholder + retention 表 + tail sampling + ZDR**（来源：valuestreamai《AI Logging and Observability 2026》2026-05-09 + Kunal Ganglani《LLM Data Leakage Playbook 2026》2026-09-06 + regolo.ai《Zero Data Retention》2026-08-26 + AI/TLDR《Trace Sampling》2026-06-13 实拉）：redaction 用带类型占位符（[EMAIL]/[NAME]/[ACCOUNT_NUMBER]）让日志可调试又不含 PII；retention 分级表（caches 24h/24h/1h/0h，analytics 90d/30d/0-7d 仅聚合/0d）；tail sampling=100% error trace+100% 低分/高成本 trace（P95 延迟或 token 阈值之上）+1-10% 随机基线；OTel custom span processors 在导出前编辑；**sampling≠anonymization**——保留的 trace 仍含 PII，需配对保留窗口+捕获时编辑；ZDR 只记非内容遥测（timestamp/status/时长/token 数/API key 标识符），提示词哈希化。判据：**明文存储是负债——能哈希的不存明文，能聚合的不存明细，能删的不留**。提升层：工具/工作流。
