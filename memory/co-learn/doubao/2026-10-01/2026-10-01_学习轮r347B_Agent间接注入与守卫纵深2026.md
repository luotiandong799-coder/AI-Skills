## 独点（10）

1. **间接注入五攻击面（RAG 文档/agentic 浏览/MCP 工具元数据/邮件与消息摄取/代码审查 agent）；标准输入分类器与限流无效——payload 走受信摄取通道到达；需架构级控制（spotlighting/信息流控制/信任级标签/最小权限工具作用域/critic agent）**（来源：securetom + cybersecify + agentmelt）——五攻击面。判据：**防御在架构层不在输入层；受信通道本身可携带 payload**。提升层：工作流。
2. **Dual-LLM 隔离三实现：Twin Agent 探索-执行分离、Explore 只发压缩 hint 给 Safe Agent；DualView 把不可信数据替换成符号、T-LLM 只见符号、工具调用时主机解析回原文；catalog 五组件=特权 LLM/隔离 LLM/主机编排器/符号句柄存储/工具运行时**（来源：arXiv 2607.19595 + arXiv 2607.03821 + agentpatternscatalog）——双 LLM 实现。判据：**特权模型永不看原始不可信文本；符号替换把提示挡在模型外**。提升层：工作流。
3. **spotlighting 家族三档：delimiting（随机不可预测分隔符，防可猜测标签被闭合）/datamarking（特殊 token 穿插全文）/encoding（base64 编码不可信块，模型可连续区分数据与指令）；极限=XML 标签/格式化无内在权威，只让意外执行更难不阻止定向攻击**（来源：arXiv 2403.14720 + theneuralbase limits + aicassindra）——spotlighting。判据：**标签无权威；越强变换越接近"数据不可读"**。提升层：工作流。
4. **输入侧预处理：NFKC 归一化（homoglyph）+剥零宽字符（U+200B/C/D、U+2060、U+FEFF）+剥 Unicode 标签块（U+E0000-U+E007F 每个 ASCII 字符映射一个 tag 字符）+BiDi 控制字符检测；检测规则=5+ 连续零宽/BiDi 控制字符即标记混淆；零宽二进制编码（U+200B=0/U+200C=1）可实现整条隐藏指令**（来源：aitoolsguidebook + agentthreatrule 00276/00002 + arXiv 2603.00164）——预处理。判据：**预处理是可确定剥离；无法可靠"清洗"自由文本注入，靠包裹与拒绝**。提升层：工具。
5. **记忆投毒命名攻击谱系：MINJA 95% 注入成功率、AgentPoison、Sleeper Memory、Memory Control Flow、MemGhost 单封钓鱼邮件 87.5% 后门；与提示注入区别=跨会话持久、时间解耦（写与效应分离）**（来源：christian-schneider + vectorize + beyondscale memghost）——攻击谱系。判据：**持久化状态=未信任输入；写-读循环要打断**。提升层：工作流。
6. **记忆防御实测对照（Trojan Hippo）：user-prompt-only 写入=ASR 0-5%（代价=丢助手输出与工具返回回忆）；不可信会话不写=0-5%；80 字符长度上限=15-30%（payload 能塞进）；可证明 IFC 污点策略=0%（但阻断收件箱会话的合法 send_email，调和均值效用≈0）；无免费修复，防御匹配任务分布**（来源：agentpatterns trojan-hippo×2）——防御对照。判据：**防御强度与合法功能损失同向；对照表选防御按任务分布**。提升层：工作流。
7. **SMSR：签名记忆+平滑检索，首个带认证鲁棒界的运行时记忆投毒防御——HMAC-SHA256 出处认证+平滑化使对抗扰动需同时破坏签名与检索；静态语料防御（RobustRAG/ReliabilityRAG）不覆盖动态多会话，启发式过滤被流畅企业文本绕过**（来源：arXiv 2606.12703）——SMSR。判据：**认证+平滑双保险；静态语料防御对 MSMP 无效**。提升层：工具。
8. **输出侧系统提示泄露检测四手段：canary 令牌（输出/工具参数中出现即泄露信号）/响应侧哈希比对（流式分块粒度）/工具参数检查（参数匹配系统提示片段=工具调用泄露模式）/输出过滤（base64 载荷/攻击者域链接/凭据模式）；设计上假设泄露不可避免，防护=分权（少放秘密）而非禁泄**（来源：deepinspect + beyondscale + promptgenius + AWS）——泄露检测。判据：**泄露检测按输出与工具参数双通道；假设泄露必然发生**。提升层：工具。
9. **工具调用治理三层：结构化输出/约束解码（严格 schema、free-form JSON 是静默损坏源）/高危操作 HITL gate（financial/destructive/communication/permission-altering 类必须人类确认，模型建议≠用户授权）/DAS Finality Token（人类批准转成受保护的、动作特定的终局谓词，绑定 act 类型/预测后果/批准角色/政策纪元）**（来源：anthale + agentthreatrule 00099 + IETF draft-das）——调用治理。判据：**无确认证据即不放行高危类；批准是受保护谓词不是口头确认**。提升层：工作流。
10. **运行时熔断两类触发：成本速度熔断（tokens/分钟超阈值，参考实现 10k/min 抓到失控循环）vs 上限熔断（绝对预算）；电路断路器=监控层检测异常行为/成本超支/失控循环实时停机；硬件看门狗（NVIDIA Sentry 在 BlueField-4 DPU 上盯 agent 出界）+软件沙箱（OpenShell 限允许动作）双层**（来源：getreadyforagents + baeseokjae + capsule 98% StepShield + nvidia platform）——运行时熔断。判据：**速度熔断抓"异常快"，上限熔断抓"总量超"；看门狗在数据面不在控制面**。提升层：工具。
