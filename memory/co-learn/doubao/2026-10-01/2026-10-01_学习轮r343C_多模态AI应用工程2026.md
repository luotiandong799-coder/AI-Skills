## 独点（10）

1. **VLM-native vs OCR-pipeline 选型判据（2026 差距闭合）：VLM-native 赢场景文本（手写+印刷+混合脚本）/复杂表格合并单元格/文中数学公式/带文本标注图；OCR pipeline 仍赢大规模纯扫描（每页延迟关键）/确定性失败 vs VLM 幻觉/监管合规——按场景分流不二选一**（来源：yennj12）——文档理解选型。判据：**高延迟敏感或合规场景走 OCR 管线；复杂版面/混合内容走 VLM**。提升层：工具。
2. **视觉文档提取生产模式：图→VLM 提取 JSON→schema 验证→有效且高置信持久化/低置信进人工复核队列→复核内容成为微调专家模型训练数据——置信度门控路由，复核队列是训练数据来源**（来源：pdpspectra）——提取流水线。判据：**结构化提取必须过 schema 验证+置信度门控；低置信转人工**。提升层：工作流。
3. **多模态提取 prompt 纪律：引用布局（"right sidebar"）而非"这个截屏"；先提取事实后解释；要求 format JSON/table/checklist/pass-fail；显式标注 uncertainty（文本/layout 不可读时）——prompt 是视觉文档 AI 最重要变量，模糊指令产生不一致结果**（来源：aisrc + ai-tldr）——多模态 prompt。判据：**视觉提取 prompt=明确任务+显式输出格式+JSON schema 示例+uncertainty 标注要求**。提升层：模型。
4. **高精度表格提取两遍法：第一遍检测表区域提取为 HTML（比 Markdown 保留 rowspan/colspan 更好）→第二遍验证 HTML 结构（列数相等/无孤儿单元格）失败换 prompt 或模型重提取——表格结构验证闭环**（来源：mixpeek）——表格提取。判据：**复杂表用 HTML 格式+两遍验证（结构校验+失败重提）**。提升层：工作流。
5. **ColPali late-interaction 视觉文档检索：文档 VLM per-patch hidden states 投影 128 维，MaxSim 对查询 per-token 嵌入；一页约 1030 向量；无 OCR/无布局检测/无分块；ViDoRe 击败最佳 pipeline——视觉检索可跳过 OCR 直建索引**（来源：bthek1 + arxiv 2606.25343 SigLIP+OpenCLIP 双编码器集成恒优于单一）——视觉检索。判据：**文档检索可选 late-interaction（patch 级）免 OCR；多视觉编码器集成优于单一**。提升层：工具。
6. **multimodal RAG 架构选型：hybrid late-fusion（并行文本+图像索引、BM25+dense、RRF 融合、VLM reranker）最灵活混合语料最佳召回但最复杂；小语料单索引快赢；答案真在像素里且召回是硬约束时上视觉专用（架构 3）；UniDoc-Bench 证据：文本+图像统一嵌入联合检索优于分开检索**（来源：bigdataboutique + openreview UniDoc-Bench）——图文 RAG 架构。判据：**混合语料用 late-fusion 双索引+RRF；像素级答案用视觉专用检索**。提升层：工具。
7. **VLM 四类幻觉分类学（SHROOM-Visions）：Invention（提图中没有的实体/属性/事件）/Mischaracterization（可见内容描述错）/OCR Problem（读错文字）/Miscounting（数量报错）——逐字符检测定位；FREAK 量化：最强模型 45.49% 准确（人类约 85%）、多数 30-43%——幻觉是常态非异常**（来源：arxiv 2608.25662 + FREAK）——幻觉分类。判据：**VLM 输出按四类幻觉逐字符扫描；高准确性任务不过度依赖 VLM 裸输出**。提升层：工作流。
8. **VLM 三个具体盲点：对象计数>4 即失败、小对象（<5% 面积）幻觉率超 60%、复杂表丢行-列关系——修复：路由到聊天 VLM 前先过专用检测器预处理（对象检测/OCR/表格结构）**（来源：ragaboutit + cacm + arxiv 2606.28322 GUI 是感知失败主导源）——VLM 盲点。判据：**计数/小对象/表格任务先专用模型预处理再进 VLM；不裸用 VLM 当检测器**。提升层：工具。
9. **confident misgrounding + context degradation 两新失效：流畅结构化响应错误链接到错误对象/区域（最危险）；长上下文窗口靠前图像注意力变弱（视频开头更多错误）——长图文任务把关键图像放靠后/重注入**（来源：cacm）——VLM 失效模式。判据：**关键视觉证据避免塞长上下文最前；高风险输出做视觉接地验证**。提升层：模型。
10. **VLM 不确定性校准：Ensembles（5 模型投票）UNC F1 0.491 vs 通用 VLM 0.163-0.205——集成显著优于单体不确定性校准；低 CER 不足（benchmark 改进可能反映语言规律利用非忠实恢复）；盲/误导时行为可靠性单独评测（SciFigBench 感知/推理/行为可靠性三方面）**（来源：papernotes + arxiv 2607.24077 + arxiv 2608.13267）——不确定性。判据：**OCR 结果要求不确定性校准（集成/置信度）；评测含视觉证据缺失/误导的行为可靠性维度**。提升层：工作流。
