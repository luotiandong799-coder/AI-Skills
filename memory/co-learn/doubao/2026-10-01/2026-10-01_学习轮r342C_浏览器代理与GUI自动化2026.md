## 独点（10）

1. **grounding 是主导失败源：意图→精确屏幕目标（元素或像素坐标）映射——页面几十相似元素/标签歧义缺失/同视觉按钮多嵌套 DOM 节点/截图无干净 handle；语义选择器（role+name）不坐标/绝对 xpath**（来源：vibeengines + hub.cissychen）——grounding 与定位器。判据：**元素定位用语义选择器（getByRole/getByLabel，抗 CSS 漂移）；不靠像素坐标/绝对 XPath**。提升层：工具。
2. **感知三通道选型：DOM 提取（快 token 高效，canvas/复杂 SPA 失败）；accessibility tree（结构化语义，跨站无需 per-site selector，快于截屏）；screenshot grounding（视觉定位，DOM/a11y 不可靠时用但每步 token 显著高）——a11y snapshot 上下文 1-5KB/步，4x-10x token 效率 vs 像素截屏**（来源：openlegion + ailearningguides + aiagentskit）——感知层选型。判据：**默认 a11y snapshot；canvas/iframe/PDF 用视觉；DOM 混淆时降级顺序明确**。提升层：工具。
3. **动作后立即验证+self-healing：每动作后断言"期望状态出现了吗"，失败重感知重规划而非蛮干；状态停滞检测（连续三次点击同元素且 DOM/布局未变→watchdog 强制刷新+注入反馈"检查阻塞 modal/需滚动"）**（来源：hub.cissychen + dev ifnodoraemon）——验证环。判据：**动作后断言状态变化；三次无变化触发恢复（刷新+上下文反馈）**。提升层：工作流。
4. **防状态漂移三件套：URL allow-list（当前域不在白名单硬停）、step budget（30-50 步封顶防无限循环）、snapshot rollback（每 5 步存浏览器状态，agent 困惑时恢复）**（来源：anhtu.dev）——漂移防护。判据：**浏览器 agent 全程配 URL 白名单+步数预算+周期快照回滚**。提升层：工作流。
5. **隔离与安全四件套：隔离沙箱（Docker/VM 无生产凭证）、域名白名单（切断外渗出口）、敏感动作 HITL（表单提交/发邮件/支付/删除——不可逆动作强制人确认，harness 层硬编码）、敏感域检测（current_url 检测挂起安全检查）**（来源：hub.cissychen + microsoft learn）——浏览器 agent 安全。判据：**浏览器 agent 在隔离环境+白名单域运行；不可逆动作 harness 层强制人确认**。提升层：工作流。
6. **Vision-first vs DOM-first 选型：作用域（桌面+web+任意 UI vs web only）、token/步（1500-4000 截屏 vs 300-800 压缩 DOM）、延迟、复杂 web 精度（像素技能 vs 清晰 id）**（来源：anhtu.dev + techiehub）——双路线对比。判据：**web 且 DOM 可靠用 DOM-first；canvas/iframe/遗留 UI 用 vision-first；成本差 5-10x**。提升层：工具。
7. **agent 探索→确定性脚本固化：屏幕驱动 agent 每步实况决策、两跑路径不同，不能替代 Selenium/Playwright 确定性回放（merge gate 需要）；模式=agent 探索生成 flows，导出确定性脚本跑 CI**（来源：testmuai）——agent 与测试分工。判据：**CI/merge gate 用导出的确定性脚本；agent 只做探索与流程生成**。提升层：工作流。
8. **Playwright 作外层 harness：agent 在浏览器内操作，harness 拥有 pass/fail 决策（trace 文件/截图/请求监控/console 日志/fixtures/retries/CI 报告）；测试含恢复用例；截图起点/关键动作/终态**（来源：scrolltest）——测试托管。判据：**浏览器 agent 测试用确定性 harness 包裹；pass/fail 由 harness 判定**。提升层：工具。
9. **viewport 分辨率与坐标契约：模型返回相对声明 viewport 的像素坐标——分辨率不一致即错位；pin 模型版本+固定 viewport（如 1280x800）**（来源：callsphere）——坐标契约。判据：**computer-use 固定 viewport 声明；模型版本 pin；坐标按声明 viewport 解释**。提升层：工具。
10. **a11y snapshot 结构感知截断：超 48KB 按页面角色与层级截断（保留 main/article，去导航/重复按钮/长列表）；纯布局元素跳过（无文本/无白名单属性/非交互标签）→每页 JSON 48KB→12KB，observation 上限防中间截断；iframe 用 iframe[title=...] 定位；canvas 渲染内容 DOM 无文本——text= 定位失败**（来源：arxiv + virtualme + skillmd）——上下文治理。判据：**a11y 快照大时结构感知截断；canvas 内容不走 text 定位；iframe 按 title 定位**。提升层：工具。
