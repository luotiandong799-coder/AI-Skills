## 独点（10）

**1. tool_choice 四值确定性控制（auto 自决/required 必调/none 禁用/tool 指定特定工具——强制结构化提取）**（来源：nisai.dev 2026-07-14 + Microsoft Foundry 2026-09-24 实拉）：tool_choice 是工具调用最确定性控制——auto 模型自决（默认，可选工具的一般对话）/required（any）必须调用某工具但不知哪个（知道需要工具调用但不知哪个）/none 不调用（临时禁用不移除上下文）/tool 指定特定工具（强制结构化提取/分类到固定 schema）；tool_choice 强制时模型无自由文本逃逸。判据：**tool_choice 四值=auto/any/none/tool 指定；强制场景用 tool 指定**。提升层：工具/工作流。

**2. 工具命名 verb_noun（名称=模型最先读的第一件事直接影响选择决策；<64 字符 snake_case）**（来源：ai-tldr 2026-06-12 + Google Cloud 2026-07-23 实拉）：函数命名直接塑造模型选择决策——名称是模型最先读的东西；verb_noun 模式（search_products/create_calendar_event/cancel_order）；<64 字符 snake_case；写清晰详细函数名/参数描述/指令；强类型参数；调用前验证；thought signatures（模型请求工具时给出思考签名）。判据：**工具命名=verb_noun snake_case <64 字符；名称=模型第一读取物直接影响选择**。提升层：工具/工作流。

**3. 输出 schema 一致性（工具输出可预测；形态不一致=模型失败源；结构化输出 API 层锁定 JSON Schema/Pydantic）**（来源：Tool Use 2026-03-07 + loooop 2026-05-20 + Future AGI 2026-05-14 实拉）：输出 schema 一致性=工具输出必须可预测——同工具输出形态不一致（list vs string）模型被迫双模式处理且常失败；@dataclass 定义固定结构（matches/total_count/truncated）；结构化输出=整个响应锁定 JSON Schema/Pydantic 模型——最强可解析保证（发票/合同/表单提取/数据库行生成）；工具处理程序小/确定性/幂等；副作用包确认+限速重试；服务端 schema 库验证输入后执行；返回结构化 success/error 对象；长任务返回简洁 artifact 引用（file ids/短摘要）。判据：**工具输出=固定 schema（不一致形态=模型失败源）；长任务返回 artifact 引用非全量**。提升层：工具/工作流。

**4. 失败分类矩阵五类响应（瞬态退避/校验回 LLM/权限升人/逻辑返回空/灾难熔断；连续失败冷却期）**（来源：Kunal Ganglani 2026 PDF + niteagent 2026-06-09 + zylos 2026-04-16 + qveris 2026-09-25 实拉）：失败分类矩阵=Transient（网络/限速秒级恢复→指数退避+抖动）/Validation（坏参数→返回错误给 LLM 让它纠正）/Permission（认证→升级人类）/Logical（无结果→返回空让 LLM 决定下一步）/Catastrophic（DB 挂→熔断中止整个任务）；连续 5 次工具失败→熔断；连续失败 N 次→冷却期暂停调用防级联故障+探测请求逐步恢复；持久失败重试烧钱无用（全量 outage/模型反复生成垃圾输出/schema 不匹配根本性不匹配）。判据：**失败五类=瞬态退避/校验回 LLM/权限升人/逻辑返回空/灾难熔断；连续失败冷却**。提升层：工作流/可复用 Skill。

**5. 重试-回退链（工具 A 退避→切 B 回退→全耗尽才放弃；图路由失败边重算不调 LLM）**（来源：qveris 2026-09-25 + arXiv 2603.01548 2026-03 实拉）：工具失败恢复=重试-回退链——工具 A 失败→退避重试→失败→再退避→失败→切工具 B（回退）→成功；只有全回退耗尽 agent 才返回"无法完成任务"；图式自愈工具路由=工具边权失败重算路径（工具失败中执行→边权无限→重算→自动恢复不调 LLM）——LLM 仅用于无可行路径（目标降级或升级）；每失败=已记录或已恢复的二元可观测性。判据：**重试链=工具 A 退避→切 B 回退→全耗尽才放弃；图路由失败边重算不调 LLM**。提升层：工作流/可复用 Skill。

**6. LLM 推理错误四类（选错改描述/畸形严验证/循环强制变/幻觉显式错；结构化输出 API 层硬约束）**（来源：Kinda Technical 2026-03-01 + DEV-aiwave 2026-06-20 实拉）：LLM 推理错误=错误工具选择（调错工具→改进工具描述）/畸形参数（无效 JSON/错类型→严格模式+验证）/无限循环（重复同动作→检测重复+强制不同动作）/幻觉工具（调不存在工具→返回显式错误）；结构化输出=API 层硬约束（Pydantic 模型定义字段+Literal 枚举）——不依赖模型"大致"返回合法 JSON。判据：**LLM 错误四类=选错改描述/畸形严验证/循环强制变/幻觉显式错；结构化输出 API 层硬约束**。提升层：模型/工具/工作流。

**7. 工具防火隔离（按能力类分离 agent/运行时；全能 agent+巨工具带=最不可靠架构；策略写成代码预检查）**（来源：richards.ai 2026-05-01 + Microsoft Learn 2026-09-23 实拉）：工具防火隔离=按能力类分离 agent/运行时——研究（web/搜索只读）/coding（仓库沙箱）/数据库（只读查询/迁移草稿）/部署（CI/CD 计划创建）/生产 operator（窄批准动作）；单全能 agent+巨大工具带=最不可靠架构；确定性策略检查=策略写成代码（policy as code）——预检查工具调用符合用户目标/无关文件系统网络数据导出/权限超限。判据：**工具防火=按能力类分 agent（全能 agent 最不可靠）；策略写成代码预检查**。提升层：工作流/工具/可复用 Skill。

**8. MCP 2026-07-28 RC 规范（无状态核心+UI 扩展+Tasks 长任务+OAuth 对齐+正式弃用策略；企业采纳安全治理清单）**（来源：ModelContextProtocol 2026-05-21 博客 实拉）：MCP 规范最大修订=无状态核心（scales 普通 HTTP 基础设施）/扩展=MCP Apps 服务端渲染 UI+Tasks 扩展长任务/授权对齐 OAuth 与 OIDC/正式弃用策略（协议演进不破坏已建）；企业采纳=远程服务器 OAuth 2.1+PKCE 必需/无硬编码 API key 用 Vault/输入验证（prompt 注入防御/PII 检测/最小权限 token scope）/服务端评估（源码审计/版本 pinning/供应链安全验证）。判据：**MCP 新规范=无状态核心+UI 扩展+Tasks 长任务+OAuth 对齐+正式弃用策略**。提升层：工具/工作流。

**9. MCP 服务端设计（按意图分组非 API 镜像；5-15 工具上限；job ID 长任务；读写分离凭证；描述标注副作用）**（来源：Claude 2026-04-22 + gingerlabs 2026-06-24 实拉）：MCP 服务端设计=构建远程服务器最大化覆盖（唯一跨 web/mobile/cloud-hosted agent 配置）；按意图分组工具非端点一对一（少而精描述良好工具胜过穷尽 API 镜像——不要把 API 一对一包成 MCP server）；工具描述显式标注写操作与副作用；参数全类型 JSON Schema 带约束（enum/maxLength）；服务端暴露 5-15 工具上限；长运行工具返回 job ID+暴露状态轮询工具；读/写工具用分开凭证范围。判据：**MCP 设计=按意图分组（非 API 镜像）+5-15 工具+job ID 长任务+读写分离凭证**。提升层：工具/工作流/可复用 Skill。

**10. 混合工具检索（纯语义词汇错配失败（cancel vs refund）→dense+sparse 双路加权；大规模工具库 top-k 注入控预算）**（来源：ajing 2026-01-09 实拉）：大规模工具选择=纯语义检索词汇错配失败（用户说 cancel 工具叫 refund）→混合工具检索=dense 语义+sparse BM25 关键词加权（alpha=0.7）；检索 top-k 工具注入上下文控制预算；工具选择=平衡候选相关性与模型决策。判据：**大规模工具=混合检索（dense+sparse 加权）+top-k 注入控预算**。提升层：工具/工作流。
