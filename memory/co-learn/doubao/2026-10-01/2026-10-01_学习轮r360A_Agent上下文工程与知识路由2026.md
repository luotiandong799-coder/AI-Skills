## 独点（10）

**1. 上下文工程独立学科（CE=信息供给架构 vs PE=查询措辞；全栈=system+历史+工具+参数）**（来源：Stanford CS224G 2026 Lecture 6 + arXiv 2603.09619 2026 实拉）：context engineering 管信息供给架构（内存/RAG/上传/工具可控元素），prompt engineering 管查询措辞；LLM 调用组件全栈=用户消息外还有 system prompts、conversation history、tool definitions、parameters；应用层杠杆=哪些 context 元素（memory/RAG/uploads/tools）开发者可控；实践=构建平衡信息的 context plan。判据：**CE=信息供给架构 vs PE=查询措辞；全栈=system+history+工具+参数，应用层杠杆=memory/RAG/upload/tools**。提升层：工作流/可复用 Skill。

**2. 自适应路由（复杂度分类器前置：简单跳过检索/中等单跳/复杂多跳；agentic 路径 2-8s 延迟+4-12x 成本）**（来源：DEV saaro 2026-09-13 + Alok 2026-06-17 + Redis 2026-08-10 实拉）：adaptive RAG=查询分类器前置按难度排序——简单事实问题完全跳过检索、中等单跳向量、复杂多步多跳；最关键的产线决策=是否用 agentic 循环的路由器——所有查询走 agentic 路径是最大常见错误；agentic 检索加 2-8 秒延迟+4-12x LLM 成本；semantic routing 跳过 LLM 调用用 embedding 相似度匹配预定义示例——刚性只处理定义过的类别、适合高吞吐稳定类别。判据：**路由=复杂度分类器（简单跳过/中等单跳/复杂多跳）；agentic 路径延迟 2-8s+成本 4-12x→不是默认路径**。提升层：工作流/可复用 Skill。

**3. 动态工具截断（N=min(jump, kneedle) 取小；最大偏离点作截止阈值；N<10 特殊处理）**（来源：arXiv 2601.01857 2026-01-27 实拉）：工具选择上下文中动态决定保留多少工具——最大偏离点选作相关工具截止阈值；两法后保留工具数 N=两个候选尺寸较小者（jump/kneedle）；N<10 系统特殊处理。判据：**工具上下文=N=min(jump, kneedle) 动态截断；最大偏离点作截止阈值**。提升层：工具/模型。

**4. 双通道请求架构（核心工具固定进请求头保前缀缓存稳定；全量工具走独立路由通道子模型选/执行/返回）**（来源：arXiv 2608.22708 2026-09-03 实拉）：工具选择与交付分通道=主模型永远只看小的固定核心工具集（请求头跨调用不变保前缀缓存）、其他工具走独立路由通道（路由子模型搜全工具列表/选一个/执行/返回结果）；工具注册源码自动完成。判据：**工具路由=核心工具固定进请求头（前缀缓存稳定）+全量工具走独立路由通道**。提升层：工具/工作流。

**5. KV 缓存块语义标记与优先级驱逐（LRU 只认 recency 忽略工作负载结构；瞬态低值 vs 首迭代高值分拣；资源独立编码可复用）**（来源：arXiv Sutradhara 2601.12967 2026-08-30 + ReCache 2608.19662 2026-09-03 实拉）：LRU 只看 recency 忽略工作负载结构——分不清低值瞬态块（不会复用）与高值首迭代块（被工具执行阻塞将复用）；orchestrator 提交请求时语义标记 KV 块（tag_block）→优先级驱逐；RAG 式资源独立编码（无相互 cross-attention）→KV 缓存可独立构造复用、不随检索组合/位置序变。判据：**缓存驱逐=语义标记 KV 块（瞬态低值/首迭代高值）优先；资源独立编码→KV 可独立复用**。提升层：工具/模型。

**6. 分层内存架构+知识分支切换（活动分支<50ms 换入窗口；3-bit KV 量化 16GB 容 768K token；只活动层随查询变）**（来源：arXiv 2606.26105 2026-06 实拉）：长时程推理上下文回收=分层内存架构管理固定上下文预算跨无界会话；活动知识分支=与当前查询相关的树节点集动态载入窗口、分支切换 <50ms；TQ3 量化（3-bit KV cache）16GB VRAM 容 ~768K token 缓存知识（~600K 词）——唯一随查询变的层。判据：**分层内存=知识树分支<50ms 换入窗口；3-bit KV 量化 16GB 容 768K token；只活动层随查询变**。提升层：模型/工具。

**7. 投机性反思循环（检索文档先投机生成内省轨迹但不提交持久轨迹；独立 critic 评证据充分性）**（来源：arXiv Critic-R 2606.00590 2026-09-17 实拉）：agentic search 改进=投机性精炼循环从无效检索恢复——每步检索文档 D_i(t) 投机提供给 reasoner 生成内省推理轨迹（不提交持久轨迹）；独立 critic 模型评估轨迹判断证据是否充分；指令微调检索器+自然语言内省反馈。判据：**检索恢复=投机轨迹不提交+独立 critic 评证据充分性（refine 循环）**。提升层：模型/工作流。

**8. 验证-迭代闭环（验证模块结构化反馈→改查询/换策略→不收敛走 HITL；guardrail 拦截工具调用；检索后三问自评）**（来源：arXiv SoK 2603.07379 2026-09-08 + Wicked Smart Data 2026-09-23 + GenAI Protos 2026-05-27 实拉）：agentic RAG 架构=验证模块检测事实不一致/语法错误生成结构化反馈→推理引擎迭代调整查询表述/切换检索策略直到过全部验证约束；自纠不收敛→HITL 升级路径；policy engine 拦截违反 guardrail 的工具调用暂停执行；检索后评估三问=上下文真回答子任务吗/足够新且权威吗/有后续检索可补的缺口吗。判据：**闭环=验证模块结构化反馈→改查询/换策略→不收敛 HITL；guardrail 拦截工具调用；检索后三问自评**。提升层：工作流/可复用 Skill。

**9. 双路召回与引用保留（reasoning effort 可配；子查询并行 keyword/vector/hybrid+语义重排+引用保留；ReAct 反思三拍）**（来源：Azure AI Search Agentic Retrieval 2026-09-18 + AWS Bedrock KB 2026-08-31 + 腾讯云 2026-09-21 实拉）：agentic retrieval=reasoning effort 默认 low 可配（low/medium 发 query+history 给 LLM 生成子查询；minimal 直发）；知识库发子查询到各源、全部并行（keyword/vector/hybrid）、每个子查询语义重排找最相关；引用提取保留供 citation；简单查询单次检索、复杂多部分问题分解子查询多跳——两况响应都 grounded 在检索段落+引文；ReAct 自我反思=推理（缺什么/矛盾）→行动（新检索/改写/调工具）→观察。判据：**Agentic 检索=reasoning effort 可配+子查询并行多路+语义重排+引用保留；ReAct 反思三拍**。提升层：工作流/工具。

**10. 上下文治理与防火墙（治理问题=文档 approved/current/attributable/integrity-verified 可消费吗；哈希链版本；层级索引小块检索父块上下文）**（来源：arXiv ContextNest 2607.02116 2026-06-15 + PyPI contextweaver 0.16.0 2026-06-23 + wittmannf 2026-08-23 实拉）：RAG 答"哪些段落相关"（检索问题）vs ContextNest 答"哪些文档已批准/最新/可归因/完整性验证过、agent 现在可消费吗"（治理问题——类型化元数据+stewardship 状态+哈希链版本历史+确定性选择）；contextweaver=context firewall+tool router for MCP 工具重型 agent（敏感度强制、基准 scorecard、gold set 50→200）；层级索引=小块精确检索+父块全上下文送模型（hierarchical indexing）。判据：**上下文治理=批准/时效/归因/完整性元数据门禁（哈希链版本）；层级索引=小块检索+父块上下文**。提升层：工具/工作流/可复用 Skill。
