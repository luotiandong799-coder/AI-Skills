## 独点（10）

**1. 记忆分层四件套（conversation/session/user/organizational）+ Hybrid Memory 混合存储**（来源：Mem0 AI Memory Management 2026-09-28 + anhtu.dev 2026-05-16 + StreamZero 生产栈 2026-04-13 实拉）：生产 agent 需要四个记忆层（会话/用户/组织），单靠加长上下文窗口不是记忆；2026 SOTA=**Hybrid Memory**——Vector Search（非结构化检索）+ Graph Traversal（结构化事实与刚性关系）+ Episodic Storage（事件时间序列），embedding 的"直觉"+graph 的"精确"互补。判据：**记忆按作用域分层（会话/用户/组织），混合向量+图谱+情节三种存储——向量管非结构化、图谱管事实关系、情节管时间序列**。提升层：工具/工作流。

**2. ADD-only 提取（不覆盖历史）+ 时间戳语义（valid_at/invalid_at）**（来源：Mem0 算法说明 2026-09-28 + Zep Graphiti bitemporal 2026-04-05 + Engram bi-temporal arXiv 2606.09900 实拉）：Mem0 用单遍 **ADD-only** 提取——新事实添加而非覆盖，历史保留不静默丢失；Zep Graphiti 每条 fact/relationship 带显式 valid_at/invalid_at，失效事实**不删除**、历史与溯源幸存，point-in-time 查询按时间解析（Tencent as-of t0 / Moonshot AI as-of now）；Engram 用 invalid_at+supersedes 保留失效历史。判据：**记忆更新用"追加+时间戳失效"而非覆盖删除——失效不删保审计，按时间点查询可回溯事实演化**。提升层：工作流。

**3. 原子事实提取（AtomMem Fact Executor）+ 验证器八项门禁**（来源：AtomMem arXiv 2606.19847 2026-06-18 + Cloudflare Agent Memory 2026-04-17 实拉）：atomic fact=**脱离原文上下文仍可理解**的单条信息（"上周五去了"→"2024-10-25 用户访问 UCLA"）；Fact Executor 是 SFT 微调的轻量 LLM 专做对话事实提取（denoising+coreference 消解），启发式规则/zero-shot 提示词效果差；Cloudflare verifier 跑八项检查（entity identity/object identity/location context/temporal accuracy/organizational context/completeness/relational context/推断事实是否被对话支持），逐项 pass/correct/drop。判据：**记忆写入前过提取器+验证器——提取用微调小模型做原子事实分解，验证器八项门禁（实体/对象/位置/时间/组织/完整/关系/推断），通不过的修正或丢弃**。提升层：模型/工具。

**4. 记忆蒸馏三层（Workflow/Subtask/Function）+ 主动/反应双注入**（来源：AMD arXiv 2608.07169 2026-09-06 + DuoMem 2606.29961 + MemoryCPT 2608.04843 实拉）：AMD 从成功教师轨迹构建三层记忆——**Workflow memory**（任务级策略）/ **Subtask memory**（中间粒度行为示例）/ **Function memory**（每函数调用约定+常见坑）；Workflow+Subtask 在任务开始**主动注入**，Function memory 在工具调用出错时**反应式检索**；Qwen3-4B 14.88%→49.40%（+34.52p）；DuoMem 教师离线提取 procedural memories 推理时 prepend（Context-Space）+LoRA 参数蒸馏双路；MemoryCPT 教师四角色 BatchSegmenter/EpisodeGenerator/EpisodeMerger/SemanticExtractor。判据：**小模型记忆=教师轨迹蒸馏三层（策略/示例/函数用法），策略与示例主动注入、函数用法出错时反应式检索——工具报错是最佳记忆触发点**。提升层：模型/工作流。

**5. 记忆评测四能力（检索/学习/理解/遗忘）+ FAMA 过期惩罚 + implicit conflict**（来源：MemoryAgentBench 腾讯云 2026-07-13 + Memora arXiv 2604.20006 + STALE 2605.06527 + MINTEval 2605.18565 实拉）：MemoryAgentBench 统一评测**检索/学习/理解/遗忘**四能力（现有基准只覆盖部分）；HippoRAG-v2 单跳冲突解决仅 54.0%；Memora 引入 **FAMA（Forgetting-Aware Memory Accuracy）**——惩罚依赖过期/失效记忆的作答，评估发现 agent 频繁复用无效记忆、无法调和演进记忆；STALE 识别 **implicit conflict**（后期观察未显式否定地使早期记忆失效，需上下文推断+常识检测）。判据：**评测记忆别只测召回——检索/学习/理解/遗忘四能力分开测；复用过期记忆要被惩罚（FAMA）；检测"未显式否定但已失效"的隐式冲突**。提升层：模型/工作流。

**6. 记忆投毒（Sleeper/Trojan Hippo/MemGhost）——持久攻击面**（来源：Sleeper Memory Poisoning arXiv 2605.15338 + OWASP 2026-05-13 + The Hacker News MemGhost 2026-07-13 + eTAMP 2604.16548 实拉）：**sleeper memory poisoning**——攻击者操纵外部上下文（文档/网页/仓库）让 agent 存储伪造记忆，潜伏跨多个会话复现，比传统 prompt injection 更危险（那是一次性的，关掉就停）；Trojan Hippo：**一个不可信工具调用**种 dormant payload，用户日后谈敏感话题触发数据外泄；MemGhost 离线训练攻击者模型对抗 shadow copy，一封邮件 87.5% 成功率；eTAMP 跨会话+跨站持久（站点 A 污染影响站点 B），还发现 frustration exploitation（环境压力下 agent 更容易接受投毒）。判据：**agent 记忆=持久攻击面（OWASP ASI06）——不可信内容（网页/邮件/API 响应）写入记忆前隔离与审查；投毒跨会话持久，危害远超一次性 prompt injection**。提升层：模型/工具/工作流。

**7. 记忆冲突解决的确定性分层（时间戳+来源权威，LLM 只做矛盾检测）**（来源：dreaming.press 2026-07-07 + Memanto arXiv 2604.22085 2026-09-16 + TEPA 2608.07429 实拉）：冲突解决是**独立能力**（MemoryAgentBench 四能力之一，HippoRAG-v2 单跳仅 54%）——"别让 LLM 自己决定哪个新"；确定性规则优先：valid_at 时间比较+来源权威度裁决；LLM 只做**语义矛盾检测**，检测到后通知 agent 请求显式确认再持久化（Memanto）；TEPA 把有效性做成记忆显式状态——keyed precedents，同 key 新鲜证据矛盾即 revoke active，保留 revoked 历史供审计。判据：**记忆冲突按"时间戳+来源权威"确定性裁决，LLM 只做矛盾检测不判新旧；同 key 新证据撤销旧记忆但保留审计历史**。提升层：工作流。

**8. 遗忘即衰减而非删除（双路径 + 差异化衰减率）**（来源：Oblivion arXiv 2604.00131 + FadeMem 2601.18642 + Human-Inspired 2605.08538 + FSFM 2604.20300 实拉）：Oblivion 把遗忘定义为**decay-driven reductions in accessibility 而非显式删除**——read/write 路径解耦：read 路径按 agent 不确定性与记忆缓冲效用决定**何时**查记忆（避免 always-on 冗余访问），write 路径强化**贡献于形成响应**的记忆；FadeMem 双层记忆层级差异化指数衰减（semantic relevance/access frequency/temporal patterns 调制）；Human-inspired λ=0.001（half-life≈29 天）+ interference-based forgetting（共享特征高干扰低价值选择性遗忘）；FSFM 神经启发（hippocampal indexing+Ebbinghaus 遗忘曲线）。判据：**遗忘=降低可访问性而非删除（保审计），衰减率按语义相关/访问频率/时间调制；读路径按不确定性决定何时查、写路径只强化有用记忆**。提升层：工作流/可复用 Skill。

**9. 记忆写入管线（Extract→Deduplicate→Persist）+ 会话结束全轨迹提取 + Briefing 加载**（来源：memory-pipeline LobeHub/OpenClaw 2026-09-27 + Daily AI World LangGraph+Weaviate+Temporal 2026-08-29 + OpenAI Agents SDK 记忆蒸馏 2026-01-05 实拉）：三阶段管线——**Extract**（LLM 提取结构化事实：decisions/preferences/learnings/commitments）→ **Deduplicate**（语义去重，防同一事实多份）→ **Persist**（Weaviate 向量存储）；记忆当**一等公民**编排（LangGraph 1.x 状态图确定性控制流+Temporal 崩溃安全），不是副作用；会话结束用**全执行轨迹**提取（捕捉 tool usage patterns 与内部推理信号）；会话开始加载 **Briefing.md**（personality reminders/active projects/recent decisions/key context）。判据：**记忆管线分"提取→语义去重→持久化"三阶段且崩溃安全；会话结束用全轨迹提取、会话开始加载 Briefing——记忆是一等公民不是副作用**。提升层：工作流/可复用 Skill。

**10. 记忆方案选型（Mem0/Letta/Zep/Cognee 四型）+ 记忆基准分数**（来源：Mem0 2026 基准 2026-09-22 + aiworkflowlab 2026-05-25 + Context Studios 2026-09-24 实拉）：Mem0（通用提取层，vector-first+metadata）LoCoMo 92.5%/LongMemEval 94.4%/BEAM-1M 64.1%；Letta（OS 分页：archival disk/active RAM，agent 用 memory tools 自管理）；Zep/Graphiti（时序知识图，valid_at/invalid_at）；Cognee（graph-native 本地优先）；Claude Memory Tool 零基建、TencentDB symbolic offloading、LangMem 适配 LangGraph。判据：**选记忆方案按四型对号入座——通用提取层(Mem0)/agent 自管理运行时(Letta)/时序知识图(Zep)/本地图原生(Cognee)，先看基准分数再选**。提升层：工具。
