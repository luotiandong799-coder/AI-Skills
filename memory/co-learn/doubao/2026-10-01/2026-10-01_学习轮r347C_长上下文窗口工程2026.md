## 独点（10）

1. **KV 缓存压缩三族：量化（混合精度、TurboQuant ~3bit K/2bit V 约 6x 压缩免校准）/淘汰与剪枝（LookaheadKV 预测未来注意力估算 token 重要性、SeKV 分辨率自适应、StructKV 结构感知全局入度中心性）/合并（MLA 低秩潜在缓存按需重建）**（来源：arXiv 2607.05399 + CSDN 综述 + hanwook-cho + research.samsung + semanticscholar + dev.to）——KV 三族。判据：**三类可独立部署可叠加；MLA 是 2026 长窗口模型主因**。提升层：工具。
2. **attention sink 是 softmax 的数学必然（多余注意力质量倾倒）；BOS sink 头=功能冗余，可安全剪枝；StreamingLLM 证明 sink 是位置性非内容驱动（占位符同样生效）；sink token 值向量被预训练排空近零**（来源：mental-momentum + arXiv 2601.06787 + aiwiki streaming + arXiv 2406.12335）——sink 必然。判据：**sink 是必然不是 bug；sink 头剪枝利用其冗余性**。提升层：工具。
3. **lost in the middle 定量：中段 40-80% 准确率从 95% 掉到 30-50%；2026 基准跨主流模型 10-25% 退化；Claude U 形更平（5-15% 降）vs 开源（20-30% 降）；65% 企业 AI 失败归因 context drift 而非窗口耗尽**（来源：codersarts + zylos + theneuralbase lost-in-middle）——中段退化。判据：**更多上下文≠更好回忆；信号埋在中间即退化**。提升层：模型。
4. **压缩触发窗口共识：60-75% 利用率触发（rot 区生成的摘要本身已退化，别等硬墙）；任务驱动压缩（任务切换时触发）与聚焦摘要；合规/审计场景压缩工作上下文但单独持久化原始日志**（来源：agentnative + zylos + CSDN + agentpatternscatalog）——触发窗口。判据：**触发窗口是执行参数不是策略轴；别在 rot 区才压**。提升层：工作流。
5. **SelfCompact：内联压缩工具由模型自己调用（<summarize>），rubric 规定何时触发（子任务解决/轨迹收敛）何时抑制（推导中途/卡住）**（来源：arXiv 2606.23525）——自触发压缩。判据：**压缩时机交给运行中模型判断，比固定阈值自适应**。提升层：工作流。
6. **缓存边界控制反直觉：naive 全量缓存可能增加延迟；只缓存 system prompt 排除动态工具结果收益更一致（Don't Break the Cache：成本 -41-80%、TTFT -13-31%）**（来源：arXiv 2601.06007）——边界控制。判据：**缓存边界是设计决策不是开关；动态内容混入前缀反而破坏一致性**。提升层：工具。
7. **prompt caching 机制差异：OpenAI 自动缓存共享前缀 30 分钟窗口（GPT-6 更高命中率默认开）；Anthropic 显式断点（最小 1024 token 块、最多 4 断点、首写 +25% 溢价、读 -90%）；2026 两家都出自动缓存；阿里 explicit 5 分钟 125%/10% 定价**（来源：openai + genta + aliyun + sureprompts）——机制差异。判据：**缓存机制差异决定设计姿势：自动型靠前缀稳定，断点型靠位置标记**。提升层：工具。
8. **KV 缓存友好三金律：不改固定系统提示/工具定义（一个空格即全缓存失效）；稳定组件化前缀+不变前缀组合；动态内容放尾部**（来源：dev.to + AWS agentperf03）——三金律。判据：**前缀稳定性=缓存命中的全部前提；动态值绝不内插进静态前缀**。提升层：工作流。
9. **上下文四动词（write/select/compress/isolate）+ 组件 token 预算：参考分配=系统 10-15%/工具 15-20%/检索 30-40%/历史 20-30%/缓冲 10-15%；显式上下文（读这个 PDF）胜隐式检索**（来源：zylos + replyant + usewire + Stanford CS224G）——四动词。判据：**预算按信息密度不按便利；分配和要 ≤ 输入长度目标**。提升层：工作流。
10. **ITR 指令-工具检索：每步只检索最小系统提示片段+工具子集，置信门控回退；per-step 上下文 -95%、工具路由 +32% 相对**（来源：arXiv 2602.17046）——ITR。判据：**系统提示本身也可动态化；按步最小暴露胜过全量常驻**。提升层：工具。
