## 独点（10）

1. **few-shot 数量纪律：2-4 例分类抽取最优 超 4 例过拟合示例表层形式 措辞长度用词 泛化下降 开放式生成 0-1 例 最后示例影响过大 多样意排序**（来源：Future AGI 9 模式 + loooop OpenAI）——提示工程。判据：**few-shot 例数 2-4 为上限，示例意排序，开放式任务 0-1 例**。提升层：模型。
2. **推理模型不需要显式 CoT：非推理模型前置 Let's reason step by step 推理类模型自动思考 reasoning effort 参数 显式 CoT 反而干扰 与 self-consistency 分工 高价值任务采样多轨迹取共识**（来源：Future AGI + loooop）——推理模型适配。判据：**推理类模型不写 CoT 指令，用 effort 参数控制；非推理模型才显式引导；高价值任务用 self-consistency**。提升层：模型。
3. **测试时计算缩放：计算最优策略按提示难度分配 算力从易题流向难题 bandit 消除式 采样估难度答对即淘汰 与训练缩放律分工 推理性能随推理计算对数到线性缩放**（来源：test-time compute + bandit）——推理预算。判据：**测试时算力按难度自适应分配，易题不浪费、难题集中投**。提升层：模型。
4. **多 agent 协同推理 Pareto 前沿：MoA 20x CoT 预算 MMLU-Pro 64.3 到 71.4 层级记忆 经验库复用低层可靠中间结论 指南库记录高层策略防冗余推理**（来源：TMAS + MoA）——多 agent 推理。判据：**跨轨迹协作配层级记忆：低层结论复用、高层策略防重**。提升层：工作流。
5. **Gambit thought-level beam search：周期剪枝无望轨迹 高质量前缀即时分支 轻量打分器探隐藏状态 持续高硬件利用 加 6.7 增益**（来源：arXiv 2608.08020）——推理算法。判据：**推理计算动态集中到最有希望轨迹，剪枝与分支并行**。提升层：工具。
6. **上下文工程四操作 write/select/compress/isolate：context rot 加 lost-in-the-middle 更多上下文不免费 子代理隔离重活 文件记忆 激进压缩 决策保持压缩 FOCUS 压缩保留决策而非逐字**（来源：Context Engineering 论文 + Oracle 四操作 + FOCUS + ACM）——上下文工程。判据：**上下文工程是独立学科：写选压隔四操作，压缩以保留决策为准**。提升层：工作流。
7. **prompt 注册表治理：内容加版本加所有者加域加策略标签加验证规则加评估基线 不可变生产版本 模型绑定加检索绑定加 guardrail 绑定 运行时拉取生产标签版本 缓存 300s 语义名加版本唯一标识**（来源：COMPEL + Suhas + Ascheriit + IETF PLPES）——prompt 治理。判据：**prompt 移出应用代码入注册表，版本不可变，绑定模型/检索/guardrail**。提升层：工具。
8. **约束解码语义差距：结构失败消除但语义正确性依赖失败原型与模型规模 工具调用等于约束解码 参数 schema 编译语法 加 begin tool call FSM 状态 生产解析失败率 自由文本加解析 15-30 百分 JSON mode 2-8 百分 约束解码 0**（来源：arXiv 2609.23742 + Zylos + Tensoria）——约束解码。判据：**函数调用与 structured outputs 底层是约束解码，结构保证 100 百分但语义正确性需单独验证**。提升层：工具。
9. **prompt 回归测试三模式：per-rubric 断言加 per-route 分层 eval 加 paired 与先前版本对比 CI delta golden set 管道每次 prompt 模型检索变化跑 对比基线 失败构建 对抗生成扰动种子 50 例 合成 paraphrase typos hostile malformed JSON**（来源：Future AGI + SurePrompts）——prompt 回归。判据：**prompt 如代码管回归：golden set 每变更跑，对抗生成补边界，超阈值失败构建**。提升层：工作流。
10. **指令层级四层：Platform 加 System 加 Developer 加 User 每层约束下层 用户不能覆盖 developer developer 不能覆盖 system system 不能覆盖 platform 工具与 schema 是 enforcement 层 层混合系统不可预测**（来源：OpenAI Model Spec + keepmyprompts + aisrc）——指令层级。判据：**按层级组织 prompt，工具与 schema 承担 enforcement，不靠提示词层叠**。提升层：工作流。
