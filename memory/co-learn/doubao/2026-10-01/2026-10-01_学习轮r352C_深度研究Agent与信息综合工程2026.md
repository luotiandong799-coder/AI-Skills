## 独点（10）

**1. 深度研究三 agent 分工 + 分阶段训练（MindDR 模式）**（来源：Mind DeepResearch arXiv 2604.14518 2026-04-14 + Gemini Deep Research docs 2026-07-21 实拉）：MindDR 用 ~30B 模型达 frontier 效果——**Planning Agent**（拆问题）/**DeepSearch Agent**（检索）/ **Report Agent**（综合）三 agent 协作；四阶段训练：SFT cold-start → Search-RL → Report-RL → preference alignment；产品侧 Gemini Deep Research 流程 = Plan > Multi-source search > Iterate > Output（可同时跨 MCP servers/内部知识/上传文件推理）。判据：**深度研究 agent 拆成"规划/检索/报告"三职责并分阶段 RL 训练，检索与报告分开强化——小模型也能逼近 frontier**。提升层：模型/工作流。

**2. 深度研究状态 = 问题 + 进行中的报告 + 最近动作（报告即状态）**（来源：WebResearcher arXiv 2509.13309 2026-09-17 + Gemini Deep Research Max 2026-04-21 实拉）：WebResearcher 每轮 state = (original question q, **evolving Report_{i-1}**, recent Action+Tool Response)——紧凑表示保证 Markov 属性且保留决策必要信息；每轮基于上一轮报告继续迭代（不是基于全部历史）；产品侧 Deep Research Max 用 extended test-time compute 迭代推理-搜索-精化报告，适合异步后台（如 nightly cron 生成尽调报告）。判据：**研究 agent 的状态别堆全部历史——"问题+演进报告+最近动作"三件套即状态，报告本身就是记忆载体**。提升层：工作流。

**3. 证据接地五段管线（Ingest→Extract→Resolve→Verify→Gate）**（来源：Daily AI World 2026-08-15 + wyattowalsh/agents research skill 2026-07-26 实拉）：Ingest（agent 读源文档起草分析）→ **Extract**（claim extractor 把 draft 分解为离散可检查 claims）→ **Resolve**（citation resolver 映射 claim→候选源）→ **Verify**（verifier 确认源实际支持 claim）→ **Gate**（evidence gate 比较 draft claims vs ledger，未验证 claims 被 blocked/flagged/回炉重研究）；source ledger 每条含 source_tool/url/access_timestamp/excerpt/cross-validation/BIAS MARKERS/GAPS。判据：**研究报告交稿前过证据门——每条 claim 必须对应到已验证源，通不过的回炉；证据账本随稿交付**。提升层：工作流/可复用 Skill。

**4. 引用三维评价与"引用但未验证"陷阱**（来源：Cited but Not Verified arXiv 2605.06635 + Future AGI 三 rubric 2026-05-20 + toolsolved CJR 数据 2026-10-01 实拉）：引用评估三维——①Link Works（URL 可达）②Relevant Content（主题相关）③**Fact Check**（具体事实/数字/日期在源里显式支持，最严）；AST parser 从 Markdown 报告提取内联引用规模化评估；表面引用质量（链接通+主题相关）高分**可能掩盖事实失败**——2026 CJR 测试引用错误率：Perplexity 37% vs ChatGPT 67% vs Gemini 76%；GPT-4o memory-only 场景编造引用 78–90%（OpenScholar）。判据：**评估引用别只看链接通不通——必须做 claim 级事实核对；高链接有效性+高主题相关≠可信，高利害领域（医疗/法律/金融）尤其**。提升层：模型/工作流。

**5. 主动推理式引用（ReCite：从相似度搜索转向 claim 级推理）**（来源：ReCite arXiv 2609.09156 2026-09-09 实拉）：准确引用需要从 similarity-based search 转向**主动 claim 级推理**——解耦三模块：location perception（定位）/ intent-aware query planning（意图感知查询规划）/ reflective verification（反思验证）；合成推理轨迹训练；检索候选缺乏逻辑支撑时**触发自纠循环**；轻量框架超大规模生成模型。判据：**找引用证据用"意图感知查询规划+反思验证"的主动推理，别靠相似度搜索碰运气——候选缺逻辑支撑就自纠重找**。提升层：模型/工作流。

**6. 上下文管理 agent 化（ACM：agent 自主决定何时压缩，阈值只是兜底）**（来源：ACM arXiv 2607.23809 + Codex Knowledge Base ACM thesis 2026-09-24 + CAT ACL 2026 实拉）：ACM 给 agent 两个 purpose-built 上下文编辑工具——`manage_context`（压缩前序轮次+raw messages offload 到磁盘文件）/ `retrieve_context`（按需查询外部记忆）；agent **自主决定**何时压缩何时检索；post-training 构建上下文管理演示提升下游任务性能；论点："token 阈值触发压缩不知道 agent 在干什么（探索 vs 重构信息保全需求不同），agent 自己知道"；CAT 把上下文维护升级为可调用工具（stable task semantics + condensed long-term memory + high-fidelity short-term interactions 结构化工作区）。判据：**长任务上下文压缩权交给 agent 自己（给压缩/检索两个工具），阈值触发只是最后防线**。提升层：工具/工作流。

**7. 推理可遗忘判据（派生状态已外部化，历史推理才可替换）**（来源：When Can Agents Forget Their Reasoning? ICLR 2026 2026-09-24 + MAGE 执行状态管理器 2026-08-02 实拉）：研究把 agent 推理视为**动态工作状态而非永久交互历史**——一旦 task relevant derived state 可靠外部化到 code/files/tool outputs/environmental feedback，对应历史推理**变得可替换**；压缩应聚焦"结论已落盘"的部分；MAGE 两层层级状态树（bottom: step-by-step action-observation trace；top: subgoal/decision boundary 处 boundary-aware summaries），当前执行状态=压缩态+最近原始态+执行提示。判据：**压缩前先问"这段推理的结论是否已落盘/落到工具输出"——落了就放心压，没落才保留；状态树按子目标边界摘要**。提升层：工作流。

**8. 综合三问（Themes / Tensions / Gaps）+ 显式矛盾标记**（来源：AI Tutorium synthesis 2026-09-30 + lobehub kirillgreen deep-research 2026-09-29 + Atlas 矩阵综合 2026-08-03 + NotebookLM 2.3 溯源 2026-05-18 实拉）：综合三问——①Themes：各源共识在哪、独立源在哪收敛 ②Tensions：分歧根因是 data/method/values 哪个 ③Gaps：缺什么、共享假设是否未检验；输出对 certainty/uncertainty/ignorance 诚实；反模式=**平滑矛盾造干净叙事**——应显式 flag（"Source A claims X [1], but Source B found Y [2]"+可能原因）、区分置信度（多源强支持 vs 单源推测）、呈现少数观点；矩阵综合读列找空单元格=缺口；NotebookLM 2.3 深度优先遍历溯源树识别未被实证子节点支撑的高层结论。判据：**研究报告综合阶段显式标记矛盾/置信度/缺口，禁止抹平矛盾造叙事；共识-分歧-缺口三问逐答**。提升层：工作流/可复用 Skill。

**9. 合成数据驱动研究 agent 训练（评分树 + 统一轨迹）**（来源：QUEST 智源 2026-05-23 + S1-DeepResearch arXiv 2606.15367 2026-09-16 + WebSeer ICLR 2026 实拉）：QUEST 用**统一评分树（unified rubric tree）**作骨架的全自动数据合成管道——无人工标注生成带可验证奖励信号的多样长程任务；仅 8K 合成任务即在 8 异构深度研究基准达标；S1 统一轨迹构建=closed-ended QA + open-ended exploration（graph-grounded task formulation → agentic trajectory rollout → multi-dimensional trajectory verification）；WebSeer SRRL 允许单轮多次 answer_submit 回灌对错信号（普通 RL 一轮只提交一次，反思无从发生）。判据：**训练深度研究 agent 用"评分树+轨迹验证"合成数据覆盖长链推理/报告写作/技能使用；RL 训练允许单轮多次提交答案才有反思**。提升层：模型/工作流。

**10. 深度搜索基准演进（反记忆捷径 + 跨模态）**（来源：LiveBrowseComp arXiv 2605.28721 2026-08-26 + BrowseComp-V³ arXiv 2602.12876 + HLE openrouter 2026-09-15 + BrowseComp-Plus 实拉）：LiveBrowseComp 题面只依赖**最近 90 天事实**且排除全球显著事件——移除"模型背过答案再做验证"的 memory-backed verification shortcut；BrowseComp-V³ 300 题多模态深浏览，关键证据**跨文本+视觉模态交织**；HLE 固定模型、只变 search engine/request format/max search budget 测"live search 给难题加多少分"；BrowseComp 1266 题 GPT-5.6 Sol 90.4% SOTA。判据：**测搜索 agent 用模型知识覆盖之外的题（90 天窗口+非显著事件），别用能背的题测出假能力；跨模态题测真"浏览"而非"回忆"**。提升层：模型/工作流。
