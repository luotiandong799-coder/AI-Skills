## 独点（10）

1. **计划即工件（plan artifact）：存 prompt 外作为持久对象——Objective/Scope（Included+Excluded）/Assumptions/Risks/Steps/Tools required；显式计划分离规划质量与执行质量**（来源：github agents-best-practices + genai4a11 Plano）——计划不是 prompt 里的文字是一等对象。判据：**计划落成外部工件带范围/假设/风险/步骤/工具段；显式计划让"规划得好不好"与"执行得好不好"可分诊**。提升层：工具。
2. **subgoal DAG 作规划工件：带 post-conditions 的结构化子目标 DAG，不是 prose 计划；任务解耦规划——局部失败只重评受影响 DAG 节点，不触发全局 replan**（来源：zylos）——失败包含性。判据：**规划输出=子目标 DAG+后置条件；局部失败只重评受影响节点，失败不扩散**。提升层：工作流。
3. **replanning 五触发器：tool failure / new information invalidates assumption / budget exceeded / goal shift / quality gate failure；触发后分支 local replan / escalation / continuation；另识别 temporal plan invalidation——环境变化使计划失效（非 agent 犯错）**（来源：agentixforce + zylos）——重规划不是可选的。判据：**每执行步后查五触发器；计划失效分两种：内部错误与环境变化，都要有检测路径**。提升层：工作流。
4. **计划深度匹配任务复杂度：过度规划加延迟（100 小步=慢贵），规划不足致游荡（"全做"=agent 猜）；is_atomic 检查防不必要递归+递归深度封顶**（来源：dataaihub + neelmishra + theneuralbase）——分解粒度是成本与可控的权衡。判据：**分解到"一步一个原子动作"即止；递归深度封顶；粒度按任务复杂度调**。提升层：工作流。
5. **终止条件显式多条件：max iterations / repeated-action detection / coverage 阈值 / 边际收益（覆盖率不因更多迭代显著提升即停）；LLM 总想"可以更好"永远不到 100%**（来源：waylandz + tutorialslogic）——防无限迭代。判据：**计划执行配显式终止条件组（迭代上限+重复动作检测+覆盖率阈值+边际收益），不设"到 100%"式单条件**。提升层：工作流。
6. **恢复策略四档：step 失败有重试→带错误信息重试同一步；无重试→Patch（只重写失败+待执行步骤）；Patch 又失败→标 failed 继续、reflection 决定 replan；全完成但目标未达→Augment 补步骤**（来源：reactiveagents）——渐进式恢复不重启。判据：**执行失败按 重试→局部补丁→标记继续→增补步骤 四档渐进恢复，不整盘重来**。提升层：工作流。
7. **abort conditions 写进计划本身：executor 前进前查（"若 step3 结果不含 X 则中止，下游依赖 X"）；计划带 post-conditions 逐步验证**（来源：openlegion + Goal2Skill）——计划自含中止语义。判据：**计划每步写中止条件与后置条件；执行前先查中止，执行后验后置**。提升层：工具。
8. **FPoF 首失败点定位：区分主错误与下游级联效应（tool mismatch 与 parameter-binding errors 主导首失败）；loop_rate/replan_success_rate 两个运维指标**（来源：DisasterBench + xbstack）——失败归因到最早根因。判据：**故障诊断先定位首失败点分离主错与级联；监控 loop_rate 与 replan_success_rate**。提升层：工具。
9. **计划即记忆载体（PLAN-AND-ACT）：executor 每步后 planner 基于"当前状态+旧计划+已做动作"重生成计划——已发现的信息写进新计划，长程任务上下文问题无需额外 memory 模块；每步重预测剩余计划形成隐式闭环**（来源：腾讯云 PLAN-AND-ACT + trace-conditioned VLA）——计划承载累积状态。判据：**长程任务把计划当滚动记忆：每步重生成计划携带已发现事实，替代外部记忆模块**。提升层：模型。
10. **规划失败最普遍的是全局优化失败（Pattern C）：无法把相互依赖的决策整合进整体计划（最低价组合/多样性约束）；APB 揭示系统性弱点在 long-horizon、tool-noise 鲁棒性、calibrated refusal、inference-time refinement**（来源：acl DEEPPLANNING + arXiv APB）——规划失败分类。判据：**长程规划重点是全局约束整合（跨步权衡），不是单步正确；评测规划能力用 APB 式诊断基准**。提升层：模型。
