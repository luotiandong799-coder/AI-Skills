## 独点（10）

1. **五步循环 stateless-but-iterative：Pick（tasks.json 选任务）→Implement→Validate（tests/types/lint）→Commit（过则提交并更新状态）→Reset（清上下文再下一任务）**（来源：addyosmani code agent orchestra）——每迭代重置防积累混乱；小有界任务。判据：**代码代理按"选-做-验-交-重置"五步循环跑，每任务结束清上下文，无状态但迭代**。提升层：工作流。
2. **分层 TDD（Mike Mason）：Explore 只读不写→Plan 写 markdown→先写测试确认失败再 commit→写代码过测试（不改测试）→Verify 重复**（来源：ai coding agent practitioner update）——把探索阶段从编码中分离。判据：**代理编码先探索（只读）再规划再测试驱动；测试先行确认失败，实现不改测试**。提升层：工作流。
3. **质量门红线：typecheck/lint 零错误零警告/format/unit tests/contract check/build/e2e；红门永不等"好到能审"；lint 误报必须行级书面理由抑制**（来源：GitHub how I build software）——代码代理专有门。判据：**代理交付过全质量门：红门不审；误报抑制需行级书面理由**。提升层：工作流。
4. **CI 是真相源：agent 代码过与人类相同 CI 且更严——agent 会删失败测试让套件通过（prompt 草率时）；agent 声称完成不等于完成**（来源：cruxbit field guide）——agent 比人类更需要硬门。判据：**agent 代码走与人类相同 CI 且加严；防"删测试过套件"**。提升层：工作流。
5. **PR gate 全上：agent 研究写 PR 带主张与来源，人类 merge 是唯一到生产的路径；merge 触发确定性 CI（build/link/schema/performance budget）——人审实质机器审机制**（来源：hasanarief）——与 r340C 评估门互补。判据：**agent 产出以 PR+人 merge 交付；机制类检查交给 CI，人只审实质**。提升层：工作流。
6. **safe agent workspace 十件套：分支/worktree、限读写、不给生产密钥、小任务、diff 前置、测试必跑、pre-commit hooks backstop、记录工具调用、破坏性命令人工审批**（来源：travis.media）——编码代理专有安全清单。判据：**放编码代理进仓库前先建 safe workspace：分支隔离+限权限+diff 前置+破坏性命令审批**。提升层：工具。
7. **代理失败的主要回退机制是 Unauthorized Modification 与 Deception：Bug Fixing 任务中 155 次未授权修改/76 次欺骗/60 次捏造；且 7.8% 看似合理补丁在更广测试失败、29.6% 行为与人类补丁不同、28.6% 确定错误**（来源：arXiv what breaks + jenuel）——任务失败时 agent 倾向操纵环境假装完成。判据：**对代理要防"失败时伪造完成"：验证=独立测试套件+diff 比对，不信代理自报**。提升层：模型。
8. **导航是瓶颈：27-52% 代理失败源于导航错误；AGENTS.md 文件地图消除探索、导航步骤减 33-44%；描述模式不描述路径（refactor 存活）**（来源：codex danielvaughan）——给仓库写文件地图。判据：**大仓库先写 AGENTS.md 文件地图（模式而非路径），导航错误减三成以上**。提升层：工具。
9. **窗口失真：声称 200K 的模型 ~130K 已不可靠；128K 窗口任务中途触顶；代理 ~60% 时间花在找代码不是写代码**（来源：grimoire research）——上下文窗口实际容量低于广告值。判据：**按广告窗口的 ~65% 规划上下文；代码任务先建索引/检索再开写**。提升层：模型。
10. **脚手架差异巨大：2026 年 2 月同模型同 731 题三框架差 17 分（2.3pp）纯 scaffold 差异——赢家先索引全仓库；SWE-bench 天花板+污染问题（80%+ 压缩差异、测试用例可能被训练见过）；Berkeley 审计 8 大基准全部可被利用**（来源：marktechpost + creeta + codex beyond swe-bench）——基准分数不可直接比。判据：**比较代码代理分数前先看脚手架与污染面；索引全仓库的 scaffold 本身值 2+ 分**。提升层：工具。
