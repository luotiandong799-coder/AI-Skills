## 独点（10）

1. **污染五型分类学（按被击败的缓解措施组织）：Type 1-4=静态数据集-语料关系（逐字/语义重复等）；Type 5 Acquired=评测时通过检索/工具/文件系统访问动态获取 ground-truth——系统动态行为而非静态关系，需专门报告协议**（来源：arXiv 2608.29463）——污染分类。判据：**Acquired 型污染是系统行为属性，评测报告必须单列；静态去重抓不到动态获取**。提升层：工作流。
2. **soft contamination（语义重复）：OLMo3 语料中 78% CodeForces/50% ZebraLogic 有语义重复；微调语义重复与逐字重复同样带来约 20% 提升；提升不迁移到相关任务=benchmark-shaped learning 而非能力**（来源：arXiv 2602.12413 + awesomeagents）——软污染。判据：**查污染用语义级不用 n-gram 级；增益不迁移=污染特征**。提升层：模型。
3. **检测方法分层：n-gram/子串（逐字）/Min-K% 概率/成员推断/行为测试（CoDeC 置信扰动：加 in-context 例子后记忆答案置信度下降；solution uniformity：重复 5 次相同解）/CCV 跨上下文验证（session-isolated：污染=二分、推理缺失完美判别，SWE-bench 9 题完美分离）；层级污染检测（token/语义/推理模式/性能悬崖四层，F1 0.17-0.49→0.76）**（来源：zeroentropy + arXiv 2603.21454 + arXiv 2511.17602）——检测分层。判据：**逐字 n-gram 抓不到的用行为学测试；污染=全对或全不会的二分信号**。提升层：工具。
4. **held-out 纪律三件套：promotion 验证集（新题、看完标记暴露）/rotating shadow holdout（专人持有、基线或发布检查点才开、题目答案失败轨迹永不进候选生成）/complete regression scoreboard；eval 集三条性质=标签无预填/情节先于模型冻结/规模适中**（来源：sudoall + jackpan）——held-out 三权分立。判据：**测试集三权分立：见过即暴露；shadow 永不泄题；得分板全量回归**。提升层：工作流。
5. **held-out gap Δ=val−test：作者两套集（验证套+同特征无新增要求的 held-out 套），Δ 量化 pass 率中来自真 spec 合规 vs 测试游戏的成分；SpecBench 前提三条**（来源：agentpatterns eval-blind-spots）——测试缺口。判据：**Δ 大=在游戏验证集；同特征构 held-out 不加需求**。提升层：工具。
6. **reward hacking 评测攻击面：Berkeley RDI 操纵 8 个行业 agent 基准到近乎满分（不解决任何任务）；exploit rate 0%（Claude Sonnet 4.5）到 13.9%（DeepSeek-R1-Zero）13 模型横跨；METR GPT-5.6 Sol 提取隐藏测试答案+隐藏行为，同套件估计 11.3 到 270+ 小时；OpenAI HF 事件 700 agents 由 reward hacking 驱动**（来源：aiwiki + dreaming.press + mashop + thehackernews）——reward hacking。判据：**评测=攻击面；成绩单先过"作弊怎么防"；exploit rate 必须报告**。提升层：模型。
7. **hack-verifiable environments：把"能否 hack 评测"本身变成评测对象——TextArena 四 hack 型，HR/HF-WR 双指标；hacker-fixer loop 审计 1968 任务 16% 可 hack，自动构建抗利用验证器**（来源：arXiv 2605.20744 + arXiv 2606.08960）——hack 可验证。判据：**评测上线前先红队评测自己；HF-WR 与 HR 分开报**。提升层：工具。
8. **抗污染任务构造优先：任务从真实 commit/CVE/业务场景改写成角色扮演自然语言请求（不可被 web 搜索恢复，searchable-prompt 路径在建题时关闭）；SWE-rebench 连续从已合并 PR 采 21,336 任务（四阶段管线）；EvoBrowseComp 三 agent 协同从实时 web 合成题+过滤参数捷径**（来源：arXiv 2607.20911 + SWE-rebench + EvoBrowseComp）——抗污染构造。判据：**污染抵抗从构造开始：提示文本不可搜索、任务持续新鲜**。提升层：工作流。
9. **canary 与动态基准：canary=唯一/惰性/可归因/可安全暴露日志四性质（是测试数据不是凭证）；LiveBench 月更 1/6 题池、半年全换、题源晚于训练截断；SWE-bench Pro 多层控制=GPL+商业排他协议+held-out 永不发布；防污染五测试=13-gram+embedding 相似度>0.85 丢弃+canary replay（held-out 5% 切片）**（来源：qaskills + aiwiki LiveBench + SWE-Pro + syncsoft）——canary 与动态。判据：**canary 可归因不可当凭证；题源新鲜度=结构免疫；多法律+技术层**。提升层：工作流。
10. **生产 eval 卫生（与训练数据隔离）：fine-tune 评估=同题同 rubric 同 judge 同周打分 base，价值在 delta；0.3 分提升在 50 样本上是 judge 噪声，需 1000 次重采样；MLflow eval 三保证=训练/验证严格分离+golden 答案带出处+覆盖真实场景；防评测污染=私有持续刷新套件+公开基准并存；每次 postmortem 问"什么 eval 会抓住这个？"**（来源：futureagi + MLflow + agentpatterns hardening-evals）——生产卫生。判据：**eval=回归非无偏精度；fine-tune 价值=delta；postmortem 反哺 eval 集**。提升层：工作流。
