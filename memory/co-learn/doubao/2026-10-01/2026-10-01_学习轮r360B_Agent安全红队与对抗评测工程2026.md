## 独点（10）

**1. 动态红队基准（RIFT-Bench 表示驱动：Discovery 结构提取+Scanning 自适应攻击；105 探针跨向量）**（来源：arXiv RIFT-Bench 2606.23927 2026-07-06 实拉）：动态红队=表示驱动方法论统一评估跨架构 agentic 系统；两自动阶段=Discovery（提取系统结构）+Scanning（执行自适应对抗攻击）；用 105 个自适应对抗探针跨多样攻击向量和目标直接评估系统。判据：**动态红队=Discovery 结构提取+Scanning 自适应攻击；105 探针跨向量统一评估**。提升层：工具/工作流。

**2. 黑盒红队分类驱动框架（SAGE-RT 全自动生成对抗场景；不依赖内部 trace/hooks→跨系统 apples-to-apples）**（来源：arXiv 2609.09647 2026-09-10 实拉）：黑盒红队=分类驱动框架自动化风险发现——许多生产 agent 不暴露内部 trace/hooks；SAGE-RT 流水线全自动生成对抗场景；无内部依赖→跨系统 apples-to-apples 比较。判据：**黑盒红队=分类驱动全自动（不依赖内部 trace/hooks）；跨系统可比**。提升层：工具/工作流。

**3. 自主攻击 agent 闭环三阶段（DTAP-RED：恶意目标→选注入向量（user prompts/工具描述/环境数据）→闭环迭代）**（来源：alphaXiv DTap 2605.04808 2026-05-06 实拉）：可扩展漏洞发现=DTAP-RED 自主 agent 攻击其他 agent；闭环三阶段=①攻击优化生成（恶意目标下决定最佳注入向量——可目标 user prompts/工具描述/环境数据如 RAG/记忆）②执行③结果反馈迭代。判据：**攻击 agent=恶意目标→选注入向量（prompt/工具描述/环境）→闭环迭代**。提升层：工具/模型。

**4. 红队-蓝队-紫队三阶段（红=主动探测；蓝=运行时监控响应；紫=闭环关联攻击调检测规则自动改进 guardrails）**（来源：OWASP GenAI Security 2026 实拉）：运营期=持续演化威胁；红队=自主 agent/prompt fuzzing/记忆投毒主动探测；蓝队=运行时行为监控/异常检测/用 AI 特定安全控制响应；紫队=闭环反馈系统关联攻击与告警、调检测规则、自动改进 guardrails——持续安全而非时点测试，防御动态适应。判据：**安全运营=红（主动探测）/蓝（运行时监控）/紫（闭环调规则）三队；持续非时点**。提升层：工作流/可复用 Skill。

**5. 红队对抗训练自改进（自动化红队模型缩放发现漏洞→对抗训练加固→分层护栏；弱模型对注入高度脆弱）**（来源：GPT-Red 2026-07-15 实拉）：自动化红队模型缩放发现漏洞能力→部署前修复；GPT-Red 是强红队者（之前模型对其 prompt 注入高度脆弱）；用 GPT-Red 对抗训练 GPT-5.6 更鲁棒；持续扩展+人类/第三方红队+分层防护。判据：**红队自改进=自动化红队模型缩放发现→对抗训练加固→分层护栏**。提升层：模型/工作流。

**6. 四阶段红队方法（CSA：准备（隔离测试环境）→执行（逐步+日志捕获）→分析→报告；目标=推理/工具/委托/动作全链）**（来源：CSA Agentic AI Red Teaming Guide via agentic-ai 2026-09-28 + DeepTeam 2026-08-22 实拉）：CSA 四阶段结构化方法=准备（定义测试场景、设隔离测试环境、备工具脚本）→执行（逐步测试、实时观察文档、捕获日志指标）→分析→报告；agentic 红队目标全自主流水线=推理规划（重定向目标/忘记 system prompt 约束）、工具调用动作（越权/工具投毒/输出注入）、委托子 agent、真实世界动作。判据：**红队四阶段=准备（隔离环境）→执行（逐步+日志）→分析→报告；目标=推理/工具/委托/动作全链**。提升层：工作流/可复用 Skill。

**7. 轨迹级手动测试（评估完整动作序列非单步；每步安全但结果有害最危险；持续测试因模型/工具/记忆演化）**（来源：swarmsignal 2026-04-07 + SIRAJ 2026 实拉）：轨迹级手动测试=设计域特定多步攻击场景、评估完整动作序列而非单步——最危险漏洞是每步都看着安全而结果有害；持续测试非时点评估——模型更新/工具变化/记忆累积都改攻击面；上月红队不反映今天攻击面→自动化红队持续跑；SIRAJ=黑盒任意 agent 通用框架（agent 定义→多样种子用例覆盖风险结果/工具轨迹/风险源→基于前次执行轨迹迭代构建精炼对抗攻击+蒸馏控成本）。判据：**轨迹级=完整动作序列评估（每步安全但结果有害）；持续测试因模型/工具/记忆演化**。提升层：工作流/可复用 Skill。

**8. 四层威胁架构与跨层链式攻击（应用/模型/工具/数据四层；基准=819 用例三范式+语义物理双验证+OS 状态回滚）**（来源：Straiker 2026-05-12 + arXiv LITMUS 2605.10779 2026-08-30 实拉）：四层 agent 威胁架构=应用层（编排/审批门/agent 目标劫持/rogue agents）+模型层（prompt 注入/jailbreaks）+工具与 MCP 连接层（工具投毒/输出注入/代码执行）+数据层（RAG/记忆投毒）；攻击典型跨层链式=模型层注入起、每步看似安全结果有害；LITMUS=819 高风险用例组织成有害种子集+六攻击扩展子集覆盖三对抗范式（jailbreak 修辞/skill 注入/实体包装）+语义-物理双验证机制+OS 级状态回滚设计。判据：**威胁面=应用/模型/工具/数据四层；攻击跨层链式；基准=819 用例三范式+语义物理双验证+状态回滚**。提升层：工作流/工具/可复用 Skill。

**9. jailbreak 六类与五族攻击（角色扮演覆盖/编码绕过/多轮漂移/间接注入/系统提示词提取/对抗后缀；启发式 ASR 70-85% 跨模型最佳）**（来源：Future AGI 2026-05-20 + qiyanjun 2026SP 课程 + arXiv 2606.18193 2026-08-15 实拉）：六类 jailbreak=角色扮演覆盖/编码绕过/多轮漂移/间接注入/系统提示词提取/对抗后缀；攻击族基准 ASR=启发式（LAA/GPTFuzz 70-85% 跨模型最佳）/混淆（Base64/DrAttack 55-70% 避检）/反馈（TAP/PAIR 45-64% 新攻击发现）/微调（MasterKey 34-52% 需开源模型）/参数（生成利用 68% 白盒优化）；家族=自适应搜索/说服（权威框架欺骗）/静态混淆。判据：**jailbreak 六类+五族（启发式 ASR 最高 70-85%）；说服族=权威框架欺骗**。提升层：模型/工作流。

**10. 三层防线与 CI 红队门（eval 离线回归/guardrail 运行时拦截/observability 事后发现；版本化对抗集 500-5000+judge 评分+回归率阻断合并）**（来源：QASkills 2026-06-08 + Future AGI CI 2026-05-14 + mfm-copilot 2026-08-02 + GuardionAI 2026-03-27 实拉）：三层=evals 离线回归（固定数据集评分质量/准确/安全）→guardrails 运行时（请求路径拦截/改写/升级单个输入输出）→observability 事后（trace/日志/聚合真实生产行为找 evals+guardrails 漏的）；每层答不同问题；CI 红队三层=版本化对抗测试集（500-5000 prompts 映射 OWASP 类别每次 prompt/模型变更重跑）+LLM-judge 评分器（安全/忠实/政策合规）+告警回滚门（回归率超阈阻断合并）；gateway 清单=间接注入韧性/工具调用检查（拦截验证 MCP 出站调用参数）/工具输出消毒/PII 密钥脱敏/外泄防护。判据：**三层=eval 离线+guardrail 运行时+observability 事后；CI 门=版本化对抗集+judge+回归阻断**。提升层：工作流/可复用 Skill。
