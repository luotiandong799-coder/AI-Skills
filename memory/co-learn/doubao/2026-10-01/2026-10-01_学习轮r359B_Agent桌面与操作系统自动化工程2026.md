## 独点（10）

**1. 可访问性树优先于像素（元素身份+稳定 ref 点击，布局移位不漂移）**（来源：DEV devandrew 2026-09-25 + fazm.ai 2026-05-27 + TechRounder 2026-03-30 实拉）：早期实现纯视觉——截图猜 (x,y) 坐标→窗口移动就错+token 重（持续截图分析）；新一代服务器查系统 accessibility tree——结构化 UI 元素列表带语义 role/labels/稳定对象标识符；按元素身份点击而非猜测坐标——布局移位/窗口移动/显示缩放不漂移；限制=自定义 UI/canvas 失效（约 60% 覆盖）；token 高效得多（结构文本非像素）。判据：**桌面定位=可访问性树优先（元素身份+稳定 ref），纯像素猜测坐标在布局移位时漂移**。提升层：工具/工作流。

**2. 双流混合融合（树快照+像素双轨，VLM 预测坐标吸附到树 bbox；99%+ 定位）**（来源：DEV agdex 2026-09-29 + frankx.ai OmniParser 2026-08-18 + fazm.ai 2026-04-05 实拉）：生产标准=agent 内存维护活动 accessibility tree 快照同时采屏幕像素——VLM 预测目标视觉元素时运行时把坐标吸附到树中最近有效 bbox，消除单像素误点；纯视觉=100% 通用但脆、纯树=60%（custom UI/canvas 挂）、双流混合=98%（优雅回退）；OmniParser=像素视觉+底层树元数据融合 99%+ 定位；归一化坐标映射（模型输出 0-1000→物理分辨率亚像素精度）。判据：**双流=树快照+像素双轨，VLM 预测坐标吸附到树 bbox（99%+）；归一化坐标映射亚像素**。提升层：工具/模型。

**3. 桌面 MCP 显式工具白名单（--tools 限制 registry/文件危险操作；运行时配置可审计）**（来源：DEV devandrew 2026-09-25 + LobeHub UIAutomation/computer-use 2026-10-01 实拉）：Windows-MCP 200 万+用户最经战——靠 Windows UI Automation 树极快；强烈建议显式工具白名单（--tools "Screenshot,Click,Snapshot" flag）限制 registry/文件等危险操作；computer-use MCP=截图+UI Automation+鼠标键盘；运行时配置 ~/.computer-use/config.yaml 或 COMPUTER_USE_CONFIG 环境变量。判据：**桌面 MCP 必须显式工具白名单（禁 registry/文件写危险操作）+运行时配置可审计**。提升层：工具/工作流。

**4. 本地后端权限规则（operations read/write+paths glob；无限制 shell 仅限可信本地）**（来源：LangChain Deep Agents 2026-10-01 + 2026-09-23 实拉）：定义权限=传规则列表（operations read/write + paths Glob 模式）；LocalShellBackend=直接文件系统读写+无限制 shell——仅适用本地开发 CLI/可信个人环境/CI 正确密钥管理；不适用生产/多租户/处理不可信输入；Open Interpreter 类=生成代码控制桌面但强制用户验证+容器化沙箱隔离。判据：**本地 agent 权限=按路径 glob 白名单（read/write），无限制 shell 仅限可信本地环境**。提升层：工具/工作流。

**5. 分级隔离（L1 路径守卫工作区白名单+防遍历；L2 VM 路由 WSL2/Lima；sandbox-exec 只限文件不限网络）**（来源：Bright Coding 2026-07-16 + OpenAI Agents sandbox 2026-09-26 + Awesome Agents 2026-04-19 实拉）：L1 Path Guard=文件操作限指定工作区（fs-extra+路径验证中间件防目录遍历 ../ 攻击）；L2 VM Isolation=Windows 自动检测 WSL2 路由 Bash 命令/macOS 接 Lima VM Linux 容器隔离+rsync 双向文件同步；UnixLocalSandboxClient=macOS 用 sandbox-exec 文件限制但无网络隔离、Linux 无 OS 级限制；Agent Safehouse=单 shell 脚本生成 sandbox-exec profile 零依赖。判据：**本地隔离=路径守卫（工作区白名单+防遍历）+VM 路由（WSL2/Lima）；sandbox-exec 只限文件不限网络**。提升层：工具/工作流。

**6. OS 级沙箱原语（内核强制 Landlock/Seatbelt/ACL+进程命名空间+超时终止，用户态不可绕过）**（来源：dreaming.press MXC 2026-07-28 + QwenPaw 2.0 2026-07-29 实拉）：MXC=跨平台策略驱动沙箱（Windows/Linux/macOS），Windows 和 WSL 内嵌为原语、MIT 开源+TS SDK 包装 agent 工具调用；QwenPaw=进程逃逸防护（Linux PID 命名空间/Windows Job Objects 限制进程可见性与传播）+资源耗尽超时（强制终止超时进程防无限循环）——内核强制（Linux Landlock LSM/挂载命名空间、macOS Seatbelt、Windows 安全 token+ACL），用户态代码无法绕过；文件系统隔离按目录细分权限。判据：**OS 级沙箱=内核强制（Landlock/Seatbelt/ACL）+进程命名空间+超时终止，用户态不可绕过**。提升层：工具/工作流。

**7. 桌面 agent=API 缺失时的自动化路径（虚拟鼠标键盘完成无 API 应用；可达本地文件与内部工具）**（来源：Microsoft Copilot Studio 2026-07-03 + Simular Sai 2026-09-08 + aisuitehq 2026-09-30 实拉）：computer use 让 agent 与 Windows 网站和桌面应用交互（选按钮/选菜单/输文本）——即使无 API 直接连接也能完成任务；Sai 类=见屏动鼠标/敲键/点击跨桌面应用+网站+文件而非调 API——可达本地文件/已装桌面软件/无公共 API 内部工具（跑用户机器或供应商 VM）；计算机控制 AI=第二员工（开应用/点按钮/敲字/拷文件/读屏），任务如更新账本/下载发票/填表无人值守后台跑。判据：**无 API 应用=虚拟鼠标键盘路径；桌面 agent 扩展可达本地文件与无 API 内部工具**。提升层：工具/工作流。

**8. 混合回退矩阵（视觉 100% 通用/树 60% 高效/混合 98% 平衡；方案选择=速度×准确×数据离设备）**（来源：DEV agdex + Devpost Orbit 2026-09-28 + fazm.ai 2026-04-05 实拉）：三维度比较=纯视觉 grounding 100% 任意像素、OS 树 60%（custom UI/canvas 失败）、双流混合 98%（优雅回退）；accessibility tree 在旧软件和现代 web app 上会断——纯视觉方案（Orbit 类视觉 AI 模型把屏当像素图）覆盖全 Windows 生态；三种方法决定速度/准确率/多少数据离开设备（视觉=数据离设备多、树=本地结构化）。判据：**回退矩阵=视觉 100% 通用/树 60% 高效/混合 98% 平衡；树在 legacy+现代 web 失效→视觉兜底；方案选择=速度×准确×数据离设备**。提升层：工作流/模型。

**9. DOM 级合成训练数据（headless 渲染+DOM 直读 bbox 免 OCR/人工标注；同族蒸馏教师-学生）**（来源：arXiv WinDOM 2606.25964 2026-09-17 实拉）：GUI grounding 训练数据=headless 渲染开源 Windows 11 web clone（Win11React）直接读 DOM 布局矩形——消除 OCR 与人工标注；语料 WinDOM=500 轨迹/2013 截图/54,425 grounding 记录；post-training=冻结更大同族教师（cross-size）+EMA 学生。判据：**GUI 定位训练数据=headless 渲染+DOM 直读 bbox（免 OCR/人工标注）；同族蒸馏教师-学生**。提升层：模型/工作流。

**10. Windows UIA 工具面（树查询深度可配+按语义找元素+稳定 ref 重试安全，免 CV 模型）**（来源：Microsoft Learn Windows 365 for Agents 2026-05-22 + PyPI windows-use 2026-09-27 + npm agent-desktop 2026-09-23 实拉）：mcp_accessibility_get_accessibility_tree=取前台窗口 UI Automation 树（深度/元素数可配）；按文本/role/可访问名找元素返回可点击屏幕坐标（按钮/文本框/复选框/菜单/组合框精确瞄准）；windows-use=GUI 层控 Windows 读 UIA API 任何 LLM 决定点击/键入/滚动/运行——无需 CV 模型；agent-desktop（Rust）=树+ref 稳定+动作可安全重试（snapshot→qualified-ref→click）。判据：**桌面工具面=树查询（深度可配）+按语义找元素+稳定 ref 重试安全，免 CV 模型**。提升层：工具/可复用 Skill。
