## 独点（10）

1. **授权链衰减约束：子授权 token 不晚于主体过期、scope 不宽于主体、吊销原子传播到后代**（来源：IETF OAuth Agent Grants + DAAP）——delegated token MUST NOT expire later than subject token；MUST be sender-constrained；scope set no broader；Authorization Servers MUST propagate grant revocation to all descendant grants atomically。判据：**授权链的衰减=到期不晚于父、scope 不宽于父、吊销原子传播到后代**。提升层：模型。
2. **凭证生命周期三动作：scope→rotate→revoke 是一个控制环**（来源：guptadeepak + systemshardening）——scope to the task not the agent；rotation 连续不可见（fresh token 在旧 token 过期前取）；revoke 需要即时通道；Vault Agent sidecar 在过期前自动轮换。判据：**短生命周期让轮换连续化，轮换滞后=暴露窗口**。提升层：工作流。
3. **基于证据的轮换：证据驱动 > 日历驱动**（来源：knowledges.cloud）——工具使用模式变化/权限不再被使用/凭据出现在意外上下文 → 立即轮换；与 secret-scanning 告警和 access review job 同一控制环（detect→assess→revoke）。判据：**轮换按证据触发不按日历，暴露-补救间隔是度量**。提升层：工作流。
4. **session policy 交集语义：临时凭据权限=身份策略 ∩ session policy，session policy 不能放大权限**（来源：AWS STS AssumeRole + Well-Architected AGENTSEC03）——15-60 分钟短会话使过期自动；JIT access 程序化授予/撤销；EKS Pod Identity 动态 scope down 不乘角色数。判据：**动态边界=AssumeRole+session policy 交集，临时化是默认**。提升层：工具。
5. **任务级临时凭据：每个 workflow 阶段独立 time-bounded task-scoped 凭据，阶段完成即过期**（来源：AWS AI agent identity）——orchestration 层每阶段取恰好的权限，传给执行 agent，阶段完成凭据过期；长流程要显式处理凭据过期（token refresh+re-auth），否则中途 access denied。判据：**授权粒度=任务阶段而不是 agent 整体；阶段完成=凭据到期**。提升层：工作流。
6. **能力租赁 capability leasing：子 agent 的权限任务完成时过期、可被委托方收回、不静默带入下一会话**（来源：zylos）——capability must expire when task done；revocable if delegating principal loses trust；one-session grant 不 carry over。判据：**授权是租赁不是赠与：任务终了=权限终了，委托方可随时收回**。提升层：模型。
7. **lazy vs strict revocation：本地缓存查过期 vs 每次 introspect**（来源：IETF KAIF）——默认 lazy（denylist 下次刷新查，分钟级延迟）；strict（每次 token use 调 /introspect 实时查）。判据：**吊销策略按威胁模型选：可容忍分钟级延迟用 lazy，高敏用 strict**。提升层：工具。
8. **lifetime is the SLA：自含 token 吊销后暴露=剩余寿命（mean TTL/2，worst TTL）**（来源：mojoauth）——40 分钟任务、1h token：mean 1794s 曝光、719 个请求继续被服务；5min：145s/59 请求；60s：TTL 递减收益拐点。判据：**自含 token 的吊销后暴露=TTL 函数，TTL 是安全的预算不是 UX 参数**。提升层：模型。
9. **JIT identity 事件触发吊销：任务完成/担保人离开/安全事件/风险重分类/评审失败各有时限动作**（来源：aisecuredbydesign + KLA digital）——task completion→JIT expires；sponsor departure→72h 限期暂停待新担保；security incident→Tier3 30 秒吊销目标；review failure→权限不续期=agent 挂起；吊销=全凭据撤销+全会话终止+全下游访问移除。判据：**授权生命周期由事件触发不靠日历：事件→动作有明确时限**。提升层：工作流。
10. **临时委派四态状态机 + exchange token 有效期：Finalized 才是委派生效点**（来源：AWS IAM temporary delegation）——Pending Approval→Accepted→Finalized（exchange token 释放，委派期开始）→Rejected/Expired（inactivity 超时）；provider 权限到期自动失效无需人工清理；CloudTrail 全程审计。判据：**跨主体临时委派要显式状态机，Finalized 才是委派生效点**。提升层：工具。
