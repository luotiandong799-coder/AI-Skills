## 独点（10）

1. **Evol-Instruct 进化四算子 + 三层多样性：deepen（改写成需多步推理+额外查找）/broaden（引入新约束维度）/obscure（隐藏信息使更难）/elimination（删除提示信息）+生产版第四算子 hostile rephrasing（红队改写）；persona-prompted 产生措辞与意图变化、taxonomy-stratified 保证覆盖关键单元——"生产流量永不自然浮现的多跳与对抗尾巴"靠进化制造**（来源：futureagi how-to + definitive guide）——进化生成。判据：**种子集太小或太简单时用进化算子扩难；覆盖面按 taxonomy 分层保证**。提升层：工作流。
2. **Teacher 天花板与六步预训练合成管线：teacher 质量是学生质量硬上限（弱 teacher 产出缺陷样本学生照单学）；管线=多样 prompt 模板覆盖目标域→最强可用 teacher 生成→多级过滤（格式校验/去污/质量评分/执行验证）→与高质量自然数据混合（典型 20-50% 合成）→训练小 pilot 模型验证数据质量→按 pilot 评估迭代生成 prompt；teacher 只在生成期运行**（来源：ai-tldr + kindatechnical）——蒸馏管线。判据：**合成数据先过 pilot 模型验证再全量投入；合成占比 20-50%；teacher 选最强**。提升层：模型。
3. **三层去重：exact（哈希归一化文本，典型去 3%）→ near-duplicate（MinHash/LSH ~0.8 Jaccard 字符 shingle，合成数据自相似远高于网页文本典型去 22%）→ semantic（embedding 聚类每簇设上限抓意译）；embedding cosine 0.88-0.92 拒绝阈值（10K 候选典型拒 15-25%）；先 dedup 再质量评分**（来源：selfhostindex + shyankdev + futureagi + prem）——去重。判据：**三层顺序=exact→near→semantic；先 dedup 后评分；每簇设上限防模式坍缩**。提升层：工具。
4. **模型坍缩三防线：混合（每训练周期混新鲜真实数据，≥30% 真实+每三轮加新批真实数据；累积 synthetic+real 而非 replace——"Is Model Collapse Inevitable"：累积时稳定，替换时坍缩）；保留 held-out 真实评测集永不碰合成；重建（需要更多数据时从原始种子重新跑生成管线，绝不拿上代输出当种子——递归陷阱）；过滤合成可避免退化甚至增强（相对未过滤数据）**（来源：visualenews + aibuzz + agentbus + aiwiki + shailzajolly）——坍缩防线。判据：**每训练周期保留真实锚定；评测集纯真实；重生成从原始种子**。提升层：模型。
5. **合成 RAG QA 四质量门 + 受约束生成：faithfulness 门（答案必须 grounded 于引用上下文）/diversity 门（问题覆盖 corpus 的 topic/length/complexity/intent）/difficulty 门（易中难按实测比例）/human spot-check 门（锁集前人工抽检 5-10%）；query 生成受约束"只可从此 passage 回答"（防需要外部世界知识的问题）；每 query 加 1-3 个 distractor chunks 教学生忽略无关上下文；faithfulness judge 验证（query/chunks/answer）**（来源：futureagi RAG + mlflow RAGEval + futureagi fine-tuning）——RAG 数据。判据：**四门全过才锁集；生成问题受 passage 约束；训练样本必带 distractor**。提升层：工作流。
6. **合成数据隐私三检测：NND（每合成样本到最近真实样本的 embedding 余弦距离，越大越隐私）；membership inference 对抗测试（训练 adversary 预测记录是否在原训练语料——高于随机即不隐私，不论是否含字面 PII）；attribute inference 检查敏感列+nearest-neighbour distance ratio；罕见离群点最危险（唯一诊断+地区+年龄+入院日期可 linkable，即使姓名 ID 假）；记忆 few-shot 参考=关键隐私泄漏**（来源：arxiv 2604.27014 + qapitol + sqaexperts + privacyneedle）——隐私。判据：**发布合成集前跑 membership inference+NND；罕见组合样本重点审查；禁止记忆参考样本**。提升层：工具。
7. **Data-Prompt 共进化：测试数据与 prompt 指令不再是独立产物而是共同演化——发现失败（合成候选输入跑模型）→人工标注正确性+对错误写短假设（rationale）→围绕 rationale 邻域生成相似输入加入测试集→修订 prompt 指令；SIPDO=合成数据生成器与 prompt 优化器耦合闭循环（生成器产出暴露当前 prompt 弱点的样本，优化器据此增量改进）**（来源：arxiv 2510.12728 + arxiv 2505.19514）——共进化。判据：**每条新测试样本带错误假设；prompt 修订由失败驱动而非直觉；闭环直到失败收敛**。提升层：工作流。
8. **GEPA 进化提示优化：Genetic-Pareto——reflection 模型诊断失败+mutation 生成改进变体+仅 Pareto-optimal 幸存（多指标同时平衡，不塌缩到单一分数）；实证 20-150 数据点优于更多数据；从生产流量导入测试数据（团队标"Bad"的行优先进 reflection）是单步最具影响力优化；DSPy 生态下与 RL 混合是趋势（reflection 比 RL 更样本高效）**（来源：fastrouter + dailydose + hermes-agent + futureagi）——GEPA。判据：**优化用 Pareto 多指标；数据量 20-150 足够；生产 Bad 行优先入 reflection**。提升层：工作流。
9. **尾部保真度退化：合成数据最一致且最重大的局限=数据分布尾部的保真退化（罕见组合/异常属性/稀有事件序列——生成模型学常见、外推罕见差）；缓解=混合真实数据锚定+每三轮注入新鲜真实批+多样生成技术混合（back-translation/规则生成/意译/多 LLM 方法）；低资源验证区（验证器只见小而碎偏的流形切片）选择本身变偏，加剧坍缩**（来源：aibuzz + apxml + openreview）——尾部退化。判据：**保留尾部多样性靠真实数据锚+混合生成技术；验证器的参考分布必须覆盖目标流形**。提升层：模型。
10. **多采样提示与多样性配方：单样本每 prompt 对齐到最典型输出；multi-sample prompting（一次请求显式要多个样本）利用上下文内意识降低重复；随机性放在你的代码（识别哪些参数/实体应变化→生成或手写值池→每次调用随机填 prompt 模板）不放 sampler；temperature 略高于默认但远不到最大**（来源：arxiv 2506.21138 + folarin）——多样性。判据：**多样化参数池在代码层控制；每 prompt 多采样；temperature 中高**。提升层：工作流。
