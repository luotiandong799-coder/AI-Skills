## 独点（10）

**1. 错误分类先行（瞬时→重试退避/永久→回退/关键→保存+升级；恢复前先分类）**（来源：Taskade 2026-07-04 + Will Spurlock 2026-07-14 + AWS Well-Architected AgentLens 2026-09-19 实拉）：Transient（超时/限流/网络闪断/瞬时 5xx）→重试（指数退避+jitter）；Permanent（无效输入/404 缺资源/格式错/认证拒）→回退（更简方法/缓存数据/默认/人工）——重试每次同结果；Critical（预算超/破坏性副作用/安全违规/范围越界）→保存状态+告警人类+可能紧急停止——重试危险；恢复动作前先分类（retries 适用 transient、fallbacks 适用 persistent、真正不可恢复才到人）；指数退避+重试预算防上游大范围失败产生无界重试风暴。判据：**恢复前先分类（瞬时→重试退避/永久→回退/关键→保存+升级）；重试预算防风暴**。提升层：工作流/可复用 Skill。

**2. 自愈根因-信号-响应映射表（OOM/429/死循环各配响应+动作元组计数器）**（来源：Zylos 2026-03-02 + DeepWiki 2026-09-05 实拉）：OOM/内存耗尽=进程退出码 137(SIGKILL)→减小上下文窗口重启+裁剪记忆；API 配额=工具日志 HTTP 429→指数退避+切 fallback 模型；死锁/语义循环=重复分高+进度指标平→注入目标重估 prompt、持续则重启；logical stall=动作元组计数器超阈值→强制转向指令或检查点回滚；三连相同失败=换策略。判据：**自愈=根因-信号-响应映射表（OOM/429/循环各配响应）；逻辑停滞用动作元组计数器检测+强制转向**。提升层：工作流/可复用 Skill。

**3. 渐进升级恢复（self-correct→fallback→degrade→escalate）**（来源：AgentPatterns.ai 2026-07-15 + Taskade 2026-07-04 + Clarion 2026-05-06 实拉）：异常处理决定 agent 恢复继续 vs 灾难性失败（毁状态/丢进度/重复工作）；渐进升级=self-correct（检测错误重试或调整——多数工具错误在此解决）→fallback（更简方法/缓存/默认——permanent 失败的降级但有用路径）→degrade gracefully（降低自主度保用户价值：模型 o1/opus→4o-mini/flash、功能逐层剥离；fallback chain=frontier→更小模型→缓存结果→人工/优雅错误四层决策树）→escalate（带足够上下文升级人类——最后手段）；拒绝用 raw error 面对用户——"小问题胜过大失败"。判据：**恢复=渐进升级（自纠→回退→降级→升级人）；降级=降低自主度保价值（模型降档/功能剥离/部分结果+缺口标注）**。提升层：工作流/可复用 Skill。

**4. 五类错误各配响应（执行/语义/状态/超时/依赖）**（来源：Zylos graceful degradation 2026-02-20 实拉）：Execution errors（工具调用/API）→熔断器+重试；Semantic errors（语法有效但 LLM 输出错——幻觉工具调用/参数幻觉/推理漂移）→验证+语义回退（工具调度校验抓不存在的工具名、JSON Schema 校验抓无意义参数）；State errors（agent 假设与现实错位）→状态验证+检查点；Timeout/latency→自适应超时+部分结果提取；Dependency failures（限流/schema 变化/服务不可用）→熔断+降级替代源；结构性错误 eval 框架能抓（JSON 不解析/缺必填字段）、语义错误更难（调对工具对参数但用错上下文）——上下文验证不可省。判据：**错误分五类各配响应（执行→熔断重试/语义→验证回退/状态→验证检查点/超时→自适应+部分提取/依赖→熔断降级）；结构校验≠语义验证**。提升层：工作流/可复用 Skill。

**5. 可恢复性三保证（进度跨失败存活/exactly-once 意图/可审计重放）**（来源：moai.team 2026-07-02 + Vadim 2026-06-04 + DataAIHub 2026-09-21 + TutorialsLogic 2026-07-26 实拉）：durable execution 三个具体保证——progress survives failure（worker 崩溃/部署滚动→从最后安全检查点恢复不重复副作用）；exactly-once intent（邮件/工单/支付/文件写外部效果只发生一次，即使内部重试多次）；auditability and replay（重建 agent 决定/调用了哪些工具/返回了什么/为何选下一步）；workflow 在等待 API/人批/定时/远程专家时崩溃→从记录状态恢复而非消失或从头盲目开始；durability=持久状态+显式生命周期转换+replay-aware code+幂等副作用+有界重试+取消+足够 trace；游戏存档类比=每关保存、断电从最后存档重载而非重开战役。判据：**可恢复性三保证（进度跨失败/外部效果恰好一次/可审计重放）；等待期间崩溃从记录状态恢复**。提升层：工具/工作流/可复用 Skill。

**6. 检查点与部分成功恢复（步边界快照+待写账本只重跑失败分支+副作用包装）**（来源：agentnative.dev 2026-07-26 + The Neural Base 2026-04-21 实拉）：checkpoint writer 每步边界快照（LangGraph supersteps），可配置持久化模式（write-before-continue/write-in-parallel/write-on-exit）；pending-writes ledger 记录并行批次中已成功步骤的输出——恢复时只重跑失败分支；side-effect wrapper（@task 或 outbox/idempotency-key 层）持久化非确定性副作用结果；node idempotency 必需——网络超时/用户中断后可能重放同节点，副作用必须可安全重复或事务包装；stream_mode='values'（全状态快照）vs 'updates'（节点级 delta 需手动合并最终态）。判据：**检查点恢复=步边界快照+待写账本（只重跑失败分支）+副作用包装（幂等键/outbox）；节点重放安全**。提升层：工作流/可复用 Skill。

**7. 恢复公式（ResumeFromCommittedState+ExecuteOnlyUncommittedWork；副作用幂等键/outbox）**（来源：CSDN 2026-09-29 + EgoistAI 2026-09-06 实拉）：Recovery=从已提交状态恢复+只执行未提交工作——worker/模型/网络/进程随时失败但任务权威状态不能丢；恢复后只继续真正未完成工作、已发生外部副作用不重复执行；不要把全部对话当任务状态（区分权威状态与上下文）；幂等键=每次重试发相同 key——provider 无原生支持就建本地 outbox+唯一性约束（邮件存 fingerprint+provider message id、文件写用内容 hash+原子改名、删操作验证前后资源状态）；预期=重试已提交请求返回原结果而非复制效果。判据：**恢复公式=已提交状态+只执行未提交工作；副作用幂等键/outbox（fingerprint/哈希+原子改名）**。提升层：工作流/可复用 Skill。

**8. 心跳与看门狗（签名心跳+异常评分+watchdog 超时重置）**（来源：aegissecurity.dev 2026-03-27 + Zylos 2026-02-17 + application-architect 2026-02-23 实拉）：synthetic heartbeats=agent 定期发签名心跳带健康与能力声明——心跳缺失触发分层告警；anomaly scoring on decisions=当前决策向量与基线比较（工具使用/参数分布/成功失败比）打异常分；watchdog timers=系统在预设时间内未收到信号就重置——更简单、自主恢复无需外部输入（agent 挂起→watchdog 触发重启）；预防性介入（心跳知系统在跑+跑得如何）；深度健康检查可引发级联故障（依赖慢→深度检查排队耗线程连接→服务本身失败被杀）——依赖检查包熔断器；OpenTelemetry spans 每 span 含 agent_id/tool/decision/policy_version/decision_reason/cost estimate。判据：**存活监测=签名心跳+缺失分层告警+决策异常评分+看门狗（超时自动重置）；健康检查包熔断防自伤**。提升层：工具/工作流。

**9. 恢复有效性度量（五指标+PRR 条件概率+按成功完成计成本）**（来源：arXiv GuardedAct 2609.11264 + arXiv PRR 2606.05806 + FutureAGI 2026-05-20 + AITutorialMaker 2026-09-04 实拉）：GuardedAct 五指标——Recovery Rate（5 分钟内恢复健康百分比）/Collateral Damage Rate（修复后此前未受影响服务降级比例）/MTTR/Rollback Success Rate（健康检查失败时成功回滚比例）/Human Intervention Rate（升级运营比例）；健康定义=p99 延迟在事件前基线 20% 内；PRR=ℙ(Recovered|Perturbation) 条件概率——分离主动恢复与被动回避；层级指标=端到端任务成功率→步级成功率→恢复率→轨迹成本；cost per successful completion（非 per attempt——重试率上升/上下文漂移时塌缩）；p95 per step type 抓慢尾（p95 尖峰常早于可靠性失败几分钟到几小时）。判据：**恢复有效性=五指标（恢复率/附带损害/MTTR/回滚成功/人介入）+PRR 条件概率；成本按成功完成计**。提升层：工作流/工具。

**10. 沉默退化是最危险故障（无异常无重试；幻觉级联=轨迹级审计+下游输入验证）**（来源：Zylos Entropy/SlopCodeBench 2026-06-22 + Galileo 2026-04-06 + arXiv Trajel 2605.24219 实拉）：silent failures 最危险——操作看似成功但质量低于阈值、无异常无重试、输出有效却是错的；幻觉级联=agent 生成虚假信息后用其指导后续决策、链式放大跨系统（库存 agent 发明不存在 SKU→调用四个下游 API 定价库存运货 phantom item→一个幻觉事实触发多系统事件）；轨迹级审计（Trajel 五型幻觉：factual/referential/logical/procedural/scope-based）而非只审最终输出——多数幻觉基准只评最终输出、漏掉中间 Thought-Action-Observation 步起源的失败；运行时工具输出不可信=下游输入验证。判据：**沉默退化=最危险（无异常无重试）；防幻觉级联=轨迹级审计+下游输入验证；语义错误需上下文验证非仅结构校验**。提升层：工作流/可复用 Skill。
