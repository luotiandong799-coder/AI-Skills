## 独点（10）

**1. 多模态架构双模式（全模态单体简单维护便宜但图像密集贵；专家路由规模化控制强=企业主流）**（来源：niteagent 2026-05-25 实拉）：多模态 agent 生产架构=全模态单体（简单/维护跨模态上下文/简单输入最低延迟——但图像密集工作负载贵/每模态控制有限）vs 专家路由架构（生产处理多样输入规模化——路由分派每模态到专门模型再融合结果；企业部署主导模式）。判据：**多模态架构=全模态单体（简单便宜）vs 专家路由（规模化控制强）；企业主流=路由**。提升层：工作流/工具。

**2. 视觉接地三技术（坐标预测 JSON/编号标记引用/空间监督嵌入权重）**（来源：zylos 2026-04-06 实拉）：视觉接地=坐标预测（模型输出 bbox 坐标或点击目标为结构化 JSON——精确交互 UI 元素）/Set-of-marks prompting（截图叠加编号标记→模型按号引用元素非空间描述）/attention-based grounding（训练时技术把空间监督直接嵌入模型权重——Llama 4 早期融合架构）。判据：**视觉接地=坐标 JSON/编号标记引用/空间监督嵌入权重**。提升层：模型/工具。

**3. 图像 token 预算与自平铺（GPT-4o 平铺长边 2048px/tile；细节敏感任务自平铺+位置上下文）**（来源：Laxaar 2026-06-18 实拉）：视觉摄入三关注=分辨率/格式/内容密度；模型有图像 token 预算（GPT-4o 平铺图像最多 2048px 长边/tile）；发 6000px 架构图单图=模型在重度降采样版本上工作；细节敏感任务自己平铺+带位置上下文传 tile 而非依赖模型自动平铺。判据：**图像输入=注意 token 预算；细节敏感自平铺+位置上下文（不靠模型自动平铺）**。提升层：工具/工作流。

**4. 视频帧采样三档（均匀 1-2fps 简单/关键帧 16-64 帧需镜头检测/原生 token 内部压缩；长视频 Video-RAG 检索+采样）**（来源：Linh Truong 2026-05-01 实拉）：视频理解帧采样=均匀帧采样（1-2 fps 最简单——多数开放 VLM 到 ~5 分钟）/关键帧/场景切采样（shot detector 预处理+16-64 帧）/原生视频 token（Qwen3-VL/Gemini 2.5/GPT-5——模型期望视频 tensor/URI 内部处理时间压缩）；长视频=检索（Video-RAG）+帧采样组合（embed+检索相关片段再帧采样）。判据：**视频=帧采样三档（均匀/关键帧/原生 token）；长视频 Video-RAG 检索+采样**。提升层：工具/工作流。

**5. GUI agent 生产模式（读截图决定动作；每动作 guardrail+URL 白名单+逐步 trace+发布前模拟）**（来源：FutureAGI 2026-05-14 + DEV UI-TARS 2026-09-29 实拉）：多模态生产模式=屏幕控制 agent（Project Mariner/GPT-5 computer use——模型读截图决定点击/输入并在浏览器/应用行动）；生产防坑=每动作 guardrails+URL allowlists+每步 traceAI+启动前 persona 驱动模拟；UI-TARS=bytedance 开源 GUI 自动化里程碑——不把 computer use 当通用模型上的提示工程技巧覆盖。判据：**屏幕控制=读截图决定动作；生产=每动作 guardrail+白名单+逐步 trace+发布前模拟**。提升层：工具/工作流。

**6. AgenticOCR 动态解析（查询驱动按需提取；thinking with images 分析布局；解耦检索粒度与页级分块）**（来源：arXiv 2602.24134 2026-08-24 实拉）：AgenticOCR=动态解析范式把 OCR 从静态全文过程转查询驱动按需提取系统；自主分析文档布局（"thinking with images" 方式）识别并选择性识别感兴趣区域；按需解压视觉 token 恰在需要处——有效解耦检索粒度与僵硬页级分块。判据：**动态 OCR=查询驱动按需提取（thinking with images 分析布局）；解耦检索粒度与页级分块**。提升层：工具/工作流。

**7. OCR vs VLM 分工（高量标准用 OCR 吞吐确定；乱/语义用 VLM；多模型按基准测试选择）**（来源：anhtu 2026-06-10 + ofox 2026-04-07 + AwesomeAgents 2026-07-22 实拉）：OCR vs VLM=传统 OCR 仍是高量标准格式工作马（吞吐+确定性输出关键）；VLM 在文档乱/布局重/需语义提取时阶跃改善（布局理解：hard zones 改版就断 vs 推理布局+含义吸收变化；表格/嵌套结构：多页表/合并单元格弱 vs 强抓行/列关系）；2026 无单模型通吃——GLM-OCR 94.62 原始 OCR 基准、Gemini 3.1 Pro 量文档（1M 上下文最低成本）、Claude Opus 4.6 复杂结构化提取；Qwen2.5-VL 72B 开源 OCRBench 877/1000 DocVQA 96.1%。判据：**OCR/VLM 分工=高量标准用 OCR（吞吐确定），乱/语义用 VLM；多模型按基准测试选择**。提升层：工具/模型/工作流。

**8. 视觉文档处理流水线（转图+JSON schema 提示→结构化输出；每字段置信度评分）**（来源：ai-tldr 2026-06-12 + Keerok 2026-05-06 + ailearningguides 2026-05-19 实拉）：视觉文档提取流水线=文档转图（PDF→PNG 页或原生 PDF 输入）→提示（指令+JSON schema+图像）→结构化文本（理想 JSON）；架构=图像编码（高分辨率视觉 token）+视觉-语言融合（统一 transformer 视觉 token 与文本 prompt 并行）+空间推理（维持元素间空间关系：header/table/totals）+结构化输出（JSON/XML）+置信度评分（每提取字段含 confidence score 供验证工作流）；零样本提取；2024-2026 变化=前沿多模态 LLM 端到端读文档（Claude 4.5 读 100 页 PDF 答问/GPT-5.5 一次 API 调用扫描发票提取）。判据：**文档提取=转图+JSON schema 提示→结构化输出；每字段置信度评分**。提升层：工具/工作流。

**9. 多模态 agent 评测基准（AgentVista 七类 25 领域混合工具链；VTC-Bench 32 OpenCV 多工具组合；VisBrowse 视觉原生搜索仍难 ~30-48%）**（来源：智源 AgentVista 2026-02-27 + arXiv VTC-Bench 2603.15030 2026-09-16 + arXiv VisBrowse-Bench 2603.16289 2026-09-17 实拉）：多模态 agent 评测=AgentVista（七大类 25 细分领域高度逼真视觉场景+自然融合混合式工具调用——跨模态长周期工具交互：网络搜索/图像搜索/网页导航/图像处理/通用编程代码化）；VTC-Bench（32 多样 OpenCV 视觉操作评估多工具组合+长程多步计划执行+680 curated 问题）；VisBrowse-Bench（视觉原生搜索工作流主动视觉推理+视觉信息检索——Claude-4.6-Opus 47.6% 最佳、多数模型 ~30%）。判据：**多模态评测=逼真场景+混合工具链基准（AgentVista/VTC-Bench/VisBrowse）；视觉原生任务仍难（~30-48%）**。提升层：工具/工作流/可复用 Skill。

**10. 统一多模态 omni 模型（单模型四模态+统一上下文跨 agent 循环省独立模型；工具栈=PyTorch+HF Transformers）**（来源：NVIDIA 2026-04-28 + jobsbyculture 2026-05-24 实拉）：统一多模态=单模型原生支持文本/图像/视频/音频输入+统一多模态上下文跨 agent 循环（消除独立视觉/语音/语言模型需要）；混合 MoE 核心架构；实用工具箱=PyTorch 主导框架+HF Transformers 标准库（LLaVA/InternVL/Qwen-VL 多数前沿实验室用 PyTorch 训练）。判据：**omni 模型=单模型四模态+统一上下文跨 agent 循环（省独立模型）；工具栈=PyTorch+HF Transformers**。提升层：模型/工具。
