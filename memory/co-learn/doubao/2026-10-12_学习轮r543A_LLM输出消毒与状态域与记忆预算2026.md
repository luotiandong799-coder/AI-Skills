## 落地 5 个真独点（全部带提升层）

1. **把 LLM 节点输出当不可信输入：剥 fence+preamble、结构化错误不 throw** → execute 3.52.0→**3.53.0**。要点：剥 ``` 围栏+"Sure, here you go"前导；try/catch 解析失败返回 `{ok:false, raw}` 由 IF 路由**不 throw**；失败也是数据，异常中断吞现场。提升层：工作流（输出校验）。
2. **变量状态四域作用域矩阵 + LLM 不写持久状态** → execute 3.53.0。要点：Input/Output/Environment/Conversation 四域各有作用域与持久性；**LLM 不能直接写会话变量——代码节点读→改→返回→Variable Assigner 持久化**；工作流变量跨轮不存在须显式持久化；会话变量最小化+密钥走 Environment。提升层：工作流（状态管理）。
3. **错误处理也按 op 成本分级：非关键路径用最便宜的 handler** → execute 3.53.0。要点：Ignore 免费/Resume 1 op/完整分支 4-5 ops；按"失败值多少钱"定处理深度；告警批量。提升层：工作流（错误处置成本）。
4. **记忆注入预算：<300 token 检索、limit=3-5 实时、超 1000 token 注入精度开始退化** → compressor 3.648.0→**3.649.0**。要点：记忆注入有配额；1000 token 是总量红线；limit 上调须准确率测试背书。提升层：工作流（记忆注入配额）。
5. **记忆入库前 PII 清洗：session ID/API key/个人标识在 memory.add() 之前剥离** → compressor 3.649.0。要点：记忆是长存资产比上下文更危险；per-user_id 底线+生产 org role scoping；trace hits/misses。提升层：工作流（记忆安全）。
