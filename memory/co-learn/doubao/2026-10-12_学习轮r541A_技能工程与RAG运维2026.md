## 本轮落地点（4 个真独点，增量判定通过）

### 1. 嵌入模型一索引一模型 + 向量库写入盲区实证（→ context-compressor，升 3.643.0）
来源：n8n-io-n8n.mintlify.app/ai/vector-stores + community.n8n.io/t/305664 + blog.apify.com/live-n8n-rag-pipeline
- **一个索引/集合只允许一个嵌入模型**：模型 A 嵌入、模型 B 查询向量不兼容（维度相同也接近随机）；换更好模型须建新索引、整库重嵌再切换；唯一跨模型例外 = Voyage 4 全家共享同一嵌入空间（最大模型离线索引 + 最小模型在线查询省成本延迟）；rerank 是唯一安全混模型阶段；多语言/廉价场景按模型分立 collection 并按 query 路由。
- **n8n 向量节点能力缺口实证**（13 个 root 节点）：全部支持 Insert；仅 5/13 支持 Update by ID（Azure AI Search / MongoDB Atlas / Pinecone / Redis / Supabase）；Delete 0/13；Insert 模式绑定 LangChain 随机 UUID 不传 ID → 每次运行重复写入同文本（向量数翻倍）；Update Documents 模式无 text splitter 且要求每 item 恰好一个文档。
- **分块与元数据**：chunk 500-1000 字符 + 10-20% overlap + Recursive Character Splitter；metadata 维度必须匹配（Supabase vector(1536)，换 text-embedding-3-large 改 3072）。
- 提升层：工具 / RAG 工程。

### 2. 错误处理器五指令语义 + Incomplete Executions 常开 + 连续错误禁用阈值（→ execute-discipline，升 3.47.0）
来源：help.make.com/fix-errors-and-warnings + academy-content.make.com/intermediate-errors
- **五条错误处理指令语义**：Resume（以替代值继续）/ Ignore（跳过该 bundle 继续处理其余）/ Rollback（撤销）/ Commit（确认已做）/ Break（停当前 bundle 继续下一个）；Ignore 最常用（10 个数据 1 个错，其余 9 个照常处理，错的那个单独记录后手工）。
- **连续错误达到阈值才禁用调度**：普通错误 N 次、致命错误（InconsistencyError）即时禁用。
- **Retry handler**：自动同 action 重试最多 3 次、延迟 5/10/15 分钟，仍失败落 Incomplete Executions；Incomplete Executions 建议常开（保存失败 run 的 blueprint+数据+日志，可改模块设置后从失败模块重放）。
- **死信模式**：每错误路径加 Google Sheets Add a Row（错误信息+时间戳+原始输入）；指数退避 + jitter（0-30% 随机）防重试风暴。
- 提升层：工作流（错误处理）。

### 3. Agent Skills 生态安全实证：stdout 捕获泄露 + 脚本捆绑 2.12x + 安装前审查纪律（→ skill-authoring，升 1.128.0）
来源：arXiv 2604.03070 + arXiv 2601.10338 + matrix.tencent.com（腾讯朱雀 2026-04-24）+ Snyk ToxicSkills
- **调试日志成为最大泄漏面**：17,022 skills 抽样 520 个（3.1%）含 1,708 处凭据泄漏，84% 开发者疏忽；76.3% 只能靠 NL 描述+编程逻辑联合分析检测；3.1% 纯 NL prompt injection 无任何代码；**print/console.log 占漏洞 73.5%——agent 框架把 stdout 捕获进 LLM 上下文窗口，记在日志里的凭据可被自然语言查询取回**；72% 硬编码凭据带 AI 辅助编程签名。
- **恶意 skills 组合攻击**：83 个中 37.3% 组合 Base64 混淆 + 反向 shell 等多模式；89.6% 可利用性经动态沙箱证实。Snyk ToxicSkills：3,984 个公开 skills 中 1,467（36.82%）含缺陷、76 个确认恶意 payload、5 个具名威胁组织；36% prompt injection。
- **风险统计特征**：>500 行 skills 漏洞 2.14x、含脚本 40.6% vs 仅指令 24.2%、依赖≥5 个 47.9%（OR=2.12）。OWASP Agentic Skills Top 10（AST10）2026-04 发布；腾讯朱雀 ClawHub 5 万+ skills 扫描，ClawHavoc 2026-01：1,184 恶意 skills、12 个被入侵发布者账号、24.7 万次安装、230 万美元被盗。
- 安装前审查纪律：①技能含 print/console.log 调试残留 → 查是否硬编码凭据；②脚本型技能（非纯指令）→ 漏洞率近 2 倍，重点审；③>500 行技能 → 更易藏注入；④依赖≥5 个 → 供应链面更大；⑤描述含 Base64/反向 shell 模式 → 拒装。
- 提升层：工作流（安全治理）。

### 4. Pipedream 组合约束：dedup 三策略优先 + trace_id 跨重试稳定 + platform axios 调试性（→ execute-discipline，升 3.47.0）
来源：pipedream.com/docs + downloads.flaviocopes.com/practical-debugging.pdf
- **每执行 trace_id 跨自动重试稳定**：同一原始事件的重试可关联——排障时先按 trace_id 聚合重试序列，再谈修复。
- **内置 dedup 策略 unique/greatest/last 优先于自定义**；轮询 source 用 $.service.db 缓存最近处理 ID/timestamp、增量扫描（scanDeltaItems）；默认轮询 15 分钟启发式。
- **HTTP 一律用 @pipedream/platform 的 axios**：标准 axios 对 4XX/5XX 不返回可调试数据。
- 调试器 vs 打印判别：打印调试每问一次=一次编辑+重跑循环，调试器可停在扩散前冻结时刻；条件断点（500 次跑 1 次失败时设 item.price===undefined）；回归测试拿最小失败输入永久保留，"无测试的修复是临时修复"；日志禁记整对象/凭据。
- 提升层：工具 / 工作流。
