## 三、提炼的核心方法与关键事实
1. **Token 预算分配公式**：total×0.85+15% 输出 buffer；system≤12% capped；history 35% decay；tools≤4096。
2. **生产分配比例**：system 10-15%/tools 15-20%/retrieval 30-40%/history 20-30%/buffer 10-15%。
3. **降级顺序与多级预算**：4 轮工具→512 字节截断→移除更旧；per_turn/per_story/per_feature 三级软预算+模型路由升级。
4. **token 用量监控**：per workflow/agent/tool call 记账；突增三因（prompt/循环/无界增长）。
5. **context=attention budget**：硬限+effective-capacity+U 形注意力（lost-in-the-middle）；组件范围表。
6. **两层记忆 token 效率**：LoCoMo +18.7 点、4x；memory-aware 模型选择；记忆条目有成本。
7. **stuff vs retrieve+缓存**：S<<Weff stuff/S>>Weff retrieve/中间 hybrid；system prompt 缓存断点；80-90% 成本削减。
