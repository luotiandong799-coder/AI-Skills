## 独点（10）

**1. SKILL.md frontmatter 官方硬约束+500 行红线+三层定义**（来源：Anthropic《Skill authoring best practices》2026-03-12 + platform.claude.com《Using Agent Skills with the API》2026-09-04 + CSDN《agentskills.io 三层》2026-09-26 实拉）：**name≤64 字符、仅小写字母数字连字符、禁 XML 标签、禁保留词（anthropic/claude）、必须匹配父目录名；description≤1024 字符非空、禁 XML 标签、写 what+when；上传总大小<30MB 未压缩；SKILL.md body<500 行——接近上限时把细节移 reference 文件+SKILL.md 里写清楚何时读每个 reference+大文件（>300 行）加目录表**；**agentskills 规范三层=文件格式层（字段命名/层级/数据类型约束，保证跨平台解析一致）/能力发现层（Agent 运行时如何扫描索引过滤 Skill：摘要最大 token 限制、前置条件表达语法）/执行语义层**；frontmatter 允许字段=name/description/license/metadata/compatibility/allowed-tools；Claude Code 扩展字段（disable-model-invocation/user-invocable/context/agent/model/hooks/argument-hint）**非基础规范，跨平台可移植性=只依赖基础字段**。提升层：可复用 Skill。

**2. 技能写作纪律=不写废话+Gotchas 最高信号章节**（来源：Claude《Lessons from building Claude Code: How we use skills》2026-06-03 + 腾讯云转译 2026-06-19 实拉）：**不写废话=Claude 已会写代码会读仓库，Skill 里重复默认能力=浪费上下文，只写能把 Claude 拉出默认行为的信息（例：frontend-design Skill 专门纠正 Inter 字体/紫色渐变 AI 味审美）；Gotchas 章节=整个技能里最高信号内容，从常见失败点积累（例：subscriptions 表是 append-only），理想情况下随使用不断更新；description 要具体含关键术语+同时写做什么与何时用；例子具体非抽象；文件引用一层深；渐进式披露（progressive disclosure）按需展开；工作流有清晰步骤**。提升层：可复用 Skill。

**3. 市场提交管线与 secrets scan 审计门**（来源：Agent Skills Marketplace《plugin-structure》2026-09-10 + Tons of Skills《Publish Guide》2026-08-04 + Skills Directory《Promote Skill》2026-05-29 实拉）：**标准提交流程=GitHub 仓库含 SKILL.md→URL 提交→自动化安全分析→管理员审核→上架；Tons of Skills 验收=所有 SKILL.md 结构化 body+标准验证零错误+企业验证 B 级（70+）分+marketplace.extended.json 正确分类+pnpm sync-marketplace 执行**；**发布前 secrets scan=正则扫 password/passwd/secret/token/api[_-]?key/PRIVATE/cookie/credential，真值不允许、环境变量名允许；发布脚本 public_skill_audit.py=无 HIGH 可继续/有 HIGH 先消毒；外发请求--execute 显式门控（发布脚本会把仓库 URL/作者邮箱/SKILL.md 全文发到市场端点，需显式确认）**。提升层：工具。

**4. SkillHub 三线并行安全审核+发布规范**（来源：腾讯《SkillHub 专为中国用户优化》2026-09-18 + 腾讯云《Skills 介绍》2026-07-14 + 抖音 SkillPay 干货 2026-08-11 实拉）：**每个 Skill 上架必须过三线并行安全审核流水线=内容合规过滤+科恩实验室深度漏洞扫描+云鼎实验室 AI 模型安全评估，全部通过才自动上架、任一不过即刻拒绝；frontmatter=slug/displayName/version/summary/license；发布建议=描述清晰准确（名称描述反映功能避免误导）/文档完整规范（SKILL.md 结构清晰+示例充分+限制说明明确）/遵守分类标准/--visibility 控制 public/unlisted/private/org 四档**；**高质量 Skill 三判定标准=确定性高+通用性强+文档清晰+输出格式相对固定；避坑=切勿搬运（平台校验原创度）/注意隐私（禁含私密数据或敏感 API Key）；企业共享 Skills 沿用上架时安全报告不重复触发检测（企业管理员审批中心可看完整安全报告）**。提升层：可复用 Skill。
