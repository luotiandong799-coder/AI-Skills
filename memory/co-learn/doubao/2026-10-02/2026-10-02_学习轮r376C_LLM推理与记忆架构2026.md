**1. 测试时计算三发现与 compute-optimal 策略**（来源：arXiv 2604.10739《When More Thinking Hurts》2026 + Wei Xu《Scaling LLM Test-Time Compute Optimally》2026 + skillgen《Test-Time Compute 2026》2026-05-19 + Zylos《Inference-Time Compute Scaling》2026-04-23 + Mr.Technology《GPT-5.5 Pro Parallel Reasoning》2026-05-13 实拉）：**三发现=①边际收益随预算增加显著递减、模型出现 overthinking（更长思考链导致放弃先前正确答案——"more thinking hurts"）②最优策略与问题难度绑定：简单题 Best-of-N 多次采样取最优最有效、难题逐步修订（先答再自我修正）最有效 ③compute-optimal scaling=按 prompt 难度分配推理计算（PRM 进程级验证器搜索 vs 自适应分布更新），简单题少想难题多想；证据链=o3 ARC-AGI 45.1%、DeepSeek-R1 以 70% 更低成本匹配 o1（10-100x 推理 token）；GPT-5.5 Pro=并行推理（多条思考链并行运行像多个特化 agent 再综合）；ThinkBooster=统一 TTC 框架（Python 库+性能/效率联合评测+OpenAI 兼容代理服务+推理轨迹可视化调试器）**。提升层：工作流。

**2. KV cache 压缩四方向与 2-bit cliff**（来源：arXiv 2608.07915《SPECTRA》2026 + arXiv 2607.12550《JoLT》2026 + NVIDIA《KV Cache Compression and Its Infra Problems》2026-06-12 + arXiv 2608.02901《AnchorKV》2026 + arXiv 2607.05399《Benchmarking KV-Cache Optimizations》2026 实拉）：**量化=SPECTRA 谱变换编码把 KV 推过 2-bit cliff（低于 2bit/值质量骤降：每值 4 个级别太少装 outlier-heavy 值，少数大项耗尽级别把小项压成噪声）、KVQuant 敏感加权非均匀量化处理离群值；剪枝=SnapKV 观察窗口一次打分（prefill 末尾 W token 对全历史的注意力一次决定去留，去除逐步记账与"待得久就被偏爱"的累积偏差）、SAGE-KV prefill 后注意力保留子集；低秩=JoLT 部分 Tucker 分解只压 token+feature 轴留 head+layer 轴+旋转低比特残差恢复截断能量（单一 Lagrangian 对偶联合分配 Tucker 秩与残差位宽，单字节预算下近无损 2-3x）；结构=AnchorKV 直接从压缩表示解码而非重建稠密 KV（Triton FlashAttention 式分块：key tile 用时才重建+RoPE 旋转+寄存器内 query 收缩）、FastKV 用 TSP 决策把 KV 预算与 prefill 计算削减解耦**。提升层：工具。

**3. **4. 长上下文评测现实差距**（来源：OfoxAI《LLM Context Windows 2026》2026-05-21 + AwesomeAgents《Long-Context Retrieval》2026-05-20 + arXiv 2601.02872《LongBench Pro》2026 + arXiv 2608.20853《MGAL》2026 + Artificial Analysis《AA-LCR》2026-08-05 实拉）：**RULER/MRCR v2/NoLiMa 暴露 30-60 分差距（1M-token 声称 vs 真实精度）；MRCR v2 8-needle=1M token prompt 中找 8 个具体事实（最硬公开配置）；同系模型差距实证=GPT-5.4 mini MRCR v2 8-needle 128K-256K 33.6% vs xhigh 79.3%（官宣上下文窗口不保证可用精度）；LongBench Pro=1,500 双语样本全部天然长文档/11 主任务 25 子任务（细粒度多指标+多维评分）；MGAL=首个多语言粒度感知基准（UN 报告 8K-128K 六官方语言×词/句/段/文档四级粒度×首/中/尾位置分层）；AA-LCR=每问约 100K token 多真实文档推理；结论=长上下文检索与推理是不同能力，须多基准并测**。提升层：工具。

**5. **6. 推理成本度量：FOCUS 公式与 ACE 指标**（来源：Doctor of Digital Transformation《Token Economics 2026》2026-06 + arXiv 2601.22132《Pay for Hints, Not Answers》2026 + GPU Smith《LLM Cost Per Million Tokens》2026-07 + NVIDIA《每 Token 成本》2026-10-01 + AWS《Beyond the price per token》2026-09-11 实拉）：**完全装载每 token 成本=Provider price+Workload tax+Platform overhead−Optimization yield（FOCUS：Unit cost=BilledCost/ConsumedQuantity，四杠杆弯曲比值）；workload tax=长上下文/累积历史/多 agent 调用/隐藏推理 token；ACE（Accuracy-per-Cost Efficiency）=归一化成本-性能指标（shepherding=给大模型提示 hint 而非答案，比直接问答便宜——"pay for hints, not answers"）；每百万 token 成本=统一比较单位（2026-07 横跨四个数量级：DeepSeek 官方 cache miss $0.14/M vs cache hit $0.0028/M=50x 缓存折扣；GB300 NVL72 $0.123/M 116 TPS 最低平台）；名义 token 价低≠cost-per-correct-answer 低（luna $0.0021/correct AIME vs mini $0.0139，选型须按任务正确率计成本）**。提升层：工作流。
