## 独点（10）

**1. 测试时扩展定律与预算匹配**（来源：howardism《Large-Scale Test-Time Compute》2026-07-09 + wanshuiyin《Reasoning Models Tutorial》2026-09-16 + frankx《Frontier Reasoning & Test-Time Compute》2026-08-18 + aiwiki《Test-time compute》2026-10-01 + superteams《Test-Time Compute》2026-09-16 实拉）：**Noam Brown 论点：模型能力是推理预算（tokens/成本/时间）的函数——不指定预算问"模型多强"是 ill-posed，破坏基准/安全评测/快起飞预测；首个预算匹配测试=独立并行采样 > 顺序细化 > 全给单模型；Snell 2024 计算最优配方=best-of-N+PRM beam search+顺序修正混合策略 >4× 优于纯 best-of-N；FLOPs 匹配下小模型+优化测试时计算可匹敌 14× 大模型；扩展随推理计算对数-线性增长（预训练数据墙→测试时扩展接手）**。提升层：工具。

**2. 预算感知推理调度**（来源：iclr《PLAN-AND-BUDGET》2026 + baai《Budget-Aware Value Tree》2026-03-13 + arxiv 2602.09574《BG-MCTS》2026-06-04 + arxiv 2604.19780《BACR》2026-09-16 + papernotes《Elastic Reasoning》2026-09-28 + zylos《Adaptive Reasoning Depth》2026-04-13 实拉）：**固定/均匀预算=次优：简单题 overthinking、难题 underthinking；BAM 原理=按问题难度/模型置信度/成本约束动态分配推理计算；BACR=课程感知预算调度联合优化（4× 优于固定预算）；PLAN-AND-BUDGET=子问题分解+不确定性模式引导预算分配（BAM 原则）；BG-MCTS=预算充足率 ρ=1-C_used/B 作唯一调度变量（剩余预算降→广探索转深精化+削减浅层晚分支）；Elastic Reasoning=总预算拆 thought 预算 t+solution 预算 s 防"一刀切截断砍掉解"**。提升层：工作流。

**3. 推理模型训练方法**（来源：teapot123《RLVR》2025-Fall + arxiv 2606.28166《Tandem RL》2026-09-16 + papernotes《TFPI》2026-06-28 + arxiv 2605.10781《Rebellious Student》2026-09-16 + arxiv 2603.04124《BeamPERL》2026-08-13 + arxiv 2603.29500《PRoSFI》2026-09-30 + aws《RLVR with GRPO》2026-05-07 实拉）：**RLVR=可验证奖励 RL（数学/代码/格式自动验证，0/1 信号）；GRPO=无 critic 组相对奖励（省显存）；R1-Zero=纯 RL 涌现推理；Tandem RL=资深+冻结初级交替共生成（匹配 vanilla GRPO 同时多属性同现：探索/对齐/效率）；TFPI=ThinkingFree 初始化段（跳过显式思考的短上下文 rollout）插在 SFT 长 CoT 蒸馏与标准 RLVR 之间=更廉价高效推理者；RLRT=逆转自蒸馏教师信号（学生教师未预测路径成功=自驱推理价值探索）；BeamPERL=1.5B 参数高效 RLVR（符号求解器二元奖励、无教师轨迹，Pass@1 +66.7%）；PRoSFI=结构化形式中间步+形式验证器逐步验证（7B 不出正式证明也能可靠推理）**。提升层：工具。

**4. 推理预算 API 旋钮对比**（来源：aiworkflowlab《Reasoning Models in Production》2026-09-07 + aiwiki《Extended thinking》2026-09-14 + zero2ai《Reasoning Models》2026-05-24 + aibuzz《Reasoning Models Explained》2026-08-29 + futureagi《LLM Reasoning 2026》2026-05-14 + intuitionlabs《Reasoning Tokens》2026-09 + aiwiki《Reasoning models》2026-09-29 实拉）：**Claude Extended Thinking=唯一暴露整数 budget_tokens 参数+流式输出 thinking blocks 供开发记录与 eval；OpenAI o 系列/GPT-5 reasoning_effort=minimal/low/medium/high（gpt-5 加 auto），思维私有默认、按 reasoning tokens 计费；Gemini 2.5 thinking_budget=Flash 可配 0-24576、Pro 默认开；成本事实：o3 单次调用=同问题 GPT-4.1 的 10-40×；2026.09 官方 output 定价跨度 $4.4-$600/M；Claude Opus 5=$5/$25 per MTok+thinking 另计；生产选型=交互工作低延迟选非思考档、深推理研究才付 thinking 溢价**。提升层：工具。

**5. 自我校验与搜索策略**（来源：particle1331《Scaling Inference Compute with Search and Self-Consistency》2026-06-28 + arxiv 2501.02497《System-1 to System-2》2026-09-16 + wanshuiyin 2026-09-16 + luowle《LLM Reasoning》2026-03-08 + zylos《LLM-as-Judge in Production》2026-04-10 + arxiv 2510.10787《Review of Inference-Time Scaling》2026-09-16 实拉）：**self-consistency=N 采样多数投票（无需 RM，最廉价）；PRM=逐步打分（非仅终答）支持步骤级搜索；MCTS=select-expand-simulate-backprop+价值函数引导（RAP 启发式价值函数：动作似然/状态置信/自评/任务启发式）；rStar=5 推理动作（单步提案/子问题/完整 CoT/分解/改写）+另一 LLM 互一致校验终节点奖励；LATS=LLM score+self-consistency 组合节点值；生产标准=best-of-N+RM ranker，多数投票为最廉价变体；2026 综述三分=推理/搜索/RAG**。提升层：工作流。

**6. 推理轨迹安全**（来源：openai《Disrupting a coordinated model-distillation campaign》2026-09-30 + arxiv 2608.09867《Stealing Reasoning Traces》2026 + arxiv 2608.20055《EchoCoT》2026-09-03 + csa《Reasoning Trace Theft》2026-08-12 + jianyu《Cracking the Vault》2026-08-15 + llm-hacking《REP》2026-06-16 实拉）：**隐藏 CoT 保护不了模型 IP：decryption jailbreak=捕获强模型加密推理块→注入同族弱模型（免费/legacy）解密转写明文（315,320 块跨 OpenAI/Anthropic/Google 重建）；EchoCoT=工具调用是保持隐藏 CoT 的 replay surface（多轮丢弃但单轮工具调用保留）；修复层级=服务端有状态存储（替换客户端签名）、网关跨模型隔离（拒绝非本模型版本生成的 AEAD 信封）、对推理块做最弱模型级防护；2026 蒸馏攻防=OpenAI 7 月首现对抗蒸馏活动处置**。提升层：工作流。

**8. 小模型推理蒸馏与边缘部署**（来源：arxiv 2606.16140《VibeThinker-3B》2026-09-15 + modelscope《Ministral 3 3B Reasoning》2026-07-22 + nvidia《Frontier Reasoning Reaches the Edge》2026-09-04 + deepthink《V4.1 Flash Edge》2026-09-22 + lunadong《Efficient Reasoning on the Edge》2026-07-20 + aratech《VibeThinker》2026-06-30 + nvidia《TensorRT Edge-LLM》2026-09-16 实拉）：**VibeThinker-3B=Qwen2.5-Coder-3B+spectrum-to-signal 后训练（课程 SFT+多域 RL+离线自蒸馏）匹配 300× 大模型结构化推理（~6GB BF16 单消费级 GPU）；Ministral 3 3B=1 块 consumer GPU 本地推理版；边缘优化组合=NVFP4 量化+投机解码（Jetson 6.28× 解码性能优于 BF16）+KV cache 压缩（CED 架构 8B 激活、全局 KV 890 bytes/token 手机级推理）；TensorRT Edge-LLM=Qwen3.6-27B 单 Jetson AGX Thor 52.33 tok/s 完成 MLPerf Edge Agentic 全 1000 任务；预算强制 RL=降低推理冗长（verbosity）**。提升层：工具。

**9. 推理成本工程实践**（来源：dev.minh-leduc《Dynamic Reasoning Budgets》2026-09-17 + nvidia gtc26《High-Performance Inference》2026-09-04 + danilchenko《LLM Inference Efficiency Guide》2026-05-13 + ailearningguides《LLM Inference Optimization 2026》2026-05-21 + 腾讯云《推理延迟吞吐优化》2026-06-18 + arxiv 2609.33184《Speculative Decoding Long-Context》2026-09-29 实拉）：**deep 多千 token 推理保留给异步 agent/后台队列——推理计算是工程拨盘非二元开关、按请求动态校准；部署三件套=KV cache reuse+NVFP4 量化+投机解码（质量无损：输出分布与目标模型数学相同，速度 2-3.5× 依 token 接受率 60-85%）；TurboQuant=polar 坐标 KV 量化每缓存项 6×+QJL 1-bit 修正层（key 误差放大处）；生产 KV 默认 FP16 安全、FP8/INT8 内存压力才量化；KV 显存占 50-75% 可缩；共享 KV cache 跨请求**。提升层：工作流。
