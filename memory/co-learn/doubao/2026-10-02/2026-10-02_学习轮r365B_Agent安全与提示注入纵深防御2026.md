## 独点（10）

**1. 多 Agent 注入威胁模型：14 向量 4 类 + 四防线量化**（来源：arXiv 2609.22949 + IETF draft-jiang-intent-security 实拉）：单模型外三个放大机制=**inter-agent message passing 创造 perimeter 防御看不见的注入通道/共享工具访问使跨 agent 提权/信任传播使被攻 agent 影响上游编排者**；14 攻击向量四类=direct 3/indirect 4/inter-agent 4/cascading 3；四防线=消息签名+来源追踪（inter-agent 注入 -91%）/agent 边界出入消毒（间接注入 -78%）/按角色最小权限工具（提权归零）/**agent 间通信异常检测（级联 84% 捕获）**，整体成功率 31.2%→4.2%；IETF T1=中间 agent 篡改对话历史/派生指令（保持表面连贯）/T2=参数注入越权（custom code executor 逃逸权限边界）。判据：**多 agent 安全必须把 inter-agent 信道当独立攻击面治理——边界消毒+消息签名+通信异常检测三层齐上**。提升层：工具/可复用 Skill。

**2. SafeFlow 语义信息流控制：语义污点+协作图传播+工作流级验证**（来源：arXiv 2607.25255 实拉）：恶意跨 agent 传播是**语义信息流问题而非单轮 prompt 分类任务**；根请求附结构化语义污点→动态协作图传播→**不可逆动作提交前工作流级验证重建全局风险上下文**；七标签方案=SENSITIVE_READ/CREDENTIAL_ACCESS（保护源）/EXTERNAL_SEND/PRIVILEGED_EXEC/CODE_EXEC/DESTRUCTIVE_WRITE（硬 sink）/PROMPT_OVERRIDE（控制面输入）；传播单调直到 staged sink 满足显式释放规则。判据：**跨 agent 风险=给数据打语义标签跟踪到 sink，而非每轮单独猜"这轮是不是攻击"**。提升层：工具/工作流。

**3. Kill-chain canaries：四阶段定位（EXPOSED→PERSISTED→RELAYED→EXECUTED）**（来源：arXiv 2603.28013 实拉）：加密 canary token 跨四阶段跟踪 950 runs/五模型/六攻击面/五防御条件；**中心发现=模型安全不由"是否看到对抗内容"决定，而由"是否跨管道阶段传播"决定**——Claude 在 memory-write 阶段阻断全部注入（0/164 ASR），其他模型继续传播；**防注入点选在管道阶段（记忆写入/摘要）而非输入层**。判据：**安全评测按 kill-chain 阶段打分定位失效点，不只测首轮成功率；记忆写入点=高杠杆拦截位**。提升层：工具/工作流。

**4. Promptware 七阶段 kill chain + 五攻击族**（来源：arXiv 2601.09625 + CSA promptware-C2 + neodrop + Schneier 实拉）：七阶段=Initial Access（prompt injection）/Privilege Escalation（jailbreaking）/Reconnaissance（提取 system prompt/工具配置）/Persistence（memory+retrieval poisoning）/**C2（建立通信信道）/Lateral Movement（自复制传播）/Actions on Objective**；21 起 2025-26 真实多阶段攻击已确认；五攻击族=**memory poisoning（诱导写入新策略规则，后续会话检索即执行）/trust laundering（不可信文档伪装成已批准本地策略）/skill poisoning（恶意技能包元数据带控制内容）/自复制（感染助手转发 payload 指数传播）/C2 relay**；**persistence=瞬态攻击变持久攻击的关键**。判据：**防注入战役级看 kill-chain——persistence 阶段（记忆/知识库写入）是最关键闸位**。提升层：工具/工作流。

**5. NeuroTaint：三类传播检测 + 跨会话溯源恢复**（来源：arXiv 2604.23374 实拉）：运行时检测三类 source-to-sink 传播=**显式内容传播/implicit control influence（隐式控制影响，未直接复制内容但行为被控制）/asynchronous provenance reuse（异步溯源复用，跨事件归因）**；**Dynamic Context Provenance Graph 跨记忆边界与会话重启持久化 taint 标签**，sink 时分析仍能归因早期来源；检索恢复 lineage 但不发判决（分析器再判）。判据：**注入检测要覆盖"行为被控制但内容没复制"的隐式路径，且 taint 状态必须跨会话持久**。提升层：工具。

**6. 运行时能力衰减：Contaminated 标记 + 高风险动作 deny**（来源：arXiv 2605.02812 自复制蠕虫 + AgentAudit 2603.22853 实拉）：暴露读任何不可信内容即保守标记 Contaminated(L)；**能力衰减规则=Contaminated(L)∧AH⇒deny——任何高风险传播动作（发邮件/推送/转账）被阻断**；AgentAudit 四阶段 taint pipeline=source 分类（函数参数/chain.invoke 返回值/request.json）/AST 数据流图/消毒检测（shlex.quote/isinstance/参数化查询绑定降置信 0.20）/sink 可达 BFS。判据：**读脏即降权——读过不可信内容后，高风险动作自动拒绝，不靠模型自律**。提升层：工具/工作流。

**7. AgentWarden 三层自适应治理：动态工具面 + RL 学习最小权限**（来源：arXiv 2604.11839 实拉）：L1 Capability Governor **动态限定每会话 agent 可见的工具集（不可见=不可调用）**/L3 Safety Router 每次工具调用前混合规则+微调 LLM 分类器拦截/L2 PPO 在累积审计日志上学习最小权限策略；**"工具不可见"即治理手段——模型不知道的工具无法被注入利用**；对照静态沙箱（固定白名单）是动态会话级作用域。判据：**最小权限从静态白名单升级为会话级动态作用域+日志驱动的自适应学习**。提升层：工具/模型。

**8. HITL 审批流工程：85% 阈值+payload 持久化+加密签名**（来源：agentnative 2026-03-13 + veto + agentixforce 2026-05-10 实拉）：**置信度低于阈值（常见 85%）或命中受保护风险类→入审批队列（不论动作类型）**；审批请求写入 durable store=精确 payload+完整上下文摘要+agent 推理轨迹+不确定性信号；**批准后 payload 加密签名再执行（防篡改）**；三种 gate=plan review（执行前审计划，长流程防误解累积）/pre-action（单动作，批准后立即继续）/output review（完成但交付前扣住）；**读操作几乎不需要审批——先按爆炸半径分级**。判据：**审批不是"高风险才审"而是"低置信即审"；请求必须带推理轨迹与签名防篡改**。提升层：工作流/可复用 Skill。

**9. 冷读式 canary：把"识别所有攻击 payload"变成"识别这一个字符串"**（来源：rapidclaw 2026-04-20 + toxsec 2026-07-16 + QASkills 2026-08-08 实拉）：高熵字符串植入模型上下文+输出/出站网络调用中监测；**真实用户永不输入随机 hex——出现在响应=确认提取，单行检查**；**检测非防御（不阻止任何攻击但近乎零误报）**；llm-prompt-guard 类把 canary 校验+pii 检测（email/apiKey/creditCard）合一；prompt-guard 双保险=canary 自动替换 [REDACTED:canary]+消毒后重扫（仍 HIGH+ 整体阻断）。判据：**canary 定位=把开放问题"所有攻击长什么样"换成封闭问题"这个串有没有出现"；输出消毒后必须重扫一遍**。提升层：工具。

**10. 容器化沙箱硬边界 + 秘密按任务注入**（来源：cdovey 2026-06-05 + stevenfoerster + NVIDIA + Anthropic contain-claude + OpenShell 实拉）：**容器 flag 比"用了容器"更重要**=docker run --user 1000:1000 --network none --read-only --tmpfs /workspace:rw,size=512m；mount 最小文件系统（不挂 $HOME/Docker socket/cloud metadata/secret 卷）+drop NET_RAW+no-new-privileges+cap CPU/mem；**secret injection per-task（NVIDIA）——沙箱 agent 只收当前任务所需凭据，运行时下发、任务完成吊销，而非继承完整宿主环境**；Anthropic=OS 级沙箱（Seatbelt/bubblewrap）读允许、工作区内写允许、网络默认拒绝，**权限提示降 84%**；OpenShell=Rust 运行时 Landlock LSM+seccomp BPF 零默认权限。判据：**沙箱=内核原语默认拒绝+凭据按任务注入，不是"套个 docker 就安全"**。提升层：工具/工作流。
