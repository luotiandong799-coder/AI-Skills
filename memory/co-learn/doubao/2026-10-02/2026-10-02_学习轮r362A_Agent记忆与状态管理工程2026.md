## 独点（10）

**1. 记忆即执行状态树（MAGE 层次状态树：Grow/Compress/Maintain/Revise 四操作，状态=根到当前路径）**（来源：arXiv 2606.06090 实拉）：MAGE=Memory as Agent-Guided Exploration 主动执行状态管理器——层次状态树存交互；agent 从活动根到当前路径派生状态（子目标摘要+最近轨迹+先前分支提示）；四耦合操作：Grow 记录新轨迹/Compress 摘要完成子目标/Maintain 验证摘要/Revise 恢复目标边界+新分支继续；限定状态空间防爆炸。判据：**记忆状态=层次树（Grow/Compress/Maintain/Revise 四操作）；状态=根到当前路径**。提升层：工作流/可复用 Skill。

**2. 记忆三层架构（episodic 时间戳事件/semantic 蒸馏事实偏好/procedural 技能计划；上下文窗口=缓冲非记忆）**（来源：zylos 2026-05-28 + augmentable 2026-07-27 + mastra 2026-06-22 实拉）：2026 收敛认知科学三层架构=episodic（短时会话状态：特定过去经历带时间戳+结果）/semantic（长期事实与偏好：独立于具体事件的抽象去上下文知识）/procedural（静态指令文件：可复用技能与可执行计划）；上下文窗口=缓冲不是记忆；主流工具分工=Claude 缓存工作记忆/Cursor Merkle 树索引代码/Copilot Codex 跨会话持久知识/LangGraph checkpoint 图状态/Mem0 四作用域（user/agent/run/app）。判据：**记忆三层=episodic/semantic/procedural；上下文窗口是缓冲非记忆**。提升层：模型/工具/可复用 Skill。

**3. 时间边存储（事实带 validate/invalidate 时间戳不覆盖；tri-store=vector+episodic+graph；查询分类器路由）**（来源：roborhythms 2026-05-18 实拉）：长运行 agent 记忆七层非单一 vector store；突破=temporal edges 时间边——每事实带 validate/invalidate 时间戳存储而非覆盖；tri-store=vector+episodic+graph 三存储；查询经分类器路由；支持数千并发。判据：**时间边=事实带生效/失效时间戳不覆盖；三存储+分类器路由**。提升层：工具/工作流。

**4. 状态管理四层（窗口/外部存储/K-V/程序性；各层成本延迟陈旧不同，边界错=生产行为不一致最常见原因）**（来源：zalt 2026-07-03 + dev-imversion 2026-09-29 实拉）：agent 记忆四层=上下文窗口（短期）/外部检索存储（长期语义）/结构化 K-V 状态（会话+工作记忆）/程序性记忆（系统提示或微调权重）；每层不同写成本/读延迟/陈旧风险；边界错=生产行为不一致最常见原因；按 store 选归属=task progress/tool outputs/scratch data/approvals/会话上下文分属不同存储。判据：**状态四层=窗口/外部存储/K-V/程序性；各层成本延迟陈旧不同，边界错=行为不一致**。提升层：工作流/可复用 Skill。

**5. 持久执行 durable execution（外部化状态+副作用幂等+每步 checkpoint；thread_id 锚点可 fork/replay/rewind）**（来源：dataaihub 2026-09-21 + ailearningguides 2026-05-06 + callsphere 2026-05-05 + openlegion 2026-06-01 实拉）：持久执行=每多步 agent 运行当可恢复工作流——外部化状态/副作用幂等/每步 checkpoint；20 步管线第 14 步崩溃=1-13 步 token 工具成本时间全白费；每步 checkpoint 恢复=加载最新 checkpoint 从 14 步续；LangGraph checkpointer=MemorySaver（测试）/SqliteSaver（小规模）/Postgres（生产）；thread_id=长活会话、checkpoint=时间旅行锚点可 fork 新分支/replay 进 eval 数据集/rewind 调试。判据：**持久执行=外部化状态+副作用幂等+每步 checkpoint；thread_id 锚点可 fork/replay/rewind**。提升层：工具/工作流。

**6. Agent 恢复状态机（Running→Checkpointed→Suspended→Replaying 跳过已记录效果；回滚三机制=快照+版本化存储+确定性重放判断）**（来源：agentpatternscatalog 2026-05-31 + getreadyforagents 2026-07-23 实拉）：Agent Resumption 模式=Running→Checkpointed（log effect/persist state）→Suspended（crash/deploy/disconnect）→Replaying（restart）→跳过已记录效果恢复；WorkflowCheckpointer 包装=每完成步捕获+run_from(checkpoint) 从该点续；回滚三机制=已知 checkpoints 的上下文窗口快照+版本化外部记忆存储+确定性状态机（知哪些步安全重放哪些不）；Durable Task 编排状态自动 checkpoint 每 yield 语句。判据：**恢复=状态机（Checkpointed/Suspended/Replaying）+跳过已记录效果；回滚三机制=快照+版本化存储+确定性重放判断**。提升层：工作流/可复用 Skill。

**7. 记忆整合 consolidation（会话间去重重写；sleep-replay 空闲期重放采样合并语义重叠；破坏性不可逆场合不做）**（来源：clawrxiv 2026-04-28 + Auto-Dreamer 2026-06-09 + usewire 2026-05-15 + zylos 2026-04-20 实拉）：记忆整合=重写累积记忆为去重紧凑形式（通常会话间）；sleep-replay=空闲期重放采样片段经 summarizer LLM 合并语义重叠原子；Auto-Dreamer=解耦快速会话内获取与慢速跨会话整合——选定工作区为只读证据+有界工具使用检查条目+来源链接源轨迹→合成新紧凑替换集跨会话抽象+取代旧；整合反面=破坏性不可逆（权威源在别处/带类型来源记忆→整合崩）；SWC 按显著性分区优先级层。判据：**整合=会话间去重重写（sleep-replay+只读证据合成替换）；破坏性不可逆场合不做（带来源/外部权威源）**。提升层：工作流/可复用 Skill。

**8. 检索排序多信号（语义相关+作用域+权威+新鲜+任务适配+置信度-冲突-冗余惩罚；混合 RRF+reranker；recency 指数衰减不清零）**（来源：xbstack 2026-07-16 + mem0 2026-05-13 + theneuralbase 2026-04-22 + elastic 2026-06-16 实拉）：记忆检索是排序问题=语义相关+作用域匹配+权威+新鲜度+任务适配+置信度-冲突惩罚-冗余惩罚（权重按用例调）；生产收敛=混合检索（vector+keyword 并行+RRF 廉价融合）+cross-encoder reranker（20 候选表）；recency=时间衰减（指数 exp(-λ·天数)）或基于上次检索（Mem0 最近 boost 1.5×/闲置 dampen 0.3×——陈旧永不清零最强相关仍赢）；Elasticsearch 生产=RRF over BM25+Jina dense+reranker 0.89 recall 零租户泄漏（copy_to 双索引一次写）。判据：**检索=多信号排序（相关/权威/新鲜/置信-冲突-冗余惩罚）+混合 RRF+reranker；recency 衰减不清零**。提升层：工作流/工具/可复用 Skill。

**9. 记忆评测基准（AgentMemBench 五策略同条件；AgingBench 四老化机制；纵向任期 vector 衰退 vs 图/hybrid 翻盘）**（来源：AgentMemBench 2608.00009 + agingbench 2026-06-04 + arXiv RECON 2607.16716 + EngramaBench 2604.21229 + Ground Truth First 2607.21962 实拉）：记忆评测=AgentMemBench（五策略同一条件：ICW 上下文窗口/EKV 外部 K-V/GEM 图 episodic/CBS 压缩摘要/WAM 网络增强）跨三数据集（LoCoMo/MultiDoc2Dial/persona）；RECON（24 案例 1604 问题——事实不累积还互动矛盾级联，维持连贯演化理解）；AgingBench 四老化机制（压缩老化=写时摘要丢未来相关细节/干扰老化=相似记忆挤占目标事实/修订老化=变更或派生状态更新错/维护老化=生命周期事件 flushing/recompaction）；Ground Truth First 纵向 9 周=vector 75.3→68.8 衰退 vs graph 75.9→90.4 hybrid 80.2→93.2——记忆架构随任期翻盘，短期 vector 赢长期图赢。判据：**记忆评测=五策略同条件对比（AgentMemBench）+老化四机制（AgingBench）+纵向任期翻盘（图/hybrid 长期胜 vector）**。提升层：工具/可复用 Skill。

**10. 会话状态三温层（热=窗口工作记忆/温=vector 摘要偏好检索注入/冷=不可变审计；Mem0 自动化提取冲突解决）**（来源：zylos 2026-06-02 实拉）：会话状态管理三温层=热层（上下文窗口=agent 工作记忆所在）/温层（跨会话语义：vector 库存摘要过去交互+提取用户偏好+已解决问题——会话启动时检索语义相关记忆注入初始上下文；Mem0 自动化提取/冲突解决/多后端存储）/冷层（审计合规：不可变 SQL 或对象存储）；三层每层写成本读延迟陈旧风险不同。判据：**会话状态=热（窗口）/温（vector 摘要偏好检索注入）/冷（不可变审计）三温层**。提升层：工作流/可复用 Skill。
