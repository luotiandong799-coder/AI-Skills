## 独点（10）

**1. SKILL.md 编写规范：Gotchas 节最高信号+description 是激活机制**（来源：anthropic-best-practices + claude-code-lessons + tencent-claude-code 实拉）：**官方十条=description 具体含关键术语+同时写"做什么"与"何时用"/SKILL.md 正文<500 行（附加细节放独立文件）/无时效信息/术语一致/示例具体不抽象/文件引用一层深/渐进式披露/工作流明确步骤**；**Claude Code 实战教训=不陈述显然之事（Claude 已知怎么读代码——只写它猜不到的）、Gotchas 节是最高信号内容（从使用中的常见失败点积累，如"subscriptions 表 append-only"）**；**description 写给模型不是人——会话开始时 agent 列出所有 skills 的 description 决定是否激活；需要用户配置的技能用 config.json+AskUserQuestion 出结构化选择题**；**路径统一 Unix 风格跨平台（反斜杠在 Unix 报错）；别给过多选项（不必要时别提供多方案）**。判据：**SKILL.md 是模型执行指令不是文档——触发靠 description、踩坑靠 Gotchas、细节靠独立文件**。提升层：可复用 Skill。

**2. 技能创建从真实专长提取：LLM 发明=空泛，evals 先行**（来源：webfuse-cheatsheet + skillmd-agentskills 实拉）：**让 LLM 凭空发明技能=产出空泛通用流程——必须从真实材料出发：①从真实任务提取（用 agent 完成真实任务、给修正、提取可复用模式：记哪些步骤奏效/哪些被纠正/输入输出格式/项目约定）②从产物综合（喂 runbooks/API 规范/代码评审意见/issue 追踪/版本控制历史/真实失败案例）**；**六步流程含=feedback loops（跑 validator、修错误、重复——validator 提早暴露问题让 agent 修正后再前进）/全目标模型测试（Haiku 比 Opus 需要更多细节，跨模型测试保证技能全目标可用）/先建 evals 再写文档（评测先找出真实缺口，再写正文，让技能对准实际问题）**。判据：**技能从真实任务与真实产物蒸馏，不经真实任务打磨的技能只是 prompt 模板**。提升层：可复用 Skill。

**3. 技能组合策略与 frontmatter 扩展：Skill 即 API**（来源：claude-skills-guide + mr-technology 实拉）：**多技能组合=任务涉及多文档/多域时组合（数据 Excel 分析+PPT 制作/报告 Word+PDF 导出/自定义域逻辑+文档生成）；避免挂载未用技能（影响性能——每个技能进上下文）**；**frontmatter 扩展成包清单=name/description/version（SemVer）/author/license/runtime（claude-code>=1.4、cursor>=2.0、codex-cli>=0.26 等兼容声明）/mcp（可选依赖如 postgres-mcp）/triggers（激活短语）**；**version 管理策略=SDK 中 container 值控制版本解析**。判据：**技能是可组合可声明依赖的模块——组合按需、frontmatter 声明运行环境与依赖**。提升层：工具。

**4. 分发工具链 2026：四条命令四种安装形态**（来源：skills.sh + skillsmp + agentskills.io + localskills 实拉）：**skills.sh=Vercel 支持的开源注册表（npx skills add <repo> --skill <name>；API 元数据 87 owners/342 skills 可编程查询；VS Code 扩展侧栏浏览/安装/启动/预览 SKILL.md/分享团队）**；**SkillsMP=社区注册表索引 280 万 SKILL.md 文件（npx skillsmp install code-review；默认落 ./ .skills/，全局 ~/.claude/skills；不认证质量——打开源仓库自审）**；**agentskills.io=GitHub CLI 分发实验（gh skill install heygen-com/…，不装新 CLI 用开发者已有命令，一条命令跨 agent 覆盖）**；**localskills CLI=交互式浏览+旗帜跳过（localskills install my-skill --target cursor,claude --project --symlink 指定平台/作用域/安装方式）**。判据：**安装形态按场景选——npx 一次装多工具共享、gh 复用现有命令、CLI 交互挑选、VS Code 侧栏可视化**。提升层：工具。

**5. 腾讯 SkillHub：本土化技能市场+TRACE 评测框架**（来源：skillhub-tencent + tencent-trace + tencent-q3 实拉）：**腾讯基于 OpenClaw 官方开源生态的本土化配套平台（2026-03-11 上线）=13000+ 技能、国内高速镜像节点分发（解决海外仓库下载卡顿）、中文搜索、Top 50 精选榜单、全量安全扫描——兼容 WorkBuddy/QClaw 等 agent 框架与 AI Coding 场景**；**规模数据=月下载 1700 万+、累计 6000 万+次（2026-07 央广网）；全球生态=AI Agent 工具 44 万+、AI Skill 近 30 万、日均新增 1300+**；**TRACE=2026-05-21 腾讯科技+SkillHub+玄武实验室联合发布，国内首个面向 Skill 真实使用场景的严选评测体系，五维度评估质量，以 SkillHub 收录技能为样本持续迭代**。判据：**本土化市场补三痛点=下载加速/中文门槛/质量筛选；评测框架是市场信任基础设施**。提升层：工具。

**6. OpenClaw Skills 加载机制：多根目录优先级+prompt 开销核算+白名单**（来源：docs.openclaw.ai-skills + openclaw-skill-config 实拉）：**加载顺序=agents/skills（最高）→ ~/.agents/skills → ~/.openclaw/skills → bundled skills → skills.load.extraDirs（最低）——按环境/配置/二进制存在性在加载时过滤**；**会话开始快照 eligible skills，会话中两情形刷新=watcher 检测 SKILL.md 变更/新授权远程节点连接——刷新列表下一轮 agent 生效**；**prompt 开销核算=XML 转义把 & < > " ' 展开为实体，每 skill 约 97 字符≈24 tokens——description 必须短且描述性强，技能数量直接线性吃上下文**；**skills.allowBundled 白名单=只列白名单内的 bundled skills 才 eligible（管理/agent/工作区级不受影响）；skill workshop 支持 proposal 状态 frontmatter 标记未定稿技能**。判据：**技能是成本项——每技能≈24 tokens 常驻，白名单+短 description 控开销，加载顺序即覆盖优先级**。提升层：可复用 Skill。

**7. skill-provenance 版本三约定+lockfile 钉版本**（来源：skill-provenance + pm-claude-skillsspec 实拉）：**三约定=①版本身份在文件内（格式允许时）+manifest 必有 ②近期 changelog 随技能包（长历史留源仓库）③manifest 列全部文件供会话验证完整性——SKILL.md 无内部记录谁改了什么=歧义**；**语义化版本=MAJOR=破坏性变更（Output Format/Execution 语义），MINOR=新章节/能力兼容，PATCH=措辞/修复**；**SKILLSPEC=注册分发版本化技能应支持 lockfile（skill.lock 钉 name@version+SKILL.md 规范内容的 sha256）——agent 行为可复现**；**skill-creator 反例=SKILL.md 内禁止版本历史节（## Version/## Changelog/## Release History）与版本号——版本由 git/外部跟踪，body 只留指令**。判据：**版本身份在 manifest、变更可审计、锁文件钉行为——技能包像 npm 包一样版本化**。提升层：可复用 Skill。

**8. 技能库工程化：metadata 六字段+description 是激活触发器不是摘要**（来源：snapsynapse-skill-provenance + devto-skillmd-standard + codex-skills-ecosystem 实拉）：**metadata 六字段=skill_bundle（属哪个包）/file_role（本文件角色）/version/version_date/previous_version/change_summary（这次改了什么）——Codex 严格平台用最小副本**；**技能库=Git 仓库+清晰目录布局（repositories 索引表分类：LIBRARY 全量/DAILY 精选/BEST 定位）**；**description 是激活触发器不是摘要——写"何时触发"不写"它是什么"**；**实现纪律=确定性步骤用脚本实现优先于散文（prefer scripted implementations over prose）；安装前审 SKILL.md 与脚本内容（不信任来源）**。判据：**库结构即索引、metadata 即审计、description 即路由——工程化技能库像代码库一样管理**。提升层：可复用 Skill。

**9. addyosmani/agent-skills：全生命周期技能包设计**（来源：addyosmani-getting-started + firecrawl + devto-hidden-uses 实拉）：**Google 工程实践打包为 24 个生产级技能，贯穿 spec→plan→build→test→review→ship 全生命周期，8 条 slash 命令激活对应阶段技能，任务间强制 test-driven verification**；**设计分层=Skills（工作流：步骤+退出标准，"如何做"）vs Slash commands（入口：用户触发点，"何时用"）**；**以多格式分发=Claude Code 插件/Gemini CLI skill pack/Cursor 规则集/Windsurf 规则集——同一批技能四种载体**；**核心价值=把隐式工程纪律转成显式、AI 可执行的 step-by-step checklist（"senior engineer discipline, packaged as agent skills"）**；规模=85K stars（2026-07）GitHub 最高星技能目录。判据：**技能包按生命周期组织而非按主题堆砌；每技能=工作流+退出标准；多格式分发同源**。提升层：可复用 Skill。

SKILL.md 标准化时间线与生态规模**（来源：anhtu-skillmd-standard + businesstechnavigator-npm-moment + habr-top50 实拉）：**SKILL.md 成为"AI 的 package.json"=发布时间轴：Anthropic 发布后 48 小时内微软集成 VS Code、OpenAI 加入 ChatGPT 与 Codex CLI；2026 年 3 月 32+ 工具读同一格式（Gemini CLI/Junie(Kira)/AWS Kiro/Block Goose…）——格式先于厂商，单一目录结构即插即用**；**生态规模=awesome-skills 22k stars v7.3.0 1234+ 技能兼容 Claude Code/Cursor/Gemini CLI/Copilot 等 5 工具；Anthropic 官方 frontend-design 单技能 277k+ 安装；TOP-50 技能统计 GitHub 合计 900 万 stars/2200 万安装；全球 AI Skill 近 30 万日均新增 1300+**；**业界判断=技能市场成为最大软件表面（largest software surface on Earth）——SKILL.md 市场正在重演 npm 时刻**。判据：**标准格式=生态杠杆——同一 SKILL.md 一次编写跨 32+ 工具生效，技能生态已到爆发临界**。提升层：工具。
