## 独点（10）

**1. LAM 检索增强记忆：查询时注入而非全量携带**（来源：anhtu.dev《Long-Term Memory for AI Agents 2026》2026-05-16 + Zylos《From Context Windows to Persistent Knowledge》2026-04-05 + Mem0《2026 Token Optimization Playbook》2026-05-06 实拉，与 r370B 判重：已落向量检索，本点补检索式记忆注入成本数据增量）：**记忆增强 LLM=episodic+semantic+procedural 四层；检索式注入对比 naive 文件注入：24 条记忆全量注入 594 token/次 vs 检索式注入 166 token（-72%，真实 prompt_tokens 验证）；语义记忆层 Mem0 最广部署（2026 年中 ~48k GitHub stars，2025-10 融资 $24M）；三层生产记忆=in-context（当前所见）+semantic（向量库事实）+episodic（过往交互持久记录）——demo 可单层，次日回来的用户必须分层否则 broken by design**。提升层：工作流。

**2. 热温冷三层记忆架构（HWC）**（来源：Armalo《Cortex Tiered Memory》2026-04-10 + Sandbase《Vector/Graph/Episodic Compared》2026-06-04 + DailyAIWorld《Hot/Warm/Cold Hierarchy》2026-08-22 实拉）：**Hot=活动会话工作上下文（全保真消息+工具调用+top-K 温记忆注入+任务态，0ms 已在上下文）；Warm=语义索引的历史交互/跨会话知识（Qdrant/Pinecone/pgvector 混合检索，10-50ms，$0.0002/1K）；Cold=持久知识（向量+图+episodes，100-500ms，历史回召/关系查询/模式检测）；每轮流动=hot 会话变化→超过阈值沉淀 warm→consolidation 提升 cold；生产库=Zep（三层内建 TTL+自动摘要）/LangChain ConversationSummaryBufferMemory（hot+warm）；LangGraph checkpoint 原生管 hot 层，Qdrant 管 cold 语义回召**。提升层：工具/工作流。

**3. 记忆图+扩展激活检索**（来源：SYNAPSE arXiv 2601.02744（2026）+ GAM arXiv 2604.12285（2026-08-30）+ HeLa-Mem arXiv 2604.16839（2026-09-16）+ MRAgent ICML 2026《Memory is Reconstructed, Not Retrieved》2026-06-26 实拉）：**SYNAPSE=记忆建模为动态图，相关性由扩展激活（spreading activation）涌现而非预计算链接：查询注入能量沿时间/因果边传播，结构显著记忆被优先——即使与查询零词面/嵌入重叠；侧抑制+时间衰减滤干扰；三重混合检索=几何嵌入+激活图；GAM=显式解耦记忆编码与整合（对话隔离在事件进展图，仅语义转移时并入主题关联网络）减少干扰保长期一致；MRAgent=cue-tag-content 关联记忆图+主动重建循环：推理中动态选遍历方向、按中间证据剪枝——替代静态 retrieve-then-reason，LoCoMo/LongMemEval 最高 +23% 且降 token/时延；CA3Mem=生成式记忆重组合成新解驱动 agent 演化（OSWorld/WebArena）**。提升层：工作流/可复用 Skill。

**4. 记忆压缩与遗忘工程**（来源：Zylos《Consolidation: Selective Retention》2026-06-08 + Zylos《Compression/State Budget》2026-06-30 + arXiv SF-AMS 2607.22562（2026）+ arXiv FadeMem 2601.18642（2026-08-15）+ Mem0《6 Techniques》2026-05-07 实拉）：**多信号重要性评分取代单纯 recency 修剪：Score=w1·Recency（decay^hours 衰减≈0.995/h）+w2·Importance（写入时 LLM 打分）+w3·Relevance；MEMTIER 五信号=recency+访问频率+任务相关性+认知权重（该记忆是否导向成功工具调用）+PPO 学习策略权重（活奖励调系数）；Ebbinghaus 衰减逐出=按内容重要性+年龄/访问频率指数衰减，低于阈值移出激活集（-59% prompt tokens）——三个月老 agent 的 stale 条目是静默上下文膨胀最常见来源；战略遗忘 SF-AMS=效用驱动存活机制（用法冗余+时间信号更新重要性、层级结构优先稳定实体一致信息）；FadeMem=生物启发差分衰减率双记忆层；动态上下文修剪四维度=recency/决策相关性/错误相关性（该记录是否可复发的失败）/来源置信度（工具输出验证 vs 推断）**。提升层：工作流。

**5. 记忆成本治理六技巧**（来源：Mem0《6 Techniques to Cut Memory Cost》2026-05-07 + Mem0《Token Optimization Playbook》2026-05-06 + 腾讯云《企业级 Agent Memory 服务》2026-05-06 实拉，与 r371B 判重：已落推理成本，本点补记忆域成本治理增量）：**六技巧叠用 3-4x 降本不改模型：token 预算（-75% prompt tokens）+层级摘要（-59%）+Ebbinghaus 逐出（-59%）+embedding 量化（存储 4x）+Jaccard 自策展+热/冷缓存（RAM -83%）；符号化压缩=摘要压缩（去废话留事实）+实体级压缩（抽取结构化实体关系，比摘要更省）；检索式架构 cut 72%（24 条目 594→166 token）；BM25 检索是性价比最高的便宜记忆（LoCoMo 369-680 轮对话上 -98% 输入 token、成本降至全上下文的 4.8%，保持留存水平）**。提升层：可复用 Skill/工作流。

**6. 记忆提取 pipeline：bi-temporal 图+under-merge**（来源：Zep《How Graph Creation Works》2026-09-26 + DeepWiki Graphiti《Data Processing Pipeline》2026-07-31 + Zep《Provenance》2026-07-14 + arXiv 2606.09900《Bi-Temporal Memory Engine》2026 实拉）：**Graphiti 六步提取=①当前 episode+前 n=4 轮上下文提实体②混合相似+全文搜索消解到现有节点③提事实为类型化边④同实体对间去重⑤提绝对/相对时间戳映射有效性窗口⑥Cypher 整合；冲突消解=LLM 比较新边与语义相关旧边，检测矛盾则置旧边 t_invalid=新边 t_valid——**invalidate 不覆盖**（"用户上季度偏好什么"仍可答）；bi-temporal=事件时间（世界发生）+ingested-at（记录事务时间）双时间轴一等公民，knowledge-update 与 as-of 查询原生；实体去重=先规范化大小写/空白精确匹配→模糊相似→模型消解（启发式不保证合并）；**identity 不清时 under-merge 优于 over-merge**——错合并污染身份难撤销，重复节点便宜；provenance=原始 episode 逐字保留，每个派生节点/边关联产出它的 episodes（追踪事实=图遍历，合并保留双侧关联）**。提升层：可复用 Skill。

**7. 记忆评估：LongMemEval-V2+LAFS 延迟-准确率联合**（来源：LongMemEval-V2 arXiv 2605.12493（2026-05）+ scale-icml-2026《Accepted Papers》2026-08-04 + dreaming.press《V2 Analysis》2026-07-29 + agentmemory LONGMEMEVAL benchmark（2026-07-31）实拉）：**V2 从聊天日志转向 agent 轨迹：≤500 web-agent 轨迹、≤115M token/haystack，目标=给 agent 一个"资深同事"的累积经验而非准确聊天助手；得分轴=准确率+查询延迟联合（LAFS Latency-Accuracy Frontier Score 单一排行）——杀死"倒一大片历史进去赢基准"的最廉价打法；AgentRunbook-C=轨迹存文件+调用编码 agent 在增强沙箱收集证据（74.9% LME-V2-Small/70.1% Medium，超 Codex 69.9% 与 RAG 42.8%）；AgentRunbook-R 三知识池=raw state slices（细粒度 UI 证据）+state-transition events（环境动态）+procedure/hint notes（工作流/导航/gotchas）；无轨迹证据时前沿 LLM ≤14.1%——LME-V2 要求超越参数化知识的习得经验；agentmemory 混合检索 LongMemEval R@5 95.2%/NDCG@10 87.9% vs BM25-only 86.2%/73.0%**。提升层：可复用 Skill/工作流。

**8. 记忆框架选型三问**（来源：aiworkflowlab《Mem0 vs Letta vs Zep 2026》2026-05-25 + dev.to《Which Should You Use》2026-07-11 + baeseokjae《Best Frameworks 2026》2026-04-15 + Mem0《Graph Memory Top 5》2026-09-18 实拉）：**选型三问：①需时序精度吗（订阅等级/票据状态/地址变化）→Zep bi-temporal 图唯一原生，Mem0/Letta 需手动覆盖旧事实；②需 LLM 自己管记忆吗（长跑研究 agent/自主编码）→Letta 三层（Core/Recall/Archival）agent 自己 read/write/edit；③只要简单 KV→Mem0（48k stars/Apache 2.0/最快个性化/跨框架）；LongMemEval：Zep 63.8%（24k stars）vs Mem0 49.0%；Zep 三子图=Episode（无损原文+参考时间戳）/Entity/Fact（类型化边+有效性窗口）/Community；框架无关=Mem0/Zep/Supermemory vs Letta/LangMem 锁框架**。提升层：工具。

**9. 记忆合规：GDPR profiling+删除多存储**（来源：selina.ai《Memory Consent Gap》2026-07-16 + AI Policy Desk《GDPR Compliance 2026》2026-06-02 + selina.ai《ChatGPT Dreaming Rewrite》2026-07-17 + anuma《2026 AI Privacy Report》2026-04-12 实拉）：**GDPR 下构建持久行为画像=profiling 活动→触发同意义务+删除权（法律为 ad-tech 设计，对滚动自编辑记忆适用）；同意必须具体（"记住对话以提供个性化"非埋条款）+知情（存什么/存多久）+自由（退出不降级核心服务）+可撤回（撤回即真删）；ChatGPT 2026-06"Dreaming"架构=模型而非用户成为持久个人数据的主要作者（同行评审 96% 记忆由系统单方创建）；删除不再是单一动作——记忆在合成层与聊天日志解耦，删对话不删学到的东西，完整擦除需清多个独立存储；该功能 EU/UK 不可用；保留基线=ChatGPT 无限（活跃）/Claude 30 天（训练关）/Gemini 18 个月/DeepSeek 零**。提升层：可复用 Skill。

**10. 记忆 benchmark 数据基线（2026）**（来源：Mem0《Memory Evaluation》2026-09-23 + Mem0《LoCoMo/LongMemEval/BEAM 2026》2026-09-22 + rohitg00/agentmemory LONGMEMEVAL（2026-07-31）+ EvoMemBench arXiv 2605.18421（2026）实拉）：**Mem0 LongMemEval 自报 94.4%（single-session 98.6/98.2/96.7、knowledge-update 93.6、temporal reasoning 97.0、multi-session 88.0，均值 token 6,78x）；基准谱=LongMemEval（in-episode 为主）/MemoryAgentBench（in-episode）/StuLife（cross-episode）/MemoryBench（开源）/EvoMemBench（自我演化视角，跨 episode+开源）；自报分数只作参考——Zep 71.2（GPT-4o judge）vs Mem0 94.4（自报）不可直接比；myco-brain LongMemEval 实跑：overall 73.6%（multi-session 68.4 最难、single-session-user 94.3）**。提升层：工作流。
