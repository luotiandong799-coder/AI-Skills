## 独点（10）

**1. 合成数据定位与成本论**（来源：premai《Synthetic Training Data 2026 Guide》2026-03-17 + zeroentropy《Synthetic Data Generation》2026-06-04 + ai-tldr《How to Create Synthetic Training Data》2026-06-12 + genai4a11《Synthetic Data for LLMs》2026-06-06 实拉）：**2026 合成数据=默认监督源：几乎每个专用模型（instruct/reranker/分类器/embedder）都主要用 LLM 生成的训练数据；成本论=5k 例人类标注 $15k-50k/数周 vs 强教师模型 $50-500/数小时（10-100× 便宜）；代价=携带教师模型的偏差/盲点/能力上限——区别在生成策略+过滤纪律+理解教师模型不能做什么；黄金律 quality>quantity**。提升层：工具。

**2. 生成方法谱系**（来源：premai 2026-03-17 + colab data-science-roadmap module88 2026-07-06 + sukruyusufkaya《Fine-Tuning with Synthetic Data》2026-09-30 + ai-tldr 2026-06-12 实拉）：**五大方法：Self-Instruct=种子引导自举；Evol-Instruct=指令演化（加深/加广/模糊/敌意四操作）；Magpie="零提示"——用 chat template 单独提示对齐模型即同时产出用户 query+response（高效 SFT 数据）；蒸馏=强教师为弱学生生成；rejection sampling（RFT 拒绝采样微调/STaR 用推理自举推理/ReST Grow+Improve 双环）；persona-based=人设变化产生措辞与意图变化；Phi-3/Phi-4、Orca-2、WizardLM、Nemotron-4 340B、DeepSeek-R1→蒸馏 Qwen/Llama 均此谱系**。提升层：工具。

**3. 生成策略模式表与过滤**（来源：futureagi《How to Generate Synthetic Data Using LLMs》2026-05-01 + futureagi《Definitive Guide》2026-05-20 实拉）：**模式表：persona-prompted=措辞/意图变化；taxonomy-stratified=按分类保证覆盖关键单元；evolution=加深/加广/模糊/敌意制造生产流量不会自然出现的多跳与对抗尾巴；hostile-evolution=对抗/边界输入（red-team 集/越狱套件）；2026 工作模式=50-200 高质量真实种子→生成 5-10×沿种子欠代表轴显式变化；过滤器承重：embedding 去重+跨族 LLM judge+塌缩检测（成对余弦距离/熵/HDBSCAN 簇数）+5% 人工抽检+校准分布对真实参考集——多数团队跳 4 步中的 3 步照样上线**。提升层：工作流。

**4. 双阶段去重与去污**（来源：shyankdev《Synthetic Data in Training Frontier LLMs》2026-08-21 + ecitis《Synthetic Data Pipelines》2026-05-28 + arxiv 2606.21631 + premai 2026-03-17 + bards《Synthetic data that survives eval》2026-08-20 实拉）：**双阶段去重：MinHash LSH 结构 n-gram 近似重复 + embedding SemDeDup 语义冗余聚类；候选合成样本 embedding 相似度 >0.88 剪除；去污=训练例与评测集 n-gram 重叠（典型 10-gram）移除；生产级=13-gram+embedding 邻近 paraphrase 检测、按 benchmark 记录移除率、held-out fresh eval split（管线从未见过，泄漏显现在 gap）；ExactDeduplicator=SHA-256 规范化文本哈希、任务类型感知（哈希键从任务家族语义字段构建，非固定列）**。提升层：工作流。

**5. 模型塌缩检测与预防**（来源：arxiv 2410.12341《Learning by Surprise》2026-09-30 + arxiv 2608.21366《Reviewing Model Collapse》2026-09-03 + datascale-ai ch17 2026-09-16 + visualenews 2026-05-01 + dev.syncsoftai 2026-06-30 + arxiv 2412.14689《Semi-Synthetic》2026-09-22 + zeuspress 2026 实拉）：**检测指标：linguistic entropy、Gini 系数、collapsed predictions 数、分布散度/重复率/perplexity/评测退化、Vendi Score、CRI（域分异塌缩率——高语义多样性低冗余域先塌）；预防：混合 ≥30% 真实数据锚+每 3 训练周期加新批真实数据（"累积真实数据而非替换"=2026 文献共识，误差停止复利）、token-level editing 半合成（先验分布调整保持源分布）、提高解码多样性（温度/top-k 恢复尾质量）、降低合成占比 λt、回退最后稳定 checkpoint；黄金律=合成是补充不是替代，控制比例**。提升层：工作流。

**6. 偏好数据构建 2026**（来源：syncsoft《RLHF+RLAIF Hybrid Stack》2026-04-25 + arxiv 2603.04968《When Weak LLMs Speak with Confidence》2026 + arxiv 2603.09692《ActiveUltraFeedback》2026-09-17 + mdpi《Noise-Aware DPO》2026-05-12 + habr《RLHF to DPO》2026-09-22 + arxiv 2605.30021《DPO Recipe》2026-08-27 + mdpi《Petrochemical RLHF》2026-07-24 实拉）：**DPO/IPO 已取代 RM（直接策略拟合二进制交叉熵，匹配/超过 PPO-RLHF）；GRPO 去 critic（DeepSeek 群完成相对排序，省显存）；UltraFeedback=GPT-4 四响应打分（最高=chosen、随机=rejected，61.1k）；ActiveUltraFeedback=主动学习（DRTS 生成 30 响应只标 2，5k 样本达 UltraFeedback 30k 峰值）；噪声容忍矩阵（干净标签 vanilla DPO/nrDPO、10-30% 噪声 nrDPO、≈30% nrDPO-gated）；pair 对比性（好/坏须明显区分，标注者需想 5 分钟的对不建）；prompt 多样性>数量（2k 对/1k 唯一 prompt 优于 10k 对/500 prompt）；双模型分数差异过滤+级联质量过滤**。提升层：工具。

**7. 评测数据工程（Golden Set）**（来源：koji《Golden Set from Real User Research》2026-08-16 + futureagi《Golden Dataset Glossary》2026-05-19 + eval.qa《Eval Dataset Construction》2026-02-01 + langfuse《Golden Dataset Evaluation》2026-09-20 + masterprompting《Golden Test Sets》2026-05-30 + mlflow《Data Validation in AI》2026-07-26 + theneuralbase《Avoiding Data Leakage》2026-04-21 实拉）：**Golden set=100-500 例四桶（生产轨迹/对抗/边界/历史失败回放），验收标准由代表用户的人写而非工程师；<100 置信区间太宽 >500 边际维护不值；golden dataset 本身要测（GroundTruthMatch pass rate 分队列/版本、failure-mode 覆盖率审计——维护 failure-mode 分类法每 release 审计）；eval 构建协议=多 rater IAA>0.7、10% 人工 QC、<5% 缺陷率、schema 合规校验；时敏事实 pin reference_date；防泄漏=训练前先去重+validate_no_overlap、自动 lineage 检查（eval_creation_date < model_training_start 即 fail loudly）；输入 embedding 相似度 >0.95 剪近重复**。提升层：可复用 Skill。

**8. RAG 评测数据生成**（来源：arxiv 2605.08838《SeedRG》2026-05-09 + arxiv 2506.00789《RARE》2026-08-15 + arxiv 2601.15487《MiRAGE》2026-08-26 + baai《EnterpriseRAG-Bench》2026-05-06 + mlflow《Performance Evaluation Datasets》2026-08-12 + arxiv 2511.14531《LiveRAG》2026-09-19 实拉）：**SeedRG=半合成泄漏-free 基准（从 seed 抽推理图+类型约束实体替换——结构相似但参数知识中不存在的新实例+防 benchmark aging）；RARE-Get=四阶段全自动（GT chunks→知识图→QA 构建→QA）随语料动态演化；MiRAGE=多 agent 群（递归上下文优化聚合分散证据+对抗验证器保证事实锚定+专家人设模拟认知工作流）生成多模态多跳 QA；EnterpriseRAG-Bench=50 万文档 9 类企业源（Slack/Gmail/Linear/Drive/HubSpot/Fireflies/GitHub/Jira/Confluence）+500 题跨文档一致性；约束生成=问题仅由给定 passage 可答（禁世界知识外溢）+答案映射 keypoint（算 Completeness）+diversion 题混合随机化（gold vs diversion 596 题混淆）**。提升层：工作流。

**9. Agentic 数据工程**（来源：arxiv 2606.25996《Autodata》2026-07-04 + marktechpost《Meta Autodata》2026-05-01 + arxiv 2606.01279《ANDES》2026-09-16 + arxiv 2605.30407《Agentic Data Engineering》2026-06-01 + arxiv 2609.19754《AutoData Pre-training》2026 + arxiv 2605.10906《DataMaster》2026-09-03 + arxiv 2607.15299《MLLM-DataEngine》2026-07-07 + alphaxiv 2604.21590《AgenticQwen》2026-04-23 实拉）：**Meta Autodata=自治数据科学家 agent：orchestrator 协调四子 agent（Challenger 生成难例/Weak Solver 小模型预期失败/Strong Solver 大模型预期成功/Verifier 判定），四标准含强弱求解器有意义性能差距——难度校准机制，把额外推理计算转为更高质量示例；AutoData（预训练选择）=直接搜索可执行选择算法程序空间（评分/分层/随机选择规则，自动发现特征交互），一夜搜索超越人工设计管线；ANDES=数据生成作即插拔 agent skill（World Tree 路由+诊断报告闭环）；DataMaster=树搜索+共享数据池+全局记忆；MLLM-DataEngine=闭环（评估→弱点分析→增量数据集→再训练）；AgenticQwen=双数据飞轮（模型失败处生成更难题，教师改写错误案例加约束）**。提升层：工作流。

**10. 数据混合与课程学习**（来源：nips《DoReMi》2023 + kindatechnical《Curriculum and Data Mixing》2026-09-03 + aiwiki《DoReMi》2026-08-09 + openreview《ODM》2026 + arxiv 2606.24133《HDS》2026-09-30 + arxiv 2502.16802《Topic-based Mixing》2026 + arxiv 2603.26164《DataFlex》2026-08-24 实拉）：**DoReMi=小代理模型 per-domain excess loss 加权（代理最难域权重最高——科学文本+代码上采样 3-5× 显著提升 MMLU/HumanEval，Pile 全域 PPL 改善+下游 6.5 点+2.6× 步数效率）；ODM=在线数据混合（达 TPW 性能省 30% 迭代）；HDS=多目标 RL 调度器（省 44% 迭代达同等验证 PPL+MMLU 7.2% 提升）；topic-based>source-based 混合（四种方法一致 +0.60 点）；动态>静态（ODM 26.04 vs DoReMi 25.84 vs baseline 25.27 MMLU）；DoReMi 局限=高资源域过拟合长尾退化（2026 研究指出 loss-based 权重不稳）**。提升层：工具。
