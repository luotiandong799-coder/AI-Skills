## 独点（10）

**1. 混沌工程程序化故障注入（AgentChaos）**（来源：arXiv 2608.06790 + floritange + zylos 2026-04-09 实拉）：所有 agent 经 HTTP 接口访问 LLM——**在共享 HTTP 层注入故障不改源码**（非侵入）；三故障类型=crash（HTTP 500/超时）/omission（缺字段）/value（字段值错），作用于 content 与 tool call 字段；**注入后验证故障是否真被触发，过滤未触发任务避免低估故障影响**；关键发现=所有系统都降级（Δpass@1 高达 50pp）/严重故障并非最有害——crash 会被检测重试，**omission 类静默吞掉最危险**；chaos 六失败模式=tool timeout/malformed result/model refusal/context overflow/retry storm/schema drift 各需特定注入机制。判据：**故障注入走共享 LLM API 层（非侵入），注入后验证触发，重点测 omission 类静默失败**。提升层：工具/工作流。

**2. 三层评估金字塔：每层只跑下层不能决定的**（来源：futureagi 2026-03-13 + 2026-02-24 + sciencx 2026-06-08 实拉）：L1 确定性地板（schema/regex/函数调用校验/引用存在/精确匹配/长度契约）——亚毫秒零成本，模型花 token 前拦结构失败与策略违规；L2 分类器护栏（LLAMAGUARD_3_8B/QWEN3GUARD_4B）返回概率+校准阈值；L3 只把模糊余量（0.4-0.7 分）发给 CustomLLMJudge 带完整 rubric；**100/10/1 采样=100% 轻量启发式/10% LLM judge/1% 人工审查**；capability vs regression evals=20-50 用例分两组：capability（低通过率驱动改进）/regression（近 100% 通过率防退化）。判据：**评估按成本分层——确定性免费拦截→分类器→judge 只处理模糊余量；capability 与 regression 两组分开建**。提升层：可复用 Skill/工作流。

**3. Judge 三失败模式与 bias 七类缓解**（来源：arXiv 2601.08654 RULERS + playbooks.aip.gov.sg + mini-claude-for-legal 2026-07-21 实拉）：judge 失败三模式=rubric 对 prompt 敏感不稳定/不可验证推理缺审计证据/scale 与人评分边界失配；RULERS=自然语言 rubric 编译为可执行规范（compiler-executor 框架）；**bias 七类=style（熟悉语气/格式胜内容）/verbosity（长即高分）/authority（自信口吻多得权重）/inconsistency（同例多次评分不同）/overconfidence（错答报高置信）/sycophancy（镜像用户立场）/self-preference（同族模型判自己）**；缓解=至少一个非同族 judge 权重 60%/rubric 每档锚定 worked example（防 scale drift）+固定人工校准集每 judge 版本跑/detailed rubric 定义每档含义+few-shot 校准。判据：**judge 按七类 bias 清单审计；rubric 每档带示例锚定+非同族混合裁判+校准集跟踪漂移**。提升层：可复用 Skill/模型。

**4. 工具 schema 契约测试：契约含 8 要素，breaking change 是行为概念**（来源：qaskills 2026-07-10 + NxCode MCPEvol 2026-07-18 + zylos 2026-06-23 实拉）：工具 schema=AI 系统的 API 契约，需与 REST/protobuf 同等兼容纪律——**小 schema 改动可破坏 prompts/evals/tool routers/audit logs/saved replays**；tool contract=完整承诺=name/description/input schema/output schema/errors/side effects/auth/latency expectations/behavioral invariants——JSON Schema 只是契约一部分；structural drift（字段名/类型/约束变化）可机械检测；**semantic drift（意义变形状不变）不可机械检测**；**CUJ 评估=描述变化导致 CUJ 场景回归=breaking change，不论 schema 向后兼容**。判据：**工具契约按 8 要素测，breaking change 判据=行为回归（CUJ 场景）非 schema 兼容性**。提升层：工具/可复用 Skill。

**5. 生产 trace 确定性重放调试**（来源：zylos 2026-04-30 + 2026-06-20 + Microsoft Learn 2026-09-16 实拉）：record 模式=正常生产捕获全部交互为结构化执行日志；**replay 模式=agent 调确定性 stub 而非 live LLM/tools——replay 引擎按记录顺序返回事件并阻止任何 live 外部调用**；每 LLM 调用记录=完整 prompt+model ID+版本串+采样参数（temperature/top_p/max_tokens/seed）+响应 token+finish reason+TTFT+token 计数（input/output/cached 分）；每工具调用=名称+版本+序列化参数+完整响应+成功失败+错误；**定位发散点=20 步 run 第 14 步失败→从第 13 步重建上下文做最小复现而非全 run**；确定性重放三支柱=确定性输入+有序事件日志+可复现模型状态转换。判据：**重放=记录全决策输入（含采样参数与版本）→stub 引擎确定性回放→发散点截断做最小复现**。提升层：工具/工作流。

**6. 测试隔离双边界：authority + reality**（来源：sincllm 2026-06-21 + ybuild 2026-08-05 + zylos 2026-05-07 实拉）：agent 不知道跨了环境边界，审计轨迹可能不标记 test-origin；**staging agent 读 live 客户数据污染 eval——检索索引/向量库 staging-production 共享→eval 被真实客户数据污染（隐私不安全+结果无效）**；authority boundary=身份/凭证/权限/钱/客户记录/仓库/通信渠道——**有真实 GitHub org 访问权的 test token 即使 agent 在 VM 内也算越权**；reality boundary=离开受控模拟进入真实世界产生后果（发测试邮件给陌生人/建公开仓库/订真实库存）；隔离测试两阶段=先 isolation（每 agent 独立测 mock 其他 agent）再 ensemble（真实协作）；mock at boundaries only（DB/API/文件系统/时间），不 mock 应用代码。判据：**测试环境=staging-production 全隔离（含检索索引）；越权按 authority/reality 双边界审查，mock 只在边界**。提升层：工作流/工具。

**7. Prompt section 隔离测试**（来源：agentixforce 2026-05-12 实拉）：capability isolation tests=**分别测 system prompt 每节**（工具使用节：该指示时调工具吗/拒绝策略：拒绝违禁请求吗/输出格式指令：产出指定 JSON 结构吗）——**隔离定位哪节导致行为破坏**；prompt section interaction tests=节间交互测试；工具调用单元测试不 mock 一切——prompt 级测试在与其他组件交互前先抓单条能力指令错误，避免涌现性失败（问题看起来整体坏但实际某节错）。判据：**大 system prompt 按节独立测能力再测节间交互，先定位再集成**。提升层：可复用 Skill/工作流。

**8. Agent drift 量化：ASI 12 维 + 88% 三十天变**（来源：syrin 2026-04-28 + agentstatus 2026-04 + agentixforce 2026-05-05 实拉）：**88% 生产 agent 30 天内行为变化**（6200+ agents/18M tests 实测）；ASI=12 行为维度复合指标；behavioral drift=响应特征变化（长度/澄清率/拒绝率/语气）可聚合统计检测——突然变短=上游改导致有效上下文被截；拒绝率升=安全更新过保守；factual drift=内容正确性；**检索漂移=语料库不断变（文档增/过时/embedding 模型换/分块策略变/索引重建）——检索服务可用但证据越来越没用**；verifier drift=验证器继续返回答案但已不可靠（最危险）；drift 是群体信号（窗口内缺陷率上升）非单次 run 失败；检测顺序=先确定性信号再 fenced judge 处理模糊类。判据：**drift 监控=行为聚合信号（长度/拒绝率/正确性）+检索/验证器独立漂移检查，群体窗口统计非单次判定**。提升层：工作流/工具。

**9. CI 回归门禁：hard blocks 与 soft warnings 分层**（来源：baeseokjae 2026-06-19 + confident-ai 2026-09-21 + mlflow 实拉）：hard blocks=完成率降 >5pt（smoke eval）或 >2pt（full eval）/p95 延迟超绝对 SLO/任何 guardrail 违规 >0（safety-set run）/任何 unit/contract 测试失败；soft warnings=成本中位数升 >10%/rubric mean 降 0.1+（PR 评论提示不拦截）；**回归=质量下降的变更像坏 build 一样 fail PR**；CI 跑 golden dataset→评分→与 baseline 对比→非协商 case 失败或通过率超容差则 fail；结果以测试报告附 PR（哪些 case flip/哪些指标动/judge 推理）；**closed loop=Error Feed 把上周生产失败提升为新用例——集从上周 miss 长出，非 sprint 造**。判据：**门禁=硬块（通过率/p95/安全违规/单测）+软警告（成本/质量微降）分层；用例集从生产失败闭环长出**。提升层：工作流/可复用 Skill。

**10. 合成数据三族 + 生成后过滤四步**（来源：futureagi 2026-05-20 + 2026-05-01 + evidently 2026-05-19 实拉）：三族=happy-path personas（匹配真实分布设 baseline）/edge-case personas（低代表群体：罕见语言/极端数量/无障碍场景扩覆盖）/**adversarial personas（注入探针/jailbreak/PII 诱饵/毒性/sycophancy/过度拒绝校准=安全地板）**；生成模式=persona-prompted（措辞与意图变化）/taxonomy-stratified（保证单元覆盖）/evolution（deepen/broaden/obscure/adversarial 造生产流量不自然出现的多跳与对抗尾部）；**过滤四步=embedding 去重/跨族 LLM judge/模式塌缩检测（pairwise cosine+entropy+HDBSCAN cluster count）/5% 人工抽检——多数团队跳过四步中三步直接上线**；合成数据是真实数据补充非替代。判据：**合成数据=三族构建（happy/edge/adversarial）+四步过滤（去重/judge/塌缩检测/人工抽检）**。提升层：工具/可复用 Skill。
