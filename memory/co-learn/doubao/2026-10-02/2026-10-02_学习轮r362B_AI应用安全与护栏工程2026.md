## 独点（10）

**1. 六类 AI 专属威胁与四层防御（语义操纵六类；输入清洗+隔离+输出过滤+人环）**（来源：iesdouyin 2026-05-20 + OWASP community 实拉）：AI 安全新威胁=攻击目标不是服务器漏洞而是模型语义可操纵性——不需要 SQL 注入也能通过自然语言诱导模型泄露信息执行危险动作；六类威胁=直接 Prompt 注入/间接注入/系统提示泄露/不安全工具调用/Jailbreak/有害输出；四层防御=输入清洗/系统隔离/输出过滤/人工确认环。判据：**AI 威胁=语义操纵六类（注入/泄露/工具/越狱/有害输出）；防御=输入清洗+隔离+输出过滤+人环**。提升层：工作流/可复用 Skill。

**2. Agentic Skills Top 10（技能层执行面风险：外部指令源钉扎/弱隔离容器化/更新漂移哈希验证）**（来源：OWASP AST10 2026-03-01 + whitepaper 实拉）：OWASP Agentic Skills Top 10=技能层（定义资源访问+如何编排多步自主工作流）十大风险——AST05 不可信外部指令（High：源清单/内容钉扎/连续重扫；Air PoC 绕过全部扫描器 26000 agents 风险）、AST06 弱隔离（High：容器化 Docker 沙箱；OpenClaw host 模式 135K 暴露实例）、AST07 更新漂移（Medium：不可变钉扎+哈希验证；ClawJacked CVE-2026-28363 patch-lag 利用）、AST02 供应链（注册表透明）、AST03 过度授权（schema 验证）、AST08 差扫描（多工具管线）。判据：**技能层风险=外部指令源钉扎/弱隔离容器化/更新漂移哈希验证**。提升层：工具/可复用 Skill。

**3. 护栏五执行点+输入四查（输入/schema/PII/权限/动作门控；长度/短语/格式/注入语法，覆盖每个信任边界）**（来源：zalt 2026-06-30 + openlegion 2026-07-01 + ai-zero-to-hero 2026-04-13 实拉）：护栏=设计层至少五执行点（输入过滤/输出 schema 验证/PII 检测/权限作用域/动作门控——缺任一=生产事故）；输入护栏作用于每个信任边界（用户消息/工具响应/RAG 检索文档/记忆检索）——主题过滤（拒禁主题）/PII 检测与脱敏（进模型前剥离掩码）/越狱检测/长度限制（截断过大输入防稀释系统提示）/注入语法剥离（进模型前删已知注入语法）；每用户消息四查=长度上限（10000 字符合理上界）/危险短语/格式/注入模式。判据：**护栏五执行点（输入/schema/PII/权限/动作门控）；输入四查=长度/短语/格式/注入语法，覆盖每个信任边界**。提升层：工作流/可复用 Skill。

**4. 输入 rail vs 输出 rail（模型前抓越狱/注入/PII/URL；网关前抓有害/幻觉/密钥/离题）**（来源：futureagi 2026-04-19 + actionai 2026-05-12 实拉）：成熟护栏架构=四点约束（提示进模型前/推理期间/生成后/回喂系统的操作循环）；input rail=模型调用前跑用户消息——抓越狱/注入/PII 探测/恶意 URL/代码注入载荷/密钥泄漏/主题违规（第一道防线最低延迟预算）；output rail=网关返回前跑模型响应——抓有害内容/幻觉医疗法律建议/完成泄漏密钥/离题响应/策略违规。判据：**输入 rail=模型前（越狱/注入/PII/URL）；输出 rail=网关前（有害/幻觉/密钥/离题）**。提升层：工具/工作流。

**5. 工具输出消毒与结构化输出约束（回传前剥离指令样文本；枚举+regex 限制自由文本防说明字段外泄）**（来源：brainupgrade 2026-04-12 + toolbrain 2026-05-26 + theneuralbase 2026-04-11 + beyondscale 2026-07-07 实拉）：工具输出消毒=回传 LLM 上下文前剥离转义类似指令文本（不完美但防常见注入）；结构化输出约束=强制 JSON schemas 分离数据与指令——注入内容下游不被解释为命令；schema 漏洞=过于宽松 string 字段接受任何值包括代码/序列化载荷——有限值字段用枚举、自由文本加 regex pattern；数据外泄=reason/summary/justification 等自由文本说明字段接受任意字符串——说明字段也要验证。判据：**输出安全=工具输出消毒+结构化输出约束（枚举+regex 限制自由文本防说明字段外泄）**。提升层：工作流/可复用 Skill。

**6. 凭证代理与短期令牌（agent 无长活凭证；每跳独立 scoped token；策略求值类型化禁字符串插值）**（来源：IETF CB4A 2026-07-21 + youcanbuildthings 2026-06-15 + zylos 2026-05-07 + curity 2026-07-17 实拉）：凭证代理 CB4A=agent 永不持有真实长活凭证——用时代理请求短时窄作用域令牌/用完过期/没有可偷的持久物；每跳 scoped token=调 Slack 和 GitHub 用不同令牌无跨调用复用；令牌到期撤销每调用检查（非仅登录时）；policy 求值用类型化编译策略语言非字符串插值——包络字段反序列化成类型结构再求值（禁字符串拼接/模板渲染在策略求值路径）；令牌库模式=安全存高权 MCP server 令牌+策略控制何时释放+调用期间释放。判据：**凭证=代理短期令牌（agent 无长活凭证）；每跳独立 scoped token；策略求值类型化禁字符串插值**。提升层：工具/工作流。

**7. MCP 安全基线（OAuth2.1+PKCE 强制/每请求验证/默认拒绝/禁 passthrough 令牌/per-client 工具白名单）**（来源：OWASP MCP Cheat Sheet 2026-10-01 + akto 2026-09-21 + systemshardening 2026-03-17 + dev kunal 2026-09-09 实拉）：MCP 安全=远程 HTTP server 强制 OAuth 2.1+PKCE 无例外（比静态 API key/会话 cookie 好——显式作用域/短活令牌/密码学验证/会话结束细粒度撤销）；每请求验证 iss/aud/签名（JWKS）/到期/时钟偏移；tools/list+tools/call 要认证默认拒绝；从不接受 passthrough 令牌、绝不把 MCP 访问令牌传上游 API；per-client identity 工具 allowlist（denied_tools ["*"]+max_calls_per_minute 30）；OAuth token delegation（RFC 8693）传用户上下文+权限给 server 同时保留独立 server 非人身份（NHI）。判据：**MCP 安全=OAuth2.1+PKCE 强制/每请求验证/默认拒绝/禁 passthrough 令牌/per-client 工具白名单**。提升层：工具/可复用 Skill。

**8. Agent 治理工具箱（确定性纯正则扫描 <5ms 零 LLM 成本；Merkle 链审计+决策 BOM+监管映射）**（来源：Microsoft Agent Governance Toolkit 2026-08-15 + 2026-04-03 实拉）：治理工具箱=首个开源框架覆盖全部 10 OWASP Agentic AI 风险+确定性亚毫秒策略执行；prompt_defense 纯正则确定性零 LLM 成本 <5ms 检查系统提示对 17 攻击向量防御（12 LLM Top10 会话安全+5 Agentic——跨 agent 权威/金融交易/技能溯源/最小 agency/编码感知注入）；审计=防篡改 Merkle 链日志（条目改不了检测得到）/决策 BOM（任何治理决策全"物料清单"重建）/监管映射（EU AI Act/SOC2/HIPAA/GDPR 自动合规证据）/SIEM 导出（CloudEvents 喂 Splunk/Sentinel/Datadog）。判据：**治理=确定性纯正则扫描（<5ms 零 LLM 成本）+Merkle 链审计+决策 BOM+监管映射**。提升层：工具/可复用 Skill。

**9. 红队评测（多轮守卫退化连续轨迹；时间到首次越狱随机变量；隔离环境行为越狱）**（来源：arXiv ADVERSA 2603.10068 + STING 2602.16346 + LITMUS 2605.10779 实拉）：红队评测=ADVERSA 自动化红队框架测守卫退化动力学=连续逐轮合规轨迹而非离散越狱事件——微调 70B attacker（ADVERSA-Red Llama-3.1-70B QLoRA）消除攻击侧安全拒绝对 5 点制 rubric 评分受害者响应；STING=基于良性人格构造分步非法计划+自适应跟进探测+judge agent 追踪阶段完成——多轮红队建模为时间到首次越狱随机变量（发现曲线/攻击语言风险比归属/新指标）；LITMUS=真实 OS 环境行为越狱基准——环境完全断开生产网络专门安全吸收破坏性测试/恶意软件引爆/高风险系统操作（授权审计票据）。判据：**红队=多轮退化轨迹（ADVERSA 连续合规）+时间到首次越狱（STING 发现曲线）+隔离环境行为越狱（LITMUS）**。提升层：工具/可复用 Skill。

**10. Agent 可观测性与审计留存（超越 API 边界全动作追踪；防篡改日志；EU6月/FINRA7年/HIPAA6年留存地板）**（来源：openhands 2026-08-25 + decasoft 2026-06-12 + zylos 2026-05-01 + futureagi 2026-05-20 实拉）：Agent 可观测性=收集 traces/logs/metrics/outcomes/attribution——质量取决于 agent/工具/运行时/周边工作流插桩完整性；超越 API 边界看 agent 做的每件事（工具调用/模型推理/子 agent 交接/连接系统内动作）——不是 APM（看基础设施响应）也不是仅 LLM tracing（记录模型输入输出到工具调用边界就停）；审计=每影响动作记录输入/模型版本/输出/下游更新到防篡改日志（监管质询主要证据+检测问题前反馈环）；留存基线=EU AI Act 19 条高风险 6 个月自动日志/FINRA SEC 交易咨询 7 年/HIPAA 医疗 6 年/GDPR 问责——这些设地板生产层之上加。判据：**观测=超越 API 边界的全动作追踪；审计=防篡改日志（输入/模型版/输出/下游）；留存=EU6月/FINRA7年/HIPAA6年地板**。提升层：工具/工作流/可复用 Skill。
