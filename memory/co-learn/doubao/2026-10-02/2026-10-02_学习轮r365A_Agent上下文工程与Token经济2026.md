## 独点（10）

**1. DTOC 动态工具输出压缩：外部内存+占位符+按需可逆重建**（来源：arXiv 2609.26121 实拉）：上下文更新建模为**显式且可逆的操作**——完整工具输出保留在外部内存，活动上下文只插入紧凑占位符，需要时选择性重建；整合进 ReAct 式 agent 架构并提供按需还原的生产实现。与 zylos L1（截断+磁盘引用，不可逆）互补：**DTOC 是可逆压缩（placeholder→selective reconstruction），截断是不可逆的**。判据：**大工具输出压缩首选"外部存储+占位符+按需重建"的可逆模型，而非直接截断**。提升层：工具/工作流。

**2. keep-verbatim zones：byte-stable 保前缀缓存**（来源：agentnative 2026-07-26 + maxtokens 2026-06-11 实拉）：**永不总结的区域=系统提示+工具 schema（byte-stable 保前缀缓存命中）+任务陈述与验收标准+最近 5-7 轮**；项目记忆快照 24h 刷新+确定性组装=**byte-identical 块，否则缓存永不命中**；tool-result clearing 是最便宜的杠杆（stale 可重取的工具输出换占位符，保留一行记录）。判据：**缓存友好的上下文=静态头 byte-stable、动态尾放最后；快照类块必须确定性组装保证字节一致**。提升层：工作流/可复用 Skill。

**3. KV 缓存经济学：cache read 0.1x / cache write 1.25-2x / agentic 缓存破坏**（来源：zylos 2026-05-27 + arXiv 2607.19214 + yage 2026-06-25 实拉）：token 类型成本表=input fresh 1x/output 3-6x/cache write 1.25-2x/**cache read 0.1x**；**agentic 工作负载系统性摧毁缓存——agent 发请求→跑工具或等人审→几分钟后 follow-up 前缀已被逐出→全额重付 prefill**；解法=客户端 keepalive 保持缓存热；**KV 缓存命中率=推理成本第一杠杆（非模型选择）**——同负载命中率 0%→90%，GPU 账单 $20,000→$2,000/月；keepalive 每 3 分钟 ping=92% 命中率。判据：**长会话成本看缓存命中率；工具/审批间隔用 keepalive 保前缀；静态前缀 byte-stable**。提升层：工具/工作流。

**4. LLMLingua 家族：SLM token 重要性评分压缩**（来源：Microsoft LLMLingua + preprints 2026-07-0924 + arXiv 2602.15843 实拉）：GPT-2/LLaMA-7B 算每个 token 的 perplexity，低 perplexity（高度可预测）token 删除；budget controller 跨段分配压缩+distribution alignment 调评分器匹配目标 LLM；LLMLingua-2 改为 token 分类任务（GPT-4 蒸馏标签，更忠实）；**20x 压缩仅 1.5 点性能降（GSM8K/BBH/ShareGPT/Arxiv）**；**Perplexity Paradox=代码语法 token 比内容词高 79x perplexity（保代码），数学数值 0.79x 更低（被优先剪——危险：数值是数学题关键）**；Telegraph English=结构化符号重写语义压缩，小模型受益更大（GPT-4.1-nano 比 GPT-4.1 差距更大）。判据：**prompt 压缩=SLM 评分逐 token 删低信息 token；压缩前检查领域敏感 token（数学数值）需保护**。提升层：工具/模型。

**5. 三区预算制 + 预算分配表 + 输出保留预算**（来源：agentixforce 2026-05-13 + clawhub + niteagent 2026-07-16 实拉）：三区=green 0-70% 正常/yellow 70-85% 轻压缩（摘要最老 20% 历史+drop 低优先工具结果）/red 85-95% 激进（只留系统提示+最近 3 轮+最新工具结果）；**预算分配表=system 5%/history 20-30%/tool results 15-20%/retrieved 15-20%/output 15-25%/headroom 10%**；**常见错=把 127,500 token 塞进 128K 窗口→模型只能生成 500 token**；总 token ≤ window−保留输出预算，输出至少留 1,500-2,500 token。判据：**上下文预算=三区触发+分项分配表+输出预算硬保留，不留输出空间等于把模型锁死**。提升层：可复用 Skill/工作流。

**6. 结构化逐出 Beyond Compaction：先 CoT 后 bulk output**（来源：arXiv 2606.11213 + arXiv 2604.17091 GenericAgent 实拉）：逐出优先级=**先删推理链（其结论已反映在后续工具调用与决策中）→再整删大枚举工具输出（search 结果/grep/glob 列表）→再删中间产物**；GenericAgent 四机制=工具输出截断/tag 级压缩（删低价值片段）/消息逐出（超预算删最老）/**working-memory anchor（关键任务信息在先前消息逐出后仍可见）**。判据：**超预算逐出按优先级：CoT→bulk 枚举→中间产物；关键任务信息用 anchor 固定不随逐出消失**。提升层：工具/工作流。

**7. STITCH contextual intent 记忆检索：标签密度排序**（来源：PaperNotes ACL 2026 实拉）：长程记忆引入 **"contextual intent"（主题域+事件类型+关键实体类型）三元组作为结构化检索 cue**，每条 trajectory step 在线归纳；**推理时按"标签密度排序"先做结构匹配再做语义打分**；CAME-Bench 随 trajectory 增长不掉点，比最强 baseline 高 35.6% 绝对。判据：**长程记忆检索=结构化 cue 先结构匹配再语义打分，纯向量语义在超长轨迹会掉点**。提升层：工具/模型。

**8. Abstention-aware 记忆注入：注入即控制决策，不对称损失**（来源：agentpatterns + arXiv 2604.27283 Iscan 实拉）：**missed reuse 只花一轮额外调试，但自信注入错误 episode 会跨轮复合放大——不对称损失**；检索证据不安全时不注入（**abstention=一等公民动作**）；RSCB-MC 风险敏感控制器每次检索在多个动作（注入/不注入/改写后注入）间选择。判据：**记忆注入按控制决策处理——证据可疑时主动不注入，宁缺勿错**。提升层：工具/工作流。

**9. Pre-flight 上下文检查：工具预算与消息预算分离管理**（来源：kaman.ai + hermes-agent + iideas18 实拉）：每个 LLM 调用前 pre-flight 节点估计 token 预算；**工具 schema 超分配时触发 tool-specific eviction，独立于消息压缩——防止工具需求增长导致激进的全局消息压缩，反之亦然**；4-chars/token 启发式估计+provider 特定调整。判据：**上下文治理双轨制——工具预算与消息预算各自独立触发逐出，不互相挤压**。提升层：工具/工作流。

**10. 缓存意识提示架构：cache-busting 防护与优化排序表**（来源：agentpatterns prompt-caching + varunsingla 2026-08-05 + dailyaiworld 2026-08-30 实拉）：**一次 cache-busting 改动抹掉后续所有调用的节省——prompt 布局即架构纪律**（静态放前：system+工具 schema+参考文档；可变尾放后）；keepalive 每 3 分钟 ping=92% 命中；**68% 多轮成本降（$7.2M/年/100K 会话）**；TTFT Turn 20 降 60%（420ms→95ms）；成本优化排序表=cache 90%/semantic cache 73%/model routing 60-80%/truncation+summarization 40-70%/concise prompt 30-55%/RAG context compression 25-80%/output length 15-60%。判据：**成本优化先动缓存架构（收益最大）再动 prompt；任何改动前检查是否破坏静态前缀**。提升层：工作流/可复用 Skill。
