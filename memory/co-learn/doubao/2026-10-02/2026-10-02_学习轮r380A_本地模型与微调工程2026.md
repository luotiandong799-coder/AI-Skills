## 独点（10）

**1. QLoRA 消费级硬件配方**（来源：InsiderLLM《LoRA Consumer Hardware》+ EgoistAI《Single Consumer GPU QLoRA》+ SumGuy《Your Gaming GPU》+ LocalAI Master《QLoRA 24GB》2026-04/05 实拉）：**12GB GPU 可 QLoRA 训练 7B 模型 2-4 小时；配方=rank 16、lr 2e-4、batch 2+gradient accumulation 8、200-500 质量样本多数任务够；Unsloth 自动优化=2x 快/60% 少 VRAM；QLoRA=基座 4-bit 量化加载（int4）+LoRA adapter bf16/fp16 训练——7B fp16 约 14GB 吃满 4090 前训练已死，4-bit 后 3.5-4GB；70B 单卡 4090 可训（质量≈LoRA 全微调内存的 ~30%）；训练后 merge 进基座再 serve（vLLM/llama.cpp）**。提升层：工具/可复用 Skill。

**2. VRAM/规模对照与训练时长**（来源：Local AI Hub《Fine-Tuning Guide》2026-04-22 + Markaicode《Ollama Workflow》2026-08-17 + KunalGanglani《Fine-Tune 2026》2026-07-02 实拉）：**3B=min 6GB/建议 8GB/500 例约 10 分钟；7-8B=8/16GB/约 30 分钟；14B=16/24GB/约 1 小时；32B=32/48GB/约 3 小时；7B 几百例私有样本 QLoRA（Llama3/Mistral）→merge→GGUF→`ollama run my-internal-model` 正确用你内部 API 名/错误约定/输出格式（基座猜或幻觉的地方就是微调收益点）**。提升层：工具。

**3. 微调 ROI 门：few-shot 对比 + 目标量化档评估**（来源：KunalGanglani《Fine-Tune ROI》2026-07-02 实拉）：**微调前先测基线：few-shot prompting 85% vs 微调 87%——2% 增益不值维护自定义模型的运营复杂度（部署/版本/回归）；目标量化档评估=以 Q4_K_M GGUF 部署就在 Q4_K_M 评估不评估全精度（低 bit-width 性能会掉，部署前必须知道）**。提升层：工作流。

**4. 合成数据蒸馏管线**（来源：NVIDIA《Synthetic Data Pipelines》2026-02-05 + ErtasAI《Synthetic Data》2026-08-13 + ErtasAI《Workflow》2026-03-09 + CEUR《10-50 Examples》2026 实拉）：**蒸馏核心=教师模型生成域内训练例→规则验证器级联筛选→紧凑学生微调；合成数据质量控制=丢弃 bottom 20%、MinHash/SimHash 去重（阈值 0.85——LLM 合成数据比人类数据重复得多，0.5B 规模近重复过度代表某些模式害处大）、格式一致性（每例输出格式与生产完全一致）；sub-1B 学生生成参数=最大输出长度匹配学生生产窗口（如 512 token）/temp 0.3-0.5（一致性优先于多样性）/推理深度限 2-3 步/每例输出格式与生产一致；10-50 标注例+NL 任务描述→SLM 专家 agent（教师合成+规则验证器级联+贝叶斯潜变量多样性采样）；许可证合规合成管线（OpenRouter distillable endpoints 免法律不确定性）+LLM-as-judge 入库前评完整性与准确性**。提升层：可复用 Skill。

**5. 数据质量多信号过滤**（来源：TheNeuralBase《Detecting Bad Synthetic Examples》2026-04-22 + TheNeuralBase《Filtered Set》2026-04-22 + AIBytes《Fine-Tune Own Data》2026-04-29 + AWS《SFT Part1》2026-08-26 实拉）：**四信号组合检测坏例=相似性过滤（embed 输入输出标离群）/LLM-as-judge 评分（参考模型 1-10）/统计检查（异常 token 长度、参考模型低困惑度、prompt-completion 语义不一致）/人工抽查（抽样 100 例检查）——组合信号不单靠一个；过滤清单=去重（精确+embedding 相似）/长度过滤（过短过长）/语言过滤（单语训练删其他语）/毒性过滤（违反策略）/格式过滤（坏 JSON/坏 markdown）；SFT 坏例教成永久坏习惯难以遗忘（模型学的是"哪些模式被强化"不是学新事实，每个 response 都该是敢上生产的金标准）；最小 500 例，1000-5000 甜区；未过滤集导致模型记忆噪声/矛盾**。提升层：工作流。

**6. 微调后评估四集合 + 遗忘检测**（来源：FutureAGI《Evaluating Fine-Tuned 2026》2026-05-19 + FutureAGI《Pipeline Evaluation》2026-04-12 + TheNeuralBase《Regression Testing》2026-04-22 + TheNeuralBase《Capability Regression Check》2026-04-23 实拉）：**四集合是底线=任务特定 holdout（从未见过）/能力漂移集（不该被微调碰的其他任务）/拒绝集（安全 prompt）/与 base 配对 arena（生产样本胜率）——只赢集合一=剧场；灾难性遗忘检测=同一通用能力基准在 base 和 candidate 上前后打分（MMLU 等）；遗忘严重度依赖 LoRA rank 与 lr——full FT 一般 5-15% 退化，LoRA 低得多；逐任务分解（多用途模型）；手动抽查≥5 输出连贯性/事实正确性，>10% 输出退化触发回滚；评分 rubric 1-3（1=不连贯/幻觉 2=对但缺细节 3=等价或更好）平均掉 >0.3 分触发回滚；eval gate=真 holdout+对比 base+回归/未达标阻断上线（最重要阶段，仅当 eval 集从未泄漏才可信）**。提升层：工作流/可复用 Skill。

**7. 数据泄漏与标签噪声检查**（来源：FutureAGI《Pipeline Eval》2026-04-12 + Latitude《Data Quality Evals》2026-06-25 + MLflow《Evaluation in AI》2026-07-26 + PostTrainBench 2026-07-28 实拉）：**同记录在训练与 eval 中以不同表面形式出现=微调赢 holdout 靠记忆不是学习——MinHash-LSH Jaccard 0.85 抓明显案例+embedding 余弦 0.95 抓改写案例，split 前先 dedup（不是 split 后）；标签噪声=抽样 200-500 行人工核；eval 数据集三保证=与训练/验证严格分离/显式金答案+可溯源出处/覆盖部署关键真实场景；污染监测=训练数据分布评估（非 benchmark 检视本身算证据），>3 个逐字或近似重合=污染；eval 集过期 6 个月就该重做（embedding 距离/intent mix/prompt hash/检索重叠 跟踪漂移）**。提升层：工作流。

**8. 嵌入模型微调 ROI 与无标注合成**（来源：ChiragHasija《Choosing Embedding 2026》2026-06-27 + DigitalOcean《Custom Embedding》2026-08-25 + Fireworks《Fine-Tune Embeddings》2026-07-29 + arXiv 2510.21729《CustomIR》2026-08-24 实拉，与 r368B 判重：检索质量已落，本点补嵌入微调触发阈值与数据合成）：**触发判据=recall@10<80%（对域查询 10 条中 <8 条命中正确文档）+能收集几千真实 query-doc 对→自训嵌入通常赢 API（准确+成本）；数据量 ROI=<500 对 overfit 不值/500-2000 边际/2000-10000 10-20% recall 提升值高价值场景/10000+ 20-40% 显著值得；实测=+39% nDCG@100/+40% Recall@100（法律问答域）；无标注=CustomIR 无监督：LLM 基于已知语料生成多样 query+LLM 验证 hard negatives（省人类标注）；hard negative mining 对对比学习关键（同 action 后缀不同 connector 做训练对+LLM 改写指令+connector 级 holdout 让模型泛化未见工具——109M BGE-base 微调在 ToolRet-full 超 Qwen3-8B/NV-Embed-v1）**。提升层：工作流/可复用 Skill。

**9. LoRA 超参速查表**（来源：Unsloth《Hyperparameters Guide》2026-01 + Codersera《Cheat Sheet》2026-06-01 + LocalAI Master《QLoRA Guide》2026-05-01 + Yobitel《Axolotl》2026-07-04 + PromptQuorum《Hyperparams》2026-04-04 实拉）：**2026 默认=rank 16 起步（16-32 大多生产任务/64-128 域特化/256+ 近 full-FT 少用），val loss 平台才升 rank；alpha=rank 或 2×rank（16/32 常规，高 alpha 学更多易过拟合）；dropout=0 优化更快（小数据集 0.05 正则）；lr=2e-4（1e-4-5e-4 范围，过高 NaN 过低不学；7B-14B LoRA 用 1e-4-2e-4；full FT 5e-5-1e-4；灾难遗忘则降 1e-5-5e-5）；target modules=q/k/v/o/gate/up/down 全线性层；有效 batch 8-32 序列；不稳定症状=训练 loss 降 eval 升→升 dropout/降 rank/降 lr/KL penalty**。提升层：可复用 Skill。

**10. 决策阶梯 Prompt→RAG→Fine-tune→Distill**（来源：Cyberax《Which When》2026-05-01 + OptiVulnix《Decision Framework》2026-05-30 + anhtu《Customizing 2026》2026-06-14 + SF AILabs《Non-engineer Guide》2026-07-09 + Qiita《How to Choose》2026-05-13 实拉）：**阶梯=默认 Prompt（基座已懂只需塑形输出）→RAG（模型缺事实：私有/更新/大容量知识——检索问题不是训练问题，微调是"让模型知道这个事实"的错误工具）→微调（prompt+RAG 证明失败+有数据：一致语调/稀有输出格式/窄域分类）→蒸馏（成本最低终局：小模型匹配教师）；FT 正确触发=prompt 基线+RAG 基线都评估过、两者有已知 FT 能修的失败模式、有几百-几千标注对、使用量证明值；成本=Prompt ~$0/RAG $5K-50K 工程/FT $10K-200K（企业），个人尺度=LoRA 训练 €500-5K；RAG 分钟级更新 vs FT 小时-天重训；行为一致性 FT 最高；生产系统多数组合 2-3 种**。提升层：工作流。
