## 落地 5 独点（每点标注提升层）

### 1. AI 购物助手分工（按场景与闭环选）（工具）
来源：awesomeagents / zplatform / aishopagents / felloai / fluxgrowth
- **ChatGPT Shopping Research=全向发现+即时结账**（免费，电子/美妆/厨房电器最强）；**Amazon Rufus=Amazon 站内研究**（一年价格历史+复购）；**Google Gemini/AI Mode=视觉+deal timing**；**Perplexity=带引用的研究+tradeoff**；**Microsoft Copilot Checkout=站内聊天结账**（2026 年 1 月进入，Bing 产品索引支撑）；**Klarna AI=免费购物 agent**。
- 提升层：工具（助手选型）。

### 2. 比价/优惠工具分工（浏览器扩展）（工具）
来源：aiforregulars / ecommerceguide / harpa / dealmonitor / sina / edge
- **PayPal Honey=结账自动找码**（3 万+站点）；**Capital One Shopping=浏览时显示同款更低价+降价提醒**（无需是 Capital One 客户）；**Karma=保存多店商品+价格/库存追踪+结账自动用码**；**HARPA=点选价格元素设触发（价格<$150）+间隔+通知动作，后台自动刷新页面**；**DealMonitor=AI 价格识别任意网站（无需手动设置）+历史图表+CSV 导出+邮件/Telegram/push 通知**；国内：**粉象生活 AI 比价**（复制链接→AI 管家一次返回淘宝/京东/拼多多/唯品会售价+券后价+历史价格走势+返利对比，1 亿+商品数据）。
- 提升层：工具（比价选型）。

### 3. 比价判据：先确认同款，再算到手价（工作流）
来源：searchengineslists / sina / edge
- **AI 能比价，但必须确认列表代表同一型号/成色/保修/捆绑**（比价专用工具如 ShopSavvy/Edge 购物功能比通用 chatbot 更适合找最低价）；**别只看标价**——券后价+历史价格走势+返利后价格才是到手价；**避坑三查**：低质产品过滤、卖家历史与评分检查、假折扣识别（11.11/黑五/网一时）；Edge 购物助手=自动过滤低评分商品+检查卖家信誉+可视化价格历史。
- 提升层：工作流（比价纪律）。

### 4. 产品研究 prompt：范围决策→搜索模型→推理模型→验证（可复用 Skill）
来源：aizolo / panstag / donely / toolradar / designs24hr-checklist
- **先界定决策**（预算+必选+一票否决）→ **先用搜索型模型拉当前价格与库存**（Gemini/Grok/browsing GPT）→ **再用推理强模型权衡 tradeoff**（Claude Opus 4.8/GPT-5.6）→ **独立验证当前价格/库存/运费/退货/保修再买**；Detailed Requirements Prompt 模板（Secondary use case/Must have/Prefer/Constraints）；**跨 3 来源交叉验证关键数据**；输出=执行摘要+对比表（功能/价格/评分）+逐产品分析+优缺点+置信度推荐；AI 对比 checklist prompt（总成本/质量/评论/卖家声誉/保修/退货政策/隐藏成本/长期价值）。
- 提升层：可复用 Skill（购物提示工程）。

### 5. 购物决策工作流：research→narrow→checklist→verify（工作流）
来源：designs24hr / aijourn / awesomeagents / dealzenohub
- **清晰购买目标+budget+must-haves+deal-breakers → Shopping Research 探索比较 → 答澄清问题 → 移除弱选项收到 3 个 finalists → 比较对你重要的 tradeoff → 独立验证**（价格/库存/运费/退货/保修）**→ 结账**；先搞清产品类别再谈型号（"想要浓咖啡、易清洁、不用昂贵胶囊——什么咖啡机"）；**"机器推荐，评论决定"**——45% 买家以软件评论平台的引文为最高置信信号，AI 建议仍走人验证。
- 提升层：工作流（购买闭环）。
