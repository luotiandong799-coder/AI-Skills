## 落地 5 独点（每点标注提升层）

### 1. 副业机会排名与收入谱（工具）
来源：stackpicks / makemoneyhunter / shopify / developersmatrix / digigenhub
- **10 大副业**：faceless YouTube / 自由 AI 写作 / AI 通讯稿 / 卖 prompt / 语音克隆服务 / Notion 模板 / 缩略图设计 / Amazon affiliate 评测 / faceless Reels / custom GPTs；**首月收入 $0-$2k，12 个月上限 $500-$15,000/月**；**AI 数据训练与评测**（$12-$200+/小时，适合无作品集新手）；副业本质=卖判断力和成品而非 ChatGPT 订阅——挑 prompt、抓错误、交付成品才是钱所在。
- 提升层：工具（副业选型）。

### 2. AI 自动化服务定价模型（工作流）
来源：makemoneyhunter / aiupdaters / scalopa / toolsvora
- **本地小企业工作流自动化**（Make/n8n/Zapier + AI：leads 导入/邮件跟进/内容排期/数据录入）——**$500-$2,000 设置费 + $200-$500/月维护**，2-3 个 retainer 就取代兼职；**AI chatbot 设置 $300-$1,500/项目**（餐饮/本地服务/电商 24/7 客服）；**价值定价而非时间定价**：省 10 小时/周 × $50/小时 = $500/周价值 → 收 $750 设置 + $300/月是 3:1 价值比，客户容易 justify；绝不按小时收设置费。
- 提升层：工作流（定价闭环）。

### 3. AI 自由职业定价阶梯（工具）
来源：developersmatrix / aijobsgate / scalopa / botpool
- **新手 $25-$50/小时或 $200-$500/项目；中级 $50-$100/小时；专家 $100-$250/小时或 $2,000-$10,000/项目**；**Python+LLM 应用开发 $75-$100/小时起**（1-2 个作品集项目），6 个月客户稳定后涨到 $120-$150，成熟从业者 $150-$250/小时；高价值域专家（金融/医疗）更高；**按价值定价不按时间**——AI 增强工作帮客户省 $5,000/月就该按这个锚定；定价模型四选：按小时（开放任务）/固定项目（明确结果）/分层套餐（基础+加急或附加 AI 交付物）/retainer 月费。
- 提升层：工具（定价阶梯）。

### 4. 产品化服务递送（工作流）
来源：fadalstore / bizwhat / personalprofitability / kubeez
- **最高收入者把服务产品化+自动化交付而非卖时间**；**AAA 商业模式=System Design→Implementation→Training→Support**（$5,000-$50,000+/系统，另加 retainer 支持）；**数字产品先卖一单不卖十单**——2 小时做一个针对特定小众的 Notion 模板（如素食食谱博主的排期模板），$19 上架，发到 3 个目标聚集地，第一单教你的比接下来 6 个月都多；**分档产品**：图片广告包（5 张 1:1+9:16 图 + 5 个文案变体 $50-$150）。
- 提升层：工作流（产品化递送）。

### 5. 2026 自由职业高价值技能集（可复用 Skill）
来源：web3geeks / panstag / zerotoai / digitalzoom
- **从单 prompt 到完整可重复系统的六个技能**：**AI agent 与工作流自动化 / 结构化输出 prompt 系统 / RAG 审计 / AI 内容编辑品牌声音 / AI 客户 onboarding / 无代码 AI 应用构建**——客户为"AI 能可靠交付的结果"付费，不为"会写一个好 prompt 的人"付费；**自动化专家平均 $116,607/年**（ZipRecruiter 2026-04）；**6 个月路线图**：先基本 prompt 工程（system vs user/具体性/示例/强制结构化输出，免费课=Anthropic Interactive + OpenAI Prompt Guide）→ 再搭工作流 → 接付费客户。
- 提升层：可复用 Skill（技能路线图）。
