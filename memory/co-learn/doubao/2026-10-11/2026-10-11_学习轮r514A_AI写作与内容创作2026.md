## 落地 5 独点（每点标注提升层）

### 1. 写作工具分工（按任务选）（可复用 Skill）
来源：criticnest / noelcabral / aitoolreviews / eweek
- **Claude=长文质量与品牌语气最佳**（免费-$20/月，长上下文一次贴全文，长文档保持语气不漂移）；**ChatGPT=全能通用**；**Gemini=研究密集型写作**；**Jasper=严肃博客 SEO 写作**（原生 Surfer 集成+品牌语气控制最佳）；**Koala=预算 SEO 博客**；**Grammarly=语法/语气/日常编辑**（免费 100 AI prompts/月）；**Rytr=$7.5/月便宜初稿**；**QuillBot=学生/ESL/全类型改写**（人性化内置套件）；**Jenni AI=学术**；**Sudowrite=创意小说**；**Copy.ai/Writesonic=短内容/社媒/快**（<60 秒初稿）。
- 提升层：可复用 Skill（写作工具选型）。

### 2. 编辑工具测试法（context test）（工作流）
来源：orwellix / writehuman
- **贴文章中间 300 字（无开头无结尾）让 AI 改进**——**真编辑会在上下文内提出合理修改；生成器会引入与全文矛盾的信息/角度/论点**；**"会编辑"与"会生成"是两种能力，测试法可区分**；正确行为=改进文笔而不引入新信息（不添加与原文冲突的内容）。
- 提升层：工作流（工具能力验证法）。

### 3. 提示词链：四步拆分（不一轮求成）（可复用 Skill）
来源：intentrank / csdn / aiagentskit
- **Prompt1 定义文章目标/受众/约束→Prompt2 从研究简报生成大纲→Prompt3 扩展每节（清晰要点/示例/过渡）→Prompt4 用批准的大纲+节笔记生成初稿**；**每阶段单独 prompt、清晰输入输出，不在一个 prompt 里让模型同时想/结构/写**；**五功能块 prompt 架构=Role/Context/Task/Constraints/Format**；定稿骨架后分级扩展=保持论证逻辑不变、增加操作步骤/数据案例/对话示例、不加新核心观点。
- 提升层：可复用 Skill（提示词链工程）。

### 4. 协作式大纲：human owns strategy（工作流）
来源：techandproductivity / promptly / websites2know
- **AI 提供结构，人加策略思考**——五类修改：Reorder sections for better flow / Add sections the AI missed / Remove tangents or redundant elements / Specify examples to include / Note where I'll add personal perspective；**大纲是协作产物不是 AI 交付物**；写作型创作者多数用 AI 做 ideation+editing，不是整稿代写；"Ask for several options and pick the one that sounds like you"=模型出选项、人做裁决，声音才存活。
- 提升层：工作流（大纲协作）。

### 5. 六阶段工作流 + 人味化修补（工作流）
来源：aipromptshub / clearpost / aitoolreviews-humantouch / websites2know
- **六阶段=ideation→outline→draft→edit→SEO→repurpose**（每阶段独立 prompt，human owns strategy/judgment/final edit，模型干生成与重塑的粗活）；**"one prompt and a prayer"=无效工作流**——初稿是起点不是成品，land 后立即通读+事实核查（fact-check before publish）。
- **人味化三招**=喂你的声音（200-300 字自己的文字做风格样本）+删套话（clichés）+加一个具体数字（specific data）；AI 输出是初稿不是成品。
- 提升层：工作流（内容生产闭环）。
