## 落地 5 独点（每点标注提升层）

### 1. AI 穿搭工具分工（按环节选）（工具）
来源：lookastic / stylinai / wearview / beautyai / getwardrobe / perfectcorp
- **Lookastic=衣橱最大化金标准**（10 万+真实服装库，从你现有衣服生成今天能穿的）；**Stylin=免费 iOS**（从已有衣服生成完整穿搭+显示在你体型上）；**Alta=最佳整体 AI 造型师**（天气+日程规划每日穿搭+渲染成像你的 avatar）；**Whering=最佳免费数字衣橱**（穿搭 shuffle+穿着追踪+大社群）；**Style DNA=最佳色彩分析**（自拍→季节色板+风格画像）；**Acloset=最佳 AI 自动打标**（拍照自动录入+天气场合推荐）；**Google Photos=从照片建数字衣橱**。
- 提升层：工具（穿搭工具选型）。

### 2. 个人风格模型（PSM）：三数据流 + 演化式学习（工作流）
来源：alvinsclub / glance / elara / tdcommons
- **Visual Affinity（用户看/停留/划过的内容）→ Contextual Utility（住址/天气/职业环境）→ Physical Geometry（精确测量超越 S/M/L）**；**AI 造型师工作原理：每次接受/拒绝推荐都更新模型**——对话式 AI 捕获偏好如何演化，区别于一次性风格测验的静态快照；风格蓝图=显式反馈+自然语言指令+隐式行为数据综合；agent 向广告库存查候选品并为每件生成 3D 体型虚拟试穿图。
- 提升层：工作流（个性化数据闭环）。

### 3. 穿搭诊断 prompt：体型/色彩季节/三色对比（可复用 Skill）
来源：aipedia / mavgpt / techpresso / buildaiq
- **Stage1 body/face typing（Style DNA/Doris 自拍→体型+色彩分析）→Stage2 color season（Colorwise 16 型个人色彩）**；**色彩诊断 prompt**："Help me create a wardrobe color palette. Colors I wear often: [COLORS]. Colors I avoid: [COLORS]. Style goal: [GOAL]. Create core neutrals, accent colors, color combinations, and shopping rules"；**同 pose 同背景三色对比 prompt**（[YOUR PHOTO] 穿 emerald/camel/off-white，保持面料纹理与版型一致，选你会真下单的那件）；上传全身照（GPT-4o）虚拟试穿，保持脸与身体。
- 提升层：可复用 Skill（形象提示工程）。

### 4. 胶囊衣橱构建：三层色彩结构（可复用 Skill）
来源：findskill / alvinsclub-colors / mavgpt / askside / estilista
- **Foundation colors（频繁中性色支持大多数穿搭）+ Supporting colors（与基础色搭配的次级色调）+ Signature colors（表达个性/创造对比的独特色）**；结构=**2-3 基础中性**（裤/裙/西装/外套：black/navy/charcoal 或 camel/chocolate/olive）+**1-2 浅中性**（上衣/衬衫：white/cream/light gray）+点缀色；30 件胶囊=10 上装×10 下装/或 5 上装×6 下装=30 套，**每件精确色描述**（"dusty slate blue"/"warm cognac" 不是 "blue"）；用当前衣橱已有 2-3 个中性色起步+加 2 个强调色，不整套换。
- 提升层：可复用 Skill（衣橱工程）。

### 5. 穿搭决策工作流：定义风格→虚拟试穿→配评论→降购物车（工作流）
来源：spicyautocorrect / puttogether / alvinsclub-pear / vistoya
- **用通用 AI 定义一句话风格+下一季简版胶囊作购物参考 → 从你已购的零售商试一次虚拟试穿 → 配评论+尺码数据 → 把购物车砍到真正兴奋想穿的那几件**；**weather-aware 穿搭 App**（体感温度/早晚拆分/雨感知/提前规划）；**虚拟试穿对梨形等非标准体型有局限**（2D 叠加忽略面料垂坠曲线，3D 体积数据才平衡肩/腰/臀几何关系）——试穿结果当参考，配评论与尺码数据做最终判断。
- 提升层：工作流（穿搭闭环）。
