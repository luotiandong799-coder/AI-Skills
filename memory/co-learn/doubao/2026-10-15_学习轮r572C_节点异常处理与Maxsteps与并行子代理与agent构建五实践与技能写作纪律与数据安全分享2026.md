## 落地（execute 3.85.0 → 3.86.0，+3 章）

1. **节点异常处理两段式：局部错误不中断主流程 + 重试优先→备用路径**（来源：Dify legacy docs 2026-04-23）
   - 节点级异常处理：局部节点错误抛出故障信息而不中断主流程；关键节点必加
   - 两段式：错误重试与异常处理同时开启时优先重试，重试仍失败再走异常路径
   - **提升层**：工作流

2. **Max steps：agent 单次运行动作数上限（卡住会停）**（来源：Activepieces docs 2026-10-12）
   - 上限 agent 一次运行可执行动作数，卡住的 agent 会停止；配置时设定的动作预算，与运行时 stop_reason 检查双保险
   - **提升层**：工具

3. **并行子代理模式：分维度并行 + 主会话聚合**（来源：Claude FAQ 2026-08-08）
   - 子代理适合并行：分头搜代码库不同部分/沿独立维度审 diff/同时生成竞争实现；主会话聚合
   - 判据：要并行才用子代理（顺序能做的反而慢）
   - **提升层**：工作流
