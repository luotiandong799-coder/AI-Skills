## 二、落地点（4 个真独点）

### 1. 按字节设硬护栏（工作流层）
`maxActiveTranscriptBytes` 达阈值即在一次 run 开始前触发本地压缩；支持 `"20mb"`；0/未设关闭。判据：token 是估算、字节是事实，长工具输出会放大估算偏差。

### 2. 压缩所有权唯一（工具层）
`ownsCompaction: true` 关闭运行时内建自动压缩，`/compact`、溢出恢复、`afterTurn()` 主动压缩归引擎 `compact()`；false/未设也不回落 legacy 路径。判据：两套压缩同时压会互相踩掉对方保留的内容。

### 3. 能力不足就拒跑（工具层）
运行时缺引擎声明所需能力时 `refuses to start the run`；`assemble()` 必须在 `tokenBudget` 内返回。判据：降级跑会写坏状态，拒跑把故障前移到启动时刻。

### 4. 队列三模式按"能否打断"选（工作流层）
`steer`（默认，可插入工具执行中）/ `collect`（不打断，debounce 后只合批兼容消息，独立 durable ingress 消息不参与）/ `interrupt`（中止并起最新）；协作 steering 默认开但执行沿用原发起者身份与已准备权限；steer 排空不用 debounce，在工具启动与模型边界 FIFO 排空。
