## 四、提炼核心方法与关键事实

1. **上下文工程=组装不是堆砌**：right info/right format/right time（动态系统设计）；最小高信号 token 集+每 token 付租金；AI 默认讨好，上下文要对抗。
2. **系统提示最小化+三层持久上下文**：system=core instructions only；动态走 user message（换 context 不 redeploy）；持久层进 CLAUDE.md/skills（progressive disclosure 拆多文件，concise ≈50 tokens）；纠正像同事不像搜索引擎。
3. **任务分解排序**：每步 input/output/dependencies/completion criteria；顺序执行逐项确认；blocking 失败即停；完成即清（Action purge）；先切范围。
4. **Compaction 阈值与评估闭环**：75% 触发+保最近 3-5 轮 verbatim；tool call/result pairs 不入摘要；压后 benchmark 对比成功率，降>几 points 增 recency 或 enrich schema（decisions/entities/open questions/artifacts）；水位线预留触发。
5. **压缩前记忆 flush**：silent memory flush turn 把重要事实先存盘；durable memory 与 working context 分离（写 memory file 按需取过期裁）；volatility 混合策略（低波动 pre-load 高波动 just-in-time）；NOTES.md 边干边更新跨 reset 保 coherence。
6. **上下文预算治理六步**：先 budget 后技术（skip budget=unmeasured system）；static/dynamic 分离；缓存静态层；路由层动态注入；governance+observability；预算分配参考（system 5%/history 40%/tool results 30%/retrieved 20%/buffer 5%）；cache boundary marker 稳定段显式标记。
