## 三、本轮 3 个独有点（完整判据见技能正文）

1. **一致性比率是「逻辑自洽门」，不是「结论正确性门」**：CR 度量的是实际判断与「A>B 且 B>C 蕴含 A>C」这种逻辑传递性之间的偏差；绿灯只证明这组成对判断不互相矛盾，**完全一致的矩阵可以整体系统性偏离**（每个判断都同样错且不违反传递性）。文献自陈「consistency is not necessary, and certainly not perfectly achievable by human subjects, but it is definitely desirable for the reliability」⇒ 一致性是「可取」不是「必要」，既不能以此跳过检验，也不能以 CR 达标宣称结果可靠。报告分两栏写「输入自洽性（CR）」与「结论有效性（外部证据/敏感性/选项集）」，禁把 `CR<0.1` 写成「权重可靠/决策已验证」。与 §十四 DQ 六要素分工：DQ 评决策过程，CR 只评 information 的一个子面。
2. **阈值随矩阵阶数分档，RI 是随机基线不是「允许错误量」；整数标度自带不可消除的不一致**：`CI=(λmax−n)/(n−1)`、`RI`=随机正互反矩阵 CI 平均值、`CR=CI/RI`；分档 **n=3→0.05 / n=4→0.08 / n>5→0.1**（巴勒莫大学逐字），中文统一 0.10 是简化口径 ⇒ 小矩阵照抄 0.1 会放过应判超标者。1–9 整数标度下 5/3 不在标度、15 超上限，「the inconsistency term is **inherent** in AHP」⇒ **CR 超标的第一排查项不是逼决策者反复改判断**，而是 ①阶数与该档阈值 ②标度是否无法表达所需比值 ③是否把本该分组的准则塞进同一矩阵。判定表固定六栏：n / CI / RI / CR / 该 n 阈值档 / 阈值出处。
3. **一致性检验有层级与规模边界**：每个局部矩阵 CR 全绿时，累积到**层次总排序**仍可能超限（科普中国逐字「也可以对整个层次结构进行总的一致性检验」）；`n(n−1)/2` 平方增长使「not sensible to use the method for a large set of criteria」⇒ 大准则集先分组/剪枝/换方法，不是硬填大矩阵再靠 CR 兜底。一致性栏固定六项（每层 n+CR / 总排序 CR / 阈值档出处 / RI 表 / 标度与不可表达比值 / 迭代修正记录），缺任一项不得写「已通过一致性检验」。
