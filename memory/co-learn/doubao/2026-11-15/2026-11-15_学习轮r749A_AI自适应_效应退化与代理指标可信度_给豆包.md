## 三、本轮独有点（判重净新）

- **① 短测试假设处理效应恒定，novelty 与 primacy 方向相反且多数疑似趋势是累计曲线的统计假象**：提高显著性（新按钮/徽章/通知）→ 早期虚高、易误发货；打断习惯（导航/布局/工作流）→ 早期虚低、易误回滚。⇒ 验收用「当日访客逐日效应 + 首 1–2 天首次暴露 cohort + 使用频次/tenure 分层 + 新用户判别」四栏；累计曲线结构性隐藏衰减。KDD 2012/2014 口径：novelty 是**待检验假设**，不是对不喜欢结果的默认解释；确实时延长到稳态（大视觉改动量级约六周，绑 UXDB 条目不写成通用事实）。
- **② 长期效应不是「跑久一点」而是换设计，且长跑自带三坑**：三选一并写明（稳定登录 cohort + 实验前分层重加权 / 关掉处理后的 post-period 残差学习效应 / 时间错开第二份处理且两者一致才宣告收敛）；「just run longer」引入 cookie churn（长期 cookie 标识失效至多 75%）、两臂差异化流失的幸存者偏差、并发实验交互；须分离 user-learned 与 system-learned。⇒ 与 §17 anytime-valid（能否提前读数）、§18 performative（数据生成随策略变）、§19 CUPED（同一指标降方差）正交，互不替代。
- **③ 代理指标与北极星的关系不能靠相关或朴素 OLS 估**：用户级 S–Y 相关被混杂污染（clickbait）；历史实验 (S,Y) 处理效应散点斜率被 correlated measurement error 污染，**真关系可为负而斜率为正**，且「加更多实验只会更精确地估出偏得更厉害的斜率」，能降偏差的是每实验更多单元。⇒ 报告先写「用哪个代理、与北极星的关系用哪种方法验证、前置假设是什么」；默认 TC 或 JIVE（官方对 LIML 的完全中介假设明确警告）；禁把「CTR 显著涨了」写成「长期价值涨了」。
