## 四、提炼核心方法与关键事实

1. **混合检索几乎总是最优**：dense 语义（conceptual/paraphrased）+sparse 精确（product codes/technical terms/IDs）双路并行；RRF 融合最简单；按查询类型定权重。
2. **Rerank 价值量化**：over-retrieve（top-50/100）→cross-encoder→top-10/20；每层增益可量化（contextual embeddings -35%/+BM25 -49%/+rerank -67%）；0.03 cosine 距离内排序基本是噪声。
3. **Contextual Retrieval**：embedding 前 prepend 50-100 token blurb（chunk 在文档哪+读者需什么 context）；索引成本 ~$1.02/百万 doc tokens（caching）便宜到没理由不做。
4. **检索质量先测后调**：golden set 30-50 真实问题；Hit Rate+faithfulness 立刻定位 retrieval 还是 generation 问题；same versioned question set 让改进可测；judge 校准 20-30 例。
5. **Chunking 2026 证据**：overlap 无收益；sentence≈semantic 至 5k tokens；>2.5k 降质；recursive 512 real tokenizer 起步；五 metadata 字段（Source ID/section path/doc date/content type/language）。
6. **Query 改写与扩展**：同义词/标准代号补全（"变频器"→"VFD, GB/T 12668"召回 4.2 倍）；LLM improve queries；模糊问（"сроки?"/"902?"）必改写。
7. **知识技能化**：Corpus2Skill（鸟瞰→钻分支→按 ID 取全文，don't retrieve navigate）；Knowledge-as-Skill；multi-source parallel RAG。
8. **Generation 端 grounding 硬规则**：Only facts directly supported；Do not infer/extrapolate；上下文不足显式说；fine-tune for behaviour/RAG for current facts。
9. **Agentic RAG**：multi-source/follow-up 检索/评估循环/claim 验证 flag；值得复杂度三判据。
