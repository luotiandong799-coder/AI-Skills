## 独点（12）

1. **Agent 记忆四层分类与五层细分**（来源：zylos 2026-07 + developersdigest 2026-05 + memorybase 2026-05 + programming-helper 2026-04）——**四层：working memory（live context window，scope 当前任务）/semantic memory（facts+world knowledge，按需检索——经典 RAG 模式放窗外只拉相关）/episodic memory（过去经历/任务实例，few-shot "以前怎么解决的"）/procedural memory（行为模式+习得例程——agent 随时间改进的层）**；**五层细分（developersdigest）：short-term=session state file（modified files/tests/decisions 生命周期=当前任务）**；**混合存储（memorybase）：vector（模糊检索）+graph（实体关系）+relational（结构化事实）**；**检索四信号组合：semantic similarity+keyword match+recency+importance**。判据：**记忆按四层分策略存取；跨会话状态写 session state file 不塞窗口**。提升层：工作流。
2. **JIT 记忆工具模式**（来源：platform.claude.com memory tool 2026-09 + claude.com managed agents memory 2026-04 + console.anthropic）——**Memory tool=文件目录跨会话存储检索：create/read/update/delete 持久文件，随时间积累不占 context window**；**just-in-time context retrieval：不前置全载——agent 学到什么记录，需要时读回（与"执行前主动注入"同构：写入即时、读取按需）**；**Managed Agents memory store=每 customer 一个共享笔记本（learn user preferences/project conventions/prior mistakes）；memories=files 开发者可导出+API 管理+完全控制保留内容；session 默认 fresh context 结束 state 丢失**。判据：**记忆文件=JIT 检索的持久目录；跨会话知识写 store 不靠上下文携带**。提升层：可复用 Skill。
3. **Dreams 异步记忆整合**（来源：platform.claude.com managed-agents/dreams 2026-09）——**dream=异步 job：取 pre-existing memory store 处理（整合/提炼/重构）——"睡眠式"记忆整合产品化：会话结束后异步跑，不阻塞主执行**；**与记忆流水线（日志→精炼→长期）互补：整合动作本身异步化、可调度、可审计**。判据：**记忆整合=异步后台任务（会话后触发），不做成同步阻塞步骤**。提升层：工作流。
4. **三档 token 预算与五策略**（来源：zylos context-window-economics 2026-05 + agentic-ai.readthedocs 2026-09 + AWS AGENTPERF03-BP02）——**预算分层：Tier1 当前对话保留/ Tier2 summarized prior context=1,000-3,000 tokens（compaction summaries+key decisions+constraint list，session resume 或 compaction 后注入）/Tier3 persistent memory（存储无限、检索带回小量）**；**五策略：Offload（中间结果写 AgentFS 用指针引用）/Reduce（compaction）/Retrieve（RAG 按需拉 chunk）/Isolate（多 agent 每 sub-agent 只拿相关 context slice）/Cache（静态前缀 prompt caching）**；**AWS：prompt content=first-order performance lever；bound history with summarization+sliding window——无纪律时历史+工具 schema 挤掉推理容量**。判据：**上下文组件按预算分层组装；多 agent 隔离 context slice 不共享全量**。提升层：工作流。
5. **三层 compaction 分级与事件感知**（来源：deepwiki claude-code 2026-06 + claude code agent-sdk docs + markdown.engineering 2026-08 + junpingyi 2026-05 + finisky 2026-04）——**分级：MicroCompact（单工具输出过长/超时衰窗，无 API 调用）/Session Memory Compact（预建 session-memory file 替换旧消息，零 summarization 调用）/Full LLM Compact（fork sub-agent 写 9-section 结构化摘要，最高保真 1 调用）；Reactive Compact（413 prompt-too-long 触发，从尾剥 API rounds 直到 fit）**；**渐进原则：cheap low-impact 先（truncate verbose 输出/strip ANSI/collapse 重复/remove redundant sections），aggressive 后**；**compact_boundary 事件（type=system/subtype=compact_boundary 流式通知）——agent 可感知压缩发生并响应（重发关键规则）**。判据：**压缩先做手术级微操作再上 LLM 摘要；压缩事件可被 agent 感知**。提升层：可复用 Skill。
6. **tool-result clearing 与 context editing**（来源：platform.claude.com context-editing 2026-09 + claude cookbook + context-optimization skill 2026-06 + cloudai 2026-06）——**clear_tool_uses_20250919 策略：上下文超阈值时按 chrono 清最旧工具结果替换 placeholder——重工具 agentic workflow 特别有用（文件内容/搜索结果处理完即不再需要）**；**context editing=主动甄选：上下文=收益递减的有限资源，Claude 看到什么是被主动管理的**；**observation masking：verbose tool outputs→compact references（tool outputs 主导 agent trajectory）**；**verbatim compaction 非 summarization（cloudai）：删 raw 不总结——turn 20 审计：>30% 未 compacted 的 raw tool output=烧注意力预算**。判据：**工具结果用后即清（chrono+placeholder）；上下文每 20 turn 审计一次成分占比**。提升层：工具。
7. **KV-cache 优化顺序与静态前缀纪律**（来源：context-optimization skill 2026-06 + agentpatterns 2026-05 + atlan 2026-09 + OpenAI cache 2026-09-22）——**KV-cache 优化：reorder+stabilize prompt structure 复用 cached KV tensors——最便宜优化（低质量风险，先做）；static content 放前 variable 放后最大化 cache hits（Anthropic cache read 0.1×/OpenAI cached up to 90% off）**；**Prompt Cache Keepalive：timer replay cached prefix 存活 tool runs/approval waits——billing/pause-length/interval 条件决定省钱还是 4× 贵**；**mask tools instead of removing（restrict 通过 config 不 remove——保缓存结构）**；**OpenAI configuration_update：调整 reasoning effort 不加 configuration_update 不失效缓存——任务难度可调而不丢可复用上下文**。判据：**静态前缀锚顶；改配置调 effort 用 configuration_update 保缓存**。提升层：工具。
8. **Agentic RAG 检索链与 5 规范模式**（来源：syncsoft 2026-05 + rapidclaw 2026-04 + openlegion 2026-06 + Microsoft Databricks 2026-09 + arXiv 2604.16394 + AWS AGENTPERF03-BP03 + theneuralbase 2026-05 + eduresearch）——**8 阶段 stack（比传统 RAG 2.3×）：retrieval grader（1-3B 小分类器对每 chunk 打分 relevance/recency/grounding fitness——第一个 agentic gate）+cross-encoder reranker+metadata-aware dedup——+contextual retrieval 切 failed retrievals 67%**；**5 规范模式：iterative retrieval/query decomposition/hypothesis-driven retrieval（HyDE）/cross-corpus triangulation/evidence-weighted synthesis；5 层架构 planner→retriever→re-ranker→reflection/grader→generator**；**RRF：score=Σ 1/(k+rank_i)，k=60——dense（语义）+sparse（精确词：产品码/技术标识/专名）两检索都高者排前**；**rerank=一行改动 ~15% 质量提升（Databricks）；query reformulation=单查询扩多（fan-out 延迟换 recall）；Plan-Retrieve-Evaluate 循环（controller 基于中间结果自适应+sufficiency 检查后 listwise rerank）**；**time-aware retrieval（按日期过滤排名）+recursive retrieval（parent summaries→child chunks）+retrieved chunk validation（语义相关+完整再传 LLM，防检索失败污染答案）+Self-RAG reflection tokens/IRCoT 检索与推理交错/FLARE 触发检索**。判据：**检索链=grader→rerank→dedup 逐级收敛；双路检索用 RRF 融合**。提升层：工作流。
9. **RAGAS 四维与 faithfulness-vs-relevance 正交**（来源：ragas docs + thenerualbase 2026-04 + confident-ai 2026-07 + arXiv 2601.04196 RAGVue + ai-tldr 2026-06 + microsoft rag-evaluators + anyscale）——**四维：faithfulness（答案 grounded in retrieved docs？）/answer_relevance（答案 address user query？）/context_precision（检索 docs 中实际相关比例？）/context_recall（是否检索到全部相关？）——三无需 ground truth**；**正交判据：fully grounded yet off-topic（faithful, irrelevant）vs on-topic yet fabricated（relevant, unfaithful）——两个都要跑**；**answer relevance 反向问题法：生成 n=3 假设问题（答案会满足的）+cosine 相似度 vs 原问题**；**RAGVue strict faithfulness：单次 LLM 调用分解答案→最小事实 claim→每个标 supported/partially hallucinated/fully hallucinated（vs 多阶段多调用流水线）**；**双路检索评估：Document Retrieval（有 ground truth：Fidelity/NDCG/XDCG/Max Relevance/Holes）/Retrieval（无 ground truth：LLM judge 1-5 阈值 Pass/Fail）**。判据：**每个 RAG 评估同时报 faithfulness+relevance（正交不合并）；检索质量有标签用确定性指标无标签用 judge**。提升层：可复用 Skill。
10. **生产失败五模式表与三 C**（来源：mech.app 2026-07 + zylos long-running 2026-06 + agentswarms 2026-06 + redis 2026-06 + neuralwired 2026-04 + zylos production discipline 2026-06）——**五模式表：context rot（evict 仍需要的数据——validate compaction against task success metrics）/quadratic cost（全 in-prompt——scoping+compaction）/retrieval miss（evict 未正确索引——embeddings+metadata tags）/state corruption（serialization/schema drift——version schemas+test migrations）/privacy leak（按 user scoping 却跨 tenant 检索——tenant boundaries in queries）**；**三 C：context distraction（>100k tokens 模型过度关注历史重复旧动作不发展新策略——aggressive pruning+curated workspace 非 log）/context confusion（superfluous content）/validation gates before context injection+quarantine zones for hallucinated outputs**；**核心洞察：most agent failures are not model failures——they are context failures（MINJA attack NeurIPS）**。判据：**上下文变更（压缩/驱逐）必须用任务成功指标校验；注入前验证+疑似幻觉输出隔离**。提升层：工作流。
11. **context drift 与 lost in the middle**（来源：neuralwired 2026-04 + cloudai 2026-06 + redis 2026-06 + agentswarms 2026-06 + dev observability 2026-08）——**context drift：工具输出+中间结果+自生成推理积累→transformer attention 稀释——step 40-50 时信号噪声比下降，agent 在扭曲版目标上运行（不是忘记是失真）**；**lost in the middle：相关信息在输入开头或结尾时性能最高——retrieval 是预算决策不是 fetch-everything 默认（更多文档可能让答案更差）**；**cap input tokens+user turn last+summarise mid-window（agentswarms 修复）**；**cap tools 15-20/agent（两工具都能处理同请求模型会常选错→routing 暴露子集）**。判据：**长任务定期核对目标是否漂移；检索拉取按预算决策；工具数超 20 用路由分片**。提升层：工作流。
12. **写 CLAUDE.md 即时化与 PKM capture/reflect 两拍**（来源：baeseokjae 2026-05 + basicmemory 2026-08 + pkm-insights 2026-05 + anthropic claude-4）——**CLAUDE.md 作为 running compaction target：发现新架构约束/debug heuristic/团队约定立即写（compaction 前，不是 post-session 清理）——有这习惯的 agent 渐进更有效而非 plateau 在单次 prompt 质量**；**memory files 模式（Claude 4）：local file access 时模型自建自维 memory files（Navigation Guide 实例）**；**PKM 两拍：capture as you go（daily note brain-dump+agent 结构化+tag [goal]/[decision]/[idea]+wiki-links）+reflect periodically（memory-reflect skill 定时 consolidate recent notes→durable memory，promote one-off thoughts→project/goal notes，surface patterns across week）**；**CODE 进化：本地 AI 自动 summarize/tag/connect 保私有（Obsidian/Anytype local-first）**。判据：**持久事实写入时机=发现当下（compaction 前）；第二大脑=捕获即时+反射定时双拍**。提升层：可复用 Skill。
