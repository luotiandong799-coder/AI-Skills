## 独点（12）

1. **n8n Force Tool Call on First Iteration + Chat 节点人机环 Actions**（来源：docs.n8n.io changelog 2026-09-24 + docs.n8n.io release-notes 2026-05-27）——AI Agent 节点 v3/Agent Tool v3 新增 opt-in "Force Tool Call on First Iteration"：首轮响应强制模型调工具，帮小模型/低依从模型（如 Mistral 系）先走工具而非直接答；Chat 节点新增两个 Actions：send a message（发消息继续工作流）/ send a message and wait for response（暂停执行等用户回复，支持自由文本或内联审批按钮），可作确定性步骤或 AI Agent 工具，实现多轮人机环。判据：**要小模型"先查再答"就强制首轮工具调用；要确定性审批就在 Chat 节点用 wait-for-response Action**。提升层：工作流。
2. **Make 场景即工具：scenario 作为 agent 工具，Return outputs 是输出契约**（来源：help.make.com create-your-first-ai-agent 2026-07-20）——Make AI Agent (New) 里加工具=添加"Call a scenario"模块，把现有 scenario 当 agent 工具；**要返回数据给 agent，场景必须以 Return outputs 模块结束**——场景的输出结构就是工具的 schema。open beta，所有计划可用，自定义 AI provider 付费计划。判据：**把既有自动化当 agent 工具时，先定义"这个 scenario 的输出结构"再接入，没有 Return outputs 的 scenario 调了也拿不到结果**。提升层：工具。
3. **Make AI Agent 多模态 + Maia 建改调试 + agent 类型库**（来源：make.com 2026-02-11 + help.make.com maia 2026-09-14 + make.com agents-library 2026-09-24）——agent 可直接收发 PDF/图片/CSV 文件（免外部 OCR/手动解析）；Maia 是场景内 AI：建场景、改场景（改模块设置/加模块）、调试（能看 scenario 执行日志解释错误）；agent 类型库：Synthesizer（多源汇总成结构化摘要）/ Routing（分析输入动态选工作流，条件树失控时用）/ Qualifier（按标准评估输入做决策，线索评分/申请筛选/内容审核）/ Orchestrator；库内 agent 带 9 类威胁分类映射 OWASP LLM Top 1 输入过滤。提升层：工具。
4. **Pipedream Build with AI + Connect SDK + 自家 MCP server**（来源：pipedream.com docs 2026-09-23 + pipedream.com 2026-09-26 + zapier 对比 2026-09-16）——Edit with AI（自然语言改代码步骤/配参）/ **Debug with AI（工作流报错时点步骤结果直接 AI 调试）**；Connect SDK=托管认证（OAuth/刷新/用户级权限抽象），10,000+ 工具跨 3,000+ API，agent 可代表终端用户执行；**Pipedream 自跑 MCP server 覆盖全部 ~3,000 连接 apps**，LangChain/CrewAI 等框架可直接指向它拿工具发现+托管认证。判据：**要"agent 用第三方服务"免自建 OAuth 就上托管认证型 MCP server；报错排查优先用 Debug with AI 而不是从头看日志**。提升层：工具。
5. **Dify New Agent by chatting + Agentic RAG + Allowed tools 白名单**（来源：dify.ai blog 2026-08-27 + 2026-01-06 + marketplace.dify.ai 2026-09-28）——对话式建 agent：聊天描述目标，Dify 自动生成可复用 skills 并保留会话上下文，就绪后并入 workflow 更大流程；Agentic RAG：非一次性 retrieve-then-generate，agent 迭代分析意图、选工具选源、重写查询，内置策略支持重试/细化/回退（Function Calling 或 ReAct）；Agent 节点可配 Allowed tools 列表——**列表非空时只允许列表内工具**。判据：**Agentic RAG 面向"问题需要多步检索才能答"的场景，单跳查询仍用普通 RAG 更省**。提升层：工作流。
6. **Dify 双向 MCP Server + Plugin Manifest v3 + Multimodal retrieval**（来源：juejin 2026-05-08 + dify.ai blog 2026-01-07）——v1.9+ 双向 MCP：Dify 应用可发布为外部可调服务、也能接入外部 MCP；插件架构 Plugin Manifest v3，**Rust+WASM 可写高性能插件**；v1.11.0 知识库支持多模态（统一语义空间，文图同检索同利用，agent 检索上下文不再限于文本）。提升层：工具。
7. **Langflow A2A 协议 + Policies guarded tools + Memory bases**（来源：langflow.org blog 1.10 2026-06-09 + 1.11 2026-07-22 + policies 2026-05-20）——1.11 支持 Agent2Agent 协议：**发布 flow 供其他 agent 调用、flow 内调用远程 A2A agent**（默认关，环境变量启用）；Policies 组件：**把自然语言业务规则变成可执行 guard 包在工具外**（guarded tools，调用前检查），不是靠模型记住的 prompt 文本；1.10 引入 Memory bases 长期语义记忆 + 可配置向量库后端 + Assistant 建完整 flow（不只单组件）。判据：**业务限制要"每次必然生效"就用 Policies 包工具，别写进 prompt 指望模型记住**。提升层：工具/工作流。
8. **SkillHub 生态数据 + SkillPay：技能经济落地**（来源：腾讯云开发者社区 2026-08-09 + aoyii.com 2026-09-28）——SkillHub 月下载 1700 万+次、累计突破 6000 万+次（央广网 2026-07-17）；**全球 AI Agent 工具总量 44 万+、其中 AI Skill 近 30 万、日均新增 1300+**；SkillPay 平台（腾讯 WAIC 2026）解决"agent 运行中怎么花钱"：skills 可定价、交易、结算——技能从市场变交易所；SkillHub 1.3 万+ skills，虾小宝 35000+ 经安全审核技能（中国市场两强：腾讯 SkillHub 镜像 ClawHub / 阿里虾小宝）。判重：r304A"技能安装风控三数据"重叠部分，生态规模+SkillPay 为独有增量。提升层：可复用 Skill。
9. **Anthropic 技能硬上限数据 + 负向触发词**（来源：console.anthropic.com best-practices 2026-03-12 + skillmd.ai 2026-09-09 + resources.anthropic.com Complete Guide）——**SKILL.md 正文 <500 行**，附加细节放单独文件；description ≤1024 字符、name ≤64 字符（小写数字连字符，禁 XML 标签，禁保留词 anthropic/claude）；**available_skills 块=上下文窗口 2%（fallback 16000 字符），约 34-36 个 skills 后截断**——技能库超 35 个就得做分层或聚合；**欠触发→description 加更多细节和关键词；过触发→加 negative triggers 明确"不适用时"**；避免挂载未使用 skills（影响性能）；多个技能组合用于多文档类型/多域任务。判重：r304B"技能写作"重叠部分，硬上限数据+负向触发词为独有增量（≥40%）。提升层：可复用 Skill。
10. **OpenClaw Skill Workshop 治理：人工批准才激活**（来源：clawdocs.org skill-workshop 2026-07-08）——v2026.6.1 起，**agents 不能直接写 SKILL.md，技能先过 review queue、需人工批准才激活**；流程带审计轨迹+安全扫描+hash 绑定+回滚。判重：r304A"技能安装风控"重叠部分，**"写技能"本身也走审批队列+回滚**为独有增量。判据：**技能变更走审批+版本回滚，跟代码变更同权——被污染的技能比没有技能更危险**。提升层：可复用 Skill。
11. **DeepSeek Harness 四模式 + 插件 vs 复制目录判据**（来源：developer.aliyun.com 2026-08-14 + bibigpt 2026-08-14）——四模式：标准（完整编程 agent）/ **PTC 模式（模型写一段代码编排多次工具调用，Code Mode SDK 把十次来回合并成一次执行）** / 极简（跑基准看模型裸实力：一个持久 bash+一个文件编辑器）/ 创造（内存里试插件、热加载 Cordis 插件）；**建插件 vs 复制目录判据："会不会持续更新"+"会不会给别人"——两个否就复制目录，任一于是才建插件**。判重：r304A"DeepSeek Harness 全插件化"重叠部分，四模式+判据为独有增量。提升层：工具。
12. **Skill 商店大战格局**（来源：xinstall.com 2026-06-04 + firecat-web 2026-06-04 + 头条 2026-09-29）——腾讯/阿里/字节/智谱/月之暗面/美团/小红书全线切入 Skill 商店：阿里在 JVS Claw Agent 内设虾小宝（用户调用消耗算力、收入归阿里云）；字节双线（火山引擎 Find Skill 企业向、扣子 Skill 商店开发者向支持付费）；腾讯 SkillHub 依托微信小程序生态封装标准化 Skill（模式类似小程序交易抽成+广告）；天猫 2026-09 上线 AI 空间站（阿里云/智谱/Kimi/MiniMax/DeepSeek 五家订阅电商化）。提升层：工作流（选型参考）。
