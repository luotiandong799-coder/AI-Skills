## 四、提炼核心方法与关键事实

1. **双索引与上下文检索**：Summary Index 双向量化（chunk+summary，摘要命中带出整组块获 fuller context）；Contextual Retrieval 小模型前缀（50-100 token 位置说明 prepend，precision +35-49%，+rerank −67%）；结构感知分块（尊重标题/代码块/表格+语义完整检查）。
2. **混合检索与重排量化**：dense+sparse 双路并行+RRF 融合（recall@10 78→91%）；cross-encoder rerank 是最大单点精度收益（Hit@1 +15-40%）；宽取窄排两阶段（top50→top5-10）。
3. **两级多级检索与工程**：元数据级→块级两级检索+LLM 元数据富化过滤；parent-child 双层级+句窗/自动合并；索引一次复用（每执行只花检索 token）；从简起步五部分首版。
4. **Agentic RAG**：迭代检索循环（search→evaluate→reformulate→综合；单次检索复杂问题失败）；四任务并行（分解/检索/验证/综合分 agent）；决策与执行分离（agent 决定问什么，管线强制可返回什么）；Self-RAG 自评。
5. **RAG 评估与防幻觉**：RAGAS 四指标（faithfulness>0.85 生产目标）+20-50 QA 对每变更跑；RAG triad 三元组（上下文相关/扎根/回答相关）；防幻觉 prompt 三要素（只用来源+没有就说没有+按 ID 引用）。
6. **RAG 质量护栏**：噪声>无上下文（低质块宁可不注入）；来源戳（source path+timestamp 随块走）；diff 后处理对账（标记引用检索块外内容的改动）；检索即工具（retrieve-as-tool+只锚检索证据）。
