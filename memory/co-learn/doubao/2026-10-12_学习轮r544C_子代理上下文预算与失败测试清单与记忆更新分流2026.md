## 落地 4 个真独点（全部带提升层）

1. **subagent 上下文隔离：聚焦任务独立上下文只回传压缩摘要 + 三工具选型 + fan-out 判据** → execute 3.57.0→**3.58.0**。要点：subagent 每用几万 token 只回传 1000-2000 token 摘要（上下文隔离量纲=回传预算）；元数据预载正文惰性；Parallel Claude/Subagents/Agent Teams 按任务关系选；fan-out 判据=共享输入不共享依赖才并行。提升层：工作流（Agent 编排/上下文管理）。
2. **代表性失败测试清单 + 最小路径** → execute 3.58.0。要点：一个 trigger+最小验证变换动作，确定性优先于 AI，baseline 跑通再加分支；上线前把会坏的方式先坏一遍（重复/乱序/撤销认证/过期 token/畸形 payload/空字段/大批量/部分写入/超时/重试/排队/恢复），失败必须有落点禁止静默。提升层：工作流（测试/上线纪律）。
3. **记忆更新分流：不是每件事都写成记忆更新 + golden recall set 回归阻塞发布** → compressor 3.653.0→**3.654.0**。要点：trace 多数保持历史，少数转 dataset examples/evals/code changes/tool-schema fixes，只小部分 durable context；golden recall set 每次部署跑回归 recall 下滑阻塞发布；system prompt 注入按 turn 记录可回放。提升层：工作流（记忆流水线/发布门禁）。
4. **方案沉淀成模板+验证器闭环** → authoring 1.135.0→**1.136.0**。要点：复杂任务分段协同执行跑通后固化成提示词模板+验证器成对落库；验证器管"做对了没"（字段齐/格式对/阈值过机检判据），只有模板没有验证器=复用复制错误。提升层：可复用 Skill（工作流固化/质检闭环）。
