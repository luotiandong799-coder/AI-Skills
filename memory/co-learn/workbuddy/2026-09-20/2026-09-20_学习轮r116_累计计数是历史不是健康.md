### wb-skill-authoring 2.27.0 → 2.28.0
- **累计计数是历史不是健康**：azure-rbac 累计 488,343 而 SKILL.md 已 404；四条被删技能 lifetime 全高于若干活技能 → "the totals count the pack's history, not the skill's future"。
- **看周序列不看总数**：周曲线向下脱离基线＝已移除，向上脱离＝新条目；"Direction of divergence is the signal"。
- **锁步＝复制计数**：整包活技能同节奏（共享一个包级计数器），相加会按条目数虚增；唯一两条独立计数的是 azure-app-onboard / -prereq（上周 12,376 / 12,373 差 3）。
- **同族名陷阱**：azure-cost（活 367K）vs azure-cost-optimization（死 209K），按名字长度/记忆选名会拿到尸体。
- **删除不删影响**：azure-kubernetes SKILL.md 仍路由到两个不存在的兄弟 → "A router skill can point at ghosts for weeks"。
- **404 三形态**：定位到删除 commit / 最后同步 commit / main 上从无 commit → 不可一律读成"被删了"。
- **预装三步检查**：raw SKILL.md HEAD → 看周序列 → grep 兄弟引用逐个验存在。
- **禁止委派要写显式清单**：`NEVER invoke {"skill": "azure-deploy"}`（"belongs to a different workflow entirely"）。

### wb-artifact-verification 1.54.0 → 1.55.0
- **"只读"是形容词，边界是点名的命令清单**：ABSOLUTE PROHIBITION 逐条点名 npm/pip/dotnet/go/cargo 全部 install/build/test 命令。
- **静态门禁瞄准"只有跑起来才炸"的失败**：manifest 中不存在的 import（MODULE_NOT_FOUND）、依赖钉 5 年以上而生态已移除（werkzeug.contrib.*）。
- **授权按次签发**："general prior consent never counts"。
- **两道门不许合并**：scaffold 门 ≠ deploy 门；门必须把 subscription(name+ID)/RG/region 作为独立行展示（approves the where, not just the what）。
- **门槛不因对象小/免费豁免**；**门禁结论要带基线**（lastScanCommit）；**路由表要含 nobody 出口**。
