## 从真实货架提取的方法论

### 1. 货架按用户意图分 8 类（技能货架组织范式）
精选推荐 / 图像 / 编程 / 工作效率 / 写作 / 研究与分析 / 教育 / 生活方式。

### 2. 爆款 GPT 的条目结构公式
`场景名 + 中英双语一句话价值主张 + 创建者分层背书 + 评分★ + 对话量社会证明`
- 创建者分层：官方(ChatGPT team) / 品牌公司(invideo·Canva·Expedia) / 社区模板(community builder) / 个人专家。
- 信任信号（评分★、对话量如 +1.7M Conversations）**排在功能罗列之前**——用户先信再点。

### 3. 描述模板（可迁移到 skill description / GPT 指令）
`能力动词 + 输入方式 + 产出`，常见输入方式两种：
- 问卷式需求收集：「Answer 4 quick questions and get your website built」
- 文件即输入：「Drop in any files and I can help analyze and visualize」
- 快捷指令系统：Grimoire「20+ Hotkeys for quick coding flows」
- 跨语言描述（中英双语）覆盖更广受众。
