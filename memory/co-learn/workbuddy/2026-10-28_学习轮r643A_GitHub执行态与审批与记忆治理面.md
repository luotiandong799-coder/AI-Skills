## ★ 纪律固化（本轮新增两条，务必沿用）

1. **`gh` 不在 bash PATH**：本会话 `which gh` 空、`gh --version` 报 command not found；真身 = `C:\Program Files\GitHub CLI\gh.exe`。**Python subprocess 调 gh 必须写绝对路径**。
2. **`gh api` 的 `--jq` 必须作为独立 argv 传入**：拼进 endpoint 字符串（如 `gh api "repos/X/issues/1 --jq .body"`）会被当成 URL 一部分，返回整包 JSON（`{"url":...}` 开头），且因含 body 被误判成功。r641 那条「issues/PR 正文走 `--jq .body`」结论须按此**执行形态**收窄。
3. （补充）**`--paginate` 是超时主因**：大仓一次拉全量会让单仓 >90s。**改用 `page=1,2` × `per_page=50` 显式分页 + 6 线程并发**，20 仓 ~40 秒完成。
