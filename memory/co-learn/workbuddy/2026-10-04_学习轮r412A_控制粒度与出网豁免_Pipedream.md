## 三、判不落（逐条理由）

- **scope 只限应用、不授予能力（每请求仍校验实时角色与访问策略）**：与 ag Cap63「可见与可调用是两道门」重叠 >60% —— 那条管"隐藏的能不能被调用"，本条同一族（声明的授权不是授权）。
- **token 为 opaque 256-bit + 单向哈希存储**：ag Cap56「bearer 256-bit 单向哈希」已覆盖 >60%。
- **access token 24h / refresh 单次使用轮转 / 授权码 10 分钟**：ag Cap44 第③点 + sa 3.119.0 同族 >60%。
- **同意页不可被 iframe 嵌入、Approve 延迟激活**：UI 反点击劫持，属产品实现细节，非 agent 方法论层。
- **默认零出网（无 phone-home / license check / update poll）**：ag Cap32「出网白名单 fail-closed」+ sa 3.123.0「安装形态可审查性」>60%。
- **响应体超限拒绝而非截断**：已并入 ag Cap62 第⑥点。
- **浏览器侧与容器侧出网分属不同策略面**：登记项（拓扑事实，无跨场景判据）。
- **SMTP / OTLP / AWS SDK 三条具体豁免**：技术特定，保留在来源侧，不泛化。
