## 落地点

### wb-artifact-verification 1.55.0 → 1.56.0
1. **回归输入优先取被测物自己举的例子**：作者把技能自带 quickstart 生成的名字（`openssl rand -hex 6` 的 hex token）喂回它的多区发现正则，后缀剥不掉 → `regionCount > 1` 返回空。判据：回归输入三档优先级＝①它自己承诺能处理的样本 ②真实产物 ③你手挑的漂亮样本；只过第三档证明的只是"你会挑样本"。**生成标识符的那段代码就是规格。**
2. **"没发现"是断言不是沉默**：这次失效形态不是报错，是一行自信的"未启用多区"。判据：断言"没有"必须同时给出"查了什么 / 命中几条 / 据此判定为无"，缺一项记 `未证明` 不记 `无`。
3. **默认值要溯源到"谁填的"与"哪个入口"**：IaC 没写 SKU → 平台回落 `Standard_GRS`，正确读法是"没人决策"不是"选了跨区冗余"；prisma SKILL.md 说 `create()` 默认 `us-east-1` 而 CLI 实测给 `us-west-1`——**同一产品 CLI 与 library API 默认值不同**。判据：跨入口套用文档默认值是错的，按你实际调用的入口实测并显式 pin。

### wb-skill-authoring 2.28.0 → 2.29.0
**检查 / 评估型技能的输出结构**：①按"能力"分行不按"对象"罗列（四行能力表，每行挂命中资源）②状态词汇由该域的决定性属性决定，不统一成通用色（存储域里"SKU 就是状态"）③产物必须带 `OutOfScope` 表，否则读者把"没扫"读成"没问题"④修复排序依据是可逆性与代价而非严重度，长耗时 / 不可逆项单独成批。

### wb-ponytail 1.41.0 → 1.42.0（三件套升级，本轮唯一）
**按产物存活期选型**：`create-db`（30 分钟实验）vs `@prisma/cli`（下季度还要用）边界在存活期不在功能；优先选自带 TTL 的自毁资源而不是自己写清理任务（"清理逻辑写在你这边会随任务中断失效，写在资源本身则必定执行"）；生命周期参数要主动钉值不接受平台默认；一次性凭证随资源过期（连接串＝bearer token）。
