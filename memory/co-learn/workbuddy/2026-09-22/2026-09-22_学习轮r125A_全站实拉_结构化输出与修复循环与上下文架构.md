## 10 次实拉（逐站留痕）
1. 事件驱动/webhook（中）：四层架构（receiver 校验鉴权/queue 缓冲/processor/response handler）；触发选择判据（cron=周期、webhook=事件驱动+时间敏感、条件触发=模式匹配）；签名验证+secret 单次显示+限速
2. Structured output（强）：**三级谱系=free-form JSON（无保证）→JSON mode（只保证合法）→constrained decoding/strict schema（保证符合 schema）**；validation-with-retry 兜底（jsonschema+reprompt）；**相同 prompt 重试常产出相同无效输出——指数退避 2s/4s/8s+改措辞/换上下文才有效**；strict 模式 schema 约束（禁 anyOf/minLength 等）
3. 任务分解（中-强）：**Atomic Task Graph（arXiv 2607.01942）=显式 DAG 暴露依赖+独立分支并行+失败用图演化史定位错误源**；**ROMA=依赖感知调度（依赖未满足不并行、避免全局屏障沿关键路径）**；分解深度按复杂度校准（微软 AAAI，已落 D116）
4. 代码修复（强）：**TrajSpec：bug 报告规格是修复主导约束——轨迹派生证据富化稀疏报告 Pass@1 41%→72%（SWE-bench Lite）**；**gold standard prompt=失败测试+traceback→一段根因解释→最小补丁修根因非症状→只改指定行/diff 不全文件/不改签名**；迭代硬上限 3-5 次+原始问题上下文每次附加（防走偏）；SWEzze 上下文 6 倍压缩提升 5-9.2%
5. 测试生成（强）：**ExecCritic：测试与修复角色分离——Test agent 独立生成仓库原生测试+fail-closed harness 冻结+Repair agent 修订（不改测试）**；**对抗式测试=Test vs Mutant agent 循环（mutant 攻击测试盲区，test 迭代补）**；**幸存变异体反馈喂回（mutation score 低=覆盖空心）；断言正确性是绑定约束（大量结构合法但断言弱）**；80% 变异分是甜蜜点+CI gate
6. 混合检索（强）：BM25+vector 并行→RRF 融合（k=60）→cross-encoder 重排 top-20/50→top-5/10；**pre-fusion re-ranking（每条流先重排再融合）**；recall budget 先定
7. 上下文工程（强）：**Anthropic 五层堆栈=minimal system prompt/progressive disclosure/tool design/auto-memory/richer references；"system prompt 是内核不是知识库"——稳定行为放 prompt、任务知识放检索、操作指引放工具、持久偏好放记忆**；128k 分配示例（8-12k system cached/20-40k retrieved/10-30k history/2-10k tool outputs/1-3k few-shot）；角色化上下文分层
8. 工作记忆（中-强）：**Context Offloading 模式=超多轮/跨会话 agent 默认文件 scratchpad（filesystem 优先）；多 agent 共享状态不共享窗口**；**working memory=结构化任务状态由 harness 序列化进 prompt（类型化字段/KV/图/文件），消息驱逐后仍存活**；AdMem 栈式记忆（子目标+计划在栈顶，栈外压缩摘要）；MemAct（记忆管理=可学习策略）
9. 平台探活：Langflow 1.11（ColBERT/ColPali 多向量+HITL checkpoints+A2A）/1.12（OpenTelemetry OTLP）；n8n（Anthropic prompt caching TTL 5min/1h）；Dify 1.14（chat 建 agent 自动生成技能+保留上下文）——事实无方法论新点
