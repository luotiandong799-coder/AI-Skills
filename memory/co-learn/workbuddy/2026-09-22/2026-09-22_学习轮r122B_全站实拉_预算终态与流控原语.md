## 10 次实拉（逐站留痕）
1. CrewAI checkpointing：**自动快照 best-effort（失败记日志继续）、手动 checkpoint() 失败抛错**；**事件驱动快照（默认 task_completed 每任务一快照=粒度/磁盘平衡，高频事件更细但文件更多）**；**gate restore on flag 防 live 快照重放成 resume**；runtime state per run 隔离并发
2. Inngest flow control：**五类流控语义区分（concurrency limit+key 每键上限/throttle 限窗口内新 run 启动 FIFO/debounce 静默期合并重复触发/rateLimit 硬丢超限/priority+batching）**；concurrency key 模型映射多租户隔离
3. Conversation Goals（强）：**status=running/complete/capped/interrupted，capped 是独立终态与 complete 区分**；GoalOutcome 报告 complete vs capped+审计轮数+judge 裁决；**预算耗尽≠失败（可能已产出部分答案/完成重要工具/停在外部效应前，StopReason 枚举 completed/budget_tokens/budget_tools/budget_turns/failed，结果带足够状态供调用者决策）**；**停止检查顺序：完成先查、成功次之、预算第三、迭代最后**
4. 循环终止：**no-progress detector（重复相同 tool+args 去重、状态哈希不变）**；**stop-reason taxonomy（done_verified/budget_exhausted/no_progress/max_iterations/human_abort）发可观测性**；非 done 退出 park 状态供后续
5. 工具重试（强）：**不可重试错误显式标记（non_retryable_error_types：declined payment/validation error 终止循环，别烧 attempts 对抗缓存拒绝）**；**只重试工具调用，不重试整个 LLM 推理循环**；幂等键每个逻辑动作生成一次重试复用；工具错误分级（读=安全重试/幂等写=同 key/非幂等写=先查状态）
6. 上下文管理（强）：**offload 优先于摘要（LangChain Deep Agents：阈值触发先把大工具输入/旧 write 参数卸载到文件系统，无可卸载才摘要）**；**阈值分数触发（context window 的分数处触发）**；保留最近 4-6 轮原文；压缩提示承诺保留什么（架构决策/未解 bug/约束）
7. OpenHands Condenser：**事件存储驱动压缩（一切皆 Event 带持久 ID，CondensationEvent 记录，完整事件日志保留）**；双触发路径（proactive 每步查大小/reactive 报错触发）；双 LLM 架构（agent.llm 主推理 vs condenser.llm 摘要独立追踪）
8. WaytoAGI/skill 教程：SKILL.md 结构（name/description/Steps/Examples/Considerations）已覆盖；skill 自动进化闭环（创建→使用→评估→优化）
9. ModelScope/HF：Skills Central/awesome-skills 合集/npx skills add；Hermes skills 闭环——生态
10. Agent 架构：**确定性工作流（代码定义控制流，LLM 在步骤内不控流程）vs agent 驱动工作流（LLM 驱动控制流）二分**；**Plan-and-Execute 失效模式（计划过时→needs_replanning 重规划）**；混合 agentic+确定性步骤（判断处用 agent、确定处用确定性）
