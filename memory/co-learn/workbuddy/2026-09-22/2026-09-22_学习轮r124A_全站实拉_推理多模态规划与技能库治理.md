## 10 次实拉（逐站留痕）
1. CoT 推理强化（强）：**置信度感知自一致性（arXiv 2603.08999）=分析单条推理轨迹的句级特征，自适应决定单路径 vs 多路径——省 80% token 保多路径精度**；**温度分层=候选生成 0.7-1.0 / 验证与反思轮 0.0-0.3**；self-consistency n=5-20 多数投票（错误是独特的、正确答案收敛）
2. 多模态 agent（强）：**AgenticOCR（arXiv 2602.24134）=查询驱动按需解析——先"think with images"分析布局，只识别感兴趣区域，按需解压视觉 token，解耦检索粒度与页级分块**；**视觉接地=模型引用"右上角红按钮"时，架构须支持坐标/bbox/区域标注回传工具**；工具返回截图/频谱图等非文本观察须正确打标格式化；OpenCode Senses 13 个接地工具（ocr/detect/segment/colors）
3. 计划-执行分解（强）：**置信度驱动分解深度（Microsoft Learn）=meta-agent 复杂度评估 simple/moderate/complex——简单任务 1-2 步直接执行，模糊/高风险才详细多步分解**；**一步一能力（"查询 /checkout 错误日志"不是"调查并修复"）+可观测输出+最小依赖链并行**；**一步超过 3 个工具调用就拆分**；ReAct（探索型）vs plan-and-execute（明确定义多步）
4. 表格 RAG（强）：**表头绑定行级切分=按行切但表头行一起带（| 月份 | 营收 | 成本 | 利润 | + 一行→自包含 chunk）**；**表格独立提取存储=chunk 前识别表格→提取为独立对象（DataFrame/markdown）单独存（document_id+table_index 元数据），检索时整表匹配**；**TableRAG=复杂表用 SQL 接口交互（离线建库+查询分解/文本检索/SQL 操作）**；naive splitter 切表中断=无表头纯管道值不可解释；表是二维语义（值=行×列）
5. 缓存策略（强）：**Relocation Trick=工作内存从 system prompt 末尾移到 user message 末尾——工作内存每步变，放 system 尾部使整个 20K system 缓存每步失效；命中率 <20%→74%**；few-shot 固定静态块紧接 system（动态选择破坏缓存）；三层缓存=gateway exact-match（全请求 hash 100% 免）/provider prompt caching（前缀折扣）/semantic caching（嵌入相似跳过 LLM，有 false-hit 风险）
6. Guardrails（强）：**system prompt 不是 guardrail（是建议——关键时被忽略/可被覆盖/换模型就漂移）；真 guardrail 在模型外、fail closed、按可靠性面度量**；NeMo 五类 rails=input/output/dialogue/retrieval/execution；guardrail 是 middleware 不是 prompt 内嵌
7. 上下文压缩（中-强）：**SALT（arXiv 2607.17486）=salience-aware 词法 trie——按主题分配预算（SF-ordered），避免 scalar ranking 的主题塌缩，支持 summary 与 multi-anchor 检索**；**ProCut=按归因估计剪 prompt 模板（分割语义单元→量化影响→剪低效用，生产 78% token 减少）**；A2C-RAG 预算感知压缩
8. 技能检索与组合（强）：**完整技能正文是路由信号——仅用元数据（name+description）路由掉 31-44pp，"写得好 description 就够了"在大规模不成立（zylos 实测）**；**技能遮蔽=库增长时相似描述技能碰撞、agent 更常选错；上下文开销=描述占上下文损害执行质量即使选对；论文结论主因是遮蔽（arXiv 2605.24050）**；GoS=依赖感知检索（目标技能+解析器/预处理器/依赖一并取）；两阶段=retrieval+composition
9. 长程 agent 评测（中-强）：**二分 pass/fail 对长程任务不足；rubric-based 每任务平均 6.1 条分级 rubric 与人类一致性更高（Odysseys）**；**双指标=Resolved Score（全 checkpoint 过才 1）+ Checkpoint Score（权重归一化部分进度）——区分严格端到端完成与部分进度（SaaS-Bench）**；**过程级=exploration SR（找到正确目标）与 execution SR（找到后完成）分离+informational coverage**；LoHoSearch 最强模型仅 34.74%，上下文管理只 +6.8%
10. 平台/生态探活：n8n=AI Assistant（自然语言建/测/修 workflow）+Agents（定义一次到处用：chat/节点/Slack/定时）+Chat node HITL 动作（发消息继续/发并等待响应，可作确定性步骤或 agent 工具）；Dify=Agent Roster（workspace 级可复用 Agent）/Agent Console（实体级配置）/Agent Node（workflow 一步，自带沙箱与作业指令）+Agent Strategy 模板（CoT/ToT/GoT）；smolagents=CodeAgent 写 Python 执行非 JSON 工具调用、~1000 行、30M 下载
