# 2026-09-22 学习轮 r123-C（人工在环 + 混合检索与模型级联 + 评测集治理与 schema 版本化 · 10 次实拉 · 落地 3 独点）

## 10 次实拉（逐站留痕）
1. HITL 人工在环（强）：**审批闸门六项契约=Trigger（确切工具名+参数形状）/Payload（人看到：动作/目标/金额/理由）/Decision set（可返回的决策）/Timeout（N 分钟没决定怎么办）/Audit row（每次决定写日志含拒绝与超时）/Resume contract（恢复时 agent 看到什么状态）**；**一次批准绑定一个具体动作（不授广泛信任）+绑定 action ID+过期时间，参数变了要重新审**；超时策略 default-deny vs default-approve 按域与代价选，超时后 escalate 或安全取消
2. 提示注入防御（中）：least-privilege tools（客服 agent 不需要"发任意邮件"工具）与既有 ctx 工具面安全重叠>60%；sandboxed execution（OS 级隔离减 84% 权限弹窗、消除跨工具污染）单点价值——判不落（与工具面安全重叠）
3. 嵌入与混合检索（中-强）：**生产标准=混合检索（dense 语义+sparse 关键词精确命中技术术语/产品 ID+RRF 融合）+ reranker**；**BGE-M3 一个模型 hybrid 模式替代 dense+BM25+reranker 三件套**；**压缩管线 top50→rerank→top5→小模型压缩 5 chunks 再生成：准确率+15-30%、LLM 输入成本-40-60%**；MRL 3072→256 维质量损失小
4. 长上下文 vs RAG（中-强）：**决策=数据>1M tokens 或频繁更新→RAG；<500K tokens 稳定→长上下文+prompt caching（省 90%）**；**成本数据：RAG ~$0.005/query vs 长上下文 200K $0.20、1M $1.00（40-200×）**；RAG 场景=需精确引用合规/频繁更新/子秒延迟；长上下文场景=整文档分析/跨文档推理/固定有界数据集；**混合是生产默认（检索窄窗口→长上下文模型+接地检查）**
5. 状态检查点（中）：三存储（Git 存工作区/检查点 DB 存图状态/artifact store 存大输出）+每状态转移自动检查点——与 WB r132 sd"编排可重放/幂等"重叠>60%，判不落
6. 模型路由/级联（中-强）：**级联=先便宜模型，QE 质量估计判不足再升级；约 80% 查询小模型即可消化，只有难的上大模型**；**升级门 precision 95% 时 76% 查询小模型独立消化**；省 70-96% 成本；router（分类器按复杂度路由）与 cascade（先小后大按质量升级）结合是生产标配
7. Agent 可观测性（中）：trace-linked evals（评测结果挂 trace，失败回放确切 prompt/检索块/工具输出/版本）；gen_ai.* OTel 约定——与 WB r132 可重放+av D97 相邻，判不落
8. RAG 评测集维护（中-强）：**测试集泄漏三源=用 golden questions 调 prompt/同一模型既生成 eval 又作答/把 eval 问题粘进 few-shot**；**corpus manifest（每文档 source ID/revision/checksum/分类/授权/生效日期/纳入原因）**；**golden set 存 provenance（谁标注/何时/置信度）+验证 expected_doc_ids 真实存在**；**分桶：adversarial 与生产样本分开仪表盘；每个生产事故转成回归用例**
9. 工具 schema 版本化（强）：**schema 用 registry 管理+schema_version 字段+验证时显式检查版本**；**破坏性变更判定=删/改必填参数/改类型/改输出结构/改工具名/改描述都是 MAJOR（描述变化即使 JSON 未变也算 major）**；**默认加性变更（加可选/加新工具/加宽输出）；必须破坏时先 deprecate 后 remove+描述里写迁移说明（描述是模型唯一通道）**；**behavioral drift：schema 不变但提供商静默换权重，输出分布变——把分布变化当一等公民跟踪**
10. 平台/生态探活：n8n 2.37 prompt caching/2.40 agent 修复/Agents 一次定义到处用/Gateway credits；Langflow 1.12 OpenTelemetry——平台功能，判不落
