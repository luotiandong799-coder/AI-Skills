## 12 次实拉（逐站留痕）
1. arXiv Claw-Eval（2604.06132）：**Judge 阶段在 agent 终止后才注入评分工件（评测脚本/参考答案/验证工具）到容器——agent 运行时环境不含评测线索防污染**；**最终分基于三证据通道：执行轨迹+服务端审计日志+工件**
2. NVIDIA（Agent Evaluation/RL）：**奖励函数三性质（测真实任务/难 hack/错时明显失败）；训练前跑 50-100 个输出人工核对分数，与判断不一致就修奖励**；agent 评测=轨迹/tool call/任务结果（任务成功率优先于模型准确率）
3. AWS（Strands 三层：tool usage>95%/reasoning>85%/output>90% 全过才部署）+ Google Cloud trajectory eval（工具调用序列路径评测）
4. Zylos/ByteRover（arXiv 2604.01599）：**Context Tree 分层知识（Domain>Topic>Subtopic>Entry 文件知识图谱+显式关系/溯源+AKL 生命周期：重要性评分/成熟度层级/recency 衰减）**；**5 层渐进检索：多数查询 sub-100ms 无 LLM 调用，仅新问题升级 agentic 推理**；**85% 填充触发输入 eviction（写入持久化后移除 >500 token 大输入参数，85% 阈值给压缩留余量）；零 LLM 调用层（只 disk I/O）防上下文爆炸**
5. Tencent Cloud 双速检索（fast lane 向量+关键词 vs deep lane agentic search）；Kanopy 摘要记忆漂移（facts round off，模型相信用户没说过的话）；四层上下文架构
6. OWASP Prompt Injection Cheat Sheet：**dual-LLM pattern（Simon Willison：特权 LLM 持工具但从不读不可信内容；隔离 LLM 读不可信内容但不能行动；特权模型只收提炼后指令）**；guardrail 只看用户任务+动作（不看不可信中间上下文）→拒绝注入漂移的动作；markdown 渲染剥离图片链接（防 fetch 外泄）；工具参数 schema 校验
7. 提示工程综述（CoT 入门/结构化输出/prompt testing+version control/DSPy 自动优化/meta-prompting）
8. 技能生态数据（Q2 2026 每周新增 4,200 技能；SkillsMP 1.9M；26% 审计技能含漏洞；搜索量 19× 增长；SKILL.md 成 package.json 类比；Linux Foundation AAIF 治理）
9. GitHub 生态（trendshift/小鹏/heatdrop/CSDN）：superpowers 289k、hermes-agent 247k、tt-a1i/archify 68.9k（可验证架构图 agent skill）；google-research/envharness；CSDN 榜单前 10 中 7 个 AI Agent 相关
10. DeepSeek（api-docs/harness）：**DeepSeek Harness（DSH）"Everything is a plugin. Every run is traceable."——模型/工具/技能/会话/沙箱/存储/循环/调度/UI 全插件化，配置选择交换扩展不改源码；DeepSeek-V4（hybrid attention+保留推理轨迹跨工具调用边界+XML tool-call schema 专用 token 减少解析失败+Rust 沙箱 DSec RL 训练）**；Copilot/IDE 集成生态
11. 规划（arXiv 2603.11445/UBC/XBSTACK/Zylos）：plan != executable plan != adaptive replanning != verified completion（四阶段分开测量）；Plan Validator（执行前硬校验参数完整性/格式/风险等级，高风险挂起 HITL）；任务解耦规划（DAG+拓扑调度）；backtracking+adaptive replanning 是主要生产失败模式
