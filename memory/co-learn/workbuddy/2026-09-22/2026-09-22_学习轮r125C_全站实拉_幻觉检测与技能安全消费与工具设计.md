## 10 次实拉（逐站留痕）
1. 错误恢复（中-强）：**三级失败分类=Recoverable（工具超时/JSON 坏→重试修正）/Degradable（上下文超限/模型答错语言→降级行为不停止）/Fatal（API key 无效/schema 破→停止无恢复）**；**渐进升级=自纠→fallback→degrade→escalate**；**多智能体无容错设计生产失败率 41-86.7%**；DLQ（永久错误/预算耗尽→告警+人工审查）；graceful degradation=设计期期待失败+收束爆炸半径+保核心功能
2. 安全（中-强）：**外部获取内容标记为 data 不是 instructions（UNTRUSTED CONTENT 分隔标记，user_task 与 fetched_content 分离）**；**RAG 检索管线按不可信输入处理=strip markup/formatting/metadata+字符限制+日志+轻量分类器预筛**；工具返回结构外文本拒绝（防注入伪装工具响应）；网络出口 allowlist；memory poisoning（持久记忆可写+跨会话=毒化面，OWASP Agent Memory Guard）；最小权限+任务后撤销
3. RAG 进阶（中-强）：**semantic chunking（句间 embedding 距离找自然语义断点）**；context-enriched chunking（每块附文档/章节摘要）；parent document retrieval（retrieve small answer big）；metadata filtering（结构化过滤先于相似度）；reranking 一步约 +15% 质量
4. 记忆架构（中）：四记忆类型（working/episodic/semantic/procedural 全行业收敛）；**遗忘=设计特性（decay/retention policy 防退化+数据暴露；频率低于 ε 删除）**；记忆写入需要与 RAG 文档摄入同级校验（坏写入静默累积）；episodic 元组 (timestamp, agent_id, user_id, event_type, content, embedding)
5. RPA vs Agentic（中）：**结构化稳定高量→RPA；异常多/判断多/输入乱→agent；最强混合=agent 决策+确定性工具执行**；agent 输出不保证每次一致正确
6. 幻觉检测（中-强）：**SelfCheckGPT=N 次随机采样，一致性=事实性信号（真知道的会稳定复现，幻觉各代不一致）**；**FactSelfCheck=事实粒度检测优于句子级，可解释+精确修正**；**MARCH=信息不对称（Solver 生成→Proposer 拆原子命题→Checker 只看声明验证）**；DBSCAN Entropy（n=20 响应聚类+熵分）
7. Claude Skills 最佳实践（中-强）：**Gotchas 节=最高信号内容（从常见失败点累积+随时间更新）**；description 含触发短语（"Use when..."+用户实际会说的话）；SKILL.md body <500 行长内容放引用子文件；**skill 基准 47,150 个：平均质量 6.2/12，只取 top 四分位（≥9）测试；focused modular 2-3/任务 +18.6 分，monolithic 单文件 -2.9 分**；restrict allowed-tools+fork context 只读快
8. 插件市场（中-强）：**skill 安装前 7 项检查=更新时间<3 个月/无可疑系统命令/无外部数据发送/description 有触发条件+排他声明/正文有执行步骤+输出规范/过度权限请求=恶意 #1 指示/网络行为分析（合法 Gmail skill 只连 Google API）**；36% 危险技能；持续监控（今天过审明天可坏）
9. MCP（中-强）：**工具 schema 扁平化=原始类型+enum 替代嵌套对象，避免镜像内部 API，避免改变行为的可选字段**；**工具定义标注副作用（read-only vs write）+幂等保证（"Read-only. Idempotent. Safe to retry."）**；一致错误分类让模型能恢复；大内容放 resources/pagination 不放工具结果
