## 三、判不落（逐条理由）

- **「删除对话或清理日志不会删除其中上传的文件」** → 与 av r395B「正文脱敏≠已删除、附件仍以 0700/0600 存在」同族，重叠 >60%，仅作例证。
- **保留期分档（Sandbox 30 天 / Pro·Team 订阅期内 / 工作流约 3 个月）** → av 已有「保留期是覆盖面的隐性边界」（Make 12 个月），重叠 >60%；本轮取的是保留之外的「搬走后怎么取回」面。
- **归档 ZIP 六种 CSV 的文件名清单** → 登记项，只取其中的 offload 语义作判据。
- **Flowise SSO 全流程** → UI 点击类，按筛选规则不计；"copy the Value, not the Secret ID" 属控制台提示，与凭据面（Cap32）重叠。
- **Flowise SSO 仅 Organization Admin 可配** → 与 ag Cap54「管理授权权是提权面」+ Cap42「管理权不含使用权」重叠 >60%。
- **Dify Sensitive Content Moderation 扩展 API 契约** → 特定域接口包装，不计。
- **Test With Params 复现通道** → compressor 自留地「回放」已覆盖（豆包线）。
