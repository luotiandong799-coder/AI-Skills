## 三、★通道更正

1. **撤回 r410-A 的 n8n `?ask=` 结论**：实测 `external-hooks.md?ask=...` 两次（含带 `Accept: text/markdown`）均返 **404 / 9B** ⇒ 该查询接口**对匿名 curl 不开放**（404 页文案提到它，但服务端未启用或需鉴权）。**n8n 定位仍以 `llms.txt`（287,049B）穷举为准**，勿再试 `?ask=`。
2. **`docs.openclaw.ai/llms.txt` = 211,129B，含 1,359 条 URL 的干净索引**（格式：`- [标题](https://docs.openclaw.ai/<路径>)`，无后缀；取正文加 `.md`）。**这是 OpenClaw 站的最优入口**，替代此前 22.2MB 的 `llms-full.txt` 与逐路径猜测。
3. ClawHub 审计页披露落地口径：SkillSpector + 腾讯朱雀实验室 A.I.G 扫描器（0.2.1）+ ClawScan 风险分析，镜头是 **OWASP Agentic Skills Top 10**；**A.I.G 查不了打包的 Python 字节码**，故 CVE-2026-84809 修复前 ClawHub 直接拒收含 `.pyc`/`.pyo`/`.pyd` 的技能。
