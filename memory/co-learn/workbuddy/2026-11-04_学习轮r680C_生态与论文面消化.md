## 论文面重点判非（本轮唯一需逐串核验的候选）
一手实拉 **arXiv 2611.03377v1《Same Outputs, Different Scores: Auditing the Unchecked Graders of Multimodal LLM Benchmarks》** 摘要（export.arxiv.org API 200，逐串命中）：

- 原文：8 个同行评审基准的官方 scorer 在 5 个单卡 16GB VLM 上复现；盲审人+LLM 裁决（Cohen's kappa=0.956）恢复模型真实答案；**"The scoring rule alone moves accuracy by up to 22 points on identical outputs, yet exactly 0 wherever a model emits clean option letters"**；**"It is the fallback and not the rambling that does the damage"**——非合规率最高的基准 artifact 恰为 0（其 scorer 选择 abstain 而非猜测）；推理模型非合规率 0.000 仍因 parser 保留哪个 regex match 摆动 9.5 分；snapping 非答案到最近选项会记入从未给出的答案却埋掉正确答案，abstention 丢弃用文字表述的答案，likelihood scoring 跟随 answer-token priors；结论要求基准报告 **non-compliance rate + 至少两条规则**，而不是一条未经检验的 grade。
- 提取判据（底层方法论）：①「输出→判定」这一步须与数据集/模型同级审计；② 差异定位在**兜底分支**（非合规输出怎么处置），不是主体输出；③ **规范输出差异恰为 0 ⇒ 越规范越自证不出问题**；④ 三种常见兜底规则各有反向偏差，应并列报告而非选一条。
