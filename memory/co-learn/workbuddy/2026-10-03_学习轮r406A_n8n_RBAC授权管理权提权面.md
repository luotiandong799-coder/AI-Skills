## 审计与落地（r406A）
- n8n RBAC 两级（instance/project），用户在不同 project 有不同角色；项目角色矩阵中 `Use external secrets` 需实例设置 `Enable external secrets for project roles` 开启才生效（n8n 2.13.0+）；Variables/Tags 不受项目 RBAC 约束（实例级全局共享）。
- 自定义实例角色权限组：Instance settings/Members/Roles/API keys/Tags/Projects/Insights；`Roles: Manage all roles` 自动含 `Manage project roles`；`API keys: Manage others` 自动含 `Manage own`（隐式包含链）。
- 提权风险：Manage all roles 可改自己角色追加未授权限；Members:Manage 可邀自己人赋 Admin；Manage project roles 可改自己项目角色自授权限 ⇒ 授权管理权重与受管授权不能同主体。
