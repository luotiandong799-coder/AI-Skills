## 独点详述
1. **修补授权令牌三件套**：`prepare_patch` 只授权一个非空唯一精确 span → `patch` 必须引用同一 span → 授权一次尝试后或目标变更即失效，同技能二次授权被拒。判据：自动修补 = 先锚定 → 按锚改 → 一次一锚，禁模糊匹配改写。
2. **运行时使用回执**：`A runtime usage receipt prevents foreground repair of skills that the run did not use` —— 没被本次运行用过的技能没有修补资格。判据：越界修补的判据是"用没用过"，不是"存不存在"。
3. **所有权按目录判定**：`A skill is Workshop-owned exactly when it is contained in that agent's directory`；bundled/ClawHub/plugin 技能由 owner 更新替换，agent 只说明不编辑；`create` 目标已存在即失败（no clobber）。判据：可写性由"归我管的目录"判定，不由名称/来源声明判定。
4. **扫描分级 + 关键词命中 ≠ 违规**：apply 前重跑扫描，**只有 critical 阻断，warn 可见不阻断**；`Prompt-related keywords are not scanner findings`。判据：命中敏感词不等于语义违规，否则越扫越不敢写。
