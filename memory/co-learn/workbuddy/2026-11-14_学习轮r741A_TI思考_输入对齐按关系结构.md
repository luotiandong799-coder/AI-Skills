## 三、本轮独有点（判重净新）

1. §13.1 路由匹配单位是关系骨架不是词面/来源：逐字「a structurally consistent set of one-to-one correspondences that maximizes the common relational structure」+ systematicity 偏好高阶关系系统；表面属性不进映射（军队规模/堡垒石墙在肿瘤问题无对应）⇒ 判定表写「哪些关系必须一一对应」，用同名换因果结构的输入撞路由验证。
2. §13.2 单范例不产生迁移，比较才产出可迁移 schema：辐射问题冷解 10% / 读堡垒故事 30% / 给 hint 75%；两案例并排 45% vs 单案例 21%（+图示 92%）⇒ 技能与路由表示例至少成对（表面相异·骨架相同）并显式写共同关系；输入增强=重述为带骨架的结构化问题，措辞改写不产生该能力。
3. §13.3 检索门槛与映射门槛分开记账：表面相似只管「想不想得到」、结构相似决定「用不用得上」；结构对齐只凸显 alignable differences ⇒ 输入层加显式 hint 字段、「未检索到先例」≠「无适用先例」两栏分记、经验只沉淀可对齐差异；与 §七调用顺序分工明确。
