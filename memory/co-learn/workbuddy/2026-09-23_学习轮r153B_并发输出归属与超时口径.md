## 二、落地汇报（强制四列表格 · 轮 / 文件 / 版本 / 独有点）

| 轮 | 文件 | 版本 | 独有点 |
|---|---|---|---|
| B | defaults/wb-context-compressor | **3.48.0** | 并发一开，「输出属于谁」必须显式携带（多输入共用一条流 → 日志自动失去归属，官方唯一解法是每条自带唯一 ID）；**取消的最小单位由实现形态决定**（同步实现里一次输入取消会终止整个容器），不是并发参数的函数；两种形态各自的前提不同（线程安全 vs 不阻塞事件循环） |
| B | engineering/wb-debug-loop | **1.47.0** | 超时是 **per-attempt** 度量（重试则各自重新起算，最坏总时长 = per-attempt × (1+重试)）、**不含调度**、且是**「至少」不是「至多」**（要精确须自查用户代码）；`startup_timeout` 与 `timeout` 是两个旋钮；**「被打断」是默认态**（默认可抢占 + 同输入重启 → 幂等是前置条件）；「不被中断」是买来的（3 倍价）**且 GPU 买不到** |
| B | engineering/wb-release-maintain | **1.8.0** | **名字不是身份**：引用绑不透明 ID、只在部署/启动时解析一次 → 同名重建拿到新 ID，**已部署引用继续指旧 ID 直到重新部署/重启**，「改名重来」不算迁移完成；成熟度三阶段写进契约（Alpha/Beta/GA 各自承诺）+ **接口稳定 ≠ 实现成熟**两栏分开；破坏性变更只允许落在 `X.Y.Z` 的 **Y 位**；「什么时候允许整体失败」由「有没有人在等这个进程活着」决定（临时 app 有失败率上限 → 整体上抛；对外服务无限重试 + crash-loop 退避降速） |
