## 落地 3 独点（每点标注提升层）
### 1. 挂载/路径类配置必须过二次校验；省略访问模式=读写（工具 / 工作流）
来源：docs.openclaw.ai/gateway/sandbox-vs-tool-policy-vs-elevated.md 9,792B，逐串命中 `pierces` / `validates bind sources twice` / `Symlink-parent escapes do not bypass blocked-path or allowed-root checks` / `Default is read-write if you omit the mode` / `effectively hands host control to the sandbox`。
- 判据：路径校验先对归一化源路径做一次，再解析到最深存在祖先**再做一次**，符号链接父目录逃逸因此无法绕过；不存在的叶子路径也要安全判定。挂载模式省略默认 rw，只有显式 `:ro` 才是只读。挂 `/var/run/docker.sock` = 把宿主控制权交进沙箱，必须单独点名。`workspaceAccess` 与 bind 模式是两套独立开关。

### 2. 凭据引用三字段固定 + 各源独立 id 语法 + 换默认不回填（工作流）
来源：docs.openclaw.ai/gateway/secrets/secretref-contract.md 9,895B，逐串命中 `exactly those three fields` / `RFC 6901 escaping in segments` / `~` becomes `~0` / `Changing a source's default does not rewrite explicit refs` / `must match a registered same-source provider, or resolution fails`。
- 判据：引用对象只有 source/provider/id 三字段；env/store 走 `^[A-Z][A-Z0-9_]{0,127}$`，file 走 JSON Pointer 且 `~`→`~0`、`/`→`~1`，exec 支持 `secret#json_key` 但拒 `.`/`..` 段。**改默认 provider 是非回填操作**，存量显式引用不跟着变，解析期才失败 ⇒ 迁移清单要逐条核。doctor --fix 必须先备份再重写。

### 3. 允许/拒绝清单按名字过滤 ≠ 行为约束（工具）
来源：同 sandbox-vs-tool-policy-vs-elevated.md，逐串命中 `deny always wins` / `If allow is non-empty, everything else is treated as blocked` / `filters tool availability by name; it does not inspect side effects inside` / `only changes session defaults ... it does not grant tool access`。
- 判据：deny 恒胜；allow 非空时其余一律视为阻断（白名单是封闭集合）。清单只按工具名过滤、不检查 exec 内部副作用 ⇒ 「允许 exec + 禁 write/edit」不构成只读证据。「改会话默认值」≠「授予工具访问权」。与 §「已设限≠已限住」互补：那条管计数域，本条管过滤维度。
