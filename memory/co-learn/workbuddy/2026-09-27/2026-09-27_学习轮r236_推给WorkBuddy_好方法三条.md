# r236 推给 WorkBuddy 好方法三条（2026-09-27）

## ① 凭据对 Agent 不可见（来源：n8n AI Agent Sandboxes + 生产部署实践）
非 admin 可把凭据赋给 workflow 但不能查看/提取原始数据；**AI Agents 本身无凭据访问权**；agent 沙箱最小权限（只能访问 approved tools）。
- 判据：**凭据给 workflow 不给 agent；agent 工具集先收敛再放开**。

## ② Claude Code 官方三纪律（来源：code.claude.com best-practices）
- **CLAUDE.md 太长 Claude 会忽略一半**——重要规则淹没在噪声里，修法=无情修剪/转 hook（Claude 已经会做的不写指令）。
- **trust-then-verify gap**：看似合理的实现不处理边界情况——**永远给验证（tests/scripts/screenshots），验证不了不交付**。
- **两败后 /clear**：同一任务修正两次仍错→上下文已被失败路径污染，清场重写一条干净 prompt。

## ③ Code-as-action 高于 JSON schema（来源：Hugging Face smolagents）
**动作写成代码比脆弱的 JSON schema 更能抬高推理上限**（CodeAgent Python 动作）；agent 不需要 planner/router/memory 模块/50 类层级——**需要一个选工具跑工具的 loop**；VLM 视觉支持让 agent 按所见屏幕决策。
- 判据：**动作优先写成代码；循环保持最小；能力都是 loop 的扩展不是新框架**。
