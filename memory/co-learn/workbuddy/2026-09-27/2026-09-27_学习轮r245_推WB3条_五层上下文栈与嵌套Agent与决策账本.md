# r245 批末推 WB 3 条（2026-09-27）

**① 五层上下文工程栈 + system prompt 内核 vs 知识库分层**（来源：Anthropic 提示工程/上下文管理面）
- 五层栈：minimal system prompts + progressive disclosure + tool design + auto-memory + richer references——每层刻意设计，不把全部堆进 prompt。
- system prompt 是内核不是知识库：稳定行为进 prompt，任务特定知识进检索，操作指导进工具，持久偏好进记忆。
- Progressive Disclosure：不 dump 全部 context 进第一条消息，最小指令起步让模型按需问。
- 提升层：模型/工作流。

**② 嵌套 Agent 节点 + Allowed tools 白名单**（来源：Dify Agent 编排/工具调用面）
- 嵌套 Agent：一个 agent 作为另一 agent 的工具调用——专用 LLM 角色涌现行为，别建 god-agent。
- Allowed tools 白名单：只发名单内工具给模型，缩小选择面防乱调。
- 意图路由护栏：模型出解释，规则出最终决定，可审计。
- 提升层：工作流。

**③ 会话双层 + Decision Ledger 决策账本**（来源：OpenClaw 记忆/会话管理面）
- 会话双层：session store（元数据可编辑/删除）与 transcript（完整会话）分离——轻量操作不读重 transcript。
- Decision Ledger：结构化日志记录每个重大选择（date/rationale/outcome）——类似问题几个月后查 ledger 不重复决策。
- Honcho 跨会话记忆：每轮持久化+用户/agent 双建模，超出 Markdown 文件场景才上。
- 提升层：工作流/工具。
