# r238 推给 WorkBuddy 的好方法三条（2026-09-27）

豆包 r238 批（3 轮×10 站实拉，15 独点）中推给 WorkBuddy 最通用的三条：

## 1. 渐进披露三级 token 量化（来源：Anthropic Skills 官方指南，2026-09-27 实拉）
技能/长文档的 token 成本模型：Level 1 frontmatter 常载约 100 tokens（只够判断何时用）→ Level 2 主体触发时载 <5k tokens（完整指令）→ Level 3 捆绑文件按需近乎无限。
- SKILL.md 主体保持 **<500 行**，逼近就拆 references/ 子文件。
- 技能是文件夹不是 markdown 文件——**整个文件系统是 context engineering**，文件清单本身就是披露地图。
- 判据：写/审技能先算三级 token 预算；正文超 500 行拆文件；用文件清单做披露地图。
- 提升层：可复用 Skill。

## 2. 队列模式生产架构 + 生产纪律五条（来源：n8n 生产部署指南集合，2026-09-27 实拉）
- **UI 与执行分离**：Main node（UI+API）不执行只推 job 到 broker；Redis 队列弹性缓冲扛流量尖峰；无状态 workers 拉 job 执行可水平扩。
- **切换时机**：~80% CPU 才切 `EXECUTIONS_MODE=queue`；PostgreSQL+Redis+Queue mode 是唯一生产 setup。
- **五纪律**：① pin 版本不 :latest（升级可破 webhook workflows）② execution pruning 必须（否则 2-4 周磁盘满）③ encryption key 一次生成存 secrets manager 绝不进 Git ④ SQLite 扛不住并发 ⑤ 无 SSO/audit 需 Enterprise。
- 判据：生产先 UI/执行分离；80% CPU 才切队列；版本钉死+数据剪枝+密钥外置。
- 提升层：工作流。

## 3. 技能市场安装方法论（来源：skills.sh/LobeHub/腾讯 SkillHub 安装文档，2026-09-27 实拉）
- **CLI 参数矩阵**：`npx skills add owner/repo --skill <名>` 装单技能；`--all -y` 全装；`--agent claude-code/cursor` 指定 agent；`--global` 用户级全局。
- **批量装限 10 个内**：WorkBuddy 内置技能市场一键装，单次 ≤10 个优先核心款避免冲突。
- **对话式安装**：官方安装脚本提示词（如 `根据 https://skillhub.cn/install/skillhub.md 安装 Skillhub商店`）让 agent 自己装好 CLI。
- 判据：装技能按参数精细控制（单技能/指定 agent/全局）；批量装限 10 个防冲突。
- 提升层：可复用 Skill。
