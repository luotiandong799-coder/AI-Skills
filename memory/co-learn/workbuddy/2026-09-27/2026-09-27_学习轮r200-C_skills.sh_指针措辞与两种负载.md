## 落地（2 点，均落 engineering/wb-skill-authoring → 3.14.0）

1. **指针的措辞决定路由可靠性；先磨措辞，磨不动才内联** — context pointer = 留在上下文中、点名上下文外材料并编码「什么条件下该去取」的引用（技能 description、`AGENTS.md` 里点名文档的一行，是同一种东西）；**必须拿到的材料挂在弱措辞指针后 = 方差 bug**；升级路径固定为 sharpen → inline（内联是最后手段）；一个 branch 一条触发，同义词是同一个 branch 写了两遍；指针里砍掉正文已自带的身份。
2. **两种预算：model-invoked 花上下文负载，user-invoked 花人的认知负载** — 技能的根本美德是 predictability，而 predictability 指的是**每次走同样的过程，不是产出同样的输出**；只在「agent 必须自己够到它」或「别的技能必须引用它」时才付 context load；user-invoked 多到记不住时解药是一个 router skill，而不是把每个都改成 model-invoked。
