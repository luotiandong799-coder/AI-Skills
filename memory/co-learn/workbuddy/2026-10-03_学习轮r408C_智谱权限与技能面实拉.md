## 三、判不落（逐条理由）

- **「要把工具彻底移除得用 `enabled: false`，策略是另一回事」** → 与 sa 3.113「能力面与授权面是两道门（包含≠可执行、缺失≠被禁用）」重叠 >60%，仅作跨厂印证（已并入 dl 1.139.0 的判据⑤）。
- **同一份工具配置三个入口（创建/更新/会话覆写）+ 更新产生新版本只影响之后会话 + 会话期内冻结** → 与 sa r321A「修订整包不可变且发布只对新会话生效」+ rm §冻结位 重叠 >60%。
- **删除被引用即 409 / latest 跟随可迁移但不能删最后一个依赖版本 / 归档 Agent 不解除历史版本引用** → 与 rm 1.65.0 发布幂等 + rm §冻结位·断链防护 重叠 >60%。
- **上传超限（≤20MB / ≤200 文件）的文件 part 被静默丢弃不报错** → av 2.119.0「静默丢」族已覆盖 >60%。
- **SkillHub 声明「以下为登录态页面不应被索引或引用」+ 指向 robots.txt / sitemap.xml** → 站点自陈抓取边界属合规声明，与既有"边界自证"族重叠，且无判定价值增量。
- **SkillHub CDN 三级降级链（主域 + 3 备用域，onerror 逐级切换）** → 基础设施形态登记项，对 agent 技能系统无复用面。
- **SkillsMP「detail URL 用响应里的 `skillUrl`，不要用 id 拼」** → sa 3.109/3.112 的 id 与路径映射族已覆盖 >60%，登记。
- **SkillsMP「关键词搜索免鉴权、API Key 提配额」** → 配额分层登记项。
- **deeplearning.ai `llms.txt` 索引** → 本轮穷举未见与既有四模式/短课方法论不同的面，判 0 净新（已耗 CPU 复核）。
