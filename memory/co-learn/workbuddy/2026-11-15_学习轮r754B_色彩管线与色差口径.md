## 三、本轮 3 个独有点（完整判据见技能正文）

1. **RGB 数不是颜色，解码链（色彩空间 + 传递函数 + 白点）才定义感知输入**：W3C 逐字给 sRGB 解码常数与「gamma-encoded / linear-light」定义，并给同一颜色在五种空间的五组不同数值。⇒ 报「模型看到的颜色 / 两图色差 / 色调统计」先写三元组；均值、插值、alpha 合成、缩放、差分必须在 linear-light 上做，在 gamma 编码值上算系统性偏差（编码空间非线性光、混色预测不成立）。与 §8.2 FR 三重对齐并列为两个前置校验。
2. **白点与渲染意图决定「转换后还算不算同一颜色」，往返不是无损**：ICC PCS 固定 D50、源非 D50 必做色适应；四意图是四种妥协，media-relative 官方逐字会改动域内**全部**颜色，只有 absolute 对域内精确匹配，perceptual/saturation 厂商自定；W3C 警告 cumulative round-trip errors，复杂设备 profile 官方标 Non-invertible。⇒ 声称「颜色一致」须写 PCS 白点 / 色适应 / 渲染意图 / 有无 profile 四项，往返测试不能当无损证据。
3. **ΔE 是「公式版本 + 参数因子 + 观察条件 + 用途」四元函数**：ΔE76 为 Lab 欧氏距离且感知不均匀；CIE94/CMC 引入权重与 kL/kC/kH（不同行业取值不同、可觉察与可接受用途取不同 l:c）；CIEDE2000 增蓝区旋转项且只是重定义计算方法。⇒ 报色差固定五栏，同一对颜色跨公式数值不同、阈值不可跨版本抄；ΔE 是模型不是主观实验，「ΔE 小」不等于「感知一致」。与 §8.3 只列名 CIEDE2000 互补，不重述 VMAF 分代。
