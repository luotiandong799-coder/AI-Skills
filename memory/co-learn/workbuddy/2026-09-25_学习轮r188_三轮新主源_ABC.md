## A 轮 — Prefect（`docs.prefect.io/llms.txt`，首次作主源，深拉 14/14）

- 落地：`engineering/wb-execute-discipline` **3.08.0**
  1. 并发槽的**释放条件**才是"这个闸门限什么"的唯一判据：完成释放＝并发上限；`slot_decay_per_second` 按时间释放＝速率限制；租约到期＝崩溃回收。启用 decay 后**占用槽数 ≠ 在飞数**。
  2. `strict`（拿不到槽是否放行）与 `raise_on_lease_renewal_failure`（续租失败是否报错）是**两个独立旋钮**，可组合出"获取严格但容忍续租抖动"。
  3. **关阀门 ≠ 拆阀门**：inactive 停用态保留配置与审计痕迹。
  4. 版本兼容是**单向不等式**：client ≤ server；升级先服务端后客户端，回滚反之。
- 判重不落：缓存隔离级别（rr r147-A）、租约/续租（ed r160-A/r187-C）、状态 name/type（av 已落）、Crashed vs Failed（debug-loop r154-A）、有界池嵌套死锁（ed §反模式）。

## B 轮 — Temporal（`docs.temporal.io/llms.txt`，首次作主源，深拉 13/14）

- 落地：`engineering/wb-execute-discipline` **3.09.0**
  1. **带外干预不进事件流**：唯一真相源只覆盖"流内"；流外干预必须自带"谁/何时/原因"（原因强制非空）；证据存活期跟对象走 ≠ 审计保留期。
  2. **运行期干预四态语义**：暂停停派发与重试但**截止时钟继续走**；Reset 清计数与退避、**默认保留心跳检查点**、不影响父流程；中断分"可协商请求 / 不可协商终止"两档，请求成功须回读确认；操作幂等 ≠ 解除条件唯一。
- 判重不落：幂等粒度 vs 历史体积（ed Continue-As-New / ponytail Local Activity）、Task Token 稳定 ID（sa 引用不可变标识，入候选池）。
