## 本轮独点（4 条）

1. **采用度计数器的口径：多计数并存、差异本身才是那个信号**（`wb-skill-authoring` 2.25.0 → 2.26.0）
   - ClawHub 一条同时给 `downloads / installs / stars / versions / comments`；实测 `department-budget-execution-check-free` = 下载 135 / 安装 0 / 星 0 / 已到第 5 版 → 只看任一个都会读错。
   - agentskills.codes 同页 `views`→`installs`：`ui-ux-pro-max` 2023→1909（94%）、`pdf-to-markdown` 2667→1175（44%），**同榜首页转化率差一倍**。
   - 同一个词"installs"在三个站是三个量（ClawHub 下载/安装分记、agentskills 记 views/installs、Skillstore 的 installCount 挂在 pack 上）。
   - 迭代次数不是质量代理（versions 5 + installs 0 + stars 0 并存）。
   - `latestVersion` 四件套 `version/createdAt/changelog/license` 缺一不可；凭据需求 `metadata.setup[{key, required}]` 须在声明阶段列出。

2. **可见 ≠ 已发布：状态位、拦因与中间态不许冒充终态**（`wb-artifact-verification` 1.53.0 → 1.54.0）
   - Skillstore pack 实测 `visibility: public` 而 `publishedAt: null` —— 可被浏览、可被计数，但从没发布过。
   - `publishBlockedReason: null` 是显式保留位 → 门禁结论一律三态（通过 / 被拦并给原因 / 未跑）。
   - 翻译是元数据不是副本：`sourceLocale` / `_contentLocale` / `_isPartialTranslation` / `translationStatus` / `englishCanonicalStatus` —— 部分翻译是真实中间态，且要指名哪一版是 canonical。
   - 审计方归属要披露：ClawHub 由 OpenClaw Foundation 运营、ClawScan 审计页挂同站。

3. **版本归因靠 changelog 不靠版本号**（`wb-debug-loop` 1.18.0 → 1.19.0）
   - 实测 `latestVersion.changelog` = 「正文新增「免费网页版」入口；名称取自 SKILL.md」→ 一句话说清改了什么 + 名字从哪来。
   - 派生标识（名称取自 SKILL.md）排障时要回到派生源验。
   - 升级检查清单＝改了什么 + 授权变没变 + 什么时候改的。

4. **采用度还要配时间跨度与能力缺口**（`wb-skill-authoring` 2.26.0 → 2.27.0）
   - topaiskills 上 Microsoft 官方 `azure-kusto` 标 585K installs，ClawHub 同类条目 downloads 135 —— **跨站同名词差三个数量级，官方身份不担保口径严肃**。
   - 计数必须配时间跨度：587K 摊一天 vs 摊一年结论相反。
   - 目录摘要要自带能力缺口："lists clusters **but cannot query them**"。
