## 三、本轮三独点（SI · system/si-safety-governance 1.8.0→1.9.0）

1. 攻击利用解析器默认规则，不需访问受害系统、不需人打错字；与 typosquatting 区别=请求名字完全正确、错的是解析源；pip 官方把根因写死为「多源无优先级、按版本号选最佳」并明标 `--extra-index-url` unsafe。
2. 修复在客户端+registry 双向配置，不在提高内部版本号：npm 组织独占 scope + `.npmrc` 绑单一 registry + token 只发该 host；pip `--index-url` 指私有代理并删 `--extra-index-url` + `--require-hashes`；registry 侧 BLOCK 路由/exclude 让内部名永不查上游并实测；占位 tombstone 仅对已知名有效是 stopgap。
3. 检出靠解析源异常 + install 期行为，非签名/CVE：SCA 做 namespace collision detection、lockfile+hash pinning 最高 ROI、postinstall 载荷主通道与构建机出网过滤、SBOM 记期望源+版本+hash；声明不防什么（占位不覆盖未知名/签名不证来源/SBOM 只列清单）。
