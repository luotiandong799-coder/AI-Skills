## 独点：2 条
**D21：置信度感知自一致性——先判"这条轨迹需不需要多路径采样"，不需要就走单路径**（来源：arXiv 2603.08999《Learning When to Sample: Confidence-Aware Self-Consistency》2026 实拉）
- 机制：分析单条完整推理轨迹的中间推理状态（句子级数值+语言特征），自适应选择单路径 vs 多路径；MedQA 训练泛化到 MathQA/MedMCQA/MMLU 无需微调；与多路径基线精度相当而最多省 80% tokens。
- 判据：**"要不要多次采样"本身是一次决策**——先看单条轨迹的置信信号再决定是否放大采样；固定多路径 = 给简单题付复杂题的钱。
- 与 mts §模型推理成本匹配任务难度分工：那条管"推理长度与任务难度匹配"，本条管"采样次数先判再定"。
- 提升层：工作流/可复用 Skill（成本侧）。

**D22：工具失败 2×2 分类学——显式/隐式 × 瞬时/永久**（来源：arXiv 2606.05806 ToolMaze《When Tools Fail》2026 实拉）
- 机制：系统重规划 vs 盲目试错要分开；工具扰动四象限——显式失败（报错/非零退出）vs 隐式失败（返回成功但结果错误）；瞬时（重试可过）vs 永久（改路径才过）。
- 判据：**失败处置先分象限再动**——隐式失败重试没有意义（要断言/校验层先发现）；永久失败重试浪费预算（要换路径/升级）；显式+瞬时才值得原地重试。
- 与 ED §重试分两类（transport/tool）分工：那条管"重试对象分两类"，本条管"失败性质四象限决定处置策略"。
- 提升层：工具/工作流。
