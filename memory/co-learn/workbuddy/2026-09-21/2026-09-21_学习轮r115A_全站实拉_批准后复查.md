## 独点：1 条
**D13：工具/MCP 配置"首次批准后不复查"是信任旁路——批准是一次事件，授权必须持续复查**（来源：CVE-2025-54136 Cursor，toolradar 2026-09-16 实拉）
- 机制：Cursor 的 MCP server 配置在首次批准时验证一次，之后从不复查——攻击者修改 config 后能力静默升级（trust bypass）。
- 判据：**一次性批准 ≠ 持续授权**——已批准的工具/MCP 配置要能检测变更（配置哈希/定期复查/变更告警）；"批准过"只对那一刻成立，不覆盖之后的任何修改。
- 与 §工具面安全 D9（来源验证信任层级）分工：D9 管**安装时**来源验证；D13 管**批准后**配置变更监控——两个时间点都要守。
- 提升层：工具/工作流。重叠：D9 20%、guardian 10%——独立成立。
