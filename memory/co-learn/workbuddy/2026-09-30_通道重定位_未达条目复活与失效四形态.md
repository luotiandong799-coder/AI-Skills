## 五、产出的可用判据（已落 wb-artifact-verification 2.76.0）
1. **失效四形态**：① 路径改版（最常见）② 地域封锁（200 + 恒定体积封锁页）③ 客户端渲染（HTML 正确正文 JS 注入）④ 连接层误判（假死，须复验）。
2. **同体积指纹**：跨页/跨子域返回**完全相同字节数** = 封锁或壳，不是内容——区分②与③最快的机检手段。
3. **缺位双证**：判「内容缺位」须**穷举索引 0 命中 且 直取 404**。
4. **判死复验律**：判「连接层死」必须带日期 + 探活证据并定期复验，单次 `ERR_CONNECTION_RESET` 不足以终判（本批两例翻案）。
5. **索引可读 ≠ 正文可取**：llms.txt 可作治理信号与目录情报，但索引里有不代表正文拿得到（Claude 为典型）。
6. **索引优先定位法**：`llms.txt` → `sitemap.md/xml` → `/docs/llms.txt`，定位后再取 `.md`；n8n 286,271B / Make 71,003B / Dify 递归 `_llms/` 均为此法实证。
