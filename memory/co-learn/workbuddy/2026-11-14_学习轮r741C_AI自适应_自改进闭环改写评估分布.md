## 三、本轮独有点（判重净新）

1. §十八 r741C-1 分布随策略参数变不是外部漂移：逐字「there is no longer an unknown static distribution generating observations; rather, data is drawn from a model-dependent distribution」、偏移「triggered directly by the choice of predictive model」；self-fulfilling（警务加巡逻→记录更多犯罪）与 self-negating（ETA 报低→都走那条→真堵）两方向；Twitter 判低互动即不展示=永不点击、Google ETA 反馈环 ⇒ 启动自改进前先判「改版是否改变数据生成方式」，旧日志是 D(θ_old) 不能当新版真值，台账固定记本批数据由哪个 θ 生成、跨版本不混池。
2. §十八 r741C-2 反复重训收敛到 performatively stable 不动点而非最优：myopic 更新「necessarily converges to a performatively stable solution」，稳定只消除重训需求；Nash（稳定）vs Stackelberg（最优），「performative prediction is typically not a zero-sum game」故「stable solutions and performative optima can be very different」；校准良好的预测器可精确预测自己造出的坏结果 ⇒ 「改到不改了」不是「改对了」，循环须显式声明追 stability 还是 optimality，验收双栏（策略自身指标 + 被诱导世界是否变好）。
3. §十八 r741C-3 凸损失不保证凸 performative risk，收敛需两条前置：「even if the loss is convex in θ, [performative risk] need not be convex」；「converges ... if the loss is well-behaved and the performative feedback effects are not too strong. If either ... is violated, there is no guarantee of convergence」⇒ 估反馈强度 ε 后才可启用自动重训环，不满足改小步人审 + 不受曝光决策影响的 holdout，收敛声明须附两前置核验；与 r733C（字段缺失致 OPE 不可用）、r737B（peeking 抬 FPR）分工为「看的对象在跟着策略动」。
