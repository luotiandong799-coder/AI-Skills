### 独点判据原文（逐条，不缩水）

- **r717B-1 ★ECE 只测校准不测 sharpness：mbrenndoerfer 逐字 "a model that always predicts the marginal class probability ... is perfectly calibrated but useless"；mlmentorship "a model that predicts 0.5 for everything has ECE = 0 if base rate is 0.5, but is useless" ⇒ 「ECE 降到 0」不等于判断变有用，必须与适当评分规则（Brier/log，接 §7.1–7.2）及分辨率同报。全库 `sharpness` 唯一命中是豆包自留地 KB 的「continuity vs sharpness」（上下文卫生），不同维度；`MCE`/`debiased` 0 命中。**
- **r717B-2 ★ECE 是分箱协议的函数且两盲点互相掩护：15 箱 0.03 与 10 箱 0.04 不可直接比、等宽箱在置信度偏斜时误导、等质量箱/去偏更稳、ECE 甚至不是预测器连续函数（Blasiok 2023）；thelion "Overconfidence in one bin and underconfidence in another partly cancel ... if almost all predictions fall in the top bin, ECE mostly measures that bin"（0.031/1200 题/990 挤在 0.9–1.0 箱）；Top-label ECE 忽略全分布校准 ⇒ 报 ECE 必附箱数+策略+每箱样本数+是否 MCE。与 §7.3 分层：那条是校准曲线估计误差，本条是把曲线压成单数后丢掉的信息。**
- **r717B-3 ★重校准不是无损操作：thelion 逐字 "Temperature does not change which Choice option wins, but it changes every Noul probability and every Score expectation, so every threshold tuned before the fit has to be tuned again"（0.8+T=2.2→自动批准份额腰斩，"Nothing was wrong with the fit"）；mlmentorship Platt 截距改 0.5 决策、vector/matrix scaling 改类序与 accuracy、"Calibration is not generally lossless on accuracy or decision cost"；连带两失效面 = 子群反向（Nimble Score 0.105→0.177）+ 分布漂移（Laya 0.000 accuracy / 0.952 confidence，"No threshold on confidence can catch that"）⇒ 重校准后必重验阈值护栏、分子群报、声明仅分布内有效。**
