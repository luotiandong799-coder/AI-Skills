## ② 关键对照（本轮最重要的一手发现）
- **规范侧 fail-closed vs 实现侧 fail-open 的直接冲突**：agentskills.io 规范写「YAML completely unparseable → skip the skill, log the error」，而 Claude Code 文档写「doesn't parse, the skill still loads with no fields set」。两者都是一手，方向相反 ⇒ 审核任何技能库时，先问"你的装载器坏了怎么反应"，"我按规范写的"不构成安全证据。此对照已在 sa 3.139.0 与 3.140.0 两条中互指。
