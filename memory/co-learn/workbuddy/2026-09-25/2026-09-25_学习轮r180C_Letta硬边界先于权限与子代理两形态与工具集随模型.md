## 独点（3 组，2 文件）
1. **硬边界装在权限系统之前**（Cross-agent memory guard）：指向别的 agent 记忆目录的调用一律拒绝，**即使 `unrestricted` 也拦**；放宽须按父进程粒度显式 `--disable-memory-guard`。
2. **子代理两种形态**：默认每次新建不复用（一次性执行器，只回最终消息）；也可指定 `agent_id` 调用一个带自己记忆/人格/技能的持久 agent；另有后台模式（完成通知自动注入）。
3. **工具形状跟着模型家族换**（Model toolsets）：OpenAI 系适配 patch 式编辑工具、Claude 系适配字符串替换式；`/model` 换模型时 toolset 自动切换，`/toolset` 可强制指定。
