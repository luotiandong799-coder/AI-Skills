## 独点（3 组，2 文件）
1. **共享状态的键要先声明、运行期只许改不许建**（`$flow.state`）：所有会被用到的键必须在 Start 节点初始化；运行期节点的 `Update Flow State` 只能改已存在的键，**不允许新建**；执行结束即销毁、并发各持一份。
2. **子流调用的单次配置覆盖**（Execute Flow `Override Config`）：可传 JSON 只对**本次执行**覆盖目标流的模型/prompt，还可单指定 Base URL 与凭据；目标流定义不动。
3. **评测器三型含数值型**：文本匹配型 / **数值型（Total·Prompt·Completion Tokens、API·LLM·Chatflow Latency、Output Characters Length）** / LLM 型；一次评测 = 数据集 × 流做笛卡尔积。

## 判非重复理由
- 1 vs ed §共享状态的原子更新（读-改-写整块上锁）：那条管**并发下别写坏**，本条管**到底写进去没有**——允许随手建键，拼错键名就是一次不报错的蒸发。
