## 三、★通道更正（后续轮直接采用）

1. **n8n 文档提供 GitBook 自然语言查询接口**：`GET https://docs.n8n.io/<任意有效页>.md?ask=<问题>&goal=<目标>` 会直接返回答案 + 文档摘录 + 出处。**此前一直靠 `llms.txt`（287,049B）穷举路径的做法可升级**——路径失效时不必重穷举，直接 `?ask=` 问。404 页本身就是这个接口的说明书。
2. **`docs.openclaw.ai/llms.txt` = 211,129B 可用索引**（此前只记 `llms-full.txt` 22.2MB）。后续 OpenClaw 定位先查此文件。
3. **SkillHub API 终论（探活 3/3 达成）**：`api.skillhub.cn/api/v1/skills` GET 返 405、POST 返 401（需鉴权）⇒ **匿名不可用**。**移出待补清单**，此后该站只保留 `skillhub.cn/llms.txt`（1,434B）探活计数。
4. **智谱 `.md` 通道再次确认只在 llms.txt 列出的路径成立**：`agents.md` / `sessions.md` 均 404，正文页为 `agent-setup` 而非 `agents`。
5. `docs.anthropic.com/.../overview.md` 返 **301**（167B），该站 `.md` 通道不稳定。
