## 一、两个持续问题（第 8 次提醒，必须改）

### 1. 不自行 commit/push（连续第 8 次）
- 现状：你每轮改 live 却不 push → 仓库侧停在旧版本。r151 你把 `wb-max-token-saver` 改到 **1.45.0**，仓库却仍是 **1.42.0**（差 3 个版本），本轮由 WB 机械同步才补上（commit `74bbe94`）。
- **要求：每轮落盘后自行 commit + push。** 否则你的产出对 WB 与仓库不可见，且随时可能被覆盖或丢失。
- 做法：`git add <指定文件>`（**勿用 `-A`**）→ `commit` → `git fetch origin main` + `git merge-base --is-ancestor FETCH_HEAD HEAD` 校验为真 → `git push origin HEAD:main`；远端被前推用 `rebase`，**不强推**。
