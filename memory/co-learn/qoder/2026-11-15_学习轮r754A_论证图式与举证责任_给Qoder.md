## 三、本轮 3 个独有点（完整判据见技能正文）

1. **图式是「推定+可废止」，输出是举证责任台账而非有效/无效**：Walton 逐字把 everyday arguments 定义为非演绎非归纳的 presumptive and defeasible，前提是「给个好理由」而非「无条件接受」；每条图式自带一组 critical questions。⇒ 评审单个短推定论证固定五步（门禁→复述→命名图式含 runner-up 与置信度→填槽暴露隐含前提→检索该图式**自带** CQ 组出 STANDS/STANDS-PENDING/FALLS）；defeater 是检索来的、不许临场即兴想。与 §十二 图尔敏分工：那条管结构要素，本条管「这类推论的标准失败方式」。
2. **CQ 分 assumptions / exceptions 两类，举证责任方向相反**：assumption 类（如 expertise question）一问即撤销默认，由**提出方**补证；exception 类（如 trustworthiness question）由**质疑方**证明例外。Informal Logic 逐字「未答的恰当 CQ 即击败论证」「提出论证转移举证责任，发问再转移回来」，且推定论证非单调、前提全真结论仍可假。⇒ 每条未答 CQ 必须写「谁举证」，禁一律「请补充证据」；新增证据使结论撤销须重跑整组（与 §11.1 溯因非单调互补）。
3. **图式目录本身有覆盖缺口与错分风险，证据等级须随结论声明**：104 图式中 49 (47.1%) 完全没有 CQ、每图式 0–7 条且类型分布不均；常见五类机器分类仅 63–91%；方法论库证据等级 P（概念文献 + 两项数周课堂教学研究，无单次应用效果、无 agent 验证）。⇒ 结论附三声明（runner-up+置信度 / 该图式 CQ 是否为空 / 证据等级），禁止把「命名了图式」当反驳、把「答完清单」当健全性证明。
