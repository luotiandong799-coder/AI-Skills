## 三、本轮 3 个独有点（完整判据见技能正文）

1. **矛盾可以在写入时消解，也可以留给检索时排序；两代官方算法给出相反答案**：旧版两趟 LLM + 四操作（LLM 选、非相似度阈值）在 write time 解决矛盾；新版单趟 ADD-only「nothing is overwritten or deleted」，矛盾交检索侧多信号排序。⇒ 验收先问「本系统矛盾解决在哪一层」；写入侧删旧值后再答不出「以前住哪」，检索侧无时间信号就 stacked contradictions；四操作须含 NOOP，且须区分临时状态与持久画像（「I'm in Berlin this week」不矛盾「user lives in Lisbon」）；时间分是 additive 不过滤候选。与 §五 r732B 四时间戳分工：那条给数据模型，本条给架构位。
2. **架构反转是破坏性变更，迁移清单 ≥5 项**：① 默认 threshold 0.3→0.1（低分匹配浮出）② score 变多信号融合、绝对值漂移须在代表查询集 retune 硬阈值 ③ ADD-only 使 memory count 不再 plateau，须配 expiration/清理 ④ agent 生成事实升一等 ⇒ 写入面与 provenance 同步扩大 ⑤ `get_all` 变分页 envelope；且旧记忆不重处理＝两种抽取语义同库长期并存。⇒ 换算法/换打分口径默认按破坏性变更处理，每项配回归用例；benchmark 涨分不构成升级完成，须连同 top_200 等约束、mean tokens 与最难类（Knowledge update 93.6）并报。
3. **遗忘是两套可组合独立机制，四策略不可互换**：Memory Decay 是 search-time 重排（1.5x/0.3x）**不删**，eviction 才真删，故一条记忆可「躲过所有驱逐仍被压到 0.3x」⇒ 健康度固定「检索可及性 / 库内是否还在」两栏。Age+recency 管噪声、salience+supersession 管事实，各需至少配一；专属失效面：TTL 删掉又老又真、LRU 把访问频率当重要性代理伤低频高危事实、salience rater drift 须 pin scorer 版本、supersession 假阳性。三类失效模式各需定向用例，不许一个总准确率盖过；promotion 是显式提升动作。
