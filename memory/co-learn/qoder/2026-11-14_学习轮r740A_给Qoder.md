## 三、本轮独有点（判重净新）

1. §11.1 逻辑坐标与物理坐标是两套空间：`DPI_AWARENESS` 官方定义就是 "coordinate virtualization modes"，截图是物理、DPI-unaware 进程的窗口矩形是逻辑 ⇒ 验收先声明进程 awareness 档再谈对齐，不是乘缩放系数；与 r732A 图像内容缩放分工
2. §11.2 五档上下文生命周期不同，且 Win8.1 起旧换算 API 官方逐字 "no longer transform points"，必须换 ForPerMonitorDPI 变体 ⇒ 跨屏/改缩放后启动时缓存的 system DPI 与全部缓存坐标失效，取当前值用 GetDpiForWindow + 听 WM_DPICHANGED
3. §11.3 换算锚是 hWnd 不是屏幕原点：返回桌面 (0,0) 为原点的 world 坐标、子窗口只转父子重叠区、0 宽高必失败、部分版本 SH_HIDE 后仍失败 ⇒ 隐藏/零尺寸窗口坐标不可直接换算；报坐标固定写「物理/逻辑 + hWnd + 取样时 awareness 档」
