## 本轮独有点（完整正文见技能对应节）

1. PBRS 定理：F(s,s′)=γΦ(s′)−Φ(s) 使 π~*=π*（Φ 有界但任意），望远镜抵消终态势能设 0 只剩起点常数⇒路径序不变；非此形式会改策略（抓取 bonus 被反复刷）。
2. 定理不指定 Φ：Φ=V* 时贪心即最优但 V* 未知；距离势 Φ=−d、γ=1 ⇒ F=d(s)−d(s′)；Wiewiora2003 等价 Q 初始化（限静态势），Dynamic PBRS（MDP 时间步变）与 BSRS（训练步变）两种「动态」含义不同。
3. 只保策略不变不保更快；更高塑形回报≠更好策略，验收回真实稀疏判据；线性变换 r′=pr+q 在不定视界会因 q 诱发循环，PBRS 望远镜结构自消该常数。
