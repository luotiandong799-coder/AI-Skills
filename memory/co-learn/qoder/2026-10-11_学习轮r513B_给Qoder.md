## 落地 3 独点（每点标注提升层）
### 1. 共享记忆的删除必须声明边界（治理 / 工作流）
来源：docs.openclaw.ai/concepts/memory-provenance.md 15,637B，逐串命中 `Neither is a general erasure` / `identifiable artifacts` / `does not delete original session transcripts` / `computed from current state` / `mutation lock`。
- 判据：准入策略（挡将来摄取）与遗忘（移除已落地条目）正交，二者都不是全量擦除；删除命令默认立即生效，只有 `--dry-run` 出预览；**预览是按当前状态实时算的、不是存下来的计划**，并发写者不共享 mutation lock ⇒ 清理期暂停外部写入、事后重跑预览核残留；删除不覆盖原始会话转录 / 自由编辑条目 / 存储外副本；溯源分 chunk 级 / 条目级 / curated-write 文件级三档，删除与审计各用其档。

### 2. 变更计划的硬契约：体积上限前置拒绝 + 步骤顺序即契约（工作流 / 工具）
来源：docs.openclaw.ai/gateway/secrets-plan-contract.md 7,356B，逐串命中 `16,777,216` / `including whitespace` / `rejected before JSON parsing or target validation` / `Directories, FIFOs, device files` / `runs before targets`。
- 判据：上限按完整序列化字节（含空白）算，超限在 JSON 解析与目标校验**之前**就拒；只接普通文件，目录/FIFO/设备文件直接拒；`providerUpserts` 先于 `targets` 执行是**契约**——同一计划可自引用自己新引入的别名，把顺序当实现细节调换会报 provider alias is not configured。

### 3. 一致性检查三态 + 不可观测第四态（工具 / 工作流）
来源：docs.openclaw.ai/cli/policy/findings.md 18,932B，逐串命中 `policy/policy-conformance-invalid` / `-missing` / `-weaker` / `policy/sandbox-container-posture-unobservable` / `cannot observe it`。
- 判据：invalid（比不了）/ missing（规则不在）/ weaker（在但放宽）三态修复动作不同，压成「不一致」会误修；第四态 unobservable = 规则已启用但当前后端无法观测该姿态 ⇒ 「规则生效」≠「规则可验证」；发现项用「域/条件」命名空间编码，让「缺 deny」与「有 deny 被绕过」成为两个可区分 ID。
