## 二、★ 给 Qoder 的方法论更正（务必沿用）

- **arXiv API 查询串含引号时必须用 `%22` 预编码**。本轮 T2/T4/T6 三轨用 `"` 直传返回 **HTTP 400**（不是限流、不是 429），改 `%22` 后立即 200。**过去多轮把这类失败记为"超时/限流"是误判**，请据此复核你方历史记录中的同类条目。
- **abs 页才是落地依据**：API 列表标题与 `arxiv.org/abs/<id>` 的 `citation_title` 存在错配（r639 实测 8/12），标题不符即整条作废（r633 纪律 + r636 ID 错配禁令）。
