### 独点判据原文（逐条，不缩水）

- **r717C-1 ★验收指标是复发率，不是文档数或行动项完成率：zakhassan 逐字 "The most direct signal is incident recurrence rate — the fraction of incidents that represent a failure mode you've seen before"（须打 failure_mode/is_recurrence 标签按 90d 查询）；三配套量 = 闭环速度比 <1.0 债务在涨 / >90 天无进展是优先级失败 / 心理安全脉冲+独立发言分布；收口 "The goal was never to have better postmortem documents" ⇒ 「行动项全关了但复发率不降」仍判无效。★单次复盘噪声大，季度 Learning Review 把复盘语料当 sociotechnical system 状态证据（五段议程、同根类 ≥2x），反事实换框问「什么条件为真才不发生」并列联合充分条件 ⇒ 干预组合而非单一根因。与 §7.4 分层：那条管单条行动项存活。全库 `repeat incident`/`facilitator` 0 命中。**
- **r717C-2 ★反事实措辞门是可机检的因果开关：tinycto 逐字 "Counterfactual reasoning ... is the most pervasive anti-pattern in incident postmortems. It is fueled by hindsight bias"；四条规则 = 禁用 could/should have/failed to/carelessly/inadvertently + 局域理性重构（"Given the information, dashboard signals, time pressure ... why did their action make complete sense to them at the time?"）+ latent traps + 技术护栏型行动项（schema 校验 / CI 门禁 / IAM 收敛，非「提醒人更小心」）；可机检 = 模板 lint 标红 + 场外 facilitator + 时间线严格按当时每人所知重建（sph.sh / pmmilestone）。双收费 bug 实例：第一次停在人 → 两周期后另一人另一路径复发，第二次深入到幂等键/dry-run/共享锁才根除 ⇒ 措辞不是文风问题是因果开关。**
- **r717C-3 ★替换测试给无责与问责可操作分界：sph.sh 逐字 "Would another competent person, with the same information and the same pressures, likely have made the same choice? If yes, the problem is the situation, not the person ... If a reasonable peer clearly would not have, you have moved toward genuine recklessness"，且 "Even then, the system learning still happens"；PagerDuty 主张 blame awareness 而非声称纯无责，模板刻意不设「谁造成事故」字段、响应者只以角色出现；配套 near miss 同等复盘、写新报告前先读旧报告、行动项上限 5。与 §7.5「无责≠无人负责」互补：那条是原则，本条给判定测试。全库 `替换测试`/`局域理性`/`local rationality`/`facilitator`/`near miss` 词边界 0 命中。**
