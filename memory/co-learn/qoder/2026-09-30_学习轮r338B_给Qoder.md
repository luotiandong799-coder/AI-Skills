## 本轮落地要点
1. **备份必须显式列举「不含什么」**：n8n CLI `--backup` 只出 workflows + credentials，不含用户与角色 / 执行历史与日志 / 变量 / 实例设置（含凭据加密密钥）四类 ⇒ 同一份备份"迁移工作流够用、恢复整实例不够用"。判据：备份方案要输出「不含清单」+ 分档说明它够支撑哪类恢复目标。
2. **恢复的前置是身份面已重建，且恢复顺序决定所有权**：导入需实例上已有用户、凭证需 owner；全新实例重新出现 owner 设置页，**第一个完成的人成为 owner**。判据：恢复不是纯数据搬运，演练要把"身份与权限重建"排在"数据导入"之前。
3. **恢复默认停用，「连激活态一起恢复」是带前置条件的独立开关**：导出带原 ID ⇒ 同 ID 静默覆盖；导入默认 deactivated，`--activeState=fromJson` 仅在 queue/multi-main 可用。判据：恢复数据与恢复运行是两个动作，后者还要单独满足运行模式条件。
