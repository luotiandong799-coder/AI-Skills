## 三、本轮 3 个独有点（完整判据见技能正文）

1. **识别性是图的性质不是样本量的性质**：Q 可识别 iff 由给定 DAG G 的 P 唯一确定；PNAS Definition 2 的可机检式 `P1(v)=P2(v)⇒Q(M1)=Q(M2)`；未测共同原因使 P 兼容任意 `p(S|do(T))`；do-calculus 对 `Q=P(y|do(x),z)` **完备**，三规则用尽仍消不掉 do = 逻辑边界。报「推不出」必须给图 + 未测边，禁止换模型 / 扩样本回应。
2. **Simpson 聚合反转由权重差与图裁决**：`p(S|T)=p(S|T,M)p(M|T)+p(S|T,¬M)p(¬M|T)` 权重不同即反转，Theorem 1 权重相等则不反转；同一份数据可对应观察等价但干预含义相反的两张图（Z 混杂 vs Z 对撞）并推出相反决策 ⇒ 先列候选图 + 每图下该不该分层，禁默认「分层更细更可信」。
3. **后门准则两硬约束 + 对撞陷阱**：Z 不含 X 后代、阻断所有含箭头入 X 的路径，命中才用 `p(Y|do(X))=Σ_Z p(Y|X,Z)p(Z)`；混杂是「量不出来」而非「另有解释」；条件于共同原因阻断、条件于对撞 `X→Z←Y` 或其后代反而**打开**伪相关（PNAS d-separation Definition 1）。调整集须逐条写排除后代 / 谁阻断 / 是否误纳对撞中介。
