## 三、本轮 3 个独有点（完整判据见技能正文）

1. **成功与失败同源，是同一枚硬币两面**：三阶段演进＝human error 是根因→performance shaping factors「迫使」人失败→failures and successes have the same source；FRAM「resonance arising from the variability of everyday performance」。判据：复盘不能只分析出事当天，要分析日常正常工作（work-as-done）里那些也支持成功的调整（Safety-II）。

2. **六方面六角 + 四原则 + 四步骨架**：四原则（equivalence/approximate adjustments/emergence/functional resonance）；六方面 input/output/precondition/resource/control/time；四步＝建模→刻化可变性→按耦合聚合共振→监控管理；两表现型 timing 与 precision；foreground(焦点可变) vs background(稳定边界)。判据：只写「谁没做什么」＝停在第一代错误观，FRAM 要求逐功能列六方面+标表现型+画耦合。

3. **耦合三态与管理观**：functional resonance＝日常噪音振荡成信号，上下游耦合 amplifying/damping/no-effect 三态；第四步「maintain ... within an acceptable boundary ... monitor and/or dampen unwanted variability」「rather than eliminating variability since this is inevitable for things going well」；11 CPC 按 stable/variable adequate/inadequate/unpredictable 判变异性。判据：改进项写「监测+阻尼」而非「消除差异」，与 r734B STAMP 互补（STAMP 管约束与控制结构，FRAM 管可变性耦合）。
