### 独点判据原文（逐条，不缩水）

- **r735C-1 ★noise ≠ bias：误差拆两轴，减偏不减噪；噪声靠噪声审计才看得见**：噪声的「statistical invisibility」是被长期忽视的根因——单例里根本看不见，必须跨判断集统计。三型分别对应评审者平均严厉度、对无关个案特征的稳定反应、同一人随时段/疲劳的波动；accuracy 与 precision 是两轴，与 `wb-agent-evaluation` §r712C（judge 准确率/校准 FNR/FPR）正好正交。判据：① 单看一次判断不构成一致性证据，要问「换个人/换一天还会是同一结论吗」；② 噪声审计先于整改（多人独立判断量化离散度，保险业 55% vs 预期 10%）；③ 方案体检单加「判断离散度」栏（人数/各自独立结论/分歧幅度/是否本应一致场景）；④ 降噪不消灭分歧——创意与政治辩论的多样性不是噪声，只在评分/验收/量刑/核保等本应一致场景压方差。

- **r735C-2 ★决策卫生是架构不是说教：顺序对了才有用，信息要说给「还没形成印象的人」**：四步是流程编排而非劝告：维度独立打分 → facts before opinions / evidence before conclusions → 讨论前各自定稿 → 机械聚合平均而非最响的声音。首位自信发言者锚定全场会 destroying the statistical independence；MAP 明确禁止在独立评估完成前形成整体印象，对有偏信息（供述、魅力）做 withholding。判据：① 体检单要能证明各评审者先各自定稿再汇总（时间/结论留痕）；② 提问顺序本身是控制项，「某某专家也这么看」放在独立评分之前＝主动注入锚定；③ 禁止过早整体印象，与 §r701C「每维 1–5 级 rubric、权重不参与单维打分」接口；④ 讨论会的目的变成解释分歧而非产出结论；⑤ 写成流程不写成「请认真评审」（预防性、类比洗手）。

- **r735C-3 ★可信直觉有前置条件，且方法论自带反例与边界**：Kahneman 与 Klein 通过对抗性协作达成两条件：环境 sufficiently regular 存在可学规律 + prolonged practice with **valid feedback**（prompt / clear / connected）。棋手与消防员可信；AI 战略判断是 novel / delayed / ambiguous，直觉不可信。判据：① 收到「凭多年经验我觉得」先问两条件，两缺一即降级为待验证假设；② 越新越靠结构化分解与机械聚合，不靠资深者拍板；③ 别把整套方法当无争议公理——Gelman 小样本批评与 priming/ego depletion 未复现须标注，只采纳噪声/前景理论/直觉条件等稳健部分，与 `vi-fact-verification` 三态 NEI 同向（证据不足就写 NEI）；④ 与 TI 既有 §有效性/健全性（论证结构）、§10 CoT 忠实度（自述推理）分工，三条正交。
