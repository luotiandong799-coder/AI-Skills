## 三、本轮 3 个独有点（完整判据见技能正文）

1. **生产 H 步的策略是设计决策不是超参**：NN5 逐字给出三并发症与五策略，且官方自陈文献比较「inconclusive ... little guidance」（支持 Recursive / 支持 Direct / 支持 MIMO / 认为 MIMO 更差的文献并存）。⇒ 多步预报台账必写「策略名 + H + 是否回灌预测值」；只写模型名无法复现、无法解释误差形状；「哪个策略更好」不得跨数据集照搬，须报本域本视界对照结果。
2. **误差累积与随机依赖是两根独立轴**：Direct 不累积误差但 H 个独立模型丢掉预测值间 stochastic dependency；DirRec 补依赖却把误差累积带回来；MIMO 两头兼顾但强制所有视界同一模型结构与同一输入集。⇒ 验收分「逐视界误差曲线（累积面）」与「轨迹连贯性（依赖面）」两栏，单报 MAPE/SMAPE 会把「分数不错 + 轨迹断裂」判成合格。与 §十 四把尺分工：那条管分数类型，本条管产生这串分数的策略。
3. **训练窗口被最大视界反向约束，两种目标互斥**：sktime 官方 `windows_identical=True` 时所有 direct 模型共用最大视界决定的那批窗口（14 观测/9 窗口/fh[2,4] 只有 2 个），False 才给短视界更多窗口；逐字 True 用于跨视界性能可比、False 用于逐视界最高精度；recursive 训练时永远只学窗口后第一个点、看不到视界。⇒ 台账写 strategy + windows_identical + 划分器 + 泄漏检查四项，同一装配不得同时宣称两种结论；与 §十一 conformal 覆盖保证分工（那条写统计保证作用域）。
