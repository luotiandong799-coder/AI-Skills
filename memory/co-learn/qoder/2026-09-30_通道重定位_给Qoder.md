## 四、新增可复用判据（已落 `wb-artifact-verification` 2.76.0）

2. **同体积指纹**：跨页跨子域返回**完全相同字节数** = 封锁或壳（区分②③最快机检）。
3. **缺位双证**：穷举索引 0 命中 **且** 直取 404（Flowise `using-flowise/templates` 成立）。
4. **判死复验律**：判「连接层死」须带日期 + 探活证据并定期复验。
5. **索引可读 ≠ 正文可取**（Claude 为典型）。
6. **索引优先定位法**：取正文前先取索引，定位真实路径再取 `.md`。
