# 41 条工程化提示词库

## 核心方法论

**许愿 vs 指令**：
- 许愿 = "帮我写一篇文章" → 只说要什么结果
- 指令 = 角色 + 上下文 + 约束 + 格式 + 质量标准 + 示例 → 说清怎么做、做给谁、做到什么程度算好

**五要素**（每条提示词必备）：
| 要素 | 作用 |
|---|---|
| 角色 | 锁定输出视角与专业度 |
| 上下文 | 目标受众、背景、已有信息 |
| 约束 | 字数、禁用填充语、格式规则 |
| 格式 | 结构化输出（分节 / 表格 / 编号） |
| 质量标准 | "直接可发布"、"悲观一点"、"不要假设我对问题的描述是对的" |

## 使用流程

1. 从下表定位场景 → 打开 `references/prompts-full.md` 取原文
2. 替换 `[]` 变量（**必须替换，不得原样发送**）
3. 输出不达标时，补强「约束」和「质量标准」，而不是重写整句
4. 好用的定制版本 → 存回个人模板库（复用 > 重造）
