# 毛选方法论蒸馏 · 战略与决策框架

把《毛泽东选集》（1–4 卷，人民出版社）中经反复验证的方法论，提炼成可直接用于决策的流水线与清单。来源均为公开公版文本，关键方法标注出处篇目。

## 何时用
- 面对复杂或不熟悉的局面，需要"先认清再动手"
- 资源有限，要在多个目标间取舍
- 多目标冲突、顾此失彼
- 长期战役 / 看不到头的项目，需要节奏与信心管理
- 方案来自拍脑袋，想先验证再推广

## 主流程（决策前必走）
1. **调查研究（实事求是的前提）**
   - 不做"下车伊始"的论断。先搞清楚：现状、历史、各方真实诉求、约束。
   - 方法：典型调查（"解剖一只麻雀"），用一手材料代替二手经验与书本教条。
   - 出处：《反对本本主义》《兴国调查》《改造我们的学习》。
2. **矛盾分析（抓主要矛盾）**
   - 列出当前所有矛盾 → 找出**主要矛盾**（决定事物性质的那个）→ 在其内部找**主要方面**。
   - 具体问题具体分析：不同质的矛盾用不同方法解决，反对"一刀切"。
   - 两点论（看全面）与重点论（抓关键）统一：既要顾全局，又要攥住枢纽。
   - 出处：《矛盾论》。
3. **小步验证（实践论）**
   - 假设 → 在小范围 / 低风险处试验 → 看反馈 → 修正 → 再推广。
   - 认识要经"实践—认识—再实践"螺旋，反对"一次想透再干"。
   - 出处：《实践论》《关于领导方法的若干问题》。
4. **集中资源（各个歼灭）**
   - 在主要矛盾方向集中优势，一次解决一个；反对"撒胡椒面"式平均用力。
   - 出处：《集中优势兵力，各个歼灭敌人》。
5. **回环校准（群众路线）**
   - 方案从真实一线 / 真实用户中来到真实场景中去检验，循环上升。
   - 反对闭门造车与脱离实际。

## 关键框架卡片

### A · 实事求是
- 是什么：一切从客观实际出发，结论服从事实，而非服从书本、经验或愿望。
- 怎么用：每一步判断都问"这个判断依据是一手事实，还是我的预设？"
- 反例：本本主义（唯书）、经验主义（唯老办法）、主观主义（唯愿望）。

### B · 调查研究
- 是什么：没有调查就没有发言权。
- 怎么用：动手前先采集（看数据、到现场、问当事人）；优先"解剖麻雀"式深挖典型，而非泛泛问卷。
- 红线：未调查不决策、不批评、不下结论。

### C · 矛盾分析法
1. 枚举全部矛盾
2. 排主次（主要矛盾决定性质）
3. 找主要方面（矛盾内部谁主导）
4. 按矛盾特殊性选对策
5. 动态复盘（主次会转化）
- 常见错：眉毛胡子一把抓；用同一药方治不同病。

### D · 实践论小步法
假设 → 试点 → 反馈 → 修正 → 推广。
- 适用：新功能、新策略、未知领域。把"大赌"拆成"小验"。

### E · 集中优势兵力
- 资源永远不够，所以必须集中。在胜负手方向投入压倒性比例，逐个解决。
- 引申：同一时段只攻一个主峰。

### F · 持久战 / 强弱转化
- 战略上藐视困难（相信能成），战术上重视（认真做每一步）。
- 速胜与悲观都错；以时间换空间，积小胜为大胜，看趋势与必然性。
- 出处：《论持久战》《星星之火，可以燎原》。

### G · 弹钢琴（统筹）
- 既要抓中心，又要照顾全局；学会"十个指头都动作"，但心中有主旋律。
- 反例：单打一（只盯一件事忽略系统）。

### H · 群众路线
- 从群众中来（需求 / 信息来自一线）→ 形成方案 → 到群众中去（执行 + 检验）→ 再集中……循环上升。
- 引申：任何方案先问"谁的真实问题？在一线验证过吗？"

## 决策自检清单
- [ ] 我做过调查吗？依据是一手事实还是预设？
- [ ] 我区分了主要矛盾和次要矛盾吗？资源压在主要矛盾上了吗？
- [ ] 这个对策是针对矛盾的特殊性，还是套用的老办法？
- [ ] 有没有先用小范围验证，而不是直接大推？
- [ ] 是"集中攻坚"还是"撒胡椒面"？
- [ ] 长期看，强弱 / 主次会转化吗？我的节奏对吗？
- [ ] 方案在一线真实场景验证过吗？
