# 个人决策智能（Personal Decision Intelligence）

把十部经典的方法论编译成 agent 可调用的工作框架：对真实决策做**多经典交叉研判**，输出结构化、可验证、可复盘的分析，而不是替用户拍板。

## 目标

将历史智慧、现代管理、认知科学蒸馏为个人决策系统。

## 适用场景

- 职业选择、行业/赛道判断
- 学习规划、能力提升路径
- 商业判断、投资/创业决策
- 人际关系、合作/竞争权衡
- 风险决策、不确定性下的取舍
- 长期战略规划、退出/坚持判断

## 核心原则

- 不复制案例，只提取决策规律。
- 不迷信经验，结合现实验证。
- 先分析，再行动。
- 复盘优化，持续迭代。

## 五层框架

执行时按下方「决策路由」抽取透镜，**一般只调 2–3 层**，不堆砌。每部经典的用途 / 核心模型 / 决策问题见 `references/decision-frameworks.md`。

| 层 | 经典 | 解决什么 |
|---|---|---|
| 一·战略判断 | 资治通鉴 / 孙子兵法 / 毛选 | 方向、时机、坚持或转向、战场与优势选择 |
| 二·人性与识人 | 史记 / 三国志 | 人是否可靠、团队组合、关系博弈 |
| 三·认知纠错 | 穷查理宝典 / 思考快与慢 | 隐藏成本、偏见、概率与确定性误判 |
| 四·风险管理 | 反脆弱 | 最坏情况、失败成本、从变化中获益 |
| 五·成长执行 | 刻意练习 / 原则 | 能力提升系统、个人运行规则与复盘 |

## 决策路由（先选层，再调用）

按问题的主类型选「必调」；只有出现「加调」条件时才扩大，**默认不超过 3 层**。

| 问题主类型 | 必调 | 加调（有条件才加） |
|---|---|---|
| 要不要继续 / 是否转向 | 资治通鉴 | 涉及竞争对手 → 孙子 |
| 值不值得投入 / 怎么打 | 孙子 | 需看长期影响 → 资治通鉴 |
| 局面复杂、看不清真实情况 | 毛选 | 风险高 → 反脆弱 |
| 看人是否可靠 / 选伙伴 | 史记 | 涉及组队 → 三国志 |
| 组团队 / 分角色 / 处理内耗 | 三国志 | 需判人 → 史记 |
| 怕自己想错、方案有隐性代价 | 穷查理宝典 | 怀疑被情绪带动 → 思考快与慢 |
| 怕被情绪、直觉或过度自信带偏 | 思考快与慢 | 需找更优方案 → 穷查理宝典 |
| 不确定性大、怕一次输光 | 反脆弱 | 需算代价 → 孙子 |
| 能力提升 / 成长路径 | 刻意练习 | 需固化成规则 → 原则 |
| 老犯同样的错 / 想建个人规则 | 原则 | 需配套训练 → 刻意练习 |

## 经典结论冲突时的裁决

两部经典给出相反建议时，按此顺序判，并把判断过程写进输出：

1. **现实优先**：谁的判断更容易被现实验证，优先采信谁。
2. **时间尺度**：长期规划听资治通鉴 / 原则；当下取舍听孙子 / 毛选。
3. **可逆性**：不可逆决策加大反脆弱与认知纠错层的权重。
4. 仍然冲突 → **不要强行收敛**，写出「两种结论 + 各自成立的条件」，交用户按价值取向选。

## AI 执行流程（收到问题后）

**Step 1 · 问题定义**：明确目标、确认约束、区分事实与假设。

**Step 2 · 关键变量分析**：调用毛选（主要矛盾）、孙子（竞争环境）、资治通鉴（长期影响），定位当前阶段最重要变量。

**Step 3 · 人性分析**：调用史记、三国志判断利益关系、动机与人际风险。

**Step 4 · 认知检查**：调用穷查理宝典、思考快与慢检查偏见、高估收益、忽略关键因素。

**Step 5 · 风险评估**：调用反脆弱分析最坏情况、可承受损失、备用方案。

**Step 6 · 行动方案**：整合上述，按下方格式输出。

**Step 7 · 能力与系统**：调用刻意练习定位这次要补的能力与训练重点；调用原则把本次教训沉淀成可复用的决策规则，避免重犯。

## 输出格式

```
【事实】当前已确认的客观信息
【假设】尚未证实、但影响判断的前提
【核心矛盾】当前最关键的取舍/冲突（来自毛选主要矛盾视角）
【历史案例】可类比的规律（只取规律，不套故事）
【关键风险】最坏情形与主要失败模式
【推荐行动】分优先级的下一步，含小步试错入口
【验证方法】如何以最低成本验证假设是否成立
【复盘节点】何时回看、以什么信号调整
```

## 输出原则

1. 不直接替用户做决定。
2. 提供分析框架和选择依据。
3. 明确未知因素，不假装确定。
4. 优先现实验证，给出可操作的小成本验证手段。
5. 避免情绪化与宣传腔判断。

## 边界与协作

- **纯毛选方法论任务**（矛盾分析、调查研究、持久战、集中优势兵力）→ 优先调用 `mao-strategy`：该技能是毛选的深蒸馏单一来源；本技能只把毛选当五层之一用，不重复实现。
- **通用质疑/挑刺**类需求 → `grill-me`（本技能偏建设性研判，不偏对抗）。
- **决策中的写作/表达**需求 → 相关写作技能。
- 本技能是推理框架，不含脚本；如需把分析落成清单/表格，再调用对应工具。
