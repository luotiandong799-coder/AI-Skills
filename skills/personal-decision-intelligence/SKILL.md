# 个人决策智能（Personal Decision Intelligence）

将历史智慧、现代管理、认知科学蒸馏为可复用的个人决策系统。不复制案例，只提取决策规律；不迷信经验，结合现实验证；先分析再行动，复盘优化持续迭代。

## 目标

把十部经典的方法论编译成 agent 可调用的工作框架，对用户的真实决策问题做**多经典交叉研判**，输出结构化、可验证、可复盘的分析，而不是直接替用户拍板。

## 适用场景

- 职业选择、行业/赛道判断
- 学习规划、能力提升路径
- 商业判断、投资/创业决策
- 人际关系、合作/竞争权衡
- 风险决策、不确定性下的取舍
- 长期战略规划、退出/坚持判断

## 核心原则

- 不复制案例，只提取决策规律。
- 不迷信经验，结合现实验证。
- 先分析，再行动。
- 复盘优化，持续迭代。

## 五层框架

执行时从对应层抽取透镜，按需组合，不堆砌。每部经典的**深层模型与决策问题**见 `references/decision-frameworks.md`，需要时读取。

| 层 | 经典 | 解决什么 |
|---|---|---|
| 一·战略判断 | 资治通鉴 / 孙子兵法 / 毛选 | 方向、时机、坚持或转向、战场与优势选择 |
| 二·人性与识人 | 史记 / 三国志 | 人是否可靠、团队组合、关系博弈 |
| 三·认知纠错 | 穷查理宝典 / 思考快与慢 | 隐藏成本、偏见、概率与确定性误判 |
| 四·风险管理 | 反脆弱 | 最坏情况、失败成本、从变化中获益 |
| 五·成长执行 | 刻意练习 / 原则 | 能力提升系统、个人运行规则与复盘 |

## AI 执行流程（收到问题后）

**Step 1 · 问题定义**：明确目标、确认约束、区分事实与假设。

**Step 2 · 关键变量分析**：调用毛选（主要矛盾）、孙子（竞争环境）、资治通鉴（长期影响）定位当前阶段最重要变量。

**Step 3 · 人性分析**：调用史记、三国志判断利益关系、动机与人际风险。

**Step 4 · 认知检查**：调用穷查理宝典、思考快与慢检查偏见、高估收益、忽略关键因素。

**Step 5 · 风险评估**：调用反脆弱分析最坏情况、可承受损失、备用方案。

**Step 6 · 行动方案**：整合上述，按下方格式输出。

## 输出格式

```
【事实】当前已确认的客观信息
【假设】尚未证实、但影响判断的前提
【核心矛盾】当前最关键的取舍/冲突（来自毛选主要矛盾视角）
【历史案例】可类比的规律（只取规律，不套故事）
【关键风险】最坏情形与主要失败模式
【推荐行动】分优先级的下一步，含小步试错入口
【验证方法】如何以最低成本验证假设是否成立
【复盘节点】何时回看、以什么信号调整
```

## 输出原则

1. 不直接替用户做决定。
2. 提供分析框架和选择依据。
3. 明确未知因素，不假装确定。
4. 优先现实验证，给出可操作的小成本验证手段。
5. 避免情绪化与宣传腔判断。

## 边界与协作

- **纯毛选方法论任务**（矛盾分析、调查研究、持久战、集中优势兵力）→ 优先调用 `mao-strategy`，其对该来源有更深蒸馏；本技能在综合决策中把毛选作为五层之一使用。
- **通用质疑/挑刺**类需求 → `grill-me`（本技能偏建设性研判，不偏对抗）。
- **决策中的写作/表达**需求 → 相关写作技能。
- 本技能是推理框架，不含脚本；如后续需把分析落为清单/表格，再调用对应工具。
