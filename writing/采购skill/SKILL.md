## 一、采购基本流程（主 SOP）

**主线 11 步**：采购需求 → 采购计划 → 寻找供应商 → 询价·比价·议价 → 采购洽谈 → 签订合同（付款条件/配送方式/售后）→ 交货验收（仓管）→ 质检（不合格退货）→ 入库 → 计划对账 → 财务结算。

**九步骤作业表**（步骤 / 作业要点 / 表单）：

| # | 步骤 | 关键动作 | 参考表单 |
|---|------|---------|---------|
| 1 | 采购需求 | 核对请购单是否经核决主管核准；确认规格与需求日期；查库存，不足才外购 | 请购申请单 |
| 2 | 材料确认 | 确认料件已报价、供应商已建档、交货办法与交易同意书签回 | 采购单 |
| 3 | 供应商挑选 | 货比三家：同行 ≥3 家对比单价/品质/服务/交期/6S | 供应商资料表 |
| 4 | 确认订单 | 核对供应商、单价、交期、规格 | 采购订单 |
| 5 | 订单下达 | 采购单发供应商签回；核对最新单价与付款条件符合公司规定 | 供应商回签订单 |
| 6 | 交期确认 | 要求供应商 1 个工作日内回签正式交货期 | 回签订单 |
| 7 | 产品验收 | 仓库收货 2 小时内收料并通知品保；OK 贴合格标签，NG 即时通知采购退供 | 验收单/退货单 |
| 8 | 验收入库 | 品保合格后 1 小时内入库，通知生产领料 | 入库单/领料单 |
| 9 | 对账付款 | 送货单+入库单+采购单三单一致，财务确认后按账期付款 | 对账单/付款申请单 |

**申请付款流**：采购按供应商账期对账 → 采购部长审批 → 财务审批。
**紧急采购**：走绿色通道（财务负责人+总经理签字后直接购买）；无正当理由不得申请紧急采购——日常计划做好，是采购的基本功。
**异常通报义务**：签约后不能及时供货的，原因提前 2 日通知请购部门；所有货物开箱验收，验收合格 1 个工作日内办入库；每月 5 日前整理上月采购合同编号备案。

**询价单 12 要素（询价单=合同前置版本，少一项就要扯皮；来源④鲸采云 2026-10-16）**：
- 买什么：① 品名+规格型号+图纸**版本号**（缺一项供应商按自己最便宜的理解报）；② 数量+统一计量单位+阶梯量（如分别报 500/2000/5000 件价+年预估量）；③ 质量标准+验收方式（写明按 GB/T 2828.1 水平 II、AQL 值、随货材质证明，检测费含在单价内）。
- 怎么交：④ 交期写「PO 下达后 X 个**自然日**」，加急单独报价；⑤ 交货地点+运费/卸货/在途风险归属，跨境写贸易术语（EXW/FOB/DDP）；⑥ 包装标识（每箱数量、物料编码+批次号标签、防静电/免熏蒸托盘，费用含否）。
- 怎么算钱：⑦ 币种+含税口径+发票类型三件同时写（"含 13% 增值税专票，另列不含税价"；小规模纳税人只能开 3 个点专票，价格没有可比性）；⑧ 付款条件前置声明（月结 60 电汇 vs 预付 30% 是不同资金成本；承兑汇票供应商通常上浮约 2 个点）；⑨ 报价有效期 ≥30 天，原料联动部分注明**基准价+调价公式**。
- 怎么比、怎么兜底：⑩ 质保起算点（到货 vs 验收）+响应时限+退换运费+停线责任；⑪ 统一《报价明细表》分列材料/加工/模具（一次性 NRE）/包装/运费，**未列项目视为已包含**；模具须写明**所有权归属**，否则日后无法转第二供应商；⑫ 报价截止时间+统一书面澄清渠道，给 A 家的答复**同步全部受邀供应商**（公平合规）。
- 发出前自检一句话：「两家供应商只看这张单、不打电话，报回来的价能不能直接比？」能=合格。
- 新人询价避坑（来源④抖音 2026-10-15）：开场**不说"我们量很大"**（易被抬价），只客观报预估用量；一次性列全要的资料（单价/MOQ/交期/付款/质保/含税含运+营业执照/检测报告/样品时效）；打样先问清样板费与快递费谁担、**大货下单后样板费可否抵扣**、色差尺寸公差须附检测数据；元器件类问清 MOQ 按颗还是按整卷/整盘（MPQ/SPQ），拆卷可能加收分切费。

## 二、供应商开发与考核

**新供应商开发链**：开发申请 → 初审 → 审批 → 推荐（采购/其它部门推荐或平台注册）→ 书面评比 → 注册 →（看厂）现场审核 → 评鉴确认 → 签资料（供货合同/反商业贿赂协议/禁限用物质保证协议）→ 预备供应商 → 询比议价 → 样品送检 → 合格 → 下订单三批 → 预备转合格 → 录入合格供应商名录。

**评鉴口径**：实地评鉴质量/环境体系与 ROHS 对应（100 分制）+ 质量管理（60 分制）；综合达标率 ≥80% 合格，70–79% 条件合格，<70% 不合格；质量/环境/ROHS 项必须 ≥80% 才可合格。ERP 下单三批后预备转合格。

**定期考核维度**：质量、交货准时率、价格竞争力、逾期率、配合度，经营情况与供应能力年度复审。同价位优先可开增值税专用发票的供应商。

**3C 配件品类供应商地图**（图拉斯场景）：
- 壳膜类：深圳/东莞注塑+贴膜厂密集，关注 TPU/PC 原料行情、抗黄变、磁吸（MagSafe/Qi2 模组）、点胶贴合良率、模具费与开模周期。
- 充电类（小冰块系列）：GaN 功率器件、电芯（锂聚合物，关注 UN38.3/CCC 认证）、协议芯片（PD/QC）、认证清单（3C、CE、FCC、MFi）。
- 数据线：线材规格（AWG）、端子、编织/液态硅胶工艺、拉力与摇摆测试标准。
- 车载香薰/挂脖风扇等生活电器：电机、香薰精油合规、外观专利侵权排查（图拉斯 1500+ 专利，自有设计多，供应商 NPI 保密协议必签）。
- 打样节奏：新品的模具/手板打样轮次是交期最大风险点，跟催要盯打样确认书而不是口头承诺。

**供应商开发渠道与真假工厂鉴别（来源⑤：1688 官方买家百科 + gpsourcing 2026-07-16）**：
- 渠道优先级：**产业带直开**（3C 电子=深圳/东莞，小家电=顺德/中山；公司所在地与品类产业带错位的多为中间商）→ 1688「找工厂」频道（看工厂档案：信息完整度≥80%、产线实拍视频、设备清单、代工履历；「超级工厂」标=TÜV/SGS 第三方实地验厂，「实力商家」=执照核验+平台保证金）→ 展会与同行推荐。
- **真假工厂三硬指标**：① 营业执照经营范围含「生产/制造」（纯「贸易/批发」=贸易商）；② 品类聚焦 1–2 类共原料的相关产品（几十类不相关 SKU=倒货）；③ 拿得出车间实景视频/近期生产日报，接受实地或视频验厂——「只接单不接待」的要警惕。
- **样品单测试**（花小钱买一次验厂）：24h 内寄出、随包附材质说明/质检报告、改色加 LOGO 小定制爽快接；「必须全款预付、样品不寄」直接拉黑。
- 实地验厂三看：设备是否真在运转、原材料库存够不够、质检流程是否走过场。
- 贸易商不是不能用：多 SKU 拼单、小批量灵活交付可用；但开模/深度定制/成本拆解必须对真工厂。

## 三、谈判话术锦囊（核心资产）

### 3.1 新手 vs 高手对照表（问价场景，一句话暴露段位）

| 场景 | ❌ 新手开口（被供应商秒判外行） | ✅ 高段位说法 | 潜台词 |
|------|------|------|------|
| 问价 | "你们最低多少钱？" | "按这个量，阶梯价能到多少？" | 我是按量级谈的，不是来砍零头的 |
| 压价 | "能再便宜点吗？" | "隔壁XX家报的比你们低10%，但我想优先跟你们合作，能匹配吗？" | 有备选+给面子，双赢台阶 |
| 压价（内部挡） | "太贵了，便宜点" | "这个报价，我拿回去可能连第一轮都过不了。" | 把矛盾转成"外部规则不允许"，对方会主动问"什么价能过"——主动权回来了 |
| 催货 | "最快多久能到货？" | "常规交期几天？如果加急，费用怎么算？" | 懂行，急单加钱我也知道，别糊弄我 |
| 质量 | "质量有保证吧？" | "次品率多少？售后怎么处理？合同里能写质保条款吗？" | 灵魂三问，直接要书面承诺 |
| 拖延 | "我再考虑考虑…" | "今天能定的话我直接走流程，否则要排到下个月了。" | 给确定激励+时间压力 |
| 被催款 | "我也在催，财务还没回复" | "流程正在走，我比你还急。一旦有卡点，我第一个给你消息。" | 我在盯、我主导节奏，你别反复来问 |
| 面对涨价 | "涨价太多，接受不了" | "理解你们的压力，但这个涨幅需要一起想办法消化——看看能不能从账期、物流或包装上找补回来？" | 把对抗变合作，不单方面让步 |
| 破冰 | "报价单发我，尽快。" | "王总，这次项目质量要求高，第一时间就想到您家，方便优先报个价吗？我们长期需求大~" | 先给情绪价值，秒回+折扣 |
| 纠纷 | "你们包装都破了！" | "陈总，这次包装破损估计是物流的问题，您看退换还是折价处理更方便？" | 给对方留台阶，二选一收敛结果 |

### 3.2 八句万能话术（按谈判时序背熟）

1. **开场定调**："我们这次是想找长期稳定合作的供应商，不是只做一锤子买卖。"（打开格局）
2. **探底比价**："目前我们手上有 3 家合格供应商在评估，最终综合性价比来定。"（不明说压价，对方自动给优惠）
3. **要求降价**："这个价格我们内部审批压力比较大，您看最实在的底价能给到多少？合适我们今天就能确定。"（给希望+逼真实底价）
4. **锁定交期**："交期必须卡死在 X 号前，生产等着上线，耽误会有停线损失。"（压力前置）
5. **质量保障**："质量我们按标准严格验收，出现异常需要无条件配合整改、退换。"（规则先说清，避免扯皮）
6. **应对涨价**："原材料波动我们理解，但短期大幅涨价很难接受，能不能按老价格再保一批？"（留余地+守底线）
7. **强势但礼貌**："我理解你的困难，但也要对公司负责，希望我们互相配合。"（不卑不亢）
8. **收尾成交**："那就按谈好的条件执行，我尽快走流程下单，希望后续合作顺利。"（干净锁定结果）

### 3.3 谈判心法

- 谈判不是吵架不是压人，是**用最少的话拿最好的结果**；目标不是"赢"，是达成双方都能执行的协议——把供应商逼到零利润，下次他偷工减料或不接单。
- 指责 → 事实："你们太贵了"（激起防御）改为"报价超出了预算范围"（客观）；对立 → 合作："帮我们梳理一下价格主要高在哪，有没有我们可以配合调整的地方"。
- 信息差是核心：供应商知道底价，你靠比价+行情猜。**永远带着 3 家以上报价上桌**，手里有备选名单、对市场价门儿清、合同条款抠得细、付款周期卡得死——供应商最怕的四种采购。
- 多用"咱们""一起"；重要事项电话说，文字冷冰冰；3 分业务 7 分关系，逢年过节一句祝福。
- 砍价杀手锏：用"未来合作"换当下优惠——"这次能到 XX 元，我马上下单，后续季度优先考虑您家。"
- **比价选最低总成本不是最低单价**（来源④抖音《从零学习做采购》2026-09-04）：低价家的延误/质量/含糊风险不写在报价单上，停线损失远大于省下的单价。做法：要求候选家把模具、包装、运输、首件、交付批次**全部写进报价说明**，交期/质量责任/付款节点写进合同初稿；对低价含糊家发一句测试——"**如果你能把所有费用一次报全，我们再继续谈**"，回复开始含糊的暂缓使用；拿低价家报价去跟交付更稳的高价家**谈条件不压单价**（"保证三周交齐我可以接受这个价""签质量扣款条款我价格上不再压你"）。

### 3.4 涨价应对三线法（先算传导，再上桌；来源④抖音《采购实战博弈》E2 2026-09-09）

1. **算合理传导**：合理涨幅 ≈ 原料占报价比重 × 原料市场涨幅。例：原料占 50%、ABS 市场涨 7% → 合理传导 3.5%，供应商报 6% 就多要 2.5% 的说法。
2. **写三条线再谈**：底线=可接受最高价（如 4%，超线向上汇报）；目标=数据算出的合理价（3.5%）；筹码=锁价期、交期责任、降价联动、付款周期不变。脑子里只有一个数的人，供应商一坚持就软。
3. **拆项质询话术**："原料占你报价 50%，市场涨 7%，对单价影响 3.5%，你报 6% 多出的 2.5% 是什么？"对方说包装人工电费也涨 → "可以，逐项列出来：每项涨多少、占比多少、加总应涨多少。加起来确实 6% 我认，不是就重新算。"——**谈判不是比谁凶，是比谁先扛不住数据**。
4. **收尾给台阶换条款**：接受合理涨幅的同时，把**锁价期+交期责任写进协议**，并以后续订单/新项目做激励（"4% 锁住，后面 600 套和新项目优先考虑你"）。

### 3.5 供应商利益诊断：不肯降价先找原因（来源④抖音《采购谈判实战课》E2 2026-09-13）

- 供应商一单生意只关心四件事：**利润够不够（不能亏）、订单稳不稳定（怕产能空转）、付款准不准时（怕的不是慢是不准：说好 30 天拖到 60 天最伤）、风险大不大**（技术要求高/变更频繁/验收苛刻）。
- **真假"做不了"判别**：说做不了但愿意继续谈细节的，可能是真做不了；说做不了连细节都不谈、几句话打发你的，基本是不想做。再对照其历史报价与接单意愿交叉验证。
- 对症换确定性而不是硬压价：量小要求高的单，给"**后面六个月用量预测，量上来价格重算**"；付款有顾虑的，给"付款准时"承诺换让价。案例：不压价、不吓唬，只用稳定量+准时款两个理由换来 3% 降价。

### 3.6 账期折现：把付款条件翻译成钱（来源④抖音 2026-09-21/2026-08-20，Dryden Group 2026-10-31 交叉核验）

- **账期价值 = 采购额 × 年化资金成本率 × 天数 ÷ 365**。资金成本率取公司真实口径（有贷款按贷款利率，不缺钱按理财收益）。参考刻度（100 万货、8%）：30 天≈0.66%、60 天≈1.3%、90 天≈2%；金额按比例缩放。供应商说"降价做不到，给你月结 60 天"→ 值 1.3%，优于降 1% 就换；只给 30 天（0.66%）则继续要条件。
- **供应商要缩短账期**（90→30 天）：先算隐性成本（1000 万×6%×60/365≈9.86 万），再回三张表——账期变化表/资金成本表/交换条件表。可换五件套：①提前付款现金折扣 1–2%；②锁价 3–6 个月；③关键料优先排产+延期补偿；④寄售或分批交付；⑤按实际采购额年度返点。邮件话术："账期调整可以评估，但需同步确认对应补偿条件，建议在现金折扣、价格锁定、交付保障中组合。"
- **现金折扣要不要拿**：放弃折扣的年化成本 = 折扣率 ÷ (1−折扣率) × 365 ÷ (信用期−折扣期)。2/10 net 30 ≈ 37%，远高于一般 7–12% 资金成本 → 有钱就借钱也要拿；2/10 net 90 ≈ 9% 则未必。前提：财务能稳定在折扣期内付款。
- 考核口径 DPO（应付账款/销货成本×天数）：**在合同账期内最大化，不是靠逾期拖欠**——拖款伤的是"付款准"这条供应商命门（见 §3.5）。

## 四、合同·验收·质检要点

- **签订前与财务核实**：付款条件、货运方式、售后服务三件套写进合同再签。
- **合同必抠条款**：单价与阶梯价、交期与违约（停线损失分担）、质保与次品率上限、退换与无条件整改、知识产权与保密（3C 新品 NPI 场景）、反商业贿赂协议、禁限用物质（ROHS/REACH）保证。
- **交货验收**：按合同+采购确认的品种/数量/质量/交期验收；所有货物开箱验收；特采（让步接收不良品）必须总经理批准。
- **分类验收**：一般物料→仓库；专业性物资/劳保/工作服→申购人；与生产直接相关的原料辅料→品管。
- **不合格品处置链**：标识隔离→信息反馈→原因分析（因果图/对策表）→评审（返工/让步/报废）→纠正预防→验证→QC监督。
- **IQC 抽检怎么定（来源④：GB/T 2828.1-2012 现行 + 电子料进料检验规范 + 维度互联 2026-10-22）**：
  - 先按后果给物料分级：A 级高风险（安规/可靠性/核心性能：电芯、功率器件、保险丝）→ 关键参数复测+外观全检；B 级中风险（常规芯片/被动件）→ AQL 抽检+外观；C 级低风险（包材/辅料/标准五金）→ 外观数量核对。检验资源花在刀刃上，不迷信全检。
  - 抽样按 **GB/T 2828.1 一般检验水平 II** 查表定样本量与 Ac/Re，**禁止凭感觉定抽多少**（例：5000 件批、AQL 0.65、水平 II ≈ 抽 80–125 件）。AQL 参考：一般物料 0.65；关键料 0.1 或加严；低值辅料 1.0–2.5。电子料行业规范口径：致命缺陷 Cr=0（零收一退）、重要缺陷 Ma 0.4、轻微缺陷 Mi 1.0。
  - **任何一件致命（安全相关）缺陷直接判整批不合格，不看 AQL**。
  - 收货核对清单：订单号/型号/品牌/数量/批次号（Date Code）/供应商；外包装真空完好、湿度指示卡未变色、MSL 等级标识、静电防护。
  - **记录体系是分水岭**：每批留供应商+批次号+抽样数+测试数据+判定人，产线批量不良时 10 分钟内回溯到批次与供应商，把召回范围缩到最小。IQC 的本质是留可追溯证据链，不只是判合格。
- **供应商 8D 整改要求（写进质量协议；来源⑥ASQ + voestalpine 中文质量协议 + CSP 2026-09-03）**：
  - 流程 D0–D8：D1 组队（指定一人对根因与纠正措施负责）→ D2 用 5W2H 量化描述问题 → D3 临时围堵 → D4 根因验证 → D5 选定并预验证永久措施 → D6 实施并证明有效 → D7 防再发（横向排查同设计/同工艺/同物料的其他产品）→ D8 结案。
  - **时限写死**：收到抱怨 24h 内 100% 全检围堵+提交 4D，7 个工作日内完成 8D（voestalpine 中文协议口径）；行业通用宽口径=D1–D3 24–48h、D4–D6 10 个工作日、约 60 天结案（CSP）。紧急问题 30 分钟内到场，未到场期间我方分选费用由供应商承担；供应商对索赔有异议须 3 个工作日内书面申述附证据。
  - **D4 拒绝拍脑袋**：根因必须用过程数据+5Why+鱼骨图验证（能复现/消除问题），且至少覆盖三类——为什么产生、为什么流出到客户、为什么体系没拦住。D6 有效性必须给改善前后同口径数据对比，没有前后对比就只是主张。
  - 被拒收批次：**后续至少 3 批加严检验**（Graco SCAR 口径）；整改期间到货批批附检验数据。
- **模具全生命周期管理（3C 开模场景必抠；来源⑥SourceSquid/维亚达/BQUQ/Importivity/Kelly Zhang 律所）**：
  - **所有权看合同不看付款**：付了钱≠模具是你的。须签模具协议（厂方盖章）：逐副列明编号/规格/照片/存放地，写明付清模具款之日起所有权归买方、厂方**代为保管**（民法典第 228 条占有改定），**排除留置权**、禁止用于其他客户生产；模具打买方产权铭牌+编号。摊销进单价或未写书面条款的，厂方可主张模具归其所有。
  - **摊销三问写进合同**：① 摊销量多少、未达量余额是否须补足；② **摊销量达标后单价是否下调**（多数纠纷源于合同没写摊完后的价格）；③ 中途买断价=直线法未摊销余额（签约时锁定公式，别等要走时才谈）。
  - **寿命与维保分担**：保证模次写进协议（SPI 分级：101 类≥100 万模次、103 类<50 万、104 类<10 万、105 类手板<500；正常量产模 30–100 万模次视钢材）。日常保养=供应商（使用方）；超保证寿命的正常磨损修复与换模=产权方；使用不当/保养不当损坏=供应商。
  - **移模与报废核验**：移模前做**末件封样+检测报告**双方签认作为状态基准（没有封样，移模后打不出合格品责任说不清）；供应商称模具报废的，要模次计数器读数+最后一次合格品检测报告，必要时第三方鉴定；建模具台账（编号/位置/付款状态/模次记录/维保记录），新模/改模随时登记。

## 五、内部沟通（采购的另一半战场）

- 需求部门口述"尽快买一批XX"= 扯皮之源。接单必确认五要素：**品名规格、数量、质量标准、需求日期、预算**，写回请购单让对方签字确认，到货验收标准即以此为准。
- 业务觉得采购是服务部门、采购觉得业务需求不合理 → 不争对错，只对目标："咱们目标一致，用合适的成本按时买到合适的东西。现在规格定不下来，后面验收标准也对不上，先把这两项锁了。"
- 汇报/传递信息做**过滤器不做传声筒**：向领导汇报带方案（A/B 选项+推荐+理由），向供应商传内部意见先消化再表达。
- 催办与挡压：对外（供应商）设定"有卡点我主动找你"规则；对内（需求部门）交期异常提前 2 日书面通报并附补救方案。

### 5.1 向上汇报（学习批VII，来源⑨抖音「书录轩」2026-05-31；采购月度会/降本汇报/转正述职通用）

**本质**：汇报不是告知，是**说服**——替老板把"接下来怎么办"想好，让他只剩点头一个动作；判断越准越有底气，信任越厚。采购岗尤其吃亏：把时间全花在砍价跟催，没花时间让老板看见，于是"做了很多"却"看起来什么都没做"。

- **三层级自查**：①事实层＝做了什么、结果如何（老板看周报也知道，不创造价值）；②分析层＝为什么成/没成、关键变量（证明有脑子）；③**决策层＝判断+建议+不做的后果**（老板只需说"行"）。多数人卡在第二层不敢判断——判断错能调整，不敢判断更致命。
- **三明治结构**：一句话结论（30 秒说清要老板带走什么，不铺垫）→ 证据（数据/事实，不用形容词：不说"供应商很配合"，说"交期准确率 78%→94%、缺料停线 0 次"）→ 回到结论并给判断（"基于以上，我建议这个料号转二供，年降 6%，不转则单点断供风险仍在，你看行不行"）。
- **黑名单四条**：只说问题不给方案（至少给"我建议"，不成熟可被改）；模糊词（大概/可能/差不多/我觉得＝信任粉碎机，进会议室前必须确定）；藏坏消息（第一时间说+原因+补救+需要协调的资源，你交付的是方案）；让老板猜（把成果翻译成他关心的**成本降幅/交付保障/风险敞口/占用资金**）。
- **节奏**：按节点（关键谈判定案前、预算将尽、供应商要断供、老板问的问题查清后），日常一周一次最稳；每天汇报反显没有独立判断。
- **汇报型 PPT 落地**：每页标题写结论句；页序＝结论→证据→判断→要决策/要资源；一页只答一个问题；形容词全换数据并标口径与时间；最后一页固定写"需要的决策/资源"（涨点批不批、二供要不要开、安全库存抬到多少）。

**一页速记（2026-11-22 用户归纳版，可直接做成汇报 PPT 首页或自查清单）**：
1. 定位：**向上管理核心就是汇报，与执行同等重要**——老板有资源，你有信息和判断，用信息换资源、用判断换信任，**老板的时间比你的值钱，用你的时间帮他省时间**。
2. 本质：**不是告知是说服**，卖判断、卖价值、卖成果；**判断就是给建议**，带着答案汇报问题。
3. 层级：事实→分析→判断，**抓重点先说结论**，数据说话（数据不会撒谎也不会跟你争），**最后重复结论**。
4. 表达：精准表达增信任，**拒绝大概/可能/差不多/我觉得**；用**领导关心的框架**（成本/交付/风险/资金/目标）翻译你的成果。
5. 坏消息：**早汇报**，越早越好，同时给原因+补救+需要的资源。
6. 节奏：**按节点汇报**（关键定案、预算将尽、断供风险、问题查清后），日常一周一次。
7. 心态：**合作共赢、不卑不亢、自信担当**——你是去帮他做决定的，不是去接受审判的。

### 5.2 结构化表达四公式（学习批VIII，来源⑩抖音「破局管思」2026-06-30）

> 用途：说话不是天赋是模板。**按场景选公式**，别一套话术打天下；与 5.1 三明治互补——三明治=正常提案，SCQA=出问题时的汇报。

- **SCQA（出错/延期/异常时汇报，专治说不清）**：S 情景（原计划这周上线）→ C 冲突（测试发现 3 个严重 bug）→ Q 问题（要不要延期）→ A 答案（建议延期 3 天先修 bug 再上线）。采购用法："原计划这周到 5000 件（S）→ 供应商模具备料晚两天且首件阻抗超标（C）→ 现在要保产线还是保节点（Q）→ 我建议先按 3000 件调拨应急仓、剩余顺延 3 天，成本增 2 千但可保不停线（A）"。四句话，领导立刻知道你的处境和建议。
- **FAB（说服老板/需求部门批方案）**：F 特征（方案具体是什么）→ A 优势（比现在强在哪，量化）→ B 利益（**给对方带来什么好处**）。换供/上自动化/接受涨价的正确说法：不说"这家更靠谱"，说"这家有双产线+同品类 3 年供货（F），交期准确率比现供高 16 个百分点（A），按去年缺料复盘测算可少停线 2 次、少损失约 X 万（B）"。**关键：B 讲对方的利益不是你的辛苦**。
- **BACC 反馈（对需求部门/供应商业务员提问题不伤人）**：B 描述事实（这个月你已经 3 次临时改单）→ A 表达感受/影响（每次改单都要重排产，我们两边都被打乱）→ C 提出方案（以后改单提前 24h、急单走紧急通道并承担加急费）→ C 说明后果（再这样产线会按最低优先级排你的单）。**先事实后感受再方案最后后果**，采购对内对外都用得上；只讲情绪＝吵架，只讲后果＝威胁。
- **PREP（会议发言/多人场合表态，专治没重点）**：P 观点（我认为这个料号要开二供）→ R 理由（单一来源谈判没有筹码、断供风险实存）→ E 例子（去年该品类一次停线 2 天，损失 X 万）→ P 重申观点（所以我建议本月启动二供认证）。**30 秒讲完，比绕三分钟有效**。
- **3W 破冰（供应商拜访/展会/饭局）**：先问"你们主要做哪类产品"（What）→"从哪个城市/园区过来"（Where）→"这次展会主要看什么"（Why）；两个问题就能打开话头，别一上来谈价格。

### 6.1 试用期工作痕迹系统（学习批VI，来源⑦知行致远 2026-10-02；采购岗尤其吃这套）

**底层逻辑**：记录不是为了回忆，是为了**证明、复用、防甩锅**。采购岗每天都在跨部门与跨公司扯皮（交期延误、来料争议、谁批的谁定的），痕迹就是你的证据链。

- **每日三行**（下班前 3 分钟，不写流水账）：① 今天解决了什么问题（证明落地能力）② 今天确认了什么事项（证明推进闭环）③ 今天学会了什么（证明持续成长）。不到 100 字，但每一行都是能力证据。
- **四类记录，每类对应采购痛点**：① **接了什么**——只记原话、截止时间、对接要求、我理解的目标、执行思路；价值=提前纠正认知偏差，别干两周才发现方向错。② **卡在哪**——精准到卡在哪一步/哪条流程/哪个对接人未回复/哪个权限未开通；越精准别人帮你的效率越高，别为面子瞒卡点。③ **确认了什么**——跨部门口头共识、供应商承诺的交期与价格，全部文字留存；结束补一句"我总结一下：我方 A，您方 B，X 点前交付，是否无误"=**责任锁扣**，杜绝后期甩锅。④ **改变了什么**——优化的流程、整理的模板（询价单/比价表/合同要点清单）、规避的风险；这是转正答辩和加薪拉开差距的增量项。
- **周报四问**（替代罗列流水）：这件事目标是什么？我完成到什么程度？现在卡点在哪？需要什么资源推进。带这四问的周报，领导不用追着催进度。
- **共享文档四页**：我在学什么 / 我问过什么 / 我搞砸过什么 / 我做成了什么。入职第一天建好，持续更新=可被看见的成长曲线。
- **被甩锅时**：不吵不解释，直接按日期检索记录，把原始截图、发送时间、文件、处理脚本一次发群，一句话"X 月 X 日 X 点已交付，资料完整请查收"——事实清晰语气平静，比任何辩解有效。
- **转正答辩**：把每日痕迹按时间线汇总成"证据版答辩"（问题→动作→结果→沉淀的模板/流程），直接共享屏幕讲真实痕迹，不套通用 PPT；采购岗可加"价格/交期/质量三条改善数据 + 沉淀的表单"。

## 七、交期跟催与库存计划（学习批II）

**跟催四锚点**（供应商说"在安排了"时，用四问逼出真实进度；来源⑤抖音 2026-07-17）：
1. 问数量："这批 5000 件已完成多少？今天还能完成多少？剩余预计何时结束？"——不肯给具体数量的要警惕，他可能自己都不知道做到哪了。
2. 问节点：原料齐套→排产→生产→质检→包装→发运，现在在哪道工序？"已经在生产"可能只是做完第一道工序。
3. 问具体时间："尽快/明后天/应该来得及"全部无效；"明天发"要追问是明天完成生产还是明天装车出库、最晚几点给物流单号。
4. 问证据：生产工单已下达？完工数量？质检预约时间？发货至少给物流单号。**催货不是怀疑供应商，是验证交付事实**。

**五节点跟催法**（来源⑤抖音 2026-11-04/2026-10-03）：下单 48h 内确认收到并排产（不回复=隐患）；① T+1 要排产单号+生产计划表确认开工日；② 原料到位日前 3 天要入库单或现场照片；③ 开工后 1/3 工期要首件/半成品照片（防"躺在计划表上"）；④ 完工日核对数量+检验报告；⑤ 发货前 2 天核对唛头/装箱单/物流单，锁死到货时间。订单 ABC 分级：A（金额大/交期紧/影响产线）每天跟、B 每周、C 按节点。**交期台账**：下单日/承诺交期/实际交货/延迟天数/原因，月更；谈判直接引用"贵司过去三个月平均延迟 X 天"，对方没法画饼。

**合同交期条款四件套**（模板合同只写一个交货期=没写；来源⑤抖音 2026-11-04）：① 分段交期：备料完成/首批完工/全部完工三个日期分别追踪考核；② 延期违约金**按日千分之三至千分之五、上限 10%**；③ 分批交货（先交六成应急）**写清运费谁担**，否则急发运费吃掉利润；④ 影响交期的变更 **48h 内书面告知否则视为违约**；不可抗力（限电/环保停产）写明举证责任与通知时限。

**催货升级与执行纪律**（来源⑤采购帮商学院 2026-11-05 全文实拉 + 抖音大厂催货 2026-09-19）：
- 供应商排产看优先级表：交期紧不紧、**违约代价大不大**、量大不大、好不好说话——"好说话的客户可以往后放"。催货本质=让你的单在对方表上往前挪，靠的是对方算得出拖你的代价。
- 插单决定权在**计划员和车间**不在销售：问"卡在换模还是卡在料"——卡料一起催原料，卡换模问能否并批。只跟销售磨，磨的是情绪不是排产。
- 三层升级：跟单员/销售层数据化问进度 → 采购经理正式邮件抄送双方管理层，要**根因分析+追赶计划** → 总监对接供应商高层发警告函、启动罚则索赔+切换备选。节奏参考：逾期 3 天书面催告一次、7 天升级对方销售负责人、超合同宽限期启动索赔/扣款，每步留记录。
- 催话四事实先写纸上：承诺到货日/晚了几天/影响哪条线/停线一天损失多少。承诺必须落到**日期+数量**并文字回签；三个送筹码动作别做：替对方找理由、不敢要具体承诺、出问题先道歉。停线记录每周固定时间原样发供应商，一句解释不加。
- **违约金第一次就要真执行**（小额扣款或下批份额调整均可）：案例真扣 2 万余元后，该供应商次年交期准确率从约 70% 提到 95%。条款不执行=没有。
- 月度供应商短会投一张表：交付准确率/来料合格率/问题响应时间，最差标红；半年复盘好的加量差的减量。

**库存计划公式**（来源⑤工博科技 2026-11-03 + carbon.ms 2026-07-12）：
- 再订货点 ROP = 日均需求 × 补货提前期 + 安全库存（可用库存+在途跌破即下单；例：日均 40 件×10 天+120=520 件）。
- 安全库存：交期固定时 SS = Z×σd×√LT；需求与交期都波动时 **SS = Z×√(LT×σd² + d²×σLT²)**（σd=需求标准差，σLT=交期标准差，Z=服务水平系数：95%≈1.65、99%≈2.33）。供应商报 10 天实际 7–16 天的，忽略交期波动会系统性低估缓冲。
- **需求结构或交期一变，两个参数必须同步重算**——不重算，要么断料要么呆滞；多数工厂缺的不是设参数，是变化后第一次调整。

## 八、降本与品类策略（学习批II）

**降本三层杠杆**（来源⑤通天晓 2026-08-30 + 抖音降本18招 2026-08-16）：价格层=询比价/集中集采以量换价；**结构层**=规格合并、VA/VE、供应商分级精简、发展二供三供、VMI 寄售降资金占用；流程层=电子化协同/合规堵漏。纯压价供应商迟早从质量/服务/交期找回来，可持续降本改变的是交易结构。

**VA/VE（价值 V=F/C）**（来源⑤创新供应链课堂 2026-11-04 + 商业新知华为案例 2026-04-30）：VA=给量产件"挤水分"（案例：基站电源进口二极管参数过剩→换参数匹配国产件，该项成本降 15% 且断供风险下降）；VE=新品研发阶段前置介入，从设计源头锁成本。三条路径：**改设计**（剔除/合并冗余功能）、**改工艺**、**改材质**（同等性能低成本替换）。采购牵头组队（研发/质量/市场/财务），先摸清客户必要功能，砍"花架子"。

**规格瘦身纪律**（来源⑤抖音降本18招）：BOM 同类物料合并、重复编码清理、建通用物料优选库、新增非标物料严审批（引导研发优先选标准件）。每次变更：研发+质量共同确认性能、变更前核对在制物料、变更后**优先消化已备原料**、评估报废损失并明确责任归属。

**卡拉杰克四象限**（利润影响×供应风险；来源⑤Kraljic 1983 HBR，抖音百科+systemsequalfreedom 2026-10-01）：

| 象限 | 3C 场景例 | 策略 |
|---|---|---|
| 战略（高利润影响/高供应风险） | 电芯、GaN/协议芯片 | 长期伙伴+联合规划改进、可行处双供、make-or-buy 评审、风险持续监控 |
| 杠杆（高/低） | 壳膜、常规数据线 | 集中量竞标、目标订价、年度一揽子协议+分订单（Call-Off）执行 |
| 瓶颈（低/高） | 独家磁吸模组、特殊工艺件 | 数量保险合同、VMI/额外库存保供应、持续开发潜在替代供应商 |
| 常规（低/低） | 包材、辅料、标准五金 | 简化流程、合并归口，把管理精力省下来投前三类 |

**年度框架协议与返点管理（来源⑥AuraVMS 2026-10-29 + wadhsons 2026-09-22 + 华律返利协议范本）**：
- 返点结构先选对：**增量阶梯**（各档费率只算该档区间内的采购额）vs **追溯阶梯**（跨档后全期采购额按高档费率重算，价值大得多）；另有增长返点（对基期增量计费）、准时付款返点。合同必须钉死：档界"含/不含"、**退货会不会把你打回低档**、返点基数扣除退换货、结算周期（自然年度+次年 X 月前核算支付）、发票前置条件。
- 管理节奏（返点是挣来的更是管来的）：**每月第一周做 tier check**——累计采购额+预测对照下一档，决定是否把分散订单归拢到该供应商冲档；期末 15 天内**用自家数据自算返点**再与供应商对账单核对（只信对方报表=送钱）；索赔附发票级证据；到期未付 30 天升级追讨；续约前 60–90 天复盘"应得 vs 实得"、差一点没够着的档位、明年档位设置。
- 与 §3.6 联动：缩账期五件套里的"年度返点"承诺，落到框架协议里就按本块写死结构与结算，不留口头。

## 九、廉洁红线与自保（学习批III）

- **刑事红线（2026 新规，民企采购同样适用）**：两高《贪污贿赂解释（二）》（法释〔2026〕6 号，2026-05-01 施行）第八条：非国家工作人员受贿罪定罪量刑**参照受贿罪标准执行**——入罪门槛由 6 万降至 **3 万元**，民企员工与公职人员"同罪同罚"（来源⑥中央纪委法规库官方全文核验+泉州晚报律师解读）。
- **围猎路径识别**（来源⑥澎湃政务号判例 2026-07-30）：判例中供应商话术="货款到账 10% 返您个人""按回款 1% 给好处""茶水费"，微信转账/现金分多次小额渗透（4 年 27 次微信+11 次现金累计 42 万），最终非国家工作人员受贿罪判刑+罚金+全部违法所得没收。**任何名目的个人返点都是红线，小额多次会累计**；"先推荐入库→再谈返点"是标准围猎两步。
- **自保动作**：① 供应商任何形式的个人利益输送当场拒绝并向公司报备；礼品/宴请/旅游按公司制度申报上交，不私下收受（"没办事也算"——收管理对象的财物本身即风险）；② 指定供应商、单一来源、紧急采购必须书面留痕理由与审批链，比价记录完整可回溯；③ 与供应商的私人往来（借款/代付/合伙）一律回避；④ 反商业贿赂协议必签（§二），发现供应商主动行贿按协议处置并上报。
- 给新人的话：采购是"供应商最愿意投资的岗位"，你的签字权就是别人的利润。职业寿命比任何一笔"茶水费"都值钱。

## 十、采购面试高频问答（学习批V）

> 来源⑧题库为单源经验版（51 问），答题要按"框架+本公司事实"组合，**不背死答案**；凡涉及公司数据/行情一律现场给方法，不编数字。

**业务题答题骨架（考官其实在验三件事：懂不懂成本、扛不扛得住异常、会不会留痕）**：
1. **采购价值与定义**：采购是用公司资金换取有用的物品与服务、以资源创造利润；价值话术="采购省下的每一元直接是利润，等价于卖出约 11 元货"（按毛利率折算的说法，面试讲"等价销售"逻辑，别当财务恒等式）。
2. **岗位分工怎么描述**：开发与维护合格供应商、询比议价、适质适量适价适时采购、供应商评鉴考核、按 SO 下 PO 并跟催交期、来料异常协同处理、快速报价与市场行情、替代料可行性分析、日报表与订单追踪——按"开发-执行-异常-数据"四段讲，显体系感。
3. **如何开发新供应商**：按品类找候选→资质与产能初筛→送样→合格入合格供应商名录（AVL），不合格重新找；答完补一句"新供应商先小批量验证再放量"。
4. **怎么判断报价真实性**：三家比价+成本分析（材料/加工/管理/税/利润/运费拆解）+同功能产品横向对比，三条腿缺一条都可能被"陪标价"骗。
5. **老供应商每次报价略高于新供应商、谈完又肯降**：这说明其首报含水分。处理=①先小批量试样验证质量与交期；②份额**三七开**——有优势的一方可占大头，老供应商价格拉平则优先给老供应商大头（保新供应商的供货资格与竞争压力）。垄断提醒：单一料号份额全给一家，次年就会被反制。
6. **单一料号月采购额 30 万，选几家**：原则 2–3 家——主供约 70%+备供约 30%，既保议价又保断供；独家的要有替代方案与安全库存兜底，家数不是越多越好（管理成本与批量折扣会吃掉收益）。
7. **电子料封装/行情怎么答**：按系列说（贴片电阻电容 0402/0603/0805/1206，晶振 3225/5032/6032/4025 等），**具体料号一律"查规格书/数据手册确认"，别硬背**（题库里的封装数字本身有误）；行情答"波动大，按当期多家报价与市场指数核"，不报死价。
8. **供应商交期达不成**：发改善通知书→按影响程度扣款/延迟付款施压→仍不改善则切换备选；话术落点="品质和交期决定公司正常运作，条款要能执行"。
9. **来料质量争议（供应商说"只能做到这个程度"）**：先按合同验收标准/样品封样验货；确属供方能力问题则施压整改，无法改善就换供应商；我方标准过严则走让步接收评审（谁让步谁签字）。
10. **新产品 BOM 成本怎么估**：拿 BOM→逐件市场询价与行业质量标准→加工费按工艺估→汇总成表→供应商报价来了对照找偏差；超专业范围请工程介入，别装懂。
11. **供应商请吃请喝**：原则上报备并邀直属上级同往，不单独赴约、不带其他人——这是自保题，考官在看你的合规意识（呼应 §九）。
12. **如何管理供应商**：一张总表定期评品质/交期/配合度，好的多下单、差的减量或淘汰；配合年度评鉴与半年复盘。

**个人素质题答题规则**：缺点要说"真但非致命、且暗示敬业"（如"对水平不如自己的人缺耐性""为促成交易有时偏激进"），别说"我粗心/不合群"；发展空间与薪资二选一时选发展（年轻阶段学东西优先）；被问前东家/前上级**一律说好话或给中肯评价**；爱好选有团队属性的；"你对我们公司了解什么"必须提前查过公司业务与岗位；结尾**一定要提问**（问品类结构、供应商管理现状、考核口径）。

## 十一、从执行到改善：采购价值三层（学习批IX，来源⑪抖音「采供小智」2026-11-15）

**先看反模式**：每天只忙询价、比价、催货、谈判，一单跟进十几次——这部分"重复执行"最容易被系统接手（常规物料自动发询价、报价自动汇总、规则订单自动流转）。**忙不等于不可替代**；真正稀缺的是"让问题不再反复"的人。

- **能力三层（自查在哪层）**：**L1 任务执行**——流程、条款、质量要求、供应商规则都熟，给明确任务能准确完成（这是底盘）；**L2 独立判断**——三家报价不是选最低价，而是判规格是否一致、质量是否可靠、交期是否满足；供应商涨价不是先逼对方降回去，而是分析原料市场、成本变化、有无替代方案（无标准答案时给有依据的判断）；**L3 过程改善**——回答"为什么这类物料长期只有一家供应商""同一产品不同部门采购价为什么差一截""库存越来越多却还经常缺料""年年降本、实际总成本为什么没改善"。
- **改善三步起手**（不用一上来搞战略）：① **记录反复出现的问题**——反复催货、重复询价、临时采购、质量异常，列清单；② **找数据与原因**——需求预测不准？供应商产能不足？流程哪一环不合理？用 6 个月数据看真实波动与下单时点；③ **推动一次小范围改善并验证**——把某类物料紧急采购次数降下来、把准时率提上去、把不合理运输费省掉，成果小但要能验证。
- **改善怎么写进成果**：谈判把 1000 万降 2% = 省 20 万（清楚直接）；补货方式优化（滚动预测+合理提前期+必要安全库存）不压单价，但降库存与急运费合计 30 万，同样是硬成果。**两者不互相贬低，关键是能核算、能验证**；同时问三句：降价会不会伤质量？减库存会不会抬断供风险？换供应商长期总成本真的降了吗（呼应 §3.3 TCO）。
- **自检一句**：过去一年我是"完成了更多订单"，还是"解决了一个以前反复存在的问题"？决定职业价值的不是你每天处理多少问题，而是你能不能让一些问题以后不再发生。

## 十二、采购体系从 0 到 1 搭建（学习批X，来源⑫抖音 Mr.zhang 2026-10-22 + 致远互联 P2P 2026-11-12 交叉核验）

**什么时候该建体系**：需求拍脑袋、价格说不清、供应商串标、出问题找不到责任人、审计一身冷汗——小公司靠人盯还行，规模一上来（采购额、供应商、物料变多）只靠人必踩坑。

- **九步闭环（每步都在堵漏洞，不是走流程）**：预算 → 请购 → 询价 → 比价 → 订单/合同 → 验收 → 入库 → 发票 → 付款。
  - **询价**（合规最敏感）：建立**询价台账**、报价线上留痕、报价信息保密（业务/其他部门不接触报价），原则上**≥3 家**参与；一家单独对接+私下报价=串标温床。
  - **比价**（内控核心）：不只比单价，比运费、账期、售后、退换货等隐性成本（TCO）；**两家比价样本不足**；金额越大参报价家数越多；**中标价与预算差距大必须书面说明**。
  - **订单/合同**：严禁口头协议，统一标准合同模板；大额订单分级审批，**大额合同财务高管联签**。
  - **验收**：验收标准**提前写进合同**，不是凭感觉；来料看检验、设备看功能节拍、服务看过程与交付成果。
  - **入库**：**实物签收与系统入库分开**，防"系统先入库、实物没到"的空单走空；日盘点，不合格样品/废料留存备查，保账实一致。
  - **发票**：**发票、订单、入库单三单核对一致**才进付款；采购只做业务对接，不单独控制付款。
  - **付款**：决策权归财务（总经理），采购只协助对账、跟踪进度；**价格/税率一变，书面通知财务更新结算标准**。
- **铁律一：四分开（权责隔离）**——申请采购、下发订单、验收、付款四个动作由四个不同角色完成。提需求的人不能下单、下单的人不能验收、验收的人不能付款；一人全包=运动员兼裁判，后果是价格操纵、虚假入库、虚假采购、审计重大缺陷+员工廉政风险。话术：**不是不信任员工，是用制度保护员工**。
- **铁律二：物料总表**——没有统一物料总表，就说不出今年降本多少、哪家供应商占比最高、哪些物料可合并采购；信息散在 Excel/聊天记录/各业务员电脑里 = 没数据基础。总表至少含：物料编码/名称/规格/单位/分类/常用供应商/近 12 个月单价与用量/年度金额/单一来源标记。
- **落地顺序（先规范流程再上系统，否则"上系统不改流程"=把混乱自动化）**：① 定九步+表单（请购单/询价台账/比价表/PO/验收单/入库单/三单核对表）→ ② 定四分开与金额审批矩阵 → ③ 建物料总表 → ④ 再考虑系统固化。
- **常见坑对照**：只比单价、两家比价、口头协议、验收凭感觉、实物与系统不同步、采购一人全包、没有物料总表——任何一条在，审计和舞弊风险就敞着口。

## 十三、采购 5R：五个合适的权衡（学习批XI，来源⑬抖音「采购牛马」2026-08-22 + 教材/英文源交叉核验）

> 这一节既是面试必考题的标准答法，也是日常下单前的自检框架。**核心不是把五项各自做到极致，而是在五项之间找整体最划算、整体风险最低的平衡点**（落到 §3.3 的 TCO）。

- **先说口径：5R 有两个版本，答错会被考官抓**。中文教材与传统培训口径＝**适时 Right Time、适质 Right Quality、适量 Right Quantity、适价 Right Price、适地 Right Place**（《采购管理实务》第 3 版、抖音百科 5R 词条一致）；英文与部分企业实践口径把"适地"换成 **Right Source / Right Supplier（合适供应商）**（Tradogram 2026-08-03 五 Right＝right product/quantity/time/source/price）。安全答法：先报五条，再补一句——"**第五个 R 在教材里是 Right Place（采购半径与交货地），企业实践里常改成 Right Source（合适供应商）；这两条其实是一体两面：选来源就要连它的地理位置和门到门物流成本一起看**"。两个考官都对得上，还显得你知道版本演变。
- **五项之间的真实取舍（一句话各一条）**：追最低价→牺牲质量/交期；追最高质→成本涨、可选供应商变少；追最小库存→缺货风险；追最快交期→赶工费与运费；只选最近供应商→可能错过更有竞争力的资源。
- **权重不是固定的，按公司阶段和品类走**：生存期（先买得到、买得起）→ 适价＋适时权重最高；成长期 → 适质＋适量（质量稳定、库存合理）；成熟期 → 适地/供应网络（效率与弹性）。品类映射 §八 卡拉杰克：**战略料保质量与供应稳定；杠杆料压价与量；瓶颈料保交付与来源；常规料简化流程、降管理成本**。
- **适价 ≠ 最低价（三个动作，缺一个就被"陪标价"糊弄）**：① **多渠道拿报价**——老供应商之外定期引入新面孔，否则拿不到真实行情；② **标准化比价**——把含税/含运/账期/质保/最小起订这些条件先拉到同一基准，再比数字；③ **成本分析**——拆材料/加工/管理/利润结构，议价才有数据支撑。补一句：一味压价，供应商会从偷工减料里找回来，总成本反升。
- **适质 ≠ 最高质（质量成本视角，本批最容易被忽略的一条）**：适质＝满足生产与业务需求的**最低经济标准**，不是等级越高越安全。**质量成本分四类**——预防成本、鉴定/检验成本、内部失败（返工、报废）、外部失败（客诉、退货、索赔）；质量水平越高，前两类成本先涨，四类成本**总和最低的点**才是经济质量点，**过度质量本身就是浪费**（还会带来更长交期、更少可选供应商）。落地两件事：① **质量前移**——合同里就写质量保证协议、检验标准、不合格处置流程（呼应 §四）；② 推供应商做认证+定期现场审核，把问题解决在他厂里而不是我产线上；考核看**长期稳定（PPM 不良率/批合格率）**，不是"这批合格就行"。
- **适时 ≠ 催货**：真正要管的是**整条时间链的节点与预警**——需求确认→采购计划→订单下达→供应商生产→物流→入库检验，每环设节点、设预警，进度可视化（哪些未排产、哪些在途、哪些可能延期、会影响哪条生产计划）；安全库存按**供应商历史交付表现**设（呼应 §七公式）；关键料必备选供应商+缺料应急预案；条件成熟用 VMI/JIT，目标不是库存越多越安全，而是在**不断供与低库存之间**取平衡。
- **适量 ≠ 折扣越大越好**：基准是 **EOQ 经济订货量**（使订货成本+持有成本总和最小的批量），现实再叠加需求预测、生产计划与实时库存动态修正；遇数量折扣算两笔账——**折扣省下的钱 vs 增量库存带来的资金占用+仓储+呆滞/过期风险**，后者更大，这个折扣就是陷阱。需求波动大的物料用**框架协议＋滚动订单**（小批量覆盖近期，后续按实际消耗更新订单），别一次性压货。
- **适地 ＝ 采购半径与门到门总成本**：不只是收货地址写对，而是供应商地理布局与物流路径。离得近＝交期快、沟通成本低、运费可控、异常响应快（本地化/区域化采购的逻辑）；报价略高但近、响应快、配合好的，**门到门总成本（运费+包装+在途库存+风险）可能更低**。
- **面试 30 秒答法（照这个结构说）**：点题一句（"5R＝在合适的时间、以合适的价格、从合适的供应商、买回合适数量与合适质量的物料，目标是整体采购效益最大、总成本最小"）→ 每条一句"陷阱"（价不是最低价、质不是最高质、时不是最快、量不是最多、地不是只写地址）→ 收尾给判断（"实际工作中我按物料类型定权重：战略料保稳定、杠杆料压价、瓶颈料保供、常规料简化"）。这一收尾是分水岭——只会背五个词的是新人，会说权重的是懂业务的。

## 十四、执行方式（给 AI 的操作指令）

- 用户问**话术** → 直接给「场景 → 推荐话术 → 潜台词」三行式，优先复用 §3.1/§3.2，不即兴发挥空话。
- 用户要**谈某个具体供应商/砍价** → 先问齐四要素（品类与量级、当前报价、目标价/预算、备选供应商情况），再出谈判方案：开场定调 → 比价筹码 → 让步阶梯（价格/账期/交期/包装互换）→ 收尾锁定话术。
- 用户问**流程/表单** → 按 §一/§二 给对应 SOP 与表单清单，需要成品表格时转 `workbuddy-sheetagent`。
- 用户问**验收/质量纠纷** → 按 §四 给处置链与合同依据。
- 用户要**分析报价合理性** → 拆解 BOM 成本（原料/工艺/模具分摊/认证/包装/物流/利润），对标同规格行情，指出水分位置与压价话术。
- 用户问**供应商涨价怎么办** → 先按 §3.4 算传导（原料占比×行情涨幅，行情联网查证），写底线/目标/筹码三线，再给拆项质询与锁价条款话术。
- 用户问**账期/现金折扣/付款方式怎么选** → 按 §3.6 先折现成钱再比较，输出三张表与交换条件组合，不凭感觉答"划不划算"。
- 用户问**IQC/抽检/AQL 怎么定** → 按 §四 IQC 块给分级+AQL 参数+Ac/Re 查表口径，致命缺陷零容忍；具体批量样本量须查 GB/T 2828.1 表，不口算拍数。
- 用户要**发询价/收报价** → 按 §一询价 12 要素生成询价单与《报价明细表》模板（成品表格转 `workbuddy-sheetagent`），并做"能否直接比价"自检。
- 用户问**催货/供应商拖延/交期风险** → 按 §七 四锚点+五节点给追问提纲与书面确认模板；已逾期的先摆四事实，再按三层升级路径走，核对合同罚则是否可执行。
- 用户问**去哪找供应商/这家是不是真工厂** → 按 §二 鉴别块给三硬指标+样品单测试清单，结合品类给产业带建议。
- 用户要**降本方案** → 按 §八 三层杠杆出组合拳（先结构层后价格层），VA/VE 按改设计/改工艺/改材质三路径列方案并标注需研发质量确认项。
- 用户问**备多少货/什么时候下单** → 按 §七 库存公式计算，先问齐日均用量、补货提前期、需求与交期波动数据、目标服务水平，禁止拍脑袋报缓冲比例。
- 用户问**供应商质量整改/8D** → 按 §四 8D 块给时限要求与 D4/D6 证据口径，输出可直接发供应商的 SCAR 要求清单。
- 用户问**模具归属/移模/模具费** → 按 §四 模具块核对合同条款缺口（所有权/留置/摊销三问/保证模次/封样），给补签条款清单。
- 用户问**返点/框架协议** → 按 §八 返点块先确认结构（增量 vs 追溯），再给 tier check 与自算对账流程。
- 用户遇到**供应商给回扣/送礼/请托** → 按 §九 给红线判断与自保动作，明确拒绝并建议报备留痕，不提供任何规避手段。
- 用户要**准备采购面试/演练答题** → 按 §十 给答题骨架，先问目标公司与品类背景再定制；公司数据与行情信息一律标注"需现场/联网核实"，不编造。
- 用户问**试用期怎么留痕/周报怎么写/被甩锅怎么自证/转正答辩怎么讲** → 按 §6.1 给每日三行+四类记录+周报四问模板，结合采购场景（交期/来料/口头承诺）生成可直接套用的记录表头。
- 用户要**向上汇报/月度经营会发言/降本汇报/汇报型 PPT 大纲** → 按 §5.1 给三明治骨架与页序，先问清要向谁汇报、要他批什么决策；数字口径必须可追溯，不编造数据。
- 用户说**话说不清/推不动方案/要给谁提问题/会上发言/展会破冰** → 按 §5.2 选公式（出错汇报 SCQA／说服批方案 FAB／提问题 BACC／会议表态 PREP／拜访破冰 3W），输出可照读的四句式，并换成采购场景实例。
- 用户问**采购干几年怎么往上走/会不会被替代/怎么做改善** → 按 §十一 先给三层定位（L1 执行/L2 判断/L3 改善），再让用户列"反复问题清单"，选一个做小范围改善并定义验证指标。
- 用户要**搭采购流程/写采购制度/做内控自查** → 按 §十二 给九步闭环卡点表+两条铁律，再按"表单→四分开与审批矩阵→物料总表→系统"顺序出落地清单；先问公司规模、金额阈值与现有审批链。
- 用户问 **5R/五个合适/面试问 5R** → 先问是**面试答题**还是**日常自检**：面试按 §十三 给 30 秒版（点题→五条陷阱→按品类定权重收尾），并主动点出"适地 vs Right Source"版本差异；自检则让用户报当前品类，按 §八 象限定五项权重，再逐项查他卡在哪一项。
- 涉及实时行情（电芯/塑胶/汇率价格）→ 必须联网查证后引用，标注日期，禁止凭记忆报价。

### A02 采购部工作流程制度（总则 · 基本流程 · 申请商品采购）
- 目的：规范采购流程、提高效率；全体采购及相关人员以此为依据开展工作。
- 基本流程：采购需求 → 采购计划 → 寻找供货商 → 询价、比价、议价 → 采购洽谈 → 合同签订（确定付款条件、配送方式、售后服务）→ 交货验收（仓管）→ 质检（不合格退货）→ 入库 → 计划对账 → 财务结算。
- 流程图节点：采购需求 → 采购计划 → **审批** → 采销部/采购部/销售部 → **总监**；采购计划 → 寻找供应商 → 寻价、比价、议价 → 采购洽谈 → 合同签订 → 建立供应商资料 → 下单 → 交货验收 →（合格）入仓 → 计划对账 → 财务结算；（不合格）退货。
- 申请商品采购流：项目部提出需求 → 采购部审批（分有合同/无合同两支）→ 总监审批 → 采购订购。

### A03 申请付款 · 到货验收 · 采购管理制度
- 申请付款流：采购 →（按供应商账期）对账 → 采购部长审批 → 财务审批。
- 商品到货验收流：仓管打入库单 → 仓库凭入库单确认型号、数量、包装等 → 审核入库单 → 合格进仓，不合格退回供应商。
- 采购执行 7 要点：① 采购计划（依请购单+公司销售计划制订）；② 供应商选择与考核（经营情况/供应能力/品质能力评定，定期按质量、运货、价格、逾期率、配合度综合打分）；③ 询价、比价、议价；④ 合同签订（询报议比后签约；须与财务部核实付款条件、货运方式、售后服务）；⑤ 交货验收（品种、数量、质量、交期正确无误，以采购员确认和合同为验收数据）；⑥ 质检（合格入库，不合格安排补救和退货）；⑦ 财务结算（入库后结算）。
- 管理制度 7 条：① 建供应商资料（表）册、售后服务管理表；② 建立健全比价制度，保证质优价廉；③ 每月末汇总付款/欠款/欠票，提下月用款计划；④ 签约后全面了解发货情况，不能及时供货的将原因**提前两日**通知请购部门或请购人；⑤ 所有货物一律开箱验收，发现问题及时联系供应商尽早解决；⑥ 验收合格后**一个工作日内**办理入库手续；⑦ 每月 5 日前将上月采购合同编号整理成册交相关部门备案。

### A05 采购流程图（含 9 条释义）
- 主流程：需求部门提出采购申请 → 需求部门负责人签字 → 计划采购/紧急采购 → 提交采购部门 → 询价 → 比价 → 谈价 → 汇总整理报采购部负责人 →（同意）财务部负责人审 → 总经理批准 → 采购员下单 → 供应商发货 → 到货 → 分类验收 → 是否特采 → 入库。
- 分类验收：一般物料/普通产品/非专业劳保/常规易耗品 → 仓库验收；设施设备/专业劳保/工作服 → 申购人验收；车间原料辅料调料蔬菜配料包装等与生产有关 → 品管验收。不合格 → 退货；特采需总经理批准。
- 释义 9 条：① 需求部门经办人填《采购申请单》、部门负责人签字；② 需求部门做好日常计划，无正当理由不得申请紧急采购；③ 紧急采购走绿色通道，财务负责人+总经理签字后采购部直接购买；④ 采购人员至少「货比三家」，按申请单品牌规格选性价比较高的产品汇总逐级审批；⑤ 同价位优先可开增值税专用发票的供应商，按财务制度做报销；⑥ 到货后严格按公司制度检验验收，杜绝不良品入厂；⑦ 特殊情况特采不良品必须总经理批准；⑧ 附件《采购申请单》；⑨ 采购编号按部门按月累计。
