# wb-outreach —— 一对一对外沟通写作

写给**一个人**看的信，不是发给一批人的公告。判断标准只有一条：这封换个人名还能发，就等于没写。

## 一、五条核心规则（任一违反就不算完成）

1. **每封都要个性化**：必须能说出"为什么是你"，而不是"贵公司平台很好"。
2. **请求要低摩擦**：一封信只给**一个具体下一步**（15 分钟电话 / 帮我看一眼这份材料 / 转给对的人），不要三门选一。
3. **用证据替代形容词**：不要"学习能力强""对行业充满热情"；给可核对的事实（做过什么、产出在哪、数字多少）。
4. **短**：正文控制在 5–8 句，收信人应在 20 秒内读完并知道要做什么。
5. **不编 CTA**：源材料里没有的钩子、提问、升华，一律不加。

## 二、五段结构（默认骨架）

1. **主题行**：具体、短（≤12 字），写事不写人设。禁"您好""一个请求"这类空标题。
2. **开场第一句 = 为什么是这个人**：引用他的一条公开内容 / 一个项目 / 共同联系人 / 与该岗位或方向的明确匹配点。
3. **自我介绍与证据**：一句说清我是谁 + 一句说清我做过什么（带可核对物：链接、作品、数据）。
4. **请求**：一个动作、一个时间窗、一个可拒绝的礼貌出口（"如果这不合适，指个方向就好"同样是一个明确请求）。
5. **落款**：姓名 + 身份 + 一个可信锚点（学校/前雇主/共同认识的人）。

## 三、个性化素材的四个来源

按可用性排序取一到两个，宁少勿编：

- 对方公开的产出（文章、演讲、项目、帖子、招聘 JD 里的一句具体要求）
- 共同联系人或同一条社群线（"X 建议我联系你"需 X 知情）
- 明确的业务/岗位匹配（JD 里的痛点 ↔ 我做过的事）
- 对方的公开选择（同校、同专业、同城、同一条职业路径）

**素材缺失时**：直接标"这封还没有个性化，需要你补一句为什么是 TA"，不要把草稿伪装成完成品。

## 四、跟进节奏与止损

- **第 0 天**：首次发出。
- **第 4–5 天**：一次短跟进，**必须带一个新信息**（新作品、新进展、补充材料），不要只写"想确认您是否看到"。
- **第 10–12 天**：最后一次，明确收尾（"不再占用您时间；若之后有合适机会我再联系"）。
- **之后不再追**，除非收信人明确表示可以继续。追到第三封之后，边际收益为负。

## 五、引荐请求（warm intro）

替中间人把活干完：

- 说清为什么合适（一句，可被直接复制）
- 附一段**可原文转发**的介绍（**≤100 词**，含"我是谁/我做什么/我想要什么"）
- 明确"如果方便的话"与"不方便也完全没问题"

## 六、会面后的跟进

四件套：① 上次具体聊了什么（一句，证明你听了）② 承诺过要补的东西（现在补上）③ 一个新证据（可选）④ 下一步与时间。

## 七、硬禁（出现即删重写）

- "我想认识一下您" / "希望能得到您的指点"（空请求）
- "久仰大名""贵司平台很好"（无 tie-in 的空赞美）
- "excited to share" / "期待与您交流" 类模板句
- 自贬式乞求（"打扰您了""知道您很忙"开头即示弱）
- 用形容词堆能力，却没有任何可核对物
- 同一封改个名字发给十个人

## 八、质量门（交付前逐条过）

- 这封换个人名还能发吗？能 → 重写开场。
- 收信人 20 秒内能读出"要我做什么"吗？
- 请求是一个动作还是三个？
- 有没有一处可核对的证据？
- 有没有一句是从源材料里没有的、我硬加的 CTA？

## 九、与相邻技能的分工

- `resume-ai-help`：简历正文本身（本技能只管"发给谁、说什么"）。
- `wb-doc-writing`：长文档、报告、方案的写作与评审。
- `humanizer-zh`：成稿去 AI 味；本技能在**起草阶段**就避免模板句。
- `doubao-multiplatform-rewrite` 等平台技能：一对多分发与平台改写；本技能是**一对一**。
