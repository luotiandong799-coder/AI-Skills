# writing/defensive-writing-audit

## 一、它解决什么

同一句话有两种写法：

- 正确姿态：**结论 → 证据 → 一句边界**
- 防御姿态：**预想反对 → 免责 → 理由 → 削弱结论 → 再免责**

后者读起来「心虚」，不是因为观点弱，而是因为作者在替假想的审稿人打自己的稿。本技能把后者识别出来，改成前者。

## 二、核心判据（三问定性质）

对每一句可疑的话，依次问：

1. **删了会不会让人误解？** 会 → 必要限定，保留；不会 → 进第 2 问。
2. **它报告了支持条件、不确定性或局限吗？** 报告 → 必要限定；不报告 → 进第 3 问。
3. **它的主要作用是不是回答一个想象中的批评？** 是 → 防御性写作，改。

四种判级：`必要限定 / 防御性 / 混合 / 干净`。

严重度：**Critical** = 像回辩、道歉、法务免责；**Major** = 反复限定、为结果开脱、为省略实验辩护、促销形容词；**Minor** = 局部措辞。

## 三、十四种模式（逐句打标）

| 代号 | 模式 | 典型信号 | 处理 |
|---|---|---|---|
| D1 | 预防式回辩 | 「需要强调的是」「值得注意的是」「为避免误解」「有人可能会说」 | 直接说技术事实 |
| D2 | 重复非主张 | 「本文并不声称……」「这不应被理解为……」 | 正面陈述一次，只划一次范围 |
| D3 | 限定语堆叠 | 一句里 although/while/despite/only/may/might/potentially 叠三层 | 留最强结论，实质限定只留一条并挪到对应章节 |
| D4 | 替弱结果开脱 | 「分数较低可能是因为……」「结果仍令人鼓舞」 | 先报数字；原因有证据才写 |
| D5 | 为省略实验辩护 | 「未做 X 是因为……」「这种比较不公平」 | 重要就在局限里写一次，否则只写评估协议 |
| D6 | 公平性自我辩护 | 「为保证公平，所有方法使用同一骨干」 | 「所有方法使用同一骨干」 |
| D7 | 初步/有限重复 | preliminary / exploratory / 仅初步 | 技术必要时才用 |
| D8 | 法务式免责 | 一长串「不得被解读为」 | 改成一句正面范围 |
| D9 | 无关自我披露 | 不影响效度与复现的过程波折 | 只留科学相关，其余进附录/日志 |
| D10 | 促销补偿 | robust / comprehensive / promising /「显著提升」 | 换测量值、协议或具体性质 |
| D11 | AI 式自动总结 | 「综上，这些结果充分表明……」 | 删；或只留一条数据支持的推断 |
| D12 | 边界过度声明 | 「支持 X，但不能确立 Y」 | 「在评估设定下，X」；Y 放局限说一次 |
| D13 | 绝对化防御 | 「任何方法都会失败」「这保证了」 | 补精确经验或理论条件 |
| D14 | 换词造贡献 | 给标准操作起新名、反复辩护新颖性 | 直接写技术增量 |

## 四、五步审计流程

1. **检测**：逐句标 D1–D14。
2. **定性**：每句判 `必要限定 / 防御性 / 混合 / 干净`。
3. **读者反应**：对「防御性 / 混合」，写一句「审稿人读到会怎么想」。
4. **改写**：先事实→正面范围→一处主张最多一条实质限定→形容词换测量值→写控制条件而非「公平」→弱结果不擅自解释→不越过证据加强→必要时直接删。
5. **全文级**：查重复局限、摘要免责、贡献条里的限定、结论自我削弱、为省略辩护、空泛褒词、重复的 AI 式总结句。

## 五、输出格式（照此交付）

| 位置 | 原句 | 类型 | 严重度 | 是否必要限定 | 为什么像防御 | 审稿人可能反应 | 建议动作 | 改后 |
|---|---|---|---|---|---|---|---|---|

后附三项：
- **防御性写作评分 0–10**：0–2 干净 / 3–4 轻微 / 5–6 明显 / 7–8 强 / 9–10 像回辩或免责通篇。
- **优先删除清单**（3–10 条，按提升读者观感的幅度排序）。
- **必须保留的限定清单**（写明它保护哪一项：观点成立、证据理解、适用范围、研究设计、结果可用性）。

## 六、中文专项

- 习惯性谦辞：**「仅仅做了初步尝试」「只能提供有限参考」「仍有很大提升空间」** → 直接写「本文在两个数据集上评估该方法」。
- 「初步」「可能」「提示」若证据确实如此就保留；不许为显得有力加「显著」「全面领先」。
- 限定只写一次，放方法/讨论/局限；摘要、段首、贡献段、结论里清干净。

## 七、英文专项

- 删叠加 hedge（may potentially suggest that X could possibly...），但**不机械删除 may / suggests / under these conditions**，按证据判断。
- 观察性研究只发现关联，不许写成因果。

## 八、边界（硬规则）

1. **不删必要限定**：影响观点是否成立、如何理解证据、结论适用范围、研究设计、读者能否正确使用结果的，必须保留。
2. **不用「显得有力」换真实性**：不许把不确定写成定论、把相关写成因果。
3. **不补造内容**：示例只示范措辞，不得据示例补数据、机制、因果关系、优势（「三种制度环境」「最适用」这类说法要有原稿依据）。
4. **不替代证据**：观点太大就缩小范围、补证据、理清推理，不允许只在后面加一句「当然也存在局限」。
5. **不改研究操作**：只动表述，不动实验设计、参数与结论指向。
