# 测试 A 链路产出：仓储管理方向（虚拟）

> 虚拟对象：云仓 A。全部资料为测试占位符，禁止用于真实论文。
> 本文件走：01 选题与开题 → 07 章节大纲 → 05 研究方法 → 03 专业问题分析 → 09 内容去重。

## 01 选题与开题

| 项 | 判定 |
|---|---|
| 资源档 | **B 档**（30 天拣货记录 + 订单明细 + 平面草图 + 2 次观察 + 1 次访谈） |
| 题目 | 基于作业环节拆解的云仓 A 拣货效率优化研究 |
| 标题结构 | 基于〔方法〕的〔对象〕〔问题〕研究 — 合格，方法与数据匹配 |
| 可行性 | 单仓、单流程、30 天数据，工作量匹配本科 1.5 万字 |
| 禁止 | 不得声称「库存周转率过高」「安全库存不足」——无库存台账与成本数据 |

B 档可做：作业环节拆解、路径观察、拣货时间与准确率计数、定性问题诊断。
B 档不可做：I1 周转率、I6 安全库存、I8 EOQ（均需成本/需求参数，fixtures 未提供）。

## 05 研究方法（适用性与数据对齐）

| 方法 | 是否采用 | 理由 |
|---|---|---|
| 流程观察 + 作业环节拆解 | 是 | 有 2 次实地观察与平面草图 |
| 描述性统计（W2/W3/W4） | 是 | 拣货记录提供件数、工时、错拣行数 |
| 访谈补充归因 | 是 | 1 次班组长访谈，仅用于解释现象，不作为定量证据 |
| 仿真建模 | 否 | 无全年订单分布与设备参数，本科无法完成 |
| 问卷调查 | 否 | 问题是「流程慢」，问卷回答不了路径长度 |

## 03 专业问题分析（只写可由 B 档资料支撑的内容）

| 观察现象 | 可核验证据 | 待验证原因 | 禁止写法 |
|---|---|---|---|
| 拣货路径重复穿越同一通道 | 平面草图 + 观察记录 2 次 | 货位按入库顺序分配，未考虑订单关联 | 不得写成「已造成 X 元损失」 |
| 错拣行数 36 / 2,400 行 | 拣货记录 | 复核环节是否覆盖高值 SKU（需访谈核对） | 不得推断为「人员责任心不足」 |
| 复核耗时占比高 | 需补工时记录 → **待补** | 数据不足，不写结论 | 不得编造工时数 |

**问题—原因—对策对应检查**：第 4 章每个「原因」必须能指回第 3 章某张表或某次观察；方案章每条措施必须标注对应的原因编号。当前 3 条现象中，第 3 条因工时记录缺失标记「待补」，不强行给对策。
