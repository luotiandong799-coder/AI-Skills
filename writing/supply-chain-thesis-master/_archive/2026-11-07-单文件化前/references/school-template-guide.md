# 学校模板适配指南

## 一、先拿到模板，再动笔

必备材料：正文模板（.doc 或 .docx）、格式规范说明、封面与声明页、参考文献格式示例、图表编号要求。

拿不到模板时，先按 GB/T 7714 与常规本科格式写，并在项目记忆标注「模板待补」，交稿前必须补齐。

## 二、需要从模板中提取的参数

| 项 | 具体内容 |
|---|---|
| 页面 | 纸张、页边距、页眉页脚、页码位置 |
| 正文 | 字体、字号、行距、段前段后、首行缩进 |
| 标题 | 各级标题字体字号、编号方式（1 / 1.1 / 1.1.1） |
| 图表 | 图题在下还是在上、表题位置、编号规则、三线表要求 |
| 参考文献 | 格式标准、数量要求、是否要求外文 |
| 其他 | 摘要字数、关键词数量、致谢、附录 |

提取后写入项目记忆，作为后续所有排版与检查的依据。

## 三、落地方式

1. 内容在 Markdown 或纯文本中完成，避免在排版上反复折腾。
2. 成稿用 workbuddy-docx 按模板生成或套用样式。
3. 排版完成后逐项对照模板检查，见 `checklists/submission-check.md`。

## 四、常见冲突与处理

| 冲突 | 处理 |
|---|---|
| 学校要求与国标不一致 | 以学校为准，注明依据 |
| 导师口头要求与模板不一致 | 以导师最新书面要求为准，并记录日期 |
| 模板本身有错 | 不改模板，按导师确认后的做法执行并记录 |

## 五、不要做的事

1. 不擅自改动学校模板的样式定义。
2. 不用「看起来差不多」代替逐项核对。
3. 不把模板里的示例文字留在正文中。
4. 不为了排版美观改动图表编号规则。

## 六、西安欧亚学院本科开题报告格式基准（用户 2026-11-07 定，长期生效）

适用：该校本科毕业论文（设计）开题报告，一律按此办理。空白模板 `templates/开题报告_格式模板_27版.docx`（已清个人标签，按各栏详略预留空行，可直接套用）。

**冲突优先级**：用户当前指令 > 2027 届模板「要求」5 条 + 备注 2 条 > 参考范样板式 > 本技能通用规则。范样与 27 届要求冲突时一律按 27 届：A4 **单面**打印（非双面）、**GB/T 7714-2025**（非 2015）、日期示例「2023年9月」、签名手写不得打印、□ 不代勾、备注要求删除括号提示文字。

**版式基准**（取自已通过评审的学长沙本开题报告）：
- 页面 A4（11906×16838 twips），页边距上/下 1440、左/右 1800；单面，不设镜像边距。
- 封面：校名 + 「本科毕业论文（设计）开题报告」；题目表 2 行 2 列（1089/8182）；信息表 8 行 4 列（1746/1485/4740/1317，两侧空列用于居中），8 项为姓名/学号/指导教师/职称职务/所在分院/专业/班级/提交日期。
- 独立「要  求」页 + 备注页（2 条），分页符保留。
- 正文为 9 行 1 列表格（宽 9140），栏目标题用中文序号「一、」~「七、」，后两栏「指导教师意见：」「教研室意见：」。
- 正文小四（sz=24）宋体、西文 Times New Roman、1.5 倍行距（line=360 auto）；各级标题加粗、首行缩进 2 字符；参考文献条目顶格、从 `[1]` 起顺序编码。
- 提纲具体到三级标题（1 / 1.1 / 1.1.1），一级标题加粗，末尾列「致谢」「参考文献」；日期全用阿拉伯数字。

**内容形式基准**（用户 2026-11-07 要求「哪个地方多就多、少就少」）：不把九栏写成等长长段落，按范样各栏的段落结构与详略分布写。

| 栏 | 段落结构 | 段数 | 参考字数 |
|---|---|---|---|
| 一、背景意义 | 「（一）选题的背景」+ 1 段 +「（二）选题的意义」+ 1 段 | 4 | ~530 |
| 二、文献综述 | 「（一）国内研究现状」+ 4 段 +「（二）国外研究现状」+ 3 段 +「（三）研究现状评述」+ 1 段 | 11 | ~1900 |
| 三、提纲 | 三级标题列表，一级加粗，末尾「致谢」「参考文献」 | 47 | ~640 |
| 四、步骤方法 | 「（一）研究的步骤」+ 6 条短句 +「（二）研究的方法」+ 总述 1 段 + 3 组「方法名 + 说明段」 | 15 | ~310 |
| 五、进度安排 | **仅 1 行起止时间**，不列分阶段 | 1 | ~40 |
| 六、参考文献 | 每条 1 段顶格；27 届要求 ≥15 篇，可多于范样 15 条 | 15+ | — |
| 七、评价 | **1 句**简短结论，不展开建议 | 1 | ~45 |
| 八/九、评审栏 | 意见区（留白）+ □ 同意 + □ 不同意 + 签名 + 日期占位 | 5 | — |

范样简则简（进度、评价只一行），详则详（综述、提纲、参考文献铺开）；冲突时按 27 届要求（参考文献 ≥15 篇、顺序编码制文内 `[n]` 全部出现且连续）。空白模板按上表段落数预留空行，直观体现详略。

**个人标签隔离**（用户 2026-11-07 强调）：范样版式可用，但其中属于他人的手写签名图片、姓名、学号、班级、评审意见、具体日期、文档元数据作者**一律不带入成品**；签名栏与意见栏保持空白占位。需要纯格式文件直接用上面的空白模板。

**引用真实性硬规则**（用户 2026-11-07「打开 Edge 知网找真的引用」，长期强制；全文单源在本节）：
1. 生成任何开题报告 / 论文 / 文献综述前，先用 Edge 打开中国知网（`https://www.cnki.net/` 或带 `kw` 的 `kns.cnki.net/kns8s/defaultresult/index` 检索页）作为核验入口；Edge 路径按全局「浏览器默认 Edge」，打开后不主动关。
2. 参考文献**逐条取证**：作者 / 题名 / 刊名 / 年卷期 / 起止页码 / DOI，至少有一个可公开访问的一手页面佐证——知网节（inds.cnki.net / r.cnki.net）、期刊官网（含 DOI 落地页）、维普、万方、出版社页面、国家科技期刊平台。把来源 URL 记入交付的核验清单。
3. 只有二手参考文献列表、元数据互相冲突（如页码 4-7 与 10-13 打架）或查不到一手页面的条目 → 标「待核实」并**剔除**，不得进参考文献；始终不虚构文献、DOI、页码（呼应 SKILL.md §二.1）。
4. 企业背景事实同样只取公开可查来源（政府网站 / 企业官网 / 权威媒体），按 `[EB/OL]` 著录并在正文标注来源；不把行业普遍情况写成该企业事实，不把公开报道的规模数据当本研究实测数据。
5. 知网检索页为 JS 动态渲染，WebFetch 常只取到导航框架而非结果列表 → 用「题名 + 作者 + 刊名」精确检索落到一手页面取证，**不得把空结果当「查无此文」**，也不得据此编造条目。
6. **中英文文献一律同等核验（用户 2026-11-07「以后记住中英文都要核查」，永久强制）**：
   - 中文条目取证通道：知网节 / 期刊官网 / 维普 / 万方 / 国家科技期刊平台 / 国家哲学社科文献中心。
   - 英文条目取证通道：DOI 落地页（`https://doi.org/{DOI}` 解析到出版社页）、Crossref API（`https://api.crossref.org/works/{DOI}`）、出版社与学会官网（Springer / INFORMS / MDPI / Inderscience 等）；逐字段核对作者全名与顺序、题名、刊名、年卷期、起止页码或文章号、DOI。
   - 交付的核验报告**按「中文 / 英文」分组逐条列证据与结论**，每组均给出条数、通道、命中率、错误与修正；禁止只核中文、禁止只给「全部真实」的整体结论、禁止因英文条目带 DOI 就默认可信。
   - 英文 DOI 未在 Crossref 注册时改由出版社页面取证，不得直接判假（同中文 DOI 纪律）；元数据冲突时以出版社一手页面为准并记录冲突。
   - 适用范围不限于开题报告：凡论文、文献综述、含中外文参考文献/资料的任何交付物，两边都要查。
7. 顺序编码制按正文首次出现顺序编号；区间引用如 `[1-3]` 须展开核对，确保 1..N 连续且每条都被引用。
8. **文献构成**（用户 2026-11-07「还要有部分英文文献」）：中文与英文文献均需具备，英文优先补系统综述 / 管理视角类，避免全部为算法仿真类；核验清单按「中文 / 英文」分组列证据并给出各组条数。英文 DOI 常见错误（如年份写成 `2018.10.023` 而实为 `2018.08.023`）必须以 Crossref / 出版社卷期目录为准更正，不得凭记忆。

**匿名案例企业写法基准**（用户 2026-11-07「我部分可以不是他，应该是以他为参考更合理」「看看那种匿名公司的怎么写的」；全文单源在本节）：

- **判定**：题目用「S公司 / A公司」等代称时，真实企业只能作**行业技术形态参考原型**，不得写「真实背景为××」「论文中以S公司指代」。理由三条：① 点名后匿名自相矛盾，答辩一句「到底是不是××」就能问住；② 「现状分析与对策」必然要写问题，安到具体企业名下等于用公开报道给企业下未经证实的负面判断；③ 坐实单一企业后结论失去可迁移性，一句「这家其实没这问题」即可推翻。
- **通行写法 5 条**（据真实可核验样例：浙江大学 2019 黄韩忠《办公家具智能仓储管理系统体系结构设计及关键技术研究》全文只写「S集团」（知网学位论文 `CDMD-10335-1019038836`）；西安欧亚学院胡玉洁《EIQ分析在S公司成品仓库规划的应用》只写行业属性「auto parts manufacturer」；硕士论文《S纺织公司仓储管理…》按流程/人员/设备/布局/储位/信息化列现状问题）：
  1. 全文统一代称，不写真名；连可反查的地点、独特设施称呼、具体设备型号与规模数字都不写。
  2. 只写行业属性与规模层级（如「工业用品流通企业的区域自动化总仓」），案例细节前后一致。
  3. 在背景或研究方法段**显式声明匿名化及理由**（保护商业信息、未取得内部数据授权），写明「S公司为依据行业共性典型化构造的案例企业，不对应任何单一特定企业」。
  4. 交代资料来源与数据边界：公开文献 / 行业公开资料 / 一般性实习观察；不掌握企业内部数据；公开报道数据不写成实测值；不虚构效率、差错率、成本指标。
  5. 结论指向「同类企业」并注明适用条件，不作特定企业归因。
- **规范依据**：西南财经大学《案例研究论文写作的基本标准》「论文中不出现案例研究对象公司的名称，若采用实名制需公司盖章许可；写作时对数据做调整以避免涉及商业机密」；Haaga-Helia《Confidentiality of Business and Trade Secrets in the Thesis》要求封面 / 摘要 / 目录 / 引言均去企业名，行业特征亦需处理到不可识别。
- **参考文献的张力**：GB/T 7714 要求题名照录，行业公开资料若题名含企业名须保留 → 须在正文明确声明「文献[n]仅用于说明行业技术形态，与案例企业无对应关系」，且该类资料不得用于支撑案例企业的现状或问题。若学校要求严格匿名（连参考文献也不得含企业名），改用不带企业名的政府 / 行业 / 学术资料替换并重新逐条核验。
- **例外**：学校「真题真做」要求绑定实习单位时，**封面 / 实习单位栏可保留真实企业**，但正文 S 公司仍匿名，两者分开写、不互相指认。

**生成方式**：纯 XML 保真改写——以范样 docx 为容器，只替换 `word/document.xml`，保留全部 26 个 xmlns 声明与 `mc:Ignorable`；删除 drawing / 嵌入字体 / 图片关系 / 元数据作者；写完逐项验证 zip、XML 可解析、格式、引用连续、个人标签残留为 0。
