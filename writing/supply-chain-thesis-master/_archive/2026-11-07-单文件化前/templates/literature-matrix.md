## 字段说明

| 字段 | 填写要求 |
|---|---|
| 编号 | 与文内引用编号可映射 |
| 作者 | 三人以内全列，超过列前三加「等」 |
| 来源 | 期刊名 + 卷期，或学校 + 学位类型 |
| 研究对象 | 哪类企业/仓库/品类 |
| 方法 | 只用原文写的方法，不推断 |
| 核心结论 | 一句话，写原文结论不写自己的评价 |
| 局限 | 原文自述的局限，或你能证明的样本/口径局限 |
| 与本文关系 | 支撑 / 对照 / 反驳，必须选一个 |
| 核验状态 | 已核 / 待核 |
