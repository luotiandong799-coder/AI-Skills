# 工作流 · 论文项目启动

## 触发

用户第一次提出要写供应链毕业论文，或要开新题目。

## 步骤

### 1. 建项目资料夹

路径由用户指定；未指定时建议 `论文项目/<年份>-<题目关键词>/`。目录结构：

```
<项目>/
├── 00-项目记录.md      题目、边界、学校要求、导师意见、待办
├── 01-资料/            原始数据、单据、布局图、观察记录
├── 02-文献/            文献矩阵、检索记录、PDF
├── 03-草稿/            分章节草稿
├── 04-成稿/            排版后文档
└── 05-审查/            核验报告、去重报告、润色对照
```

### 2. 填项目记录（必填七项）

| 项 | 内容 |
|---|---|
| 题目 | 暂定题目 + 备选 |
| 方向 | 仓储 / 库存 / 综合 |
| 研究对象 | 具体名称与范围 |
| 资料条件 | A / B / C 档，附证据清单 |
| 学校要求 | 字数、章节、模板、外文文献要求 |
| 术语表 | 概念、缩写、符号，唯一写法 |
| 待办 | 按阶段列 |

### 3. 判定资料档位并告知用户

按 modules/01 的三档表判定。若为 B 或 C 档，明确说明哪些定量分析做不了，请用户确认后再继续。

### 4. 确认下一步

给出阶段清单：开题 → 文献 → 大纲 → 正文 → 去重 → 润色 → 引用 → 终审。让用户选起点。

## 产出

- 项目目录
- `00-项目记录.md`
- 资料档位判定结论

## 停止条件

资料档位为 C 且用户仍要求定量分析 → 停下说明冲突，不硬做。
