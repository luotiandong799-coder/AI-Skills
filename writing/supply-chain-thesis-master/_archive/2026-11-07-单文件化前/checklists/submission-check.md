# 检查清单 · 交稿前

逐项打勾，不打勾不交。模板参数来源：`references/school-template-guide.md`。

## 一、结构

- [ ] 章节与学校要求一致
- [ ] 摘要（中/英）齐全，关键词数量符合要求
- [ ] 目录与正文标题一致，页码正确
- [ ] 致谢、附录（如有要求）齐全
- [ ] 无空白页、无残留模板示例文字

## 二、格式

- [ ] 页面设置（纸张、页边距）符合模板
- [ ] 正文与各级标题字体字号行距符合模板
- [ ] 标题编号方式统一
- [ ] 图表编号连续、图题表题位置正确
- [ ] 三线表符合要求
- [ ] 页码位置与起始页正确
- [ ] 页眉内容正确

## 三、内容

- [ ] 论证链完整：问题—证据—原因—对策—效果
- [ ] 每个问题都有对应措施
- [ ] 结论未超出数据范围
- [ ] 无行业数据冒充企业数据
- [ ] 数据字典已随附

## 四、引用

- [ ] 文内文末双向对应
- [ ] 参考文献数量满足学校要求
- [ ] 外文文献要求（如需）已满足
- [ ] 格式统一，无编造字段

## 五、提交物

- [ ] 正文文档（按学校命名规则）
- [ ] 查重/AIGC 检测报告（学校要求时）
- [ ] 附件（数据表、问卷、观察记录）
- [ ] 已确认：本地预检不等于学校正式检测
