# 检查清单 · 学术表达审查

规则与阈值唯一来源：`references/academic-writing-rules.md`。本清单只给审查动作与抽样方法。

## 一、抽样方法

全文超过 1 万字时，不逐句读。按章抽：

1. 每章抽 3 段：开头段、中间段、结尾段。
2. 另加全文摘要、结论各 1 段。
3. 抽样段逐句过规则；非抽样段做一次通读，只记明显问题。

## 二、审查动作

| # | 动作 | 判据 |
|---|---|---|
| 1 | 标记 AI 模式 | 按规则第二节内容层模式逐条对照抽样段 |
| 2 | 数阈值 | 高频词每段数、段末套句全文数、加粗数、泛化结尾数 |
| 3 | 查限定词 | 是否丢失「可能/通常/部分样本中」等真实限定 |
| 4 | 查术语一致 | 同一概念全文是否只有一个词 |
| 5 | 查句式节奏 | 是否存在全长句段落、是否句长单一 |
| 6 | 查过度清洁 | 是否被改得过于平滑、失去人味 |
| 7 | 查结构 | 标题层级、段落顺序是否被动过 |

## 四、改写前后比对（必做）

| 项 | 结果 |
|---|---|
| 数字/日期/金额是否变化 | 有 / 无 |
| 公式/符号/单位是否变化 | 有 / 无 |
| 引用键是否变化 | 有 / 无 |
| 参考文献条目是否变化 | 有 / 无 |
| 删除的限定词清单 | 逐条列出 |
| 汉字数变化比例 | 按规则库第五节「保量阈值 + 统计单位」判定，本清单不重复写阈值 |

## 五、不允许的「通过」

1. 只改词不改句式就宣布已去 AI 味。
2. 为压字数大量删句。
3. 声称能通过任何检测平台。
